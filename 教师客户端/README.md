# 教师客户端 · 项目入口

> **教师课堂专用工具**（桃李助手 · 龙爸易教·教师端）：Tauri 绿色 exe，U 盘拷贝部署到教室电脑/智慧屏；

## 一、项目定位（一句话）

**弥补教室电脑/电子白板不足**：素材即取即用、课堂互动工具、备课便利——把老师"现场编例句、带全班验能力"的备课还债变成**双击即用**。**不是点读（避开对外分发版权），是教师课堂工具。**

两条合规路径（与对外产品线分工）：

| 产品线 | 内容 | 分发对象 | 版权依据 |
|---|---|---|---|
| **点读陪练**（对外，本仓库独立项目） | 原创句子/图/音 | 家长/家庭 | 全原创，合规分发 |
| **教师客户端**（本目录） | 人教教材素材（原版点读） | 仅已认证教师课堂 | 课堂教学 = 合理使用范围 |

> 教师客户端吃「英语点读」v1.3.3 现成资产（实际消费 4 包并已按 D09 加密重打包+QA：预装 pep-reader-u01/pep-vocab-cards + 可下载四上 1/2 单元包；其余 zip 随发布清理，D09 ADR-3），零新增内容生产；点读陪练继续走原创线，互不污染。

## 五、关键约定（硬约束，全项目红线）

- **版权**：人教教材「仅供个人教学和学习使用」；课堂使用 = 合理使用范围；商用/对外分发需正式授权
- **合规认证**：微信实名注册（免费，任教年级/科目必填）→ 激活码绑定 → 可追溯、可封禁
- **课堂口令**：一学期有期限，到期默认 B（只读旧、锁新），免费续期
- **零采集**：软件本体不采集儿童数据；白名单上报仅限授权/使用状态；学生名单云端不留
- **AI 边界**：壳内运行时零 AI——AI 全部在内容包生产管线与在线版备课端，AI 不进壳、AI 喂壳
- **双版本**：壳 X.Y.Z（低频）与内容包 manifest+hash（高频）独立演进、互不强绑
- **兼容基线**：Win7 WebView2 停更版**真实上限 109.0.1518.x**（微软官方 2022-12-09：Runtime 109 为 Win7/8/8.1 最后版本）为 H5 内容上限基线；壳最低门槛 `minimumWebview2Version: 108.0.1462.46` 不可上调（提门槛会拒 Win7 启动）

## 五·B、服务器地址配置（部署必读）

**壳端唯一需事先明确的配置 = 服务端地址（api_base）。** 无 CF Worker 时同样适用：
直接指向任意可访问的清单/下载源（含静态托管、GitHub 直链、自建服务器），换地址只改一个文件。

**操作方式（U 盘绿色形态）**：
1. 在 **exe 同目录**放置 `config.json`（模板见 `src/config.example.json`）：
   ```json
   {
     "api_base": "https://你的服务器域名或IP"
   }
   ```
2. 启动即生效（实时读取，无需重启）。**后续更换服务器 = 改这一个字段**，拷贝到教室机同位置即可。
3. 班级进度自动写入 `recents` 子对象，与 `api_base` 共存，互不覆盖（`recents_*` 命令只更新自己的子对象）。

**解析优先级**：`config.json 的 api_base` → 编译期默认（打包时注入 `LOONGEDU_API_BASE`）→ 空（P0 离线模式）。
详细信息：D01 §2 config.json 字段定义、A01 Base URL 约定；下载源绝对 `download_url` 支持见 store.rs `store_download`。
