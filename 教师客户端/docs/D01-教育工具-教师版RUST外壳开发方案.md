# D01 教育工具-教师版 RUST 外壳开发方案（教师客户端）

> 状态：**立项，开发方案 v0.1**。本文档为教师版（教师客户端）的 Rust/Tauri 外壳技术实施方案。
> 上游：`R01-教育工具-教师客户端需求分析与设计方案.md`（需求 v1.0，2026-09-23 合并版）。本方案落技术细节，需求以该文档为准，冲突时本方案为技术执行口径。
> 定位：U 盘拷贝部署的绿色 exe；**客户端与内容包为两个独立版本体系**；教室在线时可鉴权/上报/更新，离线时凭本地缓存照常运行。
> 更新：2026-09-23 ｜ 决策记录见 §10

## 1. 立项背景与目标

### 1.1 目标

- **单一绿色 exe（Tauri/Rust）**，U 盘拷贝即用，覆盖 Win7 + Win11（学校智慧屏双系统默认 Windows）；
- **客户端（壳）与内容包（数据/应用）两个版本体系**独立演进、独立更新；
- 内容包下载时加密、运行时鉴权；可与壳打包到一起离线运行；
- 服务端认证：**扫码（微信）/短信/密码**三方式，本地可缓存凭证（默认 7 天）离线兜底；
- 典型使用流：**在家登录并更新好 → 复制到 U 盘 → 教室运行**；教室能连网则启动鉴权、数据上报、可下载/更新内容包；
- 服务端内容包起步为「简单配置」，后续演进为「内容包市场」。

### 1.2 继承的技术定稿（不再讨论）

| 项 | 结论 |
|---|---|
| 壳框架 | Tauri 2.x（Rust，绿色 exe） |
| Win7 兼容 | 是（WebView2 停更版 Chromium ~108 为 H5 基线） |
| 前端 | 教材点读 HTML 零重写复用 + 壳 UI **React 19 + Vite + TanStack Router**（与点读陪练 WebH5 一致） |
| 认证/托管 | Cloudflare Workers + D1 / R2 + CDN |
| 加密 | 包体 AES + 口令；包 manifest 服务端签名 |
| 数据原则 | 教师版零采集儿童数据；仅上报授权/使用状态（见 §5.3） |

## 2. 总体架构：双版本体系

### 2.1 核心决策：客户端与内容包解耦

```
┌─ 客户端（壳） ──────────────────────────────┐   ┌─ 内容包（数据/应用） ────────────┐
│ 版本：X.Y.Z（语义化，低频更新）               │   │ 版本：独立递增 + content_hash    │
│ 更新：tauri-plugin-updater（安装包）          │   │ 更新：内容包 manifest 拉取/导入 │
│ 职责：认证/凭证、内容包管理、窗口、Rust 命令层 │   │ 职责：教材点读、可下载应用、抽卡 │
│ 静态：壳 UI + 预装初始内容包                  │   │ 存储：本地 packages/ 目录       │
└─────────────────────────────────────────────┘   └────────────────────────────────┘
        同体：壳自带预装包（P0 离线立即可用）
        分离：壳更新不碰内容包；内容包更新不升级壳
```

**版本矩阵约束（写进内容包 manifest）：**

| 字段 | 含义 |
|---|---|
| `package_id` | 内容包唯一 id（如 `pep-reader` / `u01-content`） |
| `package_version` | 内容包自身版本（独立递增） |
| `min_shell_version` | 所需最小壳版本（旧壳不加载新包，提示升级壳） |
| `required_license_level` | 所需口令级别（基础包=Level 1；敏感教材包=Level 2） |
| `content_hash` | 完整性校验（防篡改/损坏） |
| `size` / `download_url` | 分发元数据 |

### 2.2 目录结构

```
教师版安装目录（U 盘拷贝即用）
├── TeacherClient.exe          # Tauri 绿色 exe（壳）
├── packages/
│   ├── pep-reader/            # 预装内容包（教材点读，P0 即带）
│   │   ├── manifest.json      # 签名 manifest
│   │   └── data/              # 加密/内联素材
│   └── <package_id>/          # 后续下载/导入的内容包
├── cache/
│   └── credential.bin         # 加密凭证（7 天缓存）
└── config.json                # 本地配置（口令到期日/壳版本等）
```

**config.json 字段**（v0.3 决策点4 定稿；`recents.rs` 结构化读写，未知字段保留）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `api_base` | string | **服务端地址（唯一需事先明确的配置）**。解析优先级：config.json 显式字段 > 编译期默认（`LOONGEDU_API_BASE` env，打包时注入）> 空（= P0 离线模式）。示例：`https://edu-api.<workername>.workers.dev`（CF 过渡）/ `https://api.loongba.education`（生产）；详见 A01 §Base URL |
| `recents` | object | 班级进度断点（`recents_*` 命令读写此子对象）；旧版纯进度 map 顶层格式自动迁移 |

> 生命周期：`config.json` 跟随 exe（U 盘绿色目录形态），换机器即带走；`recents_set` 只更新 `recents` 子对象，**不会覆盖** `api_base`。

## 3. 认证子系统

### 3.1 三方式认证 + 凭证缓存

```
【认证方式】（服务端签发凭证）
  A. 微信扫码：壳内展示二维码 → 手机微信扫 → 服务端确认 → 凭证
  B. 短信验证码：手机号 → 短信码 → 凭证
  C. 账号密码：注册时设密码 → 直接换凭证
        │
        ▼
  凭证（JWT/会话，含教师身份+授权级别+到期时间）
   → 本地加密缓存（默认 7 天有效期，可配置）
   → 有效期内核离线运行全部功能；到期需联网重新认证
```

**凭证缓存策略：**

| 项 | 方案 |
|---|---|
| 缓存内容 | 凭证 token + 教师身份摘要 + 授权级别 + 到期时间（客户端加密，非明文） |
| 有效期 | 默认 7 天（`config.json` 可配），到期本地标记需重新认证 |
| 离线使用 | 凭证未过期且本地签名校验通过 → 直接进入（无需联网） |
| 在线刷新 | 教室联网时启动即尝试刷新凭证（延长 7 天），静默失败不阻断使用 |

### 3.2 授权分层（认证 vs 口令）

| 层 | 机制 | 过期处理 | 作用 |
|---|---|---|---|
| **认证凭证** | 登录三方式换凭证 | 7 天缓存到期 → 需联网重登录 | 证明"使用者是活跃教师" |
| **课堂口令** | 服务端签名口令包 | 一学期 → 到期锁新内容 | 证明"授权周期内可继续解锁" |

- 两层独立：凭证过期重登录即恢复；口令过期则即使登录也无法解锁**新**内容（§4.4 过期策略）；
- 内容包运行时鉴权 = **凭证有效 + 口令级别达标 + 范围匹配** 三重闸门。

## 4. 内容包子系统

### 4.1 内容包形态与安全

```
内容包 = zip（manifest.json 签名 + data/ 加密素材）
  ├─ manifest.json        # 服务端私钥签名（ed25519），防篡改/伪造
  ├─ data/                # 教材点读 HTML/音频/图片（AES 加密存储）
  └─ 口令派生密钥         # 运行时用课堂口令/凭证派生密钥解密（不落盘明文）
```

- **下载时加密**：HTTPS（传输）+ 包体 AES（静态）；
- **运行时鉴权**：加载包 → 验 manifest 签名 → 验凭证 → 派生密钥解包 → 进入可用状态。

### 4.2 内容包获取通道（双通道）

| 通道 | 场景 | 说明 |
|---|---|---|
| **服务端下载** | 教室可联网 / 在家预更新 | 拉取 `packages/manifest` → 对比本地 → 只下增量/新包 → 校验 hash |
| **U 盘导入** | 教室无网 / 批量分发 | 检测 U 盘根目录 `packages/*.zip` → 校验签名 → 并入本地 `packages/` |

### 4.3 与壳的打包协同（离线运行）

- 壳自带**预装初始内容包**（教材点读 P0 即含，免任何操作离线可用）；
- 后续内容包：下载/导入后落入 `packages/`，壳启动时按 `manifest` 索引构建「可用内容列表」；
- **壳与内容包版本互不强制**：壳更新不迁移内容包；内容包版本高于 `min_shell_version` 才加载，否则提示升级壳。

### 4.4 口令过期行为（与需求文档一致）

| 状态 | 行为 |
|---|---|
| 口令有效期内 | 全部已下载内容可用，可下载新内容 |
| 到期前 15 天 | 本地提示续期（在线一键续期，免费） |
| **到期后（默认 B）** | **只读旧、锁新**：已下载内容可继续用；不能下载/导入新内容包、不能配置新名单；新包 manifest 要求 `required_license_level` 达标才放行 |

## 5. 网络行为（教室运行态）

### 5.1 运行状态机

```
启动
 ├─ 离线（无网）：凭证缓存有效 → 离线模式（全部本地内容可用）
 ├─ 在线-弱网：登录态校验 → 失败不阻断进入 → 异步重试
 └─ 在线-稳定：
      ① 鉴权刷新（延长凭证）
      ② 数据上报（见 5.3）
      ③ 内容包更新检查（packages/manifest 对比 → 提示/自动下载）
      ④ 口令续期检查（到期前提醒）
```

### 5.2 「在家预置 → U 盘 → 教室」典型流

```
在家（有网）：
  1. 登录（扫码/短信/密码 → 凭证缓存 7 天）
  2. 下载/更新内容包（或 U 盘导入）
  3. 确认口令有效期内
  4. 拷贝整个安装目录到 U 盘
教室（可能无网）：
  - 双击 exe → 凭证有效 → 直接进入离线模式
  - 有网：鉴权刷新 + 数据上报 + 可选内容包更新
  - 无网：离线模式照常上课（预置内容全可用）
```

### 5.3 数据上报范围（边界定义，防红线误踩）

> **口径：只上报"授权/使用状态"，不上报儿童学习数据，不改零采集原则。**

| 上报字段 | 类型 | 用途 |
|---|---|---|
| 教师账号标识（openid 哈希） | 身份 | 授权管理、安全性审计 |
| 客户端版本 + 已安装内容包清单 | 元数据 | 版本分布、兼容性分析 |
| 口令状态（到期日/有效） | 授权 | 续期提醒、盗版检测 |
| 内容包使用统计（聚合：运行次数/时长） | 运营 | 内容包市场冷启动数据（不涉及学生） |
| 崩溃日志（可选、匿名） | 诊断 | 稳定性 |

**禁止上报**：学生名单、学习行为、练习成绩、任何可定位到儿童个人的数据。上报实现为**白名单字段**，新字段须评审后加入。

### 5.4 AI 能力边界（壳内运行时零 AI）

> 来源：需求文档 §5.2（Oracle 三关校准）。本方案从技术侧落实同一结论。

**原则：AI 全部发生在生产期（内容包管线）或在线版（教师备课端）；壳运行时不做任何 AI 推理。**

- 壳内**不含**：ASR 实时口语评分、OCR 批改、本地 LLM、情感/注意力识别、声音克隆、实时翻译——见需求文档 §5.2「不做」清单；
- 壳内**只承载**：预生成内容（TTS 音频/配图/LLM 产出的练习与教案）——这些在内容包生产管线完成，运行时仅解密加载；
- 技术含义：
  - Rust 依赖**不引入** ML 推理库（ort/tokenizers/wasm-llm 等），避免包体积膨胀与 Win7 算力风险；
  - 前端 H5 **不调用** Web Speech API / MediaRecorder 采集音频做分析（Chromium 108 有 API 但零儿童数据原则禁止采集）；
  - 在线版 AI 备课助手（R4/R5）产出的内容经「内容包」通道进入壳，壳侧零 AI 代码。
- 例外登记：若后续确需壳内 AI（如本地化小模型），须先过 Win7 算力 + 零儿童数据 + 教师时间三关评审，否则不进入壳。

## 6. 服务端设计（起点：简单配置 → 演进：市场）

### 6.1 MVP（简单配置，P2 交付）

| 接口 | 说明 |
|---|---|
| `POST /api/auth/wechat/qr` + `/status` | 微信扫码登录（二维码 + 轮询确认） |
| `POST /api/auth/sms` + `/verify` | 短信验证码登录（腾讯云短信） |
| `POST /api/auth/password` | 密码登录 |
| `GET /api/packages/manifest` | 内容包清单（id/版本/hash/要求/URL），静态 JSON 起步 |
| `GET /api/packages/<id>/<ver>` | 内容包下载（R2 + CDN） |
| `POST /api/report/ingest` | 数据上报（白名单字段） |
| `POST /api/license/renew` | 课堂口令签发/续期 |

- 内容包在服务端 = **一个 manifest JSON + R2 文件桶**，运营侧手工配置即可上新包（无需代码发布）。

### 6.2 演进：内容包市场

| 阶段 | 能力 | 服务端变化 |
|---|---|---|
| 简单配置（P2） | 固定清单，手工维护 | 静态 manifest + R2 |
| 包市场 v1（P4+） | 分类/搜索/版本管理/下载统计 | D1 存包元数据表 + 管理后台 |
| 包市场 v2（远期） | 评分/创作者上传/审核流 | 上传 API + 审核工作流 |

## 7. Rust 工程结构

### 7.1 仓库布局（新工程建议独立仓 `teacher-client/`）

```
teacher-client/
├── Cargo.toml                 # workspace root
├── src-tauri/
│   ├── Cargo.toml             # tauri 壳 crate
│   ├── tauri.conf.json        # 应用配置（窗口/plugins/identifier）
│   ├── capabilities/          # 权限声明（fs/updater/dialog…）
│   └── src/
│       ├── main.rs            # 入口 + 启动流程（认证检查 → 加载内容列表 → 主窗口）
│       ├── lib.rs
│       ├── state.rs           # AppState：凭证/口令/版本/packages 索引
│       ├── error.rs           # 统一错误类型
│       └── commands/
│           ├── mod.rs
│           ├── auth.rs        # 登录三方式 / 凭证读写（加密）/ 7 天缓存
│           ├── package.rs     # 内容包：下载/解密/导入(U盘)/列表/校验
│           ├── license.rs     # 口令校验（签名+到期日）/续期提示
│           ├── report.rs      # 数据上报（白名单字段）
│           └── window.rs      # 全屏/退出/快捷键
├── ui/                        # 壳 UI（Vue3 或 Svelte + Vite）
│   ├── src/                   # 应用列表/下载管理/口令状态/抽卡入口
│   └── dist/                  # 构建产物（Tauri 前端静态资源）
├── packages-embedded/         # 预装内容包（教材点读 P0）
│   └── pep-reader/…
└── release/                   # 产出：绿色 exe + U 盘拷贝说明
```

### 7.2 关键依赖

| 用途 | crate / 插件 | 说明 |
|---|---|---|
| 壳框架 | `tauri` 2.x | 核心 |
| 认证 HTTP | `reqwest` | 调 Workers API |
| 签名校验 | `ed25519-dalek` / `ring` | manifest + 凭证签名验证 |
| 加密 | `aes-gcm` / `chacha20poly1305` | 包体 + 凭证加密 |
| 哈希 | `sha2` | 内容包 hash 校验 |
| 解压 | `zip` | 内容包解包（仅内存/临时区） |
| 本地存储 | `tauri-plugin-store` | config.json / 凭证文件 |
| 壳更新 | `tauri-plugin-updater` | 客户端版本升级 |
| 文件/对话框 | `tauri-plugin-fs`、`tauri-plugin-dialog` | U 盘导入 / 选择目录 |
| 序列化 | `serde` / `serde_json` | 全部结构 |

> 注意 Win7：`keyring` 的 Windows 凭证库在 Win7 可用性一般 → 凭证缓存用 **AES 加密文件**（密钥存壳内/DPAPI 兼容层）而非系统 Credential Manager。

### 7.3 关键 Rust 命令清单（前端 invoke 面）

| Command | 前端调用场景 | 说明 |
|---|---|---|
| `auth.scan_qr` / `auth.check_status` | 登录页 | 微信扫码全流程 |
| `auth.sms_send` / `auth.sms_verify` / `auth.login_password` | 登录页 | 短信/密码 |
| `auth.cached_credential` | 启动检查 | 返回缓存凭证状态（7 天） |
| `package.list_installed` | 应用/内容列表 | 本地可用包索引 |
| `package.download` / `package.import_usb` | 下载管理 / U 盘导入 | 加密下载/导入解包 |
| `package.load` | 运行按钮 | 运行时鉴权 + 解包上线 |
| `license.validate` / `license.renew_hint` | 口令状态 | 签名+到期日校验 / 续期提醒 |
| `report.push` | 启动/后台 | 白名单字段上报 |
| `window.fullscreen` / `window.exit` | 壳 UI | 教室大屏 |

## 8. 安全设计

| 项 | 方案 | 边界 |
|---|---|---|
| 凭证存储 | AES 加密文件（密钥壳内派生 + DPAPI 兼容层） | 挡普通顺手操作；不防专业内存转储 |
| 内容包 | 静态 AES + 口令派生密钥；manifest ed25519 签名 | 挡住 99% 用户；不做强 DRM |
| 传输 | 全 HTTPS（WeChat/Workers/R2） | — |
| 时间篡改 | 口令到期本地校验 + 服务端签发时校准；在线刷新时校准本地时钟 | 接受离线改时钟绕过（简单保护定位） |
| 上报过滤 | 字段白名单 + 禁儿童数据（§5.3） | 评审后新增字段 |

## 9. 实施计划（P0-P4，细化）

| 阶段 | 内容 | 验收标准 | 前提 |
