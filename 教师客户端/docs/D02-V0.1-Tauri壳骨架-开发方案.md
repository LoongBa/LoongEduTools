## 2. 目标与原则

### 2.1 目标（P0 达成）

1. `TeacherClient.exe` 绿色单文件（Tauri 2.x），U 盘拷贝到 Win7/Win11 双击即开全屏；
2. 预装**教材点读**（首个内容包，旧点读原样内容、Chrome 61 兼容 HTML 复用，零重写）；
3. 预装 **R7 PEP 词卡包**（976 词 × 图+音+例句，复用 PEP 词库 + LoongMediaTools 生产管线）；
4. **R6 一键开课**：记忆各班上次单元 → 秒进全屏点读；
5. 内容包按 Schema v1.0 打包（manifest 签名 + data/ AES 加密 + package.json 预检），**验证双版本体系可在壳内加载**；
6. 壳 UI 用 **React + Vite**（与点读陪练 WebH5 实际技术栈一致）。

### 2.2 原则

- **离线优先**：P0 全离线可跑（无认证、无网络、无云端依赖），教室断网照常；
- **零重写**：教材点读 HTML/base64 内联直接作为内容包资源，壳不改造其内部逻辑；
- **简单保护**：加密/签名挡 99% 顺手拷贝，不做强 DRM（对齐 Schema §6）；
- **壳薄**：壳只做窗口/全屏/内容包加载/一键开课/导航；业务逻辑不进壳；
- **Win7 兼容基线**：Chromium 108 为 H5 上限；Rust/Tauri 2.x 支持 Win7（需手动装 WebView2）。

## 3. 变更设计

### 3.1 框架决策修正（对齐在线版实际）

| 项 | 原决策（需求/RUST 方案） | **修正** | 依据 |
|---|---|---|---|
| 壳 UI 框架 | Vue 3 或 Svelte（"与在线版决策一致"） | **React 19 + Vite + TanStack Router** | 点读陪练 WebH5 实际为 React 19 + TanStack Router + Vite（`点读陪练/WebH5/package.json`）；"与在线版一致"的引用目标是 React，非 Vue/Svelte |

> 说明：需求方案 §6.2 与 RUST 方案 §1.2 的"Vue3/Svelte"表述基于当时未核实的假设，P0 以 React 为准（在线版既有先例 + 团队已有 React 经验）。壳 UI 框架与"主应用教材点读 HTML 零重写"不冲突——HTML 作为内容包资源被 `WebviewWindow` 加载，不经过 React 组件树。

### 3.2 工程初始化（新建 src/）

**现状**：无工程。**方案**：`create-tauri-app` 脚手架（React+TS+Vite 模板）。

```
教师客户端/
├── src/                          # Tauri 工程（本阶段新建）
│   ├── Cargo.toml                # workspace（壳 crate + 后续模块）
│   ├── src-tauri/
│   │   ├── Cargo.toml
│   │   ├── tauri.conf.json       # 窗口/插件/identifier 配置
│   │   ├── capabilities/         # 权限声明（fs/dialog 等）
│   │   ├── icons/                # 应用图标（复用 RedTools 1024 图标 → Tauri 各尺寸）
│   │   └── src/
│   │       ├── main.rs           # 入口 + 启动流程
│   │       ├── lib.rs
│   │       ├── state.rs          # AppState：疑存/版本/内容包索引
│   │       ├── error.rs
│   │       └── commands/
│   │           ├── mod.rs
│   │           ├── package.rs    # 内容包：预装发现/校验/解密加载
│   │           ├── window.rs     # 全屏/退出/快捷键
│   │           └── recents.rs    # R6 一键开课（各班最近单元）
│   ├── ui/                       # 壳 UI（React + Vite）
│   │   ├── package.json
│   │   ├── vite.config.ts
│   │   └── src/                  # 应用列表页 / 一键开课页 / 全屏入口
│   └── packages-embedded/        # 预装内容包（构建期嵌入）
│       └── pep-reader/           #   教材点读包
│       └── pep-vocab-cards/      #   R7 词卡包
└── scripts/                      # 构建脚本（内容包打包 + Tauri 集成）
```

**涉及文件**：`教师客户端/src/**`（全新建）；`教师客户端/README.md`（更新目录结构）。

### 3.3 内容包打包（预装包 Pep-reader / Pep-vocab-cards）

**现状**：Schema 已冻结，无打包脚本。**方案**：新建 `scripts/pack_content.py`，按 Schema v1.0 产出预装包：

```
输入：RedTools/publish/学科/新英语四上点读1单元.zip（教材点读）+ PEP词库 976 词素材
流程：扁平化 HTML 资源 → 整理为 data/（app/ 结构）→ 生成 package.json 与 manifest →
      对 data/ AES-256-GCM 加密（HKDF 派生密钥，P0 用开发期口令）→ 服务端签名占位
      （P0 本地自签测试密钥；P1 切换 Workers 真实签名）→ 产出 zip
输出：packages-embedded/pep-reader/ + packages-embedded/pep-vocab-cards/
```

**R7 词卡包**：PEP 词库 976 词 → 复用 LoongMediaTools 音频（en-GB-SoniaNeural）+ 词卡 HTML（认词闪卡样式）→ 按单元分文件，data 型内容包。

**涉及文件**：`教师客户端/scripts/pack_content.py`（新建）、`S01-内容包与口令包Schema_v1.0.md`（无变更）。

### 3.4 壳启动流程 + 内容包加载（core）

**现状**：无壳。**方案**：

```
main.rs 启动
  → 解析 tauri.conf（窗口无边框/最大化可选）
  → AppState 初始化：扫描 packages-embedded/（预装）与磁盘 packages/（后续 P2 导入）
  → 读 manifest → 校验签名（P0 自签密钥）→ 构建可加载内容包索引
  → 主窗口加载壳 UI
  → 壳 UI（React）拉取索引 → 应用列表页渲染
  → 用户点「教材点读」→ invoke package.load → 解密 data/ → WebviewWindow 加载 app/index.html
  → F11/快捷键 全屏（R6 秒进全屏）
```

**Rust 命令层（P0 实装 3 个命令）**：

| Command | 前端调用 | 说明 |
|---|---|---|
| `package.list_installed` | 应用列表页 | 返回可加载内容包清单（预装 + 磁盘） |
| `package.load` | 点「打开」 | 鉴权（P0 免认证）→ 解密 data/ 到临时区 → 返回待加载路径/URL |
| `recents.get/set` | 一键开课页 | 记录/读取 每班上次单元（localStorage 或 tauri-plugin-store） |

**涉及文件**：`src-tauri/src/**`（新建）、`ui/src/**`（新建）。

### 3.5 R6 一键开课

**现状**：无。**方案**：壳 UI 增加「一键开课」页：
- 进入后显示班级列表（本地维护，P3 多班看板复用同数据）；
- 每班显示「上次进度：XX 单元 XX 小节」+ 「秒进」按钮；
- 点「秒进」→ invoke recents.get → package.load 对应包 → 直接跳转上次单元全屏；
- 开课后返回 → recents.set 更新进度（简化版：离开时记录所在单元）。

**涉及文件**：`ui/src/routes/quickstart.*`、`src-tauri/src/commands/recents.rs`。

### 3.6 双击即开 + 全屏

**现状**：无。**方案**：
- `tauri.conf.json`: `mainWindow` `fullscreen: false`，`resizable: true`（教室可缩放）；
- 壳 UI 大屏按钮 → invoke `window.toggle_fullscreen`；
- 快捷键 F11（全屏切换）+ Esc（退出全屏）；P4 补全局快捷键（不打断教学）；
- Win7：`tauri.conf` 不启用不支持的窗口功能（vibrancy/transparency 等）；WebView2 缺失时引导安装说明（README 提及）。

**涉及文件**：`src-tauri/tauri.conf.json`、`src-tauri/src/commands/window.rs`。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| Rust 工具链首次构建耗时（依赖下载） | P0 开工延迟 | 提前 `cargo build` 预热；可先搭壳 UI 骨架并行 |
| Win7 上 WebView2 停更版兼容问题 | H5 内容异常 | 内容以 Chromium108 为基线（旧点读 Chrome61 兼容，预期安全）；Win7 真机验证提前 |
| 内容包加密/签名 P0 实现复杂度超预期 | P0 范围蔓延 | P0 用自签测试密钥 + 简化解密（整包解密），P1 换真实签名/细分加密 |
| React+TanStack Router 壳 UI 依赖安装体积 | 包体积超标 | 壳 UI 精简路由（2-3 页）；预算 < 15 MB，超标可砍路由库用手动切页 |
| 「旧点读 HTML 零重写」在 WebView2 渲染异常 | 主应用不可用 | 冒烟优先验证教材点读页；若有问题优先修壳加载层而非改内容 |
