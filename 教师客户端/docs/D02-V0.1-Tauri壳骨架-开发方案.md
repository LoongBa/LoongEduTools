## 2. 目标与原则

### 2.1 目标（P0 达成）

1. `TeacherClient.exe` 绿色 **目录形态**（Tauri 2.x，免安装、无需安装器），U 盘拷贝到 Win7 SP1 x64 / Win11 双击即开全屏；
2. 预装**教材点读 1 单元**（首个内容包，旧点读原样内容、Chrome 61 兼容 HTML 复用，零重写）；
3. 预装 **R7 PEP 词卡包**（976 词 × 图+音+例句，复用 PEP 词库 + LoongMediaTools 生产管线）；
4. **R6 一键开课**：记忆各班上次单元 → 秒进全屏点读；
5. 内容包按 S01 Schema v1.0 打包（manifest 签名 + data/ AES 加密 + package.json 预检），验证双版本体系在壳内加载；
6. 壳 UI 用 **React 19 + Vite + TanStack Router**（与点读陪练 WebH5 实际技术栈一致）。

### 2.2 原则

- **离线优先**：P0 全离线可跑（无认证、无网络、无云端依赖），教室断网照常；
- **零重写**：教材点读 HTML/base64 内联直接作为内容包资源，壳不改造其内部逻辑；
- **简单保护**：加密/签名挡 99% 顺手拷贝，不做强 DRM（对齐 S01 §6）；
- **壳薄**：壳只做窗口/全屏/内容包加载/一键开课/导航；业务逻辑不进壳；
- **Win7 兼容基线**：Chromium 108 为 H5 上限；Win7 SP1 x64 为 P0 目标（x86 留 P2 评估）；
- **绿色目录非单文件**：`TeacherClient.exe` + `packages-embedded/` 同目录，免安装器（WebView2 一次性安装见 §3.6）。

## 3. 变更设计

### 3.1 框架决策（React 19，Oracle 确认通过）

| 项 | 决策 | 依据 |
|---|---|---|
| 壳 UI 框架 | **React 19 + Vite + TanStack Router** | 点读陪练 WebH5 实为 React 19.2 + @tanstack/router 1.168 + Vite 7.3 + @vitejs/plugin-react 5（`点读陪练/WebH5/package.json`）；团队已有先例 |

> Oracle 评审：框架决策通过，但有 2 个配置级注意点（必做）：
> 1. **Vite build.target 必须显式设 `'es2022'`**（Chromium 108 完全支持；默认 `'modules'` 对老内核有风险）；
> 2. **壳 UI 不建议复用 Tailwind v4 + lightningcss**（点读陪练所用）——`oklch()/color-mix()` 在 Chromium 108 仅部分支持（完整需 111+）。壳 UI 仅 2-3 页，**用 Tailwind v3 或纯 CSS**。

```ts
// ui/vite.config.ts 关键配置
export default defineConfig({
  build: { target: 'es2022', minify: 'esbuild', sourcemap: false },
  esbuild: { jsx: 'automatic', jsxImportSource: 'react' },   // React 19 JSX 自动 runtime
});
```

### 3.4 壳启动流程 + 内容包加载（core）

**现状**：无壳。**方案**：

```
main.rs 启动（Oracle 修订版顺序）
  → ① check_webview2_runtime()          # ★ Win7 关键：注册表检测，缺失 → dialog 引导装（§3.6）
  → ② 解析 tauri.conf；单实例守卫（插件）
  → ③ AppState 初始化：扫描 packages-embedded/ + 磁盘 packages/
  → ④ validate_min_shell_version()      # ★ 内容包 min_shell ≤ 壳版本才入索引
  → ⑤ verify_manifest_signatures()      # 自签密钥验签（P0）
  → ⑥ 主窗口（label="main"）加载壳 UI
  → ⑦ 壳 UI 拉取索引 → 应用列表渲染
  → ⑧ 点「打开」→ invoke package.load → 解密 data/ 至系统 TEMP 临时区
       → content 窗口（label="content"，startup hidden）show + set_focus + 加载 app/index.html
  → ⑨ F11/Esc 全屏切换（content 窗口内）
```

**Rust 命令层（P0 实装 5 命令）**：

| Command | 前端调用 | 说明 |
|---|---|---|
| `package.list_installed` | 应用列表页 | 返回可加载内容包清单（预装 + 磁盘） |
| `package.load` | 点「打开」 | 鉴权（P0 免认证）→ 解密 data/ 到系统 TEMP → show content 窗口并加载 |
| `package.unload` | 关闭内容窗口 | ★ 清理临时区（remove_dir_all）+ 关闭 content 窗口（Oracle 必改） |
| `window.toggle_fullscreen` | 大屏按钮/F11 | 全屏切换（content 窗口） |
| `recents.get/set/list` | 一键开课页 | 每班上次单元（tauri-plugin-store 持久化，§3.5） |

**Shell↔Content 通信（Oracle 必改，事件系统）**：

```
Content → Shell：app_handle.emit("content:progress", { unit, section, ts })
   内容 HTML 注入一行桥（零重写原则，package.load 时 eval_js 注入）：
   window.addEventListener('page-hide', ...) 或 每切单元 emit
Shell → Content：app_handle.emit_to("content", "shell:goto", { unit })
```

**涉及文件**：`src-tauri/src/**`（新建）、`ui/src/**`（新建）。

### 3.5 R6 一键开课（★ Oracle 引用改动：持久化方案）

**现状**：无。**方案**：壳 UI 增加「一键开课」页：

- 班级列表本地维护（P3 多班看板复用同数据）；
- 每班显示「上次进度：XX 单元 XX 小节」+ [秒进]；
- 秒进 → invoke recents.get → package.load → content 窗口直达上次单元全屏；
- **★★ 持久化（Oracle 阻塞项 G-1）**：**禁用 localStorage**（WebView2 localStorage 在系统 AppData，换机器即丢）；用 `tauri-plugin-store` 写 **exe 同目录 `config.json`**（`resource_dir()/config.json`），进度跟随 U 盘走；
- **★★ 断点恢复（Oracle 建议 G-3）**：内容 HTML **每次切换单元即 emit `content:progress`**，Shell 收到即 `recents.set`（而非"离开时记录"）——崩溃/断电不丢进度。

```rust
// recents 存储（tauri-plugin-store 路径指向 exe 同目录）
let store = StoreBuilder::new(app, "config.json".into())
    .path(app.path().resource_dir()?.join("config.json"))
    .build()?;
```

**涉及文件**：`ui/src/routes/quickstart.*`、`src-tauri/src/commands/recents.rs`。

### 3.6 双击即开 + 全屏 + Win7 WebView2 部署（★ Oracle 阻塞项 E）

**现状**：无。**方案**：

- `tauri.conf.json` **双窗口骨架**（Shell 与内容分离，§3.4 佐证）：

```json
"app": {
  "windows": [
    { "label": "main",    "url": "dist/index.html", "fullscreen": false, "resizable": true },
    { "label": "content", "url": "about:blank",      "visible": false,   "fullscreen": true }
  ]
}
```

- F11（全屏切换）+ Esc（退出全屏）；P4 补全局快捷键；
- Win7：不启用 vibrancy/transparency 等不支持特性。

**★ Win7 WebView2 部署方案（Oracle 阻塞项，P0 必须落地）**：

> 事实：Win7 **不预装** WebView2（停更于 2023-01，Chromium ~108）；Tauri 官方对 Win7 的支持仅在 bundle/安装器层面（`embedBootstrapper`），而 P0 是绿色目录不打安装器 → **必须自带 WebView2 部署引导**。

**方案 A（推荐，P0 采用）**：随包附 `MicrosoftEdgeWebview2Setup.exe`（在线 bootstrapper ~2MB）+ Rust 启动期注册表检测 + 原生对话框引导。

```
部署目录：
TeacherClient.exe
packages-embedded/
MicrosoftEdgeWebview2Setup.exe      # ← 随 U 盘分发（~2MB）
install_webview2.bat                # ← 可选：双击静默安装

启动检测（webview2.rs，#[tauri::command] 或 setup 阶段）：
  读 HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BEE-13A647FE2BA7}
  → 存在（版本 ≥ 108）→ 继续
  → 缺失 → tauri-plugin-dialog 原生提示：
      "首次使用需安装 WebView2 运行时（约 2 分钟，仅需一次）[去安装]/[退出]"
      → 去安装 → 启动同目录 MicrosoftEdgeWebview2Setup.exe → 完成后重启 exe
```

```json
"bundle": {
  "windows": {
    "webviewInstallMode": { "type": "skip" },            // P0 不打 .msi，skip 避免 bundle 报错
    "minimumWebview2Version": "108.0.1462.46"
  }
}
```

> **方案 B（fixedRuntime，~150MB，P2 评估）**：`webviewInstallMode.type: "fixedRuntime"` 把 WebView2 运行时目录与 exe 同 U 盘——真正"双击即用"但体积代价大。P0 用 A，P2 分发阶段再评估 B。

**涉及文件**：`src-tauri/tauri.conf.json`、`src-tauri/src/webview2.rs`、`src-tauri/src/commands/window.rs`。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| Rust 工具链首次构建耗时（依赖下载） | P0 开工延迟 | 提前 `cargo build` 预热；壳 UI 骨架并行搭建 |
| Win7 上 WebView2 停更版兼容问题 | H5 内容异常 | 内容以 Chromium108 为基线（旧点读 Chrome61 兼容）；Win7 SP1 x64 真机验证提前；缺失引导（§3.6） |
| 整包解密 → 逐文件加密 P1 迁移（Oracle D） | P1 需重打包内容包 | **P0 末尾冻结 pack_content.py"整包解密"分支**；强制输出 schema_version；P1 切逐文件时检测旧包提示重打包（已入 §3.3） |
| React+TanStack Router 壳 UI 依赖体积 | 包体积超标 | 壳 UI 精简路由（2-3 页）；预算 < 15 MB；不用 Tailwind v4（兼容 + 体积双因） |
