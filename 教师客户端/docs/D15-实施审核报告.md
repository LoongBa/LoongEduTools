## 二、代码走查

### 2.1 Rust：unload 清理链重构（行为不变）

- **变更**：`unload` 命令壳保留 hide_watermark + destroy（依赖 AppHandle），清理链后段
  （clear_serve_root + clear_content_key）抽为 `run_unload_cleanup(win_destroyed) -> Vec<UnloadStep>`。
- **行为等价性**：原实现无条件执行 clear_serve_root + clear_content_key；新实现由命令壳
  恒调用 `run_unload_cleanup(destroyed)`，函数内部同样无条件执行两步 → **行为等价** ✓
- **容错语义**：`destroyed=false`（无 content 窗口）时跳过 WindowDestroyed 步骤记录，
  但 clear 两步仍执行 → 与原 `if let Some(w) = ...` 分支语义一致 ✓
- **单测**：3 测覆盖全序/容错/幂等，98/98 全过 ✓
- **无告警**：cargo check 0 warning（无未用 enum/字段）✓
