## 2. 目标与原则

1. **四项全部三绿交付**：`tsc --noEmit` + `vite build` + `cargo check` 全 exit 0；`pnpm test` 保持 33 例绿。
2. **零新 Web 依赖优先**：能用浏览器原生 `window.print()` + `@media print` 解决的不引 npm 库；Rust 侧新依赖需 Oracle 点头。**已点头项（Oracle 审核 B1）**：`tauri-plugin-global-shortcut`（官方维护插件）——跨窗口全局热键在 Tauri 2 无非插件替代方案，**这是本迭代唯一新增 Rust 依赖**。
3. **零采集红线不破**：打印/导出/浮层/反思本全部本地——反思本存 localStorage（可选导出文件到用户自选路径），不上报、不入 report 队列。
4. **D05 交互为准**：浮层形态、快捷键行为以 D05 §2.4.4/L145/L165 为准，方案只做细化不改设计意图。
5. **最小增量**：不借机重构 TimerView/CheckinView；不动 server/、不动内容包生产。

## 3. 变更设计（逐项：现状 / 方案 / 涉及文件）

### 3.1 R18 打印形态（最小增量，先行）

**现状**：CheckinView 有三态打卡表 + 完成度条 + 打印零支持；`checkin-actions`（L168-175）只有「编辑名单」「+ 任务」。

**方案**：
1. `CheckinView.tsx` actions 区新增「🖨 打印打卡单」按钮 → `window.print()`。
2. `App.css` 新增 `@media print` 块——**⚠️ 规则一律按视图容器 scope（Oracle M-6）**：选择器前缀用 `.view-checkin` / `.view-reflection`（各视图根容器 class，实施时在视图根 div 上补），**禁止全局裸 `.sidebar{display:none}` 这类跨视图生效的规则**（`.sidebar`/`.shell`/`.ghost-btn` 是全视图共享选择器，裸规则会让打卡单打印样式残留到反思本）。打印块内部结构：
   - 每个视图 scope 内隐藏壳框架（侧栏、顶栏、导航、按钮、角标、banner）；
   - 打卡表格全宽、黑字白底、去阴影/圆角、边框实线；
   - 完成度进度条**转纸面形态**（打印不显示颜色块，改显示 `○/◐/●` 字符——数据模型已存三态，直接映射）；
   - `thead` 重复（`display: table-header-group`）、避免行内断裂（`break-inside: avoid`）；
   - 页眉页脚：标题「朗读打卡单 · 班级 · 日期」（日期取打印当天，非 localStorage 数据）。
3. **无 Rust 改动**（方案 A 已确认 `window.print()` 可用，librarian + Oracle 双确认）。

**涉及文件**：`src/ui/CheckinView.tsx`、`src/ui/App.css`。

**验收**：打印预览只见打卡单内容、无壳框架；三态在纸上可辨；A4 分页不截断行。

### 3.2 R8 关键页一键导出 PDF（底座）

**现状**：三层皆无（库/命令/入口）。

**方案**：**统一"打印入口"**，两条调用路径：
- **壳内页面**（词卡查看、打卡单、未来反思本）：页面级打印按钮 → 底座函数 `printCurrentPage()`。
- **content 窗口**（课文页/词卡 H5）：壳侧提供「导出 PDF」入口（位置见下）→ 对 content 窗口执行打印。

**选型：方案 A（librarian 查证 + 证据，Oracle 终审）**：
- **A（选定）**：`window.print()` 直调——壳内页面 React 按钮直接 `window.print()`；content 窗口由 Rust 侧 `webview.print()`（= `eval("window.print()")`，wry `src/webview2/mod.rs` 实测源码）或 `eval` 触发。**零新依赖**，走系统打印对话框（Win7 SP1 起内置"Microsoft Print to PDF"虚拟打印机），用户自选另存 PDF。
  - 证据：WebView2 `window.print()` 官方确认可用（WebView2Feedback #7/#1471）；wry PR #236 Windows 实测通过；wry #1557（2025，Tauri 2.5.1）确认 `window.print()` works fine。历史 no-op 属已废弃 EdgeHTML WebView1，与 WebView2 无关。
  - Tauri 2 事实：JS 侧 `Webview.print()` 已移除（@tauri-apps/api 2.10.1 无此方法）→ 前端直接用浏览器 `window.print()`；Rust 侧 `tauri::Webview::print()` 存在但文档注释过时（"macOS only"），Windows 实际同走 eval 路径。
- **B（备选，v0.1 不做）**：若后续需"静默导出 PDF 到指定路径"（不经对话框）→ 自建私有命令：`with_webview` + `ICoreWebView2_7/16::PrintToPdf`/`PrintToPdfStream`，必须 `QueryInterface` 失败降级到 A（**严禁 unwrap**，前向兼容 SDK 在旧 Runtime 返回 `E_NOINTERFACE`）。约 100-200 行 unsafe 胶水，列为后续增强。
- **C（排除）**：`tauri-plugin-printer`（Tauri 1 only，编译不过）；`tauri-plugin-printer-v2`（单维护者/周下载 108/依赖 Runtime ≥109 踩线/v0.x 频繁 breaking）——不作交付基座。

**入口位置**：
- 壳内：打印按钮统一用 `ghost-btn inline`（既有样式族）。
- content 窗口：**全屏内容放映时壳侧不可见**——入口放 ①壳侧「apps/quickstart」详情行的「导出 PDF」动作；②内容包放映中用户可按 `Ctrl+P`（WebView2 原生，壳侧不接管；§3.3 全局快捷键选 `Alt+T` 避开）。
- **容错降级**：content H5 无打印样式时按浏览器默认排版——接受（"可打印兜底"语义，R01 L221）。
- **⚠️ 内容包硬约束（写入 S01/D04 后续修订建议）**：H5 内容包**禁止使用 `print-js` 及一切 iframe 打印库**——`iframe.contentWindow.print()` 在 WebView2 静默 no-op（wry #1557）；必须顶层 `window.print()`。

**涉及文件**：`src/ui/api.ts`（或新 `src/ui/printUtil.ts`）、壳 UI 若干视图入口、可能 `commands/window.rs`（若走 Rust 命令）、`Cargo.toml`（仅方案 B 时）。

**验收**：壳内页面一键拉起打印对话框/生成 PDF；content 窗口同样可触发；Win7 WebView2 **109.0.1518.x** 实机行为记录到验证节（Win11 本机先行，Win7 真机标"待真机"）。**版本锚点（Oracle M-7）**：实施时 `cargo tree -p tauri` 复核实际锁定版本，Tauri 版本基准以 Cargo.lock 为准。

### 3.3 计时器全局浮层（D05 §2.4.4）

**现状**：TimerView 仅在 `view === "timer"` 渲染；切视图/进内容包即失联；D05 预留 `tool.timer` 与全局快捷键。

**方案**（v0.2 按 Oracle B1/B2/B3/M-3/M-4 重写）：
1. **计时主控 = `timerStore.ts`（B2 关键修订）**：v0.1 写"TimerView 主控"**不成立**——`App.tsx` L243 `{view === "timer" && <TimerView />}` 是条件渲染，切视图即 unmount，`endAt`/`phase`/`remainMs` 全丢，计时无法跨视图存活（违背 D05"不离开当前内容包"本意）。修订：
   - 新建 `src/ui/timerStore.ts`：**框架无关纯模块**（模块级 state + 订阅回调，或 `useSyncExternalStore` 兼容接口），持有 `endAt`（时间戳）、`phase`（idle/running/paused）、`remainMs`、rAF/interval 驱动与**`beep()`/标题闪烁逻辑一并迁入**（N-1：顺带解决，比浮层复制 <30 行更干净）；
   - `TimerView` 与浮层窗口**都只消费 store**（unmount 不影响 store 存活）；浮层 v0.1 **单向只读**（不允许从浮层 start/pause/reset，操作只在 TimerView）；
   - 跨窗口同步：store 状态变化 → `emit("timer://tick", {endAt, phase, remainMs})` → 浮层窗口 `listen` 渲染。
2. **全局快捷键 = `tauri-plugin-global-shortcut` 插件（B1 关键修订）**：v0.1 写"`tauri::GlobalShortcut` 非新插件"**是事实错误**——Tauri 2 全局热键是独立官方插件 crate。修订：`Cargo.toml` 加 `tauri-plugin-global-shortcut = "2"`（**本迭代唯一新 Rust 依赖，§2.2 已列 Oracle 点头项**）、`lib.rs` 注册 builder、`capabilities/default.json` 加权限。键位 **`Alt+T`**（D05 未指定，Oracle M-3 要求论证：Alt+字母系中文输入法/Office Tools 常用键族——**实施时实测搜狗/微软拼音默认配置是否吞键**，冲突则改 `Ctrl+Alt+T` 并把最终键位写回本节）。`register()` 失败 → 降级壳内「呼出计时浮层」按钮 + 设置页改键位（真实路径，非仅风险表列名）。
3. **浮层形态 = 独立小窗口**（Oracle 确认结论）：
   - 关键约束：Tauri 2 每窗口是独立 OS 窗口——浮层须在 **content 全屏之上**仍可见 → main 的 DOM **盖不住** content 全屏 → 必须独立窗口（always-on-top）；
   - `tauri.conf.json` 静态声明 `timer-overlay`：`visible:false` + `always_on_top:true` + `skipTaskbar:true` + ~320×140 + url 同 main 同源 `#/overlay` 路由；
   - **⚠️ capabilities 必改（B3）**：`capabilities/default.json` 现为 `"windows": ["main", "content"]`——**必须加 `"timer-overlay"`**，否则该窗口零权限（不能 emit/listen/show/hide/set-always-on-top）；并补 `core:window:allow-set-always-on-top`/`allow-show`/`allow-hide`/`allow-set-focus` 权限；
   - **生命周期（M-4）**：startup 创建一次；呼出 = `show()` + `set_focus()`；收起 = `hide()`；**绝不 destroy**（静态窗口 destroy 后无法重建，且丢浮层内 React 状态）；应用退出随主进程。
4. **`tool.timer` 命令**（D05 L165 预留）：Rust 命令 = "呼出浮层"（`timer-overlay.show()`），供未来内容包/脚本调用；注册进 `commands/window.rs` 或新 `commands/overlay.rs` + `mod.rs`。
5. **首屏白闪与 F5（Oracle M-5，风险表 F7/F8）**：浮层 `visible:false` 静默预载 React；首 `show()` 前确认挂载完成（或 overlay 页面用非白背景铺底）。F5 重载浮层只丢浮层内副本——主控在 store（main 窗口）+ 跨窗口 tick 事件恢复，可接受。

**前置 Spike-S1（Oracle 强制，见 §4）**：动 TimerView/store 重构前，先用 1-2h 最小验证本仓库内"多窗口 + always-on-top + 跨窗口 event"三件事真实可跑。

**涉及文件**：`tauri.conf.json`、`capabilities/default.json`、`Cargo.toml`、`src/src-tauri/lib.rs`、`commands/window.rs`（或新 `overlay.rs`）+ `mod.rs`、新 `src/ui/timerStore.ts`、`App.tsx`、`TimerView.tsx`（改为消费 store）、新 `OverlayView.tsx`、`App.css`。

**验收**：内容包全屏放映中按 `Alt+T` 浮层置顶出现；倒计时与 TimerView 一致；到时蜂鸣；再按收起；无内容包时呼出显示兜底提示。
