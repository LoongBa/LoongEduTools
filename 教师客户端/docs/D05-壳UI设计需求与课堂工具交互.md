## 1. 壳 UI 总览

### 1.1 页面结构

```
教师客户端（React + TanStack Router）
├── /login            # 登录页（P1；P0 跳过）
├── /                 # 应用列表（首页，R 级工具/内容包入口）
├── /quickstart       # ★ R6 一键开课（多班进度 + 秒进）
├── /content          # 内容包管理（已装/可下载/更新）
├── /tools            # 课堂工具集（P3：抽卡/分组/纪律/计时器）
├── /classes          # ★ R1 多班进度看板（P3）
├── /profile          # 教师信息/口令状态/认证（P1）
├── /settings         # 设置（全屏/快捷键/关于/数据说明）
└── (全屏子窗口：教材点读等 app 型内容包独立 Webview 加载，不走壳 UI 路由树)
```

> 全部页面可**离线渲染**（无网时壳 UI 照常显示，仅登录/口令/下载相关动作提示需网络）。

### 1.2 壳 UI 职责边界

- 壳 UI 只做**导航/入口/状态**：应用列表、一键开课、内容管理、工具入口、认证状态；
- **内容包本体**（教材点读 HTML、词卡页）由 Rust `package.load` 解密后在独立 WebviewWindow 全屏加载——不嵌入壳 UI（避免 React 树与旧 HTML 混杂、保 Chrome61 兼容）；
- 课堂工具（抽卡/分组/纪律）为壳 UI 内页面（React 实现，本地数据）。

## 2. 页面需求明细

### 2.1 登录页 `/login`（P1）

| 需求 | 说明 |
|---|---|
| 三方式登录 | 微信扫码（二维码区，2s 轮询）/ 短信验证码 / 密码——切换 Tab |
| 注册补信息 | 首登后必填：任教年级（下拉 1-6）、科目（英语默认）、同意条款勾选 |
| 激活码 | 已激活态进入；未激活弹激活码输入（绑定激活码升授权级别） |
| 口令状态 | 显示课堂口令到期日 + 续期按钮（在线时） |
| 离线兜底 | 凭证缓存 7 天有效 → 直接跳过登录进首页；过期弹"需联网重新登录"非阻塞提示 |

### 2.2 首页应用列表 `/`（P0 起）

```
┌─────────────────────────────────────┐
│  [图像] 教材点读          [打开]      │  ← 预装 app 型（大卡片优先）
│  [图像] PEP 词卡          [打开]      │  ← 预装 data 型
│  ...（更多已装/可下载）                │
│  ── 可下载内容包 ──                   │  ← P2 分节：manifest 未装项，带 [下载] 按钮
│  [图像] 代课应急包(3U)    [下载]      │
│  [图像] 游戏复习包        [下载]      │
│  ── 课堂工具 ──                       │  ← P3 分节
│  [抽卡] [分组] [纪律] [计时器] [多班]  │
└─────────────────────────────────────┘
```

- 顺序：预装 app → 预装 data → 已下载 → 可下载（P2+）→ 工具（P3+）；
- 每项显示：图标 + 名称 + 版本角标 + 状态（✓已装/↓可下载/⟳可更新）；
- 离线时"可下载"区置灰提示"需联网下载"（已装不受影响）。

### 2.3 一键开课 `/quickstart`（★ R6，P0 起）

**目标**：教室分秒必争——打开壳 → 看到各班进度 → 点一下直达上次课程全屏。

| 交互 | 说明 |
|---|---|
| 班列表 | 卡片式：班名 + 「上次：U3 第 2 节 句型操练」+ 大号 [秒进] 按钮 |
| 秒进 | → 调 Rust：`recents.get(班)` → `package.load(对应包)` → 定位上次单元/页 → 全屏 |
| 返回记录 | 退出内容包 → 自动 `recents.set(班, 当前单元/页)`（免手动） |
| 新增班级 | 本地添加班名（不涉及学生名单，纯进度记录；后续 R3 多班看板复用此数据） |
| 离线 | 纯本地（localStorage/tauri-plugin-store），零上报 |

**Rust 命令新增**：`recents.get(class_id)` / `recents.set(class_id, {unit, page, ts})` / `recents.list()`。

### 2.4 课堂工具集 `/tools`（P3）

#### 2.4.1 抽卡（B5，名单包驱动）

```
数据：roster 名单包（在线版配置 → 加密下载 → 本地解密，Schema §4）
交互：
  选名单（班级）→ 全班卡片墙 → 大按钮 [抽一位]
   → 转盘/翻卡动画 → 命中高亮 + 语音播报姓名（本地 TTS，P3 可用预生成音/系统语音）
   → [再来] / [跳过]（请假/home）→ 剩余池排除
   → 已抽名单灰显（本轮不重复）
模式：随机点名（默认）/ 随机分组（R12，见下）
```

#### 2.4.2 分组（★ R12，B6）

| 模式 | 说明 |
|---|---|
| 随机分组 | 名单 → 输入组数/每组人数 → 洗牌分 N 组 → 卡片墙按组着色 + 组名 |
| 强弱搭配 | 名单打"强弱"标签（教师本地标记，可选）→ 按比例分入各组（每组 1-2 强） |
| 编号分组 | 按学号/座次规律命中（1,4,7 → A 组） |

- 交互：切换模式 → 动画分配 → [重新分] 不换名单重洗 / [确认] 投影固定显示；
- 分组结果本地存（供课堂点名/纪律积分联动）。

#### 2.4.3 纪律工具（★ R13，B8）

| 能力 | 说明 |
|---|---|
| 加分面板 | 每组 +1/−1 大按钮（全屏可用，触屏友好）→ 顶部小组积分条实时刷 |
| 排行榜 | 小组积分排名展示（同组内比较，非个人 PK）——对齐"不做个人排名"红线 |
| 随机选人延伸 | 从纪律工具直接呼出抽卡（跨工具联动） |
| 数据 | **本地瞬时**：关机即清、零上报（贴纸数字化替代，不存持久化） |

#### 2.4.4 计时器（A2/D1，课堂节奏）

- 场景预设：晨读 10min / 讨论 3min / 小测 5min / 计时挑战 30s/60s；
- 全屏大字倒计时 + 进度环 + 最后 10s 变色提示 + 到时声音（系统音）；
- 免焦点操作：全局浮层呼出（不离开当前内容包）——**P4 全局快捷键联动**。

#### 2.4.5 多班进度看板（★ R1，A4，P3 页 `/classes`）

```
├─ 网格：每班一卡（班名 + 最近更新 + 进度条 U1-U6 + 上次位置）
├─ 点卡 → 展开本周安排（两周制：Week1 1-3 天天见 / 周末 PBL / Week2 4-5 + 小阅兵）
├─ 编辑：手动拖进度 / 用"一键开课"数据自动推进
└─ 纯本地（不做班级对比/排名）
```

- 数据源：与一键开课共库（`recents` 扩展字段）——开课即自动记录进度，看板只读展示 + 手动修正。

## 3. 交互规范（全局）

| 项 | 规范 |
|---|---|
| 大按钮 | 课堂主操作按钮 ≥ 72px 高（触屏/遥控可用），全屏下 ≥ 96px |
| 误触保护 | 关键操作（删除/重置/提交）需二次确认；全屏上课时禁止意外退出（Esc 需长按/确认） |
| 离屏 | 全屏时鼠标/触屏自动隐藏光标（播放态），移动即现 |
| 对比度 | 投影场景深底浅字（黑/深蓝底 + 白/黄字），文字 ≥ 28px（后排可读） |
| 状态可视 | 网络离线 / 证书状态 / 内容包更新 常驻角标（低干扰） |
| 无障碍 | 全键盘可操作（Tab/Enter）；音量键/多媒体键支持（P4 全局快捷键） |
| 无广告无弹窗 | 课堂场景零打扰 |

## 4. 与 Rust 命令层接口（壳 UI 调用面）

| Command | 页面 | 说明 | 阶段 |
|---|---|---|---|
| `package.list_installed` | / | 已装内容包列表 | P0 |
| `package.list_available` | / | manifest 可下载项（联网） | P2 |
| `package.download` / `package.import_usb` | /content | 下载 / U 盘导入 | P2 |
| `package.load` | /quickstart / | 解密加载 → 全屏子窗口 | P0 |
| `package.unload` | (内容包返回) | 退出回收临时区 + 触发 recents.set | P0 |
| `recents.get/set/list` | /quickstart /classes | 多班进度 | P0/P3 |
| `auth.*` | /login | 登录三方式/凭证 | P1 |
| `license.*` | /login /profile | 口令状态/续期/绑定 | P1 |
| `roster.load` | /tools | 名单包解密加载 | P3 |
| `roster.save` | /tools | 分组/标记本地留存 | P3 |
| `window.toggle_fullscreen` / `window.hide_cursor` | 全局 | 大屏控制 | P0 |
| `tool.timer` | /tools | 计时器（壳内 React 即可，此命令为 P4 全局呼出预留） | P3/P4 |

## 5. 视觉风格（指导，非禁区）

- **基调**：亲子工具的温暖感 × 教师端的克制专业——圆角卡片 + 暖色主色（橙/黄系）+ 白底/深底双主题（投影深底优先）；
- **图标**：线性图标 + 圆角填色（对齐 RedTools 系列图标语言）；内容包图标由各包携带（Schema `icon` 字段）；
- **字号体系**：正文 ≥ 20px；大屏/投影 ≥ 28px；班卡片 ≥ 24px；
- **动效**：轻量（转场 ≤ 200ms；抽卡/分组有反馈动画但不过度）——课堂不炫技；
- **品牌**：龙爸乐学 logo + 教师客户端副标；登录页体现"仅供个人教学使用"合规声明。

## 6. 决策记录

- **2026-09-23 v1.0 定稿**：
  - 壳 UI 只做导航/入口/状态，内容包本体独立 Webview 全屏加载（不混 React 树）；
  - R6 一键开课 = 纯本地（recents 命令 + localStorage），P0 即落地；
  - 小组纪律积分/计时器本地瞬时&零上报（贴纸数字化）；无个人 PK/排名（红线）；
  - 多班看板与一键开课共库，开课即自动记录进度；
  - 视觉走"温暖×克制"，投影深底大字（对比度/字号规范入实现验收标准）。

- **2026-09-26 v0.3 补录（R03 关联决策）**：
  - **命名**：全界面禁「商店」（易误会收费）；「内容商店」→ **「下载扩展」**（R03 §0）；
  - **架构方向变更**：内容/扩展两分区从**服务端页面搬进壳内** StoreView（原「由服务端承载」注释/文案已在 App.tsx/window.rs 同步清理）；分区依据 = S01/A01 已预留的 `categories` 标签（R03 §3.2 方案 A，否决 `package_type` 加值）；
  - 侧栏导航改**二级分组**；新增**工具箱**页（服务端清单为权威源 + 本地只存快捷方式，R03 §4.4）。
