## 1. 背景与目标

- **场景（F4）**：课前 2-3 分钟 Daily Report——学生轮流用英语说天气/心情/日期等，教师用大屏展示话题卡 + 示范音频跟读。
- **交付物**：data 型内容包 `pep-daily-report`，内含话题卡 JSON + 全量示范音频 mp3。
- **验收**：壳内可打开浏览话题卡；点播放有示范音；P1 口令级别 1 即可使用（基础展示包）。

## 2. 内容结构（S01 Schema 对齐）

```
pep-daily-report/
├── manifest.json                 # pack_content.py 生成（签名）
├── package.json                  # 预检清单
└── data/data/                    # data 型：数据区
    ├── topics.json               # 话题卡清单（权威数据源）
    ├── audio/dr01_weather.mp3    # 示范音频（每卡 1 条）
    └── ...
```

### 2.1 topics.json（草案字段）

```jsonc
{
  "schema_version": "1.0",
  "pack_id": "pep-daily-report",
  "title": "Daily Report 课前展示",
  "topics": [
    {
      "id": "dr01_weather",
      "title": "Weather 天气",
      "prompt": "How's the weather today?",
      "sample": "It's sunny today. I like sunny days.",
      "level": 1,
      "audio": "audio/dr01_weather.mp3"
    }
  ]
}
```

## 3. 话题清单（M1，24 卡）

分 4 组 × 6 卡，覆盖小学常用 Daily Report 维度；`sample` 为一至两句示范（现在时、第三人称/第一人称混用由教师口头替换）。

| 组 | id 前缀 | 话题（title → prompt） |
|---|---|---|
| 天气日期 | dr01-06 | Weather / Date / Day of week / Season / Temperature / Holiday |
| 情绪状态 | dr07-12 | Feelings / Energy / Sleep / Breakfast / Health / Weekend mood |
| 校园生活 | dr13-18 | School things / Homework / After school / Club / Best subject / Teacher |
| 兴趣爱好 | dr19-24 | Hobby / Sport / Food / Animal / Colour / Future job |

> M1 产出 `topics.json` 全文（24 × prompt+sample 英文文案），需人工通读一遍（发音友好：避免生僻词、控制 ≤12 词/句）。

## 4. 音频生产（M2）

工具：`F:\LoongBa_Git\LoongMediaTools\音频批量生成工具\tts_batch.py`

```powershell
# 1) 从 topics.json 导出清单 [{name, text}]
#    name = id（如 dr01_weather），text = sample 句
# 2) 批量合成（Edge，英音与点读/词卡一致）
python F:\LoongBa_Git\LoongMediaTools\音频批量生成工具\tts_batch.py `
  --engine edge --voice en-GB-SoniaNeural --rate=-15% `
  --list build/daily-report/tts_list.json --out build/daily-report/assets/audio
```

- 断点续传默认开启（>100B 跳过）；句间节流 0.4s；
- 失败项看 `fail` 计数重跑同一命令即可；
- 验收：24 mp3 齐全、均可播、时长 1-4s。

## 5. 打包（M3）

```powershell
# 目录形态 data 型（无 app/index.html）
python 教师客户端/scripts/pack_content.py `
  --source build/daily-report/pack-src --package-id pep-daily-report `
  --version 1.0.0 --type data --name "Daily Report 课前展示" `
  --out 教师客户端/dist
```

- `required_license_level=1`（基础包，P1 默认）；
- `min_shell_version=0.1.0`；
- 产出 zip 放入 `教师客户端/dist/`，并列入服务端 manifest（`packages[]` 追加条目，S4 上传通道就绪后走 `POST /api/edu/packages`）。

## 6. 里程碑

| 里程碑 | 内容 | 产出 |
|---|---|---|
| **M1** | 24 话题文案定稿 + topics.json | `topics.json` + 人工通读记录 |
| **M2** | TTS 批量 + QA | 24 mp3 + `tts_list.json` |
| **M3** | pack_content 打包 + 结构验收 | `pep-daily-report-1.0.0.zip` + manifest 校验 |

## 7. 待确认决策点

1. **卡数**：24（默认）是否够两周一循环？可扩到 30（每组+1）。
2. **音色**：固定 `en-GB-SoniaNeural`（与词卡/点读一致）是否接受？若课前展示想要更「播音感」可试 `en-GB-RyanNeural` 对比 1 次。
3. **配图**：P1 是否纯文本卡（CSS 排版）？若要插图，从 P2 生图管线补，不阻塞音频里程碑。
4. **结构**：是否需要 Weekday 专用「今天星期X」动态文案？动态部分由壳 UI 模板替换，卡内只存静态 prompt/sample。
