## 1. 定位：什么是扩展内容模块

扩展内容模块是客户端运行期可下载、导入、安装、更新、卸载的**内容包**，与壳二进制解耦演进。分两型：

| 类型 | package_type | 形态 | 加载方式 |
|---|---|---|---|
| 应用型 | "app" | 含 data/app/index.html 的离线应用，有独立入口 | 可 load 进内容窗口（src/src-tauri/src/commands/package.rs:45-51） |
| 数据型 | "data" | 无独立入口（data/data/**），P0 暂不支持直接 load | 作配套数据，由 app 型工具经 requiresPkgId 消费（package.rs:49-51；src/ui/lib/eduTools.ts:6-44） |

现有与规划内容包：

| 包 | 类型 | 状态 | 内容 |
|---|---|---|---|
| pep-reader-u01 | app | 预装 packages-embedded/，v1.3.3，139 文件 5.06MB | 教材点读 |
| pep-vocab-cards | app | 预装，v1.1.0，10,377,259B | 976 词闪卡 |
| substitute-kit | data | 规划（scripts/content_sources/substitute-kit/，R2 代课应急） | 含 u01/u02 |
| game-review-pack | app | 规划（scripts/content_sources/game-review-pack/，R14 游戏复习） | idiom-match + antonym-match |

首发内容源清单见 scripts/content_sources/README.md。

- **与预装包（packages-embedded）的关系**：预装包随壳嵌入 exe 同目录 resource_dir，与下载/导入包共用同一套扫描与验签体系（package.rs:154-186），以 is_embedded 标记来源（package.rs:235-238）。预装实例见 src/src-tauri/packages-embedded/pep-reader-u01/manifest.json、pep-vocab-cards/manifest.json。
- **下载中心 = 分发入口**：下载中心四分区 Tab：任务/内容/工具/原版教材（src/ui/components/DownloadExtView.tsx:285-317）；categories 含"工具"进工具区，否则进内容区（:73-76）。
- **与工具箱扩展通道的关系**：工具箱是另一类可扩展物，不走包格式；清单走独立接口 GET /api/edu/toolbox/manifest（server/src/handlers/toolbox.ts:34-60），首发 4 类截屏录屏/屏幕标注/按键显示/虚拟键盘（:38-43），recommend:true 的工具进入待办总览「需下载」（:38-43）。内容包与工具箱都从下载中心分发，但包通道必须验签并受口令保护，工具通道是服务端清单直配。

## 2. 实现原理与机制

### 2.1 包格式

zip 三件套（scripts/pack_content.py:199-204）：

| 成员 | 内容 | 明文/密文 | 用途 |
|---|---|---|---|
| manifest.json | 签名清单（schema/签名/哈希） | 明文 | 验签与元数据（package.rs:190-246 read_manifest） |
| package.json | 预检清单（含 file_index） | 明文 | 解包前预检（store_import_usb 先读它，store.rs:426-436） |
| data/<rel> | 逐文件 AES-256-GCM 密文 | 密文 | 实际内容 |

- app 型：data/app/** 且必须有 data/app/index.html（pack_content.py:118-120,135-136）；data 型：data/data/**（:123-125）。
- 加密布局：iv(16B)|ct|tag(16B)，无 AAD（scripts/crypto_out.py:35-39；src/src-tauri/src/commands/protocol.rs:295-304）。

manifest 字段表（scripts/gen_manifest.py:38-57；实例 packages-embedded/pep-reader-u01/manifest.json）：

| 字段 | 值例 | 说明 |
|---|---|---|
| schema_version | "1.0" | 格式版本，冻结见 S01 |
| package_id | "pep-reader-u01" | 包唯一 ID |
| package_type | "app" / "data" | 类型 |
| name / display_name | - | 名称 |
| icon | null | 图标 |
| package_version | "1.3.3" | 版本 |
| content_hash | "sha256:<64hex>" | data 存储区整体 SHA-256，按存储序（pack_content.py:153-156） |
| size_bytes | 5058755 | 大小 |
| min_shell_version | "0.1.0" | 最低壳版本，语义化比较 version_lt（package.rs:250-267） |
| required_license_level | 1 | 口令级别 |
| categories | ["教材","英语"] | 分类（下载中心分区依据） |
| description | - | 描述 |
| release_date | "2026-09-26" | 发布日期 |
| author | "LoongBa" | 作者 |
| download_url | "/api/edu/packages/pep-reader-u01/1.3.3" | 下载源（支持绝对 http(s)，store.rs:265-275） |
| checksum | "sha256:<zip 本体 hash>" | 不入签名（循环依赖，gen_manifest.py:4-5） |
| min_free_version | null | 预留 |
| signature | {alg:"ed25519", key_id:"dev-sign-2026", nonce, signed_payload_hash, sig} | 签名信封 |

package.json 字段（scripts/gen_package_json.py:32-40）：package_id、package_version、file_count、total_size、encrypted、enc_alg "AES-256-GCM"、file_index[] {path, sha256}；其中 sha256 为裸 hex 无前缀（:19）。

签名与验签：
- 签名覆盖剔除 signature 与 checksum 后的全部字段（checksum 依赖 zip 本体，构成循环，gen_manifest.py:4-5）。
- 规范化：sort_keys=True、separators=(",",":")、ensure_ascii=False → signed_payload_hash="sha256:"+sha256(canon) → ed25519 签名（gen_manifest.py:60-75；package.rs:274-319）。
- 公钥表 SIGN_PUBKEYS（package.rs:14-17）：dev-sign-2026 → caa4223f...caf7d；换钥采用追加条目双轨，旧 key_id 保留可验（package.rs:13）。
- 壳端 read_manifest（package.rs:190-246）：签名缺失 / 未知 key_id / 验签失败 / signed_payload_hash 不符 → Err；min_shell_version 不满足的包跳过不入索引（:250-267）。

入口 scripts/pack_content.py（CLI + build_package），薄入口 pack_app.py / pack_data.py 按类型封装。

| --type | 是 | app / data |
| --name | 是 | 名称 |
| --display-name | 否 | 显示名 |
| --icon | 否 | 图标 |
| --min-shell | 否 | 最低壳版本 |

build_package 11 步（pack_content.py:129-231）：

| 步 | 动作 | 位置 |
|---|---|---|
| 1 | collect_source：zip 或目录 → {相对路径:字节}；跳过 ip/ 下与 .webp 同名并存的 .png（D09 附A M1） | :85-115（:78-82） |
| 2 | normalize_app / normalize_data：校验目录形态 | :118-125 |
| 3 | load_content_key：读 scripts/keys/content-master.key（64 位小写 hex = 32B）；缺失则 secrets.token_hex(32) 自动生成并 chmod 0600 | :54-74 |
| 4 | build_file_index：明文 hash + total_size | scripts/gen_package_json.py:13-21 |
| 5 | 逐文件 encrypt_bytes | scripts/crypto_out.py:35-39 |
| 6 | build_package_json（encrypted=True） | - |
| 7 | content_hash = sha256(b"".join(sorted blobs)) | :153-156 |
| 8 | build_manifest + sign_manifest | scripts/gen_manifest.py:60-75 |
| 9 | 输出 zip content-pack-<id>-<ver>.zip，或 --dir-out 目录（预装用） | - |
| 10 | checksum = zip 本体 sha256，写 .meta.json | :206-210 |
| 11 | registry.json 版本记录：[{package_id, version, sha256}]，同 id+ver 去重 | :212-227 |

密钥来源：
- 内容密钥：scripts/keys/content-master.key，32B 原始密钥，gitignored、办公室保管（pack_content.py:50-51）；包内不含密钥，只含密文（见 §2.4）。
- 签名钥：scripts/keys/dev-sign.key，ed25519 PEM（crypto_out.py:21）。
- HKDF 口令派生已弃用（pack_content.py:17-18）；crypto_out.py:24-32 derive_key 仍存在但不再调用。

QA：scripts/verify_pack.py 7 项（:47-203）：

| # | 项 | 检查内容 | 位置 |
|---|---|---|---|
| 1 | structure | zip 三件套齐全 | :72-88 |
| 2 | signature | ed25519 验签 | :96-108 |
| 3 | hash | file_index 逐文件解密后 SHA-256 比对 | :110-138 |
| 4 | decrypt_smoke | 抽 ≤3 文件解密冒烟 | :139-144 |
| 5 | size | 教材点读 ≤10MiB、其余 ≤50MiB，超限 WARN | :146-151 |
| 6 | app_deps | app 型 index.html 的相对 src/href 引用在包内 | :153-175 |
| 7 | registry | 无重复 WARN | :177-191 |

输出 dist/<id>-<ver>-qa.json；任一 FAIL 则 exit 1。

发布：scripts/publish_pack.py 4 步（:66-163）：
1. POST {base}/api/edu/packages（multipart + X-Api-Key）上传包体（:94-118）。
2. GET /api/edu/packages/manifest 确认条目存在（需 JWT，无则 SKIP）（:120-136）。
3. GET /api/edu/packages/{id}/{ver} 探测下载接口（401/403 即接口存在）（:138-142）。
4. 写 dist/<id>-<ver>-published.json（:144-158）。

注意：--prod 必须显式指定（:77）。registry.json 是**本地打包记录**，不是服务端清单；服务端清单是 R2 manifest/latest.json（server/src/handlers/packages.ts:155-185）。

### 2.3 分发三通道

**(a) 云端下载**（src/src-tauri/src/commands/store.rs:222-335 store_download）：

| 步 | 动作 | 位置 |
|---|---|---|
| 1 | 凭证 + api_base 检查 | :229-233 |
| 2 | 防降级：本地已装版本 ≥ 请求版本即拒绝 | :235-246 |
| 3 | 严格 checksum：清单必须含该条目且带有效 "sha256:" 前缀 | :248-263 |
| 4 | 下载源解析：清单 download_url 为绝对 http(s) 时优先，否则回退 {api_base}/api/edu/packages/{id}/{ver} | :265-275 |
| 5 | 流式下载 + 边下边算 SHA-256（300s 超时） | :337-384 |
| 6 | hash 不符：删临时文件 + Err | :279-282 |
| 7 | 解包暂存 .{id}-{ver}.staging → read_manifest 验签 + package_id 匹配 + encrypted!=true 拒收 | :298-316 |
| 8 | fs::rename 到 packages/{id}-{ver}/ → scan_packages 刷新 | :322-334 |

**(b) U 盘导入**（store.rs:414-531 store_import_usb）：

| 步 | 动作 | 位置 |
|---|---|---|
| 1 | 读 zip 内 package.json 预检：package_id/package_version/file_count/encrypted 必填 | :426-436 |
| 2 | encrypted!=true 零磁盘写入即拒（D09 §7 步骤 2） | :437-444 |
| 3 | 读 manifest：package_id/version 一致性 + min_shell_version 守卫 | :446-473 |
| 4 | 先验签后解压（D09 §7 步骤 1）；恶意 zip 验签失败零磁盘写入 | :474-477 |
| 5 | 版本守卫：不降级、不覆盖同版本 | :479-491 |
| 6 | 解包暂存 → 校验 → rename → scan_packages | :493-530 |

**(c) 预装嵌入**（package.rs:154-186 scan_packages）：
- 双源去重：exe 同目录 resource_dir + 当前工作目录（开发期）（:157-165）。
- 扫描 packages-embedded/ 与 packages/ 下每个子目录（:166-182）。
- is_embedded = 父目录名以 packages-embedded 结尾（:235-238）。
- 启动时扫描：src/src-tauri/src/lib.rs:116-118。

验签与拒收时点汇总：云端下载在解包暂存后 read_manifest 验签（store.rs:298-316）；U 盘导入在解压前验签（store.rs:474-477）；预装包与两者共用 read_manifest 验签（package.rs:190-246）。明文包在 load、store_download、store_import_usb 三处拒收（详见 §6）。

zip 解析（store.rs:577-773）：零 zip 库，自写 central directory + flate2 raw deflate；防炸弹限制：条目 ≤2000、累计 ≤500MB、单条目 ≤2GiB（:698-700,748-749）；路径越界拒绝（safe_rel_path，:733-745）。

| 步 | 动作 | 位置 |
|---|---|---|
| 1 | PIN（≥6 位）+ 课堂口令 | - |
| 2 | 重跑步骤 1-4 校验防绕过 | :437-438 |
| 3 | key_material(base64) = [salt:16][nonce:12][内容密钥:32][tag:16] | :357-359 |

### 2.5 更新机制

- 检测：store_list_available 计算本地已装集合与远端 manifest 的差集（store.rs:536-575）；installed = 本地有该 package_id；update_available = version_lt(installed, remote)（:549-552）。
- UI 映射（src/ui/components/DownloadExtView.tsx:186-215）：壳端 update_available → 数据源 updatable；package_version → latest_version。
- 卡片三态（:718-727,757-797）：
  - updatable → 橙色「可更新」徽标 + 刷新按钮；
  - installed 且不可更新 → 绿色「已装」+ 禁用按钮；
  - 未装 → 下载图标。
- 待办总览（:243-251）：needPkg（未装 data 型）、needTool（推荐工具）、missingData（工具缺配套数据）、dataUpdatable、appUpdatable，各带「一键下载/补全/更新」。
- 启动检查：docs/_archive/v0.2-legacy-views/updateCheck.ts:13-26 **已归档**（原设计：每会话一次复用 store_list_available，过滤 installed 且 update_available，离线/未配服务端静默不弹）；当前 Shell.tsx 未引用。如实说明：更新检测实际靠下载中心待办总览 + 卡片三态，不是启动 banner。
- 服务端版本管理（server/src/handlers/packages.ts:143-154）：上传新版本时 UPDATE packages SET is_latest=0（旧版）＋ INSERT ... ON CONFLICT(package_id) DO UPDATE（新版置 is_latest=1）；findPkg 先查精确版本，回退 is_latest=1（:44-57）。

## 3. 如何创建内容模块

可照做的端到端流程：准备源 → 打包 → QA → 产出 dist → 发布。

1. **准备源**：目录或 zip 均可（collect_source 同时支持，pack_content.py:85-115）；ip/ 下与 .webp 同名并存的 .png 会被跳过（D09 附A M1，:78-82）。首发内容源清单见 scripts/content_sources/README.md。
2. **确认密钥**：内容密钥 scripts/keys/content-master.key（32B hex；缺失会自动生成，gitignored、办公室保管，pack_content.py:50-51,54-74）；签名钥 scripts/keys/dev-sign.key（crypto_out.py:21）。
3. **打包**：pack_content.py CLI（参数表见 §2.2）；app 型确保源含 data/app/index.html（normalize 校验，pack_content.py:118-120,135-136），data 型放 data/data/**（:123-125）。薄入口：pack_app.py / pack_data.py。
4. **QA**：verify_pack.py 7 项（见 §2.2 表），输出 dist/<id>-<ver>-qa.json，任一 FAIL exit 1（verify_pack.py:47-203）。
5. **产物**：dist/content-pack-<id>-<ver>.zip（+ .meta.json，pack_content.py:206-210）。**预装包**改用 --dir-out 输出到 src/src-tauri/packages-embedded/，随壳构建嵌入（package.rs:154-186）。
6. **发布**：publish_pack.py 4 步（见 §2.2）；--prod 必须显式指定（:77）。

## 4. 如何更新内容模块

1. **新版本号**：--version 升版（manifest 与 package.json 均记录 package_version，gen_manifest.py:38-57、gen_package_json.py:32-40）。
2. **重打包**：按 §3 流程走一遍（打包 + QA）。
3. **发布**：publish_pack.py；服务端 packagesUpload 将旧版本 is_latest=0、新版本置 1，并同步 manifest/latest.json（packages.ts:143-154,155-185）。
4. **端侧检测**：store_list_available 发现 update_available = version_lt(installed, remote)（store.rs:549-552）；卡片进入「可更新」态（DownloadExtView.tsx:718-727），待办总览出现 dataUpdatable / appUpdatable（:243-251）。
5. **教师点更新**：一键下载最新版本；下载任务先取最新版本再 storeDownload（src/ui/lib/store.ts:414-418）。

守卫：
- 防降级：云端下载时本地已装版本 ≥ 请求版本即拒绝（store.rs:235-246）；U 盘导入不降级、不覆盖同版本（store.rs:479-491）。
- 同版本去重：registry.json 同 id+ver 去重（pack_content.py:212-227）。
- 预装包同样走云端/U 盘更新：安装后 scan_packages 刷新索引（store.rs:322-334,493-530）。

## 5. 教师使用

### 5.1 智慧屏（联网）

1. **登录**：下载/清单接口 requireAuth，未登录返回 401（packages.ts:60-92）。
2. **浏览**：下载中心四分区（任务/内容/工具/原版教材，DownloadExtView.tsx:285-317）；内容区按科目子分类（SUBJECTS=英语/语文/数学/科学/综合，取 categories 末位，:41-42,78-81），工具区按其余标签（:43-46）；tag chips 过滤（:168-174）。
3. **下载**：内容包点下载 → 入队（并发上限 3，其余排队，src/ui/lib/store.ts:381,384-468）→ 进度模拟递增（真实 Tauri 命令无逐字节回调，命令完成置 100，:398-407）→ 完成回调 onInstalled（DownloadExtView.tsx:231-241）。内容包取最新版本下载（store.ts:414-418）；工具走 toolboxDownload（:411-412）；历史持久化 taoli.downloads.history，上限 60（:382,424-432）。
4. **启动**：启动中心（src/ui/components/LaunchpadView.tsx）徽章三态：need/update → 弹选包或直接下载；已装 → 直接启动（:430-448）。内置工具与 requiresPkgId：edu-eng-read（英语点读，requiresPkgId "pkg-pep-eng-g3"）、edu-char-cards（生字卡片）、edu-dictation（听写助手，requiresPkgId "pkg-word-junior"）、edu-poem-roll（诗词轮播，requiresPkgId "pkg-poem-tang"）（src/ui/lib/eduTools.ts:6-44）；dataOptions 年级子包如 pkg-pep-eng-g4s（:14-17,39-42）。
5. **关课卸载**：unload 销毁内容窗口、清除密钥（package.rs:125-136）。

### 5.2 U 盘（离线/导入）

1. 电脑端装好 zip（content-pack-<id>-<ver>.zip）。
2. 下载中心 → U 盘导入（open() 选 zip → api.storeImportUsb → toast + 通知，DownloadExtView.tsx:108-120）。
3. 壳端校验顺序（store.rs:414-531）：package.json 预检（:426-436）→ encrypted!=true 零磁盘写入拒收（:437-444）→ manifest 一致性 + min_shell_version（:446-473）→ 先验签后解压（:474-477）→ 不降级不覆盖同版本（:479-491）→ 解包暂存 → 校验 → rename → scan_packages（:493-530）。
4. 之后启动流程与 §5.1 相同。

### 5.3 随身工具包与原版教材

- 随身工具包：工具箱面板导出/导入 toolbox-pack.json（kind:"taoli-toolbox-pack"，含 shortcuts + downloaded_tools + packed textbooks；src/ui/components/ToolboxPanel.tsx:165-192）。
- 原版教材：不走包通道、不走云端下载；教师用浏览器「教材下载」扩展抓取后导入本地 textbooks/ 目录，随随身工具包打包（src/ui/lib/mockData.ts:30-64）。基线 3 套：人教版英语三年级上、牛津阅读树 Level 1-3、统编语文四年级下。
- 工具箱通道：清单 GET /api/edu/toolbox/manifest（toolbox.ts:34-60）；首发 4 类：截屏录屏/屏幕标注/按键显示/虚拟键盘（:38-43）。

## 6. 已知边界与限制

| 限制 | 说明 | 依据 |
|---|---|---|
| data 型不能直接 load | P0 暂不支持直接 load，仅作配套数据由 app 型工具消费 | package.rs:49-51；eduTools.ts:6-44 |
| 进度条是模拟的 | 真实 Tauri 命令无逐字节回调，进度为递增模拟，命令完成置 100 | store.ts:398-407 |
| updateCheck 已归档 | docs/_archive/v0.2-legacy-views/updateCheck.ts，Shell.tsx 未引用；更新检测靠待办总览 + 卡片三态 | updateCheck.ts:13-26 |
| 明文包三点拒收 | load（package.rs:62-66）、store_download（store.rs:312-314）、store_import_usb（store.rs:440-444）；--plain 已从管线删除 | pack_content.py:19-20 |
| checksum 不入签名 | zip 本体 hash 与签名循环依赖，签名覆盖除 signature/checksum 外全部字段 | gen_manifest.py:4-5 |
| 内容密钥不在包内 | 包内仅密文；密钥经 credential.enc + PIN+口令 → Argon2id → AES-256-GCM → 仅内存 | credential.rs:423-469 |
| 下载 401 | 未登录或口令级别不足（requireAuth + loadClassroom 学期口令级别校验） | packages.ts:60-92,77-87 |
| 服务端清单缺省 | manifest/latest.json 缺失时返回空清单 | packages.ts:29-42 |
| GCM 无随机访问 | Range 请求须整文件解密后切片 | protocol.rs:14-15 |
| Win7 兼容基线 | 系统兼容性与 WebView2 基线约束见 D01-教育工具-教师版RUST外壳开发方案，防扩散相关见 D09-内容包防扩散与部署方案，本方案不重复 | 见上述文档 |
