# D13 · 轻量机生产部署方案（server-dotnet · 腾讯云 Ubuntu）

> 状态：v0.2（2026-09-29，Oracle 外审 6B/10I/5N 全采纳后修订）
> 定位：**教师客户端生产服务端 = `server-dotnet/`（.NET 10）部署到腾讯云轻量应用服务器（Ubuntu）**；`server/`（TS Node/Workers 完整版）退役/降级为实验。
> 契约 A01 / 签名 D10 / 防扩散 D09；部署模式复用 D03 附录 A（systemd/Caddy/secrets/备份）。

## 1. 背景与决策

### 1.1 背景

- 双服务端并存：`server/`（TS 完整版，D03 附录 A 部署工件已就绪）与 `server-dotnet/`（.NET 简单版：配置下发 + 认证 + 激活码，2026-09-27 落地）。
- 2026-09-29 用户裁定：**轻量机生产 = server-dotnet**；S6 微信/短信真接入同版落地（见 D14）。
- 腾讯云轻量应用服务器 Ubuntu **已购**（2026-09-24 决策），CF Pages 继续承载静态内容（`taoli.loongba.cn`，已上线）。

### 1.2 决策

| # | 决策 | 说明 |
|---|---|---|
| D1 | 生产服务端 = **server-dotnet**（.NET 10） | 功能边界：配置下发 + 认证（短信/微信）+ 离线激活码——壳端实际消费面；TS 版功能冗余且云设施耦合 |
| D2 | TS `server/` 降级为实验/参考 | 不再部署轻量机；`server/deploy/` 工件保留供 .NET 部署参考（systemd/Caddy/secrets 模式复用） |
| D3 | 部署形态 = **dotnet publish 自包含单文件（linux-x64）** | 服务器免装 .NET runtime，Ubuntu 22.04/24.04 开箱即跑 |
| D4 | 域名 = `api.taoli.loongba.cn` | 看板已预留；静态 `taoli.loongba.cn` 已在 CF Pages（不同子域，无冲突）。**回写 A01 §1.1 Base URL**（契约权威，B6） |
| D5 | 反代 = Caddy（自动 HTTPS） | 与 D03 附录 A 一致；零配置证书续期 |
| D6 | 生产环境 fail-fast | `JWT_SECRET` 缺失 / SMS Mode=Mock / 激活码 demo seed 存在 → **拒绝启动或认证端点禁用**（B2/B3/B4，Oracle 评审） |

### 1.3 功能缺口确认（.NET 版上生产的影响）

.NET 版不含 TS 版的口令包（license pack）/签名凭证签发/内容包市场上报——壳端实际运行仅消费：health / config 下发 / sms 认证 / codes 激活。**上线前需壳端冒烟验证**（见 §7），缺口项列入后续迭代（如需要）：
- 内容包下载 = CF Pages 静态（`taoli.loongba.cn/packs/`，已上线 4 包 + toolbox）——**不经 .NET 版**
- 口令包/签名凭证 = 暂由壳端既有机制兜底或后续补（另立项）

## 2. 部署拓扑

```
教师客户端（教室/办公室） ── https ──▶ api.taoli.loongba.cn
                                        │
                              Caddy（80/443，自动 HTTPS）
                                        │ 反代到 127.0.0.1:5088
                              edu-teacher-api（.NET 10 自包含）
                                        │
                              data/（users/sms/codes.json，SQLite 等价 JSON 存储）
```

- **Caddy**：公网 80/443 → 127.0.0.1:5088；证书 Let's Encrypt 自动签发续期
- **应用**：仅监听 `127.0.0.1:5088`（`dotnet run`/publish 后 `--urls http://127.0.0.1:5088`），不对公网暴露
- **安全组**：腾讯云控制台放行 **80/443** 入站；5088 不放行

## 3. 部署工件（新增 `server-dotnet/deploy/`）

| 文件 | 用途 | 说明 |
|---|---|---|
| `publish.sh` | 发布脚本 | `dotnet publish -c Release --self-contained -r linux-x64 -o dist/`（单文件） |
| `install.sh` | 一键部署（幂等） | 建目录 / 拷贝 dist / 生成 `/etc/edu-teacher-api.env`（chmod 600）/ 安装 systemd / 启动 + 健康检查 |
| `edu-teacher-api.service` | systemd 单元 | `EnvironmentFile=/etc/edu-teacher-api.env` + `ExecStart=/opt/edu-teacher-api/edu-teacher-api` + `Restart=on-failure` |
| `edu-teacher-api.env.example` | 密钥模板 | `JWT_SECRET`（必填）+ S6 预留：`SMS_*` / `WECHAT_APPID` / `WECHAT_APPSECRET` |
| `caddy.example` | Caddyfile 模板 | `api.taoli.loongba.cn` → `127.0.0.1:5088` |
| `backup.sh` | 数据备份 | 打包 `data/`（users/sms/codes.json）+ 保留 14 天（cron） |
| `README.md` | 上线手册 | 步骤 / 密钥生成 / 验收 / 回滚 |

### 3.1 密钥（/etc/edu-teacher-api.env，chmod 600）

```bash
# JWT_SECRET（≥32 字节随机，HS256 签名）
openssl rand -base64 48
```

- **生产 fail-fast（B3）**：`Program.cs` 增 `ASPNETCORE_ENVIRONMENT=Production` 时 `JWT_SECRET` 缺失/等于 dev 默认值 → **拒绝启动**（不再 fallback `dev-only-secret-2026`，该公开密钥仅限本地 Development 兜底）。install.sh 亦在启动前校验 `[ -n "$JWT_SECRET" ] || exit 1`。
- S6 接入后追加短信/微信密钥（见 D14），本方案预留键位。
- `JWT_SECRET` 丢失 = 所有已签 JWT 失效、用户需重新登录（凭证 7 天滚动，影响可控）；**务必备份**（见 §4.2 secrets 备份）。

### 3.2 systemd 要点

```ini
[Unit]
Description=EduTeacher.Api (teacher-client dotnet server)
After=network.target

[Service]
User=www-data
WorkingDirectory=/opt/edu-teacher-api
EnvironmentFile=/etc/edu-teacher-api.env
Environment=ASPNETCORE_ENVIRONMENT=Production
ExecStart=/opt/edu-teacher-api/edu-teacher-api --urls http://127.0.0.1:5088
Restart=on-failure
RestartSec=3
# 安全加固（I3，Oracle 评审）：最小权限 + 防提权 + 崩溃风暴限制
NoNewPrivileges=true
ProtectSystem=strict
ProtectHome=true
PrivateTmp=true
ReadWritePaths=/opt/edu-teacher-api/data
StartLimitBurst=5
StartLimitIntervalSec=60

[Install]
WantedBy=multi-user.target
```

### 3.3 Caddyfile

```caddy
api.taoli.loongba.cn {
    reverse_proxy 127.0.0.1:5088
    # 基础限频（I4）：认证端点防刷（应用层 RateLimiter 亦可，二选一）
    @auth path /api/edu/auth/*
    rate_limit @auth 5 r/s burst 20
}
```

### 3.4 生产安全过渡策略（B2，Oracle 评审）

> **问题**：`SMS_MOCK`/`TencentSms:Mode=Mock` 时验证码 dev_code 会进入响应体——公网泄露 = 任意手机号可登录（无认证）。S6 企业认证（7–10 工作日）是前置阻塞，D13 可能先于 D14 上线。

**过渡策略（二选一，上线时执行）**：
1. **方案 A（推荐）**：`ASPNETCORE_ENVIRONMENT=Production` + `Sms:Mode=Mock` → 认证端点 `/api/edu/auth/sms/*` 与 `/api/edu/auth/codes/*` 返回 **503 `DISABLED`**（不签发 dev_code、不发短信）；配置下发/健康检查不受影响。S6 Real 就绪后 Mode=Real 自动恢复。
2. **方案 B**：S6 未过审期间 Caddy 对 `/api/edu/auth/*` 直接 503（`.NET` 应用内不改，等 S6 落地一次放开）。

**验收含**：Production + Mock 时 send → 503 无 dev_code；Production + Real 时正常。

## 4. 上线步骤（腾讯云 Ubuntu）

```bash
# 0) 前置：服务器装 git + caddy（root）；安全组放行 80/443
apt update && apt install -y git caddy

# 1) 本机构建发布产物
#    （Windows 本机或 CI：见 deploy/publish.sh）
cd 教师客户端/server-dotnet
./deploy/publish.sh          # 产出 deploy/dist/（自包含 linux-x64）

# 2) 上传到服务器 /opt/edu-teacher-api/
scp -r deploy/dist/* root@<server>:/opt/edu-teacher-api/

# 3) 一键部署（幂等：密钥生成/配置/安装服务）
bash /opt/edu-teacher-api/install.sh /opt/edu-teacher-api

# 4) 反代 + HTTPS
cp deploy/caddy.example /etc/caddy/Caddyfile
systemctl reload caddy

# 5) 验收
curl https://api.taoli.loongba.cn/api/edu/health   # {"ok":true,...}
```

### 4.1 数据与配置目录

```
/opt/edu-teacher-api/
├── edu-teacher-api            # 自包含单文件
├── appsettings.json           # 环境无关配置（AllowedHosts 等）
├── data/                      # 运行时数据（users/sms/codes.json，首次启动自动创建 + seed）
│   ├── users.json / sms.json / codes.json
├── wwwroot/config/            # 配置文件（manifest/toolbox/shell.config.signed.json）
│   └── ...（随版本从仓库同步）
└── releases/                  # 回滚版本目录（I10）
    └── v0.3/ → current 软链
```

- **wwwroot/config/**：部署时从仓库拷贝最新产物（或按 D04 发布管线生成后同步；后续可加 `sync-config.sh` 自动化，N2）。
- **激活码 seed（B4，Oracle 评审）**：`Program.cs` 内置 demo 3 条（`TEACHER-2026-0001/0002`、`PRO-2026-0001`，码值公开于代码库）——**生产必须清空**：`ASPNETCORE_ENVIRONMENT=Production` 时 seed 为空 + 拒绝启动时发现 demo 散列存在于 `codes.json`（install.sh 校验）。真实签发 = 生成 `codes.csv` → 散列 → 运维导入 `data/codes.json`（导入脚本见实施清单 I7）。

### 4.2 备份（cron 每日）

```bash
# backup.sh：tar 打包 /opt/edu-teacher-api/data/ → /opt/backups/edu-api-data-<date>.tar.gz，保留 14 天
#  + sha256 完整性清单（N1）+ 异地推送（I2，腾讯云 COS 或 scp 到另一主机）
0 3 * * * bash /opt/edu-teacher-api/backup.sh
```

- 配置目录（wwwroot/config/）为仓库产物可重建；**data/ 是唯一权威**（用户/验证码/激活码）。
- **secrets 备份（I2）**：`/etc/edu-teacher-api.env`（JWT_SECRET + S6 密钥）加密后随备份上传异地，或记录密钥生成命令供重建；密钥丢失 = 全员重登。

### 4.3 回滚（版本目录 + current 软链，I10）

1. 发布按 `releases/<ver>/` 落盘，`current` → 软链指向在用版本
2. 回滚 = 切换软链 + `systemctl restart edu-teacher-api` + 健康检查
3. **data/ 不覆盖**——兼容契约：**data schema 只增不破**（新字段可加，旧版读新 data 忽略未知字段——System.Text.Json 默认行为，须在方案/Storage.cs 注明）
4. Caddy 配置变更单独回滚（`/etc/caddy/Caddyfile` 备份 + reload）

## 5. 域名与 TLS

| 项 | 值 |
|---|---|
| 域名 | `api.taoli.loongba.cn`（A 记录 → 轻量机公网 IP；**回写 A01 §1.1**） |
| 证书 | Caddy 自动 Let's Encrypt（80 端口 HTTP-01 校验需可达） |
| 静态域 | `taoli.loongba.cn`（CF Pages，不变） |

DNS 变更注意：
- `api.` 子域解析到轻量机 IP，与 CF Pages 的 `taoli.loongba.cn`（CNAME → pages.dev）互不干扰。
- **前置确认（I9）**：`api.taoli.loongba.cn` 不得走 CF 橙云代理（代理则 80 端口 HTTP-01 校验不通、Caddy 无法自动签证书）——须 **DNS only 灰云直连**轻量机 IP；**ICP 备案状态**（loongba.cn 主域已备案否、api. 子域是否需要接入备案——D14 微信回调域亦依赖）上线前确认。

## 6. 安全基线（对齐 D09 精神）

- 应用仅监听 127.0.0.1，公网面只有 Caddy（80/443）
- `/etc/edu-teacher-api.env` chmod 600，仅 www-data 可读（systemd EnvironmentFile）
- Caddy 自动 HTTPS，无明文 80 回退（默认重定向）；**认证端点基础限频**（§3.3 rate_limit，I4）
- 验证码散列存储 + 一次性消费（已有实现，Storage.cs Sha256Hex）
- 激活码单向散列（已有实现）
- **生产 fail-fast（B3/B4）**：Production 下 JWT_SECRET 缺失/demo seed 存在/Mode=Mock 认证端点 → 拒绝启动或 503（§3.1/§3.4）
- **服务器本地加固（I8）**：`timedatectl set-timezone Asia/Shanghai` + chrony 时间同步（时钟漂移影响 JWT exp）；ufw `allow 22,80,443` + default deny；SSH 密钥登录禁密码
- **监控（I8）**：外部探测 health（腾讯云监控/uptime 类）+ 磁盘告警（data/ backups/ 增长）+ systemd 崩溃告警（journal 监听）

## 7. 验收标准

1. `curl https://api.taoli.loongba.cn/api/edu/health` → 200 `{"ok":true,...}`
2. 配置下发：`/config/manifest.json` + `/config/toolbox.json` + `/config/shell.config.signed.json` → 200（CORS 头 + no-cache）
3. **生产安全过渡**：Production + Mock → `send` 503 无 dev_code；Production + Real（S6 后）→ 正常闭环
4. 壳端真机：config.json `api_base` 指向 `https://api.taoli.loongba.cn` → 启动探测绿、下载中心清单可拉（静态包走 taoli.loongba.cn）
5. 重启恢复：`systemctl restart` 后健康检查通过；数据不丢
6. 备份可恢复：backup.sh 产物 sha256 校验 + 解包后 data/ 完好；异地备份可达
7. 回滚演练：切 `current` 软链到旧版本 → 重启 → health 绿（data 不覆盖）
8. 限频生效：连续刷认证端点触发 429/503（Caddy rate_limit）

## 8. 风险与缓解

| 风险 | 缓解 |
|---|---|
| .NET 10 自包含体积大（~70MB） | 单文件发布 + gzip 传输；磁盘无忧（轻量机 ≥40GB）；RID 核实（N5：轻量机 CPU 架构，ARM 需 linux-arm64） |
| JWT_SECRET 丢失 | secrets 异地备份（§4.2）；重新登录成本可控；生产 fail-fast 防漏配 |
| data/ JSON 并发（单进程） | Storage.cs 互斥锁已实现；多实例前不扩展 |
| 微信/短信 S6 未过审期间公网无认证 | **§3.4 过渡策略**：Production + Mock → 认证端点 503（不再"Mock 兜底"裸奔） |
| 腾讯云轻量机可用性（单点） | 数据异地备份 + 部署脚本可迁移重建（恢复 <30min） |
| 激活码 demo seed 泄露提权 | 生产 seed 清空 + demo 散列校验（B4） |
