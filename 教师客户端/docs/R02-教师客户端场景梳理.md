# R02 教师客户端场景梳理：家庭 / 备课办公室 / 教室

这三个场景的设备、网络、时间、隐私、操作方式完全不同。同一个功能在不同场景下的需求优先级、技术实现、交互方式可能截然不同。下面按场景逐一分析，再重新对标和排优先级。

---

## 一、三场景核心差异

| 维度     | 家庭                   | 备课办公室               | 教室                      |
| -------- | ---------------------- | ------------------------ | ------------------------- |
| 设备     | 个人电脑（Win/Mac）    | 学校办公电脑（多人共用） | 教室电脑 + 智慧白板       |
| 网络     | 稳定WiFi               | 学校内网，可能有限制     | 不稳定，甚至无网          |
| 时间     | 晚上/周末，大块时间    | 课间/午休，碎片时间      | 上课40分钟，分秒必争      |
| 隐私     | 个人设备，但含学生数据 | 共用设备，不能留数据     | 公开环境，学生都在看      |
| 操作方式 | 键盘鼠标，精细操作     | 快速处理，即插即走       | 触屏/遥控，极简操作       |
| 核心诉求 | 深度备课、批改、分析   | 中转、转换、打印、共享   | 展示、互动、批注、控场    |
| U盘角色  | 可选（可安装版）       | **刚需**（不能装软件）   | **刚需**（换教室/换电脑） |
| 数据留存 | 可留存，需加密         | **不留痕**，随U盘走      | 临时缓存，下课即走        |
| 容错率   | 高（可慢慢弄）         | 中（课间有限）           | **极低**（卡顿=教学事故） |

**关键结论**：U盘便携版的核心战场是**备课办公室+教室**，家庭场景可以走安装版或同一U盘但功能更重。三场景不是三个独立产品，而是**同一工具的三套模式/配置**。

## 二、按场景重新分类功能

### 场景一：家庭（深度工作模式）

**典型任务**：备课、做课件、批改作业、成绩分析、写评语、整理资料、录微课。

| 功能模块       | 具体需求                             | 对标工具                      | 开发判断           |
| -------------- | ------------------------------------ | ----------------------------- | ------------------ |
| 备课与课件     | 教案模板、课件模板、素材库、思维导图 | 希沃白板（生态绑定）、WPS模板 | 集成模板+内容包    |
| 成绩分析       | Excel导入、均分/及格率/排名/图表     | 无专用开源工具                | **需开发**         |
| 评语生成       | 模板+变量替换、批量导出              | xxt-tools（仅学习通）         | **需开发**         |
| 试卷整理       | 拍照→OCR→去手写→导出PDF              | Umi-OCR + PDF工具分离         | **需开发工作流**   |
| 媒体处理       | 录屏、视频压缩、格式转换             | FFmpeg GUI（通用）            | 集成+场景预设      |
| PDF工具        | 合并/拆分/水印/加密                  | PDFTK Portable                | 集成Rust库         |
| 微课录制       | 录屏+简单剪辑+压缩                   | OBS Portable                  | 集成FFmpeg基础录屏 |
| 资料整理       | 批量重命名、图片压缩、去重           | 无专用工具                    | **需开发**         |
| AI增强（可选） | 写教案草稿、写评语、出题             | 各类AI API                    | 在线可选，离线降级 |

**家庭场景特点**：

- 可以联网，AI功能可用
- 屏幕大、键鼠操作，适合复杂界面
- 数据可留存，但需加密
- 不赶时间，容错率高
- **可以走安装版**，不一定要U盘

**优先级**：成绩分析、评语引擎、试卷整理工作流、媒体场景预设。

### 场景二：备课办公室（快速中转模式）

**典型任务**：课间快速改文件、打印、和同事共享资源、临时查资料、准备下一节课。

| 功能模块   | 具体需求                       | 对标工具         | 开发判断              |
| ---------- | ------------------------------ | ---------------- | --------------------- |
| 便携启动   | U盘插上即用，不写注册表        | PortableApps     | **需开发Tauri启动器** |
| 文件快传   | U盘/局域网传文件、二维码分享   | LocalSend        | 集成/参考             |
| 文档转换   | PPT转PDF、Word转PDF、图片转PDF | WPS便携版、PDFTK | 集成                  |
| 打印辅助   | 试卷排版、批量打印、打印预览   | 无专用工具       | **需开发**            |
| 快速查资料 | 教材目录、课标查询、公式表     | textbook-library | 集成内容包            |
| 资源包调用 | 教案模板、评语模板、学科资源   | 无标准           | **需开发内容包机制**  |
| 文件暂存   | 跨电脑临时存放文件             | 无专用工具       | **需开发**            |
| 认证       | 首次联网激活，离线宽限         | 无现成           | **需开发**            |
| 数据不留痕 | 退出后清除本地缓存             | 无现成           | **需开发**            |

**办公室场景特点**：

- 多人共用电脑，不能留个人数据
- 可能无管理员权限，不能装软件
- 网络可能受限，离线优先
- 碎片时间，操作要快
- **U盘是刚需，且要“无痕”**

**优先级**：便携启动器、认证、文档转换、打印辅助、内容包调用、无痕模式。

### 场景三：教室（课堂表演模式）

**典型任务**：上课展示、屏幕批注、课堂互动、计时控场、随机点名、播放媒体。

| 功能模块   | 具体需求                         | 对标工具                                     | 开发判断                |
| ---------- | -------------------------------- | -------------------------------------------- | ----------------------- |
| 全局批注   | 任意界面批注、聚光灯、幕布、放大 | DrawPen（Electron重）、wayscriber（仅Linux） | **需开发**              |
| 课堂节奏   | 计时器、随机点名、分组、积分     | HyperClass、ClassNamePicker                  | 集成+统一面板           |
| 全局快捷键 | 不离开当前应用呼出工具           | 无现成                                       | **需开发**              |
| 局域网互动 | 投票、答题、收作业（学生扫码）   | openmenti（需Node）                          | **需开发Tauri内置服务** |
| 媒体播放   | 视频播放、格式兼容、音量控制     | 系统播放器                                   | 集成                    |
| 录屏       | 课堂录制、微课                   | OBS（重）                                    | 基础录屏                |
| 白板兼容   | 触屏操作、投屏到智慧白板         | 希沃自带                                     | 适配，不替代            |
| 离线可用   | 断网也能用                       | 无现成                                       | **需开发**              |
| 极低延迟   | 批注不卡、切换不卡               | 无现成                                       | **需开发**              |
| 防误触     | 学生乱点、误操作保护             | 无现成                                       | **需开发**              |

**教室场景特点**：

- 网络不稳定，必须离线优先
- 公开环境，界面要干净、不尴尬
- 操作要极简，不能打断教学
- 容错率极低，卡顿=事故
- 智慧白板是显示端，工具跑在教师电脑
- **U盘是刚需，换教室换电脑**

**优先级**：全局批注覆盖层、课堂节奏面板、全局快捷键、离线可用、低延迟。

## 二·五、教室场景全景明细（36 场景 · Oracle 深度分析 2026-09-23）

> 来源：Oracle 教室场景穷举（×三关校准：Win7 离线 / 零儿童数据采集 / 教师时间成本 >2 分钟/节 即出局）。本明细是"场景三：教室"的深度展开，供需求文档 §5 与 AI 路线引用。

### A 组 课前与晨读（7:00-8:00）

| # | 场景 | 痛点 | 现状 |
|---|---|---|---|
| A1 | 晨读领读缺位 | 老师同时巡视 3-4 个班，不在场的班无人领读，错音互相传染 | 录音机/蓝牙音箱放磁带；指定"小老师"（发音未必对） |

## 三、跨场景功能对照表

| 功能          | 家庭     | 办公室   | 教室           | 开发策略                 |
| ------------- | -------- | -------- | -------------- | ------------------------ |
| 便携启动+认证 | 可选     | **刚需** | **刚需**       | 一套启动器，三模式配置   |
| 屏幕批注      | 精细编辑 | 截图标注 | **全局覆盖层** | 教室版最重，家庭版可简化 |
| 计时/点名     | 少用     | 少用     | **高频**       | 教室专属                 |
| 成绩分析      | **高频** | 查看     | 展示（脱敏）   | 家庭版最重               |
| 评语生成      | **高频** | 微调     | 不用           | 家庭版                   |
| 文件转换      | 中频     | **高频** | 少用           | 办公室版                 |
| 打印辅助      | 中频     | **高频** | 不用           | 办公室版                 |
| 内容包        | **高频** | 调用     | 即取即用       | 三场景共用，侧重不同     |
| 局域网互动    | 不用     | 不用     | **高频**       | 教室专属                 |
| 录屏          | **高频** | 少用     | 中频           | 家庭版最重               |
| AI增强        | **高频** | 中频     | 低频           | 在线可选                 |
| 数据无痕      | 可留存   | **必须** | 下课即走       | 办公室版最严             |
| 离线可用      | 可选     | **必须** | **必须**       | 办公室+教室              |

**关键洞察**：

- **家庭** = 深度功能 + 可联网 + 可安装
- **办公室** = 便携 + 无痕 + 快速 + 离线
- **教室** = 极简 + 极快 + 离线 + 不抢戏

三者不是三个产品，而是**同一Tauri应用的三种模式**：通过启动时的场景选择（或U盘上的配置文件）切换UI布局、功能集、数据策略。

## 六、产品形态建议：一个应用，三种模式

```
U盘/
  TeacherTool.exe
  config/
    mode.json          # 场景配置：home / office / classroom
  data/
    home/              # 家庭模式数据（可留存）
    office/            # 办公室模式数据（退出即清）
    classroom/         # 教室模式数据（下课即清）
  packages/            # 内容包
```

**启动时**：

- 自动检测环境（是否有智慧白板？是否联网？是否首次运行？）
- 或手动选择模式：家庭/办公室/教室
- 不同模式加载不同UI布局、功能集、数据策略

**家庭模式**：完整功能，可联网，数据留存，界面偏桌面端。
**办公室模式**：便携功能，无痕，快速，界面偏工具集。
**教室模式**：极简，全局快捷键，离线，界面偏悬浮/覆盖层。

**一句话**：不是做三个软件，而是做一个Tauri应用，通过场景模式切换，分别服务教师的三个工作场景。U盘是载体，认证是基础设施，内容包是扩展方式，三场景整合是核心差异化。
