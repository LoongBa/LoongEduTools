# 代课应急包 · R2（U1 + U2）

给「非本班任课老师 / 代课 / 自习」的 20–40 分钟应急材料。围绕教材三处断点的**简化版**，不引入新知识点。

## 内容清单

```
substitute-kit/
├── u01/
│   ├── lesson_plan.md        # 5 分钟流程 + 20 分钟活动
│   ├── board_notes.md        # 板书要点（可直接抄黑板）
│   ├── backup_activities.md  # 备用活动 ×3（时间不够/设备故障）
│   └── assets_index.json     # 素材索引（TTS/配图/词卡引用）
├── u02/
│   ├── lesson_plan.md
│   ├── board_notes.md
│   ├── backup_activities.md
│   └── assets_index.json
└── README.md
```

## 使用约定

- 时长：默认 20 分钟；`lesson_plan.md` 含 40 分钟扩展段。
- 依赖：**纯 markdown + JSON**，无网络、无 AI；图片走壳端本地包（素材索引相对路径）。
- 命名：u01 = PEP 四上 Unit 1；u02 = Unit 2。
