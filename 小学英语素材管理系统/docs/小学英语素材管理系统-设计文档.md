# 小学英语素材管理系统 · 设计文档（v1.0 草案）

> 版本：v1.0 ｜ 日期：2026-09-21 ｜ 状态：**草案（待评审）**
> 上游：`小学英语素材管理系统-需求文档.md`
> 原则：**轻量、可重建、SSOT（单源真值）**、只读素材、agent 可查询。

## 1. 架构总览

```
                ┌────────────────────────────────────────────────┐
                │ 小学英语素材管理系统（本系统，自用）              │
                │                                                │
 只读输入 ──▶    │  inventory.py（CLI：scan/check/status/missing）│
  ┌──────────┐  │      │                                          │
  │ 素材根目录 │  │      ▼                                        │
  │ PEP词库/  │  │  inventory/ 清单仓库（SSOT）                   │
  │ 重绘tasks │  │  ├── manifest.json      ← scan 产物（册→单元→页→track）│
  │ qa_reports│  │  ├── integrity.json     ← check 产物（对账结果） │
  │ 点读陪练   │  │  ├── production.json    ← status 产物（四类状态）│
  └──────────┘  │  └── readiness.json     ← 三消费方就绪矩阵      │
                │      │                                          │
                │      ▼                                          │
                │  report.md（由 JSON 生成，替代手工素材清单.md）    │
                └────────────────────────────────────────────────┘
                              │ 消费方读取（agent / 构建管线 / 人工）
```

- **SSOT = manifest.json**：一切派生（integrity/production/readiness/report）都由它 + 只读输入重建
- **绝不写素材**：所有产物只落在 `小学英语素材管理系统/inventory/` 目录，素材根目录只读
- **可重建**：删除整个 `inventory/` 后 `python inventory.py scan && check && status` 即可还原

## 3. 数据模型（JSON Schema v1）

### 3.1 manifest.json（SSOT 核心）

```jsonc
{
  "schema_version": "1.0",
  "generated_at": "2026-09-21T00:00:00+08:00",
  "root": "F:\\_教材素材\\人教版（PEP）（主编：吴欣）",
  "grades": [
    {
      "grade": "四年级",
      "term": "上册",
      "book_id": "1212001401255",
      "published": true,                    // false = 六下未出版
      "book_name": "英语（PEP）四年级 上册",
      "pdf": "2022新课标：义务教育教科书•英语 四年级上册.pdf",
      "cover": { "file": "Cover.png", "source": "pdf_page1", "w": 1087, "h": 1536 },
      "stats": { "page_images": 86, "audio_tracks": 1257, "subtitles": 24, "size_mb": 690.4 },
      "units": [
        {
          "unit_no": "U01",
          "title": "Unit 1 Helping at home",
          "pages": [
            {
              "page_no": 2,
              "image": "Page_002.png",
              "image_exists": true,
              "page_audio": "P002.mp3",
              "page_audio_exists": true,
              "tracks": [
                { "track_id": 1553610, "text": "Unit 1 Helping at home",
                  "audio": "P002_01_Unit_1_Helping_at_home.mp3",
                  "audio_exists": true, "cn": "第一单元 在家帮忙",
                  "hotzone": { "l": 0.0773, "t": 0.0479, "r": 0.8536, "b": 0.2396 } }
              ],
              "no_audio_page": false          // true = 数据源特性（六上 P9 等 7 页）
            }
          ]
        }
      ]
    }
  ]
}
```

- 单元划分以 book.json `bookaudio_v3` 为准；页码与 `Page_NNN.png` / `P{NNN}.mp3` 对齐
- `track_id` 关联 `PEP词库/data/diandu/` 原始热区，避免重复存储大对象

### 3.2 integrity.json（check 产物）

```jsonc
{
  "schema_version": "1.0",
  "generated_at": "...",
  "summary": { "books_checked": 11, "pages_total": 900, "missing_images": 0, "missing_tracks": 0 },
  "issues": [
    { "grade": "六年级", "term": "上册", "page_no": 9, "type": "no_audio_page",  // 数据源特性
      "detail": "track_info 为空（平台无点读音频）", "severity": "info" },
    { "grade": "一年级", "term": "下册", "page_no": 2, "type": "missing_audio",  // 真实缺漏
      "detail": "P002_02_*.mp3 未找到", "severity": "error" }
  ]
}
```

### 3.3 production.json（status 产物）

```jsonc
{
  "schema_version": "1.0",
  "generated_at": "...",
  "units": [
    {
      "grade": "四年级", "term": "上册", "unit_no": "U01", "title": "Unit 1 Helping at home",
      "redraw": { "state": "passed",            // 未开始|进行中|QA待检|通过|返工
```

## 4. 模块设计（scripts/）

### 4.1 scanner.py —— 盘点（FR1）

- 遍历素材根：按 `年级/册次/_图片素材/Page_NNN.png` + `_音频素材/`（单句/页/单元/字幕）
- 并行读 book.json（`PEP词库/data/diandu/`）构造「册→单元→页→track」骨架
- 文件名解析（`P{页}_{序号}_{文字}.mp3` ↔ track 序号）建立音图对应
- 输出 manifest.json；增量模式按目录 mtime 跳过未变册

### 4.2 integrity.py —— 对账（FR2）

- 基准 = book.json（页码/每 track）
- 校验项：页面图存在、每 track 单句音频存在、页音频存在、字幕存在
- 特判：`no_audio_page`（数据源无音页，六上 7 页等）→ 记 `info` 不记 `error`
- 输出 integrity.json + 终端摘要（"11 册对账完成：缺图 0、缺音 0、无音页 N 页"）

### 4.3 status.py —— 四类状态推导（FR3）

| 状态 | 推导规则（只读） |
|------|------------------|
| 重绘 | 读 `tasks/<册>/<单元>/output/` 产物数 + `qa_reviews.json` 结果（passed/rejected） |
| TTS | 读 `_重读音频素材/单句音频/` 与 track 清单比对完成率 |
| 视频 | 读 `素材清单.md`（迁移后读 readiness 或 CapCutTool 产物目录） |
| 内容包 | 读 `点读陪练/` 相关内容包（content.json）的 schema_version/审校标记 |

- 规则集中在一张表（`STATUS_RULES`），便于按新视频模式扩展
- 人工覆盖：允许 `production.overrides` 段写入原因（如"手调保留"）

### 4.4 readiness.py —— 就绪矩阵（FR4）

| 消费方 | 就绪条件 |
|--------|----------|
| 视频 | 页面图全 + 重绘通过（或原图可用）+ 音频齐全 |
| 小程序（点读陪练） | content.json 已审校 + audio/images 已产 + 无阻塞热区 |
| 教辅（打印） | content.json 已审校 + print_version 六件套字段已填 |

- 输出 readiness.json + `next_actions`（按阻塞数排序）

### 4.5 report.py —— markdown 渲染（FR7 / Q2）

- 由 manifest+integrity+production 渲染出 `report.md`
- 结构对齐现有 `素材清单.md`（册表 + 说明），**成为其替代生成物**
- 人工备注段保留（`report.notes` 由人工维护，脚本不覆盖）

### 4.6 inventory.py —— CLI 入口

```bash
python inventory.py scan              # 盘点 → manifest.json（增量）
python inventory.py check [--grade G] # 对账 → integrity.json + 摘要
python inventory.py status [--unit U] # 状态 → production.json
python inventory.py missing [--mode  video|peidian|print]   # 缺失清单/下一步
python inventory.py report            # 渲染 report.md
python inventory.py matrix            # 就绪矩阵（终端表格）
```

- 全部支持 `--json` 输出（agent 消费）；`--full` 全量重扫
- 退出码：0 正常 / 2 参数错 / 3 发现 error 级缺失

## 5. 与既有系统的衔接

| 既有系统 | 本系统角色 | 冲突/改动 |
|----------|-----------|-----------|
| `PEP词库/` | **只读引用**（diandu 对账基准 + vocab 词库） | 无改动 |
| `素材清单.md` | 由本系统 `report.md` **替代生成** | 手工表 → 生成物（保留 notes） |
| `RedTools/重绘工具/` | 读取 tasks/ + qa_reviews.json（只读） | 无改动 |
| `RedTools/build_framework.py` | 构建前可选调 `check` 做完整性预检 | 可选接入，不强制 |
| `LoongMediaTools/CapCutTool/` | 视频模板只读引用 | 无改动 |
| 批量生图/TTS（LoongMediaTools） | 通过 CLI 读 `missing` 获取下一批任务 | 只读 |
| 点读陪练（`点读陪练/`） | 读取内容包/构建产物状态 | 无改动（schema 已冻结） |

## 6. 数据流与运行时序

```
首次/数据变化时：
  scan ──▶ manifest.json（SSOT）
    │
    ├─▶ check ──▶ integrity.json
    ├─▶ status ──▶ production.json
    └─▶ readiness ──▶ readiness.json
              │
              ▼
          report.md（人工查阅/分享）

消费方查询（随时）：
  agent  ──▶ python inventory.py missing --mode peidian --json
  构建   ──▶ python inventory.py check --grade 四年级 --term 上册（退出码 3=缺素材）
  人工   ──▶ report.md / matrix 终端表
```
