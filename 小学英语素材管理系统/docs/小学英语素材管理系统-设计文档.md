## 1. 架构总览

```
                ┌────────────────────────────────────────────────┐
                │ 小学英语素材管理系统（本系统，自用）              │
                │                                                │
 只读输入 ──▶    │  inventory.py（CLI：scan/check/status/missing）│
  ┌──────────┐  │      │                                          │
  │ 素材根目录 │  │      ▼                                        │
  │ PEP词库/  │  │  inventory/ 清单仓库（SSOT）                   │
  │ 重绘tasks │  │  ├── manifest.json      ← scan 产物（册→单元→页→track）│
  │ qa_reports│  │  ├── integrity.json     ← check 产物（对账结果） │
  │ 点读陪练   │  │  ├── production.json    ← status 产物（四类状态）│
  └──────────┘  │  └── readiness.json     ← 三消费方就绪矩阵      │
                │      │                                          │
                │      ▼                                          │
                │  report.md（由 JSON 生成，替代手工素材清单.md）    │
                └────────────────────────────────────────────────┘
                              │ 消费方读取（agent / 构建管线 / 人工）
```

- **SSOT = manifest.json**：一切派生（integrity/production/readiness/report）都由它 + 只读输入重建
- **绝不写素材**：所有产物只落在 `小学英语素材管理系统/inventory/` 目录，素材根目录只读
- **可重建**：删除整个 `inventory/` 后 `python inventory.py scan && check && status` 即可还原

## 3. 数据模型（JSON Schema v1）

### 3.1 manifest.json（SSOT 核心）

> **数据来源（Oracle 评审 M1/M2 修正）**：manifest 必须 **JOIN 两个数组**——
> - `bookaudio_v3[]`：单元目录树（Unit → Part A/B/C → `page_no`），只给"单元→页"映射，**无 track/热区**
> - `bookpage[]`：扁平数组（86 条/册），按 `page_no` 索引，含全部 `track_info[]`（热区/音频/文本）
> - scanner 先用 `bookaudio_v3` 建"单元→page_no 集合"，再按 `page_no` 从 `bookpage[]` 取 track。
>   字段名一律对齐 book.json 原生命名（`track_text/track_genre/track_left...`），本地音频文件名由 `page_no+track_index` 推导。

```jsonc
{
  "schema_version": "1.0",
  "generated_at": "2026-09-21T00:00:00+08:00",
  "root": "F:\\_教材素材\\人教版（PEP）（主编：吴欣）",
  "diandu_root": "F:\\LoongBa_Git\\LoongEduTools\\PEP词库\\data\\diandu",
  "grades": [
    {
      "grade": "四年级",
      "term": "上册",
      "book_id": "1212001401255",
      "published": true,                    // false = 六下未出版
      "book_name": "英语（PEP）四年级 上册",
      "pdf": "2022新课标：义务教育教科书•英语 四年级上册.pdf",
      "cover": { "file": "Cover.png", "source": "pdf_page1", "w": 1087, "h": 1536 },
      "stats": { "page_images": 86, "audio_tracks": 1257, "subtitles": 24, "size_mb": 690.4 },
      "units": [
        {
          "unit_no": "U01",
          "title": "Unit 1 Helping at home",
          "pages": [
            {
              "page_no": 2,
              "image": "Page_002.png",
              "image_exists": true,
              "page_audio": "P002.mp3",
              "page_audio_exists": true,
              "tracks": [
                { "track_id": 1553610, "track_index": 1,
                  "track_text": "Unit 1 Helping at home",
                  "track_genre": "第一单元 在家帮忙",        // 原设计 cn
                  "track_duration": 4.41,                   // 视频/音频时长需要
                  "audio_local": "P002_01_Unit_1_Helping_at_home.mp3",  // 推导：P{页:03d}_{track_index:02d}_{clean_name(track_text)}.mp3
                  "audio_exists": true,
                  "hotzone": { "left": 0.0773, "top": 0.0479,
                               "right": 0.8536, "bottom": 0.2396 } }     // 原设计 {l,t,r,b}
              ],
              "no_audio_page": false          // true = 数据源特性（六上 P9 等 7 页）
            }
          ]
        }
      ]
    }
  ]
}
```

- 单元划分以 `bookaudio_v3` 为准（单元→页映射）；**track/hotzone 数据取自 `bookpage[].track_info[]`**，二者按 `page_no` JOIN
- `audio_local` 命名规则对齐 `diandu_audio.py`（`P{页:03d}_{track_index:02d}_{clean_name(track_text)}.mp3`），避免重新发明
- **scanner 断言**：manifest 总 track 数 ≈ sum(bookpage[].track_info[].count)
- **前置条件**：`PEP词库/data/diandu/*.json` 需已解压（`book_data.zip` 分发，原始 json 不入 git）——scan 启动时检查 book.json 存在，缺失则提示解压命令

## 4. 模块设计（scripts/）

### 4.1 scanner.py —— 盘点（FR1）

- 遍历素材根：按 `年级/册次/_图片素材/Page_NNN.png` + `_音频素材/`（单句/页/单元/字幕）
- 读 book.json（`PEP词库/data/diandu/`）构造「册→单元→页→track」骨架（**JOIN bookaudio_v3 + bookpage[]**）
- 文件名解析（`P{页}_{序号}_{文字}.mp3` ↔ track_index）建立音图对应；`audio_local` 按 `diandu_audio.py` 命名规则推导
- 输出 manifest.json；增量模式按**册级子树比对 + 文件数校验**（非纯目录 mtime，防 Windows 误跳）

### 4.2 integrity.py —— 对账（FR2）

- 基准 = book.json `bookpage[]`（页码/每 track）
- 校验项：页面图存在、每 track 单句音频存在、页音频存在、字幕存在
- 特判：`no_audio_page`（数据源无音页，六上 7 页等）→ 记 `info` 不记 `error`
- 输出 integrity.json + 终端摘要（"11 册对账完成：缺图 0、缺音 0、无音页 N 页"）

### 4.3 status.py —— 四类状态推导（FR3，Oracle M3-M6 修正）

| 状态 | 推导规则（只读，真实数据源） |
|------|------------------|
| 重绘 | 完成度 = `tasks/pep{N}{s|x}_u{MM}/output/` 文件数 ÷ input/ 文件数（task_name 正则解析册/单元）；QA = 读 `qa_reports/<册>.html` 内嵌 `const DATA={pages:[{page,has_orig,has_redr,ssim,...}]}`（正则提取 JSON），`has_redr` 判页级重绘事实；pass/rejected 暂由 overrides 人工填（qa_reviews.json 当前为空 `{}`，M1.5 决定策略） |
| TTS | 读该册 `_重读音频素材/单句音频/` 与 track 清单比对完成率（实测仅四上有此目录，其余册=未生成） |
| 视频 | **读 `RedTools/publish/学科/新英语四上点读*.zip` 存在性 + LoongMediaTools/CapCutTool 产物**（不读 readiness，消除循环依赖） |
| 内容包 | 检查 `点读陪练/build/uXX/uXX_content_package.json` 是否存在 + `07_qa_report.md` 结论行（PASS/WARN/SKIP） |

- 规则集中在一张表（`STATUS_RULES`），便于按新视频模式扩展
- 人工覆盖：允许 `production.overrides` 段写入原因（如"手调保留"、"QA 已过"）

### 4.4 readiness.py —— 就绪矩阵（FR4）

| 消费方 | 就绪条件（Oracle R4 修正） |
|--------|----------|
| 视频 | 页面图全 + 重绘产物齐全（output≥input）+ TTS 重读完整 + 无返工标记（QA=未质检记 warning 不阻塞） |
| 小程序（点读陪练） | `uXX_content_package.json` 存在 + `07_qa_report.md` 通过 + 音频/图片产物存在 |
| 教辅（打印） | `print_worksheet_sample.html` 存在 + content_package 已审校（"六件套"字段见需求 FR4，此处以文件存在性判定） |

- 输出 readiness.json + `next_actions`（按阻塞数排序）

### 4.5 report.py —— markdown 渲染（FR7 / Q2）

- 由 manifest+integrity+production 渲染出 `report.md`
- 结构对齐现有 `素材清单.md`（册表 + 说明），**成为其替代生成物**
- 人工备注段保留（`report.notes` 由人工维护，脚本不覆盖）

### 4.6 inventory.py —— CLI 入口

```bash
python inventory.py scan              # 盘点 → manifest.json（增量）
python inventory.py check [--grade G] # 对账 → integrity.json + 摘要
python inventory.py status [--unit U] # 状态 → production.json
python inventory.py missing [--mode  video|peidian|print]   # 缺失清单/下一步
python inventory.py report            # 渲染 report.md
python inventory.py matrix            # 就绪矩阵（终端表格）
```

- 全部支持 `--json` 输出（agent 消费）；`--full` 全量重扫
- 退出码：0 正常 / 2 参数错 / 3 发现 error 级缺失

## 6. 数据流与运行时序

```
首次/数据变化时：
  scan ──▶ manifest.json（SSOT）
    │
    ├─▶ check ──▶ integrity.json
    ├─▶ status ──▶ production.json      # 重建输入 = manifest（应有）+ 外部产物目录扫描（实有）
    └─▶ readiness ──▶ readiness.json
              │
              ▼
          report.md（人工查阅/分享）

消费方查询（随时）：
  agent  ──▶ python inventory.py missing --mode peidian --json
  构建   ──▶ python inventory.py check --grade 四年级 --term 上册（退出码 3=缺素材）
  人工   ──▶ report.md / matrix 终端表
```

> **重建输入（Oracle R2）**：manifest = 素材根 + diandu book.json；integrity = manifest + 素材根；
> production = manifest + 外部产物目录（tasks/、_重读音频素材/、publish/CapCutTool、点读陪练/build/）；
> readiness = production + integrity。均只读、可一键重建。
