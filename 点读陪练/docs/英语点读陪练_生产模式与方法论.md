## 1. 模式总览



```
教材单元（PDF）──①提取──▶ 知识骨架 JSON（话题/词汇/句型/语音/项目/自测）

&#x20;                                 │

&#x20;                                 ▼ ②套模板（9 段，参数化）

&#x20;                         内容 JSON（原创词句/题目/绑定表）

&#x20;                                 │

&#x20;             ┌─────────────┬─────┴──────┬─────────────┐

&#x20;             ▼             ▼            ▼             ▼

&#x20;       ③ AI 批量配图   ④ TTS 批量配音  ⑤ 前端组装(热区)  ⑥ 审核/QA

&#x20;             └─────────────┴─────┬──────┴─────────────┘

&#x20;                                 ▼

&#x20;                          发布 zip（复用 build\_framework）
```



* **① 知识骨架提取**：人工 + OCR，约 0.5 人天 / 单元（规则见 §3）

* **② 模板套用**：内容生成（LLM 起草 + 教师审校），约 0.5 人天 / 单元（规则见 §2、§4）

* **③④⑤**：全部复用现有资产（批量生图工具、**音频批量生成工具**〔LoongMediaTools 通用 TTS，Edge TTS/Kokoro 双引擎〕、build\_framework、热区交互），近零新开发

* **⑥ QA**：机器比对 + 人工抽查，约 0.25 人天 / 单元

> 单单元净新增工作量约 1–1.5 人天（主要是原创句与审校），且随单元数增加递减（人物 IP、词卡资产、句型池复用）。

### 2.1 段间固定衔接规则



* 段 0→1：段 0 活动卡 = 段 1 词卡子集，资源复用

* 段 1→2/3/4：段 1 词卡 = 句型操练的词库来源（词卡资产跨段复用）

* 段 4→5：段 4 卡池 = 段 5 支架选卡来源（同一卡池两处用）

* 段 5→7：段 7 短文人物 = 段 5 项目人物（同 IP 连贯）

* 段 7 Self-check 4 条 = 教材 Self-check 原文对应功能（可同步，为课程目标）\`n- 段 7→8：段 8 检验任务复用段 1–7 的句库 / 词卡 / 人物资产（同一资产最后验收）

### 2.2 能力检验站规则（Self-check 落地・全册强制）

> 教材 Self-check 是能力清单但没人会执行；产品把每条「I can…」变成可执行检验任务：练到会、测得准、缺了补。



* **能力清单**：直接采用教材 Self-check 的功能目标（课程目标可同步），数量 4 条

* **检验任务设计规范**：每条能力 1 个检验任务（含 3 小项），必须「孩子自主产出」（口语产出 / 指认 / 听写），**不得用选择题充当检验**（选择题是训练，检验要产出）

* **能力↔训练段映射**：每条能力至少映射 2 个训练段；未通过自动补练映射段（错哪练哪）

* **先测后评**：检验结果 → 三档自评（我能做到 / 基本可以 / 需要帮助），自评有实测依据

* **判定**：口语产出由家长对照句卡确认（对 / 再练一次），书面类由工具判定；不做语音评分

* **家长能力报告**：4 条能力 × {✅ 达标 / 🔁 需补练} + 建议补练段；数据最小化（只存能力状态）

### 2.3 段内通用交互（全段复用）



* 热区 = 点击发音区（句中每个词、题目每题），窄屏按 9:16 适配，热区最小 44×44px

* 作答 = 点选 / 连线 / 拖卡，答对打勾 + 鼓励音效；答错只提示重试，无惩罚

* 产出型任务 = 槽位模板 + 词卡，孩子自己说出 / 拼句（非选项），家长确认；每句型段标配 2–3 题 + 段末小老师 1 题

* 中文释义仅首次出现显示，可开关（家长可关）

* 打卡 = 段完成 → 星星 / 日历记录，只存完成状态

### 3.1 提取来源映射（教材板块 → 骨架字段）



| 教材板块                               | 提取内容      | 写入骨架字段                            |
| ---------------------------------- | --------- | --------------------------------- |
| 起始页主题问句                            | 单元话题      | `topic`                           |
| Let's learn + 词卡                   | 必学词       | `words.core`                      |
| Let's talk / Listen and chant / 正文 | 出现但非词卡词   | `words.extra`（标注来源，决定是否进产品）       |
| Let's talk 句型                      | 主句型结构     | `patterns[1-3]`（含主语 / 宾语槽位）       |

| Project                            | 支架句结构     | `project.scaffold`                |
| Self-check                         | 功能目标（可同步） | `self_check[4]`                   |

### 3.2 骨架 JSON Schema（开发 / 生产接口）



```
{

&#x20; "title": "My friends",

&#x20; "words": {

&#x20;   "core": \["tall", "short", "strong", "thin", "kind", "quiet", "funny"],

&#x20;   "extra": \["special", "long hair", "short hair", "big eyes", "small eyes"]

&#x20; },

&#x20; "patterns": \[

&#x20;   {"id": "p1", "frame": "What's {poss} friend's name? — {pron} name is {name}."},

&#x20;   {"id": "p2", "frame": "{pron} is {adj}. {pron} has {hair/eyes}."},

&#x20;   {"id": "p3", "frame": "{pron} often {v3} with me. / We {v} together."}

&#x20; ],
```

### 3.3 词表取舍规则



* `words.core`：Let's learn 词卡词全部进产品（必学）

* `words.extra`：正文 / 歌谣出现、且符合当前年级认知 → 进 "拓展卡"，默认开启、家长可关；超纲或低价值（如专有名词）不进

* 每组词卡固定 8 词：core 不足 8 用 extra 补；超过 8 按主题子组拆分（本模板两组共 16 词）

## 4. 三层内容模型（原文 / 补全 / 扩展・步骤 ②）

> 目标：教材只给 "句型框架 + 词表 + 1 个完整例句"，家长和孩子都不会补全扩展，家校教学断开；产品
>
> **替他们补全、扩展，直接给出结果**
>
> （三层句库）。



1. **原文层**：教材出现的完整例句（示范锚点，每知识点 1–2 句），数据层标记 `source: textbook`，QA 白名单放行；音频为 TTS 重读版本

2. **补全层**：教材 "句型框架 × 词表" 的**全部合法组合**—— 槽位 × 词表自动枚举，语法修正脚本处理 a/an、三单、is/has，人工审核；判定 = 组合合法（标准答案）；**"三甚至更多" 由补全层天然满足**

3. **扩展层（收敛版）**：= 补全的换位变体（换主语 / 人物 / 场景，仍用教材句型与词）+ 融入已学词（复习标签）的新句；**完全围绕教材，不引入教材外知识点**；每知识点 ≥3 句；判定 = 标准答案 / 结构校验

4. **复习机制**：扩展词若来自已学册词表，自动打 `review: <册次>` 标签（家长端可见，孩子无感），形成 "新学 + 复习" 闭环

5. **语音段**：原文层 = Let's spell 全部完整句；扩展层 = 用组合词自组新句（换人物 / 场景 / 动作）

6. **短文**：原文层 = Reading time 核心句（1–4 句）；扩展层 = 续写 3–5 句（保持 4 上难度与主题）

7. **PBL（Project）**：同样分层 ——PBL 补全 = 模板槽位 × 词表 = 完整句库；PBL 扩展 = 不同家庭结构 / 人物组合

8. **句卡库**：每单元产出三层完整句卡清单（屏显滚动 + 可打印），家长直接拿来陪读

9. **词用范围白名单（全册硬规则）**：补全层用词 = 本单元词表；扩展层用词 ∈ {本单元词表 ∪ 已学年级词（复习标签）∪ 正文出现词（拓展标签）}；禁止超前词与生僻词；原文层豁免。QA 脚本扫词标红。

10. **音频与配图红线**：所有音频（含原文层）为 TTS 重读版本，不使用教材原版录音；图片 / 人物自绘，不复制教材页面与角色形象

11. **词 ID 一词多标签（数据层）**：同一词可属多知识点（如 share 既是 sh 语音词又是行为动词），用全局词 ID 关联多标签，词池唯一不重复建

12. **举一反三引导（学习方法・全册强制）**：每个句型知识点标配 ——① 方法卡（句型槽位可视化 + 引导话术 "换哪个词 = 新句子"）② 产出型任务 2–3 题（孩子自己造句，非选项作答）③ 小老师环节（孩子教家长，输出即掌握）；顺序：示范（原文）→ 方法（方法卡）→ 产出（自己造）→ 资源兜底（句卡库全量）

## 5. 内容生成模板（步骤 ② 的 LLM Prompt 骨架）

每单元调用内容生成时使用统一 Prompt 模板（人工审校兜底）：



```
你是小学英语（人教版 PEP 四上）同步练习的内容作者。

输入：单元骨架 JSON（topic/words/patterns/phonics/project/self\_check）。

输出：8 段内容 JSON，要求：

1\. 每个知识点输出三层句库：原文（教材完整例句，标记来源）+ 补全（句型×词表全量合法组合）+ 扩展（≥3 句，复习词/正文词）；

2\. 补全用词 = 单元词表；扩展用词 ∈ {单元词表 ∪ 已学词(复习) ∪ 正文词(拓展)}，禁止超前词与生僻词；句长 ≤ 8 词/句；

3\. 每段满足模板 §2 的参数数量（题数、词数、句数）；

4\. 判定绑定表完整（图↔词↔音、图↔主语↔动作、人物↔属性）；

5\. 配图 prompt 遵循统一人设与画风（见 §6.1）；

6\. 输出能力检验站：4 条能力 → 检验任务（自主产出型）+ 训练段映射 + 补练映射。
```

## 9. V1.3 新增：册次通用结构 / 词表公共资产 / 程序骨架（2026-09-21）

### 9.1 册次通用结构（全册强制）

每册 = **N 个普通单元**（单元数随年级变化，如四上 = 6）+ **1 个 Revision 复习单元**（第七单元，走《复习单元与附录模式》的复习版 7 段）+ **1 个 Songs 附录**（点唱机模式）+ **1 个单元词汇表 Appendix 2**（词卡浏览器 + 听写/背单词数据源）+ **1 个字母序词汇表 Appendix 3**（全册词典模式）。

### 9.2 词表跨工具公共资产

单元词汇表同源服务于三工具：**点读陪练**（词卡/句库/挖空）、**听写工具**（四会词听写单）、**背单词工具**（词卡刷词）。数据层统一引用公共词库（word/grade/unit/meaning/audio），三工具共享学情（达标状态互认），不重复建库。

### 9.3 程序骨架蓝图（模式固定后搭建）

```
教材 PDF ─①骨架提取(人工/OCR)─▶ 骨架 JSON
        ─②三层句库 LLM 生成（提示词 + 词库判定脚本）─▶ 句库 JSON（人审）
        ─③AI 批量配图（原创 IP）──▶ 图集
        ─④TTS 批量配音（原文层重读）──▶ 音频
        ─⑤组装（JSON + 图 + 音 + 热区 + 句卡/打印版）──▶ zip
        ─⑥QA 闸门（比对/扫词/绑定/听音抽查）
```
中间环节（②③④）全部接 AI API（提示词生成内容 + 图片 + 音频），人审兜底（②审核 + ⑥QA）；骨架提取仍人工（约 0.5 人天/单元），随模板固化可逐步半自动化。

## 10. V1.4 新增：载体分工（小程序 vs 打印版）

### 10.1 判断原则

- **小程序（微信/小红书生态）= 互动主力**：需要声音/动画/即时反馈/自动判定/个性化调度（点读、听写、记忆曲线背记、闪卡、能力检验、进度）
- **打印版（PDF 电子版）= 无屏补充**：需要纸笔书写/离线查阅/亲子共看/不设屏的场景（练习小单、句卡、PBL 模板、记录单、路线图、歌词）
- **同一内容双渲染**：内容包（句库 JSON + 音频 + 原创图）同源，小程序渲染互动版，打印模板渲染 PDF 版；不重复制作

### 10.2 分工总表

| 内容 | 小程序（主力） | 打印版（补充） |
|---|---|---|
| 九段练习（互动点读/判定） | ✅ 热区点读、自动判定 | ❌（练习过程在小程序） |
| 练习小单（填空卷） | 可做线上填空 | ✅ 空白卷+背面答案，纸笔做 |
| 听写 | ✅ TTS 报词自动判 + 记忆曲线调度 | ✅ 听写单（家长报） |
| 记忆曲线背记 / 闪卡 | ✅ 间隔重复、翻卡 | ❌（调度靠程序） |
| 句卡库 | ✅ 屏显滚动 | ✅ 可打印陪读卡 |
| PBL 模板 | ✅ 选卡生成海报/小书 | ✅ 空白模板纸面画 |
| 能力检验站 | ✅ 互动检验 + 自动记录 | ✅ 检验记录单（家长签名） |
| 能力报告 / 进度 | ✅ 看板/打卡 | ✅ 全册能力报告单 |
| 陪练路线图（DayN） | ✅ 今日陪练卡片 | ✅ 一周计划表（贴冰箱） |
| 歌词（Songs） | ✅ 点唱机跟唱 | ✅ 歌词页（家庭合唱） |
| 单元词汇卡 | ✅ 闪卡/复习卡 | ✅ 词汇卡纸 |
| 全册词典（Appendix 3） | ✅ 查词+发音 | ❌ |

### 10.3 双载体协同

- 7 天路线图天然分工：**Day 1–6 小程序互动，Day 7 周末打印版**（不方便/不想用手机时全套纸面可完成）
- 联动：纸面完成 → 回小程序打卡/题号回填（补练闭环延伸到纸面，已在练习小单设计）

### 10.4 与人教点读差异化

| 维度 | 人教点读 | 本产品 |
|---|---|---|
| 内容 | 教材页面/原文照搬 | **三层句库**（原文 TTS 重读 + 补全 + 扩展复习）+ 原创 IP 场景，不复制页面 |
| 点读 | 教材点读 | 互动点读（同功能）+ 原创场景热区 |
| 附加功能 | 少 | **听写 / 记忆曲线背记 / 闪卡 / PBL / 能力检验站 / 打印版五件套 / 路线图**（人教点读没有） |
| 教学闭环 | 只"点" | **练→测→补** 闭环 + 能力报告（练到会、测得准、缺了补） |
| 载体 | App（教材配套） | 小程序（微信/小红书）+ 打印版补充 |

> 原则：**功能取长（互动点读等），内容不同（三层句库/原创）**，形成差异化而非同质竞争。

## 12. V1.6 新增：单元节奏三级命名（天天见 / 小阅兵 / 自助餐）

### 12.1 三级命名（产品面向用户的叫法）

| 层级 | 名字 | 含义 | 载体 |
|---|---|---|---|
| 每日 | **天天见** | 每天见面陪练，新学+巩固+复习，每天 15–20 分 | 小程序"今日陪练"卡片 |
| 周末 | **小阅兵** | 检阅一周所学：Day6 检验站（测）+ Day7 打印小单（练+家长判） | 小程序检验 + 打印版 |
| 并行可选 | **自助餐** | 想吃啥拿啥：点唱机 / 听写 / 背单词旧词 / 旧词过句型，碎片时间自选 | 小程序工具层 |

### 12.2 单元节奏（一个单元 ≈ 两周 = 4–6 上课日 + 2 周末）

> 现实约束：每周 2–3 节英语课，两周一个单元；**天天见跟上课日走**（英语课当天课后 15–20 分），不是每个工作日。

- **上课日（4–6 天，天天见）**：每天一个主题小课包（开场复习→新学→巩固→收尾），按 9 段内容编排
- **Week1 周末 = PBL**：项目式学习需要整块时间（30–40 分）+ 家长参与确认，放第一个周末做
- **Week2 周末 = 小阅兵**：S8 能力检验站（测，先测后评，未过映射补练）+ 打印单元小单（练，背面答案家长判，能力报告存档）
- **缓冲（弹性）**：检验未过 / 小单错题多 → 回对应段补练；学校进度不同步时拉伸位；掌握快的单元两周内完成即进 Revision
- **自助餐（并行，不占正课）**：单元点唱机（碎片随时唱）/ 单元听写（每周 1–2 次）/ 背单词旧词（每天 5 分钟记忆曲线）/ 旧词过本单元句型（= 天天见①开场复习弹药）

### 12.3 天天见小课包四环节（每天内部结构）

1. **① 开场复习（2–3 分）**：记忆曲线调度——旧词 / 前几天句型 / 旧词过本单元句型（扩展层 review 句）
2. **② 新学（5–8 分）**：本单元当天句型补全层（课本句型 × 本单元词表），原句示范→换词操练
3. **③ 巩固（5 分）**：扩展层（换场景/人物，仍用本单元词），方法卡→自己造句→产出型任务
4. **④ 收尾（2 分）**：小老师教家长 + 打卡

### 12.4 内容包 Schema 增补（v1.0 → v1.1）

顶层新增 `schedule`：
```json
"schedule": {
  "days": [
    {"day": 1, "type": "tiantian", "segments": ["S0", "S1"],
     "review": {"cards": ["旧词ID..."], "old_pattern": "前几天句型ID"},
     "new": ["S0", "S1"], "consolidate": ["S1扩展句ID"], "tutor": true},
    {"day": 6, "type": "yuebing", "segments": ["S7", "S8"]},

```
- `type`: tiantian（天天见）/ yuebing（小阅兵小程序）/ yuebing_print（小阅兵打印）
- 内容本身（三层句库/段）不变，`schedule` 只是把它们"按天编排"

## 13. V1.7 新增：模板变体（年级差异 · 九段是"段池"不是写死一套）

### 13.1 核心转变

九段模板不是"每册必须 9 段"，而是一个**段池**——每年级/册按教学重点从池里**选段 + 调参**组合出该册模板。四上验证的九段 = 默认模板；低年级/高年级从中删减或加段。

### 13.2 段池（可插拔的段类型）

| 段类型 | 低年级（3 年级） | 四上（默认） | 高年级（5-6 年级） |
|---|---|---|---|
| 0 单元地图 | ✅ 必选 | ✅ | ✅（可简化） |
| 1 词汇 | ✅ 词卡多 | ✅ 16 | ✅ 词多 |
| 2-4 句型 A/B/C | 选 1-2 段 | ✅ 3 段 | ✅ 3 段 + 语法点加深 |
| 4 语法点 | ❌ 不讲语法 | ✅（a/an、三单、There be…） | ✅（过去式等，方法卡加深） |
| 5 PBL | ✅ 槽位少（4） | ✅ 槽位 4-8 | ✅ 槽位多 + 写作输出 |
| 6 自然拼读 | ✅ 字母/短元音 | ✅ 辅音组合 ch/sh/ck/ph/th/wh | ✅ 长元音/字母组合 |
| 7 综合阅读 | 短句/对话 | ✅ 短文 4+5 句 | ✅ 长文 + 理解加深 |
| 8 能力检验站 | ✅ 4 条（口语为主） | ✅ 4 条 | ✅ 4-6 条（写为主） |

### 13.3 写的能力分档（贯穿小单/检验）

- 低年级：只描红/选词，**不做无提示默写**
- 四上：图/中文提示 + 可抄写（已验证）
- 高年级：去提示默写句子

### 13.4 骨架 Schema 增补

骨架顶层新增 `template_variant`：
```json
"template_variant": {
  "grade_band": "low | mid | high",
  "segments_used": ["S0","S1","S2","S3","S5","S6","S8"],
  "writing_level": "trace | hint_copy | no_hint_dictation",
  "grammar_skip": true
}
```
- 提取骨架时即标注该册用哪套段组合、写的档位、是否跳过语法段
- 内容生成 Prompt 按 variant 收窄（如低年级不输出语法方法卡）
