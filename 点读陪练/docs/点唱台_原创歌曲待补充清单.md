## 三、补充流程（补一首走一遍）

1. **Suno 生成**：按设计稿歌词 + Style prompt → Custom Mode → 下载 MP3，命名 `<unit目录名>_song_raw.mp3`（如 `g1u2_song_raw.mp3`）放入 `build/_assets/songs_inbox/`
2. **自动处理**：`python src/process_song.py`（Demucs 分离人声/伴奏 + 歌词对齐 + song.json）
3. **入单元**：产物落 `build/<unit>/assets/song/`
4. **删跳过标记**：若该单元有 `build/<unit>/song.skip`，删除它（恢复原创整曲进包）
5. **QA 抽听**：人声干净 / 伴奏无人声残留 / 时间戳抽 3 句对齐 / 60-90 秒
6. **重新发布该单元**：`python src/publish_offline.py -u <unit>`（可并入同册 U1,U2 一起重发）
7. **更新本表**：状态 → ✅；同步更新 `docs/日常工作对齐表.md` 点唱台列

## 四、发布中的对应行为（已实施，SOP v1.3）

- 有 `song.skip` 的单元：发布跳过原创整曲（song_vocal/instrumental + song.json），**保留教材歌词跟读**（textbook_lyrics.json + textbook/）
- 无 `assets/song` 目录的单元：发布自动跳过（WARN），包内无 song 目录
- 对外文案：无原创歌单元不宣传「点唱台原创儿歌」，仅保留教材跟读能力
