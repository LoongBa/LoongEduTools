## 1. 三层句库

**词用范围**：
- 颜色：red/blue/orange/brown/green/yellow
- 物品：pencil/apple/flower/tree/rabbit/dog/cat
- 句型：This pencil is red. / Let's draw a red apple. / I like colours.

---

## 2. 能力目标
| 能力 | 检验任务 |
|---|---|
| 说颜色 | This pencil is red. |
| 画+说 | Let's draw a red rabbit. |
| 说我喜欢的颜色 | I like red and blue. |

0 画画热身 / 1 颜色词大本营 / 2 This...is...颜色 / 3 Let's draw... / 4 宠物公园 PBL / 5 颜色总复习 / 6 检验站。

## 4. 要点
- **句型**：This + 物品 + is + 颜色 / Let's draw a + 颜色 + 物品
- **PBL**：设计宠物公园（画红兔子/蓝狗等）
- **玩法**：听色画画 / 颜色配对
