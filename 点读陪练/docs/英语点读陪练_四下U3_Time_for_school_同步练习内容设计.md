## 5. 分段要点

### 段 1 · 几点了
- **原文**：What time is it? / It's 5 o'clock. / It's 6 o'clock.
- **补全**：时间（整点）× 问答 ≈12 句
- **扩展**：What time is it? / It's 7:30. / It's 8:15.

### 段 2 · 该做什么了
- **原文**：It's time to go home. / It's time for dinner. / It's time for English class.
- **补全**：活动（get up/go to school/go home/go to bed/have breakfast/have lunch/have dinner/English/maths/art/PE class）× It's time... ≈15 句
- **扩展**：It's time to go to bed. / It's time for art class.

### 段 3 · 课程表
- **原文**：breakfast / lunch / dinner / English class / maths class / art class
- **补全**：课程×时间 ≈10 句
- **玩法**：点图发音 + 时间配对

### 段 4 · 我的作息表
- **原文**：7:00 get up / 7:30 go to school / 12:00 lunch / 3:00 PE / 9:00 bed
- **补全**：活动×时间 ≈10 句
- **扩展**：My schedule: 7:00 get up, 7:10 breakfast, 7:30 go to school...
- **方法卡**："作息表 = get up + go to school + have class + go home + go to bed"

### 段 5 · 周末作息表（PBL · 一天）
- **PBL 补全**：周末一天的作息表（起床/学习/运动/睡觉）

### 段 6 · or 语音 + 能力检验
- **字母词**：Ford/horse/work/world/sport/short/fork/word
- **玩法**：指读 or 词 → 圈首音
- **检验**：Self-check 4 条逐条过关
