## 1. 上课日 · 天天见（每天四环节）

### Week1 上课日1 · S0 地图 + S1 词汇
- **①开场复习**：前册旧词热身（三上家庭称谓 father/mother/grandpa/grandma）
- **②新学**：S0 家庭活动地图（8 热区点读）→ S1 词卡 16（职业 8 + 家务 8）
- **③巩固**：词图配对（听音选图/看图选词/听音点词）
- **④收尾**：打卡

### Week1 上课日2 · S2 Can 句型
- **①开场复习**：昨天 16 词抽 4 个闪卡 + 旧词过句型（旧词套 Can）
- **②新学**：Can 补全层（主语 × 动作 ≈40 句，脚本枚举）
- **③巩固**：扩展层换场景 + 方法卡 + 产出型任务
- **④收尾**：小老师（教家长问 Can…help?）

### Week1 上课日3 · S3 职业问答
- **①开场复习**：Can 句型闪卡 + 旧词 uncle/aunt（三上词——这天扩展层正好用）
- **②新学**：职业问答补全层（家庭 6 人 × 5 职业 ≈30 句，a/an 自动修正）
- **③巩固**：扩展层（uncle/aunt 的 job）+ 方法卡 + 产出型任务
- **④收尾**：小老师（家庭树问答）

### Week2 上课日4 · S4 I can…and…
- **①开场复习**：职业问答闪卡 + ch 词预热（teach/lunch）
- **②新学**：动作组合补全层（8 动作两两组合 ≈28 句）
- **③巩固**：扩展层（cook for my family / draw with mum）+ 方法卡
- **④收尾**：小老师（选两个动作连句教家长）

### Week2 上课日5 · S6 ch 乐园 + S7 阅读
- **①开场复习**：前四天句型快速过（2 句）
- **②新学**：S6 ch 拼读（8 词听辨/归类/拼读/听写）→ S7 快乐一家读一读（原文 4 + 续写 5，理解题 4）
- **③巩固**：ch 扩展句 7 句
- **④收尾**：打卡

## 2. 周末（家长在场）

### Week1 周末 · S5 PBL 幸福家庭海报
- 家长陪做：示范 → 方法卡（人+职业/活动=海报句）→ 自己组合 3-4 句 → 对照补全句库 → 点读跟读 → 完整朗读 → 家长确认 → 打卡
- 选周末的原因：PBL 需要整块时间（30-40 分）+ 家长参与（确认海报），工作日课后做不完

### Week2 周末 · 小阅兵（S8 检验站 + 打印小单）
- S8 能力检验站：4 能力逐条测（口语产出家长确认 / ch 词听写工具判定）；未过映射补练段
- 打印单元小单：纸面填空（Part1 职业 8 空 / Part2 Can 8 空 / Part3 组合 4 空 / Part4 ch 4 空）→ 背面答案家长判 → 错题回填对应段
- 能力报告存档（4 能力 ✅/🔁）

## 4. 关键设计点

1. **两个周末分工**：Week1 周末 = PBL（家长陪做项目）；Week2 周末 = 小阅兵（检验+小单）——不再是"周末才小阅兵"，而是"先做项目，再验收"
2. **天天见跟上课日走**：每周 2-3 天（英语课当天课后 15-20 分），不是每个工作日
3. **ch 自然拼读**：放 Week2 上课日5（和阅读一起），不占周末
4. **待硬依赖**：词库文件（review 自动打标 + 记忆曲线调度）
5. **年级差异**：低/高年级段池变体见方法论 v1.7
