## 2. 八步详解

### 步骤 ① 骨架提取（人工/OCR，0.5 人天/单元）

- **输入**：教材 PDF（印刷页范围，如 U01 = 印刷页 2–13）
- **输出**：`01_skeleton.json`（骨架 Schema v1.0 + template_variant）
- **方式**：人工读 PDF，按骨架字段填（见《Schema 定稿》§1）
- **字段**：unit/title/topic/words(core+extra)/actions/patterns/grammar_rule/phonics/project/self_check/reading/template_variant
- **审核点**：人审——词表是否对、句型框架是否准、Self-check 4 条是否齐

### 步骤 ② 补全层枚举【脚本】

- **输入**：`01_skeleton.json` + 公共词库
- **输出**：`02_complete_layer.json`
- **逻辑**：
  1. 读 `patterns[].frame`，解析槽位 `{who}` `{job}` `{action}`
  2. 槽位候选 = `words.core`（按语义分桶：who 桶/ job 桶/ action 桶）
  3. 笛卡尔积枚举 → 全部组合句
  4. 语法修正规则：
     - a/an：职业词元音开头（office worker/old engineer）用 an
     - 三单：He/She + 动词加 s（read→reads, play→plays）
     - is/has：样子用 is（He's tall），身体部位用 has（He has hair）
     - 进行时：v-ing（make→making, tell→telling）
- **示例**：frame `What's your {who}'s job? He's a {job}.` × who=[father,grandpa,mum...] × job=[farmer,nurse,doctor...] ≈30 句
- **审核点**：人审抽查（语法修正对不对、组合是否合法）

### 步骤 ③ 扩展层生成【LLM】

- **输入**：`01_skeleton.json` + `02_complete_layer.json` + 公共词库
- **输出**：`03_extend_layer.json`
- **方式**：调用提示词模板（见《Schema 定稿》§4，v1.0 冻结）
- **词库打标**：LLM 生成后，脚本扫每句用词 → 命中已学词库则打 `review:gX_uY` 标签
- **规则**：每知识点 ≥3 句；换场景/人物/动作；不引入教材外知识点；句长 ≤8 词
- **审核点**：人审——超前词/生僻词标红打回

### 步骤 ④ 配图【生图 API】

- **输入**：`04_content_package.json` 里所有 `image` 字段 + `image_prompt`
- **输出**：`assets/images/*.png`（与 image 字段同名）
- **逻辑**：遍历 JSON，每图槽位调生图 API
- **统一画风后缀**（拼接到每个 prompt）：
  > 扁平卡通暖色调、圆角白底卡片、简洁可爱、画面无任何文字、原创儿童插画风格
- **人物一致性**：家庭人物用原创 IP（小虎一家：爷爷/奶奶/爸爸/妈妈/孩子），不指教材角色
- **审核点**：抽检——无文字、画风统一、人物一致

### 步骤 ⑤ 音频【TTS API】

- **输入**：`04_content_package.json` 里所有 `audio` 字段 + 对应 `text`
- **输出**：`assets/audio/*.mp3`（与 audio 字段同名）
- **逻辑**：遍历 JSON，每句调 TTS
- **固定音色**（写死 prompt）：
  > 小学英语教材朗读风格，清晰标准美式发音，语速适中偏慢，温柔亲切女声，适合四年级儿童跟读
- **红线**：全部 TTS 重读，不用教材原版录音
- **审核点**：抽检——发音/语速/音色一致

### 步骤 ⑥ schedule 编排【脚本】

- **输入**：`04_content_package.json` + 两周制参数
- **输出**：`05_schedule.json`
- **两周制映射**（U01 实例）：
  | 时段 | segments |
  |---|---|
  | Week1 上课日1 | S0, S1 |
  | Week1 上课日2 | S2 |
  | Week1 上课日3 | S3 |
  | Week1 周末(PBL) | S5 |
  | Week2 上课日4 | S4 |
  | Week2 上课日5 | S6, S7 |
  | Week2 周末(小阅兵) | S8 + worksheet |
- **每天四环节**脚本填充：
  - ①开场复习：从记忆曲线调度旧词闪卡 ID + 前一天句型
  - ②新学：当天 segments 的补全层
  - ③巩固：当天 segments 的扩展层
  - ④收尾：小老师任务（从 segments.tutor 取）
- **输出**：
```json
"schedule": {
  "weeks": [
    {"week": 1, "school_days": [
       {"day": 1, "review": ["旧词ID"], "new": ["S0","S1"], "consolidate": ["S1扩展句ID"], "tutor": true},
       {"day": 2, "review": ["S1词卡"], "new": ["S2"], "consolidate": ["S2扩展句ID"]},
       {"day": 3, "review": ["S2"], "new": ["S3"], "consolidate": ["S3扩展句ID"]}
    ], "weekend": {"type": "pbl", "segment": "S5"}},
    {"week": 2, "school_days": [
       {"day": 4, "review": ["S3"], "new": ["S4"], "consolidate": ["S4扩展句ID"]},
       {"day": 5, "review": ["S4"], "new": ["S6","S7"], "consolidate": ["S6扩展句ID"]}
    ], "weekend": {"type": "review", "segments": ["S8"], "print": "worksheet"}}
  ]
}
```

### 步骤 ⑦ 组装【脚本】

- **输入**：`04_content_package.json` + images + audio + `05_schedule.json`
- **输出**：
  - **小程序包** `u01_pack.zip`：JSON（含 schedule）+ assets/images + assets/audio，按目录组织
  - **打印版** `u01_print.pdf`：五件套（句卡/PBL 模板/检验记录单/词汇卡/worksheet）
- **打印版生成**：从 `print_version` 字段渲染 HTML → 无头打印 PDF（weasyprint 或浏览器 print）
- **校验**：zip 内所有 audio/image 文件存在性检查

### 步骤 ⑧ QA【脚本】

- **输入**：`u01_pack.zip` + `u01_print.pdf`
- **输出**：`07_qa_report.md`
- **7 项校验**（自动）：
  1. **Schema 合法**：JSON 校验器
  2. **词库判定**：扫扩展/补全句，超前/生僻词标红
  3. **教材比对**：补全/扩展句 vs 教材 OCR，撞车标红
  4. **绑定检查**：图↔词↔音 ID 三方对齐
  5. **数量检查**：扩展 ≥3/知识点、句卡全量、检验 4 条齐
  6. **音频覆盖**：所有 audio 字段有对应文件
  7. **打印渲染**：五件套 HTML 渲染抽检
- **审核点**：人审 QA 报告，标红项打回对应步骤

## 3. 人工审核点汇总（4 处）

| 步骤 | 审核内容 | 耗时 |
|---|---|---|
| ①骨架 | 词表/句型/能力是否对 | 0.5 人天 |
| ②补全 | 语法修正抽查 | 0.5 人天 |
| ③扩展 | 超前词/生僻词 | 0.5 人天 |
| ⑧QA | 报告打回项 | 0.2 人天 |

> 每单元人审 ≈ 1.7 人天；其余全自动。

### 5.3 给 LoongMediaTools 组的要求（生图补纯文生图）

当前 `批量生图工具` 只支持图生图（sensenova `/images/edits` 必须带 input_image），但点读陪练的配图是**纯文生图**（词卡/场景图/题目图，从 prompt 直接生成，没有参考图）。要求：

1. **加纯文生图模式**：在 `批量生图工具` 加 `/images/generations`（文生图）Provider，或新增支持文生图的 Provider（不依赖 input_image）
2. **复用现有引擎**：多 Key 均衡 / 并发 / 断点续跑 / 重试机制不变，只加"无 input_image 的 job"分支
3. **统一画风参数**：我们的配图统一画风后缀（扁平卡通暖色调/圆角白底/无文字/原创 IP），prompt 由内容包 JSON 的 image_prompt 字段批量生成 jobs.json
4. **验证**：加一个文生图测试任务（词卡 farmer → png）确认链路

> 音频侧无需改动，直接复用。生图侧补完纯文生图后，步骤④即可直接 `batch_cli.py run` 批量生成全部配图。

**试跑发现并修复的问题**：
1. 功能词误判（what/your/a/is/my 词库没收→误判生僻）→ 加 STOPWORDS 白名单
2. 缩略词（uncle's/he's/what's 当整词查）→ normalize 拆 's
3. 词形变化（teaches/draws 三单）→ normalize 去 s/es 还原

**遗留精度问题**（量产前优化）：词形还原用简单规则，teaches/children/pictures 边缘情况可加完整词形词典；当前不影响主流程。
