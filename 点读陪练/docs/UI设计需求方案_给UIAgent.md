# 英语点读陪练 · UI 设计需求方案（给 UI Agent）

> 版本：**v1.2** ｜ 2026-09-22
> 用途：交给 UI Agent 做视觉与交互设计。
> **分工边界**：本文档负责"功能模块详尽介绍 + 界面所需元素清单 + 风格需求 + 入口关系"；**具体布局排版、用户交互细节由 UI Agent 设计**（下文元素清单仅作"有哪些元素"参考，非布局约束）。
> 内容依据：《产品形态与功能模块开发指引》《内容交接表》

## 一、产品定位与用户

| 项 | 说明 |
|---|---|
| 产品 | 英语点读陪练（PEP 教材同步拓展练习） |
| 用户 | **7-12 岁儿童（小学全阶段，当前先做四上）**+ 家长陪练 |
| 使用场景 | 每天 15-20 分钟，晚上家里 |
| 情绪 | 温和、鼓励、收集感（非考试/非竞技） |

> **年级范围说明**：当前 MVP 是四上（8-10 岁），但产品模式会复制到 1-6 年级，UI 设计要兼顾低龄（字体更大、交互更简）和高龄（信息密度可高）。

**设计红线**：
- ❌ 不做 PK/排行/分数对比
- ❌ 不使用教材原版 IP/角色
- ✅ 原创儿童 IP（Leo/Mia/Sam/Nana/Kiki/Bubu）
- ✅ 儿童数据最小化（本地存储）

## 二、视觉风格需求

### 2.1 整体风格
- **扁平卡通**：圆润线条，无复杂阴影/渐变
- **暖色调**：主色柔和（米黄/浅橙/天蓝/草绿），高饱和色只用于点亮/完成状态
- **圆角**：所有卡片/按钮圆角（12-16px）
- **字体**：圆润无衬线，儿童友好；正文 ≥16px（家长读）/ ≥18px（孩子读）

### 2.2 色彩规范（建议）
| 用途 | 色值建议 |
|---|---|
| 主色（按钮/标题） | 暖橙 #FF9F43 或 天蓝 #54A0FF |
| 背景 | 米白 #FFF8F0 |
| 完成/点亮 | 草绿 #6FCF97 |
| 待完成 | 浅灰 #E0E0E0 |
| 提醒/需补练 | 暖黄 #F2C94C |
| 文字主色 | 深灰 #333333 |

### 2.3 原创 IP
- 6 个朋友角色：Leo/Mia/Sam/Nana/Kiki/Bubu（U2 出现，全册同框）
- 配图风格统一：扁平卡通 + 暖色调 + 圆角白底 + 无文字
- **不复制教材角色**

### 2.4 情绪基调
- 收集感：打卡点亮、成长卡收集、词卡收集
- 鼓励感：完成后温暖反馈（星星/贴画，不做分数）
- 无压迫感：无倒计时催促、无失败红色

## 三、双版本差异

### 3.1 在线版（微信小程序）
**核心**：互动点读 / 闪卡 / 听写 / 记忆曲线 / 打卡 / 分享。

**认证流程**（⚠ 开发重点，本 App 不做登录页）：
1. 未认证 → 引导跳转到**认证中心**完成 OAuth
2. 认证中心完成后，**返回 token** 给本 App
3. 本 App 用 token 调后端接口拉数据（课程进度/词库/能力数据）
4. token 过期 → 重新跳认证中心
5. **认证界面完全在认证中心**，本 App 只做跳转与 token 接收后的进入

**页面清单（10 模块）**：启动/引导、首页、天天见、小阅兵、成长卡、闪卡背单词、听写、点唱台、生词本、单元进度、我的、打卡/分享。

### 3.2 离线版（小红书/打印）
**核心**：无屏补充——打印版五件套。

**形态**：
- A4 黑白友好打印（家长在家打印）
- 内容：句卡 / PBL 模板 / 检验记录单 / 单元地图 / 练习小单（背面答案）
- 风格：打印版走简洁黑白线稿，有填空线/答题区
- 不需要认证/后端——纯静态 PDF

## 四、功能模块详尽介绍（界面所需元素清单）

> 按用户核心路径排序：每日核心 → 周末检验 → 自助餐（并行）→ 数据/进度 → 我的。
> 每个模块说清"做什么 + 界面需要哪些元素"。**具体布局、交互细节由 UI Agent 设计。**

### A. 每日核心（两周一循环）

#### 模块 1：天天见（每日小课包 · 核心）
**做什么**：每天 15-20 分钟的核心陪练入口。类似点读的播放壳，但内容是我们的三层句库。每课固定四环节：开场复习 → 新学 → 巩固 → 收尾。
**节奏**：Week1 上课日 1-3 + Week2 上课日 4-5 = 5 天/单元。

**界面所需元素**：
- 环节指示（当前在四环节的哪一步）
- 句卡：原创配图 + 英文句（大字）+ 中文释义（小字）
- 点读按钮：点图发音、点词发音
- 跟读录音按钮（录本地，家长回听，不评分）
- 句卡切换指示（共几句、第几句）
- 完成后进入下一环节的引导

**状态**：未开始 / 进行中 / 已完成（点亮）。

### B. 周末检验（Week2）

#### 模块 2：小阅兵（周末检验站测）
**做什么**：Week2 周末，能力检验站测 + 打印小单。4 条能力逐条检验，孩子自评三档。
**时机**：Week2 周末才亮（平时灰态）。

**界面所需元素**：
- 4 条能力列表（每条一句中文描述，如"能介绍我的朋友"）
- 检验任务展示（给新人物/新场景图，孩子自主说）
- 三档自评按钮：我能做到 / 基本可以 / 需要帮助
- 未过能力 → 补练提示（映射回对应单元对应段）
- 全过 → 点亮 + 解锁成长卡
- 打印小单入口（渲染 HTML→PDF）

**状态**：未测 / 进行中 / 已完成 / 有未过项。

#### 模块 3：成长卡（周末结算）
**做什么**：Week2 周末小阅兵做完，出一份本周学习结果——收集感卡片，非分数评判。

**界面所需元素**：
- 本周点亮情况（Day1-5 完成状态）
- 4 条能力达成（✅/🔁）
- 新学词数 / 复习词数
- 下周建议（薄弱点，一句）
- 家长签名位
- 分享成长卡按钮

**情绪**：收集感——像收集一张卡片，不是考试成绩单。

### C. 自助餐（并行可选，不排进度）

#### 模块 4：闪卡背单词
**做什么**：全册已学单词的闪卡复习，**记忆曲线调度**（按遗忘曲线出现旧词）。
**模式 = 闪卡**：正面英文词 + 配图，翻面看中文/发音，用户自评"认识/要再看"，调度下次出现。

**界面所需元素**：
- 闪卡正面：英文词（大字）+ 配图
- 闪卡翻面：中文释义 + 发音按钮
- 自评按钮：认识 / 要再看（决定下次出现时机）
- 今日新词/复习词计数
- 生词本快捷入口
- 按单元/词类筛选

**状态**：今日待学 / 学习中 / 今日完成。

#### 模块 5：听写
**做什么**：听发音写单词，家长/孩子配合。从单元词表抽词听写。

**界面所需元素**：
- 发音按钮（点即读词，可重复）
- 输入框（孩子写/拼）
- 自动判对错（拼写对/错）
- 错词自动收进生词本
- 完成后正确率统计
- 可设置每次听写错词数/范围

**状态**：待听写 / 听写错 / 听对。

> **闪卡 vs 听写**：闪卡 = 认词（看词想意思，识别）；听写 = 写词（听音拼出，产出）。互补。

#### 模块 6：点唱台（点唱机）
**做什么**：Appendix 1 单元歌曲跟唱。歌词 TTS 重唱（不碰教材原版旋律），亲子合唱打卡。

**界面所需元素**：
- 歌曲列表（6 首单元歌）
- 歌词逐句热区（点句即唱）
- 录音按钮（自己跟唱录一段）
- 播放/暂停
- 已唱/未唱标记

**状态**：未唱 / 跟唱中 / 已录。

### D. 数据与进度

#### 模块 7：打卡与分享
**做什么**：每日完成天天见后打卡点亮，生成分享图卡。

**界面所需元素**：
- 今日完成点亮动画（温和，星星/贴画）
- 连续天数统计
- 进度统计（本周 Day1-5 完成度）
- 分享图卡生成（孩子/家长可分享，不带用户 ID、不做云端对比）

**状态**：未打卡 / 已打卡。

#### 模块 8：生词本（错词复习）
**做什么**：闪卡"要再看"+ 听写答错的词自动汇集，集中再练。

**入口**：闪卡页顶部快捷入口 ｜ 我的 → 生词本。

**界面所需元素**：
- 错词列表（词/中文/出处单元/错几次）
- 一键再练（对全部/选中错词，走闪卡或听写模式）
- 掌握后移除（点"已会"移出）
- 按单元筛选

**与闪卡/听写关系**：闪卡和听写练出的错词，自动进这里，集中消化。

#### 模块 9：单元进度（课程地图）
**做什么**：看当前在哪个册、哪个单元，各单元学到哪一步。

**入口**：我的 → 单元进度；首页顶部册次/单元切换。

**界面所需元素**：
- 当前册次（四上）下的单元列表（U1-U6 + Revision）
- 每单元完成状态（未开始/进行中/已完成）
- 当前单元的 Week1/Week2 进度（天天见 Day1-5 + 周末小阅兵）
- 点进去直达对应单元的天天见/小阅兵

**为什么需要**：家长随时知道"孩子学到哪了"，不会断档；也是学校进度同步的参照。

### E. 个人中心

#### 模块 10：我的
**做什么**：个人数据与设置入口。

**界面所需元素**：
- 当前年级/册次切换
- 学习数据概览（累计天数/总词数/总句数）
- 生词本入口
- 单元进度入口
- 设置（音量/语速/通知）
- 关于/反馈

**数据合规**：儿童数据最小化，只存必要学习状态。

## 五、模块入口关系（导航逻辑）

> 底部导航具体几个 tab、怎么排布由 UI Agent 定；这里说清"从哪能到哪"。

- **首页**：今日天天见入口（主）+ 本周进度 + 周末小阅兵入口（Week2 亮）+ 册次/单元切换
- **自助餐入口**：闪卡 / 听写 / 点唱台——从首页或"我的"进，并行不排进度
- **生词本**：闪卡页顶部快捷入口 + 我的
- **单元进度**：我的 + 首页顶部切换
- **小阅兵/成长卡**：首页 Week2 周末卡片进
- **打卡分享**：完成天天见后自动弹出 + 首页进度区

## 六、元素清单速查（布局参考，非约束）

> ⚠ 以下仅列出"页面里有哪些元素"，**具体布局/排版/交互由 UI Agent 设计**。

**首页**：本周进度（Day1-5 点亮）｜ 今日陪练卡片（Day N + 主题）｜ 开始按钮 ｜ 周末小阅兵入口（Week2 才亮）｜ 册次/单元切换

**天天见**：环节指示 ｜ 配图 ｜ 英文句（大字）｜ 中文释义（小字）｜ 点读按钮 ｜ 跟读录音 ｜ 句卡切换指示

**闪卡**：正面（词+图）｜ 翻面（中文+发音）｜ 自评（认识/要再看）｜ 今日计数 ｜ 生词本入口

**听写**：发音按钮 ｜ 输入框 ｜ 对错判定 ｜ 错词收集 ｜ 正确率

**点唱台**：歌曲列表 ｜ 歌词逐句热区 ｜ 录音 ｜ 播放/暂停

**小阅兵**：4 能力列表 ｜ 检验任务图 ｜ 三档自评 ｜ 补练提示 ｜ 打印入口

**成长卡**：Day1-5 点亮 ｜ 能力达成 ｜ 词数 ｜ 下周建议 ｜ 家长签名 ｜ 分享按钮

**生词本**：错词列表 ｜ 一键再练 ｜ 已会移除 ｜ 按单元筛选

**单元进度**：单元列表 ｜ 每单元完成状态 ｜ Week1/Week2 进度 ｜ 直达入口

**我的**：册次切换 ｜ 数据概览 ｜ 生词本/单元进度入口 ｜ 设置 ｜ 关于

## 七、组件规范建议（供 UI Agent 参考）

| 组件 | 建议规范 |
|---|---|
| 句卡 | 圆角 16px，白底，图在上句在下，点读按钮右下 |
| 闪卡 | 圆角 16px，正面图+词，翻面动效 |
| 按钮 | 圆角 12px，暖橙主色，按压反馈 |
| 点亮态 | 草绿 + 星星/贴画动画（温和） |
| 进度环/点 | 5 个（Day1-5），点亮/未点亮 |
| 成长卡 | 卡片样式，可分享为图片 |
| 音频播放 | 小喇叭图标，点即发音 |
