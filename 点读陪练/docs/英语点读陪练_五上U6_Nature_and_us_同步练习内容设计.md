## 1. 三层句库

**词用范围**：
- 自然景观：forest, river, lake, mountain, waterfall
- 恶劣天气：fog, heavy rain, flood, strong wind, fire, heavy snow
- 句型：There is a forest in the park. / There are some waterfalls. / Are there any mountains? Yes, there are.
- 自然拼读：al/au/aw（all, saw, draw, tall, wall, autumn, Paul）

---

## 2. 能力目标
| 能力 | 检验任务 |
|---|---|
| 说公园里有什么 | There is a big forest. / There are some beautiful waterfalls. |
| 问有什么吗 | Are there any mountains? Yes, there are. / Is there a lake? Yes, there is. |
| 说恶劣天气 | There is often fog. / Sometimes there are floods. / Be careful of fires. |
