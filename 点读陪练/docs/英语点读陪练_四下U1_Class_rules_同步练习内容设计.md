## 5. 分段要点

### 段 1 · 班规
- **原文**：Keep the classroom clean. / Don't eat in class. / Don't be late. / Put up your hand to speak. / Turn off the lights after school.
- **补全**：规则×祈使句 ≈12 句
- **扩展**：Don't run in the classroom. / Please be nice. / Don't talk in class.

### 段 2 · 班规小剧场
- **原文**：Jack, you can't take toys to school. / Don't be late for class!
- **补全**：场景（迟到/吃东西/说话/跑）× 对话 ≈10 句
- **玩法**：对错判断（√/×）+ 说正确规则

### 段 3 · 教室物品 + 值日
- **原文**：window / fan / teacher's desk / door / chairs / floor / blackboard / desks
- **补全**：物品×值日（I can clean/sweep/put back）≈10 句
- **玩法**：点图发音 + 听指令做动作

### 段 4 · 为什么要守规则
- **原文**：We follow rules to help us learn. / We don't want a messy room. / Our classroom is for everyone.
- **补全**：理由×We... ≈8 句
- **扩展**：Rules keep us safe. / Rules make learning fun. / Rules help us be good friends.
- **方法卡**："守规则的理由 = help us learn + keep us safe + make learning fun"

### 段 5 · 班规标牌（PBL · 5 张）
- **PBL 补全**：5 条班规各做一张标牌（图 + 文字）

### 段 6 · ar 语音 + 能力检验
- **字母词**：farmer/card/hard/farm/park/car/arm
- **玩法**：指读 ar 词 → 圈首音
- **检验**：Self-check 4 条逐条过关
