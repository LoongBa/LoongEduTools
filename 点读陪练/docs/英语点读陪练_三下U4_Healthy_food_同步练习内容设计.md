## 5. 分段要点

### 段 1 · 点餐
- **原文**：I'd like some bread and eggs, please. / Would you like some rice and meat? / Yes, please.
- **补全**：食物（bread/egg/milk/juice/noodles/cake/rice/soup/fruit/meat/vegetables）× 点餐 ≈15 句
- **扩展**：I'd like some juice and noodles. / I'd like some fruit and vegetables.

### 段 2 · 食物饮料词图配对
- **原文**：noodles / egg / cake / juice / bread / milk / rice / soup / fruit / meat / vegetables
- **补全**：食物×分类（早餐/午餐/晚餐）≈8 句
- **玩法**：点图发音 + 分类配对

### 段 3 · 接受还是拒绝
- **原文**：Would you like some...? / Yes, please. / No, thank you.
- **补全**：食物×问答 ≈10 句
- **扩展**：Would you like some cake? / No, thank you. I'd like some fruit.

### 段 4 · 健康小顾问
- **原文**：Vegetables are healthy. / Don't eat too much candy.
- **补全**：食物×评价 ≈8 句
- **扩展**：Milk is good. / Noodles are good. / Candy is yummy but don't eat too much.
- **方法卡**："健康饮食 = 米饭面条 + 肉蛋奶 + 水果蔬菜 + 糖果少吃"

### 段 5 · 健康餐盘计划（PBL · 3 餐）
- **PBL 补全**：早餐 + 午餐 + 晚餐，每餐 3-4 种食物

### 段 6 · o-e 语音 + 能力检验
- **字母词**：Joe/home/note/bone/Jones/joke/cone/less
- **玩法**：指读 o-e 词 → 圈首音 → 对比 not/note, hot/home
- **检验**：Self-check 4 条逐条过关
