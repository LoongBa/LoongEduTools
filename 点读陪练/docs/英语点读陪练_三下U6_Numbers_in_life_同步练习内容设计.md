## 5. 分段要点

### 段 1 · 数字 11-15
- **原文**：eleven / twelve / thirteen / fourteen / fifteen
- **补全**：数字×物品（books/pencils/apples/eggs）≈10 句
- **扩展**：Five and six makes eleven. / Six and seven makes thirteen.

### 段 2 · 数东西小问答
- **原文**：How many books do we have? / We have fifteen books. / How many boxes do we need? / We need three boxes.
- **补全**：物品×问答 ≈15 句
- **扩展**：How many apples? / We have twenty. / How many pencils? / Twelve.

### 段 3 · 数字 16-20 + 问价格
- **原文**：sixteen / seventeen / eighteen / nineteen / twenty / How much is this bag? / It's twenty yuan.
- **补全**：物品×价格问答 ≈12 句
- **扩展**：How much is this book? / Six yuan. / How much is this toy car? / It's twelve yuan.

### 段 4 · 数字在生活中
- **原文**：A clock has twelve numbers. / A year has twelve months. / A football team has eleven players.
- **补全**：场景×数字 ≈10 句
- **扩展**：A mobile phone has eleven numbers. / A box has... apples.
- **方法卡**："数字在生活中 = 时钟 + 月份 + 球队 + 电话号码"

### 段 5 · 三明治小摊贩（PBL · 3 步）
- **PBL 补全**：做三明治 + 定价格 + 卖三明治

### 段 6 · c/g/l/y 语音 + 能力检验
- **字母词**：cake/face, cool/long, girl/orange, my/yellow
- **玩法**：指读 c/g/l/y 词 → 圈首音
- **检验**：Self-check 4 条逐条过关
