## 1. 三层句库

**词用范围**：
- 数字 1-10：one/two/three/four/five/six/seven/eight/nine/ten
- 字母 A-Z（整体认，不细分发音）
- 物品：pencil/apple/banana/cat/dog 等（复现三上词）
- 句型：I see number... / I see... letters. / One, two, three...

---

## 2. 能力目标

| 能力目标 | 训练段 | 检验任务 |
|---|---|---|
| ① 数 1-10 | 段 2 | 数物对应，说 one-ten |
| ② 认字母 A-Z | 段 3 | 指图说 I see letter L. |
| ③ 用数字描述数量 | 段 4 | 说 I see eight cats. / Ten pencils. |

---

## 3. 七段路径
0 数字热身 / 1 数字词大本营 / 2 数字问答 / 3 字母认一认 / 4 数字画 PBL / 5 字母总复习 / 6 检验站。

## 4. 要点
- **数字**：one-ten，数物对应
- **字母**：整体认 A-Z（三上再细分发音）
- **PBL**：画数字画（用数字画动物）
- **玩法**：听音数数 / 找字母 / 数字画画
