## 二、各功能模块开发说明

### 1. 天天见（播放壳 · P0）
**定位**：每天 15-20 分钟的核心陪练入口，类似点读的播放壳，但内容是我们的三层句库。

**双载体**：
- **在线/微信版（小程序）**：互动点读/闪卡/听写/记忆曲线——在线主体验
- **离线版（打印）**：A4 黑白打印五件套（句卡/PBL 模板/检验单/单元地图/练习小单），纯静态 PDF，不需认证

**每节课四环节**（对应 schedule_build 的天天见）：
1. 开场复习（旧词闪卡，记忆曲线调度）
2. 新学（当段原文+补全句点读）
3. 巩固（扩展层+互动题）
4. 收尾（小测+打卡）

**开发要点**：
- 句卡热区点读（图/词/音绑定，assets 里已生成）
- 跟读录音（本地，家长回听，不评分）
- 记忆曲线调度（背单词旧词按遗忘曲线出现）

### 2. 点唱台（点唱机 · P1）
**定位**：Appendix 1 Songs 的跟唱模块。

**功能**：
- 歌词逐句热区跟唱（TTS 重唱，不碰教材原版旋律）
- 亲子合唱打卡
- 碎片随时唱（自助餐，不排进度）

### 3. 小阅兵（周末检验 · P0）
**定位**：Week2 周末，能力检验站测 + 打印小单练。

**功能**：
- **检验站测**：4 条能力逐条检验（先测后评，三档自评：我能做到/基本可以/需要帮助）
- **未过补练**：自动映射回对应单元对应段
- **打印小单**：从 print_version 字段渲染 HTML→PDF（纯填空卷，背面答案）

### 4. 打卡与分享（数据统计 · P1）
**定位**：每日完成后打卡 + 分享。

**功能**：
- 每日打卡（完成天天见点亮）
- 连续天数/进度统计（本地存储，儿童数据最小化）
- 分享卡片（生成精美图卡，家长可分享——不做 PK/排行）

### 5. 周末结算（小阅兵产出 · P1）——**成长卡**
**定位**：Week2 周末小阅兵做完，出一份本周学习结果——**「成长卡」**（收集感，非分数评判）。

**为什么叫成长卡**：
- 内容本质是"本周练了什么 + 能力达成 + 下周建议"，**不是考试分数**
- 和产品调性一致：打卡/点亮/解锁/词卡/句卡——都是"卡"，孩子拿到是收集感，不被评判
- 温和、去分数化，家长也懂"成长=进步"

**内容**：
- 本周练了哪几天（Day1-5 完成度，点亮状态）
- 4 条能力检验结果（✅/🔁）
- 新学词数/复习词数
- 下周建议（薄弱点）
- 家长签名位

## 三、数据与合规红线

- **儿童数据最小化**：只存本地词状态/打卡天数，不上传云端个人数据
- **无 PK/排行**：不做班级排名/好友对比
- **标准答案原则**：检验只有对错，不评优劣
- **分享卡片**：只生成图片，不带用户 ID/进度云端对比

## 四、开发顺序建议

| 阶段 | 内容 |
|---|---|
| MVP | 天天见播放壳（在线版）+ 小阅兵检验站 + 打印小单 |
| V1 | 打卡分享 + 成长卡 + 闪卡 + 听写 + 点唱台 |
| V2 | 生词本 + 单元进度 + 我的 + 离线打印版完善 |
| V3 | 附录工具型（词卡浏览器/全册词典） |
