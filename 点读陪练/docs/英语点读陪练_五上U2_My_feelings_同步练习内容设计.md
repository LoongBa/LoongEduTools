## 1. 三层句库

**词用范围**：
- 情绪（6）：excited, worried, angry, sad, happy, afraid
- 建议句型：You can talk to... / You need to listen to... / You can ask... for help.
- 句型：You look sad. What's the matter? / I'm worried. / You should...
- 自然拼读：ee/ea（see, sheep, eat, meet, tea, team, bee, free）

---

## 2. 能力目标
| 能力 | 检验任务 |
|---|---|
| 问别人怎么了 | You look sad. What's the matter? |
| 说我的情绪 | I'm worried. / I'm excited. |
| 给建议 | You can talk to your parents. / You should ask your teacher for help. |

## 3. 七段路径
0 情绪热身 / 1 情绪词大本营 / 2 You look... / What's the matter? / 3 You should...建议 / 4 情绪书 PBL / 5 ee/ea 语音 / 6 检验站。

## 4. 要点
- **句型**：You look + 情绪. What's the matter? / I'm + 情绪. / You can/should + 建议
- **PBL**：情绪书（4 格：什么让我生气/我看起来怎样/我想做什么/我能做什么）
- **玩法**：问题-建议配对 / 角色扮演
