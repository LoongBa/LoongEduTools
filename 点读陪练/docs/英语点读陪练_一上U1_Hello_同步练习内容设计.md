## 1. 三层句库

**词用范围**：
- 问候（3）：hello, hi, bye
- 句型：Hello! I'm Sarah. / Hi! I'm Binbin. / Bye! / Hello, Sarah!
- 名字（复现）：Sarah/Binbin/John/Chen Jie/Li Dong

---

## 2. 能力目标
| 能力 | 检验任务 |
|---|---|
| 打招呼 | Hello! / Hi! |
| 自我介绍 | Hello! I'm Sarah. |
| 道别 | Bye! / Goodbye! |

## 3. 七段路径（低年级最简）
0 打招呼热身 / 1 问候词大本营 / 2 Hello/Hi 练习 / 3 I'm...自我介绍 / 4 名字树 PBL / 5 复习 / 6 检验站。

## 4. 要点
- **句型**：Hello! I'm + 名字 / Hi! I'm + 名字 / Bye!
- **PBL**：名字树（画自己+写名字，贴树上）
- **玩法**：互相打招呼 / 角色扮演（孙悟空/花木兰）
