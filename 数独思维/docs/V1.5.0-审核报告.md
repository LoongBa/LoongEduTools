## 三、变更摘要

1. **findHiddenPairPattern**（sudoku.ts，纯模式识别）：遍历 row→col→box 固定序（I6-3 稳定性），单元空格 ≥3 时按数字对 {x,y} 检测「候选位交集=并集=同 2 格」→ 返回 `{cells, values, unitKind, unitIdx}`。**显性数对排除**：两格候选均恰 {x,y}（`c1n===2 && c2n===2`）才跳过——允许「一格恰2另一格≥3」非对称隐性数对（I6-1）。**前置条件**（I5）JSDoc 标注「调用方应确保 findLogicStep 返回 null」，纯模式不落子，绕开 V1.4.0 裁剪根因。
2. **useHint 退化**（Practice.tsx）：`findLogicStep` null → `findHiddenPairPattern` 命中 → `setPattern({cells, tone:"hidden-pair"})` + 文案（含 unitLabel 行列定位 + N3 代词「这两个格子把 x、y 悄悄锁住了」）+ 3200ms 清空。**I2**：走新 pattern prop（`<Board pattern={pattern}>`），`hintCells`/peerGuide 保留给常规提示（排除源格 vs 藏身格语义区分）。
3. **analyzeTechniques**（sudoku.ts）：卡住时二次 findLogicStep 确认真卡住 → `findHiddenPairPattern` 命中即 `set.add("隐性数对")` 自然 break（**I1**：不猜测、不推进，「诚实子集」语义保持）。
4. **B1 content.ts**：LESSON_MAP + adv 组补 `隐性数对` → 含隐性数对错题正确归「进阶观察」组并关联 hiddenPair 教学关。
5. **Board pattern 高亮**（I3/I4）：新 `pattern` prop；`isPattern = patternSet.has(i) && !val`（仅空格）；优先级 peer 后 errMark 前；fallback 含 `!isPattern`；`bg-hl-pattern/30 + ring-hl-pattern/60`。
6. **styles.css**（I4）：8 组主题块 `--hl-pattern`（柔紫 268-300 hue，随主题色相微调）+ `@theme` 注册。
7. **版本规则修订**（AGENTS.md，2026-09-28 用户指令「默认子版本，你可以判断是否升子版本，主版本需要审」）：patch 自主 / **minor 由 Sisyphus 自主判断**（此前「须经用户同意」作废）/ 主版本（V2.0.0）须审核。V1.5.0 定性为 minor（新提示形态 + 跨文件接口）。

## 五、审核发现（Sisyphus 逐行核对）

- **A1（算法正确性）**：`px[0]===py[0] && px[1]===py[1]` 等价于「交集=并集=同 2 格」（两数字候选位全集相同恰落 2 格）；`px.length!==2` 前置过滤在 I5 前置条件下覆盖全部非 pair 情形。显性排除用「两格候选数均=2」而非「候选集恰{a,b}」——数学等价（候选 ≥{x,y} 且长度 2 ⟹ 恰 {x,y}），且天然允许非对称（I6-1）。engine 断言实证（含手工盘 cells/values 精确匹配）。
- **A2（画像语义边界）**：`analyzeTechniques` 二次 `findLogicStep` 为「真卡住」判定（非「已解完」），避免对解完盘误加隐性数对——已解完盘 `findHiddenPairPattern` 对全填盘必然返回 null（`cells.length<3` 兜底），双保险。`TECHNIQUE_MAX_ROUNDS`/`techniqueCache` 上限未破坏。
- **A3（性能）**：`findHiddenPairPattern` 每格 `candidatesFor` 独立计算（9×9 最坏约 27 单元 × C(9,2) 对 × ~2 格候选 ≈ 轻量，同步 ms 级）；不引入跨调用缓存（与 findLogicStep candCache 隔离，避免状态耦合）。useHint 点击触发无卡顿风险。
- **A4（无用代码）**：`tone` 字段当前仅 "hidden-pair" 单一值——为未来扩展预留（pattern 视觉 family），无未使用告警。
- **A5（样式一致性）**：`--hl-pattern` 每主题 hue 与现有 badge 色相协调（paper 272 / mint 268 / dusk 300 紫系；sky 280），深浅版亮度阶梯对齐 hl-peer/hl-same 体系；`@theme` 已注册 → `bg-hl-pattern`/`ring-hl-pattern` utility 生效（冒烟 0 JS 错误佐证 Tailwind 编译）。

**阻断项：0｜改进项：0｜观察记录：5（A1-A5，均通过/可接受）**
