## 1. 背景与现状问题

| 编号 | 优先级 | 问题 | 代码位置 |
|---|---|---|---|
| P0 | 中 | **同类专项连做进行时无组内进度反馈**：孩子做题中不知道这是组内第几题、还有几道。V1.4.1 已把进度放在**结算层**（已完成 x/n + Bar），但**练习中顶栏无提示**——进入连做后直到做完一题才看到进度，连做体验仍有盲区 | `src/components/Practice.tsx` 顶栏（L491-503） |
| P1 | 低 | 进度数据已在 Practice 内但未用于练习中展示：`StartParams.group?: {total, idx}`（V1.4.1 传入的展示快照）目前仅在结算 Overlay 使用（L641-657） | `Practice.tsx` `params.group` |

> 背景：V1.4.1 oracle I-1 明确「结算层够用但留『练习中盲区』——本版结算层进度条 + 不触顶栏（顶层改动大，V1.4.2 再考虑）」。V1.4.1 已落地传参 `params.group`，**本版无需改 index.tsx 连做骨架**，仅在 Practice 顶栏消费既有快照——改动面远小于 V1.4.1 预期。

## 2. 目标与原则

- **目标**：连做进行时，练习页顶栏显示组内进度「第 x/n 题」，与结算层「已完成 x/n · 还剩 m 道」呼应，闭环连做体验。非主要功能 → **V1.4.2（patch）**。
- **原则**：
  - **最小化修改**：不动 index.tsx（groupSession/startGroupItem/handlePracticeFinish 零改动），仅 Practice 顶栏渲染 + copy.ts 文案常量。
  - **语境区分文案**（延续 I-3）：结算层「已完成 x/n · 还剩 m 道」（已完成语境）；**练习中「第 x/n 题」**（正在做语境——I-3 原判「避免正在做第几题误读」正说明「第 x/n 题」语义属于练习中）。
  - **延续 I-5b 规则**：`total ≤ 1` 不显示（单题无进度意义）。
  - **单向派生不变**：params.group 仍是展示快照，不反向写回；练习中显示不触碰 groupSession。

## 3. 变更设计

### 3.1 顶栏进度徽章（P0 / P1）

- `Practice.tsx` 顶栏（L491-503）右侧、计时徽章左侧插入：

  ```tsx
  {/* V1.4.2：同类专项连做练习中进度（第 x/n 题；total≤1 不显示，与结算层规则一致） */}
  {params.group && params.group.total > 1 ? (
    <span className="tnum shrink-0 rounded-full bg-primary/10 px-2.5 py-1 text-[12px] font-bold text-primary">
      {GROUP_IN_PROGRESS(params.group.idx, params.group.total)}
    </span>
  ) : null}
  ```

  - 布局：顶栏 `flex items-center gap-2`，标题区 `min-w-0 flex-1`（truncate 自动压缩），进度徽章与计时均为 `shrink-0`——窄屏不换行、标题可压缩，**无 truncate 截断风险**（对比副行追加文字方案）。
  - 样式：`bg-primary/10` + `text-primary` 与计时徽章（`bg-secondary`）对称呼应，`tnum` 数字等宽，`rounded-full` pill 形态与全站徽章语系一致。
  - **守卫**：`params.group && params.group.total > 1`——普通练习/free/daily/map/import/单题 replay（不带 group）零影响；<3 题全练 total=1 不显示（I-5b 延续）。
  - 不新增 aria/role：静态进度文本本身可读（读屏读出「第 3/5 题」），不加多余地标。

### 3.2 文案常量（copy.ts）

- `src/lib/copy.ts` 追加：

  ```ts
  /** V1.4.2：同类专项连做练习中进度文案（正在做语境；与结算层「已完成 x/n · 还剩 m 道」区分）。idx 为 0-based 组内序号，函数内自管 +1 */
  export const GROUP_IN_PROGRESS = (idx: number, total: number) => `第 ${idx + 1}/${total} 题`;
  ```

  - 参数语义（I-1 方案 A）：`idx` 为 **0-based 组内序号**（与 `params.group.idx` 一致），函数内 `+1` 转展示值——调用点零转换，杜绝漏 +1 渲染「第 0/3 题」的脚枪；`total` 组总题数。
  - 命名：与 V1.4.1 `GROUP_PROGRESS`（结算层）/`GROUP_PROGRESS_DONE` 并列为进度文案族，`IN_PROGRESS` 标识练习中态。
