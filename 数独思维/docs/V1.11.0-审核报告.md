## 三、变更摘要

- **哲学护栏落地**（源自《教育工具产品指导原则》+ 用户拍板）：
  - 双模式可切换，**默认纯现状**（自由试错）——个体差异由家长选策略，不改存量体验；
  - **无惩罚**：3 次用尽 → 三出口询问（需要提示 / 再自己想想 / 带我复盘）——「机会」是教学介入触发器，非生命值；宽容态后不再计数、不再弹、反馈回 free 行为；
  - **暗计数不剧透**：非冲突错填仅机会-1 + 「再想想」温和提示，不显示正解；复盘（StepReview）只给推理链；
  - **去游戏化**：措辞走「大胆试错」「引导」，机会指示低调静态 text-muted 小字（无红色心跳 UI）。
- **关键实现**：
  - 机会 = `3 - errors` 派生（零状态，断点恢复自然续接；旧快照 errors≥3 直接宽容态）；
  - strict3 仅作用于首次解题（free/daily/map/import），replay 重练与教学关不适用；
  - 冲突与非冲突错填共用 `maybeStrictAsk`（errors 2→3 时触发一次三出口 + 置宽容态 guard）；
  - Settings「练习容错模式」选项文案明示「不改变星星与成绩记录」（保住记录口径一致性）。
