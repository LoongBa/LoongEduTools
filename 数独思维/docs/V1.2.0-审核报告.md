## 3. 变更摘要（与方案 v0.2 对照）

- **backup.ts**：
  - `buildBackup`：data 深拷贝 + stats 摘要（history/mistakes/favorites/achievements/checkinDays 实际长度）
  - `validateBackup` 强校验（B1）：format/v/data.version + 顶层类型 + BookItem（mistakes/favorites）元素含 `board/solution: Array` + history 元素含 `date: string`/`ms: number` + cur 含 `puzzle/solution/board: Array`/`notes: object` + `__proto__`/`constructor` 自有键拒绝（I5）+ 未识别字段不拒绝（I5）
  - `downloadBackup`：Blob UTF-8 + a[download] 纯客户端，零网络
  - `importBackup`：try/catch `setItem` 配额异常（B2）→ 返回 reason 不重载，旧数据安全保留
- **Settings.tsx**：
  - 数据卡新增「📤 备份到文件」「📥 从文件恢复」按钮 + 隐藏 file input（`accept=".json,application/json"`）
  - 恢复流程：JSON.parse → validateBackup → Overlay 确认（stats 摘要 + 「覆盖当前全部进度，包括当前正在做的这道题」）→ importBackup → sessionStorage 旗标 → reload
  - 恢复反馈（I1）：reload 后 Settings 挂载读 `redtools.shudu.restored` 旗标 → Toast 摘要 → 清旗标
  - FileReader.readAsText（I2，自动处理 BOM）；busy 防双击（I2）
- **边界**：scheme/mode 不纳入备份（与 Settings 现有文案「外观选择只影响这台设备」承诺一致，N1）

## 4. 审核发现与处置

| # | 级别 | 发现 | 处置 |
|---|---|---|---|
| A1 | 低 | `RESTORED_FLAG` 初版写作 `"shudu.restored"`，未遵循 `redtools.shudu.*` 既有键前缀惯例 | 改为 `redtools.shudu.restored`（key 命名一致性） |
| A2 | 中 | 初版 `onBackup` 将 `BACKUP_IOS_HINT` 放在 catch 分支——但 `downloadBackup` 内 `a.click()` 在 iOS Safari 静默忽略 download 属性**不抛异常**，catch 永不触发，iOS 兜底提示永远不显示（oracle I4 意见落空） | 改为成功路径合并提示：`BACKUP_DONE + BACKUP_IOS_HINT` 始终显示 |
| A3 | 观察 | `React.ChangeEvent` 无显式 `import React`——已验证项目现有 `use-mobile.tsx`/`ui/tooltip.tsx`/`ui/drawer.tsx` 同用 `React.` 前缀（tsconfig 全局可用），typecheck 0 错误 | 无改动，与项目惯例一致 |
| A4 | 观察 | backup.mjs 的 `__proto__` 用例初版构造错误（对象字面量走原型 setter 不产生自有键；后误放嵌套 achievements 层；最后定位攻击面为 data 顶层合并处） | 用 `JSON.parse('{"__proto__":...,"version":1}')` 构造自有键攻击载荷，且带 version 以通过前置校验到达 hasProtoKey；测试已通过 |

oracle 意见落实复核：B1（元素形状校验 ✓）/ B2（配额异常 ✓）/ I1（sessionStorage 反馈 ✓）/ I2（cur 覆盖明示 + readAsText + 防双击 ✓）/ I3（测试 6 类补充 ✓）/ I4（iOS 兜底经 A2 修正为始终提示 + accept 过滤 ✓）/ I5（未识别字段不拒绝 + __proto__ 拒绝 ✓，hasProtoKey 用 hasOwnProperty 避免误拒普通对象）✅ 全落实。

## 7. 发行说明（供发布引用）

- **新功能**：设置页「💾 本机数据」新增「📤 备份到文件 / 📥 从文件恢复」——导出全部学习进度为单个 JSON 文件，换设备/换浏览器可完整迁移（练习史/错题/收藏/成就/打卡/地图/最佳成绩）。
- **安全**：备份文件双重校验（格式版本 + 数据结构/元素形状），损坏、伪造、版本不兼容文件安全拒绝并提示原因；恢复前两级确认（含「覆盖当前进度」警示）。
- **体验**：恢复成功后自动重载并提示恢复摘要；备份文件含记录数概览便于人工辨识。
- **测试**：新增备份专项 15 断言 + 冒烟扩至 32 项，0 JS 错误。
