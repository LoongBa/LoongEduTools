# 数独思维（React 版）V1.4.1 开发方案（v0.2，已按 oracle 评审修订）

> 项目：`数独思维/src`（Vite + React 19 + TS，单路由视图状态机）
> 版本规则：非主要功能仅升子版本号（2026-09-27 修订）；主要功能 → minor 须经同意
> 本方案遵循 `数独思维/src/AGENTS.md` 迭代流程：开发方案 → oracle 评审 → 实施 → 验证 → 亲自审核代码 → 审核报告 → 提交发布
>
> **评审记录（v0.1 → v0.2）**：oracle 审核 `B=0`，「5 项 I/N 建议已采纳」。已修订：
> - I-1（进度位置）：结算层够用但留「练习中盲区」——本版结算层进度条 + 不触顶栏（顶层改动大，V1.4.2 再考虑）；「下一道」按钮不冗余加剩余数（进度条已含）
> - I-3（文案歧义）：**「第 x/n 题」→「已完成 x/n · 还剩 m 道」**（结算语境避免「正在做第几题」误读）
> - I-5a（末题边界）：`idx === total-1`（且 total>1）时文案显示**「已完成 n/n · 本组已完成」**替代「还剩 0 道」
> - I-5b（total≤1）：**total≤1 不渲染进度条**（<3 全练可能 total=1，单题无意义）
> - I-4（失步防范）：**单向派生 groupSession→params.group**（groupSession.idx 仅用于 startGroupItem 取 list[next]；params.group.idx 仅用于展示快照），handlePracticeFinish 用当次渲染 groupSession.idx 推进（无批量 finish 场景，闭包安全），绝不反向写回
> - I-5c（签名变更）：startGroupItem (item)→(item, idx, total)，实施时 grep 全部调用点确认无遗漏
> - I-5d（Bar 样式）：目视确认 tone="primary" 在结算 Overlay 背景对比度 OK
> - I-4 冒烟（成本评估）：现有冒烟无「构造错题组」场景，成本 Medium——本版不做正向断言，进度条由代码审核 + 手动验证覆盖（审核报告记录）

## 1. 背景与现状问题

| 编号 | 优先级 | 问题 | 代码位置 |
|---|---|---|---|
| P0 | 中 | **同类专项连做（V1.3.0）无进度反馈**：孩子不知第几题/剩几题；结算层只有「下一道」按钮，缺进度条/剩余提示，连做体验缺掌控感 | `src/routes/index.tsx`（`groupSession={list,idx}`）、`src/components/Practice.tsx`（结算层 604-651，`params.inGroup` 仅切换按钮文案） |

## 2. 目标与原则

- **目标**：连做结算层显示「已完成 x/n 题 · 还剩 m 道」+ 进度条；末题显示「本组已完成」。非主要功能 → **V1.4.1（patch）**。
- **原则**：最小化修改（StartParams 加可选 `group?`，复用现有 Bar 组件 `value/total` API）；不改连做流程骨架（startGroupPractice/handlePracticeFinish 推进逻辑不动，仅传参）；单向派生防止失步；末尾边界显式处理（末题文案 / total≤1 隐藏）；措辞「已完成/还剩/本组已完成」教学语系。

## 3. 变更设计

### 3.1 传组进度（P1 / I-4 / I-5c）

- `Practice.tsx` `StartParams` 增：
  ```ts
  /** 同类专项连做进度（V1.4.1）：第 idx+1 题 / 共 total 题（仅展示快照，源 = groupSession） */
  group?: { total: number; idx: number };
  ```
- `index.tsx`：
  - `startGroupItem(item, idx, total)`：`start({ ..., inGroup: true, group: { total, idx } })`（签名变更，grep 全部调用点：startGroupPractice 首题、handlePracticeFinish 推进）
  - `startGroupPractice(gid)` 首题：`startGroupItem(ordered[0], 0, ordered.length)`
  - `handlePracticeFinish`：`const next = groupSession.idx + 1; setGroupSession({ list, idx: next }); startGroupItem(groupSession.list[next], next, groupSession.list.length)`——**groupSession 为组游标 SSOT，params.group 为展示快照，单向派生不反向写回**（I-4）

### 3.2 结算层进度显示（P0 / I-3 / I-5a / I-5b）

- `Practice.tsx` 结算 Overlay（ResultSummary 上方）：
  ```tsx
  {params.group && params.group.total > 1 ? (
    <div className="mb-3 space-y-1.5 rounded-xl bg-secondary/50 px-3 py-2.5">
      {(() => {
        const g = params.group!;
        const done = g.idx + 1;
        const last = done >= g.total;
        return (
          <>
            <p className="text-center text-[11.5px] font-semibold text-muted-foreground">
              {last ? `已完成 ${g.total}/${g.total} 题 · 本组已完成` : `已完成 ${done}/${g.total} 题 · 还剩 ${g.total - done} 道`}
            </p>
            <Bar value={done} total={g.total} tone="primary" />
          </>
        );
      })()}
    </div>
  ) : null}
  ```
  - **total≤1 不渲染**（I-5b）；末题「本组已完成」（I-5a）；Bar 用 `value/total`（修正 v0.1 笔误）
  - 空态（无 params.group）不渲染——普通练习/replay 无 group，零影响
