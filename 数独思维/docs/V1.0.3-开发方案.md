## 2. 目标与原则

- **目标**：回写版本权威字段（1.0.2 → 1.0.3）；设置页「关于」区与首页 footer 显示版本号；补全/统一隐私声明（规范串）。纯文案/展示类变更，零逻辑改动。
- **原则**：版本号唯一来源 = `package.json` version（构建期注入，不硬编码）；措辞「教学与训练」语系；最小化修改（`lib/version.ts` 新增 + `Settings.tsx`/`index.tsx` + `AGENTS.md` + `tests/smoke.mjs`）。

## 3. 变更设计

### 3.0 版本权威字段回写（P0 / B1）

- 本次实施**第一步**：`package.json` version `1.0.1` → **`1.0.2`**（补 V1.0.2 发布回写），随后按本迭代升至 **`1.0.3`**。
- 发布时同步更新 `AGENTS.md`「当前 V1.0.x」行（B1/N3）。

### 3.1 版本号注入（P1/P3 / I1）

- 新增 `src/lib/version.ts`：
  ```ts
  import pkg from "../../package.json";
  /** 唯一权威版本号（package.json version，构建期内联） */
  export const APP_VERSION = pkg.version;
  ```
- `Settings.tsx` 关于区补一行 `版本 V{APP_VERSION}`（独立成段，`<br />` 分隔——避免 `text=` 匹配跨节点）。
- `index.tsx` 首页 footer 补版本标识（独立小字行，与隐私行分行）。

### 3.2 隐私声明规范串（P2 / I2）

- 规范串：`无账号 · 无云同步 · 无排行 · 数据只存本机`（覆盖数据本地化 + 去游戏化两维度，与 AGENTS.md 硬性约束「无排行」一致）。
- 首页 footer 现有「无账号 · 无云同步 · 不排名。所有记录保存在这台设备的浏览器里。」→ 改为规范串（同串复用）。
- 设置页「关于」区最终 4 行结构：
  1. 图标（app-icon，保留）
  2. `数独思维 · 逻辑推理教学与训练`（保留）
  3. `版本 V{APP_VERSION}`（新增）
  4. `无竞技 · 无排行 · 不比较，只和孩子自己的上一次对照。`（保留，去游戏化语气）+ `无账号 · 无云同步 · 无排行 · 数据只存本机`（新增规范串，独立行）
- Report.tsx / MapView.tsx 的既有隐私文案本次不动（留后续统一，不在此迭代过度承诺）。

## 4. 验证计划

1. `pnpm typecheck` 零错误（json import 类型通过，`APP_VERSION` 字面量类型可赋 string）。
2. `pnpm build` 通过；**补 dist 体积 delta 校验**（I4）：对比改动前后 `dist/assets/*.js` 体积，增量 < 1KB；若显著偏大说明整包 package.json 被内联，回退用 `define: { __APP_VERSION__ }` 方案。
3. `pnpm test:engine` 全过（回归）。
4. `pnpm test` 冒烟 19 项全过 + 新增断言（I3）：测试内读 package.json version 动态拼接 `text=版本 V${ver}` 断言设置页可见；首页 footer 含规范串（`text=数据只存本机`）。
5. oracle 代码复核 + 审核报告。
