# 数独思维（React 版）V1.3.0 开发方案（v0.2，已按 oracle 评审修订）

> 项目：`数独思维/src`（Vite + React 19 + TS，单路由视图状态机）
> 版本规则：微调（bug fix / 样式 / 文案）→ patch（升子版本号，自主）；较大调整（新功能 / 交互改进）→ minor（升次版本号）
> 本方案遵循 `数独思维/src/AGENTS.md` 迭代流程：开发方案 → oracle 评审 → 实施 → 验证 → 亲自审核代码 → 审核报告 → 提交发布
>
> **评审记录（v0.1 → v0.2）**：oracle 审核「2 阻断 B1-B2 + 6 建议 I1-I6 + 4 说明 N1-N4」。已修订：
> - B1（映射事实错误）：`content.ts` **已有** `uniqueElim`（唯一余数💎）教学关，brief「一格所在行列宫已出现其余全部数字」与引擎 `technique="唯一候选"`（reason「行、列、宫里已经出现过其余 N-1 个数字，只剩 X 能填」）是**同一技巧**。映射改为 `唯一候选→uniqueElim / 宫内排除→boxElim / 行列排除→rowColElim / 卡住→需综合`
> - B2（skills 语义 gap）：显式定义 `techniques` 语义 = 「题目推理链前段（基础技巧可推进部分）涉及的技巧集合（近似题目标签）」，**不等于**「孩子错误对应的技巧」；分组统计结论据此审慎解读，UI 文案用「这类题常涉及」而非「你错在」
> - I1：`analyzeTechniques` 套用 `replay.ts` 同款 `MAX_STEPS`（100）+ `MAX_ROUNDS`（size²）双上限 + 按题面签名缓存（`Map`），pushMistake 入库补算走缓存，避免 9×9 主线程卡顿
> - I2：BookItem 新字段命名 `techniques?: string[]`（避开 State 层已有的 `skills: Record<string,boolean>` 同名异义）
> - I3：旧错题补算 **写回 store 一次性迁移**（首次打开错题本批量补算 + persist），非视图层惰性
> - I4：同类专项练习交互具体化：组卡「练这一组」→ 连做模式（组内题逐一 source="replay"+errIdx）→ 每题「下一道/返回」→ 练完「这组练完了」回错题本；组内 <3 题直接全练、≥3 题随机起手
> - I5：「需综合」组按钮改「📚 去练一道」（跳自由练习/地图）——4 基础关不匹配该组，不空指教学关
> - I6：实施前核查 backup schema 是否 strip 未知字段（zod）；若 strip 则 backup 显式允许 `techniques`
> - N1：无死循环（每轮 findLogicStep 必填一格 → ≤size² 轮必然终止），仍加 MAX_ROUNDS 兜底
> - N2：4 组粒度够，`size` 作为组内次级小标签（不独立成 12 组）
> - N3：minor + `techniques?` optional 向后兼容合理
> - N4：文案过「去游戏化」红线（禁「闯关/挑战/对战」）

## 1. 背景与现状问题

| 编号 | 优先级 | 问题 | 代码位置 |
|---|---|---|---|
| P0 | 中 | **错题本无技巧维度**：错题按时间平铺，只能逐题重练，无法识别「哪类题常涉及难住的技巧」；同类错误反复出现得不到针对性补强 | `store.tsx` `BookItem`（无技巧字段）、`Walls.tsx` `BookList`、`Practice.tsx` `pushMistake` |
| P1 | 低 | **「错题 → 教学关」无关联**：错题暴露的技巧短板，无法一键跳回对应教学关复习 | `routes/index.tsx`、`content.ts` |

## 2. 目标与原则

- **目标**：错题入库时静态计算「题面技巧画像」（该题推理链用到的基础技巧集合），存 `BookItem.techniques`；错题本页新增「按技巧分组」区——每类显示题数 + 关联教学关快捷入口 + 「练这一组」同类专项连做。
- **原则**：
  - 技巧判定复用引擎 `findLogicStep`（诚实能力：唯一候选/宫内排除/行列排除 3 类基础技巧；进阶技巧不误判——无能力识别就归「需综合」组）
  - **`techniques` 语义显式定义为「题面推理链涉及的基础技巧近似标签」**（B2），UI 措辞「这类题常涉及 X」而非「你错在 X」
  - 纯本地、可单测、无新依赖；旧错题一次性迁移写回（I3）；措辞「练习/巩固/掌握」语系，无游戏化（N4）

## 3. 变更设计

### 3.1 技巧画像引擎（P0 / I1 / N1）

- `sudoku.ts` 新增：
  ```ts
  const TECHNIQUE_MAX_ROUNDS = 100;              // I1：与 replay.ts 同款步数上限
  const techniqueCache = new Map<string, string[]>(); // 按题面签名缓存
  /** 题面技巧画像：模拟推理链收集去重 technique 集合；上限兜底；结果按题面缓存 */
  export function analyzeTechniques(board: Grid, size: Size): string[] {
    const sig = `${size}:${toSDString(board, size)}`;
    if (techniqueCache.has(sig)) return techniqueCache.get(sig)!;
    const set = new Set<string>();
    const grid = board.slice();
    for (let i = 0; i < TECHNIQUE_MAX_ROUNDS; i++) {
      const step = findLogicStep(grid, size);
      if (!step) break;                    // 卡住（需进阶技巧或已解完）
      set.add(step.technique);
      grid[step.index] = step.value;       // 每轮必填一格 → ≤size² 轮必然终止
    }
    const out = [...set];
    if (techniqueCache.size > 200) techniqueCache.clear(); // FIFO 上限
    techniqueCache.set(sig, out);
    return out;
  }
  ```
  - 返回 0~3 种基础技巧中文名；卡住（findLogicStep null 未填满）→ 返回已收集集合（诚实：仅代表可推进子集）。

- **技巧组映射**（`content.ts` 新增，B1 修正）：
  | findLogicStep technique | 教学关 key | 组名 |
  |---|---|---|
  | `唯一候选` | uniqueElim | 唯一候选 |
  | `宫内排除` | boxElim | 宫内排除 |
  | `行排除` / `列排除` | rowColElim | 行列排除 |
  | 其他/无 | — | 需综合 |

### 3.2 错题存储（P0 / I2）

- `store.tsx` `BookItem` 增加 `techniques?: string[]`（I2：避开 `skills` 同名异义；optional 兼容旧存档）。
- `Practice.tsx` `pushMistake`：入库时 `techniques: analyzeTechniques(board, size)`。

### 3.3 错题本分类视图 + 专项连做（P0/P1 / I3/I4/I5/I6）

- `index.tsx` 错题本视图**两段式**：
  1. **技巧分组区**（仅 kind=mistake 且有题时）：按 techniques 分组统计，组卡含：组名 + 题数 + 「🎓 复习技巧」（跳 skillByKey 对应教学关；唯一候选→uniqueElim，B1）+ 「📝 练这一组」（I4 连做）+ 「需综合」组按钮为「📚 去练一道」（I5 跳自由练习）
  2. **明细列表**（现有 BookList 保留平铺）
- **迁移**（I3）：`index.tsx` 错题本视图挂载时 `useEffect` 检查 `store.mistakes` 中 `!m.techniques` 的条目 → `analyzeTechniques` 补算 → `update` 写回（一次性；单条 try/catch 失败跳过）
- **连做模式**（I4）：组卡「练这一组」→ 该组题 list → 逐题 `start({ source:"replay", ...errIdx })` → 每题完成「下一道 / 返回」→ 组内练完「这组练完了」回错题本。组内 <3 题直接全练；≥3 题随机起手顺序全练。
- **教学关关联**（P1）：组卡「🎓 复习技巧」→ `openSkill(skillKey)`（技能墙/教学关现有流程）。
