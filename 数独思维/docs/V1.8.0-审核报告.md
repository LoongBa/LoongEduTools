## 五、代码自审发现（实施级）

1. **JSX 结构错误（首轮 typecheck 4 错）**：编辑 Report.tsx 插入两卡时误吞 print-root 外层 div 闭合 + 「共 N 个技巧阶梯」提示段——已修复（补回 `</div>` + 提示 `<p>`），typecheck 归 0。**教训：插入长 JSX 片段后必须立即 typecheck。**
2. **冒烟导航路径（首轮 4 FAIL）**：⑧ 段后 mistakes 页返回按钮是 **TopBar 箭头**（`button[aria-label="返回"]`），非文本「返回难度」——修正选择器后 4 断言全过。
3. **`ChartLegendContent` 用法**：直接传 `payload` 数组（value/dataKey/color）——内部 `useChart()` 需要 config，此处用硬编码 color 传参绕过 config 依赖，typecheck + 运行时均通过（Pie 图 legend 正常渲染）。
4. **`ChartContainer config={{}}`**：空 config 合法（ChartStyle 无 colorConfig 时返回 null）；Pie 的 Cell fill 直接取 CHART_GROUP_COLORS，不依赖 config 变量——简化接线。
5. **冒烟注入 `totals: { count: 12, ... }`**：真实 finishAll 累加由既有冒烟覆盖不足（早段无完成局），注入保证累计卡断言确定性；recharts 真实渲染由 `.recharts-wrapper` 断言覆盖。
6. **未引入的改动**：backup.ts validateBackup 未加 totals 类型守卫（Oracle I 级评估为与既有 best/skills 等缺省容忍一致，缺省路径 load 嵌套合并兜底）；引擎零改动。
