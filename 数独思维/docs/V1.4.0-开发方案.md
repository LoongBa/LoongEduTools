# 数独思维（React 版）V1.4.0 开发方案（v0.2，已按 oracle 评审修订）

> 项目：`数独思维/src`（Vite + React 19 + TS，单路由视图状态机）
> 版本规则：微调（bug fix / 样式 / 文案）→ patch（升子版本号，自主）；较大调整（新功能 / 交互改进）→ minor（升次版本号）
> 本方案遵循 `数独思维/src/AGENTS.md` 迭代流程：开发方案 → oracle 评审 → 实施 → 验证 → 亲自审核代码 → 审核报告 → 提交发布
>
> **评审记录（v0.1 → v0.2）**：oracle 审核「2 阻断 B1-B2 + 6 建议 I1-I6 + 4 说明 N1-N4」。已修订：
> - B1（测试夹具不可用）：实证 LESSON_DATA.xwing 盘上 idx9（行1列3）初始即单候选{4}，findLogicStep 首次返回"唯一候选"——X-Wing 永不触发；且 idx18（行3列0）候选集为空（整盘无解，教学快照非合法题）。nakedPair 盘同理（idx5=6 单候选抢先）。**教学盘系统性不能用作 findLogicStep 单调用测试夹具** → 全部识别器单测改**手工构造极小盘**（目标技巧为唯一首产者）
> - B2（命名字段歧义）：明确 **`findLogicStep.technique` 存中文名**（"显性数对"等，与现有 base 3 技巧一致）、**`TECHNIQUE_LESSON_MAP` 存英文 lesson key**（"nakedPair"等）。两层不可混淆，否则破坏 groupOfTechniques 全链路
> - I1（砍 triple）：本轮只做 **nakedPair / hiddenPair / xwing 三项**；nakedTriple/hiddenTriple 组合爆炸 + 低 ROI（儿童练习盘极少以 triple 为门槛），推 V1.5
> - I2（null 语义）：识别器坚持「必须定位落子」（不改签名——LogicStep{index,value} 被提示讲解与 analyzeTechniques 循环强依赖）；X-Wing 排除后**无唯一落子则返回 null**，绝不返回 pattern 提示（防假阳性）
> - I3（分组折叠）：tier 折叠——base 三组平铺 + 一个可展开「进阶观察」折叠组（内含数对/X-Wing）+「需综合」= 5 顶部条目（复用 content.ts tier:"adv" 字段）
> - I4（旧错题迁移补强）：迁移条件扩为「techniques 缺任意新技巧名时重算」，避免同盘新旧条目分组不一致（当前仅补 `!m.techniques`）
> - I5（测试补三类）：① pattern 存在但排除后无唯一落子→断言返回 null；② 基础可解题上断言进阶识别器不抢占；③ technique 名 / TECHNIQUE_LESSON_MAP 键 / ADV_SKILLS.name 三处一致性断言
> - I6（性能 + X-Wing 列向）：findLogicStep 入口一次性算全盘候选矩阵（五段共享，防 9×9 candidatesFor 重复扫描——性能风险实为中非低）；X-Wing 补列向形式（行/列两向对称）
> - N1：techniqueCache 是模块级 in-memory Map（非 localStorage），重载即清 + 内容寻址 + 确定性 → **不会跨版本缓存旧 3 技巧**，§8 担忧基于误读
> - N2：版本 minor 正确（新功能）
> - N3：xwing 技巧名精确为 "X-Wing"（ADV_SKILLS.name 原样）
> - N4：痛点定性——教学盘走 LessonStep 引导不走 findLogicStep，识别器真正价值在**真实错题盘**（基础卡住需进阶才推进）
>
> **实施决策补充（v0.2 定稿后，记录于审核报告 §4）**：**隐性数对识别器裁剪**——14000+24000 盘零命中实证（真实触发条件在小学规格盘面极稀有）+ 单步落子语义结构性限制（锁定格恒 2 候选，数学上无法产出「排除后变单」落子）。本轮交付显性数对 + X-Wing 两项已验证项；隐性数对与 triple 留 V1.5+ 转「模式识别标注」方案。符合 oracle I1（收敛）/ I2（必须定位落子）原则。

## 1. 背景与现状问题

| 编号 | 优先级 | 问题 | 代码位置 |
|---|---|---|---|
| P0 | 高 | **findLogicStep 只识别 3 种基础技巧**：候选排除类进阶技巧（显性/隐性数对、X-Wing）无法识别 → 真实错题盘中「基础技巧卡住、需进阶才推进」的题被归「需综合」组（占比大、失去分类价值），「复习技巧」关联失效 | `sudoku.ts` `findLogicStep`（166-213）、`analyzeTechniques`（V1.3.0）、`content.ts` `TECHNIQUE_GROUPS` |
| P1 | 中 | **进阶技巧教学关与引擎脱节**：nakedPair/hiddenPair/xwing 关（LESSON_DATA）有教学盘与引导，但引擎对同类盘面无法给「下一步提示」——孩子自由练习遇到同类题时没有引擎引导 | `content.ts` `LESSON_DATA`（nakedPair 216-222 / hiddenPair 224-230 / xwing 208-214） |

## 2. 目标与原则

- **目标**：扩展 `findLogicStep` 识别**候选排除类进阶技巧**（显性数对/隐性数对/X-Wing 三项，B1/I1 范围），使真实错题盘中基础卡住的题能继续推进；`analyzeTechniques` 随之对进阶题给出更细画像，错题分组「需综合」组缩小，进阶技巧正确关联教学关。
- **原则**：
  - **识别器必须定位落子**（I2）：LogicStep{index,value} 被 Practice 提示讲解（告诉孩子「点哪格填哪个数」）与 analyzeTechniques 循环（`grid[step.index]=step.value` 每轮必推进）强依赖——不舍弃落子语义改 pattern 检测
  - **null 语义**（I2）：识别器「检测 pattern → 排除候选 → 复算」后，**恰有一格变单候选才返回该格；否则返回 null**（不返回 pattern 提示，防假阳性）
  - **优先级链**：基础技巧（现有 ①②③）优先；全部无果才进入进阶段（保证简单题不因进阶扫描降响应）
  - **命名字段分离**（B2）：`technique` 字段 = 中文名（"显性数对"等）；`TECHNIQUE_LESSON_MAP` = 中文名→英文 lesson key
  - **诚实归组**：识别不了（triple/swordfish/XY-Wing 等留 V1.5+）仍返回 null → 归「需综合」
  - 纯本地、可单测（手工构造极小盘，B1）、无新依赖；措辞去游戏化、教学语系

## 3. 变更设计

### 3.1 findLogicStep 扩展（P0 / B1 / B2 / I2 / I6 / N3）

- `sudoku.ts` `findLogicStep` 改造：
  - **入口一次性算候选矩阵**（I6）：`const cands = new Map<number, number[]>()` 懒计算（首次需要某格候选时算并缓存），①②③④⑤⑥ 共享——防 9×9 candidatesFor 重复扫描（性能风险实为中）
  - ①②③：现有基础技巧（唯一候选/宫内排除/行列排除）——迁移到共享候选矩阵，行为不变
  - ④ **显性数对（裸对）**：对每个单元（行/列/宫），找 2 个空格候选集**各恰好 = {a,b}**（并集=2 数，非仅共享——防过触发，oracle I6 精度）→ 单元其他格排除 a,b → 复算后若有格变单候选 → 返回 `{index, value, technique:"显性数对", reason}`
  - ⑤ **隐性数对**：对每个单元，找 2 个数字 {a,b} 其候选位置集合完全落在同 2 格 → 该 2 格锁定 {a,b}，清除其多余候选 → 若有格变单候选 → 返回 `{..., technique:"隐性数对"}`
  - ⑥ **X-Wing（行向 + 列向两对称，I6）**：数字 v 在两行候选位各恰 2 个且列对齐 → 这两列其他格排除 v → 复算后若有格变单候选 → 返回 `{..., technique:"X-Wing"}`（名字精确带连字符，N3）；列向同理
  - 全部无落子 → return null

- **技巧命名表**（B2 明确双层）：
  | technique 字段（中文） | TECHNIQUE_LESSON_MAP 值（英文 key） | 教学关名（ADV_SKILLS.name） |
  |---|---|---|
  | `显性数对` | nakedPair | 显性数对 |
  | `隐性数对` | hiddenPair | 隐性数对 |
  | `X-Wing` | xwing | X-Wing |

## 4. 验证计划

1. `pnpm typecheck` 零错误。
2. `pnpm build` 通过。
3. `pnpm test:engine` 全过 + 新增进阶识别器单测（**全手工构造极小盘**，B1）：
   - 显性数对：4×4/6×6 盘面（单元内两格候选各 {a,b} → 其他格排除 → 唯一落子）
   - 隐性数对：两数候选位落同两格 → 清多余候选 → 唯一落子
   - X-Wing：行向盘 + 列向盘各一（数字 v 两行/两列 2 候选对齐 → 排除 → 落子）
   - **null 语义**（I5）：数对/X-Wing pattern 存在但排除后无唯一落子 → 断言 findLogicStep 返回 null
   - **不抢占**（I5）：基础可解题 FIRST 返回基础技巧（进阶不抢占）
   - **命名一致性**（I5）：新识别器 technique 值 = TECHNIQUE_LESSON_MAP 键 = ADV_SKILLS.name（防 B2 漂移）
   - 回归：基础 3 技巧识别不变；analyzeTechniques 对「仅进阶可推进」盘不空转（≤MAX_ROUNDS 终止）
4. `pnpm test:backup` / `pnpm test:share` / `pnpm test` 回归。
5. 亲自审核代码 + 审核报告。
