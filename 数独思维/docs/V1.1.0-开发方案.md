# 数独思维（React 版）V1.1.0 开发方案（v0.2，已按 oracle 评审修订）

> 项目：`数独思维/src`（Vite + React 19 + TS，单路由视图状态机）
> 版本规则：微调（bug fix / 样式 / 文案）→ patch（升子版本号，自主）；较大调整（新功能 / 交互改进）→ minor（升次版本号）
> 本方案遵循 `数独思维/src/AGENTS.md` 迭代流程：开发方案 → oracle 评审 → 实施 → 验证 → 亲自审核代码 → 审核报告 → 提交发布
>
> **评审记录（v0.1 → v0.2）**：oracle 审核「3 阻断 B1-B3 + 5 建议 I1-I5」。已修订：
> - B1（版本定性）：URL 直启 + 剪贴板预填属**交互改进**，按 AGENTS.md 规则升次版本号 → **V1.1.0**（非 patch）；本文档同步改名
> - B2（P0 闭环边界）：V1.0.4 二维码是纯文本 `SD{N}:<sd>` 非 URL，离线无后端不 URL 化 → **本版 URL 直启只闭环「链接/书签场景」**；扫码场景收口为「导入浮层 + 显式粘贴按钮」（见 B3/I1），边界写进风险表
> - B3（剪贴板预填触发方式）：**自动 useEffect 读剪贴板 → 显式「📋 从剪贴板粘贴」按钮**——规避 Chrome 原生权限弹窗打扰儿童、iOS Safari 无手势必失败、transient activation 超时三类问题；权限弹窗在用户预期内，且不影响 V1.1.0 其他功能
> - I1：URL `sd` 参数先 `decodeURIComponent` 再解析（防分享渠道百分号编码 `.`/`,` 截断正则）
> - I2：`useEffect` 加 `useRef` 单次守卫（React 19 StrictMode dev 双调用）
> - I3：**消除 solveSolution 重复求解**——`validateImported` 顺带返回 solution，`ParseResult` 带 `solution` 字段，直启直接复用；9×9 由 3 次回溯降为 1 次
> - I4：直启失败 Toast 复用 `importMsg(parsed)`（错误文案收敛 copy.ts，不内联 index.tsx）
> - I5：测试补 3 项——刷新不重复直启 / 9×9 81 字符长串直启 / 剪贴板降级无 JS 错误

## 1. 背景与现状问题

| 编号 | 优先级 | 问题 | 代码位置 |
|---|---|---|---|
| P0 | 中 | **「链接 → 练习」隔着一层手动导入**：V1.0.4 已实现协议串 `SD{N}:<sd>` 分享闭环（复制/二维码），但拿到编码后仍需打开 App → 首页点「导入题目」→ 粘贴 → 点「开始练习」三步，端到端未直连；分享链接/书签场景（家长发链接给孩子）无直达路径 | `routes/index.tsx`（`importing` 状态）、`components/ImportRules.tsx` |
| P1 | 低 | **导入浮层不感知剪贴板**：复制了分享文本后打开导入浮层需手动按出键盘粘贴，移动端体验割裂 | `ImportRules.tsx` `ImportOverlay` |

## 2. 目标与原则

- **目标 A（URL 直启，链接/书签场景）**：支持 `?sd=SD{N}:<编码>` URL 参数——应用启动时解析，校验通过（复用 `parseImportedText` 白名单：前缀 + 长度 + 唯一解）自动进入练习（source="import"）；校验失败弹 Toast 提示并回首页。`file:///….html?sd=…` 与静态部署均适用（纯本地解析，零网络）。
- **目标 B（剪贴板显式粘贴）**：导入浮层提供「📋 从剪贴板粘贴」按钮：点击时 `navigator.clipboard.readText()`，命中 `SD{N}:` 协议串才预填 textarea；权限拒绝/非安全上下文/隐私模式 → 静默降级（按钮仍在，提示「请手动粘贴」）。
- **原则**：复用 V1.0.4 校验链（I3 顺带返回 solution）；直启与手动导入共享同一 `parseImportedText` 结果；无新依赖；隐私/去游戏化红线不变；**版本按交互改进升 V1.1.0**。

## 3. 变更设计

### 3.1 URL 直启（P0 / B1 / I1 / I2 / I3 / I4）

- `routes/index.tsx` 挂载 `useEffect`（`useRef` 守卫单次，I2）：
  ```ts
  const sdRaw = new URLSearchParams(window.location.search).get("sd");
  const sd = (() => { try { return decodeURIComponent(sdRaw ?? ""); } catch { return sdRaw ?? ""; } })(); // I1
  ```
  - 为空 → 无操作；存在 → `parseImportedText(sd)`：
    - `error === null && board && solution` → `start({ size, level: "normal", source: "import", board, solution })`（**I3：直接用 ParseResult.solution**，不再调 solveSolution 二次求解），并 `history.replaceState` 清 URL（同路径无 query）。
    - 校验失败 → `showToast(importMsg(parsed))`（I4：复用 copy.ts 文案）并停留首页。
- **不新增首页按钮**：URL 直启为隐式增强（分享链接 / 书签 / 二维码含 URL 场景）。
- **扫码场景边界**（B2）：V1.0.4 二维码保持纯文本协议串不变；扫码→复制→打开 App→首页「导入题目」→「📋 从剪贴板粘贴」→开始 = 两步内闭环（P1 改善），URL 直启专管链接场景。

### 3.2 剪贴板显式粘贴（P1 / B3）

- `ImportRules.tsx` `ImportOverlay`：
  - 新增「📋 从剪贴板粘贴」按钮（文本区下方，secondary 变体）：
    ```ts
    const [pastable, setPastable] = useState(false);
    async function pasteClipboard() {
      try {
        const clip = await navigator.clipboard.readText();
        if (clip && /SD(4|6|9)\s*:/.test(clip)) { setText(clip); setPastable(false); return; }
        showTip?.("剪贴板里没有识别到题目编码");
      } catch { showTip?.("无法读取剪贴板，请长按输入框手动粘贴"); }
    }
    ```
  - onClick 挂用户手势，权限弹窗在预期内；`readText` 抛错（权限/非安全上下文/隐私模式）→ 静默提示手动粘贴。
  - 不再自动读剪贴板（B3）；未命中 `SD{N}:` 正则不预填（防误读无关内容）。

### 3.3 引擎返回 solution（I3）

- `sudoku.ts`：
  - `validateImported` 返回值加 `solution?: Grid`（唯一解时携带 `solve(grid, size, 1)[0]`）。
  - `ParseResult` 加 `solution?: Grid`；`finishParse` 通过时透传。
- `ImportRules.tsx`/`index.tsx` 手动导入 `onStart` 改用 `parsed.solution`（`solveSolution` 保留兜底或移除——审核时定）。
