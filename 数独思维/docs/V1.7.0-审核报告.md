## 三、变更摘要

- **B5 核心**：组内连做完成最后一题 → 结算层「下一道」→ `handlePracticeFinish(result)` 累积结果 → 组结束开小结浮层「🧮 这组练完了」：共完成 N 题 / 全对 M 道 / 总用时 + 每题星级/用时/失误明细 + 三按钮（回到错题本/再练一组/回首页）
- **数据流**：`groupSession.results` 内存态累积（每题 stars/ms/errors/hints），**零 store 迁移**；`全对` = stars===3（0错0提示，与三星成就同口径）
