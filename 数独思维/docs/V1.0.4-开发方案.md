## 1. 背景与现状问题

| 编号 | 优先级 | 问题 | 代码位置 |
|---|---|---|---|
| P0 | 高 | **「分享→导入」闭环实际断裂（oracle 证实的隐性 bug）**：复制文本/二维码为中文标题 + `题目编码：sd` 混排。复制全文粘贴导入时，无前缀分支 `replace(/[^0-9.\s]/g,"")` 会把标题里 `4×4` 的数字也保留，污染 sd 长度 → 16/36/81 判规格失败 → **导入必然失败**；纯数字分支只在用户手动抠出 sd 时可用。解析逻辑内联 useMemo 无法单测 | `Share.tsx:101` `text` / `ImportRules.tsx` `ImportOverlay` |
| P1 | 低 | **隐私规范串未收敛**：footer 与 about 各写一遍；Report/MapView 为教学散文（不同语义，不应强行统一） | `routes/index.tsx:501`、`Settings.tsx:147` |

## 2. 目标与原则

- **目标 A（闭环修复 + 协议化）**：二维码/复制文本统一为 `SD{N}:<sd>` 协议串（ASCII 纯编码，二维码更短更稳、含 `SD{N}:` 前缀优先命中导入分支 ①）；导入解析下沉 `sudoku.ts` 纯函数（可单测、复用）；copy.ts 统一文案。
- **目标 B（规范串收敛）**：隐私徽章串 `无账号 · 无云同步 · 无排行 · 数据只存本机` 抽为 `PRIVACY_BADGE` 单点维护（footer + about 两处引用）。
- **原则**：引擎层零 UI 文案（error code 结构）；Share 编码不变式 = 仅 givens；最小化修改不借机重构。

## 3. 变更设计

### 3.1 协议串与 Share 输出（P0 / B3 / I1 / I4 / I7）

- **协议格式**：`SD{N}:<sd>`，`sd` = `toSDString(board,size)`（`N=4/6/9`，`.` 表空，长度 `size²`）。
- `SharePuzzleOverlay`：
  - `qrText` → `SD{N}:<sd>`（纯 ASCII，无中文混排）
  - `text`（复制文本）→ 保留人读标题 + 教学句，删除原裸 `题目编码：sd` 行，新增 **`导入编码：SD{N}:<sd>`** 行（I7：唯一 sd 来源，避免双源漂移；`SD{N}:` 前缀保证粘贴即被分支 ① 捕获，标题中的 `4×4` 不再污染）
  - canvas 容器加 `data-qr-text={qrText}`（I4：share.mjs 断言钩子，生产无副作用）
- `ShareResultOverlay`：成绩卡二维码 `qrText` 同步改协议串。

### 3.2 导入解析下沉（P0 / B1 / B2 / I2 / I5）

- 新增 `sudoku.ts`：
  ```ts
  export type ImportError = "EMPTY" | "BAD_LEN" | "BAD_CHAR" | "CONFLICT"
    | "TOO_FEW" | "NO_SOLUTION" | "MULTI_SOLUTION";
  export function parseImportedText(text: string):
    { size: Size | null; board: Grid | null; error: ImportError | null }
  ```
  逻辑 = 搬运 ImportOverlay 现有分支：① `SD{N}:` 前缀（`/SD(4|6|9)\s*:\s*([0-9.,\s]+)/`）→ clean 保留 `[0-9.]` 剥离 `[,\s]`（B1 写死）→ 长度校验 → `fromSDString` → `validateImported`；② 无前缀纯数字 16/36/81 → 同上。返回结构化 error（B2：不含中文，message 由 copy.ts 映射）。
- `ImportRules.tsx`：`useMemo(() => parseImportedText(text), [text])`；`parsed.message` 改为 `IMPORT_MSG[parsed.error]`（来自 copy.ts）；原有「目前是 N 个字符」动态消息由 copy.ts 函数 `importMsg(parsed)` 生成。
- `copy.ts`（新增）：
  ```ts
  export const PRIVACY_BADGE = "无账号 · 无云同步 · 无排行 · 数据只存本机";
  export const PROTOCOL_PREFIX = "导入编码";
  export const IMPORT_MSG: Record<ImportError, string> = { … };
  export function importMsg(r: { size: Size|null; error: ImportError|null }): string { … }
  ```
- **round-trip 不变式**（B3/I5）：engine.mjs 断言 Share 编码回路——`parseImportedText("SD4:" + toSDString(board,4))` 的 board 与原始 givens 逐格相等；`fromSDString(toSDString(g))` 恒等。

### 3.3 规范串收敛（P1 / I6）

- `routes/index.tsx:501` footer、`Settings.tsx:147` about → `{PRIVACY_BADGE}`。
- Report.tsx:82/174、MapView.tsx:28 教学散文**保留原文**（语义=节奏鼓励，非徽章；不强行统一）。
