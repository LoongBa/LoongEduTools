## 二、变更设计

### 2.1 二维码内容：裸协议串 → URL（核心变更）

**现状**：`Share.tsx:106` `const qrText = proto;`（裸 `SD{N}:<sd>`）；`Share.tsx:309` `drawRealQr(ctx, sdProtocol(...), ...)`（成绩长图裸串）。

**变更**：二维码内容改为完整 URL。

```ts
// copy.ts 新增（V1.9.0 B8）：
/** 扫码直进 URL（V1.9.0）：含 pathname 的完整 URL——B1 修复：vite base 可含子路径（如 /shudu/），origin 不含 pathname 会指向站根 */
export function sdUrl(size: Size, sd: string): string {
  const u = new URL(window.location.href);   // href 含 origin + pathname + 当前 search/hash
  u.search = "";                             // 清掉当前 query（防与 ?sd= 叠加）
  u.hash = "";                               // 清 hash
  u.searchParams.set("sd", sdProtocol(size, sd));  // URLSearchParams 自动百分号编码（: → %3A）
  return u.href;
}
```

- `Share.tsx:106` `qrText = sdUrl(size, sd)`（分享题卡）；`Share.tsx:309` `drawRealQr(ctx, qrText, ...)`（成绩长图）
- **ShareResultOverlay 提取 `qrText` 变量复用（v0.3 I2）**：L309 绘制与 L341 `data-qr-text` 同用该变量（消除脱钩 + 重复计算）
- **文案同步（v0.3 I1，共 4 处）**：
  - `Share.tsx:144`（题卡 canvas 内）「📱 扫码复制题目编码，在「导入题目」粘贴即可练习」→「📱 扫码直进练习」
  - `Share.tsx:183`（题卡 Overlay DOM）「二维码扫码复制题目编码」→「扫码直进练习」
  - `Share.tsx:312`（成绩卡 canvas 内）「扫码复制题目，在导入题目里粘贴练习」→「扫码直进练习」
  - `Share.tsx:304` 注释同步（cosmetic）
  - **保留**：`Share.tsx:104` 复制文本 `IMPORT_PROMPT_LABEL：${proto}` 仍裸协议（粘贴路径不变）✓
- **QR 容量（v0.3 I3 修正论证）**：byte 模式（`qrcode.stringToBytesFuncs["UTF-8"]`）+ `qrcode(0,"L")` 自动选版（typeNumber=0）；SD9 URL ~113-127B → 自动 v9-v10（模块 53-57），200px 下模块 ~3.08px / 260px 下 ~4.0px——**仍可扫**（≥3px）；SD9 贴 v9-L 122B 上限，更长 origin 落 v10（auto 兜底不致失败），无需调尺寸
- **风险表修正（v0.3 N1）**：file:// 下 `window.location.href` 的 origin 为字符串 `"null"`（非空串），产物非有效扫码 URL——与现状一致（裸协议本非链接），file:// 非扫码部署场景无影响

### 2.2 URL 直启分派：保持 import（不扩 mode、不扩技巧标签）

**现状**：`routes/index.tsx:87-89` `parseImportedText(sd)` → 校验通过 `start({ source: "import", ... })`。

**变更**：
1. **URL 解析兼容**：`?sd=SD{N}:<编码>` 中编码含 `encodeURIComponent`——`decodeURIComponent` 已有（L83-85），扫码 URL 完整解码后 `parseImportedText` 正则正常匹配
2. **不扩 `mode=daily/map`**（v0.1 决策）：每日/地图有 seed 随机性、需当日状态，扫码无法还原完整语境；「扫码直进更深层能力」一期只做「题面直达」
3. **不扩 `s=` 技巧标签**（v0.2 修正，自审发现）：`mapSkillName` 只在 `source === "map"` 时产生（`Practice.tsx:509-514`），扫码直启的题是 `source="import"` 无地图语境；结算层技巧画像由 `analyzeTechniques(start.puzzle)` **引擎实时计算**（`Practice.tsx:519`），不需外部标签——`s=` 参数无消费方，做它纯属增熵
4. **向后兼容**：老二维码（裸协议串）粘贴导入浮层路径不变（`parseImportedText` 正则不变）；新二维码 URL 的 `?sd=` 由 `URLSearchParams` 提取

**最终 scope（v0.2 定稿）**：二维码内容改 URL（扫码即点开直达练习）+ 成绩卡文案更新 + 冒烟兼容断言。**零接口变更**（不碰 StartParams/parseImportedText/路由分派逻辑）。

### 2.3 冒烟/分享测试断言

**新增（v0.3 N2：改 SD9 补真实边界，去 ⑤b 重复）**——smoke.mjs ⑤b 旁：
- `扫码 URL 直启（SD9）`：`?sd=${encodeURIComponent("SD9:<81 数字>")}`（完整 URL 形态）→ 直达练习页（**`count === 81`**，SD9 棋盘）——SD9 是 URL 最长场景，触发 v9-v10 QR 边界 + 长解析路径
- `扫码 URL 后 query 清除`：直启后 `sd=` 已删（既有 L183 断言模式，SD9 场景覆盖）

**必须更新（v0.3 B2）**：`share.mjs` 读 `data-qr-text`（调试钩子，验证「画进 QR 的内容」）——URL 化后现有断言必 FAIL：
- L94 `/^SD4:[0-9.]+$/` → URL 形态正则 `^https?:\/\/.+\?sd=SD4%3A[0-9.,%]+$`
- L95 `length === 20` → 删除（URL 长度随 origin 变）或改「> 裸协议长度」下界
- L96 `qrText.slice(4) === toSDString(...)` → 从 URL 解析 `?sd=` 再比盘面（`new URL(qrText).searchParams.get("sd")`）
- **验证计划新增 `pnpm test:share`**（不能只验 smoke）
