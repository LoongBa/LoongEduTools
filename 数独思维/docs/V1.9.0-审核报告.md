## 三、变更摘要

- **扫码直进**：二维码内容从裸协议串 `SD{N}:<sd>` → 完整 URL（`{origin}{pathname}/?sd=SD{N}:<sd>`）——扫码即点开直达练习，无需复制粘贴；复制文本仍裸协议（粘贴路径不变）
- **B1 子路径修复**：`sdUrl` 用 `URL(window.location.href)`（含 pathname）——vite `base: "/shudu/"` 在线部署下二维码指向正确应用页（非站根）
- **QR 容量如实**：byte 模式 + `qrcode(0,"L")` 自动选版，SD9 URL ~113-127B → v9-v10，模块 ~3-4px 仍可扫（实测 share 8/8 含 4×4 URL 绘制无错）

## 五、代码自审发现（实施级）

1. **SD9 直启首轮 2 FAIL 根因**：smoke.mjs 里我随手写的 81 数字非合法唯一解盘（parseImportedText 拒绝 → 停留首页）——「9×9」文本误匹配首页难度选项导致「直达」假 PASS。**修复**：用引擎 `generatePuzzle(9,27,seed)` 生成合法题面（实测 `{puzzle, solution}` 对象结构），替换后 47/47。
2. **`qrText` 依赖注入**：ShareResultOverlay 的 useEffect 原依赖数组（L318）不含新 `qrText`——补依赖防闭包过期（绘制用最新 URL）。
3. **share.mjs 断言语义变化**：原「长度=20」断言删除（URL 长度随 origin 变）；改「解码后协议串与盘面一致」（`new URL(qrText).searchParams.get("sd")`）——语义更强（验证编码往返）。
4. **smoke 变量改名**：⑤b 原 `sdUrl` 变量名与 copy.ts 新函数同名冲突（不同作用域无碍），为清晰改名 `encSd4`。
5. **未引入的改动**：`parseImportedText` 正则不变（老裸协议串粘贴路径零回归）；`IMPORT_PROMPT_LABEL` 复制文本保留裸协议（粘贴导入路径不变）。
