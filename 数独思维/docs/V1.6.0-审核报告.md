## 三、变更摘要

1. **`onLessonKey` 回调**（N1 改名）：Practice Props 新增可选 `(lessonKey: string) => void`，index.tsx 传 `openSkill`（签名兼容，`TECHNIQUE_LESSON_MAP` 值域 ⊂ ALL_SKILLS，`openSkill` 内置 `if (!s) return` 防户）。换轨语义：跳教学关后 Practice 卸载，学完回首页，不返回结算层（N3 注明）。
2. **`SkillSuggestions` 组件**（Practice.tsx 内联，紧耦合范式）：
   - 空画像 → null（纯观察盘无建议，对齐 StepReview「没有可拆解」口径）；
   - 标题 + 技巧 chips（`TECH_TONE_BASE` 色带）+ 每技巧教学关复习按钮；
   - **I1**：`TECH_TONE_BASE` 扩展含 `隐性数对: "adv"`（StepReview TECH_TONE 缺此映射，V1.5.0 遗留）+ 显性数对/X-Wing 防御兜底；
   - **I2**：`TECHNIQUE_LESSON_MAP[t]` undefined 防户（当前画像 5 种全映射，纯冗余防御防 findLogicStep 未来扩展）；
   - **I3**：色带（中文名→色，`唯一候选`→base 是与 tier 不一致的既有设计）与点亮判定（store 双查 skills/advSkills）显式正交；
   - **I4**：诚实限定文案「按标准推理链整理，未必和你当时的思路完全一致」（对齐 StepReview L138）。
3. **`settlementTech` memo**：`useMemo(() => finished ? analyzeTechniques(start.puzzle, size) : [], [finished, start.puzzle, size])`——finished 前零开销，finished 后一次（techniqueCache 兜底，无主线程卡顿风险）。
4. **版本**：package.json 1.6.0 + AGENTS.md「当前 V1.6.0」同步（唯一权威字段）。

## 五、审核发现（Sisyphus 逐行核对）

- **A1（import 序）**：`import { HINT_LIMIT, LEVEL_GIVEN, MAP_LEVELS, skillByKey, TECHNIQUE_LESSON_MAP }` 追加式 import，风格一致，无未使用告警。
- **A2（空安全链）**：`hasLesson = !!lessonKey && !!onLessonKey` 短路——`onClick={() => onLessonKey!(lessonKey!)}` 的非空断言仅在两条件均真时执行，TS 编译期内安全（typecheck 0 佐证）；`onLessonKey` 未传时区块降级为只读 chips（手动验证 ④ 的 `!hasLesson` 分支等价路径覆盖）。
- **A3（性能）**：`settlementTech` 依赖 `[finished, start.puzzle, size]`——`start.puzzle` 稳定（`initial` useMemo 一次产出），finished 切 true 仅算一次；9×9 最坏同步 ~ms 级（analyzeTechniques 有 techniqueCache，V1.5.0 A3 评估过）。
- **A4（样式一致性）**：色带复用 badge-* token（base/adv/ach）与 StepReview 徽章墙同语系；区块 `bg-secondary/50` 与结算层既有卡片（连做进度条、建议卡）视觉统一；`ml-auto shrink-0` 按钮防窄屏挤压。
- **A5（组内/连做兼容）**：SkillSuggestions 与连做进度条（group 区块）、E5 降档建议（suggestion）顺序：连做进度条 → ResultSummary → **SkillSuggestions** → suggestion——信息层级合理（进度 → 成绩 → 学习建议 → 难度建议），互不干扰。

**阻断项：0｜改进项：0｜观察记录：5（A1-A5，均通过/可接受）**
