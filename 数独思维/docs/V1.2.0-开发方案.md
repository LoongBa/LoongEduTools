# 数独思维（React 版）V1.2.0 开发方案（v0.2，已按 oracle 评审修订）

> 项目：`数独思维/src`（Vite + React 19 + TS，单路由视图状态机）
> 版本规则：微调（bug fix / 样式 / 文案）→ patch（升子版本号，自主）；较大调整（新功能 / 交互改进）→ minor（升次版本号）
> 本方案遵循 `数独思维/src/AGENTS.md` 迭代流程：开发方案 → oracle 评审 → 实施 → 验证 → 亲自审核代码 → 审核报告 → 提交发布
>
> **评审记录（v0.1 → v0.2）**：oracle 审核「2 阻断 B1-B2 + 5 建议 I1-I5 + 4 说明 N1-N4」。已修订：
> - B1：**validateBackup 补元素形状校验**——BookItem（mistakes/favorites）元素须含 `board: Array` + `solution: Array`；`cur` 非 null 须含 `puzzle/solution/board: Array` + `notes: object`；history 元素须含 `date: string` + `ms: number`（防外部损坏文件白屏渲染）
> - B2：**importBackup 显式处理 localStorage 配额异常**——try/catch `setItem` 的 `QuotaExceededError`，失败返回人类可读 reason（"存储空间不足…"），Settings Toast 提示，**不 reload**（setItem 原子，旧数据安全保留）
> - I1：恢复反馈——reload 前 `sessionStorage.setItem("shudu.restored", stats)`，Settings 挂载读 flag → 本地 Toast 显示恢复摘要 → 清 flag（tab 级、不污染 URL）
> - I2：恢复 Overlay 明示 cur 快照覆盖（"包括当前正在做的这道题"）；FileReader 用 `readAsText`（自动处理 UTF-8 BOM）；备份/恢复按钮 disabled 防双击
> - I3：测试补充——`data.version: 2` 拒绝 / 空档 round-trip / `stats` 准确性断言 / smoke `setInputFiles` 上传 + 按钮可见
> - I4：iOS Safari `<a download>` 兜底提示文案（"如果没自动保存，长按页面内容选择保存到文件"）；file input `accept=".json"` 单一过滤（以 validateBackup 为守门人）
> - I5：**不拒绝未识别字段**（load() 浅合并保留多余字段无害，拒绝会造成误拒手改 backup）；`__proto__`/`constructor` 键纵深防御（N 级可选，实施时加）
> - N1：scheme/mode 不纳入备份——与 Settings 现有文案「外观选择只影响这台设备，不会同步到任何地方」一致，维持边界
> - N2：minor 定性正确（新功能入口，StoreShape.version 保持 1）
> - N3：无 XSS 面（全站仅 chart.tsx 用 dangerouslySetInnerHTML 且不消费 store 数据；backup 字符串字段经 React 自动转义）
> - N4：大文件无虞（实测 ~300KB 上限，Blob/createObjectURL 零压力）

## 1. 背景与现状问题

| 编号 | 优先级 | 问题 | 代码位置 |
|---|---|---|---|
| P0 | 高 | **换设备 / 清除浏览器数据即丢全部进度**：设置页「本机数据」卡明确写着「换设备或清除浏览器数据会丢失进度，请先用『分享成绩』留存」——但分享成绩只留一题，非全量进度。错题本、收藏、成就、打卡、训练地图、最佳成绩全部无法跨设备迁移 | `store.tsx`（KEY=`redtools.shudu.v1`）、`Settings.tsx`「💾 本机数据」卡 |
| P1 | 低 | **无任何导出/导入机制**：数据完全封闭在浏览器 localStorage，无文件级备份入口 | `store.tsx` `save/load` |

## 2. 目标与原则

- **目标**：新增「备份到文件 / 从文件恢复」：导出当前全量存档为单个 `.json` 文件（含全部学习进度；外观偏好 scheme/mode 不纳入——本机偏好，跨设备重选），换设备/换浏览器通过导入文件完整迁移；导入前强校验文件结构与元素形状，防损坏/伪造数据白屏。
- **原则**：纯离线（文件下载/上传，零网络）；复用 `StoreShape.version` 做格式校验锚点；导出文件含元信息（创建时间、应用版本、记录数）便于人工辨识；恢复是破坏性操作 → Overlay 两级确认 + 明示断点快照也会被替换；措辞「备份/恢复」教学与训练语系，无游戏化。

## 3. 变更设计

### 3.1 备份导出（P0/P1）

- 新增 `src/lib/backup.ts`（纯工具，零 UI 依赖）：
  ```ts
  export const BACKUP_PREFIX = "数独思维-备份";
  export interface BackupFile { format: "sudoku-tutor-backup"; v: 1; appVersion: string; createdAt: string; stats: { history: number; mistakes: number; favorites: number; achievements: number; checkinDays: number }; data: StoreShape }
  export function buildBackup(store: StoreShape, appVersion: string): BackupFile
  export type ValidateResult = { ok: true; file: BackupFile } | { ok: false; reason: string }
  export function validateBackup(raw: unknown): ValidateResult
  export function downloadBackup(file: BackupFile): void
  export function importBackup(file: BackupFile, onOk: (stats) => void): { ok: boolean; reason?: string }
  ```
- `buildBackup`：`data` = 深拷贝 store；`stats` 摘要（数组实际长度，I3 断言准确性）。
- `validateBackup`（**B1 强校验**）：
  1. `format === "sudoku-tutor-backup"` 且 `v === 1`
  2. `data` 为对象且 `data.version === 1`
  3. 顶层关键字段类型：`history/mistakes/favorites` 为数组、`settings` 对象、`cur` 为 null 或对象、`best/recent/skills/advSkills/achievements` 对象
  4. **元素形状（B1 新增）**：mistakes/favorites 每个元素是对象且含 `board: Array` + `solution: Array`；history 元素含 `date: string` + `ms: number`；`cur` 非 null 时含 `puzzle/solution/board: Array` + `notes: object`
  5. 拒绝 `__proto__`/`constructor` 键（纵深防御，I5）
  6. **不拒绝未识别字段**（I5：load() 浅合并保留无害）
  7. 返回人类可读 reason（用于 UI 提示）
- `downloadBackup`：`Blob`（`type: application/json`，UTF-8）+ `URL.createObjectURL` + 临时 `<a download>` 点击 + 撤销 URL。iOS Safari download 属性不可靠 → 调用方补兜底提示（I4）。

### 3.2 恢复导入（P0/P1 / B2 / I1 / I2）

- `importBackup(file, onOk)`：
  1. `validateBackup(file)` 通过（在调用方已校验，此处兜底再验）
  2. **try/catch `localStorage.setItem(KEY, JSON.stringify(file.data))`**（B2）：`QuotaExceededError` → 返回 `{ ok:false, reason:"存储空间不足，请先清理浏览器数据后重试。" }`，**不 reload**，旧数据安全保留
  3. 成功 → `onOk(file.stats)`（I1：内部 `sessionStorage.setItem("shudu.restored", JSON.stringify(stats))`）→ `window.location.reload()`
- `Settings.tsx`「💾 本机数据」卡：
  - 「📤 备份到文件」按钮：`downloadBackup(buildBackup(store, APP_VERSION))` + Toast「已生成备份文件」+ iOS 兜底提示文案（I4）+ 点击瞬间 disabled 防双击（I2）
  - 「📥 从文件恢复」按钮：隐藏 `<input type="file" accept=".json">`（label 触发，I4 放宽过滤，validateBackup 守门）→ `FileReader.readAsText`（I2，自动处理 BOM）→ `validateBackup`：
    - 通过 → **Overlay 确认**（显示 stats 摘要 + 「恢复将覆盖当前全部进度，**包括当前正在做的这道题**，确定？」（I2））→ 确认后 `importBackup` + reload
    - 失败 → Toast 展示 `reason`（不执行任何写入）
  - Settings 挂载 useEffect 读 `sessionStorage "shudu.restored"` → 有则本地 Toast 显示恢复摘要（I1）→ 清除 flag
