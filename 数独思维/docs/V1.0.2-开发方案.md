> 本方案遵循 RedTools AGENTS.md §6A 迭代流程：方案 → oracle 审核 → 实施 → 验证 → 代码审核 → 审核报告 → 提交发布

> **评审记录（v0.1 → v0.2）**：oracle 审核结论「整体可行，2 阻断 B1/B2 + 5 建议 I1-I5 + 3 说明」。已修订：

## 2. 目标与原则

- **目标**：分享题浮层补真二维码（复用 `drawRealQr` + `qrcode.js`，内容与成绩卡一致）；选中格加瞬时闪光。
- **原则**：纯本地无网络；措辞「教学与训练」语系；最小化修改（Share.tsx / Board.tsx / Practice.tsx / styles.css / tests/smoke.mjs）；二维码不编码答案。

## 3. 变更设计

### 3.1 SharePuzzleOverlay 补真二维码（P1）——同一 canvas 绘制（B1 修订）

**实现方式**：沿用成绩卡模式，二维码画在**现有题面 canvas 的同一 ctx**上（不新增 DOM canvas 元素）。调用已有 `drawRealQr(ctx, text, x, y, size, dark, light)`（Share.tsx L62 附近）。

**canvas 布局坐标表（B2 修订）**：
- 现：`cv.width = 720`；`cv.height = 720 + 120 + tagH`（tagH = skillName ? 46 : 0）
- 新：`cv.height = 720 + 120 + tagH + 240`（二维码区 200×200 + 上下各 20 静区边距 + 40 间隔）
- 绘制坐标：
  - 标题 (40, 34) 不变；技巧标签行 (40, 70) 不变
  - 题面 `drawBoard(ctx, ..., 40, 90 + tagH, 640, ...)` 不变
  - 二维码：`drawRealQr(ctx, qrText, (720 - 200) / 2, 90 + tagH + 640 + 20, 200, dark, light)`（题面下方居中）
  - 底部提示文案 y 坐标从原 760 下移至 `90 + tagH + 640 + 240 + 8` 附近
- `aspectRatio` 样式同步：`(720) / (720 + 120 + tagH + 240)`（Share.tsx canvas style L168 附近）

**二维码内容（I1 修订）**：与成绩卡短版一致，不含提示行/技巧标签行：
```
数独思维 · {size}×{size} 练习题\n题目编码：{toSDString(board, size)}
```
（注：`board` = 当前盘面，与 textarea 一致；不含答案版——切换"看答案"不改变码，防扫码泄漏答案，与老版本一致）

**文案**：底部补「📱 二维码扫码复制题目编码，在「导入题目」粘贴即可练习」。

**不改**：textarea 全文（复制用）、题面/答案切换按钮、ShareResultOverlay。

**涉及文件**：`src/components/Share.tsx`（SharePuzzleOverlay 内 canvas 尺寸/坐标/文案 + 复用 drawRealQr）。

### 3.2 选中格瞬时闪光（P2）——叠加 span + `selCell` 瞬时 prop（I2 修订）

- `Board.tsx`：新增可选 prop `selCell?: number | null`；当 `selCell === i` 时，在 button 内叠加 `<span className="pointer-events-none absolute inset-0 animate-flash-sel" />`（参照现有 `okCell` span 范式，Board L120-123）。`animate-flash-sel` 为轻量脉冲（橙色调，一次 ~300ms）。
- `Practice.tsx`：onPick 里 `setSelected(i)` 后置 300ms 定时器 `setSelCell(null)`（参照 okCell 现有定时器范式 L238-240）；新增 `selCell` state（初始 null）。点同格取消选中时不触发闪光（仅选中路径）。
- `styles.css`：`@theme inline` 增 `--animate-flash-sel: flashSel 0.3s ease-out;` + `@keyframes flashSel`（参照 `flashOk` 写法，用 `--hl-selected` 系色，仅 background 脉冲，不含 transform 位移，避免与 `hl-shape-selected` 冲突）。
- 语义：闪光与选中高亮解耦；重复点同格取消不闪、再选中可靠再闪。

**涉及文件**：`src/components/Board.tsx`、`src/components/Practice.tsx`、`src/styles.css`。

### 3.3 不改动

引擎（sudoku.ts）、存储（store.tsx）、路由（index.tsx）、qrcode.js/d.ts、成绩卡（ShareResultOverlay）、教学关/地图/报告/设置。

## 7. 风险表

| 风险 | 等级 | 缓解 |
|---|---|---|
| 二维码内容含答案泄漏 | 低 | 二维码编码 `board`（当前盘面），切换答案不改变码；与老版本一致 |
| 9×9 长文本二维码模块过小 | 低 | 内容为短版（无提示行），9×9 约 90+ 字符，200×200 区每模块 ~3.5px，可扫（I5） |
| 闪光动画与既有高亮冲突 | 低 | 叠加 span + 独立动画类（无 transform 位移），与 bg-hl-selected 解耦 |
| 冒烟断言依赖实现细节 | 中 | 断言按 B1/I3 明确路径（canvas 尺寸属性 + 瞬时类出现/消失） |
