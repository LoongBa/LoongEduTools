## 三、变更摘要

- **轮换算法**：`advSkillsFor(dateStr)` 纯日期驱动（零存储），本地日差口径（基准日 2020-01-01 + Math.round，与 `dailyFor` 本地周几同口径，I1）。步长 5 与 12 互质 → 同日不重复、相邻天组合恒不同、12 天周期内任意两天组合唯一、i1/i2 各自遍历全部 12 个。
- **首页 UI**：③「学习与技巧」区基础技巧 grid 下新增「✨ 进阶技巧 · 今日 2 个」区块——标题行右对齐「全部 12 个 ›」跳转 skillwall（N4）；2 卡片与基础技巧同形态（emoji/名/`🎯 grade 适龄`/brief），徽章底色 `bg-badge-adv/15`，点亮判定 `store.advSkills`（进阶墙同源），点击 `props.onLesson` 进教学关。**不新增独立 hint 行**（SectionGroup 已有「先看懂再动手」，I4）；**grade 显式标注**做龄段预期管理（I2）。
- **测试**：engine 6 断言精确化（N1：12 天 i1 集合=12 个；N2：固定日期对不依赖运行时）；smoke ⑩ 段 Node 侧 import `advSkillsFor` 计算期望名、浏览器侧断言渲染（N3 同源码确定性一致）、断言前等待 reveal 动画（I3）。
- **响应遗留**：V1.5.0 触达率遗留（进阶技巧在首页零露头）——12 个进阶技巧现按天轮换触达，教学关入口每日更新。

## 四、自审意见处置

| 意见 | 结论 | 处置 |
|---|---|---|
| Oracle I1 算法 epoch 口径 | 采纳 | 本地日差口径，与 dailyFor 同口径；两本地午夜差恒为 86400000 整数倍，Math.round 精确 |
| Oracle I2 混龄展示 | 采纳 | grade 显式标注（`🎯 K4-6 适龄`），诚实龄段预期管理，保算法零存储简洁 |
| Oracle I3 smoke flaky | 采纳 | 断言前 waitForTimeout(700) 等待 reveal 动画 |
| Oracle I4 嵌套 hint | 采纳 | 去独立 hint 行，仅区块标题 |
| Oracle N1-N4 | 全采纳 | 断言精确化/固定日期对/同源厘清/「全部 12 个 ›」跳转 |
| 自审：smoke ⑩ 段首版误点「规则教学」 | 修正 | 上段已回首页，改直接等待动画后断言（避免离开首页） |
| 自审：todayStr 需 import store.tsx（.tsx Node 直跑风险） | 修正 | smoke 内联本地日期构造（`d0.getFullYear()/getMonth()/getDate()`），避免 import .tsx |
