## 3. 变更摘要（与方案 §3 对照）

- **协议串**：二维码内容由「中文标题 + 题目编码」改为纯 `SD{N}:<sd>`（ASCII 短码）；复制文本增「导入编码：SD{N}:<sd>」行。修复 P0 隐性 bug：老文本无前缀路径会把标题 `4×4` 数字混入 sd 导致长度判规格失败 → 闭环断裂；现在 `SD{N}:` 前缀行被导入分支 ① 正则优先捕获，标题不再污染。
- **解析下沉**：`parseImportedText(text): {size, board, error, cleanLen}`——分支 ① SD 前缀、分支 ② 纯数字 16/36/81；`finishParse` 统一 clean=保留 `[0-9.]`（. 与 0 均空）剥离 `[,\s]` → 长度校验 → fromSDString → validateImported。组件仅 `useMemo` 调用。
- **错误码化**：`validateImported` 由传中文 message 改传 `ImportError` 联合类型；文案映射收口 `copy.ts importMsg`（动态拼接 BAD_LEN 的规格数 / TOO_FEW 的 MIN_GIVENS）。
- **规范串收敛**：`PRIVACY_BADGE` 单点维护，footer（index.tsx）+ about（Settings.tsx）引用；Report/MapView 教学散文按 oracle I6 保留原文未动。
- **测试钩子**：SharePuzzleOverlay 与 ShareResultOverlay 的 canvas 均加 `data-qr-text`（生产无副作用），share.mjs 三规格语义可断言。

## 7. 发行说明（供发布引用）

- **修复**：「分享这道题」复制/二维码内容无法直接导入练习（标题 `4×4` 数字污染编码长度导致判规格失败）——粘贴即识别、校验通过即可开始。
- **编码协议**：二维码/导入编码统一为 `SD{N}:<编码>`（ASCII 短码，识别更稳，可打印更清晰）。
- **内聚**：隐私规范串「无账号 · 无云同步 · 无排行 · 数据只存本机」收敛为共享常量，首页/设置页同源。
- **测试**：引擎单测 + 冒烟扩展至 22 项 + 分享题专项 9 项（含协议串 round-trip 与二维码内容断言）。
