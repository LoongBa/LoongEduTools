## 3. 变更摘要（与方案 v0.2 对照）

- **URL 直启**（P0/B1/I1/I2/I4）：`?sd=SD{N}:<编码>` → 首帧单次 useEffect（ref 守卫防 StrictMode 双调用）→ `decodeURIComponent`（防分享渠道百分号编码截断正则）→ `parseImportedText` 白名单校验 → 通过 `start({ size, level:"normal", source:"import", board, solution })`；URL 参数用 URL API `searchParams.delete("sd")` 清理（兼容 sd 非首参的多参链接）。失败 `showToast(importMsg(parsed))`（复用 copy.ts 文案，不内联）。
- **剪贴板显式粘贴**（P1/B3）：按钮触发 `navigator.clipboard.readText()`（用户手势，权限弹窗预期内）；命中 `/SD(4|6|9)\s*:/` 才 `setText`；未命中/异常 → 文案提示手动粘贴（两个常量收口 copy.ts）。无自动读取（B3 采纳）。
- **引擎返回 solution**（I3）：`validateImported` 在唯一解校验时（`solve(…,2)` 已算出 sols）顺带返回 `sols[0]`，`finishParse` 透传至 `ParseResult.solution`，直启与手动导入直接消费，**9×9 由 3 次回溯降为 1 次**；`index.tsx` 的 `solveSolution` 删除（不再需要）。
- **版本定性**（B1）：交互改进 → minor，**V1.1.0**（方案/package/AGENTS/测试同步）。

## 4. 审核发现与处置

| # | 级别 | 发现 | 处置 |
|---|---|---|---|
| A1 | 中 | 首版 `replaceState` 用正则 `/[?&]sd=[^&]*/g` 删参：当 sd 非首个 query 参数时（如 `?a=1&sd=2`），正则会只剩 `a=1` 前缀、产生 `pathname+&a=1` 畸形 URL | 改用 `new URL(href)` + `searchParams.delete("sd")` + 拼接 `pathname+search+hash`（审核时修复，重跑 typecheck + 冒烟全过） |
| A2 | 低 | smoke 用例增补过度：⑤b/⑤c 先导航直接断言，其中 ⑤d「query 已清除」初版误放失败路径之后（失败路径保留参数是正确行为，断言错误报 FAIL） | 重排断言：成功路径（⑤b2）紧接 `url 不含 sd=`；失败路径（⑤c3）改断言「保留参数供检查」；全部 PASS 29/29 |
| A3 | 低 | ImportRules 空态提示区改动后，原「正在识别…」分支移除（text 非空必有 importMsg），语义等价 | 确认无行为回归（冒烟 ⑤ 段全过） |
| A4 | 观察 | `decodeURIComponent` 二次解码在 URLSearchParams 已解码场景下近乎幂等，但对分享渠道双重编码（`%253A`）有兜底价值 | 保留（oracle I1 明确要求），try/catch 包裹防非合法编码崩溃 |

oracle 意见落实复核：B1（minor 定性 ✓）/ B2（风险表边界声明 ✓ 未 URL 化二维码）/ B3（显式按钮 ✓）/ I1（decode ✓）/ I2（ref 守卫 ✓）/ I3（solution 透传 ✓）/ I4（importMsg 复用 ✓）/ I5（测试 +4 ✓）。

## 7. 发行说明（供发布引用）

- **新交互**：支持 `?sd=SD{N}:<编码>` 链接/书签/二维码 URL 直启——打开即进入该题练习，无需手动导入。
- **导入增强**：导入浮层新增「📋 从剪贴板粘贴」一键识别（复制过分享文本后直接粘入，未识别/无权限时文字提示手动粘贴）。
- **性能**：导入/直启路径由「校验 + 二次求解」合并为一次校验顺带取解（9×9 明显提速）。
- **测试**：冒烟扩至 29 项（URL 直启成败两态、query 清理、剪贴板按钮）+ 引擎 solution 断言，0 JS 错误。
