## 五、审核发现（Sisyphus 逐行核对）

- **A1（语义一致性）**：徽章「第 x/n 题」（正在做语境）与结算层「已完成 x/n · 还剩 m 道」（完成语境）同值不同义、不同屏可见——结算 Overlay 为全屏 `fixed inset-0`（Shell.tsx z-[75]），练习中徽章与结算进度**不会同时可见**，无冗余冲突。oracle 复核确认。
- **A2（idx 边界不变量）**：`handlePracticeFinish` 的 `next < list.length` 守卫保证练习渲染期 `params.group.idx ∈ [0, total-1]`，徽章永不出现「第 n+1/n 题」；`total ≥ 2`（守卫）→ 最小「第 1/2 题」，无「第 1/1 题」怪文案。
- **A3（窄屏布局）**：标题区 `min-w-0 flex-1`（truncate 自动压缩）+ 徽章/计时 `shrink-0` → 320px 窄屏不换行、标题可压缩；徽章文本最长「第 10/10 题」≈6 字符，与计时对称。
- **A4（类型安全）**：`params.group && params.group.total > 1` 真值分支 TS 窄化 `params.group` 非空，`params.group.idx` 无 `!` 断言、无 `as`——typecheck 0 佐证。
- **A5（改动最小化）**：产品代码净增 7 行（import 1 + JSX 6）+ copy 常量 1 行；index.tsx/引擎/测试零改动——符合「按方案最小化修改，不借机重构」。
