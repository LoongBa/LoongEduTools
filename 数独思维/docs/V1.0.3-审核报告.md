## 3. 变更摘要

1. **版本权威字段修复（B1）**：package.json version 1.0.1 → 1.0.3（V1.0.2 发布时漏回写，本次补正并升至当前）；AGENTS.md「当前版本」行同步 V1.0.3（版本权威文档随发布更新，杜绝双源漂移）。
2. **版本号显示（I1）**：新增 `src/lib/version.ts` 集中导出 `APP_VERSION`（唯一来源 package.json）；设置页关于区 `版本 V1.0.3` 独立行；首页 footer `数独思维 · 版本 V1.0.3` 小字行。
3. **隐私声明规范串（I2）**：定规范串 `无账号 · 无云同步 · 无排行 · 数据只存本机`（覆盖数据本地化 + 去游戏化，与 AGENTS.md「无排行」一致）；首页 footer 与设置页关于区**同串复用**；Report/MapView 既有文案留后续统一。
4. **测试强化（I3）**：冒烟 VERSION 动态读取 package.json（杜绝硬编码失效）；新增 2 断言（设置页 `版本 V${VERSION}` / 首页 footer 规范串）。
