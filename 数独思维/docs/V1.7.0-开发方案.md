## 一、背景与现状问题

| # | 问题 | 代码位置 |
|---|---|---|
| 1 | 同类专项连做（V1.3.0）做完一组后，直接 `setView("mistakes")` + toast「这组练完了，错题本里再挑一组继续」——**孩子看不到本组整体成绩**（共练了几道、对了几道、总用时、各题星级） | `routes/index.tsx:170-173`（`handlePracticeFinish` else 分支） |
| 2 | 组内每题的成绩（ms/errors/hints/stars）只在 `Practice.finishAll` 局部态存在，完成后即丢弃，无累积 | `components/Practice.tsx:375-433` |
| 3 | B5 方向自 V1.6.0 候选未选，现作为 B 类可选功能第一项推进 | 工作清单 B-5 |

**产品价值**：组练习（错题巩固）是目前隐性数对常态化入口之一（V1.5.0 遗留），做完一组的成果反馈能让孩子看到「这组错题巩固得怎么样」——对了几道、哪里还有失误，形成巩固闭环。**措辞去游戏化**：不用「胜利/关卡/得分」，用「完成 x 题 / 对了几道 / 用时」。

## 二、变更设计

### 2.1 接口变更：`Practice.onFinish` 携带成绩（跨文件接口变更 → 重要级）

**现状**（`Practice.tsx:39`）：`onFinish: () => void;`——无参回调。

**变更**：改为 `onFinish: (result: GroupItemResult) => void;`（**非 optional**——两处调用点均传值，TypeScript 强制），其中：

```ts
/** 组内一题的成绩（V1.7.0 B5）：结算 Overlay「下一道/选难度」时回传 */
export interface GroupItemResult {
  stars: number;   // calcStars(hints, errors)：3=0错0提示 / 2=hints≤1&errors≤3 / 1=完成
  ms: number;
  errors: number;
  hints: number;
}
```

- `Practice.tsx` 结算 Overlay 的 `onFinish` 调用点（L655「下一道」/L659「查看打卡日历」）改为 `onFinish({ stars, ms, errors, hints })`
- `index.tsx` 的 `handlePracticeFinish(result: GroupItemResult)` 接收并累积
- **非组模式**：`onFinish` 仍调用，父级忽略 result，行为不变
- **无兜底 `??`**（v0.2 删，I4）：所有路径均有 result，删除死代码

### 2.2 `groupSession` 扩展：累积 results + 记住 gid

**现状**（`index.tsx:62`）：`useState<{ list: BookItem[]; idx: number } | null>(null)`

**变更**：

```ts
interface GroupSession {
  gid: TechniqueGroupId;       // 记住组 id，支持「再练一组」
  list: BookItem[];
  idx: number;
  results: GroupItemResult[];  // 每题成绩累积（组内推进时 push）
}
```

- `startGroupPractice(gid)`（L140）：`setGroupSession({ gid, list: ordered, idx: 0, results: [] })`
- `handlePracticeFinish(result: GroupItemResult)`（L162）：
  ```ts
  if (groupSession) {
    const results = [...groupSession.results, result];
    const next = groupSession.idx + 1;
    if (next < groupSession.list.length) {
      setGroupSession({ ...groupSession, idx: next, results });
      startGroupItem(groupSession.list[next], next, groupSession.list.length);
      return;
    }
    // 组结束（B1 修复）：改 view 卸载 Practice（结算浮层随之消失）+ 开小结浮层
    setGroupSession({ ...groupSession, results });
    setGroupSummaryOpen(true);
    setView("mistakes");
    return;
  }
  setView("home");
  ```
- **`onExit` 清 groupSession（v0.2 新增，I1）**：`onExit={() => { setGroupSession(null); setView("home"); }}`——中途退出（←/返回难度）不留残留，防既有 bug 被 results 累积放大（安全性：小结浮层显示中遮罩全屏，用户点不到 ←，不会误伤）
- **`GROUP_PRACTICE_DONE` 弃用标注（v0.2，N1）**：组结束分支不再 toast，该常量 V1.7.0 后无引用，暂留不删

### 2.3 新组件：`GroupSummaryOverlay`

**文件**：`components/GroupSummary.tsx`（新，~90 行）

**结构**：复用 `Overlay` 壳 + 表格/统计块，展示：

```
🧮 这组练完了
共完成 3 题 · 全对 2 道 · 总用时 4:32

┌─────────┬────────┬──────┐
│  # │ 星级 │ 用时 │ 失误 │
├─────────┼────────┼──────┤
│  1  │ ★★☆ │ 0:58 │  1  │
│  2  │ ★★★ │ 1:12 │  0  │
│  3  │ ★★☆ │ 2:22 │  2  │
└─────────┴────────┴──────┘

[📚 回到错题本]  [🔁 再练一组]  [🏠 回首页]
```

- **全对口径**：`stars === 3`（0 错 0 提示）计为全对；文案「全对 X 道」
- **Footer 三按钮**：
  - 回到错题本 → `setGroupSession(null); setGroupSummaryOpen(false)`（view 已是 `mistakes`）
  - 再练一组 → `setGroupSummaryOpen(false); startGroupPractice(gid)`（重新 shuffle，results 清零；`start` 内部 `setView("practice")`）
  - 回首页 → `setGroupSession(null); setGroupSummaryOpen(false); setView("home")`
- **渲染位置（v0.2 改，B1 修复）**：**顶层浮层**，与 `ImportOverlay`/`RulesTeach`/`ShareResultOverlay` 同层（index.tsx 子视图判断之后），不依赖 `view === "practice"`——组结束时 `setView("mistakes")` 卸载 Practice（结算浮层消失），小结浮层作为唯一浮层显示在 mistakes 视图之上
