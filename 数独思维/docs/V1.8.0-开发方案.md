## 二、变更设计

### 2.1 store 迁移：无上限聚合计数器 `totals`（跨文件接口变更 → 重要级）

**现状**（`store.tsx:62-77`）：`StoreShape` 无累计字段；`history` 上限 30（`Practice.tsx:405-406`）。

**变更**：`StoreShape` 增 `totals` 字段（**无上限**，仅聚合数字，不存明细）：

```ts
/** V1.8.0：累计练习统计（B6）——无上限聚合计数器，history 仅存最近 30 条明细，累计口径靠本字段 */
totals: { count: number; ms: number; errors: number; hints: number; stars: number };
```

- `emptyStore()`（`store.tsx:85-102`）默认 `totals: { count: 0, ms: 0, errors: 0, hints: 0, stars: 0 }`
- `load()`（`store.tsx:104-115`）**显式嵌套合并**（v0.2 I1——对齐 settings/checkin/mapProgress 既有模式，防未来子字段添加时被浅合并吞默认）：
  ```ts
  return { ...emptyStore(), ...parsed, settings: { ...emptyStore().settings, ...(parsed.settings || {}) }, checkin: { ...emptyStore().checkin, ...(parsed.checkin || {}) }, mapProgress: { completed: parsed.mapProgress?.completed || [] }, totals: { ...emptyStore().totals, ...(parsed.totals || {}) }, version: 1 };
  ```
  ——**旧存档无 totals 字段自动回落默认，零迁移代码**
- `finishAll()`（`Practice.tsx:398-420`，`source !== "import"` 分支内）累加：
  ```ts
  d.totals.count += 1;
  d.totals.ms += ms;
  d.totals.errors += errors;
  d.totals.hints += hints;
  d.totals.stars += stars;
  ```
  - 位置：与 `d.history.unshift(...)`（L405）同处——**导入局不计**（与 history/best 同口径）；ms/errors/hints/stars 与 history 记录同一最终值（同步一致）

### 2.2 Report.tsx 新增「累计统计」卡 + 技巧分布图

**变更**：`ParentReport`（`Report.tsx:11-178`）三卡后追加两张卡：

**卡 A：累计练习**（`report-card print-clean`）
```
📈 累计练习
累计完成 N 题 · 总用时 T · 平均星级 Y★
[按难度分布：简单/普通/困难 —— 复用 Dist 组件]
```
- 数据全部派生自 `store.totals`（v0.2 I3 修正 mockup——totals 无独立解出局数，诚实口径不展示该率）：
  - 累计完成 = `totals.count`
  - 总用时 = `formatMs(totals.ms)`
  - 平均星级 = `totals.count ? totals.stars / totals.count : 0`（v0.2 I7 零除保护，对齐 Report.tsx L30 既有模式）
  - 独立解出率**不在此卡**（totals 聚合 hints 总数无法知 hintFree 局数），保留近 30 次窗口口径（`hintFree`，现有成长进度卡文案）
- 按难度分布：从 `history`（30 条窗口）派生 byLevel（复用现有 data.byLevel）——诚实标注窗口
- **注**：诚实口径——不夸大 totals 无法支撑的指标；窗口类指标沿用 history 并在文案说明「近 30 次练习」

**卡 B：技巧分布**（`report-card print-clean`）
```
🧩 待巩固技巧分布
[Pie 图：唯一候选 / 宫内排除 / 行列排除 / 进阶观察]
```
- 数据源：`store.mistakes[].techniques`（上限 50，**当前待巩固弱点的真实分布**）
- 聚合：`groupOfTechniques(m.techniques)` → 按 `TECHNIQUE_GROUPS` 4 组计数（`unique/box/rowcol/adv`；mixed 不入图，v0.2 I4 单独处理）
- **空态双级（v0.2 I4）**：
  - `mistakes.length === 0` → 「错题本是空的，先练习再回来看薄弱点分布」
  - `mistakes.length > 0 但 4 组全 0`（全 mixed）→ 「当前错题暂未识别到具体技巧分类，多练几道再回来看分布」+ 不渲染 ChartContainer
- 渲染：**recharts `PieChart`** 经 `ChartContainer`（`ui/chart.tsx` 首次接线）+ `ChartTooltipContent` + `ChartLegendContent`
  - `ChartConfig` 4 组设 **`color` 单值**（v0.2 N1——CSS var 本身主题感知，`var(--color-badge-*)` 随 8 主题自动切换，无需 theme 双值）
  - **4 组 4 色映射（v0.2 I5）**：唯一候选→`var(--color-badge-base)`、宫内排除→`var(--color-badge-adv)`、行列排除→`var(--color-badge-ach)`、进阶观察→`var(--color-star)`（4 色互不歧义；badge-adv 与 star 色相不同）
  - **尺寸（v0.2 I2）**：ChartContainer 硬编码 `aspect-video`（chart.tsx:51），必须显式覆盖 → `className="h-48 aspect-auto"`（tailwind-merge 冲突移除 aspect-video，防 Pie 方形被压成 16:9）
  - 说明文案：「错题本里待巩固的推理环节分布——点开错题本可按技巧分组复习」（与 Walls.tsx SkillGroups 同源口径）

### 2.3 打印兼容

- 两张新卡均 `print-clean`（家长报告唯一可打印页，打印时保留）
- Pie 图打印：recharts SVG 可打印（无 canvas），`ChartContainer` 无 `aspect-video` 依赖——设固定高度（如 `h-48`）避免打印变形

### 2.4 冒烟断言（smoke.mjs 扩展）

**报告页断言追加 2 条（v0.2 I6 关键修正——必须在注入含 mistakes 的 store 后访问报告页，真正渲染 recharts）**：

在 ⑧ 段（组内推进，已注入 `a2Store` 含 2 条 mistakes）之后追加访问报告页断言：
- `累计统计卡渲染`：`vis(page, "累计练习")`
- `技巧分布卡渲染（含图）`：`vis(page, "待巩固技巧分布")` + **`pageerror` 为空**（recharts 首接的 JS 错误会被现有 pageerror 捕获——这是 recharts 渲染真正被冒烟覆盖的关键）
- 注：⑧ 段结束时 view 在错题本/小结浮层——需先关浮层回首页再进报告；`a2Store.mistakes` 有技巧标签（`唯一候选`），4 组中 unique 非 0 → Pie 有切片渲染，非空态

**放置调整**：原 v0.1 计划把断言放 ⑦ 段（早段，mistakes 为空）→ 改放 ⑧ 段后（v0.2 I6），否则 recharts 永不渲染、接线错误检测不到。
