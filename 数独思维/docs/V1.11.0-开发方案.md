# V1.11.0 开发方案 — 练习容错模式（三次引导 / 自由试错）

> 版本：v1.0（2026-09-29）｜ 级别：**重要**（新设置项 + 新交互形态）
> 评审：**用户指定免 Oracle 外审**（2026-09-29，产品哲学取舍由用户拍板——「对教学哲学的影响，需要仔细对比、取舍」后定案；本方案为最终版直接实施，审核流程改为 Sisyphus 自审 + 审核报告）
> 需求来源：用户提出「三次机会，填错了理解减一次」→ 教学哲学对比分析 → 用户确认按护栏细化。

## 一、背景与哲学结论（定案依据）

**用户诉求**：现有练习「填错不提示」（非冲突错填静默落子）——孩子可能盲目乱填无介入；能否切「三次机会，填错扣一」？

**教学哲学对比结论**（依据《教育工具产品指导原则.md》+ 代码事实）：

| 支柱 | 原则 | 对本设计的影响 |
|---|---|---|
| 练习≠游戏（§一） | 有标准答案判定 vs 表现性挑战 | 「机会用尽=终止/判负」是红灯（=扫雷「踩雷=输」，§二明确改造成「踩雷不判负、显示推理依据」） |
| 无胜负无惩罚（§4.1） | 无「游戏结束」 | 用尽≠失败惩罚；用尽=教学介入触发器 |
| 不剧透（数独自身） | 填错不显正解、提示不替填 | 暗计数（知道这格错≠知道答案）；复盘只给推理链不给答案 |
| 错误是学习素材 | 错题本闭环 | strict3 局 errors 照旧入册（支柱④不变） |
| 个体差异 | — | **双模式可切换**（默认自由试错）＝因材施教策略选择，非游戏化妥协 |

**定案护栏**（用户拍板）：
1. 双模式开关，**默认保持现状**（free），家长按孩子特质开启 strict3；
2. **无惩罚**：3 次用尽 → 询问是否需要提示 → 提示耗尽 → 安慰、鼓励 → 进入复盘（不复位、不判负、不降星惩罚）；
3. **暗计数**：strict3 填错仅消耗机会配额 + 温和提示「再想想」，**不显示正解**；
4. **去游戏化**：措辞全走教学语系（「大胆试错」「引导」），机会指示用低调静态样式，不做红色心跳 UI；
5. **范围**：仅首次解题（free/daily/map/import）；replay 重练（已有掌握即清机制）与教学关（无 errors 概念）不适用。

## 二、变更设计

### 2.1 设置项（`src/lib/store.tsx`）

```ts
settings: { sound: boolean; errorMode: "free" | "strict3" };  // 默认 "free"
```
- `emptyStore()` 默认 `errorMode: "free"`；`load()` 嵌套合并已支持新子字段回落默认（无需迁移）。
- 断点快照**不加字段**：机会 = `3 - errors` 派生（strict3 局每次判错 errors+1），恢复后自然续接；旧快照 errors≥3 属 free 遗留，恢复进 strict3 局机会已尽 → 直接进入宽容态（不崩）。

### 2.2 fill 判定（`src/components/Practice.tsx`）

strict3 局（`mode === "strict3"`）填数判定链：

```
① 冲突（同行/列/宫撞车）→ 现状行为（红闪+文案+errors+1）→ 机会-1
② 非冲突但 nb[i] ≠ solution[i]（暗计数，不剧透）→ 本格红闪 + 「再想想」文案 + errors+1 → 机会-1
   —— 错误数字留在盘上可覆盖（与现状一致），不显示正解
③ 正确 → 绿闪 + ok 音 + checkComplete（现状）
```
- onlyErrors guard：**3 次用尽后进入宽容态** —— errors 不再 +1、不再重复弹询问；反馈回到 free 行为（冲突红闪文案、非冲突静默）。
- 用尽触发（`errors === 3` 且 strict3 且未处理过）→ 弹「三出口」询问 Overlay（仅一次）。

### 2.3 三出口询问（用尽后，copy.ts 文案 + Overlay）

标题：「已经大胆试错 3 次啦」｜正文：「这一次先别急着填，我们一起来看看。」三个出口：

| 出口 | 行为 |
|---|---|
| 🔍 需要提示 | 调 `useHint()`；若提示已耗尽（`hints >= HINT_LIMIT`）→ Overlay 切换为安慰鼓励文案（「提示也用完了没关系——重要的是学会怎么推，我们一起看这一步。」）+ 「带我复盘」按钮 |
| 🤔 再自己想想 | 关闭 → 宽容态继续练习（不打扰） |
| 🎯 带我复盘这一步 | `setReview(true)` 打开「推理步骤回顾」（StepReview）浮层 |

### 2.4 机会指示（Practice 顶栏 meta，低调静态）

- strict3 局显示小字「大胆试错剩 N 次」（N=1/2/3；0 → 「已用尽，可求提示或复盘」）；
- 样式：text-muted 小字（**不红不闪**，去游戏化感知）；free 局不显示。

### 2.5 设置页（`src/components/Settings.tsx` 练习偏好卡）

「练习容错模式」radio 两项：
- 「自由试错（默认）」：desc「和孩子平时一样，放心大胆地试。」
- 「三次引导」：desc「填错 3 次后，陪孩子提示或复盘这一步。」

### 2.6 文案（`src/lib/copy.ts`，全走教学语系，红线自检：无「游戏/一局/玩家/通关」✓）


## 三、验证计划

1. `pnpm typecheck` 0 错误。
2. `pnpm build` 通过。
3. `pnpm test:engine` / `pnpm test:backup` 回归（引擎/备份未动）。
4. `pnpm test` 冒烟全过 + 新增 strict3 流程断言：
   - 设置页「三次引导」选项可见 → 开启；
   - 自由练习（注入 fixture 盘）填错 3 次（含非冲突错填）→ 「三出口」询问出现（标题/三按钮可见）；
   - 「再自己想想」→ 第 4 次错不重复弹窗（宽容态）且「大胆试错」指示为已用尽；
   - 「带我复盘这一步」→ StepReview 浮层出现。
5. 亲自审核代码 + 审核报告（`docs/V1.11.0-审核报告.md`）。

## 四、里程碑验收

- [ ] settings.errorMode 双值 + 默认 free，load 兼容旧档

## 六、风险表

| 风险 | 等级 | 缓解 |
|---|---|---|
| 答案比对引入轻微剧透（知道该格错） | 低 | 暗计数不显正解；复盘只给推理链（StepReview 现成）；「再想想」措辞温和 |
| 谨慎型孩子被机会数字抑制 | 中 | 默认 free 不开启；strict3 由家长按孩子特质选择（个体差异护栏）；指示低调静态 |
| 用尽后弹窗打断探索 | 低 | 「再自己想想」出口保全自主权；宽容态后零打扰 |
| 断点恢复机会派生误差 | 低 | 机会=3-errors 派生，无状态漂移；旧快照 errors≥3 → 机会已尽直接宽容态（不崩） |
| settings 扩展迁移 | 低 | load 嵌套合并回落默认（store.tsx:114 已支持） |
