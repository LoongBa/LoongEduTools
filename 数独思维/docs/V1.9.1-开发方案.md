# V1.9.1 开发方案 — B9 备份提醒

> 版本：v0.1（2026-09-29）｜ 级别：**常规**（单模块增强、无跨文件接口变更、无架构决策，按仓库根 AGENTS.md 分级不交 Oracle）｜ 状态：已实施

## 一、背景与现状问题

V1.2.0 已实现「备份到文件 / 从文件恢复」（`backup.ts` + 设置页数据卡）。V1.2.0 审核报告遗留可选增强：「自动定时提醒备份（避免依赖手动，但会增加打扰，保持手动最简）」。

**问题**：备份入口仅在设置页数据卡，且无「上次备份时间」提示——用户换了设备或浏览器数据被清空后才想起没备份，进度无法找回。

**目标**：零打扰的备份提醒——只在设置页内联展示「上次备份时间」状态；距上次备份 ≥ 14 天（或从未备份但已有数据）时显示一行建议文案。不弹窗、不打断、不推首页。

## 二、变更设计

### 2.1 备份时间戳（`src/lib/backup.ts`）

新增单独 localStorage 键 `redtools.shudu.backupAt`（本机行为，**不随 store 备份/恢复**——避免备份文件自指与跨设备误同步）：

- `saveBackupAt(ts)`：写入时间戳（try/catch 静默）。
- `readBackupAt()`：读取并校验（非数字/非法返回 null）。
- `clearBackupAt()`：清除（清除进度时调用）。

### 2.2 设置页数据卡（`src/components/Settings.tsx`）

- 挂载时 `readBackupAt()` 初始化 `lastBackup` state。
- 「本机数据」卡 ul 新增常驻状态行：`· 上次备份：今天 / N 天前 / 从未备份`。
- 提示行（仅超期显示，warning 色，不打扰）：
  - 从未备份 **且** 已有数据（history/mistakes/favorites 任一非空）→ `还没备份过，建议先备份一份——换设备或清除浏览器数据时进度不丢。`
  - 距上次备份 ≥ 14 天 → `距上次备份已 N 天，建议先备份一份。`
- 写点：
  - `onBackup()` 成功 → `saveBackupAt(Date.now())` + 更新 state（备份即清零提醒）。
  - `onRestore()` 成功 → `saveBackupAt(备份文件 createdAt 时间戳)`（恢复后的数据 = 备份文件快照，「上次备份」时点即该文件创建时刻，诚实一致）。
  - 「清除全部进度」确认 → `clearBackupAt()`（数据已清，提醒无意义）。

### 2.3 文案（`src/lib/copy.ts`）

```ts
/** 备份提醒（V1.9.1 B9） */
export const BACKUP_LAST_NEVER = "从未备份";
export const BACKUP_LAST = (days: number) => (days === 0 ? "上次备份：今天" : `上次备份：${days} 天前`);
export const BACKUP_NEVER_TIP = "还没备份过，建议先备份一份——换设备或清除浏览器数据时进度不丢。";
export const BACKUP_DUE_TIP = (days: number) => `距上次备份已 ${days} 天，建议先备份一份。`;
```

措辞符合教学与训练语系，无游戏化表述（红线自检 ✓）。

### 2.4 冒烟（`src/tests/smoke.mjs`）

⑧b 段后新增 ⑨ 段（2 项断言 + 2 次注入）：

1. 注入 `backupAt` = 20 天前 → reload → 设置页：断言「上次备份：20 天前」+「距上次备份已 20 天」提示行。
2. 移除 `backupAt`（store 仍为 a2Store，有数据）→ reload → 设置页：断言「还没备份过」提示行。
