## 3. 变更摘要（与方案 v0.2 对照）

- **候选矩阵**（I6）：findLogicStep 入口懒计算 `candCache`，①②③④⑥ 共享，避免 9×9 candidatesFor 重复扫描；基础识别逻辑行为不变（迁移到共享矩阵）。
- **显性数对**（④）：三单元（行/列/宫）遍历，找候选各恰 {a,b} 的两格 → `findSingleAfterExclude` 排除 a,b 后找变单落子（**返回排除后唯一候选值，修复 cand(victim)[0] value bug**）。
- **X-Wing**（⑥，I6）：行向 + 列向对称；数字 v 在两行/两列候选位各恰 2 个且对齐 → `findXWingVictim` 排除矩形顶点格外的落子（同修 value bug）。
- **隐性数对裁剪**（实施决策，记录见 §4）：24000 盘零命中实证 + 单步落子语义结构性限制 → 移除识别器，留 V1.5+。
- **分组折叠**（I3）：TECHNIQUE_GROUPS 增 `adv` 组（显性数对/X-Wing，tier:"adv"）；SkillGroups 默认折叠、展开显示成员技巧 + 复习按钮 + 练这一组。
- **迁移**（I4）：BookItem.migrated14 标记；错题本打开时对 `!techniques || !migrated14` 条目重算写回（防无 adv 技巧旧题每次打开重算——analyzeTechniques 确定性）。
- **命名分离**（B2）：technique 字段存中文名（"显性数对"/"X-Wing"），TECHNIQUE_LESSON_MAP 值存英文 key（nakedPair/xwing）。
- **测试**（B1/I5）：手工构造两夹具盘（X-Wing 盘/显性数对盘，均唯一解）断言识别命中 + 落子合法 + 解完；null 语义；不抢占；命名一致性。

## 4. 实施中决策记录（隐性数对裁剪，oracle I1/I2 收敛）

**背景**：方案 v0.2 计划实现显性数对/隐性数对/X-Wing 三项；隐性数对识别器首版实现后，14000+24000 盘搜索**零命中**。

**根因分析**（实证）：
1. 首版实现「锁定 {a,b} 于两格后，某格候选过滤为仅 a/b 变单」——但 sel 两格必同时含 a、b（spotsA===spotsB），`reduced` 恒 [a,b]（长 2），`reduced.length===1` 数学上永不成立（死分支）。
2. 修正为「锁定后其它数字 v 剔除 sel 后剩 1 位落单」——仍 24000 盘零命中：真实触发条件「数字 {a,b} 候选位重叠于同 2 格」在小学规格盘面（4/6×6，多基础可解）极为稀有。
3. LESSON_DATA.hiddenPair 教学盘是快照（oracle B1 证实整盘无解），不可作测试夹具；标准隐性数对定义（数字候选格 ⊆ sel）亦难构造稳定单步落子测试。

**决策**：移除隐性数对识别器（注释记录原因），本轮交付**显性数对 + X-Wing** 两项已验证触发项。隐性数对与 naked/hidden triple 一并留 V1.5+，转为 analyzeTechniques「模式识别标注」方案（不硬塞单步落子语义）。此决策符合 oracle I1（收敛范围、保交付质量）与 I2（识别器必须定位落子；无唯一落子返回 null）原则。

## 5. 审核发现与处置

| # | 级别 | 发现 | 处置 |
|---|---|---|---|
| A1 | 中 | **findSingleAfterExclude / findXWingVictim 初版返回格索引，调用点用 `cand(victim)[0]` 取 value——错误**（取排除前第 0 候选而非排除后唯一候选）。显性数对盘实测落子错误（idx14=2 应为 3）污染盘面 | 辅助函数改返回 `{index, value}`（value = 排除后唯一候选），调用点直接用；重测两夹具盘全部落子合法且解完 |
| A2 | 低 | `resolvePairCell` 恒返回 -1（标准裸对两格不产生新落子）→ 调用分支死代码 | 删除函数 + 调用分支 + 悬浮注释（保持 findSingleAfterExclude 单一主路径） |
| A3 | 观察 | 「⑥ X-Wing」段注释编辑残留重复两次 | 清理为单条 |
| A4 | 观察 | 隐性数对首版实现含错误守卫（`cells.some(i => !cand(i).includes(a)) continue` 要求 a 在每个空格都是候选，实际跳过几乎所有数字）+ 错误推导（锁定格内过滤，数学上永不变单） | 已裁剪（见 §4）；若 V1.5+ 重做需避开这两个反模式 |

oracle 意见落实复核：B1（手工构造盘 ✓）/ B2（中文/英文命名分离 ✓）/ I1（砍 triple + 隐性数对 ✓）/ I2（落子语义 + null 返回 ✓）/ I3（adv 折叠组 ✓）/ I4（migrated14 迁移标记 ✓）/ I5（测试 8 项含 null/不抢占/命名一致 ✓）/ I6（候选矩阵 + X-Wing 列向 ✓）/ N1-N4（缓存/版本/命名/痛点定性记录 ✓）✅ 全落实（隐性数对裁剪为 I1/I2 的进一步收敛，符合 oracle 原则）。
