## 3. 变更摘要（与方案 v0.2 对照）

- **analyzeTechniques**（P0/I1/N1）：循环 findLogicStep 模拟推理链收集去重 technique；`TECHNIQUE_MAX_ROUNDS=100` 双上限兜底（每轮必填一格 → ≤size² 轮必然终止，N1）；按 `size:SD` 签名缓存（FIFO 200，防 9×9 重复计算卡主线程，I1）；卡住返回已收集子集不抛错。
- **技巧组映射**（B1）：`唯一候选→uniqueElim / 宫内排除→boxElim / 行列排除→rowColElim / 卡住→需综合`——唯一候选正确关联已存在的「唯一余数」教学关。
- **存储**（I2）：`BookItem.techniques?: string[]`（避开 State.skills 同名异义）；`pushMistake` 入库时计算（try/catch 失败留空由迁移补）。
- **分组视图**（P0/P1/I4/I5）：错题本页新增 `SkillGroups`（按组统计题数、一题可属多组）；非 mixed 组「🎓 复习技巧」（跳对应教学关）+「📝 练这一组」；mixed 组「📚 去练一道」（I5，不空指教学关）。
- **迁移**（I3）：进入错题本 `useEffect` 对缺 techniques 的条目一次性 `update` 写回（单条 try/catch 跳过；无死循环——view 依赖不变不重跑）。
- **连做**（I4）：`startGroupPractice(gid)` → 组内题（<3 全练 / ≥3 随机起手）→ `start` 带 `inGroup` 标记 → 结算层按钮「下一道」（Practice 内条件化文案）→ `handlePracticeFinish` 推进 idx 直至组完 → Toast「这组练完了」回错题本。

## 7. 发行说明（供发布引用）

- **新功能**：错题本新增「按技巧分组」区——一眼看出哪类题常涉及哪些推理环节（唯一候选/宫内排除/行列排除/需综合）。
- **补强闭环**：每组可「🎓 复习技巧」（跳对应教学关）或「📝 练这一组」（同类错题连做，完成自动下一题，练完回错题本）。
- **自动迁移**：旧错题首次打开错题本自动补算分类，无需手动操作。
- **边界说明**：分组标签基于题面推理链（近似），措辞用「这类题常涉及」而非「你错在」。
- **测试**：引擎 +6 断言（题面画像/缓存/边界），冒烟扩至 33 项，0 JS 错误。
