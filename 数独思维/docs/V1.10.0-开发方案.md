# V1.10.0 开发方案 — B7 首页进阶技巧盘·每日轮换

> 版本：v0.2（2026-09-29）｜ 级别：**重要**（新功能、用户可感知新形态，按仓库根 AGENTS.md 分级交 1 个 Oracle 外审）｜ 状态：已修订（Oracle 无 B、4I/5N 全采纳）
> 需求确认：用户已选定形态 A（首页进阶技巧盘·每日轮换），回应 V1.5.0 触达率遗留。

## 一、背景与现状问题

- **V1.5.0 触达率遗留**（审核报告 §六-1）：隐性数对等进阶技巧在小学随机盘单步落子极稀有；自由练习随机盘「提示退化观察」触发概率低属预期——进阶技巧的常态化入口目前只有错题本「进阶观察」组，教学关依赖「全部技巧」墙手动翻找。
- **首页现状**：「学习与技巧」区仅展示 4 个**基础**技巧卡片（`HOME_SKILL_KEYS`），12 个**进阶**技巧在首页完全不露头（只在「🏵️ 全部技巧」墙里）。孩子不点「全部技巧」就永远见不到进阶技巧教学关入口。
- **目标**：首页新增「进阶技巧盘」，按天从 12 个进阶技巧轮换展示 2 个卡片（点击进教学关），让 12 个进阶技巧轮流触达、每天都有新鲜入口，提高教学关触达率与进阶技巧认知面。

## 二、变更设计

### 2.1 轮换算法（`src/lib/content.ts`）

```ts
/** 首页进阶技巧盘每日轮换（V1.10.0 B7）：12 个进阶技巧按天展示 2 个。
 *  步长 5 与 12 互质 → 同日不重复、12 天周期内任意两天组合唯一、i1/i2 各自遍历全部 12 个。
 *  纯日期驱动（确定性、零存储）；本地日差口径（与 dailyFor 本地周几同口径，I1）——固定基准日 2020-01-01
 *  使 di 恒非负，Math.round 对本地午夜差值取最近整数日序号（两本地午夜差恒为 86400000 整数倍）。 */
const ROTATE_BASE = new Date("2020-01-01T00:00:00");
export function advSkillsFor(dateStr: string): Technique[] {
  const d = new Date(dateStr + "T00:00:00");
  const di = Math.round((d.getTime() - ROTATE_BASE.getTime()) / 86400000);
  const i1 = ((di % 12) + 12) % 12;
  const i2 = (i1 + 5) % 12;
  return [ADV_SKILLS[i1], ADV_SKILLS[i2]];
}
```

性质自检（Oracle 验证通过）：`i1 ≠ i2`（5 mod 12 ≠ 0）；`i1` 每天 +1 → 12 天遍历全部 12 个；相邻天组合 `{a,a+5}` vs `{a+1,a+6}` 相等需 6≡0(mod12) → 不可能，组合恒不同（且 12 天周期内任意两天组合唯一）；与 `dailyFor` 本地周几口径一致（I1 采纳）。

### 2.3 测试

**engine.mjs 新增 `advSkillsFor` 断言**（已 import content.ts，Node 26 原生 TS）：

1. 固定日期对（**N2 采纳**，不依赖运行时）：`advSkillsFor("2026-09-28")` 与 `"2026-09-29"` 各返回 2 个、同日不重复、相邻天组合不同（无共同元素）。
2. **N1 精确化**：连续 12 天（`"2026-09-01"`..`"2026-09-12"`）的 i1 集合 = 12 个技巧 key（对应「12 天遍历全部 12 个」承诺）。
3. 12 天窗口内任意两天组合唯一（去重组合数 = 12）。
4. 边界：基准日 `"2020-01-01"` 起 i1 稳定；负 epoch 前（`"1969-12-31"`）不抛错、长度恒 2（防御性，产品不实际使用）。

**smoke.mjs**（**N3 采纳**：Node 侧 import `advSkillsFor` 计算期望值，浏览器侧断言渲染，两侧同源码确定性一致）：
- Node 侧：`import { advSkillsFor } from "../src/lib/content.ts"` → 计算 `todayStr()` 的 2 个技巧名。
- 首页断言：`vis(page, "进阶技巧 · 今日 2 个")` + 2 技巧名卡片可见 + `vis(page, "全部 12 个")` 跳转链。
- **I3 采纳**：断言前 `page.waitForTimeout(600)` 等待 reveal 动画完成（进阶卡片 `reveal-up` + `data-reveal-delay`，opacity 门控），防 flaky。
