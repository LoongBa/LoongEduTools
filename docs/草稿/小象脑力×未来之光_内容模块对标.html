七、龙爸乐学 · 益智/学科双线规划草案

已确认方向：两条产品线、两套驱动范式，互不混用。线一「益智类」= 认知能力维度驱动；线二「学科类」= 单独做学科知识领域驱动的小应用（数与量 / 趣味计算 / 空间与图形 / 逻辑与推理）。假设面向 3–10 岁儿童、Web/H5/轻应用交付（符合 LoongEduTools 技术栈），细节可再调。

产品线定位驱动范式对标范式模块组织
线一 · 益智类脑力 / 认知训练认知能力维度驱动小象脑力 / 未来之光六维任务库 + 测-学-练-评闭环
线二 · 学科类思维学科小应用学科知识领域驱动洪恩思维四大领域各自成应用

① 线一：益智类 · 认知能力维度驱动（测 → 学 → 练 → 评 四层闭环）

  • 测评层：轻量基线测评（5 分钟内、题目按年龄分档），输出六维雷达起点（参照小象脑力"心理学+天赋评测"）。
  • 计划层：每日任务 + 打卡日历（参照小象脑力实机"每日任务+第 N 天打卡"），每次 10–15 分钟、4 个任务以内。
  • 训练层：六维一级分类任务库（记忆/思维/注意/语言/观察/反应），每维 5–8 个任务（MVP 30–48 个）。任务不挂学科标签，纯认知能力。
  • 报告层：家长端周报 + 能力曲线 + 人群对比。

② 线一任务库（纯能力维度）

  • 记忆：卡牌配对、图形追忆、听记指令、数字串回忆、物品藏匿。
  • 思维/逻辑：迷宫路径、因果排序、规律补全、数独启蒙 4×4、编码解码。
  • 注意：限时找不同、舒尔特方格（3×3/4×4）、目标追踪、抗干扰计数。
  • 观察：颜色/形状配对、连线作战、影子匹配、数量比较。
  • 语言：看图说话排序、故事复述、反义词配对、绕口令节奏。
  • 反应：红绿灯反应、捕鱼点击、方位指令快速响应。
  • 分龄与自适应：3–5 / 6–8 / 9–10 三档；连续 3 次未通过自动降档或给提示，表现优异解锁高阶。

③ 线二：学科类 · 学科知识领域驱动（四大领域 = 四个独立小应用）

  • 数与量：数感、计数、数量比较、数字书写。
  • 趣味计算：加减法、乘除法专项、口算。
  • 空间与图形：图形认知、空间位置、几何启蒙。
  • 逻辑与推理：分类、对比、推理、数独。
  • 单应用内部结构（对标洪恩思维 学-练-反馈）：学=知识演绎（动画/儿歌/语音交互）→ 练=情景化互动练习（每领域题库/关卡）→ 反馈=每日进度+家长端推送；内容按 L1–L4 阶梯、学段（幼小衔接/小学低年级）进阶。

④ 两线关系与边界

  • 益智类任务不挂学科标签（纯认知能力）；学科类不混入能力维度（纯知识领域）——每线范式纯粹、测评与迭代独立。
  • 数据可选打通（增强项，非 MVP）：益智类能力曲线 + 学科类学情报告，统一在家长端呈现。
  • 参考先例：大象智酷内部（未来之光/小象脑力 = 能力线）、洪恩教育内部（思维/识字/拼音 = 学科线），均分线运营。

⑤ 留存与激励（两线通用）+ 避坑

  • 打卡日历 + 连续天数成就；家长端"今日报告"推送；集章/贴纸/成长树（避免成人向 PK，符合儿童合规）。
  • 不堆量：益智类任务控制在 50 内；学科类以"领域纵深 + 学段衔接"取胜。
  • 测评不作贩卖焦虑点，只作起点与可视化；儿童数据保护与防沉迷优先（对照未成年人保护要求）。
本草案为方向性建议，非实施文档；任务名与数量、年龄段、交付形态（Web/H5/小程序）待确认后展开为 PRD。
