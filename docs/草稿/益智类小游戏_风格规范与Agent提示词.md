# 益智类小游戏・风格统一策略与 Agent 提示词（UI / UE / UX）

> 适用范围：龙爸乐学・线一益智类六款小游戏（记忆星 / 逻辑迷宫 / 专注工坊 / 观察镜 / 语言剧场 / 反应竞速场）
> 三个问题：① 如何统一风格特点 ② 选什么风格 ③ 给 Agent 的提示词怎么写
> 结论先行：
>
> **统一靠 "设计系统 + 设计令牌" 而非 "每款各自画"；风格选 "扁平矢量 + 高饱和系列色 + 单一 IP 角色"；提示词用 "锚定 → 参数化 → 验收" 三段式。**



***

## 一、如何统一风格特点：五层统一

统一不是 "六张图长得像"，而是**所有游戏共享同一套可复用的设计资产与规则**。拆成五层，每层都可被 Agent 明确执行：



| 层级      | 统一什么                        | 具体约定                                                                                   |
| ------- | --------------------------- | -------------------------------------------------------------------------------------- |
| 1. 视觉令牌 | 颜色 / 字体 / 圆角 / 间距 / 描边 / 投影 | 6 套系列色板共享同一逻辑（主色 / 成功 / 提示 / 中性）；统一圆体字族与字号阶梯；统一 20px 卡片圆角、全圆角按钮、8pt 栅格、柔和低对比投影         |
| 2. 角色系统 | 同一 IP 贯穿                    | Q 版幼龙「乐仔」出现在所有游戏的开始页与结算页；表情系统仅 4 种（开心 / 思考 / 鼓励 / 惊讶）；系列差异只靠 "领巾颜色 + 场景元素"，不新增角色       |
| 3. 布局骨架 | 页面三段式                       | 顶部状态栏（系列名 + 关卡 + 奖励）→ 中央游戏区（上下留白 8% 安全区）→ 底部操作区（主按钮 ≥120×88px）；每款必有 开始页 → 游戏页 → 结算页 三屏 |
| 4. 交互规则 | 反馈与容错                       | 可点区域 ≥88×88px、单指操作、点击即时反馈（缩放 0.95 + 音效）、答错不惩罚只提示、连续 2 次失败自动降难度、奖励统一为星星 + 成长树           |
| 5. 内容语气 | 文案与鼓励语                      | 页面文字 ≤30 字、少文字多图标；鼓励语统一词库（"你真棒 / 再试一次 / 差一点点"）；难度统一用 L1–L4 分级（对应学段，见规划文档 5.0）                     |

> 落地要点：
>
> **先把 "设计令牌" 写成一份全局常量（色板 HEX、字号、圆角、间距、动效时长），所有游戏从这份令牌取数，而不是每款重新设计**
>
> —— 这是 "统一" 与 "省成本" 的关键。

## 二、选什么风格：推荐 "扁平矢量 + 高饱和系列色 + 单角色"

### 2.1 方案对比



| 方案              | 视觉特征         | 制作成本 | AI 一致性      | 儿童吸引力    | 适配年龄          |
| --------------- | ------------ | ---- | ----------- | -------- | ------------- |
| A. 扁平矢量多彩（推荐）   | 大圆角、高饱和、简单层次 | 低    | 高（已用前批配图验证） | 高        | 3–10 全段       |
| B. 手绘水彩 / 蜡笔绘本风 | 质感强、暖        | 中高   | 中（笔触难统一）    | 高        | 3–6 更佳，7+ 偏幼稚 |
| C. 3D Q 版 / 粘土风 | 立体、精致        | 高    | 低（渲染一致性难）   | 高        | 全段            |
| D. 极简几何风        | 高级、克制        | 最低   | 最高          | 中低（趣味性弱） | 7+            |

### 2.2 推荐 A 的理由



1. **与对标产品同频**：小象脑力、洪恩思维均为扁平卡通风格，选用同类视觉语言可降低家长与孩子的认知成本，也便于在对比中被 "归类" 为专业儿童教育产品。

2. **AI 生产一致性最好**：扁平矢量 = 明确的色块、描边、形状，Agent 生成与代码实现的还原度最高；本文前一批六张系列配图即为该风格验证。

3. **儿童认知适配**：3–6 岁偏好高饱和原色与圆润形状；7–10 岁可接受更丰富色阶。扁平风格 + 大圆角恰好覆盖全段。

4. **扩展成本低**：动效、贴纸、奖励、周边都能低成本延展；换比例（公众号 / 小程序 / 专题页）不改风格。

5. **性能友好**：矢量 / 轻量图片资源小，适合 H5 与小程序。

### 2.3 系列色板（设计令牌・建议值）



| 系列    | 主色 | 色值        | 场景元素           | 音效基调     | 动效基调 |
| ----- | -- | --------- | -------------- | -------- | ---- |
| 记忆星   | 蓝紫 | `#7B6CF6` | 星星 / 卡牌        | 轻快木琴     | 卡片翻转 |
| 逻辑迷宫  | 青绿 | `#2FBF9E` | 迷宫 / 积木 / 齿轮   | 清脆积木     | 路径移动 |
| 专注工坊  | 橙黄 | `#F5A623` | 聚光灯 / 钟表 / 放大镜 | 滴答 + 叮   | 高亮聚焦 |
| 观察镜   | 玫粉 | `#F46FA2` | 放大镜 / 形状卡片     | 柔和叮咚     | 放大提示 |
| 语言剧场  | 天蓝 | `#4FA8F5` | 舞台 / 对话气泡 / 书本 | 人声鼓励     | 气泡弹出 |
| 反应竞速场 | 红橙 | `#F4633F` | 跑道 / 红绿灯 / 闪电  | 起跑哨 / 加速 | 快速位移 |

统一中性色：纸白 `#FFF9F0`・墨灰 `#3A3A45`・成功绿 `#4CAF50`・提示黄 `#FFD666`。

色彩心理学依据：蓝紫 - 冷静专注、青绿 - 理性、橙黄 - 警觉唤醒、玫粉 - 温暖细致、天蓝 - 开放交流、红橙 - 兴奋速度 ——**色相即能力语义**，孩子与家长都能 "一眼认出系列"。

## 三、给 Agent 的提示词：锚定 → 参数化 → 验收

### 3.1 提示词设计原则



* **锚定**：先注入全局风格锚定提示词（系统级、恒定），让 Agent 每次都在同一套设计系统内工作 —— 这是 "统一" 的根本保证。

* **参数化**：单款游戏的提示词只替换 6 个参数（系列名 / 游戏名 / 能力维度 / 目标年龄 / 玩法一句话 / 单局时长），不重新描述风格。

* **验收**：交付前用 UE/UX 检查清单提示词逐项过审，把 "一致性" 从口头承诺变成可勾选条目。

* **分流**：给 "生图 Agent" 的提示词管构图 / 色彩 / 角色一致；给 "代码 Agent" 的提示词管设计令牌与交互规则 —— 两者别混写。

### 3.2 P1・全局风格锚定提示词（一次性注入，复制即用）



```
你是龙爸乐学「益智类」小游戏系列的 UI/UE 设计师与前端实现者。

请严格遵守以下设计系统，本系列所有游戏页面必须保持一致：

【视觉系统】

\- 风格：扁平矢量儿童插画风；卡片圆角 20px、按钮全圆角；柔和低对比投影；8pt 栅格

\- 色彩：只用本系列色板。六系列主色为：记忆星-蓝紫#7B6CF6、逻辑迷宫-青绿#2FBF9E、专注工坊-橙黄#F5A623、观察镜-玫粉#F46FA2、语言剧场-天蓝#4FA8F5、反应竞速场-红橙#F4633F；中性色：纸白#FFF9F0、墨灰#3A3A45、成功绿#4CAF50、提示黄#FFD666

\- 字体：圆体字族；字号阶梯 28/24/20/16/14（标题/副题/正文/说明/辅助）；禁用手写体与衬线体

\- 图标：圆角线性图标，笔画 3px

\- 角色：Q版幼龙「乐仔」贯穿全系列，表情仅限开心/思考/鼓励/惊讶四种；不引入其他角色

【布局系统】

\- 三段式骨架：顶部状态栏（系列名+关卡+奖励）→ 中央游戏区（上下留白 8% 安全区）→ 底部操作区（主按钮 ≥120×88px）

\- 每款游戏必有三个界面：开始页（规则图示+开始按钮）、游戏页、结算页（星星1-3颗+鼓励语+再来一次）

【交互规则】

\- 所有可点区域 ≥88×88px；单指操作；禁止需双指的交互

\- 每次点击有即时反馈（按压缩放0.95+音效）

\- 答错不惩罚：只给温和提示与重试；连续2次失败自动降难度

\- 奖励统一为星星+成长树积分；不使用排名、竞技、社交

\- 页面文字 ≤30 字，少文字多图标；鼓励语词库：你真棒/再试一次/差一点点

【禁忌】大面积深色底、高对比闪烁动画、广告、社交功能、诱导付费、需登录才能玩。
```

### 3.3 P2・单款游戏设计提示词模板（每次替换 { } 参数）



```
请为龙爸乐学益智类「{系列名}」设计并实现小游戏「{游戏名}」的完整 UI/UX：

【游戏参数】

\- 能力维度：{记忆}

\- 目标年龄：{6-8岁}

\- 玩法一句话：{翻开两张卡牌配对，全部配完过关}

\- 单局时长：{60-90秒}

【本次设计要求】

1\. 布局：按全局风格锚定的三段式骨架，输出开始页/游戏页/结算页三屏

2\. 视觉：主色用本系列{蓝紫}色板；场景沿用本系列元素（{星星与卡牌}）；「乐仔」出现在开始页与结算页

3\. 交互：给出状态流转（开始→游戏→结算→再来一次）与四类反馈（点击/答对/答错/超时）规则

4\. 难度：给出 L1–L4 四档参数（数量、速度、干扰项，对应 preK / K1-3 / K4-6 / K7-9 远期）与自适应规则

5\. 无障碍：触控区尺寸、对比度、可关闭音效、家长模式入口

6\. 实现：用 HTML/CSS/JS（无外部依赖）输出可直接运行的单页原型；颜色/圆角/字号必须取自全局设计令牌
```

### 3.4 P3・UE/UX 验收清单提示词（交付前必跑）



```
请按以下清单逐项审查你产出的游戏页面，全部通过才能交付：

1\. 一致性：颜色/圆角/字号是否全部来自全局设计令牌？与系列其他页面是否同源？

2\. 儿童适配：所有可点区域≥88px？页面文字≤30字？是否存在需要精确定位或双手操作的地方？

3\. 反馈完整性：点击、答对、答错、超时、结算五个时刻是否都有反馈？

4\. 防挫败：连续失败是否有降难度或提示？是否出现任何惩罚性表达？

5\. 合规：无广告、无社交、无诱导付费；家长模式可退出；无强制授权

6\. 性能：单页无外部请求，动画时长 200-300ms，可离线打开
```

### 3.5 生图 Agent 与代码 Agent 提示词差异



| 场景                     | 提示词重点                | 示例要点                                         |
| ---------------------- | -------------------- | -------------------------------------------- |
| 生图 Agent（系列配图 / 界面视觉稿） | 角色一致、构图、色彩、文字        | "保持乐仔形象与扁平矢量画风一致，仅换场景与主色"；系列名用中文引号标注；一次只描述画面 |
| 代码 Agent（可运行原型）        | 设计令牌、布局骨架、交互规则、无外部依赖 | 复用 P1 的令牌与骨架；输出单文件 HTML；动效 200-300ms；验收走 P3  |

### 3.6 完整示例：以「记忆星・卡牌配对」跑一遍三件套



1. **注入 P1**（全局锚定，只注入一次，本系列所有游戏共用）。

2. **调用 P2** 并填参：系列名 = 记忆星；游戏名 = 翻牌配对；能力维度 = 记忆；目标年龄 = 6-8 岁；玩法一句话 = 翻开两张卡牌配对，全部配完过关；单局时长 = 60-90 秒。

3. **输出验收 P3**：核对主色是否 `#7B6CF6`、卡片圆角 20px、按钮 ≥120×88px、乐仔出现在开始 / 结算页、"你真棒 / 再试一次" 词库、失败 2 次降难度、无外部请求。

4. **存档**：每款游戏交付时附一张《设计令牌使用清单》（用到的色值 / 字号 / 圆角 / 角色表情 / 奖励元素），供后续游戏对齐。

## 四、落地清单（每款游戏交付时的统一检查项）



* [ ] 设计令牌全部来自全局色板，无自定义新色

* [ ] 三段式骨架与三屏（开始 / 游戏 / 结算）齐全

* [ ] 「乐仔」角色与 4 表情系统合规，系列只靠领巾色 + 场景元素区分

* [ ] 触控区 ≥88px、单指、五时刻反馈齐全

* [ ] 答错不惩罚、连败降难度、奖励 = 星星 + 成长树

* [ ] 无广告 / 社交 / 诱导付费；家长模式可退出

* [ ] 单文件可离线运行、无外部依赖、动效 200-300ms

* [ ] 附《设计令牌使用清单》存档
