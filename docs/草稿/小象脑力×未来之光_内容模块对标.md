## 3. 对标洞察

1. **同一引擎、两种封装**：小象脑力 = 未来之光的儿童化封装（官方口径），共享测评 / 自适应 / 可视化底座；连「连线作战」等任务资产都直接复用。自建儿童产品可参考「复用成人能力体系、重做儿童化交互」。
2. **两种组织范式可分线并行**：能力维度（认知训练）与知识领域（学科思维）是两套独立范式——益智类走「认知能力维度驱动」（对标小象 / 未来之光），学科类单独做「学科知识领域驱动」小应用（对标洪恩思维）。分线后每线范式纯粹、测评与迭代独立，是龙爸乐学的差异化空间。
3. **闭环是标配、深度分档**：未来之光「测-划-练-报」最完整；洪恩思维弱测强学；儿童产品应把「测」做成起点与可视化而非贩卖焦虑。
4. **留存机制分层**：成人靠竞技 / 工具，儿童靠打卡日历 + 家长端反馈 + 趣味化。
5. **内容数量存在门槛效应**：未来之光 80+ / 6000+ 难度形成壁垒；差异化应落在双线架构（益智六维任务库 + 学科领域小应用）与学情联动等垂直场景，而非堆量。

## 4. 龙爸乐学 · 益智 / 学科双线规划草案（方向性建议，非 PRD）

**双线架构（已确认方向）**：两条产品线、两套驱动范式，互不混用。

| 产品线 | 定位 | 驱动范式 | 对标范式 | 模块组织 |
|---|---|---|---|---|
| 线一 · 益智类 | 脑力 / 认知训练 | 认知能力维度驱动 | 小象脑力 / 未来之光 | 六维任务库 + 测-学-练-评闭环 |
| 线二 · 学科类 | 思维学科小应用 | 学科知识领域驱动 | 洪恩思维 | 四大领域各自成应用 |

### 线一：益智类 · 认知能力维度驱动

**总架构：测 → 学 → 练 → 评 四层闭环（儿童化落点）**

- **测评层**：轻量基线测评（5 分钟内，题目按年龄分档），输出六维雷达起点。
- **计划层**：每日任务 + 打卡日历（参照小象脑力实机），每次 10–15 分钟、4 个任务以内。
- **训练层**：六维一级分类任务库（记忆 / 思维 / 注意 / 语言 / 观察 / 反应），每维 5–8 个任务（MVP 30–48 个）。
- **报告层**：家长端周报 + 能力曲线 + 人群对比。

**任务库（纯能力维度，不挂学科标签）**

- 记忆：卡牌配对、图形追忆、听记指令、数字串回忆、物品藏匿
- 思维 / 逻辑：迷宫路径、因果排序、规律补全、数独启蒙 4×4、编码解码
- 注意：限时找不同、舒尔特方格（3×3 / 4×4）、目标追踪、抗干扰计数
- 观察：颜色 / 形状配对、连线作战、影子匹配、数量比较
- 语言：看图说话排序、故事复述、反义词配对、绕口令节奏
- 反应：红绿灯反应、捕鱼点击、方位指令快速响应

**分龄与分级**：按学段 L1–L4 四级分档（L1=preK 3–5 岁、L2=K1-3 6–8 岁、L3=K4-6 9–10 岁、L4=11–14 岁远期），每级内再分 3 子档（-/+/++）；连续 3 次未通过自动降档或给提示，表现优异解锁高阶。

### 线二：学科类 · 学科知识领域驱动（独立小应用）

**产品形态：四大领域 = 四个独立小应用**

- 数与量：数感、计数、数量比较、数字书写
- 趣味计算：加减法、乘除法专项、口算
- 空间与图形：图形认知、空间位置、几何启蒙
- 逻辑与推理：分类、对比、推理、数独

**单应用内部结构（对标洪恩思维 学-练-反馈）**

- **学**：知识演绎（动画 / 儿歌 / 语音交互）
- **练**：情景化互动练习（每领域对应题库 / 关卡）
- **反馈**：每日进度 + 家长端推送
- **内容分级**：L1–L4 阶梯，按学段（幼小衔接 / 小学低年级）进阶

### 两线关系与边界

- 益智类任务不挂学科标签（纯认知能力）；学科类不混入能力维度（纯知识领域）——每线范式纯粹、测评与迭代独立。
- 数据可选打通（增强项，非 MVP）：益智类能力曲线 + 学科类学情报告，统一在家长端呈现。
- 参考先例：大象智酷内部（未来之光 / 小象脑力 = 能力线）、洪恩教育内部（思维 / 识字 / 拼音 = 学科线），均分线运营。

### 留存与激励（两线通用）

打卡日历 + 连续天数成就；家长端「今日报告」推送；集章 / 贴纸 / 成长树（避免成人向 PK，符合儿童合规）。

### 避坑

- 不堆量：益智类任务控制在 50 内；学科类以「领域纵深 + 学段衔接」取胜。
- 测评不作贩卖焦虑点，只作起点与可视化。
- 儿童数据保护与防沉迷优先。

## 5. 龙爸乐学 · 产品规划矩阵（依据三款对标整理）

### 5.0 学段覆盖与 L1–L4 分级（全规划前置口径）

**学段定义（K12 口径）**

| 学段 | 年龄 | 阶段定位 | 规划归属 |
|---|---|---|---|
| preK | 3–5 岁 | 启蒙期：感知、兴趣、语音引导、无计时压力 | 主营 · L1 |
| K1-3 | 6–8 岁 | 奠基期（核心）：幼小衔接、规则理解、独立操作 | 主营 · L2 |
| K4-6 | 9–11 岁 | 拓展期：策略运用、计时挑战、复合任务 | 后置 · L3（低段）/ L4（高段起） |
| K7-9 | 12–14 岁 | 远期暂缓：能力分化，另议 | 远期 · L4 延伸 |

**三款对标产品学段覆盖矩阵**

| 学段 | 洪恩思维 | 未来之光 | 小象脑力 |
|---|---|---|---|
| preK（3–5） | ✓ 核心（2–7 启蒙） | ✓ | ✓ |
| K1-3（6–8） | ✓ 核心（幼小衔接） | ✓ | ✓ |
| K4-6（9–11） | △ 小学同步课（数学） | ✓（9–10 岁段） | ✓（9–10 岁档） |
| K7-9（12–14） | ✕ | △ 全年龄池（非儿童专项） | ✕（上限 10 岁） |

> 结论：preK–K1-3 三家高度重叠（红海）；K4-6 仅未来之光 / 小象脑力部分覆盖；K7-9 无人做儿童专项。龙爸乐学主营 **preK–K1-3 核心 + K4-6 后置** 三阶段，K7-9 留远期——与"聚焦 3–8 岁幼小衔接段"策略一致。

### 5.6 风险与对策矩阵

| 风险 | 影响 | 对策 | 对标印证 |
|---|---|---|---|
