# 情绪识别 — 使用文档

> 系列：扩展（情商启蒙） ｜ 版本：v1.0（2026-09-22）
> 一句话：看看小表情在表达什么情绪？

## 这是什么

「情绪识别」展示一个表情符号，孩子选择它表达的情绪（开心/难过/生气/害怕/惊讶/平静）。
学会读懂表情、识别情绪，是情商培养的第一步。

适合 3-11 岁（preK–K4-6）。

## 怎么玩

1. **选择难度**：入门 6 题 / 进阶 8 题 / 挑战 10 题（首页显示各难度最佳成绩）。
2. **看表情选情绪**：大表情下方 4 个情绪选项，点选正确的。
   - 答对：✓ 答对啦！答错：显示正确答案（学习反馈，不判负）。
3. **完成练习**：全部答完 → 结算页（星级 + 答对数 + 用时）。
4. **打卡**：完成练习后可打卡，连续天数在顶部显示（🔥 连练 N 天）。

## 星级规则

| 星级 | 条件 |
|---|---|
| ★★★ | 只错 ≤1 题 |
| ★★☆ | 错 ≤3 题 |
| ★☆☆ | 错 >3 题 |

> 星级只和自己比（鼓励进步），没有排行榜、不和别人比。

## 家长面板

首页右下角空白处**连点**可进入家长面板（或用键盘 F7）：
累计/连续打卡天数、各难度最佳成绩、最近 10 条记录、清除所有数据（不可恢复）。

## 常见问题

**Q：答错会扣分吗？**
A：不会。答错会显示正确答案（学习反馈），不判负。

**Q：数据存在哪里？**
A：全部保存在本机浏览器（localStorage，键 `redtools.qingxushibie.v1`），不联网、无账号、无上传。

## 离线使用

下载 zip → 解压 → 双击 `index.html` 即可使用（完全离线，无需网络）。
