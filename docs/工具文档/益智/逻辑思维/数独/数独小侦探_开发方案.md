# 数独小侦探 · 开发方案（v0.1）

> 面向：龙爸乐学 · 线一益智类 · 逻辑迷宫 · H5 数独
> 关联文档：《数独小侦探_双版本设计草案.md》（需求）、《益智类小游戏_风格规范与Agent提示词.md》（设计令牌）
> 基线：`数独小侦探原型/index.html` 已通过自检（生成器 107 项测试通过、桌面/移动截图 lint 无报错）
> 状态：开发方案 v0.1，随评审与排期更新

---

## 0. 结论先行

1. **技术形态锁定为单文件 H5**：HTML/CSS/JS 全内联、无外部依赖、`file://` 可直接打开——对齐系列「单文件可离线运行」验收项，正式发布时原样托管静态页即可。
2. **架构分四层**：核心引擎（纯函数，可单测）→ 状态与存储 → 三视图渲染 → 反馈层（音效/语音）。原型已按此分层实现，开发方案在其上增量演进。
3. **分三阶段推进**：阶段一 = 原型基线（已完成）；阶段二 = 教学技巧体系 + 家长报告 + 小屏适配；阶段三 = 闯关地图 + 线二题库联动。
4. **难度参数为建议值，阶段二开工前须试玩校准**（见 §4）。

## 1. 技术架构

| 层 | 模块 | 职责 | 现状 |
|---|---|---|---|
| 核心引擎 | `sudoku-core` | 填满解 / 挖洞生成 / 唯一解校验 / 候选数 / 提示格 | ✅ 已实现并测试（`logic_test.js`） |
| 状态与存储 | `game-state` / `storage` | 对局状态、撤销栈、铅笔笔记、设置/成长星/进度持久化 | ✅ 已实现（localStorage） |
| 视图层 | `board-render` / `input` / `teach` / 三视图 | 盘面渲染与宫格边界、输入条、规则教学、开始/游戏/结算三屏 | ✅ 已实现（view 切换） |
| 反馈层 | `audio-voice` | WebAudio 音效、SpeechSynthesis 语音、开关 | ✅ v1 已实现；语音包为 v2 待评估 |

**约束**：不引入框架与外部库；设计令牌（色板/字号/圆角）全部来自全局常量，禁止自定义新色；动效 200–300ms。

**版本控制（一套引擎，界面层控制）**：核心引擎与题库不分版本。生成器按 L0–L7 技巧标签出题；界面层用构建配置 / 开关控制「适龄教学版」（只露 L0–L4：启蒙版 + 普通版）与「全功能版」（另含自由解题模块 L5–L7）的开放范围。高阶内容（鱼翼 / 唯一性 / 链 / 强制链 / 自编题）统一收进自由解题模块，不进适龄版。

## 2. 模块职责与演进点

| 模块 | 职责 | 阶段二演进 |
|---|---|---|
| `sudoku-core` | 生成/求解/候选/唯一解 | 无改动（稳定） |
| `game-state` | 对局状态、撤销、铅笔、错误集 | 增加「连败降难度」判定（最近 2 局正确率 < 阈值自动降档） |
| `board-render` | 盘面、宫格边界、选中/同行列宫/冲突高亮 | 9×9 自动切横屏或双指缩放提示 |
| `input` | 数字条、铅笔/橡皮/撤销/提示 | 提示次数按难度档限流（普通版困难档） |
| `teach` | 规则教学三步动画、提示带讲解 | 新增技巧教学关（单宫排除→行列排除→区块排除）+ 技巧徽章；教学关独立标记不混入普通进度 |
| `audio-voice` | 音效、语音、开关 | 评估内嵌语音包（v2）；失败降级为文案+音效 |
| `storage` | 设置、成长星、进度 | 扩展 schema（§3）：技巧掌握度、每日局记录 |
| `parent-report` | 今日反馈 / 周报 | 新增：完成局数、平均用时、技巧使用次数与首用关卡 |

### 3.3 技巧识别规则（阶段二）

- **单宫排除**：提示/落子时，若某宫剩余可填数唯一且因宫内已有 N-1 种而唯一 → 记 `boxElim`；
- **行列排除 / 区块排除 / 交叉排除**：按提示格候选数来源判定（候选数唯一且由行/列/宫联合约束），v1 先按提示触发记录，精确判定在技巧教学关内做标记打点。

## 4. 难度与题库参数

沿用需求方案 §3（四参数：盘面尺寸 × 符号 × 已知格密度 × 技巧层级）。实现要点：

| 参数 | L1 启蒙 | L2 基础 | L3 进阶 | L4 挑战（远期） |
|---|---|---|---|---|
| 盘面 | 4×4 | 4×4 / 6×6 | 6×6 / 9×9 | 9×9 |
| 已知格（建议） | 12 | 9 / 20–24 | 24 / 30–36 | 17–26 |
| 生成目标 | 精确 | 精确 | 目标±4 宽容带 | 目标±4 宽容带 |

- 生成算法：随机回溯填满解 → 洗牌挖洞 → 每挖一格 `solveCount(puzzle, N, 2) === 1` 校验，失败回填；最多换 4 个满解重试，兜底单趟（已知格可能略高于目标，难度不劣化）。
- 性能基线：4×4 / 6×6 生成 <10ms，9×9 <100ms（Node 已验证）。
- **阶段二开工前**：用 3–4 名目标年龄儿童试玩，校准各档已知格数量与单局时长预期。

## 5. 教学体系实现拆解

| 层 | v1（原型） | v2（阶段二） |
|---|---|---|
| 规则教学 | 行→列→宫三步动画 + 启蒙版语音 | 保持；普通版增加数字样例 |
| 技巧教学 | — | 每技巧 1–2 个教学关（在简化盘上逐步引导落子）+ 技巧徽章；与难度解锁绑定：L2 单宫排除 → L3 行列/区块排除 → L4 交叉排除 |
| 题面引导 | 提示按钮自动填正确值 + 文字解释「第 r 行第 c 列只能填 X」 | 提示升级为「分步讲解」：先高亮约束来源，再落子 |

**教学关约定**：独立标记、不计入普通关进度、可跳过；启蒙版全程语音。

## 6. 家长端与数据（阶段二）

- **今日反馈**：完成局数、平均单局用时、提示与错误次数、用到的技巧。
- **周报**：技巧掌握度（每个技巧首次使用关卡、使用次数）、难度分布。
- **防沉迷**：连续游玩 20 分钟出现温和提醒（不强制中断）；家长模式可设置单次时长上限；无社交、无付费。
- 数据只存本地（单机版）；如后续接入账号体系再做云同步，本期不做。
