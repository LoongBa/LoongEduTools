# 扫雷推理 — 使用文档

> 系列：益智 · 逻辑思维 ｜ 版本：v1.0（2026-09-22）
> 一句话：数字推理排雷，踩到也不怕——标出来继续想！

## 这是什么

「扫雷推理」是经典扫雷的**推理练习版**：棋盘上有雷，每格数字表示**周围 8 格里藏了几颗雷**。
孩子靠数字推理找出所有安全格（点开它们）就完成练习。

**和以前玩的扫雷不一样**：
- 踩到雷**不会输**——雷会被标出来，孩子看看推理提示继续；
- 没有「输/赢」——把**所有安全格都翻开**就完成，踩雷次数只作参考。

适合 6-11 岁（K1-3 至 K4-6），训练：**逻辑推理 + 排除法 + 耐心**。

## 怎么玩

1. **选难度**：初级 9×9 / 中级 16×16 / 高级 30×16。
2. **翻开格子**：点一格翻开——
   - 数字 = 周围有几颗雷（推理依据）；
   - 空白 = 周围无雷，自动翻开一片。
3. **标旗**：点「🚩」切换标旗模式，把推断出的雷标出来（防止误点）。
4. **踩雷了？** 没关系！雷被标出 + 弹出推理提示（「看周围数字」），继续翻其它安全格。
5. **完成**：所有安全格翻开 → 「🎉 完成推理！」+ 用时/踩雷次数。

## 星级参考

- 完成即可；**踩雷次数越少、用时越短** = 推理越稳（个人最佳记录，不和别人比）。
- 完成练习后打卡（🔥 连练 N 天显示在顶部）。

## 家长面板

首页右下角空白处**连点**可进入家长面板（或用键盘 F7）：
累计/连续打卡天数、各难度最佳、最近记录、清除所有数据（不可恢复）。

## 推理小技巧

- 数字「1」= 周围只有 1 颗雷，其它格都安全；
- 数字「3」旁边已标 2 旗 → 剩下 1 个一定安全；
- 先翻角落和边缘（信息更明确）。

## 常见问题

**Q：踩到雷会扣分或输吗？**
A：不会。踩雷只是标出这颗雷（+提示），局继续，翻完所有安全格即完成。

**Q：数据存在哪里？**
A：全部保存在本机浏览器（localStorage，键 `redtools.saoleituili.v1`），不联网、无账号、无上传。
