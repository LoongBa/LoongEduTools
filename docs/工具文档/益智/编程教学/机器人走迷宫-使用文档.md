# 机器人走迷宫 — 使用文档

> 系列：益智 · 编程教学 ｜ 版本：v1.1（2026-09-22；v1.1 = 关卡扩展 + 循环指令）
> 一句话：用指令让机器人把箱子推到目标点！

## 这是什么

「机器人走迷宫」是**编程启蒙练习**：迷宫里有个机器人要搬运箱子到橙色圈（目标点），
孩子不能直接遥控它，而是**用指令积木编好「行动程序」**，再让机器人一次性执行。
如果箱子没到位，就调整指令重新执行——就像小程序员在调试代码！

适合 6-11 岁（K1-3 至 K4-6），训练：**逻辑顺序思维 + 问题拆解 + 调试能力**（编程启蒙）。

## 怎么玩

1. **选择难度**：简单（1-15 关）/ 普通（16-40 关）/ 挑战（41-60 关）。
2. **编排指令**：点指令按钮加入序列——
   - **↑ 前进**：机器人向前走一格（前方有箱子就推着走）；
   - **↰ 左转**：原地向左转 90°；
   - **↱ 右转**：原地向右转 90°。
   - **循环技巧**：点指令 chip 可把「↑ 前进」变成「↑×2/×3/×4」（重复执行，像编程里的循环！）；
   - 点指令 chip 上的 ✕ 删除，点「↺ 清空」全部清除。
3. **执行**：点「▶ 执行」，机器人按序列一步一步走。
   - 成功：所有箱子到橙色圈 → ✓ 完成 + 星级；
   - 失败：还有箱子没到位 → 调整指令（点「⟲ 重置」恢复盘面）再试。
4. **下一关**：完成后点「下一关 ›」。

## 星级规则

| 星级 | 条件 |
|---|---|
| ★★★ | 指令条数少（接近最优解） |
| ★★☆ | 指令条数适中 |
| ★☆☆ | 指令条数多（多试几次） |

> 星级只和自己比（鼓励进步），没有排行榜、不和别人比。

## 家长面板

首页右下角空白处**连点**可进入家长面板（或用键盘 F7）：
累计/连续打卡天数、各难度最佳成绩、最近 10 条记录、清除所有数据（不可恢复）。

## 小贴士（编程思维）

- 先想好箱子怎么走，再编指令（规划优先）；
- 走错一步不要紧——观察哪里不对，改掉那一条（调试）；
- 试试用最少指令完成（优化）。

## 常见问题

**Q：机器人卡住/不动了？**
A：撞墙的指令会被忽略，调整指令绕开障碍即可。

**Q：数据存在哪里？**
A：全部保存在本机浏览器（localStorage，键 `redtools.jiqirenzoumi.v1`），不联网、无账号、无上传。
