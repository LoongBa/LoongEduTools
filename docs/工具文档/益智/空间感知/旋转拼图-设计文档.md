# 旋转拼图 — 设计文档

> 系列：益智 · 空间感知（子系列第 4 款）
> 版本：v1.0（2026-09-22 交付）
> 状态：✅ 已实现（审计 PASS / 冒烟通过 / 双模式接入）

## 1. 定位与玩法

**一句话**：正方形场景切成 N×N 碎片，碎片位置正确但**方向被旋转**（0°/90°/180°/270°），
孩子点选碎片使其旋转到正确方向（每次点击转 90°）。全部碎片归正 = 完成。
有标准答案（每碎片唯一正确方向，合规安全区）。

**与同系列差异**：
- 简单拼图：碎片位置打乱（方向正确），交换归位——「位置推理」；
- 旋转拼图：碎片**位置正确、方向错乱**，点选旋转归正——「方向/旋转推理」，
  考察对整图方位的记忆与旋转思维（比交换更高一层的空间变换能力）。

## 2. 关卡与难度

| 难度 | 盘面 | 错乱碎片数 | 星级标准 |
|---|---|---|---|
| 简单 | 2×2（4 块） | 1 块 | 旋转 ≤ 理想步 = 3★；≤ 2×理想 = 2★；其余 1★ |
| 普通 | 3×3（9 块） | 2 块 | 同左（理想步 = 错乱块数 × 1） |
| 困难 | 4×4（16 块） | 4 块 | 同左 |

- 错乱碎片随机选（位置随机、角度随机 90/180/270，排除 0）；
- 每关随机场景（复用简单拼图 8 个 400×400 正方形场景，SVG 程序化零素材）；
- 参考缩略图按钮（🖼 看原图）辅助判断正确方向。

## 3. 渲染机制（关键）

- **碎片渲染**（pieceSvg）：`<svg viewBox="x y w h">` 取「正确位置」区域裁剪完整场景，
  内层 `<g transform="rotate(deg 中心)">` 包裹场景内容 → 碎片内容旋转显示；
- **点选交互**：点击碎片 → 其内层 g 旋转 +90°（`rot = (rot+90)%360`）→ 重渲染该碎片；
- **判定**：`rot % 360 === 0` = 归正；全部归正 = 完成；
- 碎片宽度按难度 JS 动态设（2×2→50% / 3×3→33.33% / 4×4→25%）。

## 4. 数据与存储

- `LX_SHARED.storage`（V0.4 双模式公共模块）：
  - `configure({toolName: 'xuanzhuanpintu'})` → 键前缀 `redtools.xuanzhuanpintu.v1`；
  - 存储结构：`{version, best:{easy,normal,hard}, recent, checkin:{dates,streak}, history[]}`；
  - 清除数据按钮走 `LX_SHARED.storage.remove('v1')`；
- `calcStreak(dates)` → `LX_SHARED.progress.streak(dates)`。

## 5. 合规（教育工具指导原则）

- 有标准答案（每碎片唯一正确方向）→ 安全练习区；
- 无排行榜/无跨用户对比 → 个人纵向激励（星级/打卡/最佳）；
- UI 文案练习用语（「点碎片转方向，全部转正就完成」）；
- 零图片素材（纯程序化 SVG），包体 0.03 MiB。

## 6. 技术要点

- Chrome 61 基线（ES2017 经典脚本、CSS 无 gap/aspect-ratio/clamp）；
- 双模式：index.html 脚本顺序 `data.js → _shared/lx-shared.js → scenes.js → main.js`；
- 构建：`python build_all.py --tool 旋转拼图`（offline zip → publish/益智/；online 仅部署目录）；
- 复用：scenes.js 基于简单拼图场景库（8 正方形场景 + 元素 draw）直接复制。
