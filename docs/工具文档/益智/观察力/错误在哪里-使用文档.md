# 错误在哪里 — 使用文档

> 系列：益智 · 观察力 ｜ 版本：v1.0（2026-09-22）
> 一句话：找出场景里不对劲的地方，点一点它！

## 这是什么

「错误在哪里」是一幅**有错误的场景图**——比如海底飘来火箭、森林里站着雪人、农场出现宇航员。
孩子需要**观察并找出那个不符合场景逻辑的元素**，点选它即答对。

适合 6-9 岁（K1-3 至 K4-6），训练：**观察力 + 逻辑合理性判断**。

## 怎么玩

1. **选择难度**：简单 5 关 / 普通 6 关 / 困难 8 关（首页显示各难度最佳成绩）。
2. **找出错误**：每关显示一幅场景图，其中有 **1 个不该出现的元素**，点它！
   - 点对：✓ 答对啦！进入下一关；
   - 点错：错点 +1（红闪提示「再看看…」），可以继续点，不判负。
3. **完成练习**：全部关卡完成 → 结算页（星级 + 错点 + 用时）。
4. **打卡**：完成练习后可打卡，连续天数在顶部显示（🔥 连练 N 天）。

## 星级规则

| 星级 | 条件 |
|---|---|
| ★★★ | 全程 0 错点 |
| ★★☆ | 错点 ≤ 2 |
| ★☆☆ | 错点 > 2 |

> 星级只和自己比（鼓励进步），没有排行榜、不和别人比。

## 家长面板

首页右下角空白处**连点**可进入家长面板（或用键盘 F7）：

- 累计/连续打卡天数；
- 各难度最佳成绩（星级/错点/用时）；
- 最近 10 条练习记录；
- 清除所有数据（不可恢复，谨慎使用）。

## 常见问题

**Q：孩子点错会扣分吗？**
A：不会。错点只计数影响星级，不判负、无失败惩罚，鼓励继续尝试。

**Q：数据存在哪里？**
A：全部保存在本机浏览器（localStorage，键 `redtools.cuowu.v1`），不联网、无账号、无上传。

**Q：会收集孩子信息吗？**
A：不会。只存练习记录（星级/错点/打卡），数据最小化。

## 离线使用

下载 zip → 解压 → 双击 `index.html` 即可使用（完全离线，无需网络）。
