# 全球小学生数学科普读物清单

> **调研日期**：2026-09-24
> **范围**：面向 6–12 岁（小学阶段）的数学科普 / 知识读物，全球主要国家与地区
> **筛选原则**：不选"讲得全"的，选"讲得活"的——能体现本质、留白、可迁移；对照"形式化教学四缺口"（本质梳理 / 逻辑思维 / 举一反三 / 生活结合）
> **数据来源**：Mathical Book Prize 官方名单（209 本）、日本数学会出版奖、中国国家级科普奖项、多轮交叉网络调研
> **状态**：v1.2（约 75 部核心书目；v1.1 经 Oracle 审查增补；v1.2 完成 12 处【待核实】定点核验——2 处修正、1 处无法核实降级、9 处确认）

## 七、对照"形式化教学四缺口"——书目 → 缺口映射

> 背景判断：当前中小学数学教学**过于形式化**——本质梳理不足、逻辑思维锻炼不足、举一反三与生活结合不足、师生灵活性不足。以下按缺口分类，标注代表性书目。

| 缺口 | 补法 | 代表书目 |
|---|---|---|
| **本质梳理**（记住了"是什么"不知道"为什么"） | 从问题/悖论/量感出发重建概念 | 遠山启"水道方式"（先量后数）、安野光雅 13 种数学思想、张景中"只讲思想不讲理论"、《数字魔鬼》虚构词汇、《数的"发现"故事》、**Wells《你能数到 googol 吗》量感阶梯**、**Malba Tahan《算数的人》以解题叙事逼近"数为何物"** |
| **逻辑思维**（证明被简化成套模板） | 暴露思考过程：猜想→试错→修正；悖论与谜题留白 | 《平面国》《爱丽丝》悖论、Math Curse、《点与线》、Ivan Moscovich 315 题、苏联奥数题库、《啊哈！灵机一动》、**Dudeney/Loyd 谜题根脉**、**KenKen 不靠试错推演** |
| **举一反三**（题型归纳=同一题刷 N 遍） | 一题多解、跨情境迁移 | 《数学西游记》（明确"一题多解"）、Sir Cumference 跨情境迁移、Life of Fred 连续叙事、波利亚《怎样解题》方法、《好玩的数学》、**谈祥柏《数学百草园》一题多变** |
| **生活结合**（"小明买苹果"贴壳应用题） | 真实问题驱动：零花钱、做菜配比、游戏规则中的概率 | Bedtime Math 睡前题、《从小做数学高手》六职业、Math Matters 食谱活动、别莱利曼从生活现象反推、《门铃响了》分饼干、**Adler《百万、十亿、万亿》把身边数字变可感** |

**结构性发现**（多路交叉验证）：

1. **美国占英语市场 70%+**，Mathical 是英语世界唯一系统性筛选机制；
2. **德法英本土数学童书国际声量弱**——德国靠 Enzensberger 一人扛，法国未识别出公认小学数学科普代表作（已知缺口），英国以活动书（Usborne）为主；
3. **中日双轨最明显**：
   - 中国：童话派（李毓佩）+ 院士派（张景中）
   - 日本：绘本派（安野光雅）+ 教育革命派（遠山启）
   - 韩国：漫画派（柳己韵）+ 绘本启蒙派（你好！数学）
   - 俄罗斯：问题集/兴趣班传统（用问题培养智力）
   - 以色列：数学家故事路线
   - 印度：拉马努金传记绘本
4. **东亚课堂训练全球领先但数学兴趣调查常年垫底**——恰说明需要"无标准答案安全区"的科普读物补位；
5. 该品类**仍在活跃期**：Sir Cumference 2024 出新册、Mathical 年年更新，不是"已完结的经典清单"；
6. **数学家传记绘本**是英语世界独有且活跃的子体裁（Erdős/Sophie/Ramanujan/Fibonacci/Pythagoras/Einstein），对应"本质"缺口的"以人带史"路径，东亚尚无对应规模化产品；
7. **拉美数学文学化传统由 Malba Tahan 一人奠基**（《算数的人》1938 至今拉美学校必读），与东亚"童话派+院士派"、苏俄"问题集派"构成第四条路线。

## 八、内容设计参考（可用于点读陪练 / 素材系统）

- **筛选背书**：优先对标 **Mathical 名人堂 + 日本数学会出版奖 + 中国国家级奖** 三重背书条目。
- **可复用编排模式**（"本质优先"三种结构）：
  1. **《数字魔鬼》模式**：12 梦境 = 12 个概念单元，每单元一个虚构词汇 + 一个核心问题；
  2. **李毓佩模式**：故事块驱动，每故事对应一个课内知识点，显式设计"一题多解"环节；
  3. **遠山启模式**：量 → 数的递进（先建立大小/长短直觉，再引入符号运算）。
- **缺口补齐检查**：每个内容单元自检——是否触及"为什么"（本质）？是否留了猜错也安全的空间（逻辑）？是否至少两种解法（举一反三）？是否锚在真实情境（生活）？
