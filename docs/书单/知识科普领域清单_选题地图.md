# 面向中小学生与家长的知识科普领域清单（选题地图）

> **状态**：v1.3（2026-09-24；v1.1 编入数学/逻辑；v1.2 标记 13 号已交付；v1.3 同步逻辑/计算机附录定点核验升 v1.1）
> **用途**：`docs/书单/` 书单系列的**选题总规划**——完整领域地图（23 项，已交付 3 项）+ 优先级排序。
> **方法论**：每个领域按"并行 librarian 多轮穷尽搜索 → Oracle 审查 → 定点核验【待核实】→ 落正式文档"流程生产（同《全球数学科普读物清单》）。

## 全领域地图

### A. 学科基础线（对应课内，补"本质 / 思维 / 生活"缺口）

1. **数学** — 数学科普、数学知识读物 → ✅ `docs/书单/全球数学科普读物清单.md`（v1.2，12 处待核实已核验）
2. **物理科普** — 力学 / 电光 / 相对论启蒙（DK 物理、Chris Ferrie 系列等）
3. **化学科普** — 元素故事、厨房化学（小学偏"现象"，初中偏"本质"）
4. **生物 / 自然观察** — 微观世界、动植物、人体（法布尔、DK 自然）
5. **天文 / 宇宙** — 太阳系、航天、黑洞启蒙（长销、受众广）
6. **地球科学 / 气象 / 地质** — 火山、地震、石头、天气（STEM 缺口中较空白）
7. **语文 / 阅读写作** — 字源、修辞、整本书阅读（对应数学的"本质梳理"）
8. **历史科普** — 少年版世界史 / 中国史（希利尔、写给儿童的中国历史）
9. **地理 / 地图** — 国家、地形、地图绘本（DK 地图、各国童书）
10. **外语 / 多语言启蒙** — 与点读陪练产品线相邻，做书单需划清边界

### B. 思维与元能力线（跨学科底层能力）

11. **逻辑思维 / 思辨 / 元认知** — 童书 + 家长认知类 → ✅ `docs/书单/全球逻辑思维与元认知读物清单.md`（v1.1，附录 B 8 项已定点核验）
12. **哲学启蒙 / 儿童哲学（P4C）** — 与 11 号交叉，边界需划清（或作 11 号子章节）
13. **计算机 / AI / 编程思维** — 不教代码教计算思维（CS Unplugged 一类）→ ✅ `docs/书单/全球计算机与编程思维读物清单.md`（v1.1，附录 C 8 项已定点核验；AI 素养并入本清单）

### C. 素养与生存线（家长最愿买单）

14. **媒介素养 / AI 素养** — 信息真假、AI 幻觉——**2026 年新缺口**（注：AI 素养书籍已并入 13 号清单；本号余媒介素养/信息真假独立方向）
15. **安全教育** — 交通、防灾、身体边界
16. **健康 / 生理 / 性教育** — 小学高段刚需，优质中文书稀缺
17. **情绪与社交（SEL）** — 与 11 号重叠区，可并入或单列
18. **财商 / 经济启蒙** — 零花钱、交换、稀缺（教材缺口大）
19. **艺术 / 音乐 / 设计（美育）** — 偏家长选书

### D. 家长认知线（"我即我脑"同款）

20. **脑科学与学习科学** — 已有《我即我脑》锚点，可扩 Swaab / Doe /《Make It Stick》
21. **发展心理学 / 教育方法** — 依恋理论、教育经典（《教养的迷思》中译待核）
22. **青春期沟通 / 家庭治疗** — 刚需强但书目杂，需强筛选
23. **家庭教育通识 / 亲子关系** — 泛家长书市，需强筛选防鸡汤

## 优先级建议（缺口 × 可行性，不含已交付）

| 序 | 领域（编号） | 理由 |
|---|---|---|
| 1 | 物理 + 天文（2、5） | 与数学方法论完全同构，复用搜索范式 |
| 2 | 脑科学家长书（20） | 已有锚点（《我即我脑》），扩写成本最低 |
| 3 | 健康 / 性教育（16） | 刚需强，但需先做中文书市调研 |
| 4 | 媒介素养（14，余量） | AI 素养已随 13 号交付，余信息真假方向 |

## 选书总原则（跨领域通用）

- **不选讲得全的，选讲得活的**（重本质梳理、逻辑思维、举一反三、生活结合四缺口）
- 清单格式：书名（原文 + 中译）/ 作者 / 国籍（国旗 emoji）/ 年代 / 特点 / 影响力
- 不确定项标【待核实】，定点核验后升级版本
- 限 6–12 岁学生 + 家长认知类；不虚构销量、奖项、年份
- **归属边界**：与点读陪练（教材同步）、RedTools（可玩工具）区分——本地图只收"读物 / 书单"类知识科普
