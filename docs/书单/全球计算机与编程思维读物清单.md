# 全球计算机 / AI / 编程思维读物清单（中小学生 · 家长）

> **状态**：v1.1（2026-09-24；v1.0 四路 librarian 并行调研；v1.1 附录 C 8 项定点核验——3 项重大勘误（三书虚构删除/CCF 四书修正/成长算法口径）、中译项统一"暂未见"、2 项网络受限保持 ❓）
> **范围**：6–12 岁学生读物（绘本 / 章书 / 练习册）+ 家长认知类；重点覆盖 2014–2026，奠基经典不设下限。
> **选书原则**：不选讲得全的，选讲得活的——重"计算思维本质、逻辑、举一反三、生活结合"，不选纯教程与教材。
> **方法**：四路并行穷尽搜索；不确定项标【待核实】→ 附录 C 已定点核验升 v1.1。

## §7 结构性发现（本领域 vs 数学领域对照）

1. **AI 素养童书是真实白空间（2024–2026）**：主流首发者仅 DK *A Kids Book About*（2025）与 Gestalten/Watering Can；自出版长尾同质化严重、缺权威——**比数学清单的法国缺口更空**。
2. **"家长 × AI"是全新品类且零中译**：Raising AI（MIT Press 2025）等 4 本 2024–2026 新书均无中文版——**明确翻译引进机会**。
3. **中文世界"李毓佩空缺"**：涂子沛是**唯一现象级**儿童 AI 科普作家（15.5 万印量），**缺乏作者群**——与数学界的李毓佩/谈祥柏/张景中"三驾马车"形成鲜明对照；CS 少儿科普作家群 = 结构性缺口。
4. **信谊/蒲公英线未识别出编程绘本代表作**；原列《这就是计算机科学》《了不起的编程》《寫給孩子的電腦史》三书经查**均不存在/系误记，已从调研结论删除**（v1.1 核验）。
5. **市场成熟度分层**：童书+教材并行成熟 = 日/韩/法/中/台；教材为主无旗舰童书 = 印度；2024 前空白正被填补 = 以色列；原创故事绘本稀缺 = 巴西；**俄语原创未识别（结构性缺口）**。
6. **IP 联名是日台市场独有趋势**：ちいかわ、SPY×FAMILY 编程练习册——中国尚无同款头部 IP 联名编程书【机会点】。
7. **政策驱动出版**：日 2020 必修化、韩 2019 必修、法 Scratch 进课纲、德 Calliope 官配、台 108 课纲——**各国出版爆发均滞后政策 1–2 年**；中国 2022 信息科技新课标后的原创潮尚在早期。
8. **无屏（Unplugged）理念全球同源**：CS Unplugged（新西兰 2008）→ 英国 Coding Unplugged（2023）→ 台湾不插电绘本（2019）——**一条可追溯的思想传播链**，与"数学本质派"呼应。
