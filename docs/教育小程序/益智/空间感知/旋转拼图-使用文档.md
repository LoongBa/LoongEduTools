# 旋转拼图 — 使用文档

> 系列：益智 · 空间感知 ｜ 版本：v1.0（2026-09-22）
> 一句话：碎片方向被转乱了，点一点把它转回正确方向！

## 这是什么

「旋转拼图」把一幅图切成小碎片——**碎片位置是对的，但方向被转乱了**
（有的横着、有的倒着）。孩子需要**点选碎片把它转回正确方向**，全部转正就完成练习。

适合 6-11 岁（K1-3 至 K4-6），训练：**空间感知 + 旋转思维 + 整体方位记忆**。

## 怎么玩

1. **选择难度**：简单 2×2 / 普通 3×3 / 困难 4×4（首页显示各难度最佳成绩）。
2. **转正碎片**：点一下碎片，它就转 90°；多点几次转回正确方向。
   - 拿不准方向？点「🖼 看原图」查看完整参考图。
3. **完成练习**：所有碎片方向正确 → 结算页（星级 + 旋转次数 + 用时）。
4. **打卡**：完成练习后可打卡，连续天数在顶部显示（🔥 连练 N 天）。

## 星级规则

| 星级 | 条件 |
|---|---|
| ★★★ | 旋转次数最少（每块只转对方向的次数） |
| ★★☆ | 旋转次数适中 |
| ★☆☆ | 旋转次数较多（多试几次方向） |

> 星级只和自己比（鼓励进步），没有排行榜、不和别人比。

## 家长面板

首页右下角空白处**连点**可进入家长面板（或用键盘 F7）：

- 累计/连续打卡天数；
- 各难度最佳成绩（星级/旋转次数/用时）；
- 最近 10 条练习记录；
- 清除所有数据（不可恢复，谨慎使用）。

## 常见问题

**Q：点错了会扣分吗？**
A：不会。旋转次数只影响星级，不判负、无失败惩罚，随时可继续。

**Q：数据存在哪里？**
A：全部保存在本机浏览器（localStorage，键 `redtools.xuanzhuanpintu.v1`），不联网、无账号、无上传。

**Q：会收集孩子信息吗？**
A：不会。只存练习记录（星级/旋转次数/打卡），数据最小化。

## 离线使用

下载 zip → 解压 → 双击 `index.html` 即可使用（完全离线，无需网络）。
