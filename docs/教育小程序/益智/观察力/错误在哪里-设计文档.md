# 错误在哪里 — 设计文档

> 系列：益智 · 观察力（子系列第 4 款）
> 版本：v1.0（2026-09-22 交付）
> 状态：✅ 已实现（审计 PASS / 冒烟双协议通过 / 双模式接入）
> 对标：小象脑力/未来之光「观察」维度——错误场景图找不合逻辑处

## 1. 定位与玩法

**一句话**：显示一幅场景图，图中故意嵌入 1 个「不合逻辑」的元素（如海底出现火箭、森林出现雪人），
孩子点选异常元素即答对。有标准答案判定（合规安全区，见 `docs/教育工具/教育工具产品指导原则.md`）。

**与同系列差异**：
- 找不同：两图对比找差异（5 种差异变换）；
- 错误在哪里：**单图找逻辑错误**（场景内嵌 1 个跨场景错位元素）——考察「逻辑合理性判断」而非「视觉差异」，
  比找不同高一个认知层次（需理解场景语义）。

## 2. 关卡与难度

| 难度 | 轮数 | 星级标准 |
|---|---|---|
| 简单 | 5 关 | 0 错 3★ / ≤2 错 2★ / 其余 1★ |
| 普通 | 6 关 | 同左 |
| 困难 | 8 关 | 同左 |

- 每关随机选场景 + 随机错位候选（8 场景 × 3 候选 = 24 种错误项，程序化随机，孩子不会背答案）；
- 场景可重复但错位元素/位置随机。

## 3. 错位候选设计（scenes.js 扩展）

复用找不同场景库（8 场景 × 8-10 元素，SVG 程序化零素材），追加 `window.WRONG_OPTIONS` 错位表：

| 场景 | 错位候选（跨场景借元素） |
|---|---|
| 海边 ocean | 兔子（森林）、章鱼（海底）、火箭（太空） |
| 森林 forest | 章鱼（海底）、雪人（冬日）、飞碟（太空） |
| 农场 farm | 鲸鱼（海底）、宇航员（太空）、企鹅（冬日） |
| 太空 space | 奶牛（农场）、鱼（海底）、花（花园） |
| 海底 undersea | 火箭（太空）、奶牛（农场）、雪人（冬日） |
| 城市 city | 鲸鱼（海底）、企鹅（冬日）、鹿（冬日） |
| 冬日 winter | 椰树（海边）、章鱼（海底）、蝴蝶（花园） |
| 花园 garden | 宇航员（太空）、鲸鱼（海底）、雪人（冬日） |

- 错位元素 = 从源场景 elements 数组取元素 draw 渲染，嵌入目标场景（`SCENE_BY_NAME` / `ELEM_BY_KEY` 索引）；
- 渲染位置 x/y 预设（场景视口 480×320 内，避开正常元素密集区）；
- 错位元素**融入场景配色**（不靠颜色刺眼，靠逻辑不合理），难度自然。

## 4. 交互与反馈

- 点错位元素 → 绿闪 +「✓ 答对啦！」+ 650ms 后进入下一关；
- 点正常元素 → 错点计数 +1 + 红闪 +「✗ 再看看…」（不判负、可继续，无失败惩罚）；
- 顶部状态栏：返回 | 进度（第 x / N 关）| 计时 | 错点计数。

## 5. 数据与存储

- `LX_SHARED.storage`（V0.4 双模式公共模块）：
  - `configure({toolName: 'cuowu'})` → 键前缀 `redtools.cuowu.v1`；
  - `loadStore/saveStore` 转发 `LX_SHARED.storage.get('v1')/set('v1', store)`；
  - 存储结构：`{version, best:{easy,normal,hard}, recent, checkin:{dates,streak}, history[]}`；
  - 清除数据按钮走 `LX_SHARED.storage.remove('v1')`。
- `calcStreak(dates)` → `LX_SHARED.progress.streak(dates)`（打卡连续天数）。

## 6. 合规（教育工具指导原则）

- 有标准答案（错位元素判定）→ 安全练习区；
- 无排行榜/无跨用户对比 → 个人纵向激励（星级/打卡/最佳）；
- UI 文案用「练习/关/完成练习」练习用语，无「游戏/闯关/对战」；
- 零图片素材（纯程序化 SVG），包体 0.04 MiB。

## 7. 技术要点

- Chrome 61 基线（ES2017 经典脚本、CSS 无 gap/aspect-ratio/clamp）；
- 双模式：index.html 脚本顺序 `data.js → _shared/lx-shared.js → scenes.js → main.js`；
- 构建：`python build_all.py --tool 错误在哪里`（offline zip → publish/益智/；online 仅部署目录）；
- 复用：scenes.js 基于找不同场景库扩展（8 场景 73 元素 draw 复用 + 错位表）。
