# 数独入门 — 使用文档

> 经典数独启蒙小练习：点空格、选数字，让每行、每列、每宫都只出现一次 1~N，全部填满就过关；**每次进入都是算法新出的盘面**，锻炼观察与逻辑推理能力。
> 适用：手机 / 电脑（点空格 + 底部数字条选数；电脑可用键盘 1-9 输入）。
> 版本：v1.4（含 🎯 技巧教学关 + 📖 规则教学三步 + ✏ 候选笔记铅笔模式 + ▶ 断局恢复）· 更新：2026-09-25
> ⚠️ Chrome 61 / Android 8.1 / 真机 WebView 未实测。

---

## 1. 怎么练

1. 打开工具，在**难度选择页**选一个难度：简单 4×4 / 普通 6×6 / 困难 9×9。
2. **还不懂规则？** 先点难度页顶部的「📖 规则教学」——一个 4×4 小盘面，三步带你看懂「每一行、每一列、每个宫都只能出现一次」，看完点「开始挑战」就回来选难度啦。
3. **想学解题技巧？** 点「🎯 单宫排除技巧」——跟着引导在简化盘上练一次「看一个宫缺哪个数」，练完点亮技巧徽章（教学关不计成绩，随便试）。
3. **点一个空格**，格子会带**橙色描边**，同时它的同行、同列、同宫格子变浅蓝，盘面上相同的数字变浅橙（帮你一眼看清"这个数能放哪"）。
4. 在底部**数字条**点一个数字（1 到盘面大小）填入：
   - 填了行/列/宫里**没有的数**：格子闪一下绿，数字确定；
   - 填了行/列/宫里**已有的数**：格子闪红，这个数不进格子，错误次数 +1，下方提示换一个试试。放心，填错**不会扣分、不会结束练习**，擦掉重填就行。
5. 直到**所有格子都填满**（每行每列每宫都是 1~N 各出现一次），就过关啦！
6. 过关后按**提示次数与错误次数**评定星级，记录最佳成绩并点亮今日打卡。

## 2. 练习规则

| 规则 | 说明 |
|---|---|
| 目标 | 把盘面全部填满，使每行、每列、每宫（粗线框）都是 1~N 各出现一次 |
| 操作 | 点空格 → 数字条点数字（电脑键盘 1-9 也行） |
| 填数 | 行/列/宫不冲突 → 绿色确认接受；有冲突 → 红闪 400ms、错误 +1、提示换数，不改变盘面 |
| **规则教学（v1.3）** | 难度页「📖 规则教学」→ 4×4 演示盘三步讲解「每一行 / 每一列 / 每个宫都只能出现一次」，每步高亮对应约束格、问「缺哪个数字」，可上一步/下一步/跳过，看完「开始挑战」回难度页 |
| **技巧教学关（v1.4）** | 难度页「🎯 单宫排除技巧」→ 独立教学关（4×4 简化盘）：跟着引导点空格、点数字，练会「看一个宫里缺哪个数就填哪个」；填错温和提示**不计错误**；完成点亮技巧徽章；教学关**不计入普通成绩**、可随时返回、可重练 |
| **候选笔记（v1.1）** | 点「✏ 笔记」进入铅笔模式 → 点空格 → 点数字在格子里记候选数（小字），再点同数字取消；若该数同行/列/宫已存在会被拒绝并温和提示；填好一个数后，同行/列/宫其他格里的这个候选会自动清除（自动铅笔） |
| **断局恢复（v1.2）** | 玩到一半退出（返回难度/关页面）会自动保存进度；再进来时难度页顶部出现「▶ 继续上次」，点它接着玩，计时从上次继续算；通关或点重新开始后，旧进度作废 |
| 已知格 | 浅灰底深色字的格子是题目给好的数，**不可编辑** |
| 工具 | 橡皮（擦掉选中格，值+笔记一起）/ 撤销（恢复上一步，含提示/橡皮/笔记均可撤）/ 提示（自动填正确解）/ ✏ 笔记（铅笔模式） |
| 出错惩罚 | **无**：答错不惩罚，只有冲突计错误次数，影响星级 |
| 星级 | 0 提示 0 错 3★ / 提示 ≤1 且 错 ≤3 2★ / 其余 1★（用过提示最高 2★）；记笔记不影响星级 |
| 出题 | 每局算法随机生成全新盘面（保证只有唯一正确答案），不会背题 |

## 3. 界面说明

- **难度选择页**：顶部「📖 规则教学」入口 + 「🎯 单宫排除技巧」入口（练完变 ✅）；三个难度卡片，显示该难度**最佳成绩**（星级 · 用时 · 错误 · 提示），底部是打卡日历入口。
- **顶栏**：`← 返回`、当前难度名与盘面信息（如「4×4 · 已知 10 格」，是**本局实际**已知格数）、`⏱ 用时`（**进入练习页即开始**计时，数独按整局计时）。
- **棋盘**：白底卡片里的 N×N 方格；**粗线把盘面分成若干宫**（4×4 分成 4 个 2×2 小宫，9×9 分成 9 个 3×3 小宫）；已知格浅灰底深色字，你填的数字是天蓝色。
- **高亮教具**：选中格橙色描边；同行/列/宫浅蓝 tint；盘面同数字浅橙 tint——选中一个格子，相关的约束一眼可见。
- **数字条**：底部一排 1~N 数字按钮（大按钮，方便小手点按）。
- **工具条**：橡皮 / 撤销 / 提示 三个按钮。
- **错误计数**：练习页底栏 `❌ N` 实时显示本局冲突次数。
- **提示行**：棋盘下方提示当前操作（正常蓝色；需要提醒时橙色）。

## 4. 成绩与打卡

- **星级**（按提示与错误两指标，宽松友好）：
  - ★★★：没点过提示、一次都没填错过；
  - ★★：提示 ≤1 次 且 错误 ≤3 次（**点过提示最高 2 星**）；
  - ★：其余情况（过关即有）。提示次数越多、错误越多，星级越低，鼓励独立思考。
- **提示**：点「提示」自动找一个最好填的空格并填上正确答案，同时告诉你它填在哪（如「提示：第 3 行第 5 列 填数字 7」）。用提示会**封顶 2 星**；如果提示说「有格子被填错了，先用橡皮擦掉」，说明你前面填的数堵住了它，先用橡皮擦掉再试。
- 每过关一局即点亮**今日打卡**；打卡日历显示本月打卡与连续天数（连续 7 天及以上有 🎉）。
- 各难度分别记录**最佳成绩**（星级高优先，同星级比用时短）；**最近用时**与最近 **30 局**成绩记录自动保存。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- 点错格子了？**再点一下同一个格子**取消选中，或直接点另一个格子切换。
- 数字条上一排数字，先想好"这个数放哪一行、哪一列、哪一宫"再点，减少试错。
- 提示之前先把填错的数**用橡皮擦掉**：提示会自动跳过被填错的格子，擦干净才能给出最有用的提示。
- 9×9 盘面格子较小，建议设备竖屏使用；数字字号已按盘面自动调整保证可读。想先熟悉规则，可以从 4×4 / 6×6 练起，或先看难度页的「📖 规则教学」。
- 电脑上练：数字键 1-9 填数（超出本局盘面的数字自动忽略），Backspace 或 Delete 擦掉选中格。
- 计时从进入练习页就开始，想慢慢观察不慌，星级主要看提示和错误，不卡时间。
- 玩到一半想歇会儿？直接关页面或返回难度就行——下次打开点「▶ 继续上次」接着玩，进度和记的候选笔记都在。

## 6. 常见问题

**Q：填错数字会不会扣分、会不会算失败？**
不会。只要填的位置行/列/宫不冲突，任何数字都会被接受（这局照样能赢）；只有**冲突**（行/列/宫里已有这个数）才计 1 次错误，也不会结束练习，擦掉或撤销重填就好。错误次数只影响星级：0 错 3 星、≤3 错有机会 2 星、超过 3 错 1 星。

**Q：提示能不能一直用？会不会掉星？**
可以一直点，每个提示都会自动填一个正确的数。但**用一次提示，这局最高就只能拿 2 星**（提示 ≤1 次且有条件拿 2 星；用多了或错误超过 3 次就是 1 星）。建议实在卡住时才用。

**Q：橡皮和撤销有什么区别？**
橡皮是**擦掉当前选中格子**里的数字；撤销是**恢复上一步操作**（填的数、擦掉的数、提示填的数都能撤，可连续撤销到开局）。想清掉一格用橡皮，想退回上一步用撤销。

**Q：题目给的格子为什么不能改？**
浅灰底的格子是这局题目给出的**已知数**，数独盘面以它们为准，改掉题目就不成立了。你只需要填空白格，让每行每列每宫都凑齐 1~N。

**Q：适合几岁的孩子？**
定位 K1-3（幼儿园中大班）到 K4-6（小学中高年级）。「简单 4×4」刚接触数独就能练（数字只用到 1~4）；「普通 6×6」适合熟悉规则后进阶；「困难 9×9」是标准数独，适合小学高年级或想挑战的孩子，家长一起练也不无聊。所有局数每次进入都是新盘面，不会背答案。完全没接触过数独的孩子，建议先看「📖 规则教学」，再练「🎯 单宫排除技巧」，最后从 4×4 开始。
