# 数独小侦探 · H5 数独（启蒙版 × 普通版）设计草案

> 面向：龙爸乐学 · 线一益智类 · 逻辑迷宫（思维逻辑维度）
> 定位依据：小象脑力 / 未来之光 / 洪恩思维 对标 + 《益智类小游戏_风格规范与Agent提示词》设计令牌
> 状态：草案 v0.1，待评审；**难度参数为建议值，需真实试玩校准**
> 配套原型：`数独小侦探原型/index.html`（单文件 H5，启蒙版 + 普通版共用引擎）

---

## 0. 结论先行

1. **一个引擎、两套参数与皮肤、一个入口**：同一套数独规则，两条学习路径；开始页选版本（或家长按年龄设置自动推荐），共用存档与奖励。
2. **双版本**：启蒙版（3–6 岁，规则启蒙）与普通版（7–12 岁，策略进阶），交接带在 L2。
3. **不做变体**：锯齿、对角线等变体玩法砍掉，远期再议；差异化落在「教学体系 + 图标降龄 + 技巧报告」，而非玩法堆砌。
4. **降龄三抓手**：传统数独对孩子有三道门槛——数字抽象、规则抽象、策略抽象；对策是**图标化**（启蒙段用图形符号代替数字）、**盘面小型化**（4×4 → 6×6 → 9×9）、**教学前置**（每级配对应技巧课）。

## 1. 定位与规划衔接

- 归属「逻辑迷宫 · 思维训练系列」，系列色青绿 `#2FBF9E`，乐仔角色贯穿，三段式三屏，答错不惩罚、星星 + 成长树奖励——均复用既有设计系统，不重新设计。
- 与规划文档（《小象脑力×未来之光_内容模块对标》）衔接：
  - 线一 P0 任务清单已有「数独启蒙 4×4」——本产品即该任务的**旗舰化**落地；
  - 线二 P2「逻辑与推理」应用规划了数独题库——本产品的**生成引擎与技巧体系可直接反哺**，避免重复开发。

## 2. 双版本对照

| 维度 | 启蒙版 | 普通版 |
|---|---|---|
| 定位 | 规则启蒙 · 兴趣培养 | 策略训练 · 技巧进阶 |
| 学段 / 年龄 | preK–K1（3–6 岁） | K1-3–K4-6（7–12 岁） |
| L 级 | L1–L2 | L2–L4 |
| 符号 | 图形图标（颜色 + 形状双编码，色弱友好） | 数字 1–9 + 候选笔记（铅笔模式） |
| 盘面 | 4×4 → 6×6 | 6×6 → 9×9 |
| 难度档 | 启蒙 / 进阶 2 档 | 简单 / 中等 / 困难 / 挑战 4 档 |
| 计时 | 无 | L3 起计时挑战 |
| 教学 | 先练「行 + 列」不重复 → 再加「宫」；动画 + 跟做，全程语音引导 | 技巧课逐级解锁：单宫排除 → 行列排除 → 区块排除 → 交叉排除 |
| 节奏 | 无失败 · 无惩罚 · 填错只温和提示 | 错误温和提示 · 提示可关 |
| 升版衔接 | 完成启蒙版（约 6–7 岁）→ **一键升版**：星星、成长树、已学技巧、进度全部迁移，从 L2 起步 | — |

> 关键定性：**启蒙版不是普通版的"减配"，而是换了一套入门引擎（图标 + 语音 + 无失败）；普通版也不是启蒙版的"加难"，而是进入策略训练（候选笔记 + 技巧课）。**

## 2.5 发布版本策略（一套引擎，界面控制）

产品内三个模块，共享同一套引擎与题库：

| 模块 | 技巧层 | 盘面 | 面向 |
|---|---|---|---|
| 启蒙版 | L0–L1（规则、排除、唯一余数） | 4×4 / 6×6 | 3–6 岁 |
| 普通版 | L1–L4（单宫排除 → 行列/区块/数组） | 9×9 | 7–12 岁 |
| **自由解题模块** | **L5–L7（鱼翼 / 唯一性 / 链 / 强制链 / 自编题）** | 9×9 | 高年级 / 成人 / 竞赛培训 |

发布两个版本，**差异只在界面层开放范围**，算法与题库完全不分：

- **适龄教学版**：只开放启蒙版 + 普通版（L0–L4），面向儿童与家长。
- **全功能版**：开放全部三个模块（L0–L7），含自由解题模块。

> 算法不区分：一套生成器按 L0–L7 技巧标签出题（见 §3 与开发方案），界面层按发布版本控制开放哪些难度档与模块。教材中超出适龄的高阶内容（L5–L7）统一收进自由解题模块，不污染适龄版体验。

## 3. 难度阶梯（参数化四参数）

难度由四个参数共同决定：**盘面尺寸 × 符号形式 × 已知格密度 × 所需技巧层级**，对齐规划 5.0 的 L1–L4 口径（每级内再分 3 子档 -/+/++，连败自动降档）。

| 参数 | L1 启蒙（启蒙版） | L2 基础（启蒙→普通交接） | L3 进阶（普通） | L4 挑战（普通 · 远期） |
|---|---|---|---|---|
| 盘面 | 4×4 | 4×4 / 6×6 | 6×6 / 9×9 | 9×9 |
| 符号 | 图形图标 | 图标 → 数字 1–6 | 数字 1–9 | 数字 + 完整候选笔记 |
| 已知格（建议） | 4×4 约 9–12 / 16 | 6×6 约 20–24 / 36 | 9×9 约 32–36 / 81 | 9×9 约 17–26 / 81 |
| 教学重点 | 规则动画（行 / 列 / 宫） | 单宫排除法 | 行列排除 → 区块排除 | 交叉排除 · 唯一矩形等高阶 |
| 单局特征 | 无计时 · 语音引导 | 轻计时可关 · 铅笔笔记入门 | 计时挑战 · 技巧徽章 · 提示可选 | 挑战赛 · 个人纪录 · 成就解锁 |

> 注意：9×9 在手机竖屏格子偏小，L3 起建议自动切横屏或允许缩放（见 §6 交互坑）。

## 4. 教学体系（三层，教学关独立标注，不混入普通关卡进度）

1. **规则教学**：动画演示「每行、每列、每个宫不重复」。启蒙版教学顺序是关键——**先只教"行 + 列"不重复，再引入"宫"**，3–5 岁一次接受三个约束太多（这是儿童数独教学公认的降阶方式，非变体）。
2. **技巧教学**：与难度绑定逐级解锁，每个技巧配 1–2 个教学关 + 获得技巧徽章：
   - L2 单宫排除 → L3 行列排除 / 区块排除 → L4 交叉排除等高阶。
3. **题面引导**：在真实盘面上解释「第一步为什么填这里」——这是儿童数独与成人数独最大的差异点；提示功能同时给出逻辑解释，而非只给答案。

## 5. 趣味与激励

- **复用**（既有设计系统）：乐仔四表情（开心 / 思考 / 鼓励 / 惊讶）、星星（1–3 颗）+ 成长树积分、答错不惩罚、连续 2 次失败自动降难度、无排名无竞技无社交。
- **数独特有**：
  - 闯关地图（每级一段旅程，关卡按难度档推进）；
  - 技巧徽章收集（学会一种排除法点亮一枚徽章）；
  - 结算按「用时 + 提示次数」评 1–3 星（启蒙版不评时，只评完成）。

## 6. 界面与交互

- **三屏结构**：开始页（版本选择 + 规则教学入口 + 开始）→ 游戏页 → 结算页（星星 + 鼓励语 + 再来一次 / 换难度）。
- **输入方式**：底部「数字（图形）条 + 点选格子」；**不做成人版九宫格键盘**。候选笔记（铅笔模式）L2 起开放。
- **辅助**：点选格子高亮同行同列同宫（教具功能，非装饰）；撤销 / 橡皮；冲突即时温和提示（启蒙版语音「再试试」）。
- **两个交互坑的解法**：
  1. 9×9 小屏格子过小与触控区 ≥88px 冲突 → 9×9 自动切横屏或允许双指缩放，数字用高对比大字号；
  2. 启蒙版防误触 → 增加撤销与确认提示。
- **设计令牌**（沿用全局规范）：纸白 `#FFF9F0` 底、墨灰 `#3A3A45` 字、青绿 `#2FBF9E` 主色；20px 卡片圆角、全圆角按钮、8pt 栅格、柔和低对比投影；圆体字族，字号阶梯 28 / 24 / 20 / 16 / 14；图标圆角线性、笔画 3px。

## 7. 家长与数据

- **技巧掌握度是数独独有卖点**：记录每个技巧（单宫排除 / 行列排除 / 区块排除 / 交叉排除）的实际使用次数与首用关卡，周报呈现「学会了哪些排除法」——正好补齐规划 5.4 的报告层。
- 其他：单局用时、正确率、连续打卡天数；家长端防沉迷时长；无社交、无付费。
- 启蒙版额外记录：语音引导开启率、平均单局时长（判断难度是否合适）。

## 8. 题库与工程

- **生成算法**：随机回溯填满解 → 按目标已知格数挖洞 → 每挖一格用「回溯求解器 + 唯一解校验」验证，不唯一则回填；参数化出题 = 天然无限题库（对标未来之光 6000+ 难度参数化思路）。
- **技术形态**：单文件 HTML / CSS / JS（无外部依赖），可离线打开；进度与设置存 localStorage。
- **语音取舍（需提前拍板）**：单文件离线运行与启蒙版「全程语音」有张力——
  - v1：浏览器 TTS（Web Speech API，无外部依赖，音色不可控，部分离线场景不可用）；
  - v2：内嵌语音包（增大文件体积）或外置资源按需加载。
  - 建议 v1 先跑通交互，v2 评估语音包。

## 9. 合规与无障碍

- 无广告、无社交、无诱导付费、无强制授权；家长模式可退出。
- 触控区 ≥88px、页面文字 ≤30 字、音效可关、动效 200–300ms。
- 图标「颜色 + 形状」双编码（色弱儿童可辨）；数字高对比。
