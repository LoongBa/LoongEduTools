## 1. 定位与玩法

**一句话**：情景安全选择题——每轮 1 题（防溺水/交通/用电/防拐/饮食/消防），4 选 1 点选正确答案，
即时反馈 + 安全知识解释。有标准答案（单选唯一正确，合规安全区）。

**题库**：6 情景 × 6 题 = 36 题（emoji 图标零素材，程序化内嵌）：
交通安全（红绿灯/安全座椅/骑车头盔）、防溺水（不独自下水/呼救/救生衣）、
用电安全（湿手/裸露电线/雷雨）、防拐骗（陌生人/走丢/家庭信息保密）、
饮食安全（洗手/过期/野果）、消防安全（119/湿毛巾逃生/煤气）。

## 2. 关卡与难度

| 难度 | 题量 | 星级标准 |
|---|---|---|
| 入门 | 6 题 | ≥5 对 3★ / ≥3 对 2★ / 其余 1★ |
| 进阶 | 8 题 | ≥7 对 3★ / ≥5 对 2★ / 其余 1★ |
| 挑战 | 10 题 | ≥9 对 3★ / ≥7 对 2★ / 其余 1★ |

- 每局随机抽题（乱序取前 rounds 题），可重复练习；
- 答对：绿框 + ✓ + 安全知识解释；答错：红框 + 正确答案 + 解释（学习反馈，不判负）。

## 3. 数据与存储

- `LX_SHARED.storage`（V0.4 双模式公共模块）：`configure({toolName: 'anquanchangshi'})` →
  键前缀 `redtools.anquanchangshi.v1`；结构 `{version, best, recent, checkin, history}`；
- `calcStreak(dates)` → `LX_SHARED.progress.streak(dates)`。

## 4. 合规

- 有标准答案（单选）→ 安全练习区；无排行榜/无跨用户对比；UI 用「题/练习」练习用语；
- 零图片素材（emoji + 文字），包体 0.04 MiB。

## 5. 技术要点

- Chrome 61 基线（ES2017 经典脚本）；双模式脚本顺序 `data.js → lx-shared.js → main.js`；
- 构建：`python build_all.py --tool 安全常识问答`；
- 复用：打卡/星级/家长面板/清除数据模式对齐扩展系列。
