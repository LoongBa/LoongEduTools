# 小红书小工具产品矩阵规划方案

> 版本：v1.0
> 日期：2026-09-17
> 定位：一线教师设计的学习能力训练工具矩阵，小红书小工具为引流入口，教师版 H5 为核心交付



***

## 一、项目概述与定位

### 1.1 核心定位

**不做 B2G / 教育局采购大项目，不拼课件内容数量，做一线教师真正想用的交互式教学工具。**



* 以小红书小工具为**引流入口**，家庭端免费体验

* 以教师版离线 H5 为**核心交付**，课堂端专业使用

* 以**最佳实践 + 教学方案**为壁垒，不是单纯卖代码

### 1.2 目标用户



* **家长**：3-12 岁孩子的妈妈，重视教育，碎片时间想让孩子学点东西

* **教师**：一线小学老师，需要好用的课堂交互工具，愿意分享给班级家长

### 1.3 增长模型：B2C2C 裂变



```
教师课堂使用工具 → 班级群推荐家长 → 家长使用小红书小工具 → 家长口碑传播 → 更多家长/老师
```

一位老师带动 50 + 家庭，自下而上渗透。

## 二、小红书小工具平台规则与限制

### 2.1 上传规则



| 项目   | 规则                         |
| ---- | -------------------------- |
| 账号门槛 | 实名认证、注册≥180 天、粉丝≥1000、无违规  |
| 包体上限 | 单个 zip ≤ 10MB              |
| 目录规范 | index.html 放 zip 根目录，不嵌套多层 |
| 审核方式 | 每个小工具单独提交审核                |
| 挂载规则 | 一篇笔记只能挂 1 个小工具；一个小工具可挂多篇笔记 |

### 2.2 沙箱能力与禁止项

**✅ 允许：**



* HTML/CSS/JS，DOM 操作

* `<audio>` 播放 zip 内本地 mp3

* Web Speech API（本地 TTS，不联网）

* localStorage（本地存储，保存进度 / 打卡记录）

* 用户点击触发音频播放

**❌ 完全禁止：**



* 任何网络请求（fetch/XHR/WebSocket）

* 加载 zip 外的图片、音频、字体

* 服务端接口、AI 接口、云端存档

* 自动播放音频

### 2.3 上传数量

目前无公开明确的数量上限，内测期每日有名额限制，全量后未披露总上限。

## 五、益智类产品线（深度对标小象脑力六大系列）

> 对标小象脑力六大能力维度：专注力、观察力、记忆力、逻辑思维、空间感知、反应力。
> 策略：一款游戏一个小工具，挂载不同笔记引流，形成体系化产品矩阵。

### 5.1 专注力训练系列

## 十、宣传包装策略

### 10.1 核心突出点（别人抄不走的）



1. **教师视角设计**—— 一线老师，不是产品经理拍脑袋

2. **和学校学习挂钩**—— 不是纯玩，是为学习打基础

3. **双端联动**—— 课堂 + 家庭，别人只有一端

4. **轻量免费**—— 不用下载、没广告、点开就练

5. **科学体系**—— 六大能力 + 分龄 + 每日 5 分钟，不是零散小游戏

### 10.2 每个小工具的标准化介绍模板



```
【适合年龄】5-8岁

【训练能力】视觉注意力 + 手眼协调

【训练时长】每天5分钟

【为什么练这个】

上课坐不住、看书跳字、做题粗心……

根源是视觉注意力不够，舒尔特方格是全球公认的训练方法。

【怎么练】

每天练1-2局，记录时间，坚持21天看变化。
```

### 10.3 笔记内容公式



```
痛点标题（宝妈一看就中）

↓

问题分析（为什么会这样）

↓

训练方法（你的小工具）

↓

训练效果（坚持多久有变化）

↓

挂载小工具（点开就能练）
```

**示例：**



* 标题：「孩子看书跳字、做题粗心？练这个 5 分钟就够」

* 正文：分析视觉注意力问题 → 介绍舒尔特方格 → 坚持 21 天的变化 → 挂小工具

### 10.4 统一命名规范



* 英语类：`龙爸英语·Unit1点读`、`龙爸英语·单词闪卡`

* 数学类：`龙爸数学·口算打卡`、`龙爸数学·24点`

## 十一、差异化竞争策略

### 11.1 和小象脑力的对比



| 对比项  | 小象脑力 App        | 我们的小红书小工具             |
| ---- | --------------- | --------------------- |
| 数量   | 一个 App 装 30 + 款 | 一款游戏一个小工具，更聚焦         |
| 难度系统 | AI 自适应，动态调整     | 手动分档（简单 / 中等 / 困难）    |
| 数据记录 | 云端成长报告          | 本地 localStorage 记录最高分 |
| 用户路径 | 应用商店下载→注册→付费    | 刷到笔记→点开就玩→关注          |
| 核心优势 | 体系完整、科学背书       | 碎片化、即开即用、零门槛          |
| 变现模式 | 会员订阅            | 引流→教师版 / 资源包变现        |

### 11.2 壁垒层级



| 壁垒层级 | 内容                 | 别人能不能抄     |
| ---- | ------------------ | ---------- |
| 第一层  | 单个小游戏代码            | 能抄，谁都能写    |
| 第二层  | 六大能力体系 + 分龄 + 话术   | 能抄，但要时间    |
| 第三层  | **教师视角 + 课堂教学经验**  | 难抄，需要真的在教课 |
| 第四层  | **课堂 + 家庭双端联动体系**  | 很难抄，需要两端产品 |
| 第五层  | **账号 IP + 家长社群口碑** | 抄不走，需要时间积累 |

### 11.3 核心打法

**别人卖的是 "小游戏"，我们卖的是 "一线老师验证过的学习能力训练方案"。**

第一波先打透一个爆点：**舒尔特方格・专注力训练**



* 让家长记住 "龙爸 = 专注力训练专家"

* 然后再逐步扩展到记忆力、观察力……
