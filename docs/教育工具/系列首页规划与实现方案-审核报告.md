## 三、代码审核发现

### 3.1 lexue 侧（scripts/build_lexue_site.py）

- `PLACEHOLDER_RE` 用 `re.DOTALL` + 非贪婪 `.*?` 正确处理跨行占位元素；替换用 lambda 保序（逐 key 替换，其它 key 原样保留）——**注意**：`html.count(marker)` 在循环中随替换逐步更新，第二次 key 计数基于首次替换后的 html，行为正确（每次替换不影响其它 key 的 marker 文本）；
- `gen_miniapp_page` 用 `sorted(tool_names)` 字符串排序（中文字典序），与旧实现 `sorted(iterdir)` 一致；
- 潜在改进（非阻断）：`inject_placeholders` 两脚本同构重复（lexue/taoli 各一份）——因两脚本分属不同产品线（scripts/ vs 教师客户端/scripts/），保持独立是并行任务规则的既有约束，**不合并**（N3 已确认）。

### 3.2 taoli 侧（教师客户端/scripts/build_static_site.py）

- `gen_home_page(out, manifest, now)`：从内存 manifest（而非重读文件）取 packages[]，无 IO 冗余；下载链接直接用 `p["download_url"]`（绝对 URL，与壳端 store.rs 契约一致）；
- 注入顺序：`main()` 中 `_headers`（步骤 5）在 `gen_home_page`（步骤 6）之前——`_headers` 不依赖 index.html 存在，顺序正确；
- 模板目录 `WEB_TEMPLATES = Path(__file__).parent / "web"` 与 lexue 侧 `scripts/web/` 对称，各自产品线内自包含。

### 3.3 verify_lexue.ps1

- 新断言 1b：盘符检测 `($_ -notmatch '^https?://') -and ($_ -match '[A-Za-z]:')` ——排除外链后任何含盘符冒号的即泄漏；已实测对 `href="https://taoli.loongba.cn"`（合法外链）不误报（首版正则曾误报 `s:/`，已在实施中修正）；
- 新断言 1c：目录页三重断言（含"工具"字样 + 无盘符 + 无未替换占位）。
