# 教育工具产品指导原则（v1.0）

> 适用范围：LoongEduTools 下的「教育工具」产品线（口算/专注力/闪卡/七巧板/数独等）
> 用途：① 调整已开发工具的对照清单；② 后续新工具的开发红线
> 上位文档：《家庭时间管理产品方案》（同目录）
> 版本：v1.0（2026-09）

---

## 一、定位

**一句话定位**：给家长和孩子的「可信练习工具」——有标准答案的训练工具，不是游戏。

**在矩阵中的角色**：
- 属于 LoongEduTools 产品层，是**引流钩子层**（承接 LoongMedia 内容流量，沉淀到公众号与家庭系统）；
- 核心价值：训练具体能力（计算、专注、记忆、空间、逻辑），「值得信任」是立身之本；
- 商业原则：**工具永久免费、核心功能不设墙**——付费在「替你整理收藏」订阅服务，不在解锁工具。

**与「游戏」的根本区别**：
- 练习 = 有可判定的正确性（对错由标准答案决定）；
- 游戏 = 表现性挑战（价值在反应/生存时长/分数，无教育判定点）。

---

## 二、最高原则：标准答案原则

> 判断任何候选工具「能不能做」的唯一尺子。

- **有标准答案 = 练习（安全区）**：口算、拼图目标图形、数独唯一解、扫雷推理结论确定、找不同、记忆配对；
- **无标准答案、只有生存/分数 = 游戏（红线）**：俄罗斯方块、贪吃蛇、2048、弹球、飞机大战。

**工具分级表**：

| 灯 | 工具 | 判定 |
|---|---|---|
| 🟢 可做 | 口算/竖式、专注力计时、单词闪卡、七巧板、数独、华容道、找不同、记忆翻牌 | 有标准答案 |
| 🟡 改造后做 | 扫雷 | 核心是推理，但要弱化「踩雷=输」：改「推理练习」，踩雷不判负、显示推理依据、计时仅个人记录 |
| 🔴 不做 | 俄罗斯方块、贪吃蛇、2048、弹球/打砖块 | 无答案纯玩法，最易撞版号 |

## 三、合规约束（红线，不可逾越）

### 3.1 版号红线：不做真游戏
- 面向国内公众运营的网络游戏（含 H5、小程序）均需版号；2026 年监管「全域监管、零容忍、顶格处罚」，违法所得数百元也罚；
- **触发版号的特征清单（一律不做）**：计分对抗、等级排行、联网排行榜、云存档/多人实时互动、内购/广告变现、抽卡抽奖、关卡胜负机制；
- 我们的工具全部是「练习」，从设计根上避开。

### 3.2 未成年人个人信息保护
- 处理不满 14 周岁未成年人信息须监护人同意（《个人信息保护法》第 31 条）；
- 落点：家庭码绑定（家长操作）、孩子端无社交、数据仅家庭内可见；
- **数据最小化**：只存完成状态/打卡天数，不存错题、正确率、能力评估；
- 组内统计防反推：小组 <10 人只显示不可反推的汇总量。

### 3.3 主体与资质路径
- 现在：个人订阅号 + 个人网站（非经营性免费）；
- 付费：走小报童托管（综合到手约 80%）；
- 达标后：个体工商户 → 备案转企业 → 服务号认证 → 微信支付。

### 3.4 双版规范
- **小红书离线版**：纯静态 HTML，纯前端、无后端、无账号、本地存储；官方要求「不联网也能用」，禁排行榜/云存档/实时互动——我们天然契合；
- **公众号在线版**：H5 挂已备案网站 + 公众号基础菜单 + 自建家庭码；**不依赖微信 openid**（个人订阅号无认证、无网页授权）；
- 账号主键 = 家庭码/口令，换号不丢数据。

### 3.5 商标避让
- GTD（David Allen）、PSP（SEI）为注册商标，概念可讲、产品命名与宣传不打商标名。

## 四、产品设计原则

### 4.1 练习形态
- 结构：题目 → 作答 → 判对错 → 即时正反馈（打勾、进度条）；
- 无胜负、无失败惩罚、无「游戏结束」。

### 4.2 激励而非竞争
- **可做（个人纵向）**：连胜天数、徽章、进度条、历史曲线——「和自己昨天比」；
- **不做（跨用户）**：好友排行、PK、班级竞赛、实时对战——任何「和别人比」的结构。

### 4.3 社交五档（数据可见性）
| 档 | 形态 | 规则 |
|---|---|---|
| ① 和自己比 | 连胜/里程碑/历史 | 孩子端默认 |
| ② 全体匿名聚合 | 「超过 20% 同伴」 | 统计量不可反推 |
| ③ 组内聚合 | 「组平均 5.2 天」 | 家长端；组≥10 人开放 |
| ④ 搭子（状态化） | 「搭子已完成打卡」 | 家长牵线+双方同意；只显状态不显数值；可解除 |
| ⑤ 搭子数值对比 | 「他 87 分钟你 40」 | 不做 |

### 4.4 免费与引流
- 工具核心功能永久免费；不设墙、不内置广告、不开内购；
- 引流靠「增值服务」引导（完整记录/家长报告/榜单），不在工具内变现。

### 4.5 双版分工
- 小红书离线版 = 体验钩子（打开即用、单次会话完成价值交付）；
- 公众号在线版 = 留存沉淀（练习历史、错题本、家长报告）。

## 五、现有工具自查清单（调整对照用）

逐项打勾，任一红灯即需整改：

- [ ] 是否有标准答案/可判对错？（无 → 改造成练习形态或下架）
- [ ] 是否有排行榜/名次/「最快/第一」奖励？（有 → 删）
- [ ] 是否有跨用户数值对比/PK/对战？（有 → 改为个人纵向或删除）
- [ ] 是否有联网排行榜/云存档/多人实时？（有 → 剥离）
- [ ] 是否有内购/广告变现/抽奖？（有 → 移除，移到订阅服务）
- [ ] 是否收集未成年人个人信息？处理者是否为家长/监护人同意？
- [ ] 数据是否最小化（仅完成状态，不含错题/成绩）？
- [ ] 小红书版是否纯静态、可离线、无后端？
- [ ] 在线版是否家庭码进入、无社交、无注册墙？
- [ ] 孩子端是否无添加好友/搜索/公开组入口？

## 附：一句话总纲
