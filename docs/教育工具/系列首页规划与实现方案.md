## 二、目标与非目标

### 目标

1. 为 `lexue.loongba.cn` 与 `taoli.loongba.cn` 各制作**简单可用的静态首页**（HTML 模板 + 脚本注入数据）；
2. **首页模板独立成文件**（不内嵌 Python 字符串）→ 后续 **UI Agent 直接美化模板文件** 即可；
3. **修复线上 MiniApp 死链 Bug**；
4. 保持"纯静态 + 随 push 部署 + CF 缓存"既有机制，不加构建依赖。

### 非目标（本方案不做）

- 不做主力产品页（peilian/shudu/qiaosuan/timemanager 单独产品页——方案 v0.9 §7 决策点 8 后续另立）；
- 不做认证/口令/互动功能（公众号互动与认证均为独立立项）；
- 不迁移 taoli 发布链路归属（仍走教师客户端侧 `publish_static_site.ps1`）；
- 不做品牌图形/CSS 精修（UI Agent 美化阶段，本方案只保证结构、内容、链接正确）。

## 四、技术方案

### 4.1 模板机制（核心架构决策）

**模板独立成 HTML 文件 + 占位符替换**，不再字符串拼接页面：

```
模板文件（HTML，UI Agent 可任意精修）          构建脚本（注入数据）
scripts/web/lexue-home.html            ──→   lexue/index.html
scripts/web/lexue-miniapp-home.html    ──→   lexue/MiniApp/index.html
教师客户端/scripts/web/taoli-home.html ──→   taoli/index.html
```

- 占位符约定（**`<template data-inject="KEY">` 真实 HTML 元素**，Oracle I3）：采用标准 `<template>` 元素（内容不渲染但 DOM 存在、CSS 可选中、**不会被 minifier 删注释**、UI Agent 当正常元素处理），不用 HTML 注释：
  - `<template data-inject="MAIN_CARDS"></template>` — 主力应用卡片（lexue）
  - `<template data-inject="MINIAPP_CARDS"></template>` — MiniApp 工具卡片（lexue-miniapp）
  - `<template data-inject="PACKS_LIST"></template>` — taoli 内容包清单（taoli）
  - `<template data-inject="UPDATED_AT"></template>` — 更新时间（两站 footer）
- 脚本侧：新增/复用生成函数，读模板 → 构造卡片 HTML → **正则替换** `<template data-inject="KEY">...</template>` 整块 → 写产物；
- **占位符校验（Oracle B1，阻断项）**：构建前校验每个 `data-inject` 占位符在模板中**恰好出现 1 次**（`html.count()`——`str.replace` 会替换全部匹配，0/2 次均须中止）：
  ```python
  n = html.count(f'<template data-inject="{KEY}"')
  if n != 1:
      raise SystemExit(f"[strict] 占位符 {KEY} 出现 {n} 次，必须唯一")
  ```
  验收补：最终产物**无 `data-inject` 残留**（`'data-inject' not in final_html`）——防 UI Agent 破坏占位符后"存在性通过、替换缺失"；
- _headers 同步新增：`/MiniApp/index.html` 需 no-cache（入口页高频更新）；template 产物本身不变。

### 4.2 lexue 侧改造（scripts/build_lexue_site.py）

1. **修复死链**：L336 `f"MiniApp/{t}/"` → `f"MiniApp/{t.name}/"`（`Path` 不可直接格式化）；
2. `gen_series_page()` 重构为模板驱动：读 `scripts/web/lexue-home.html` → 注入 MAIN_CARDS（主力 4 卡，timemanager 无产物时剔除）+ UPDATED_AT → 写 `out/index.html`；
3. 新增 `gen_miniapp_page()`：读 `scripts/web/lexue-miniapp-home.html` → 注入 MINIAPP_CARDS（43 款，`t.name`）+ UPDATED_AT → 写 `out/MiniApp/index.html`；
4. `gen_headers()` 在 `rules` 列表 `/timemanager/index.html`（L284）之后追加（Oracle I4 锚点）：
   ```python
   ("/MiniApp/index.html", "Cache-Control: no-cache"),
   ```

### 4.3 taoli 侧改造（教师客户端/scripts/build_static_site.py）

**⚠ 跨产品线文件：用户已同意本次改动（仅新增首页生成，不动现有逻辑）。**（Oracle I5/I6）

1. 新增步骤 6（`main()` 末尾、`_headers` 写入之后）：读 `教师客户端/scripts/web/taoli-home.html` → 注入 PACKS_LIST（从已生成的 `out/api/edu/packages/manifest.json` 读 `packages[]`，渲染为列表卡片：名称/版本/大小/下载链接）+ UPDATED_AT → 写 `out/index.html`；
2. `_headers`：**直接字符串追加**（不重构为函数，Oracle I5——`build_static_site.py` 当前是硬编码 `write_text` 三块，保持风格一致）在 `/shell/*` 块之后加：
   ```python
   "/index.html\n"
   "  Cache-Control: no-cache\n",
   ```
3. 模板文件新增：`教师客户端/scripts/web/taoli-home.html`（含 `<template data-inject="PACKS_LIST">` + `<template data-inject="UPDATED_AT">`）。

### 4.4 部署

- 沿用两发布脚本：`publish_lexue.ps1`、`publish_static_site.ps1 -Series taoli`；
- **用户决策①：死链修复 + 简单版首页立即部署**（不等美化）——S2 完成后即 push 上线，恢复线上可用性；

- 每次部署前置 gate = 本地重建 exit=0 + **verify 脚本全 PASS（Oracle I1）**。

## 七、风险与缓解

| 风险 | 缓解 |
|---|---|
| 模板占位符与脚本不同步（UI Agent 增删 `<template data-inject>`） | 占位符唯一性校验（Oracle B1：恰好 1 次，缺失/重复均中止）+ 产物 `data-inject` 残留检测 + 模板头部注释注明"勿删/勿重复 data-inject 元素" |
| taoli 脚本改动影响教师客户端发布 | 只新增步骤（读模板写 index.html），不动 api/packs/shell 现有逻辑；**用户已同意** |
| MiniApp 目录页导航层级变化影响使用 | 首页工具集入口直连 MiniApp/ 目录页；产品页/验证脚本无依赖此导航 |
| 43 款目录页构建性能 | 纯静态卡片生成 <1s，无风险 |
| UI Agent 美化破坏链接 | S3 后跑 verify_lexue.ps1 全套断言（含死链检测）作为部署 gate |
| UI Agent 美化引入构建流水线（minify） | `<template>` 元素不会被 removeComments 删除（I3 已规避 HTML 注释方案）；若改用其它占位方式需同步 build 脚本 |

## 十、S3 UI 美化任务 brief（Oracle I6，后续 UI Agent 输入）

> 本 brief 供 S3 UI Agent 美化时使用，随交付物输出为 `scripts/web/PLACEHOLDERS.md`（模板维护约定）。

**信息架构（不得改变）**：
- lexue 根首页 = 品牌 Header + 主力 4 卡（peilian/shudu/qiaosuan/timemanager）+ **1 个「小工具集」入口卡**（链接 `/MiniApp/`）+ 合规脚注 + Footer；
- lexue `/MiniApp/index.html` = 43 款工具卡片**目录页**（网格布局），不在根首页逐个列 43 款；
- taoli 首页 = 品牌 + 产品简介 + 核心能力 + 内容包清单 + 合规声明 + Footer。

**模板硬约束**：
- 保留 `<template data-inject="KEY">` 元素**原样**（不得加空格、不得拆分到 fragment 文件、不得复制两份），每 KEY 恰好 1 次；
- 链接保持相对路径（`peilian/`、`MiniApp/数学口算/` 等），禁止绝对路径/盘符；
- 不引入外部资源依赖（纯静态，随 push 部署）；
- 美化范围：颜色/字体/间距/卡片样式/响应式/品牌感——结构、占位符、链接不改。
