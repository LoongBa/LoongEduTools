### 1.3 缺失（本方案要解决）

1. **lexue 分区无产物、无发布脚本**：主力应用（在线版）+ 双骨架小程序集没有统一汇聚、推送、验证机制；
2. **无 lexue 目录结构约定**：多产品共存于一个 CF Pages 项目（lexue.loongba.cn），子路径组织未定；
3. **产物路径约束未核对**：点读陪练 WebH5 online 用 `base="/"` + 前端 fetch `/api/manifest`（同域根），与"多产品共存放子路径"冲突；
4. **publish_online.py 产物与部署目标多处不匹配**：URL 化规则、输出目录、无后缀访问三处不一致（详见 §2.3），直接部署到 CF Pages 会 404。

### 1.4 认证路线（下一步主线 · 与静态发布并行规划）

| 阶段 | 认证方式 | 状态 |
|---|---|---|
| 1（近期） | **手机号绑定认证**（免费单元） | 预留契约（教育工具在线版设计要求 §4.6 + 教师客户端 A01 §2 复用），静态发布先行 |
| 2（近期） | **授权口令验证**（付费购买解锁） | 同上，口令校验走动态 API（SCF/Workers） |
| 3（推迟） | **微信认证**（OAuth） | 个人订阅号不可行，需注册个体工商户后转服务号认证——**推迟** |

> **静态发布与认证的关系**：静态页先承载「桩 + 全量内容」，认证/口令/上报走动态 API（待开发）；API 就绪后替换 `auth.js`/`storage.js` 内部实现，不改 `core/`（教育工具双模式骨架既有设计）。

### 1.5 非目标（红线）

- **不实施**：不写脚本、不改前端、不推仓库（本方案交付后另行立项实施）；
- **不碰教师客户端/教材点读**（乐教侧已单独发布，本方案只做 lexue 分区）；
- **不接在线认证/云存储**（`/api/progress` 等 SCF 动态端点非静态范围，认证路线见 §1.4）；
- 不迁移 RedTools 全部 44 款（双骨架按需选配，首批见 §5）。

**设计要点**：

1. **系列页/产品页统一静态化**：系列产品页（lexue/taoli 根 index.html）+ 各产品页（主力三款 + 桃李助手）都是**纯静态 HTML**（无构建依赖），随仓库 push 部署，加 CF 缓存。
2. **产品页与应用关系**（待定，见 §7 决策点 7）：产品页 = 应用首页合一（SPA 首页自带介绍区），或产品页 = 独立静态页 + 应用挂子路径（`peilian/app/`）——推荐后者（产品页高频改文案不动应用包）。
3. **素材放 `lexue/units/`（站点根），不属于 peilian/**——与 `publish_online.py --base https://lexue.loongba.cn` 的 URL 规则对齐（素材 URL = `https://lexue.loongba.cn/units/<uid>/audio/...`）。**素材 base 与前端 base 解耦**：前端 base 是 `/peilian/`，素材 base 是站点根，互不影响。
4. **主力子路径命名**：`peilian/`（点读陪练）、`shudu/`（数独思维）、`qiaosuan/`（数学巧算）、`timemanager/`（家庭时间管理）——拼音/语义短名；双骨架小程序统一 `MiniApp/` 前缀（下沉一级 + 缓存通配一条规则 + 与主力区分）。
5. **前端改造（点读陪练 3 处 + 数独/巧算各 1 处）**：
   - 点读陪练（3 处）：`vite.config.ts` online `base` → `/peilian/`；`main.tsx` `new RemoteProvider(import.meta.env.VITE_API_BASE ?? "")` 注入 `/peilian`；**TanStack Router `basename: '/peilian'`**（Oracle B2：routeTree 不自动感知 vite base，漏则子路径刷新 404）。
   - 数独思维/数学巧算（各 1 处）：`vite.config.ts` online `base` → `/shudu/`、`/qiaosuan/`（数独思维需先确认其 online 形态脚本，见 §5）。
   - `submit.ts`：`fetch("/api/progress")` → `${base}/api/progress`（可选，P2 上报未接可后置）。
6. **publish_online.py 产物 → 部署目标的三处路径转换**（Oracle I1，关键）：
   - `build/online/manifest.json`（根·有后缀）→ `peilian/api/manifest` **+ `manifest.json` 双写**（C6）；
   - `build/online/units/<id>.json`（有后缀）→ `peilian/api/units/<id>` **+ `<id>.json` 双写**（C6）；
   - `build/online/assets/<uid>/...`（C5）→ `lexue/units/<uid>/...`（改名对齐 URL）。
   - **修正方向**：源头改 `publish_online.py` 输出（`OUT_ASSETS` 改 `units/` + manifest/units 落 `api/` 双写）比部署期改名更优；若改动面大，则 `build_lexue_site.py` 汇聚时完成转换——**实施时二选一，倾向源头修正 + 汇聚器兜底双写**。
7. **双骨架小程序 MiniApp/ 子路径**：相对路径天然适配，构建产物直接复制零改造；全量笼统打包（不做精选），新工具随建随发。
8. **taoli 侧（乐教）**：本方案**只记录不实施**——乐教系列页/桃李助手产品页/教材点读入口由教师客户端侧链路（`publish_static_site.ps1 -Series taoli`）扩展。
9. **可选简化（方案 A）**：若点读陪练前端改造成本高，可退化为 **点读陪练占 lexue 根**（`lexue/index.html` 即点读陪练，`/api/manifest` 命中根，前端 0 改造）。**注意：方案 A 仍非"零改造"**——`publish_online.py` 路径转换（I1）与双写（C6）仍需做（Oracle N1）；且数独/巧算仍走子路径。取舍见 §7 决策点 1。

## 3. 缓存策略（_headers）

对齐 taoli 样板（`build_static_site.py` L239-249），按 lexue 特性调整：

```http
# 静态资源（hash 文件名 → 永久缓存）
/assets/*
/peilian/assets/*
/shudu/assets/*
/qiaosuan/assets/*
/timemanager/assets/*
/MiniApp/*/assets/*
  Cache-Control: public, max-age=31536000, immutable

# 在线内容目录/单元包（更新信号即时）
/api/*
/peilian/api/*
  Cache-Control: no-cache

# 入口页/导航页
/index.html
/peilian/index.html
/shudu/index.html
/qiaosuan/index.html
/timemanager/index.html
  Cache-Control: no-cache

# 素材（文件名含单元 id + hash 语义，随 manifest 更新换名）
/units/*
  Cache-Control: public, max-age=31536000, immutable
```

> 1. **`/MiniApp/*/assets/*` 通配语义**：CF Pages `_headers` 的 `*` 为通配符（文档：`https://developers.cloudflare.com/pages/configuration/headers/`），多段写法可行；**M2 实施时以 1 个真实工具路径冒烟验证**（`GET /MiniApp/数学口算/assets/<file>` 检查 `Cache-Control` 头）。
> 2. `#` 注释行为 CF Pages `_headers` 支持。

## 4. 发布脚本设计

### 4.1 统一发布脚本 `publish_lexue.ps1`

参照 `publish_static_site.ps1`（幂等、可反复执行），差异 = 产物源为**多产品汇聚目录**：

```
用法：
  .\publish_lexue.ps1 -DryRun          # 只汇聚 + commit，不 push
  .\publish_lexue.ps1                  # 汇聚 + commit + push（触发 CF Pages 构建）

流程（全量替换语义，Oracle I2）：
  0) 【前置校验】确认所有本次发布产品的产物目录存在（点读陪练 WebH5/dist + build/online、
     数独思维 dist、数学巧算 dist、家庭时间管理 dist（若已开工）、RedTools dist/<系列>/<工具>/online/
     全量清单、系列页/产品页模板）——任一缺失 → 中止并列出缺失项
  1) 清理发布仓库 lexue/ 目录（保留 .git，不碰 taoli/）
  2) 汇聚各产品产物 → lexue/：
       a. 点读陪练：build_lexue_site.py 转换（三处路径 + 双写，见 §2.2 要点 6）→ lexue/peilian/ + lexue/units/
       b. 数独思维：dist → lexue/shudu/（base 已改子路径）
       c. 数学巧算：dist（build:online）→ lexue/qiaosuan/
       d. 家庭时间管理：dist → lexue/timemanager/（开工后接入）
       e. 双骨架小程序：dist/<系列>/<工具>/online/ → lexue/MiniApp/<工具>/（全量笼统打包）
       f. 系列页 lexue/index.html + 各产品页 + MiniApp/README + _headers（生成）
  3) git add + commit（信息含 updated_at / 产品清单）+ push
```

**汇聚器**：新增 `scripts/build_lexue_site.py`（对齐 build_static_site.py 模式）：
- 输入：各产品产物路径 + 双骨架全量清单（tools.py 登记的 online 工具列表）；
