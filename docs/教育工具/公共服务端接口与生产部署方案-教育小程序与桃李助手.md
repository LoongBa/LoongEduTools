# 公共服务端接口与生产部署方案（教育小程序 + 桃李助手）

> 状态：v0.3（2026-09-30——分层接入模型 + family 域家庭码弱凭证自洽修订；v0.2 = 2026-09-29 Oracle 外审 4B/10I/4N 处置后修订）
> 定位：**教育小程序与桃李助手共用的服务端 = `教师客户端/server-dotnet/`（.NET 10，单实例）**，统一承载两产品的认证基建与生产部署；各自私有接口在既有/新增域内隔离演进。
> 上游：桃李助手契约 `A01`（教师客户端/docs/A01-教师客户端服务端API契约_v1.0.md）、部署 `D13`、S6 真接入 `D14`；教育小程序预留契约（`docs/教育工具/教育工具在线版设计要求.md` §4.6，6 端点）与认证路线（`docs/教育工具/在线版静态发布统一机制-开发方案.md` §1.4）。
> 技术路线：**.NET 10**（`server-dotnet/`）；TS `server/` 降级实验（D13 D2 继承）。

## 1. 背景与决策

### 1.1 背景

- **桃李助手**（教师客户端，Tauri 壳）：服务端 = `server-dotnet/`（.NET 10，2026-09-27 落地，当前零 NuGet 依赖）。A01 v1.1 契约 18 端点；server-dotnet 已实现 **4 业务端点**（`sms/send`、`sms/verify`、`bind/wechat`、`codes/activate`）+ `health` + 3 静态配置（manifest/toolbox/shell.config.signed.json）。
- **教育小程序集**（RedTools 44 款 / lexue.loongba.cn 在线 43 款）：纯静态、**零服务端依赖**（`auth.js`/`storage.js` 为桩，`lx.auth.v1` stub-token，全部 TODO 待接服务器）；在线版预留契约 6 端点（设计要求 §4.6）；认证路线三阶段：手机号绑定 → 授权口令 → 微信（推迟）。
- **共用锚点**：A01 §1.1 已声明「统一前缀 `/api/edu/...`（与 RedTools 在线版命名空间对齐）」——两产品 API 前缀本已统一。
- **语义冲突**：两产品均有 `/auth/activate` 概念但语义不同——桃李助手 = 激活码⇄微信身份绑定（教师授权）；教育小程序 = 手机号⇄产品授权口令绑定（家庭付费解锁）。公共设计必须消解。
- **D13/D14 v0.2 已定稿**（2026-09-29，Oracle 外审 6B/10I/5N 全采纳），但**实施清单全未落地**：无 `deploy/`、无 `ASPNETCORE_ENVIRONMENT` fail-fast、无 `Sms:Mode`（仅布尔 `Sms:Mock`）、无频控小时/天级、无微信 OAuth 代码、`dev_code` 任意环境进响应体（公网裸奔风险）。
- **账号模型差异**：桃李助手 = 教师（微信实名/短信/密码，JWT 7 天，Level 1/2/3 授权）；教育小程序 = **家长手机号 + 家庭码**（孩子端无账号是硬约束，设计要求 §3.5）。

### 1.2 决策

| # | 决策 | 说明 |
|---|---|---|
| D1 | **公共服务端 = `server-dotnet/`（.NET 10，单实例服务两产品）** | 认证基建（短信/微信/JWT）+ 生产部署为公共层；TS `server/` 降级实验（D13 D1/D2 继承） |
| D2 | 生产域名 = **`api.taoli.loongba.cn`** | 回写 A01 §1.1（契约权威，D13 B6）；静态 `taoli.loongba.cn`（桃李）与 `lexue.loongba.cn`（教育小程序）不受影响 |
| D3 | **统一账号体系 + 角色分域** | 单一 User 表（手机号唯一）；JWT 增 `roles` claim（`teacher`/`family`）；既有 JWT 无 roles → 默认 `["teacher"]`（向后兼容壳端） |
| D4 | **路径分域消解 `/auth/activate` 语义冲突** | 公共认证留在 `/api/edu/auth/*`（既有签名不变）；教育小程序私有一律 `/api/edu/family/*`；桃李助手私有保持 A01 现状路径不动 |
| D5 | **教育小程序 6 预留端点 → 公共 + family 域映射** | login（手机号+密码）→ 公共 `password`；reset → 公共 `password/reset`；验证码登录（可选增值）→ `sms/send`+`verify`（`scene:"family"`）；`auth/activate`→`family/auth/activate`、`auth/status`→`family/auth/status`、`data/sync`→`family/data/sync`、`report/query`→`family/report/query` |
| D6 | **S6 真接入落公共层** | 腾讯云短信（`TencentCloudSDK.Sms` 3.0）+ 微信开放平台网站应用 OAuth；两产品共用 `ISmsService` / 微信绑定流程 / 频控 / 错误码映射（D14 全套） |
| D7 | **Mock/Real 双模式 + 生产 fail-fast** | Production 下：`JWT_SECRET` 缺失/默认 → 拒绝启动；demo 激活码 seed 清空；`TencentSms:Mode=Mock` → 认证端点 503 `DISABLED`（D13 B2/B3/B4 + D14 B2，503 范围扩展至 family 域） |
| D8 | **微信绑定 = 绑定票据中转回调** | `authorize` → 扫码 → `callback` → `bind/status` 轮询；bind_token 状态机落盘（D14 B5）；两产品共用同一微信网站应用（统一账号体系） |
| D9 | **既有端点签名不变** | A01 v1.1 契约 + server-dotnet 既有 4 端点语义冻结；新增端点/可选字段必须回写 A01 §2（D14 B1） |

## 2. 公共接口面（两产品共用）

> 既有端点签名冻结（D9）；下表标注「增」= 公共层新增实现/新增可选字段，不破坏既有调用。

### 2.1 公共认证接口（`/api/edu/auth/*`）

| 方法 | 路径 | 用途 | JWT | 现状→公共层 |
|---|---|---|---|---|
| POST | `/api/edu/auth/sms/send` | 发短信验证码 | 否 | **增可选字段 `scene`**（`"teacher"`缺省/`"family"`）：决定首登默认角色；既有调用不受影响 |
| POST | `/api/edu/auth/sms/verify` | 手机号验证码登录/首登注册 | 否 | **增可选字段 `scene`**（同 send）；响应增 `roles` |
| POST | `/api/edu/auth/bind/wechat` | code 换 openid 直接绑定（网页端回调场景） | ✅ | 既有端点，签名不变（D14 D2）；Mock 保留 `wechat_mock_<code>`；Real 与 `wechat/callback` **共用 `ExchangeCodeForOpenid(code)` 内部函数**，差异仅在绑定主体（JWT user vs bind_token user，Oracle I9） |
| POST | `/api/edu/auth/password` | 手机号+密码登录 | 否 | 增（A01 契约已有，server-dotnet 补实现） |
| POST | `/api/edu/auth/password/reset` | 找回密码（短信验证码→重置） | 否 | 增（A01 契约已有，补实现） |
| POST | `/api/edu/auth/refresh` | JWT 过期刷新 | 过期 JWT | 增（补实现；**简化模型：过期 JWT 直换新 JWT，无需 `refresh_token`**——Oracle I5，回写 A01 §2.6） |
| GET | `/api/edu/auth/wechat/authorize` | 微信绑定授权 URL | ✅ | 增（D14 §3.4；Mock 返回假 URL） |
| GET | `/api/edu/auth/wechat/callback` | 微信中转回调页（无 JWT） | 否 | 增（D14 §3.4；Mock: `code → wechat_mock_<code>` 保留） |
| GET | `/api/edu/auth/wechat/bind/status` | 轮询绑定结果 | ✅ | 增（D14 B1：路径不与 A01 §2.1 登录轮询 `/wechat/status` 冲突） |

**send/verify 的 `scene` 语义**（D3 配套）：

| scene | 首登默认角色 | 引导 | 既有兼容 |
|---|---|---|---|
| `teacher`（缺省） | `["teacher"]` | 补任教信息（A01 §2.4 profile，桃李助手既有流程） | 现状调用不带 scene = teacher，零破坏 |
| `family` | `["family"]` | 家庭码绑定（教育小程序侧流程，本期由教育小程序立项实现） | 新字段 |

> scene **仅影响首登默认角色**；短信文案不受 scene 影响（教育行业仅一个验证码模板，Oracle I10）。

**响应结构**（verify，公共层）：

```jsonc
{
  "jwt": "...", "expires_in": 604800,
  "roles": ["family"],                      // 增：账号角色数组
  "teacher": { "id": "...", "level": 1, "wechat_bound": false }   // scene=teacher 时（既有字段不动）
}
```

### 2.2 JWT 约定（公共，D3）

| 项 | 设计 |
|---|---|
| payload | `{ sub, roles: ["teacher","family",...], lvl?, exp, iat }` |
| 兼容 | 既有 JWT 无 `roles` → 校验侧默认 `["teacher"]`；`lvl` 仅 teacher 语义（保持既有字段，family 角色忽略） |
| 读取层默认（Oracle I7） | **Storage 反序列化旧 users.json 时 `User.Roles` 为 null** → 读取/签发处补 `Roles ?? ["teacher"]` 默认（JWT 解码层与 Storage 读取层都要处理；回滚场景同） |
| 角色变更边界 | 角色由首登 scene 定 + 后续服务端操作（如 family→teacher 需激活码链路/运维操作，本期不定义自动变更流程）；已有账号登录时 scene 忽略，角色以账号既有 roles 为准 |
| 签发 | `sign(secret, sub, roles, lvl?, ttlSec=604800)`（Jwt.cs 扩展，HS256 自实现不动） |
| 校验 | `Verify` 容错读取 roles（缺省 `["teacher"]`）；过期语义不变 |

**端点 ↔ 角色矩阵**（Oracle B3——roles 是安全边界，非仅 label；实施层必须有鉴权 guard）：

| 域 | 端点 | 要求角色 |
|---|---|---|
| 公共认证（公开） | `sms/send`、`sms/verify`、`password`、`password/reset`、`refresh`、`wechat/callback` | 无 |
| 公共认证（需登录） | `wechat/authorize`、`wechat/bind/status`、`bind/wechat` | teacher 或 family（任一） |
| 桃李助手私有 | `auth/activate`、`license/*`、`packages/<id>/<ver>`（下载）、`credential/sign`、`report/ingest` | teacher（+ `lvl` 按既有语义校验）；`packages/manifest`/`toolbox/manifest` 匿名可读（A01 2026-09-27 放宽） |
| 教育小程序私有·家长端 | `family/auth/activate`、`family/auth/status`、`family/report/query` | family JWT（family_code 授权映射留教育小程序立项，Oracle B2） |
| 教育小程序私有·孩子端 | `family/data/sync` | **家庭码弱凭证（非 JWT，无账号）**——孩子端无账号是硬约束（设计要求 §3.5），请求体带家庭码；服务端校验家庭码存在性/格式（高熵 + 频控防枚举）；已登录家长态亦可代传（v0.3 澄清） |
| 公共基础 | `health`、`config/*` | 无 |

> 越权行为：teacher JWT 调 `family/*` → 403 `FORBIDDEN`；family JWT 调桃李助手私有域 → 403；孩子端家庭码仅可访问其家庭码维度数据、无法访问家长管理端点。单测含反向用例（Oracle B3）。

### 2.3 统一错误结构（公共）

A01 §1.2 七码为基线（`BAD_REQUEST`/`UNAUTHORIZED`/`AUTH_EXPIRED`/`FORBIDDEN`/`NOT_FOUND`/`RATE_LIMITED`/`INTERNAL`）；**新增 `SERVICE_UNAVAILABLE`(503) + `SMS_SEND_FAILED`(502)**（Oracle B1，回写 A01 §1.2，见 §6 #2）。腾讯云错误码 → A01 code 映射表（D14 §2.5 I7）为公共层引用（短信 Real 分支全量复用）：

| 腾讯云错误码 | A01 code | HTTP |
|---|---|---|
| `Ok` | — | 200 |
| `LimitExceeded.PhoneNumber*` / `DeliveryFrequencyLimit` | `RATE_LIMITED` | 429 |
| `UnauthorizedOperation.SmsSdkAppIdVerifyFail` | `UNAUTHORIZED` | 401 |
| `InvalidParameter.*` | `BAD_REQUEST` | 400 |
| `FailedOperation.SignatureIncorrectOrUnapproved` / `TemplateIncorrectOrUnapproved` | `SERVICE_UNAVAILABLE` | 503 |
| `FailedOperation.*`（运营商送达失败） | `SMS_SEND_FAILED` | 502 |
| 网络/超时 | `SERVICE_UNAVAILABLE` | 503 |

### 2.4 限频（公共，D14 I1）

| 项 | 值 | 现状 |
|---|---|---|
| 单号 60 秒 | 1 条（`ResendGap` 保留） | ✅ 已实现 |
| 单号小时级 | **5 条/小时**（滚动窗口，新增 `SmsRecord.HourCount/WindowStart`） | ❌ 补 |
| 单号自然日 | **2 条/天**（应用默认，严于 A01 §6 的运营商硬顶 10 条/天；防验证码过期重发计入配额后的狂发） | ❌ 补 |
| IP 级 | 认证失败 5 次/小时/IP → 429 | ❌ 补——**Caddy rate_limit 兜底（IP 级，per-IP-per-path）**；应用层只管手机号级（60s/小时/天）（Oracle I4） |
| 微信扫码 | 1 会话/2 分钟/设备；轮询 ≤TTL 30min | ❌ 补 |
| Caddy 层 | `/api/edu/auth/*` 与 `/api/edu/family/auth/*` `rate_limit 5 r/s burst 20`（§3.4） | ❌ 补 |

## 3. 生产部署（D13 公共化）

### 3.1 部署拓扑

```
桃李助手（教室/办公室，Tauri 壳） ─┐
                                  ├─ https ─▶ api.taoli.loongba.cn
教育小程序（lexue.loongba.cn，浏览器）─┘          │
                                        Caddy（80/443，自动 HTTPS + rate_limit）
                                                 │ 反代 127.0.0.1:5088
                                        edu-teacher-api（.NET 10 自包含单文件）
                                                 │
                                        data/（users/sms/codes/wechat_binds.json）
```

- **单实例服务两产品**：静态内容仍在 CF Pages（`taoli.loongba.cn` / `lexue.loongba.cn`），公共服务端只承载认证/配置/私有域 API。
- **应用仅监听 `127.0.0.1:5088`**；腾讯云安全组只放行 80/443。
- **服务名沿用 D13 已定稿 `edu-teacher-api`**（公共化**不更名**：名字不阻碍服务 family 域，避免 D13 v0.2 级联改写——Oracle I1 处置，留痕见 §9）。

### 3.5 生产 fail-fast 三件套（公共强制项，上线前置）

| # | 项 | 规则（Production 下） | 出处 |
|---|---|---|---|
| 1 | `JWT_SECRET` | 缺失或等于 `dev-only-secret-2026` → **拒绝启动**（不再 fallback） | D13 B3 |
| 2 | demo 激活码 seed | seed 清空（真实签发走运维导入 `data/codes.json`）；启动时发现 demo 散列存在于库 → **拒绝启动** | D13 B4 |
| 3 | `TencentSms:Mode=Mock` | **认证端点 503 `DISABLED`**：`/api/edu/auth/sms/*`、`/api/edu/auth/wechat/*`、`/api/edu/auth/password/reset`、`/api/edu/codes/*`、`/api/edu/family/auth/*`（不签发 dev_code、不发短信；配置下发/health 不受影响） | D13 B2 + D14 B2，**503 范围扩展至 family 域 + password/reset** |

> 扩展说明（vs D13 §3.4；D13 原文 503 = `sms/*` + `codes/*`；配置键统一为 `TencentSms:Mode`——Oracle I3，Program.cs 现 `Sms:Mock`(bool) 实施时改枚举）：
> - **安全门**（防 dev_code/微信 mock 泄露，Mock 期禁用）：`sms/*`、`wechat/*`、`password/reset`、`codes/*`——依赖短信验证码或微信 mock 的端点，生产 Mock 期会泄露 dev_code / 产生 mock 绑定；
> - **产品门**（S6 未过审期间教育小程序认证不裸奔上线，Oracle I8）：`family/auth/*`——本身不发 dev_code、不绑 mock openid，503 是产品就绪门控而非泄露防护；
> - `password` 登录本身无短信/微信泄露面，**保留可用**（以 §10 password 补实现完成为前提，Oracle I6）；`refresh` 纯 JWT 无泄露面，保留。

### 3.6 备份与 secrets（D13 §4.2，服务名同步）

## 4. S6 真接入（D14 公共化）

### 4.1 腾讯云短信（公共）

- **前置阻塞（必须先办，7–10 工作日）**：企业实名认证 → 资质报备 → 签名（~2h 审核 + 运营商报备）→ **验证码模板**（教育行业仅允许验证码模板，通知/营销一律驳回）→ 应用取 `SdkAppId`（D14 §2.1）。
- 依赖：`TencentCloudSDK.Sms` 3.0.1499（首次引入 NuGet 依赖，传递 `TencentCloudSDK.Common` + `Newtonsoft.Json`）。
- `ISmsService` + `TencentCloudSmsService`（`SmsClient` Singleton）；`Sms:Mock` 升级为 `TencentSms:Mode`（`Mock`/`Real`）判定。
- **失败降级**：Real 不可达/频控 → 现有 Error 结构（§2.3 映射），**不得回退 Mock 发码**（生产泄露验证码 = 安全事件，D14 §2.5）。
- 验证码散列存储/一次性消费/60s 重发逻辑不动（Storage.cs 既有）。

### 4.2 微信 OAuth（公共，绑定票据中转回调）

- **前置**：微信开放平台注册 + 开发者资质认证（300 元/年，企业/组织主体）+ 网站应用审核 + 开通「微信登录」能力 + 授权回调域名（`api.taoli.loongba.cn`，需 ICP 备案，D14 §3.1）。
- **两产品共用同一网站应用**（单一 `WECHAT_APPID`）：统一账号体系下教师/家长均扫码绑定到同一账号；`unionid` 落库（可空）为跨端打通预留。**微信网站应用展示名应中性**（如「龙爸教育」），避免扫码时误导教师/家长任一群体（Oracle N3）。
- **流程**（D14 §3.2）：

```
壳/小程序（已登录，持 JWT）── GET /api/edu/auth/wechat/authorize ─▶ 服务端
    服务端：生成 bind_token（TTL 30min，关联用户）+ state → 返回授权 URL
客户端 WebView ── 打开 open.weixin.qq.com/qrconnect?appid&redirect_uri&response_type=code&scope=snsapi_login&state#wechat_redirect ─▶ 用户扫码
微信 ── 302 ─▶ https://api.taoli.loongba.cn/api/edu/auth/wechat/callback?code&state
    服务端：校验 state → code 换 openid（AppSecret 服务端持有）→ 关联 bind_token 用户 → 绑定 wechat_openid
    ── 返回「绑定成功/失败」HTML（客户端 WebView 展示）
客户端 ── GET /api/edu/auth/wechat/bind/status?token=bind_token ─▶ 服务端：bound → 刷新用户态
```

- **bind_token 状态机**（D14 §3.2b，落盘）：

| 项 | 设计 |
|---|---|
| 存储 | 新增 `data/wechat_binds.json`（`WechatBindRecord(bind_token, state, user_id, status, created_at, bound_at)`） |
| 状态 | `pending → bound / expired / failed`；TTL 30min 写 expired；code 换 token 失败写 failed |
| 轮询 | `bind/status` 每 2s、上限 TTL 30min；命中终态即返回；轮询不改状态 |
| 安全 | bind_token/state 均 32 字节随机 hex；state 一次性校验；bind_token 高熵 + TTL 防枚举 |
| 并发 | 同一用户多次发起 → 前序 bind_token 置 expired（只保留最新） |

- **token 生命周期简化（D14 I6）**：不缓存 `access_token`、不持久化 `refresh_token`；userinfo（昵称/头像）后置为可选迭代。
- **安全边界记录**：当前仅「绑定」不「登录」；未来微信扫码登录需独立 session 防绑定劫持（D14 §3.2b 记录，公共层继承）。

### 5.2 教育小程序（`/api/edu/family/*`，D5 映射）

| 方法 | 路径 | 用途 | 预留契约原路径 |
|---|---|---|---|
| POST | `/api/edu/family/auth/activate` | 手机号 + 产品授权口令 + 设备标识 → 首次开通 | `/auth/activate`（改名消解冲突） |
| GET | `/api/edu/family/auth/status` | 授权状态 / 剩余有效期 / 可解锁工具 | `/auth/status` |
| POST | `/api/edu/family/data/sync` | 家庭码维度完成状态 / 打卡（数据最小化） | `/data/sync` |
| POST | `/api/edu/family/report/query` | 家长报告（仅完成状态/打卡聚合） | `/report/query` |
| （复用公共） | `password`（login 语义：手机号+密码）、`sms/send`+`sms/verify`（`scene:"family"`，验证码登录可选）、`password/reset`、`refresh`、微信 OAuth 三端点 | 家长登录/找回/刷新/微信绑定 | `/login`→`password`、`/reset`→`password/reset` |

**分层接入模型**（v0.3 澄清——非全量 44 款一次接入；对齐设计要求 §3.5/§4.6 与在线版统一机制「A→B→C 分批」）：

| 档 | 工具类型 | 服务端接入 | 示例 |
|---|---|---|---|
| **A** | 纯单机工具（离线红线：无账号/无云同步/无登录） | **不接**——保持纯静态 + localStorage（`auth.js`/`storage.js` 桩不变） | 多数益智/扩展款（舒尔特方格、找不同等） |
| **B** | 需跨设备进度 / 云存档 / 打卡 | **家庭码弱凭证**（孩子端无账号）+ `family/data/sync` 轻量信封（明细仍 localStorage，只上传完成状态/打卡） | 数独、口算热身等 |
| **C** | 需家长管理（报告 / 防沉迷 / 授权） | **家长手机号强认证**（family JWT）+ `family/auth/status` / `family/report/query`；孩子端走家庭码 | 数学巧算家长报告、点读陪练家长端、**主力 4 款**（peilian/shudu/qiaosuan/timemanager） |

- **接入节奏**：主力 4 款优先按 B/C 档接入；43 款非主力中多数 A 档不接，需要账号的按 B 档后续分批（设计要求 A→B→C 批；看板「B4 在线服务端接入 = C 批」）。
- **`data/sync` 语义（轻量信封）**：只同步「完成状态 / 打卡天数」等**最小化聚合**（设计要求 §4.6），**不做 44 款全量明细数据上云**——明细数据各工具 localStorage 自持，避免与离线红线（无账号/无云同步是产品特性）冲突。

- **孩子端无账号（家庭码进入）是硬约束**（设计要求 §3.5）：family 域数据以家庭码隔离，不采集儿童可定位数据。**家庭码 = 弱凭证**（非 JWT）：孩子端 `data/sync` 上传持家庭码即可；家庭码高熵（≥16 位随机，设计要求组内统计防反推）+ 服务端存在性校验 + 频控，避免成为可爆破的裸凭证（v0.3 澄清）。
- **接入替换边界**：公共 API 就绪后，教育小程序**只替换 `auth.js`/`storage.js` 内部实现，不改 `core/`**（在线版统一机制 §1.4 既有承诺）。
- 产品授权口令的签发/校验机制（口令 = 服务端签发？离线包口令包复用？）——**留教育小程序立项定稿**，公共方案仅定端点契约与「产品授权口令/家庭码数据不入公共 User 表」边界。

## 7. 验收标准

1. **公共部署**：`curl https://api.taoli.loongba.cn/api/edu/health` → 200；配置下发三件套 200（CORS + no-cache）。
2. **fail-fast 三件套**：Production 下 `JWT_SECRET` 缺/默认 → 拒绝启动；demo seed 清空 + 库中 demo 散列 → 拒绝启动；Production + Mock → `sms/send`、`wechat/authorize`、`family/auth/*` 503 `DISABLED` 无 dev_code；Production + Real → 正常闭环。
3. **短信**：Mock 冒烟（send → dev_code → verify）不变；Real 腾讯云（send → 验证码短信 → verify）；频控小时/天/IP 级生效（429）；腾讯云错误码映射正确。
4. **微信**：Mock（authorize → 假扫码 → 绑定幂等）；Real（扫码 → 中转回调 → 绑定真实 openid；重复绑定幂等；state 过期/错配拒绝；bind_token 终态轮询）。
5. **公共认证**：`scene:"family"` 首登得 `roles:["family"]` JWT；既有壳端无 scene 调用得 `roles:["teacher"]`（回归）。
6. **教育小程序 family 域**：`family/auth/activate` 开通 → `family/auth/status` 授权状态（Mock 态）；`data/sync` + `report/query` 冒烟**留教育小程序立项**（Oracle B2——与 §4.4 FamilyRecord deferred 一致，避免无存储空冒烟）。
7. **回滚演练**：切 `current` 软链 → 重启 → health 绿（data 不覆盖）。
8. **备份可恢复**：backup.sh sha256 校验 + 解包 data/ 完好 + 异地可达。

## 8. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 统一账号下 teacher/family 角色越权 | JWT roles 鉴权分域（family 域只接受 family 角色；teacher 域接口校验 lvl）；角色边界入单测 |
| family/teacher 数据隔离（儿童数据红线） | family 域数据以家庭码隔离；复用 A01 §5.1 白名单强制过滤机制；儿童可定位字段禁入公共库 |
| 家庭码弱凭证被爆破（孩子端 `data/sync`） | 家庭码高熵（≥16 位随机）+ 服务端存在性校验 + 频控（§5.2 v0.3）；弱凭证仅限最小化聚合上传，不含儿童可定位数据 |
| 腾讯云企业认证/微信审核阻塞（7–10 工作日 + 1–7 工作日） | **fail-fast 过渡**：Production + Mock → 认证端点 503，配置下发不受影响；教育小程序 family 域同期 Mock |
| 单一微信网站应用教师/家长共用 | 统一账号体系下绑定无冲突（openid 唯一挂账号）；安全边界记录继承（D14 §3.2b） |
| 双产品流量冲击单实例 | 轻量机单实例容量有限（认证接口轻量）；Caddy rate_limit + 应用层频控；超限再横向拆分（data/ JSON 单进程约束，D13 §8 同） |
| `scene` 可选字段被滥用（新账号角色歧义） | scene 仅影响**首登默认角色**；已有账号 scene 忽略（角色以账号既有 roles 为准） |
| server-dotnet 首次引入 NuGet 依赖（TencentCloudSDK.Sms） | 锁版本 3.0.1499；依赖仅限短信服务模块 |
| 教育小程序产品授权口令机制未定 | 公共方案只定端点契约与边界，口令签发机制留教育小程序立项（避免范围蔓延） |
