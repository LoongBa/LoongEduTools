# 龙爸乐学-教师客户端需求分析与设计方案（立项）

> 状态：**立项评估完成，待实施**。本文档为教师客户端（桌面壳）的需求分析与设计方案。
> 关联：点读小工具产物见 `RedTools/`（zip + dist 数据），本方案解决其**桌面分发、防盗、在线验证、升级**。
> 更新：2026-09-17

---

## 1. 项目背景与目标

### 1.1 背景

- 现状：龙爸乐学系列 H5 小工具（首个为「新英语四上点读1单元」）以 **zip + index.html** 分发。
- 痛点：
  1. 老师需在**教室电脑**上播放，zip 解压 + 双击 index.html 的操作对非技术用户不友好；
  2. 资源（音频 base64 js / 图片 webp）全部**明文可解压**，任何人解压即得全部素材；
  3. 无身份验证，谁拿到 zip 谁就能用；无升级通道，修复/新增单元需重新分发 zip。
- 目标：提供**单文件可执行客户端**，老师在教室电脑双击即用；资源嵌入加密提高防盗门槛；
  支持**在线验证身份（激活码）** 与 **自动升级**。

### 1.2 产品定位

| 项 | 说明 |
|---|---|
| 产品名 | 龙爸乐学（教师客户端） |
| 目标用户 | 小学英语老师（教室电脑，Win10/11） |
| 核心价值 | 一键播放教材点读内容；资源防盗；授权可控；版本可升级 |
| 形态 | 单 exe 桌面程序（WebView 承载 H5） |

## 2. 需求分析

### 2.1 功能需求

| 编号 | 需求 | 优先级 | 说明 |
|---|---|---|---|
| F1 | 双击运行即打开点读工具 | P0 | 无需安装、无需命令行、无需浏览器操作 |
| F2 | 支持全屏/窗口播放 | P1 | 教室投影场景常用 |
| F3 | 资源嵌入 + 加密，不可解压获取 | P0 | 普通用户无法从安装目录拿到原始素材 |
| F4 | 在线验证身份（激活码/账号） | P1 | 防止 zip 随意传播；离线兜底策略见 §2.3 |
| F5 | 自动升级（检测新版本→下载→替换） | P1 | 修复与新单元发布免人工分发 |
| F6 | 多工具支持（同一壳加载不同小工具数据） | P1 | 一套壳服务后续所有龙爸乐学小工具 |
| F7 | 教室无网可用（离线运行） | P0 | 验证通过后缓存授权，断网可继续用 |

### 2.2 非功能需求

| 项 | 要求 |
|---|---|
| 包体积 | 尽量小（目标 < 15 MB） |
| 目标电脑依赖 | 零额外依赖（或依赖 Win10/11 自带组件） |
| 兼容性 | Win10/11 x64 教室电脑 |
| 安全性 | 资源非明文；验证逻辑不被简单绕过 |
| 维护性 | 数据与壳分离：换单元只更新数据包，不动壳 |

### 2.3 关键场景与边界

- **离线兜底**：教室无网时不能锁死 —— 设计「激活后本地缓存授权，N 天免验证；到期需联网刷新」。
- **盗版边界**：无法绝对防盗（客户端资源终需解码），目标是挡住 99% 普通用户而非专业逆向。
- **版权边界**：素材版权归人教社，个人学习/课堂教学用途宽松；**商用需正式授权**（见 §7）。

## 3. 技术方案

### 3.1 打包技术选型（2026-09 评估）

| 方案 | 打包体积 | 目标电脑依赖 | 前置条件 | 结论 |
|---|---|---|---|---|
| **Tauri**（Rust） | **~3-10 MB** | **零依赖**（静态编译 + 系统 WebView2） | 需装 Rust 工具链（~500 MB） | **首选**（P0/P1 全满足） |
| .NET 单文件 self-contained | 60-150 MB | 零依赖 | 已有 dotnet 10 + C# 经验 | 备选（体积大） |
| .NET framework-dependent | ~5 MB | 需装 .NET 运行时 | 同左 | 教室电脑可能没有运行时 |
| Electron | 100 MB+ | 零依赖 | — | 体积劝退 |

**结论**：Tauri 为最优 —— 不捆绑 Chromium（用系统 WebView2）、Rust 静态编译无运行时、
官方升级插件（`tauri-plugin-updater`）、资源可编译进二进制。若暂不装 Rust，可先用 .NET 壳过渡。

### 3.2 总体架构

```
┌─ 龙爸乐学 教师客户端（Tauri 壳，一次开发通用）──────┐
│  exe（资源嵌入二进制 + 加密 + 前端 H5）              │
│  ├─ 启动 → 本地授权校验（缓存授权，过期走在线）     │
│  ├─ 在线验证身份（激活码 → Workers API）            │
│  ├─ 验证通过 → 加载对应小工具数据（可多工具切换）    │
│  └─ 启动时检测服务器新版本 → 下载签名包 → 自动替换   │
└────────────────────────────────────────────────────┘
        │ HTTPS                     │ HTTPS
        ▼                           ▼
  Cloudflare Workers            更新服务器
  验证/激活/授权 API            版本 JSON + 签名安装包
  （D1 存激活码）               （R2 存安装包）
```

### 3.3 关键设计决策

| 决策点 | 方案 | 理由 |
|---|---|---|
| 壳框架 | Tauri 2.x（Rust） | 体积最小、零依赖、官方 updater |
| 资源保护 | 前端资源编译进二进制 + 简单加密/混淆 | 挡 99% 普通用户；不做 DRM |
| 数据分离 | 小工具数据（data.js/音频/图片）作为**资源目录**或**独立更新包** | 换单元不动壳，走升级通道 |
| 在线验证 | Cloudflare Workers + D1 存储激活码；API 返回授权 + 到期时间 | 成本≈0、已有 Cloudflare 技能 |
| 授权缓存 | 本地加密存储（OS keychain/加密文件），离线 N 天兜底 | 教室无网可用 |
| 自动升级 | `tauri-plugin-updater` + 服务器版本 JSON + 签名安装包 | 官方成熟机制 |
| 构建集成 | 复用 `RedTools/build.py` 产物，打包脚本接入 Tauri 资源目录 | 数据管线零改造 |

### 3.4 数据流

1. **开发侧**：`RedTools/build.py` 产出 dist（数据+音频+图片）→ Tauri 构建脚本嵌入为资源。
2. **启动**：壳检查本地授权缓存 → 未过期直接进工具；过期/无授权 → 弹激活页 → 调 Workers API 验证。
3. **升级**：壳带当前版本号请求服务器 → 有新版则提示下载 → 下载签名安装包 → 校验签名 → 替换重启。
4. **多工具**：壳内置工具清单（id/名称/数据 key），按激活授权展示可用工具列表。

## 4. 部署与运维

| 项 | 方案 |
|---|---|
| 验证/授权 API | Cloudflare Workers（`/api/activate`、`/api/verify`、`/api/versions`） |
| 激活码存储 | Cloudflare D1（激活码表：码/状态/绑定设备数/到期时间） |
| 安装包托管 | Cloudflare R2 + 公网只读 bucket |
| 更新清单 | `versions.json`（版本号/下载 URL/签名/变更说明） |
| 签名 | Tauri updater 密钥对；私钥本地保管不入库 |
| 发布流程 | build.py 产数据 → Tauri 打包 exe → 上传 R2 → 更新 versions.json |

## 5. 实施计划（分阶段）

| 阶段 | 内容 | 交付物 | 验收标准 | 前提 |
|---|---|---|---|---|
| **P0 最小可用** | .NET WebView2 单文件壳：资源嵌入 + 简单加密，加载现有 dist | 可双击运行的 exe | 教室电脑双击即用；目录无明文资源 | dotnet 10 已就绪 |
| **P1 体积优化** | 迁 Tauri：编译进二进制、官方 updater | ~5MB 单 exe | 包体达标、升级通道可用 | 安装 Rust 工具链 |
| **P2 在线验证** | Workers + D1 激活码；壳接入授权 API + 本地缓存 | 激活码可生成/校验；离线兜底 | 激活→使用→到期→续期闭环 | 明确激活码销售/分发渠道 |
| **P3 多工具** | 壳内置工具清单，按授权展示 | 一壳多工具 | 切换不同小工具数据正常 | P1/P2 完成 |
| **P4 打磨** | 全屏/快捷键/日志/错误兜底 | 发布版 | 教室场景稳定性 | 实测反馈 |

## 6. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 资源仍可被专业逆向提取 | 素材泄露 | 接受边界：目标挡普通用户；版权合规兜底 |
| Rust 工具链安装成本 | 阶段 P1 延后 | 先用 .NET 壳交付 P0，Rust 就绪再迁 |
| 教室电脑无网 | 验证失败锁死 | 激活后本地缓存 N 天兜底，离线可用 |
| 激活码被共享 | 授权失效 | 绑定设备数上限 + 到期时间 + 风控（异常 IP） |
| WebView2 缺失（极老 Win） | 无法运行 | Win10/11 基本预装；缺失时引导安装（微软官方链接） |

## 7. 合规与版权

- 素材版权归**人民教育出版社及权利人**所有，仓库定位「个人学习用途」。
- 课堂教学（老师教室使用）通常属合理使用范围，**商用/对外分发需正式授权**。
- 激活码机制仅控制客户端使用，不改变素材版权归属。
