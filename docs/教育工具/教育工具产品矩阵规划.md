| 指标 | 值 |

**核心商业模式**：别人卖的是小游戏，我们卖的是**一线老师验证过的学习能力训练方案**（有标准答案的练习，非游戏，见指导原则 §一）。
**转化路径**：益智类引流 → 学科类转化 → 教师版变现。

**优先级图例**：
- 🔴 **P0** 首批上线（1-2 月）
- 🟠 **P1** 第二批（3-6 月）
- 🔵 **P2** 第三批（6-12 月）
- ⚪ **P3** 补充款

**学段与 L 级**：全产品标注适用学段（preK / K1-3 / K4-6），L 级为任务难度统一口径，见 §2.3。

### 2.3 学段与 L1–L4 分级口径（全规划前置口径）

**学段定义（K12 口径）**

| 学段 | 年龄 | 阶段定位 | 规划归属 |
|---|---|---|---|
| preK | 3–5 岁 | 启蒙期：感知、兴趣、语音引导、无计时压力 | 主营 · L1 |
| K1-3 | 6–8 岁 | 奠基期（核心）：幼小衔接、规则理解、独立操作 | 主营 · L2 |
| K4-6 | 9–11 岁 | 拓展期：策略运用、计时挑战、复合任务 | 后置 · L3 |
| K7-9 | 12–14 岁 | 远期暂缓：能力分化，另议 | 远期 · L4 |

> 对标学段覆盖：preK–K1-3 三家高度重叠（红海）；K4-6 仅未来之光/小象脑力部分覆盖；
> K7-9 无儿童专项。**主营 preK–K1-3 核心 + K4-6 后置**，K7-9 留远期。

**L1–L4 分级体系（任务难度 / 内容阶梯统一口径）**

| 等级 | 对应学段 | 益智类（能力任务难度特征） | 学科类（知识阶梯） | 分档参数示例 |
|---|---|---|---|---|
| L1 启蒙 | preK（3–5） | 单要素、零干扰、语音引导、无计时 | 数感 / 计数 / 图形认知入门 | 卡牌 4 对、无干扰 |
| L2 基础 | K1-3（6–8） | 双要素、低干扰、短计时（15–30s） | 数字书写 / 加减法 / 空间位置 | 卡牌 6–8 对、轻度干扰 |
| L3 进阶 | K4-6 低段（9–10） | 多要素、干扰项、计时挑战（30–60s） | 进退位 / 乘除启蒙 / 图形变换 | 卡牌 10–12 对、干扰项 |
| L4 挑战 | K4-6 高段 ~ K7-9（11–14，远期） | 复合任务、多策略、单人挑战赛 | 应用题 / 数独 / 推理综合 | 卡牌 16 对 + 记忆干扰 |

> 每个工具标注适用学段（如「preK–K1-3（L1–L2）」）；每 L 级内可再分 3 子档（-/+/++）
> 供自适应降档与解锁使用（对标未来之光「难度参数化」：一套任务模板 × 多档参数）。

### 2.4 双线边界与组织范式

| 产品线 | 定位 | 驱动范式 | 对标范式 | 边界原则 |
|---|---|---|---|---|
| 线一 · 益智类 | 脑力 / 认知训练（引流） | 认知能力维度驱动 | 小象脑力 / 未来之光 | 任务**不挂学科标签**（纯能力维度） |
| 线二 · 学科类 | 思维学科小应用（变现） | 学科知识领域驱动 | 洪恩思维 | 内容**不混入能力维度**（纯知识领域） |

> 两线范式纯粹、测评与迭代独立；数据可选打通（增强项，非 MVP）。
> 参考先例：大象智酷内部（未来之光/小象脑力 = 能力线）、洪恩教育内部（思维/识字/拼音 = 学科线），均分线运营。

### 2.5 对标要点（落地小工具的启示）

1. **同一引擎、两种封装**：小象 = 未来之光的儿童化封装，连「连线作战」等任务资产直接复用
   → 自建可参考「复用任务模板、重做儿童化交互」。
2. **不堆量**：未来之光 80+ / 6000+ 难度成壁垒，但小工具场景以「单款即用」取胜；
   益智类任务库控制在 50 内，靠 L1–L4 参数化一模板多难度（对标 6000+ = 参数化）。
3. **闭环是标配、深度分档**：小工具形态落地「练 + 打卡」为最小闭环；测/评/家长端属
   App 化增强（教师客户端立项另议），不塞入离线 zip。
4. **留存机制**：打卡日历 + 连续天数成就 + 集章/成长树（避免成人向 PK，符合儿童合规）。
5. **防沉迷优先**：儿童数据保护、家长控制、无社交——已有通用能力
   （`docs/通用需求-防沉迷自控力.md`）全工具复用。
