## 二、目标与原则

- **目标**：V0.4.0 交付「原理复述卡」闭环——①每讲结束引导孩子用自己的话复述原理（自由输入 2-3 句）；②复述内容本地存储（store v2→v3 迁移）；③家长在家长报告区回看（可打印，不评分仅供参考）。
- **原则**：
  - **原理先行落地，不评分不施压**：复述"不评分，仅记录"（需求 §2.3 原文）；鼓励性反馈，绝不出现对错/分数/排行。
  - **提示源自数据，不写死文案**：复述卡提示从 `lesson.principle`（一句话原理）+ `lesson.explore.steps`（推导链）+ `lesson.method.rhyme`（口诀）拼接生成，32 讲零人工维护。
  - **零音频约束**：需求 §4.3 硬约束"无 `<audio>`/`<video>`/data: URI"→ 复述**仅文字输入**（textarea + 键盘），不做录音（也规避真机录音权限/兼容问题）。
  - **儿童数据最小化**：复述文本仅存本机 localStorage，随 store 走；家长报告打印不含复述明细之外的画像。
  - **最小化修复，不借机重构**：不重构 LessonView 七步状态机、不重构 ReportView 现有 Panel。
  - **默认不打断练习流**：复述卡作为七步完成后的**可选收尾**（非强制弹层），已复述可修改。

## 三、变更设计（逐项）

### 3.1 复述数据模型（P2 · store v2→v3）

**现状**：`LessonRecord = { done, best, practiced }`；`StoreShape.version: 1 | 2`（类型 L57）；`emptyStore()` 返回 `version: 2`（L72）；`load()` 末尾硬写 `version: 2`（L103）。
**方案（v0.2 修订：落实 B1/B3 + I1/I2/I4 + N1/N6）**：

1. **`StoreShape.version` 类型扩展**（**B1/O3-N3 采纳**）：`version: 1 | 2` → `1 | 2 | 3`；`emptyStore()` 返回 `version: 3`；`load()` 末尾 `version: 2` → `version: 3`。`clearAll()` 调 `emptyStore()` **无需修改，自动跟随**（N1）。
2. **`LessonRecord` 扩展**：
   ```ts
   export interface LessonRecord {
     done: boolean;
     best: Partial<Record<Level, number>>;
     practiced: number;
     /** V0.4 原理复述卡：最新一次复述（文本 + 日期），未复述为 undefined */
     recite?: { text: string; date: string };
     /** V0.4 复述修改次数（置位时累计；删除不累计，I2/O3-I4 采纳） */
     reciteCount?: number;
   }
   ```
3. **store v2→v3 迁移**（对齐 v1→v2 迁移先例 load() L76-108）：
   - **无需逐讲补字段**：recite 可选，undefined 即"未复述"；旧 lessons 原样保留（复用 parse→merge 模式，`load()` 里 `lessons: parsed.lessons || {}`）。
   - 只需 version 字段升 3 写回（load 返回后 useEffect save 自动持久化）。
4. **新增 API** `saveRecite(lessonKey, text)`（ProgressApi）：
   - **纯逻辑抽 `applyRecite(store, lessonKey, text): StoreShape` 到 `src/lib/recite.ts`**（**B1/O3-B1 / I1/O2-I1 采纳**：必须独立纯 .ts，engine.mjs 才能 import；对齐 `guard.ts` 先例。`store.tsx` 内接线 `setStore(s => applyRecite(s, k, t))`，**返回 void**，不学 recordPractice 的 newCheckin 副作用反模式）。
   - 逻辑：
     - `text.trim() === ""` → **删除**（置 `recite: undefined`），**`reciteCount` 不累加**（语义=撤销，I2/O3-I4 采纳）；
     - 非空 → `recite: { text, date: todayStr() }`，`reciteCount = (prev || 0) + 1`（覆盖更新时累计）；
     - lessonKey 无记录 → 新建 `{ done: false, best: {}, practiced: 0, recite, reciteCount: 1 }`（复述可独立于练习完成；入口在 LessonView 七步后，practiced=0 + recite 有值属边缘可接受，N6）。
   - **`done` 语义不变**（仍=至少练过一次）；复述不置 `done`。
   - **不计入打卡/防沉迷**：不复用 recordPractice/addPlayed；`todaySec` 不累计。
5. **今日日期函数**：复用 `guard.ts` 导出的 `todayStr()`（已 padStart 2 位，YYYY-MM-DD 字符串排序可靠，O3-I3 确认）。

**涉及文件**：`src/src/lib/store.tsx`；新建 `src/src/lib/recite.ts`。

### 3.2 复述卡视图 ReciteView（P1 · 新增）

**现状**：LessonView 七步走完 →「开始练习」；无复述环节。
**方案（v0.2 修订：落实 B2/B3-I3 + I3/I4 + N2）**：

1. **App 路由扩展**（`App.tsx`）：
   ```ts
   | { name: "recite"; stage: number | string; lesson: string }
   ```
2. **LessonView props 扩展**（**I4/I3-O2 采纳**）：加 `onOpenRecite: () => void`（App.tsx 分发 `setView({name:"recite", stage, lesson})`）。
3. **入口（三层曝光，均不打断主流程，合并 O2-I3 + O3-N1）**：
   - **③ 原理步骤（ExploreStep）底部 inline 轻量入口**（O3-N1 采纳）：在现提示语"讲得出「为什么」，才算学会巧算"（L169-171）后追加 `<button className="text-link text-[12.5px]">→ 现在讲一讲</button>`——刚看完原理的最佳复述时机，不强迫。
   - **⑦ 练习步骤（PracticeStep）底部入口卡**（含已复述态"已复述 ✓ · 可再讲/修改"）——七步终点收尾时机。
   - **LessonView 顶部 banner 二次曝光**（**O3-I1 采纳**，实现 R2 机制）：PracticeView 结算返回时 LessonView 重新 mount（step 重置"前置"），靠练习步骤入口不可达 → 在 StepDots 上方（L56 前）渲染复述提示 banner：未复述"🧠 还没讲一讲原理哦 →"（点击 onOpenRecite）/ 已复述"✓ 原理已讲过 · 可修改"。banner 所有 step 可见、非模态、可忽略，符合"不打扰"。
4. **ReciteView 内容**（新文件 `src/src/views/ReciteView.tsx`）：
   - **头部**：返回 + 讲标题（对齐 LessonView 头部样式）。
   - **原理提示卡（先遮后展，B2/O2-B3 采纳）**：
     - **默认态**：只显示提问引导"想一想，用自己的话说说：为什么能这样算？" + 占位提示"2-3 句写下你的理解" + `🔎 看一眼提示` 折叠按钮；
     - **展开态**（点击后）：`lesson.principle`（一句话原理）+ `lesson.explore.steps`（带序号推导链）+ `lesson.method.rhyme`（口诀）；与 ExamplesStep "看答案/收起答案"（L222-233）交互模式一致。**绝不在默认态直接展示原理全文**（防复述退化为照抄）。
   - **复述输入区（非受控 defaultValue + ref，O3-B2 采纳）**：
     ```tsx
     const taRef = useRef<HTMLTextAreaElement>(null);
     <textarea ref={taRef} defaultValue={prevRecite?.text ?? ""} maxLength={200}
               placeholder="把你对原理的理解写下来，2-3 句就好"
               onInput={() => setLen(taRef.current?.value.length ?? 0)} />
     ```
     - **规避中文 IME composition 坑**（React 受控 onChange 会在拼音候选期间触发 setState 打断输入）——`defaultValue` + ref 取值，保存时才 `taRef.current.value.trim()`；字数用 `onInput` 读 ref（不 setState 驱动 textarea 值）。
     - **maxLength=200 兜底 + 字数软提示**（O3-N2 采纳）：字数显示"已写 X 字"，X≥180 时 `text-warm` 色软引导收尾，不强制。
   - **提交按钮**：保存 → `saveRecite(lessonKey, text.trim())` → 本地成功态「已保存 ✓」。**不评分、不显示对错**。
   - **已完成态**：再次进入预填已存文本（defaultValue 已含）；底部显示"上次复述：{recite.date}"。
5. **Chrome 61 合规**：textarea/受控组件/onInput/maxLength 属性原生支持；`String.prototype.trim` 自 Chrome 1 起可用（O2-N2 确认）；无新 API。

**涉及文件**：新建 `src/src/views/ReciteView.tsx`；`src/src/App.tsx`；`src/src/views/LessonView.tsx`（③ inline 入口 + ⑦ 入口卡 + 顶部 banner + props）。

### 3.3 家长回看（P3 · ReportView 增强）

**现状**：ReportView 4 Panel；打印管线已就绪（`print-hidden` / `report-root` / @media print）。
**方案（v0.2 修订：落实 B2/O2-B2 + I5/O3-I3 排序）**：

1. **ReportView 新增「📖 原理复述」Panel**（置于错题摘要之后、家长提示之前）：
   - **反查路径（B2/O2-B2 采纳）**：store.lessons 只存 `${stageKey}:${lessonId}` 键，**不存 title/grade** → 遍历 `STAGES`（参考 stageProgress L29-36 模式）取 `stage.grade` + `lesson.title`，按 `store.lessons[\`${s.stage}:${l.lesson_id}\`]?.recite` 筛选。
   - **显式 sort（I5/O3-I3 采纳）**：`recite.date`（YYYY-MM-DD，padStart 已对齐）字符串 `localeCompare` 倒序：
     ```ts
     const reciteRows = STAGES.flatMap((s) =>
       (s.lessons || []).map((l) => {
         const r = store.lessons[`${s.stage}:${l.lesson_id}`];
         return r?.recite ? { grade: s.grade, title: l.title, recite: r.recite } : null;
       }),
     ).filter(Boolean).sort((a, b) => b.recite.date.localeCompare(a.recite.date));
     ```
   - **无 warmup 前缀问题**：STAGES 遍历天然不含 warmup（warmup:* 键走 Object.entries 才需要过滤，此处反查路径自动规避）。
   - 每讲一行：`{grade} {title}` + 复述文本 + 复述日期（`recite.date`）。
   - **空态**："还没有原理复述记录——鼓励孩子讲一讲，讲得出原理才算学会。"
   - **打印语义（I5/O2-I5 采纳）**：屏幕态完整展示；**打印态只打印最近 5 条摘要**（`print-truncate` 类，styles.css 加规则：标题+日期+前 30 字），避免 32 讲全量拉伸多页。
2. **MeView 家长报告入口描述更新**：文案补「原理复述回看」。
3. **联动注意**：ReportView 只读，不新增写操作。

**涉及文件**：`src/src/views/ReportView.tsx`；`src/src/styles.css`（print-truncate 规则）；`src/src/views/MeView.tsx`（仅文案）。

## 五、风险与决策点

| # | 风险/决策 | 评估 | 处置 |
|---|---|---|---|
| R1 | 复述是文字输入，低年级孩子打字慢 | 口算/巧算产品需键盘输入答案（现已有 normalizeInput），打字能力是既有依赖 | 2-3 句软提示 + 不设最少字数门槛；家长回看重在"讲得出"的痕迹而非篇幅 |
| R2 | 复述卡可能被跳过（七步后直接去练习） | 复述是**可选收尾**（设计意图：不强迫），但需求期望"每讲结束设复述卡" | **三层曝光**（v0.2 强化）：③ 原理步骤 inline 入口 + ⑦ 练习步骤入口卡 + LessonView 顶部 banner（练习返回后二次曝光，O3-I1 机制）；仍不强制 |
| R3 | 空态/未复述讲次占比高 → 家长报告复述区空 | 新功能冷启动正常现象 | 空态引导文案；不做"必须复述才能解锁练习"的强制（会伤害主练习流） |
| R4 | recite 文本长度失控（localStorage 容量） | 单讲 2-3 句 ≈ 百字级，32 讲满算 < 10KB，远低于 5MB | textarea maxLength=200 兜底（O3-N2：字数 X≥180 时 text-warm 色软引导收尾） |
| D1 | 复述是否算练习时长（todaySec）/防沉迷 | 复述是思考表达，无标准答案 | **不累计**（方案 3.1 已定）；防沉迷只拦练习 |
| D2 | recite 是否需要独立时间线（多次复述保留历史） | 需求"家长可回看"未要求历史多次 | **只存最新一次**（覆盖）；`reciteCount` 记录编辑次数（删除不累计，v0.2 修订 I2），识别频率 |
| D3 | ReportView 复述 Panel 是否参与打印 | 家长回看核心价值 = 纸面可读 | **参与打印但截断**（v0.2 修订 I5）：打印态只出最近 5 条摘要（`print-truncate`），屏幕态完整 |
| D4 | `applyRecite` 抽取位置 | 支持 engine.mjs 单测 | **独立 `lib/recite.ts`**（纯 .ts，对齐 guard.ts 先例；store.tsx 是 .tsx 不可 import，O3-B1） |
| D5 | textarea 中文输入法（IME） | React 受控 onChange 会在拼音候选期打断输入（低幼产品敏感） | **非受控 defaultValue + ref**，保存时才取值（O3-B2） |
