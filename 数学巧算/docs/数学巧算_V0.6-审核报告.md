## 三、变更摘要（Oracle 外审 B3 + I5 + N4 处置记录）

方案 v0.1 → Sisyphus 自审 → **单 Oracle 外审**（bg_548da298）→ v0.2 修订。全部意见落实：

| 级别 | 意见 | 落地 |
|---|---|---|
| B1 | generatePractice 读 `window.SMART_GENERATORS` 违反 weak.ts 自包含先例（engine.mjs node 无 window） | engine **必填注入**、无默认值、不读全局；HandoutView 显式传 `getEngine()`；L9 单测 mock 传参零污染 |
| B2 | 打印场景 fallback 静默降级 = 废纸 | engine 不可用 → generatePractice 返回 [] → 讲义练习单区警告 + 打印按钮置灰（disabled），不降级 |
| B3 | §2「innerHTML 拼接」与 React 范式冲突 | 纯 JSX `.handout-sheet` 渲染（与 ReportView `.report-root` 同构），删 innerHTML 措辞 |
| I1 | StageView `<button>` 嵌套禁律（HTML 规范） | 外层改 `<div role="button" tabIndex onKeyDown>` + 内层 🖨️ button `stopPropagation` |
| I2 | 答案区在分页时会泄露给孩子 | `.handout-answer-area { break-before: page }` 强制新页 + 虚线提示 |
| I3 | 三档分区缺视觉分隔与命名 | 每档小标题「一、基础题（N 题）/二、提高题/三、挑战题」+ 描述文案 |
| I4 | count 硬编码 5/5/3 与部分讲次不一致 | count 从 `lesson.practice[level].count` 动态取，缺失兜底 5/5/3 |
| I5 | 路由无 level → 明确三档全打 | HandoutView 不接收 level，固定三档全打（贴"每讲 A4"语义） |
| N1-N4 | 生成日期 / 分区防切页 / 不计 store / useState 初始化器 | 全采纳（页脚生成日期；`.print-block` break-inside: avoid；不 todaySec/guard/practiced；`useState(() => ...)` 初始化器） |
