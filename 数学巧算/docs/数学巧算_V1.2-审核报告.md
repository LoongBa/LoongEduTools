## 三、实施偏离记录（方案 v0.2 与实现差异，全部留痕）

| # | 方案原文 | 实施 | 理由 |
|---|---|---|---|
| D1 | addPlayed 上移至 finished effect 统一两路径 | 定数完成路径（checkAnswer 内）保持现有同步调用；计时到期路径新增同构同步调用 | 上移 effect 会改变既有 dueInfo 浮层判定时序（effect 异步晚于 setStore）；两路径同构同步调用达成 Oracle I3 诉求且零行为回归 |
| D2 | 冒烟「计时触发到期」用真实等待 | 改用 `page.clock.runFor(31000)`（playwright-core 1.63） | 30s 真实等待不可行；runFor 连续触发 interval（fastForward 每 timer 至多 fire 一次，首跑 FAIL 后修正） |
| D3 | 冒烟「薄弱加权题型分布偏向（UI 统计）」 | UI 分布统计取消，分布验证由 engine L11 纯逻辑 400 次抽样覆盖（加权命中 >50% 且 <90%、封顶近似、avoid 零连选）；冒烟仅验证 warmupMist 持久化写入 | UI 抽样需 20+ 题真实作答成本高、随机波动大；L11 统计已直接覆盖加权逻辑 |
| D4 | 测试入口重生成命令 | 脚本无改动；调用方式 `powershell -File` 失败（$PSScriptRoot null），改 `pwsh -File` 成功 | 环境调用差异，脚本本身无问题 |
