# 数学巧算 V1.2.0 开发方案 · 口算热身增强

> 版本：v0.2（2026-09-29，Oracle 外审后修订）· 迭代级别：**重要级**（新功能 + store schema 跨文件接口变更）
> 流程：方案 v0.1 → Sisyphus 自审（1B）→ Oracle 外审（3B/5I/3N）→ 修订 v0.2 → 实施 → Sisyphus 审核报告

## 一、背景与目标

口算热身（V0.3.0 落地）是巧算学习的前置基础层。对照需求文档 §2.2 P0 承诺，当前只实现了最小子集，四项已承诺能力未落地：

| §2.2 承诺 | 现状 | 本轮 |
|---|---|---|
| 选题默认跟随当前教程阶段（学到阶段 4 → 默认出四则混合） | ❌ 固定三档年级手动选，且池仅一~三年级 12 个知识点（KOU_META 25 个只用了一半，阶段 4-6 的孩子热身无对应池） | **A 跟随教程阶段** |
| 计时挑战（30/60/120s） | ❌ 仅 10 题定数模式 | **B 计时挑战模式** |
| 题量可选 | ❌ 固定 10 题 | **C 题量可选（5/10/20）** |
| 薄弱优先出题 | ❌ 错题只进通用错题本（lessonId=`warmup:${level}` 无知识点类型信息，无法回练加权） | **D 薄弱优先出题** |

目标：V1.2.0 将口算热身从「三档 10 题」升级为「六档知识点池 + 跟随教程阶段默认选题 + 定数/计时双模式 + 薄弱加权」，补齐需求文档 P0 承诺。错题**重练**（按 expr 重出原题）属后续迭代「错题重练闭环」，本轮只做**同知识点加权优先出题**（不越界）。

## 二、范围

- **A. 跟随教程阶段选题**：六档（g1~g6）知识点池全启用；默认档 = 当前已学最大阶段对应年级（无进度回退 g1；仅学拓展阶段 → g6）；选档页「推荐档」标记。
- **B. 计时挑战模式**：30/60/120s 限时连答，倒计时到期自动结算；成绩口径 = 正确率（与定数模式统一）。
- **C. 题量可选**：定数模式 5/10/20（默认 10）。
- **D. 薄弱优先出题**：store 新增 warmup 错题知识点计数，出题按错题次数加权（封顶防偏科）。
- 防沉迷联动不变弱：两模式均计 todaySec + addPlayed；自律锁照常拦截。

**不做**：错题按 expr 重出原题（留给「错题重练闭环」）；热身进步曲线（后续看板候选）；键盘扩展（无必要，见 B3 裁决）。

## 三、设计

### 3.1 新增纯逻辑文件 `src/src/lib/warmup.ts`（engine 可单测，参考 recite.ts/weak.ts 模式）

- `export type WarmLevel = "g1" | "g2" | "g3" | "g4" | "g5" | "g6"`（**WarmLevel 从 WarmupView 迁入此处导出**，store 复用）
- `export const WARM_LEVELS: WarmLevel[]`（六档）
- `export const POOL: Record<WarmLevel, string[]>` —— 六档知识点池（见 3.1.1）
- `export const QUANTITIES = [5, 10, 20] as const`；`export const TIMES = [30, 60, 120] as const`
- `export function stageToLevel(stage: number): WarmLevel` —— 1→g1 … 6→g6；`<1`（0/负/NaN）回退 g1（无进度起点）；`>6` 回退 g6
- `export function currentStage(lessons: Record<string, unknown>): number` —— 遍历非 `warmup:` 前缀 key，取 `key.split(":")[0]` 可转数字者最大值；**`"X"` 前缀 key 记为 7**（拓展阶段视同 >6，Oracle I5）；无 → 0
- `export function defaultLevel(lessons: Record<string, unknown>): WarmLevel` —— `stageToLevel(currentStage(lessons))`（0 → g1；仅拓展 → g6）
- `export function pickType(pool: string[], mist: Record<string, number>, avoid?: string): string` —— 加权选型（见 3.1.2）
- `export function mistKey(level: WarmLevel, type: string): string` —— `"${level}:${type}"`

#### 3.1.1 POOL 知识点池（键盘可达性约束下全量启用）

现数字键盘 `0-9 . /`。KOU_META 25 知识点按「口算性 + 键盘可达」筛选，Oracle B3 核实后 **g6_pct / g6_ratio 答案不含 %/:（% 与 : 仅在题面），键盘可答，纳入池**：

| 档 | 知识点（id） | 取舍 |
|---|---|---|
| g1 | g1_10addsub / g1_20add / g1_20sub / g1_100 | 沿用现有 |
| g2 | g2_mult / g2_div / g2_100 / g2_mixed | 沿用现有 |
| g3 | g3_wan / g3_mult1 / g3_mult2 / g3_div1 / g3_frac | 沿用现有 |
| g4 | g4_simple / g4_div2 / g4_dec | 运算定律简算/整十除法/小数加减；排除 g4_big（大数改写，非口算） |
| g5 | g5_decmul / g5_decdiv / g5_frac1 / g5_frac2 | 小数乘除 + 分数约分/异分母加减 |
| g6 | g6_fracmul / g6_fracdiv / g6_pct / g6_ratio | 分数乘除 + 百分数互化 + 化简比求比值（答案均键盘可达，B3） |

#### 3.1.2 pickType 加权算法

```
权重 w(t) = 1 + min(mist[mistKey(level,t)] ?? 0, 3)   // 封顶 3，防薄弱知识点永久霸占
总分 S = Σw；随机 r ∈ [0,S)；按池顺序累减取中 → 返回 type
avoid 生效（Oracle I2 明确）：若池长 > 1 且选中 == avoid，则从 pool 中剔除 avoid 后
  对剩余 type 重新加权随机抽取一次（保留随机性，避免确定性回退）；剩余仅 1 个则直接取
```

### 3.2 store schema v3 → v4（跨文件接口变更）

`src/src/lib/store.tsx`：

- `StoreShape` 新增字段：`warmupMist: Record<string, number>`（key = `${level}:${type}`，count 累计；去重键有限 6 档 × 池大小）
- **`version` 类型联合 `1 | 2 | 3` 更新为 `1 | 2 | 3 | 4`**（Oracle I1，否则 typecheck 失败）
- `emptyStore()` 补 `warmupMist: {}` 且 `version: 4`；`load()` 补 `warmupMist: parsed.warmupMist || {}` 且 `version: 4`
- `ProgressApi` 新增 `addWarmupMist(level: WarmLevel, type: string): void`（count+1，纯 setStore updater）
- **`pushMistake` 签名不动**（通用错题本保持兼容，ReportView/weak.ts 零影响）；WarmupView 错题时**同时**调用 `pushMistake` + `addWarmupMist`

### 3.3 WarmupView 改造

- **选档页**（`level === null`）：
  - 顶部「推荐档」大卡：`defaultLevel(store.lessons)`，标注「按当前进度推荐」（学到阶段 3 → 推荐三年级档；无进度 → 一年级；仅拓展 → 六年级）。
  - 六档列表（POOL 全展开）：每卡显示档位知识点数与当前模式配置。
  - 页面底部配置条：**模式**（定数 / 计时）+ **题量** 5/10/20 或 **时长** 30/60/120 单选（不持久化，D3 惯例；默认 定数 10）。
  - 点击任一档卡片 → 以当前配置开始。
- **练习页**：
  - 定数模式：沿用现有流程，`TOTAL` 由所选题量决定；出题改 `pickType(POOL[level], store.warmupMist, prevType)`。
  - 计时模式：顶部倒计时条（剩余 mm:ss，每 100ms 刷新；与现有 ms 计时共用）；到期（ms >= 时长×1000）自动 `finish`；结算答对题数。
  - 判题错误：`pushMistake("warmup:"+level, q.text, q.answer)` + `addWarmupMist(level, q.type)`（**KouQ 已含 type 字段，无需改动**，Oracle N1）。
  - **防沉迷 addPlayed 统一**（Oracle I3）：定数与计时两 finish 路径（checkAnswer 完成 / 计时到期）的 `addPlayed(实际完成题数)` 调用**上移至 finished effect**（与 recordPractice 同处），避免计时到期路径漏调导致题量档少计。
  - 结算页：模式感知文案（定数「答对 X / N 题」；计时「限时内答对 X 题」）；`recordPractice("warmup:"+level, "basic", correct, total, sec)` **统一 key 不拆分**（correct/total = 正确率口径一致，best 兼容；`warmup:time:*` 新 key 会破坏 ReportView/MeView 解析，否决）；计时模式 total = 实际完成题数（含到期瞬间未答不计）。
  - **清理重复 locked() effect**（Oracle N2）：WarmupView 第 93-96 行与 181-184 行完全重复，删后者保留前者。
- **入口**（HomeView 文案/图标不动）。

### 3.4 测试

- `tests/engine.mjs` 新增 **L11「口算热身增强纯逻辑」**（**L10 已被「教程库→生成器契约」占用，Oracle B1**；新块编号 L11，变量 `l11bad`，输出 `L11 口算热身增强`）：
  - `stageToLevel`：1..6 → g1..g6；**0/NaN/负 → g1；>6（7/100）→ g6**（Oracle B2 修订测试设计，原「7→g1」与规格矛盾）
  - `currentStage`：warmup key 跳过；**"X:sxl1" 字符串 stage 记为 7**（Oracle I4/I5，原用例 "advance:..." 非真实 key 模式）；多讲取 max；空 → 0
  - `defaultLevel`：空进度 → g1；学到 s3 → g3；仅 "X:sxl1" → g6
  - `pickType`：无错题均匀落池（多次抽样覆盖全池）；错题加权命中提升（注入 mist 后该 type 命中率显著上升，抽样统计）；封顶（count 100 → 权重仍 1+3）；avoid 生效（池长 2 时不连选 avoid）
  - 键盘可达性抽查：POOL 六档全部 type 的 `gen` 返回 answer 均可被键盘输入域表达（数字/小数/分数 `a/b`）——逐 type 调 `KOU_GENERATORS.gen` 10 次断言 answer 格式（覆盖 g6_pct/g6_ratio）
- `tests/smoke.mjs` 扩展（热身场景）：
  - 选档页六档渲染 + 推荐档标记存在
  - 定数 5 题流程：配置条切 5 → 答 5 题 → 结算「答对 X / 5」
  - 计时模式流程：切计时 30s → 答若干题 → 触发到期 → 结算计时文案
  - 薄弱加权：预热 `addWarmupMist`（多次答错同一型）→ 断言练习页题型分布偏向该型（统计多题）
  - 防沉迷联动：计时模式完成仍触发打卡文案

### 3.5 合规复查

- 无网络引用 / 无 PK 排行晒分 / 儿童数据最小化（warmupMist 纯本地）；防沉迷不减弱。

## 七、风险与决策

| # | 风险/决策 | 处置 |
|---|---|---|
| R1 | 键盘仅 `0-9 . /`，部分知识点答案可能不可输入 | POOL 白名单保证键盘可达；g6_pct/g6_ratio 答案经核实不含 %/:，已纳入池（B3）；L11 逐 type 抽样断言答案格式（3.4） |
| R2 | 计时模式成绩口径与定数不同 | 统一为正确率（correct/total），不拆 key，兼容现有 best/报告 |
| R3 | 加权出题导致薄弱知识点永久霸占 | 权重封顶 `1 + min(count,3)`；avoid 剔除后重新加权（I2） |
| R4 | g4~g6 知识点 gen 可用性/键盘可达性未在现有测试覆盖 | L11 逐 type 抽样断言 answer 键盘可达（3.4） |
| R5 | 用户手动选高年级档可能超前于所学 | 产品自由（自选挑战），推荐档仅默认不强制；文案提示「当前进度」 |
| R6 | store v4 迁移遗漏导致旧数据丢失 | load 补默认 `parsed.warmupMist || {}`，与 v0.3/v0.4 迁移同模式；类型联合与版本号同步升 4（I1） |
| R7 | 仅学拓展阶段（无 1-6 进度）学生推荐档 | currentStage "X"→7 → stageToLevel→g6（I5） |
