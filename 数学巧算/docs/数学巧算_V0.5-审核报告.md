## 三、变更摘要（Oracle 双审 B1 + I×6 处置记录）

方案 v0.1 → Oracle2（架构视角 bg_e60a30b7）+ Oracle3（实施可行性 bg_74960324）双审 → v0.2 修订。全部意见落实：

| 级别 | 意见 | 落地 |
|---|---|---|
| B1 | `mistakes.lessonId` 是 raw "s4l3"，方案误用复合键 "4:s4l3" 反查 → 全量落空（双审独立发现） | `buildLessonIndex().get(mistakes.lessonId)` 直比（`l.lesson_id`），孤儿标记不静默丢弃 |
| I1 | recite-only 讲次照常推荐（删"不推荐"排除措辞） | `done !== true && practiced === 0` 判定，不检查 recite |
| I2 | 空态分两种（无错题 / 有孤儿错题） | `nonWarmupMistakeCount === 0` vs `weakMethods 全 orphan` 两组空态文案 |
| I3 | weak.ts 注入 STAGES 不 import（engine 无 `@/` 别名支持） | 零 import，`buildLessonIndex(stages)` 注入；L8 用 mock stages 测孤儿/边界 |
| I4 | 阶段 Pill 独立判定（不依赖 top-3 截断漏报） | `weakStages` 独立聚合：该阶段任一讲 wrongCount ≥ 2 即亮 |
| I5 | 错题摘要计数排除 warmup（与 share 分母口径一致） | `nonWarmupMistakeCount` 过滤 `warmup:` 前缀 |
| I6 | suggestWeek"跨阶段按序取前 2 讲" + 来源不足不强凑 | STAGES 顺序遍历取 incomplete；不去重逻辑不强凑 |
| N1-N4 | 建议不落地留 V0.6 / 不 truncate / 并列字典序 / 无需再抽象 | 采纳（N1 明确：ReportView 是家长门槛，跳学生练习流属 mode switch 留 V0.6） |
