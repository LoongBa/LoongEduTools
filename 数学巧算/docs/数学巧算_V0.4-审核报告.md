## 三、变更摘要（Oracle 双审 B×5 + I×6 处置记录）

方案 v0.1 → Oracle2（架构视角 bg_daecb3c3）+ Oracle3（实施可行性 bg_f3222eef）双审 → v0.2 修订。全部意见落实：

| 级别 | 意见 | 落地 |
|---|---|---|
| B1 | `StoreShape.version` 类型须扩展 `1\|2\|3`（O2）+ applyRecite 必须独立纯 .ts（O3） | `store.tsx` version 类型扩展 + 新建 `lib/recite.ts`（自包含零依赖，engine.mjs 直接 import） |
| B2 | ReportView 拿不到 title/grade 需 STAGES 反查（O2）+ textarea 中文 IME 坑需非受控（O3） | ReportView 遍历 STAGES 反查（`${s.stage}:${l.lesson_id}`）；ReciteView `defaultValue` + `ref` + `onInput` 读数 |
| B3 | 提示卡展示全文=照抄，需先遮后展（O2） | ReciteView 默认只显提问引导 + 「看一眼提示」按钮，展开含 principle/steps/rhyme |
| I1 | saveRecite 返回 void 不学 newCheckin 反模式（O2）+ R2 二次曝光机制缺失（O3） | saveRecite 纯接线无返回值；LessonView 顶部 banner（所有 step 可见，非模态） |
| I2 | reciteCount 删除语义模糊（O2/O3） | 空串删除置 `recite: undefined` 且 reciteCount **不累加**（语义=撤销） |
| I3 | ExploreStep ③ 错过复述时机（O2）+ 冒烟场景位置（O3） | ③ 原理步底部 inline「→ 现在讲一讲」；smoke 插在七步走查后、练习前 |
| I4 | LessonView props 缺 onOpenRecite（O2）+ 空串删除边界（O3） | props 加 `onOpenRecite`；handleSave 空串且无旧复述直接 return 不误触 |
| I5 | 打印态拉伸多页（O2）+ 显式 localeCompare 倒序（O3） | `print-truncate` 打印态只显最近 5 条 + 30 字摘要；`[...rows].sort(date.localeCompare)` |
| N | clearAll 自动跟随 / trim 可用 / maxLength=200 + 字数变色 / 防沉迷软提示 / done:false 边缘可接受 | 全部采纳（详见方案 §六） |
