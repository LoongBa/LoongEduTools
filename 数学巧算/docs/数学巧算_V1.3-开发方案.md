# 数学巧算 V1.3.0 开发方案 · 错题重练闭环

> 版本：v0.1（2026-09-29）· 迭代级别：**重要级**（新功能 + store API 新增）
> 流程：方案 v0.1 → Sisyphus 自审 → Oracle 外审 → 修订 v0.2 → 实施 → Sisyphus 审核报告

## 一、背景与目标

需求文档 §2.4「错题集：按方法分类，薄弱方法自动多出题」与 §2.5「薄弱方法 TOP3 + 下周建议」已落地**错题记录**与**家长侧只读摘要**（ReportView），但存在核心缺口：**错题本只进不出——学生端无重练入口、无掌握判定**。错题一旦入本，永久滞留（上限 50 满后旧题被挤掉），弱项统计（topWeakMethods/suggestWeek）无法反映"已掌握"。

目标：V1.3.0 补齐**错题重练闭环**——学生端「错题重练」入口 → 逐题原题重做 → 答对移出错题本（掌握即从薄弱统计消失）、答错保留计数 → 空态/结算反馈。衔接 V1.2 热身薄弱加权（warmupMist 知识点层加权）与本轮题面层重练，两层并行。

## 二、范围

- **入口**：HomeView 新增「错题重练」卡（显示当前错题数；空态改为表扬文案），位于口算热身卡下方。
- **视图**：新增 `ReviewView`（App 状态机加 `{ name: "review" }`）。
- **重练流程**：队列 = `store.mistakes`（最新优先，巧算 + warmup 错题统一处理）→ 逐题原题重做（题干 = `expr`，判题 = `normalizeInput(input, answer)`，WarmupView 同款）→ 答对移除 / 答错保留计数 → 队列清空结算或中途退出。
- **store**：新增 `retryMistake(key, correct)`：`correct` → 移出错题本；`wrong` → wrongCount+1（与 pushMistake 去重逻辑同源）。
- **防沉迷联动**：重练计 `addPlayed`（做题量）与 `dueInfo` 引导条（与练习/热身一致）；**不** `recordPractice`（重练不重复打卡、不新增 lessons 记录）。
- 顺带修正：HomeView 热身卡文案「一年级到三年级」过时（V1.2 已六档）→「六档年级」。

**不做**：PracticeView 结算联动"去重练"按钮（后置）；warmupMist 联动降权（见 R3）；错题按方法分类筛选重练；错题本上限调整；错题清空按钮（既有 clearAll 全清不动）。

## 三、设计

### 3.1 新增纯逻辑文件 `src/src/lib/review.ts`（engine 可单测，参考 recite.ts/weak.ts 模式）

- `export interface ReviewMistake`：`{ key: string; lessonId: string; expr: string; answer: number | string; wrongCount: number }`（StoreShape.mistakes 元素子集，结构化兼容）
- `export function applyRetry(m: ReviewMistake, correct: boolean): ReviewMistake | null`：
  - `correct` → `null`（已掌握，从错题本移除）
  - `wrong` → `{ ...m, wrongCount: m.wrongCount + 1 }`（保留）
  - 纯函数，store 接线调用
- `export function reviewQueue(mistakes: ReviewMistake[]): ReviewMistake[]` —— 重练队列：按数组序（pushMistake 已最新优先，无需再排序）；返回**新数组副本**（不污染入参，I4 边界断言验证）
- **删除 summarizeRetry**（Oracle I3 改法 a：结算只在队列全空触发，kept 语义失真；结算卡直接用本地 masteredCount / totalQueueSize 显示）

### 3.2 store API 新增（跨文件接口变更）

`src/src/lib/store.tsx`：

- `ProgressApi` 新增 `retryMistake(key: string, correct: boolean): void`：
  - **Oracle I2 改法**：`setStore` 内用 `flatMap` 遍历——`m.key !== key` 保留原条；命中条目调 `applyRetry(m, correct)`（null → 剔除，非 null → 替换）。**applyRetry 为唯一逻辑源**，store 零内联逻辑，L12 单测即覆盖 store 行为。
  - **pushMistake / addWarmupMist 签名不动**（重练是读-判-改错题本，不碰现有写入口；retryMistake 只移除/递增不新增，去重与 50 上限语义不受影响）

### 3.3 ReviewView（新视图）

- **布局**：复用练习页骨架（BackBtn + 题面 Panel + 数字键盘 + 提交/退格）。
- **队列**：`useState(reviewQueue(store.mistakes))`（进入时快照；答对移除 → 本地队列剔除 + `retryMistake(key, true)`；答错 → 本地计数 +1 + `retryMistake(key, false)`）。
- **顶部信息**：`剩余 N 题 · 本次已掌握 M 题`。
- **答对**：✓ 提示 + 300ms 后下一题；若队列空 → **结算卡（"错题重练完成 🎉 全部掌握（共 N 题）"）**（Oracle I3 改法 a：删"掌握 X/共 Y/还剩 Z"冗余文案，Z 恒 0）；结算时检查 `dueInfo()`，到点显示**组后二选浮层**（extendDue/enoughNow，同练习/热身，Oracle I1）。
- **答错**：显示答案 + 保留，不推进（同练习/热身交互），400ms 后继续可重试同一题。
- **空态**（进入时队列为空）：表扬卡（"错题都清光啦，继续保持！"）+ 回首页按钮。
- **中途退出**：BackBtn 直接退出（已掌握题已即时生效；不做结算）。
- **防沉迷**：答对推进时 `addPlayed(1)`（逐题累计，总量 = 队列数，与练习/热身组级累加等价，且中途退出场景更准确）；`dueInfo` 引导条 15s 轮询（同 WarmupView 第一段）；结算时 dueInfo + 组后二选（I1）；自律锁拦截（mount 检查 locked）。
- **判题**：`getNormalizer()`（SMART_GENERATORS.normalizeInput）+ `eqFallback` 兜底（从 WarmupView 复用模式，独立拷贝——第三份拷贝，N1 留痕：未来提取 `lib/judge.ts` 共享，V1.4 候选）。

### 3.4 视图接线

- `App.tsx`：View 联合加 `{ name: "review" }`；`HomeView` 加 `onOpenReview` prop。
- `HomeView`：热身卡下新增「错题重练」卡：
  - 有错题：`📚 错题重练 · N 道待掌握`（N = store.mistakes.length）
  - 无错题：`📚 错题重练 · 错题都清光啦`（仍可进入看空态表扬）
  - 热身卡文案修正「10 题口算打底 · 一年级到三年级」→「六档年级 · 定数/计时双模式」

### 3.5 测试

- `tests/engine.mjs` 新增 **L12「错题重练纯逻辑」**：
  - `applyRetry`：correct → null；wrong → wrongCount+1；边界 `wrongCount: 0 → 1`（I4 防御，pushMistake 不产生 0 但函数应自洽）
  - `reviewQueue`：返回全量副本（**与入参 `!==` 引用不等**，I4）、序保持、**空入参 → `[]`**（I4）
- `tests/smoke.mjs` 扩展（错题重练场景）：
  - HomeView 入口卡渲染 + 错题数显示
  - 空态：无错题进入 → 表扬卡文案
  - 完整闭环：练习答错 1 题 → 进入重练 → 原题重做答对 → 移出（HomeView 错题数减）→ 再进重练空态
  - 答错保留：重练答错 → 题保留（错题数不减）
  - **防沉迷固化断言（Oracle I5）**：① 重练答对 N 题 → `store.guard.playedToday` 增量 = N（addPlayed 生效）；② 重练前后 `store.checkin.length` 不变 + `store.lessons` 无新 key（不 recordPractice = 不打卡不新增记录）

### 3.6 合规复查

- 无网络引用 / 无 PK 排行 / 儿童数据最小化（重练纯本地读写）；防沉迷不减弱。

## 六、审核记录

| 版本 | 审核方 | 结论 | 意见处置 |
|---|---|---|---|
| v0.1 | Sisyphus 自审 | 自审 1 条（R1 修正） | R1 经分析为**伪风险**：重练判题 `normalizeInput(input, answer)` 只比较输入 vs answer（均数字/分数，键盘可答），与题面含 □ 无关；队列**不**过滤 |
| v0.2 | Oracle 外审 | **无 B** + 5I + 3N | **I 级 5 条全采纳**（I1 结算补 dueInfo + 组后二选；I2 retryMistake flatMap + applyRetry 唯一逻辑源；I3 删 summarizeRetry，结算「全部掌握共 N 题」；I4 L12 补空入参/引用不等/wrongCount:0 边界；I5 冒烟防沉迷固化 playedToday 增量 + checkin/lessons 不变断言）。**N 级**：N1（eqFallback 第三份拷贝→V1.4 提取 lib/judge.ts 候选，留痕）、N2（warmupMist 单向棘轮→未来 schema v5 mistakes 加 type? 联动递减，留痕）、N3（HomeView 文案 rider 接受，实施仅改文案行） |

## 七、风险与决策

| # | 风险/决策 | 处置 |
|---|---|---|
| R1 | 错题 expr 含 `□`（填空式题面）重做时无法作答 | **伪风险（自审修正）**：重练判题 `normalizeInput(input, answer)` 只比较输入 vs answer（answer 均为数字/分数，键盘可答），与题面含不含 □ 无关；队列不过滤，□ 题面照常重练 |
| R2 | 重练答对移除会改变 topWeakMethods/suggestWeek 分母 | 正是闭环价值（掌握即不薄弱）；家长报告口径自动一致（同读 mistakes） |
| R3 | warmupMist 不联动降权（错题无 type 字段无法定位） | 留痕：热身加权是知识点层、重练是题面层，封顶 3 防霸占；两层独立可接受。**N2 留痕**：未来 schema v5 迁移给 mistakes 加 `type?` 字段，重练答对时联动 warmupMist 递减（V1.4+ 候选） |
| R4 | 重练中途退出已移除的题 | 即时生效（无回滚）；退出不做结算，语义清晰 |
| R5 | 重练全量含 warmup 错题 | 统一处理（题干 + normalizeInput 判题兼容），闭环完整（热身错题也能重练） |
| R6 | 防沉迷记录：重练不 recordPractice（不重复打卡）但 addPlayed | 打卡日由 recordPractice 驱动；重练仅累计题量防沉迷，语义分离 |
