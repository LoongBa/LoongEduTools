## 0. 需求与目标

### 0.1 产品定义

**小学数学巧算学习产品**——以**口算、计算为基础**，按阶段教程教小学生**巧算技巧**并**分层练习**。

**一句话**：口算打基础，教程教技巧，练习见实效。

- **口算基础层**：继承现有「数学口算」v1.2.2 的 25+ 知识点出题引擎与练习闭环（看题→点选→即时反馈→打卡），作为每日基础计算能力训练。
- **巧算教学层**：按《小学数学巧算学习教程规划》的六阶段 + 拓展路线（一年级凑十 → 四年级简便运算枢纽 → 六年级分数裂项），每讲"原理先行"（七步结构），用生活情境 + 直观模型（小棒/点子图/面积图）讲透"为什么能这样算"。
- **巧算练习层**：每讲配基础/提高/挑战三档变式练习，并落"常规算法 vs 巧算"对照，让孩子体会巧算价值与适用边界。

### 0.3 产品原则（硬约束，延续规划文档）

| # | 原则 | 说明 |
|---|------|------|
| 1 | **原理先行** | 每一种巧算先讲"为什么能这样算"（背后运算律/数位原理），再给"怎么算"口诀；讲不出原理 = 没学会。 |
| 2 | **先明理、后提速** | 初期用直观模型慢算，理解透了再练速度；反对只背套路的"秒杀式"教法。 |
| 3 | **一题多解对比** | 每题同时给"竖式常规算"与"巧算"两条路，体会巧算价值与适用边界，避免机械套用。 |
| 4 | **路线螺旋上升** | 按年级认知与教材进度，从一年级凑十到六年级分数裂项逐级递进，每个新技巧建立在已学原理之上。 |
| 5 | **有标准答案** | 练习全部有正确答案判定（巧算结果 = 算出来的数，可判对错），无 PK/排行，合规安全区。 |
| 6 | **儿童数据最小化** | 只存本地进度/打卡/错题，不上传个人数据；防沉迷通用能力复用。 |
| 7 | **完全对齐教材** | 章节与人教版单元对应（见教程规划 §八），可作课堂补充或家庭自学路线；不额外扩展超纲内容。 |

## 1. 总体架构

### 1.1 架构原则：内容 SSOT（教程库），练习引擎复用，表现层双形态

```
                    ┌──────────────────────────────────────────────┐
    教程内容（LLM+人工）─▶│ content/ 教程库（SSOT）                    │
                    │  courses/<stage>/<lesson>.json              │
                    │  + stageN 分阶段教程（原理/例题/练习/变式）      │
                    └───────────────┬──────────────────────────────┘
                                    │
                     ┌──────────────┴──────────────┐
                     ▼                              ▼
          【口算引擎（复用）】            【巧算教程渲染层】
          generators.js 25+ 知识点       stage lessons 教学视图
          + 巧算技巧练习题生成器（新）      （原理探究/例题精讲/变式易错）
                     └──────────────┬──────────────┘
                                    │
                     ┌──────────────┴──────────────┐
                     ▼                              ▼
        【离线形态】单 HTML / Chrome 61      【在线形态】WebH5 React
        zip → 小红书/自营分发                 build:online → 部署（同点读陪练管线）
```

- **共享层**：教程库 JSON（SSOT）、口算生成器、练习判定逻辑、进度/打卡存储
- **分叉层**：
  - 离线：全部内联、Chrome 61 兼容（小红书 webview + 未知设备）
  - 在线：URL 直引、现代浏览器（与点读陪练 WebH5 同构）
- **复用**：数学口算 generators.js 原样接入（25+ 知识点零改动），新增**巧算技巧练习生成器**（按教程方法出变式题）

### 1.2 教程库结构（content SSOT）

### 1.3 练习判定（有标准答案）

- 口算基础层：复用数学口算 `validate()`（25 生成器真实反推校验，7500 题 0 失败）
- 巧算练习层：每道题统一 `answer`（数值）+ `accepted`（可接受等价答案集），`normalizeInput()` 归一判定

## 2. 功能需求

### 2.1 功能模块总览

| 模块 | 形态 | 说明 | 开发优先级 |
|---|---|---|---|
| **口算热身** | 每日基础计算 | 复用数学口算：年级+知识点选题 / 随机出题 / 计时挑战 / 打卡 | P0（复用即得） |
| **巧算课堂** | 分阶段教程 | 六阶段 + 拓展课程地图；每讲七步（原理探究为核心）；可打印讲义 | P0 |
| **技巧练习** | 每讲三档练习 | 基础/提高/挑战变式题；作答→判定→错题解释；"常规 vs 巧算"对照 | P0 |
| **练习报告** | 学习数据 | 打卡日历 / 各阶段进度 / 薄弱方法与错题集 / 家长报告（打印） | P1 |
| **防沉迷/自控力** | 通用能力 | 练习限时 / 到点提醒 / 自律锁（复用 V0.5 guard） | P1 |

### 2.2 口算热身（基础层 · P0）

**复用数学口算 v1.2.2 全部能力**（零重写）：
- 年级 + 知识点选题（25+ 知识点：20 以内加减、表内乘除、多位数乘除、小数、分数基础等）
- 随机出题 / button 数字键盘点选 / 即时反馈 + 连击 / 计时挑战（30/60/120s）
- 每日打卡 / 错题本 / 薄弱优先出题 / 进步曲线 / 防沉迷限时 + 自律锁

**与纯数学口算的差异**：口算热身是巧算学习的前置基础（每天 5 分钟明理后练速度），选题默认跟随当前教程阶段（如学到阶段 4 就默认出四则混合）。

### 2.3 巧算课堂（教学层 · P0）

**课程地图**：六阶段 + 拓展纵向路线（对齐知识路线信息图），每阶段一个卡片，进入后按讲次序学。

**每讲七步视图**（对齐教程规划 §二）：

| 步骤 | 呈现 | 交互 |
|---|---|---|
| 1. 前置知识检查 | 旧知识清单 | 点开自查，缺哪补哪 |
| 2. 情境引入 | 生活/游戏化问题 | 让孩子先有"算起来麻烦"的体验 |
| 3. 原理探究 | 直观模型（小棒/点子图/面积图/数轴）+ 运算律推导 | 逐步点击推进推导步骤 |
| 4. 方法要领 | 简短口诀 + 步骤化 | 可复述卡片 |
| 5. 例题精讲 | 2-3 道由易到难 | **常规算法 vs 巧算对照**（遮答案自己算 → 对比） |
| 6. 变式与易错 | 常见错误 + 算理原因 | 错误也是学习材料 |
| 7. 分层练习 | 基础/提高/挑战三档 | 5+5+3 题，判定 + 解释 |

**"讲不出原理不算学会"落地**：每讲结束设**原理复述卡**——让孩子用自己的话解释"为什么能这样算"（自由输入 2-3 句，家长可回看；不评分，仅记录）。

**打印讲义**：每讲可生成 A4 打印版（原理 + 例题 + 练习单），供离线纸张练习（复用数学口算打印题卡渲染）。

### 2.4 技巧练习（练习层 · P0）

- **三档变式**：基础（直接套方法）/ 提高（混合方法）/ 挑战（综合 + 限时）
- **常规 vs 巧算对照**：每道提高/挑战题先展示常规算法路径（竖式步骤），再展示巧算路径，"巧在哪"高亮
- **判定与解释**：答对 → ✓ + 鼓励；答错 → 显示答案 + 本方法口诀回放 + 入错题集
- **错题集**：按方法分类（如"分配律漏乘"），薄弱方法自动多出题（复用数学口算薄弱优先逻辑）

### 2.5 家长报告与打印（P1）

- 打卡日历（连续天数 + 今日阶段进度）
- 各阶段完成度（共 28 讲点亮状态）
- 薄弱方法 TOP 3（按错题分类统计）+ 下周建议（建议重练哪几讲）
- 家长报告可打印（复用英文陪练家长报告打印模式）

### 2.6 合规红线（延续全局）

- **有标准答案**：巧算练习全部可判定对错；无 PK/排行/晒分
- **儿童数据最小化**：本地存储；家长报告不导出个人画像
- **防沉迷**：练习限时档（5/10/15 分钟）+ 到点提醒延迟/自律 + 自律锁
- **零素材/零外部依赖**（离线形态）：教程用文本 + SVG 直观模型（小棒/点子图/面积图程序化渲染，零图片素材）

## 3. 内容范围与教程路线（对齐教程规划 §四/§五）

| 阶段 | 年级 | 主题 | 讲次 | 核心原理 |
|---|---|---|---|---|
| 1 | 一年级 | 20 以内加减 | 4 讲（10 分与合/凑十/破十/平十） | 十进制 · 凑十 |
| 2 | 二年级 | 百以内加减、表内乘除 | 4 讲（补数凑整/带符号搬家/连加转乘/综合） | 交换律、结合律直观版 |
| 3 | 三年级 | 多位数乘除 | 4 讲（分配律面积模型/拆数乘法/25·125·11 特殊数/商不变） | 分配律、结合律、商不变 |
| 4 | 四年级 | 简便运算系统化（**枢纽**） | 9 讲（运算律总览/基准数/结合律配对/分配律正用/提取公因数/减法性质/除法性质·商不变/两位数口算诀/综合策略） | 五大运算律 + 减除性质全齐 |
| 5 | 五年级 | 小数巧算 | 4 讲（化整还原/小数凑整/扩倍缩倍/小数分配律·拆数） | 数位移动 · 积的变化规律 |
| 6 | 六年级 | 分数与综合巧算 | 4 讲（乘前先约分/分数分配律/带分数拆分/裂项相消） | 约分本质 · 分数单位 |
| 拓展 | 四~六年级穿插 | 思维进阶 | 3 讲（等差数列求和/移多补少/平方差直观） | 配对 · 平均数 |

> **合计：28 讲**（六阶段 25 讲 + 拓展 3 讲）。本质 = 用好运算律，不是记特殊题型答案。

## 4. 技术设计

### 4.1 技术选型

| 层 | 选型 | 依据 |
|---|---|---|
| 口算引擎 | **复用** `数学口算/src/assets/generators.js` | 25+ 生成器 + validate 反推已交付零改动接入 |
| 巧算出题 | 新增 `smart_gen.js`（按方法出变式题） | 每讲 practice.gen 指向生成器 + 参数化 |
| 教程渲染 | 模板渲染（stageN_*.json → 视图） | 纯文本 + SVG 直观模型；数据驱动 |
| 离线形态 | 单 HTML + Chrome 61（对齐数学口算） | 小红书 zip ≤10MB |
| 在线形态 | WebH5 React `build:online`（对齐点读陪练） | 现代浏览器 + 增量内容更新 |
| 存储 | localStorage（`redtools.qiaosuan.v1`） | 进度/打卡/错题/薄弱统计 |

### 4.2 巧算出题生成器（smart_gen.js）

| 方法 | 生成逻辑 | 例题 |
|---|---|---|
| 凑十 | 9/8/7 + 随机个位（先算 10+ 余数） | 9+6=15 |
| 补数凑整 | 生成两对补数（和=100）+ 散数 | 28+75+72+25 |
| 基准数法 | N 个接近某数的数 + 差额 | 52+54+46+49+51 |
| 拆数乘法 | 接近整十整百的乘数 | 99×7 |
| 25/125 配对 | 25×4n / 125×8m 组合 | 25×16×4 |
| 提取公因数 | 同因子 × 两数 | 25×37+25×63 |
| 商不变 | 除数凑 25/125/100 | 600÷25 |
| 小数凑整 | 0.25×4 / 1.25×8 组合 | 4.8×9.9 |
| 裂项 | 1/(n×(n+1)) 连加 | 1/2+1/6+1/12+1/20 |

> 每生成器配 `validate()`（反推校验），对齐数学口算"7500 题 0 失败"质量标准。

### 4.3 Chrome 61 兼容（离线形态硬约束，对齐 RedTools 规范）

- JS：经典脚本、无 `?.`/`??`/`replaceAll`/对象展开；事件一律 `addEventListener`
- CSS：无 flex `gap` / `aspect-ratio` / `clamp()` / 逻辑属性 / `:has`
- 音频：**零音频**（巧算是数学练习，无需 TTS；口算热身也无音频，天然规避 CSP 音频问题）
- 无 fetch/XHR/外部引用；无 `<audio>`/`<video>`/`data:` URI
