## 二、目标与原则

- **目标**：V0.6.0 交付「打印讲义」——①每讲可生成 A4 打印版（标题 + 原理 + 例题 + 练习单 + 答案区）；②入口从 LessonView（课堂内打印当前讲）+ 课程地图（打印任意讲）；③复用 V0.3 打印机制（window.print + @media print + print-sheet 模式对齐数学口算）。
- **原则**：
  - **复用不重写**：打印管线对齐 V0.3 家长报告（window.print + @media print）；讲义结构取 SmartLesson 现有字段（principle/explore.steps/method/examples），零内容改动。
  - **题面运行时生成**：练习单题面由 `engine.gen(genName)` 打印时生成 N 题（复用 PracticeView 同源引擎），**不改 content SSOT / 不扩 stages.generated**。生成题面以 `{type, text, answer}` 返回（已验证 combo_basic → `"30 + 18 + 9 ="` / `57`）。
  - **纸张练习语义**：练习单每题 = 题面 + 空白作答区（下划线），答案区独立块（家长批改用，不让孩子先看到）。
  - **纯 JSX 渲染（B3 修订）**：讲义 DOM 由 React JSX 渲染（`.handout-sheet`，与 ReportView `.report-root` 同构）；**不用 innerHTML 拼接**（那是数学口算经典脚本的 makeEl 方案，React 工程不适用）。
  - **离线合规**：零新依赖/网络/音频；print 仅 window.print + @media print。
  - **打印讲义不计入 store（N3 采纳）**：不累加 todaySec、不触发 guard 拦截、不计入 practiced——纯只读 lesson 数据 + 只生成题面。
  - **最小化修复，不借机重构**：不重构 LessonView 七步状态机 / ReportView / store。

## 三、变更设计（逐项）

### 3.1 打印讲义数据组装（P1 · 新文件 lib/handout.ts）

**现状**：SmartLesson 有 principle / explore.steps / method.rhyme / examples[].expr/normal/smart/why；无题面池。
**方案**：

1. **新建 `src/src/lib/handout.ts` 纯逻辑层**（对齐 guard/recite/weak 自包含模式，engine.mjs 可单测）：
   ```ts
   export interface HandoutExample { expr: string; normal: string; smart: string; why: string; }
   export interface HandoutSheet {
     lessonTitle: string;
     grade: string;
     principle: string;
     exploreSteps: string[];
     methodRhyme: string;
     examples: HandoutExample[];      // 讲义例题（取 SmartLesson.examples 全部，≤3）
     practice: HandoutPractice[];     // 练习单（运行时生成）
   }
   export interface HandoutPractice { text: string; answer: number | string; }
   /** 组装讲义结构（纯数据变换，examples 截断 ≤3、字段缺省兜底） */
   export function buildHandout(lesson, grade): HandoutSheet;
   /**
    * 生成练习单题面（B1 修订：engine 必填、无默认值，不读 window——对齐 weak.ts 零全局依赖先例）
    * 失败不降级（B2 修订）：engine null 或 gen 返回 null → 返回空数组，由调用方决定 UI
    */
   export function generatePractice(
     genName: string,
     count: number,
     level: string,
     engine: { gen(name: string): { text: string; answer: number | string } | null } | null,
   ): HandoutPractice[];
   ```
   - `buildHandout`：纯变换，从 lesson 提取 principle/explore.steps/method/examples（examples slice(0,3)）。
   - `generatePractice`（B1/B2 落实）：循环 `engine.gen(genName)` 生成 count 题；engine 为 null 或某次 gen 返回 null → **立即返回 `[]`（不静默降级）**；count 由调用方传（I4 落实：HandoutView 从 `lesson.practice[level].count` 动态取，缺失兜底 5/5/3）。
2. **engine.mjs L9「handout 纯逻辑」单测**（B1 落实：engine mock 直接传参，零全局污染）：
   - buildHandout：字段提取 / examples 截断 ≤3 / 缺省兜底（无 explore.steps → []）；
   - generatePractice：mock engine 生成 count 题 / engine null → `[]` / gen 返回 null → `[]`。

**涉及文件**：新建 `src/src/lib/handout.ts`；`src/tests/engine.mjs`（L9）。

### 3.2 打印讲义视图 HandoutView（P1 · 新视图 + 路由）

**现状**：无讲义视图；App.tsx 路由有 home/stage/lesson/recite/practice/warmup/me。
**方案**：

1. **App 路由扩展**：`| { name: "handout"; stage: number | string; lesson: string }`。
2. **新建 `src/src/views/HandoutView.tsx`**（B3 落实：纯 JSX 渲染，不用 innerHTML / 不挂 #print-sheet）：
   - **屏上预览态**（print-hidden 顶部工具条）：返回 + 标题「打印讲义 · {grade}《{title}》」+ 预览说明 + `🖨️ 打印` 按钮（`window.setTimeout(() => window.print(), 30)` 保手势上下文，对齐 ReportView L52-54）。
   - **`.handout-sheet` 渲染**（纯 JSX，与 ReportView `.report-root` 同构）：
     - 头部：产品名 + 讲标题 + 年级 + 日期行（纸张手写填写）；
     - **一、原理**：principle 段落 + explore.steps 编号列表；
     - **二、方法口诀**：method.rhyme 高亮块（若有）；
     - **三、例题**：examples 每题（题面 + 常规算法 / 巧算对照，对齐 ExamplesStep 布局的纸张版）；
     - **四、练习单（三档全打，I5 明确——路由不接收 level）**：每档小标题（I3 落实）——
       ```
       一、基础题（5 题）
       1. 30 + 18 + 9 = ______
       …
       二、提高题（5 题）
       …
       三、挑战题（3 题）
       …
       ```
       档数 = `lesson.practice[level].count` 动态取（I4 落实），缺失兜底 5/5/3；
     - **答案区（I2 落实）**：独立块 `break-before: page`（强制新页）+ 虚线"请家长沿此线裁剪/折叠"——防孩子翻页见答案；
     - 页脚：`生成日期：{todayStr()} · 巧算乐学 V0.6.0`（N1 采纳）；
     - 分页：每档 `.print-block { break-inside: avoid }` 防档内切页（N2 采纳）。
   - **生成时机（B2 落实）**：`useState(() => generatePractice(...))` 初始化器（N4 采纳：StrictMode dev 双调无害，纯函数）；生成结果为空（engine 不可用）→ 练习单区渲染 `print-hidden` 警告 + 屏上提示「⚠️ 引擎未就绪，练习单未生成，请刷新后重试」，打印按钮置灰（disabled）。
   - **打印隔离**：`view.name === "handout"` 条件渲染，打印时 DOM 仅讲义；`.app-shell` 打印解绑（styles.css I9 已就绪）覆盖。
3. **入口（两处）**：
   - **LessonView 顶部 banner 下方**加次级入口「🖨️ 打印讲义」（与复述 banner 并列，不打断主流程）；已进课堂即打印当前讲，最贴"每讲 A4"语义。
   - **StageView 讲次列表**每讲行尾加「🖨️」小按钮（I1 落实：**外层 `<button>` 改为 `<div role="button" tabIndex={0} onClick onKeyDown>`**，内层打印 `<button onClick={(e) => { e.stopPropagation(); onPrint(); }}>`——HTML 禁 `<button>` 嵌 `<button>`）。
4. **打印隔离**：HandoutView 条件渲染（view.name === "handout"），打印时 DOM 仅讲义（对齐 ReportView 条件渲染注释）；App 外壳 `.app-shell` 打印解绑规则（styles.css I9 已有）已覆盖。

**涉及文件**：新建 `src/src/views/HandoutView.tsx`；`src/src/App.tsx`；`src/src/views/LessonView.tsx`（次级入口）；`src/src/views/StageView.tsx`（列表行按钮，外层 div role=button 改造）。

### 3.3 @media print 样式（P1 · styles.css）

**现状**：styles.css L248+ 已有 @media print（.print-hidden / .print-clean / .app-shell 解绑 / .report-root）。V0.4 加 .print-truncate / .print-only。
**方案（v0.2 修订：落实 I2 答案区分页 + I3 三档分隔 + N2 档内防切）**：
- 新增讲义打印规则（@media print 内追加）：
  ```css
  .handout-sheet { max-width: 100%; padding: 0; }
  .handout-sheet .print-block { break-inside: avoid; page-break-inside: avoid; margin-bottom: 12px; }
  .handout-practice-row { display: flex; align-items: baseline; gap: 8px; margin: 6px 0; }
  .handout-answer-area { break-before: page; margin-top: 16px; border-top: 2px dashed #999; padding-top: 8px; }
  ```
  - I2：`.handout-answer-area { break-before: page }` 强制答案区新页，防孩子翻页见答案。
  - N2：每档一个 `.print-block`（基础/提高/挑战各一），档内 `break-inside: avoid` 防切页，档间允许分页。
  - 对齐现有风格（.report-root 同类）；flex gap 本项目已用（ReportView L69 `gap-x-5 gap-y-1`，audit 通过，非经典脚本静态构建）。
- 屏上预览态隐藏：工具条 `print-hidden`；`.handout-sheet` 默认可见（预览 = 打印内容）。

**涉及文件**：`src/src/styles.css`。

## 五、风险与决策点

| # | 风险/决策 | 评估 | 处置 |
|---|---|---|---|
| R1 | 打印题面每次生成不同（非确定性） | 纸张练习本就随机出题，家长可接受；若需固定可在未来加 seed | 接受（随机题单 = 复练价值）；不改 content SSOT |
| R2 | 打印触发时机（点按钮 → window.print）在 Chrome 61 的手势上下文 | ReportView L52-54 已验证 `setTimeout(30)` 模式可用（V0.3 交付时 file:// 验证通过） | 沿用 |
| R3 | 讲义过长撑多页（32 讲全打印） | 单讲讲义 = 原理段 + 例题 3 + 练习 13 题，约 1-2 页 A4；拓展 X 或例题多的讲可能超 2 页 | 每档 `.print-block { break-inside: avoid }` 防档内切页（N2）；答案区 `break-before: page` 独立新页（I2） |
| R4 | HandoutView 与 LessonView 复用 lesson 数据 | STAGES 反查模式（V0.4 recite 同构） | 沿用 |
| R5 | 引擎未就绪时打印练习单 | engine null / gen 失败 | **不降级**（B2）：练习单区警告 + 打印按钮置灰；杜绝废纸 |
| D1 | 练习单是否含答案区 | 纸张练习需家长批改 | **含**（独立"答案（家长用）"区 + `break-before: page` 强制新页防泄露，I2） |
| D2 | 打印入口位置 | 课堂内（当前讲）+ 课程地图（任意讲） | 两处都做（入口廉价）；课堂内为主（贴"每讲"语义） |
| D3 | 讲义题量 | 练习档 count（动态取 `lesson.practice[level].count`，I4） | 不硬编码；缺失兜底 5/5/3 |
| D4 | generatePractice 的 engine 依赖 | 参数必填注入（B1）；失败返回 [] 不降级（B2） | HandoutView 传 `getEngine()`；测试传 mock |
| D5 | 打印讲义是否计入防沉迷/store | 纸张练习非屏上 | **不计入**（N3）：不累加 todaySec、不触发 guard、不计 practiced |
