## 4. 变更摘要（发布用）

**英语点读 v1.3.0 — 重绘工作台修复迭代**：
1. **测试链接动态化**：app_name 由服务端权威下发（BOOK_MAP 前缀派生 + resolve_unit_no 单元解析），11 册任意单元可正确解析产物；未构建时友好提示
2. **审核单元定位**：工作台点「审核」直达对应单元首张重绘页（?unit 锚点）
3. **修复重绘队列瘫痪**：`import time` 缺失导致 worker 线程 NameError 崩溃（修复前 /api/redraw 入队后任务永久卡 queued）
4. **寻址口径统一**：服务端为单元元数据权威源，前端零重复逻辑
5. **发布闭环可诊断**：rebuild 失败展示构建日志尾部；promote 备份带日期时间戳保留多版
