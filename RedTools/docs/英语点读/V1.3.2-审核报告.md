## 4. 变更摘要（发布用）

**英语点读 v1.3.2 — 书页完整性校验 + 工作台补强 + 审计/合规一体化 + 并发防护**：
1. **书页完整性校验**：构建期自动校验缺页/零 track/图片对齐（重绘缺原版兜底=WARN、双缺=ERROR 进 `--strict`）；`build_framework.py` 直跑也支持 `--strict`
2. **工作台校验升级**：单元卡片增「📄 缺页 N」「📄 零track N」徽章；`--strict` 对发布 zip 附加体积/文本门禁审计
3. **合规自查脚本**（`scripts/compliance_check.py`）：扩展名白名单 + CSP 禁项 + 产品红线禁词（排行榜/云存档/多人互动/PK/排名），zip/目录双输入，audio 数据目录与 base64 误报已校准
4. **一键审计**：工作台「🔍 审计」按钮 → /api/audit 跑体积门禁 + 合规自查，弹层分级展示 ERROR/WARN/PASS
5. **任务日志流式**：重绘任务实时日志（增量渲染 + 自动滚动 + 500 行封顶），子进程零输出挂起自动超时 kill（不再卡死队列）
6. **交互打通**：热区编辑器保存后自动回传刷新工作台；审核按单元推进，单元末自动衔接下一单元（无重绘页自动跳过）
7. **并发防护**：校验/审核缓存文件读写加锁，并发 validate 不再丢失更新
