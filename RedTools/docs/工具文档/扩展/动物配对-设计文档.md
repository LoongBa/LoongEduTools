## 2. 玩法设计

### 2.1 核心规则

- 每局限定 N 对：左列 **N 只动物卡**（固定顺序，题面）+ 右列 **N 个家园卡**（洗牌，答案）。
- 点动物（选中高亮）→ 点家园：该动物生活在该家园 → **配对成功**（绿框 + 右上角 ✓ 角标 + 卡片淡化）。
- 配错 → 两卡红闪 + 错误计数 + 取消选中，可重试（仅计错误次数）。
- 全部 N 对配对完成 → 过关结算（计时 + 星级 + 打卡 + 成绩记录）。
- 卡片 = **大字 emoji + 文字标签**（对标反义词配对，系统 emoji 零素材、Chrome 61 兼容）。

### 2.2 六大家园与动物归属

| 家园 | emoji | 动物（每家园 ≥1，出题随机抽 1） |
|---|---|---|
| 🌊 海边 | 🌊 | 海鸥🐦 小鱼🐟 螃蟹🦀 海星⭐ |
| 🌲 森林 | 🌲 | 松鼠🐿️ 狐狸🦊 兔子🐰 猫头鹰🦉 |
| 🏡 农场 | 🏡 | 奶牛🐮 绵羊🐑 小鸡🐔 鸭子🦆 |
| 🐠 海底 | 🐠 | 海龟🐢 水母🪼 鲸鱼🐳 章鱼🐙 |
| 🌷 花园 | 🌷 | 蝴蝶🦋 蜜蜂🐝 蜗牛🐌 |
| ❄️ 冬日 | ❄️ | 企鹅🐧 小鹿🦌 |

> 动物归属表驱动出题（ANIMAL_HABITAT：animal key → habitat key）；后续扩展动物只需加表项。

### 2.3 三档难度（栖息地数 ≥ 对数 → 家园卡必不重复）

| 档位 | 家园集合 | 对数 N | 卡总数 |
|:---:|---|:---:|:---:|
| 简单 | 海边 + 森林 | 2 | 4 张 |
| 普通 | 海边 + 森林 + 农场 + 海底 | 4 | 8 张 |
| 困难 | 6 家园随机 5 | 5 | 10 张 |

- **关键设计**：每局从不同家园各取 1 只动物（`shuffle(habitatKeys).slice(0, pairs)` 后逐家园抽），保证右列家园卡**视觉不重复**——低龄儿童不会被两张一模一样的答案卡困惑。
- 星级常模：0 错 3★ / 1-2 错 2★ / ≥3 错 1★（对齐反义词配对口径）。

## 3. 界面结构

```
首页（难度选择）
  ├─ 标题/版本徽标（header）
  ├─ 页题「选择难度」+ 提示「把动物送回它的家园！」
  ├─ 三档难度卡（名称 + 对数徽章 + 最佳成绩）
  ├─ 🐾 小知识（六大家园 + 打卡说明）
  └─ 📅 打卡日历入口（连续天数）
游戏页
  ├─ 顶栏：←返回 / 档位 / ⏱ 计时
  ├─ 进度「配对 x/N」+ 提示「点一只动物，再点它生活的家园」
  └─ 左右双列：左「动物」N 卡 ｜ 右「家园」N 卡（emoji 40px + 标签 14px）
结算浮层
  ├─ 🎉 全部送回家啦！+ 用时/错误
  ├─ ★ 星级 + ✅ 打卡行 + 🎉 新纪录
  └─ 再来一局 / 选难度 / 📅 打卡日历
打卡日历页（本月打卡 + 连续天数）
```

- 视觉：绿系（对齐扩展系列/反义词配对，`#2fbe9e` 主色）；Chrome 61 兼容（无 flex gap / aspect-ratio / clamp / :has；前后清浮动）。
