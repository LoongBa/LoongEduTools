### 2.2 金额表示与运算（关键设计）

- **最小单位 = 角**（1 元 = 10 角），全部整型运算，**杜绝浮点误差**
- `fmtMoney(jiao)`：10 的倍数 → "X 元"；<10 → "X 角"；否则 → "X 元 Y 角"
- 找零 = 实付(元) − 价格(角)，恒为正且展示一致

## 3. 技术方案

### 3.1 SVG 钱币渲染（零图片素材）

```js
// 硬币（1角/5角）：viewBox 0 0 60 60，外圆 r25 面额主色 + 内圈白环 + 面值数字+「角」
// 纸币（1元/5元/10元）：viewBox 0 0 80 60，圆角矩形浅底 + 左侧色条 + 面值大数字 + 「元」+ 装饰圆点
// 面额主色：1角 金 #e8b04b / 5角 银 #c9ced6 / 1元 绿 #2e9e5b / 5元 紫 #7b4bb6 / 10元 蓝 #3b7dd8
```

- 面值数字：**硬币 = val（角数）**，纸币 = val/10（元数）——修复过 5 角误显示 "0.5角" 的 bug（val/10 无特判）

### 3.2 出题引擎

| 题型 | 生成 | 答案/校验 |
|---|---|---|
| 认一认 | 随机 1 种面额 SVG + 4 选 1（正确 + 3 干扰面额名） | 面额名匹配 |
| 换一换 | 7 个换算模板随机（5 角=几个1角/1元=10角/10角=几元…） | 模板内置答案 |
| 凑一凑 | 价格 = 随机抽 2-6 枚钱币求和（**保证可恰好凑出**）+ 随机商品 | 贪心解 + 恰好匹配 |
| 找一找 | 价格 15-45 角随机 + 实付 50 角，找零 = 50−价格；干扰 ±1/±5/±10 角去重 | 角整型相减 |

### 3.3 持久化（redtools.money.v1）

{

## 4. 交互流程

```
首页（进度卡 + 认识钱币/开始练习 2 入口，垂直居中）
  ├─ 认识钱币 ────► 5 面额 SVG 展示 + 元角换算说明
  ├─ 开始练习 ────► 阶段选（1 认钱币 / 2 凑钱购物 / 3 购物找零，未解锁 🔒）
  └─ 底部导航：打卡日历 / 首页
练习页（10 题）：
  认一认：钱币图 → 4 选 1
  换一换：换算题 → 4 选 1
  凑一凑：商品价 + 钱堆点选（合计实时）→ 检查（恰好✓ / 多·差提示，3 次给解）
  找一找：价 + 实付 → 4 选 1 找零
  └─ 结果页（正确率/星星/答对/阶段/打卡 + 解锁提示）
家长面板：标题连点 5 次
```
