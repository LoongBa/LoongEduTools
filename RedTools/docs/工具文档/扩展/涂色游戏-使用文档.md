# 涂色游戏（扩展系列）— 使用文档

> 版本：v1.0（2026-09-19）· 适用：手机竖屏（离线 zip，双击 index.html 即用）· 适合 3-8 岁

## 1. 这是什么

儿童自由涂色小游戏：选一幅**线稿画**（太阳、苹果、小花、房子、小鱼、大树），
用调色板把自己喜欢的颜色涂上去。**没有对错，想怎么涂都行**，涂完自动保存进作品集。

## 2. 首页

- **进度卡**：已涂多少幅作品、连续打卡几天
- 两个入口：
  - **开始涂色**：选线稿 → 填色
  - **作品集**：看自己涂过的作品

## 3. 开始涂色

1. 点「开始涂色」→ 6 幅线稿选一幅（涂过的带 ✨ 标记）
2. 进入填色页：
   - 顶部进度条：已涂 x / y 块
   - 中间大线稿：白色区域 = 还没涂
   - 底部调色板：10 种颜色 + 🧽 海绵（擦掉恢复白色）

## 4. 怎么涂

1. **先点颜色**（调色板上的圆圈，选中的带蓝圈高亮）
2. **再点线稿上的区域** → 该区域填上颜色
3. 想改色：换一个颜色再点同一区域即可覆盖
4. 涂错了：点 🧽 再点区域，恢复白色

> 提示：太阳有 9 块（圆+8 根光芒）、苹果 4 块、房子 7 块…每块都能单独上色。

## 5. 完成与打卡

- **所有区域都涂满** → 顶部显示"完成啦！🎉"
- **完成一幅自动打卡**（每天第一次完成时点亮日历）
- 作品自动保存在本地，随时能在「作品集」里回看

## 6. 作品集

- 显示涂过的所有作品（缩略图 + 名称）
- 点作品可**继续改色**或重新欣赏

## 7. 家长面板（隐藏入口）

- 标题（顶部中间"涂色游戏"文字）**5 秒内连点 5 次**进入
- 可看：累计打卡天数、连续打卡、完成作品数
- 提供「清除所有数据」按钮（重置作品和打卡）

## 8. 常见问题

| 问题 | 说明 |
|---|---|
| 涂色有对错吗？ | 没有！任何颜色都可以，重点是享受色彩 |
| 涂完能改吗？ | 能，作品集里点开继续涂 |
| 作品存哪？ | 手机浏览器本地（redtools.color.v1），离线可用不上传 |
| 清浏览器缓存？ | 作品和打卡会重置 |

## 9. 提示

- 建议完成后和孩子聊聊："为什么选这个颜色？"启发配色思考
- 每天涂 1-2 幅即可；打卡日历鼓励坚持
- 先涂大块（太阳圆、苹果身），再小块（光芒、叶子）更容易完成
