# 动物配对 — 使用文档（扩展 · v1.0）

> 适用版本：v1.0（2026-09-21）。离线小工具：下载 zip 解压后双击 `index.html` 即可使用，无需联网。

## 1. 这是什么

「动物配对」是给低龄宝宝认动物、学常识的小游戏：左边是一只**动物**，右边是它的**家园**，
你帮动物找到它生活的家，把它们配成一对！

适合：3-6 岁幼儿 + 家长亲子互动。

## 2. 开始使用

1. 打开工具进入首页，选一个难度（**简单 / 普通 / 困难**）。
   - **简单**：海边 + 森林，2 对
   - **普通**：海边 + 森林 + 农场 + 海底，4 对
   - **困难**：六个家园随机 5 对
2. 进入游戏：左边是**动物**（🐰🦉🐟…），右边是**家园**（🌊🌲🏡…）。
3. 点一只动物（它会变绿）→ 再点它生活的家园：
   - 送对了 → 两张卡变绿 + 右上角出现 ✓；
   - 送错了 → 红闪提醒，可以重新选（错误次数会计入成绩）。
4. 全部送回家就过关！

## 3. 六大家园认识一下

| 家园 | 住着谁 |
|---|---|
| 🌊 海边 | 海鸥、小鱼、螃蟹、海星 |
| 🌲 森林 | 松鼠、狐狸、兔子、猫头鹰 |
| 🏡 农场 | 奶牛、绵羊、小鸡、鸭子 |
| 🐠 海底 | 海龟、水母、鲸鱼、章鱼 |
| 🌷 花园 | 蝴蝶、蜜蜂、蜗牛 |
| ❄️ 冬日 | 企鹅、小鹿 |

## 4. 成绩与打卡

- 过关后结算页显示：**用时 · 错误次数 · 星级**（0 错 3★ / 错 1-2 次 2★ / 错再多 1★）。
- 每完成一局自动**打卡**，连续打卡天数在首页可见。
- 每个难度的**最佳成绩**自动记录，可在「打卡日历」里回看。

## 5. 常见问题

| 问题 | 说明 |
|---|---|
| 宝宝不认识字怎么办？ | 卡片上是**大大的表情图标**（emoji），不认字也能玩 |
| 想换题目？ | 右下角「重新开始」；或返回难度页重选，每次动物和家园都是随机抽取 |
| 宝宝答错了会难过吗？ | 答错只红闪一下提示，随时可以重试，不惩罚 |
