## 2. 玩法设计（玩法A：成语接龙，v1.1 仅此玩法）

### 2.1 核心规则

- 系统随机出首条成语（课本层 4 字起步，优先可选可接的）→ 高亮**尾字** X。
- 玩家从 **3 个候选成语**中点选以「X」开头的成语（点选式，规避手机中文输入；正确 1 + 干扰 2）。
- 答对 → 绿闪 + **释义教学卡**（成语/拼音/释义/出处/例句，自动展示 2.2s）→ 自动进入下一步（新尾字）。
- 答错 → 红闪 + 错误计数，**可重选**（错卡锁定不重复计错）。
- 已用成语不重复（used 集合），候选过滤已用。

### 2.2 关键交互

| 交互 | 说明 |
|------|------|
| **提词按钮** | 每局限 2 次；点击后正确候选橙色边框高亮 + 反馈「橙色边框就是正确答案」；用提示计入结算扣分 |
| **同音容忍开关** | 默认关；开时正确候选范围扩大为「首字拼音与当前尾字拼音（忽略声调）相同的成语」（如 石 shí → 时 shí 可接）；干扰项首字拼音同样避开 |
| **死路检测** | 当前尾字（同音容忍开时含同音首字）无可接成语 → 自动结算，提示「『X』这个字没人接得上啦」 |
| **限时模式** | 默认关；开时每步倒计时（30/20/10s 三档，默认 30s），超时计 1 次错误 + 正确候选红框高亮，仍可继续 |
| **可续优先出题** | 正确候选在课本层内优先选「还能再接下去」的成语（同层可续 > 同层 > 扩展可续 > 任意），大幅降低死路频率（换题精神，README 需求）；死路结算兜底保留 |

### 2.3 星级常模（结算）

| 接龙长度 L | 条件 | 星级 |
|:---:|------|:---:|
| L ≥ 6 | 错误 + 提示 ≤ 1 | 3★ |
| L ≥ 4 | — | 2★ |
| L ≥ 2 | — | 1★ |
| L < 2 | — | 0★（鼓励语，仍打卡） |

## 3. 出题引擎（数据驱动，运行时索引）

- **题源**：`_shared/成语词库/成语词库.json`（975 课本 + 781 接龙扩展，公共领域）；构建期注入
  `window.CHENGYU_DATA` + 预建首字索引 `window.CHENGYU_CHAIN`（913 个首字键，`datasource="chengyu"` 管线）。
- **运行时索引**：
  - `entryMap`：成语 → 词条（课本优先）；`kebenSet`：课本层标记（正确候选课本优先 + 「扩展」角标）；
  - `byFirstPy`：无调首字拼音 → 词条列表（同音容忍判定：`toneLess()` 去声调，āáǎà→a 等全量映射）。
- **正确候选**：普通模式 = `CHAIN[尾字]`；同音模式 = `byFirstPy[尾字无调拼音]`；优先课本层（≥4 字），
  仅扩展层可接时用扩展层（带「扩展」角标）。
- **干扰项**：全量词库抽 2 条，首字 ≠ 正确首字（同音模式首字拼音也避开）、不与正确/彼此重复（400 次尝试上限，失败按死路结算兜底）。
- **死路判定**：`buildPool` 过滤已用后为空 → 结算。

## 4. 交互设计（移动端优先，点选式）

### 4.1 页面流

```
首页
 ├─ 开始接龙（大按钮）
 ├─ 状态卡：今日打卡 / 连续打卡 N 天 / 最佳接龙 N 条
 ├─ 设置卡：同音容忍开关（默认关）· 限时模式开关（默认关，开时显 30/20/10s 档位）
 └─ 底栏：打卡日历 / 首页
接龙页
 ├─ 顶部：第 N 步·已接 M 条 · ⏱ 总用时 · 退出（confirm 确认，成绩不记录）
 ├─ 当前成语大字（尾字橙色高亮+下划线）+ 引导「请接以『X』开头的成语」
 ├─ 倒计时行（仅限时模式：⏳ 本步剩余 mm:ss，≤5s 变红）
 ├─ 反馈行（答对✅ / 答错❌ / 提示💡 / 超时⏰）
 ├─ 3 个候选成语卡（成语 + 拼音；扩展层带「扩展」角标）
 └─ 提示按钮（💡 剩 N 次）+ 错误计数
释义教学卡（答对后替换候选区 2.2s）
 ├─ 成语大字 + emoji（如有）+ 拼音 + 释义 + 出处 + 例句
结算页
 ├─ 星级大卡 + 接了 N 条 +（死路提示 / 🎉 新纪录）
 ├─ 统计：总用时 / 错误 N 次 / 提示 N 次 + 今日已打卡 · 连续 N 天
 ├─ 0 星鼓励语卡
 └─ 【再来一次】【回首页】【分享打卡】
分享浮层：canvas 卡片图（1080×1920）+ 文案 + 复制/保存/关闭
家长面板（标题连点 5 次）：打卡日历小圆点 + 最近成绩 recent10 + 重置数据
```

### 4.2 判定与反馈

- 点选即判定：正确 → 绿闪（flashOk）+ 其余候选置灰 + 700ms 后释义卡 + 2900ms 后自动下一步；
  错误 → 所点红闪（wrong 锁定，不重复计错）+ 反馈「不对哦，再想想」，可重选。
- 提示：点击后正确候选橙色边框（hint-mark）+ 反馈；2 次后按钮禁用。
- 限时：每步 `setInterval` 倒计时；超时 `onStepTimeout` → 错误 +1 + 正确候选红框（timeout-mark）+ 反馈「超时啦！红框就是正确答案」。
- 退出：`window.confirm` 二次确认；退出局不记录成绩。

## 5. 成绩与打卡（通用能力对齐 `docs/通用需求-打卡分享记录.md`）

localStorage 单 key，**toolId = `chengyu`**：

```js
redtools.chengyu.v1: {
  version: 1,
  checkin:  { dates: ["YYYYMMDD"], streak },   // 打卡 + 连续天数（dates 回溯计算）
  bestLen:  8,                                  // 最佳接龙长度（条）
  recent10: [ { len, sec, stars, date } ],      // 按时间倒序 FIFO ≤10
  prefs:    { homophone: false, timed: false, limitSec: 30 }  // 设置持久化
}
```

- 打卡：结算（含死路结算）即点亮当日；连续天数回溯 `dates`。
- 成绩：结算后 `bestLen`（更长则更新）+ `recent10.unshift` 滚动。
- 分享：canvas 1080×1920 卡片（暖色渐变 + 白内卡 + 连续打卡胶囊 + 大字「N 条」+ 三列统计 + 星级 + 按星级分级鼓励语 + 日期落款）+ 一键复制文案
  （`document.execCommand('copy')` + 隐藏 textarea，失败保底显示全文）+ `<a download>` 保存图片（桌面）。

## 6. 技术方案

### 6.1 合规与基线（对齐 `series/学科/设计文档.md` §1）

- **成语词库工具**（`datasource="chengyu"`）：复制 src/ + 注入共享词库 data.js → 包体 ~0.26 MiB。
- **JS**：ES5 经典脚本（var/function，无 let/const/箭头函数/模板字符串/`?.`/`??`/对象展开/`replaceAll`）；
  事件全部 `addEventListener`；动态内容 `createElement` + `textContent`。
- **CSS**：Chrome 61 基线（无 `gap` 用 `margin`、无 `aspect-ratio`/`clamp()`/`:has`/`@container`/`dvh`/`backdrop-filter`；
  Flex 子项 `min-width:0`；按钮 hit ≥48px；safe-area 用 `--safe-area-inset-*` + `env()` 组合；`--app-height` 视图高度方案）。
- **能力**：`localStorage`、`document.execCommand('copy')`、离屏 `<canvas>` 分享卡、`window.confirm`。
- **禁项自检**：无 `fetch`/XHR/Worker/定位/`window.open`/剪贴板 API、无外部 `http(s)://` 引用、无 `eval`、无内联事件。
- **测试钩子**：`window.CY_DEBUG = { getState(), toneLess() }`（只读，冒烟测试定位正确答案用）。

### 6.2 src 结构

## 8. 风险与待验证

| 风险 | 对策 |
|------|------|
| 词库尾字密度低（平均可接 0.72，609 尾字中约半数死路） | 「可续优先出题」显著降频（同层优先选可续成语）；死路作为**合法结算条件**保留并友好提示 |
| 接龙需认识"以某字开头的成语"，低年级词汇量有限 | 默认关闭同音容忍、限时模式；提词×2 + 释义教学卡降低挫败；扩展层词仅作候选（不要求主动回忆） |
| 同音判定忽略声调可能误放（如 石 shí/时 shí） | 教学友好优先（口语接龙习惯），README 备案；如需严格可加声调匹配档 |
| 干扰项随机可能同音近形 | v1.1 接受随机；后续可按首字/主题差异度优化 |
| Chrome 61 真机未实测 | 如实标记，README 总表备注 |
