## 2. 玩法设计

### 2.1 核心规则（经典 24 点）

- 系统给出 **4 张数字牌**（如 `3 5 7 9`），用 `+ − × ÷` 和括号组成算式，结果 = **24**。
- 每张牌的数字**必须且恰好使用一次**（牌面 6 6 6 6 等重复数字按张数计）。
- **允许中间结果为分数**（如 `6 ÷ (1 − 3/4) = 24`）；最终结果容差 `1e-6` 判定。

### 2.2 模式

| 模式 | 玩法 | 计时 | 打卡 | 成绩记录 |
|------|------|:---:|:---:|:---:|
| **自由练习** | 单题，可随时换题/改难度 | 单题计时 | — | 仅单题用时展示 |
| **每日挑战** | **10 题闯关**，全部解出为完成（单题可反复修改，计时不停） | 总用时 | ✅ 完成即点亮 | `best` + `recent10` + 星级 |

> 每日挑战为打卡与晒分的主要来源（对标数学口算"每日打卡"，规划"计时挑战"落地）。

### 2.3 难度分级

| 难度 | 数字范围 | 出题约束（解的运算特征） | 目标人群 |
|------|:---:|------|------|
| 入门 | 1-9 | 最简解只用 `+ −`（可含简单 `×`，无 `÷`、无嵌套括号） | 低中年级：熟悉四则与括号 |
| 进阶 | 1-10 | 最简解含 `×` 或 `÷`，括号嵌套 ≤1 层 | 中高年级：混合运算 |
| 挑战 | 1-13 | 最简解含 `÷` 且括号嵌套 ≥2 层或存在分数中间态 | 高年级：策略与心算 |

> 牌面展示升序排列（如 `2 3 4 5`），不按出题顺序展示。

### 2.4 星级常模（参考值，待实测校准）

> 同「找不同」做法：初版给参考常模，首版上线后按真实测试数据校准（见 §8 v1.1）。

| 难度 | 3★ | 2★ | 1★ |
|------|------|------|------|
| 入门（10 题） | ≤150 秒 | ≤240 秒 | 其余 |
| 进阶（10 题） | ≤240 秒 | ≤360 秒 | 其余 |
| 挑战（10 题） | ≤360 秒 | ≤540 秒 | 其余 |

## 3. 出题引擎（核心技术，保证 100% 可解）

### 3.1 可解性求解器 `solve24`

- 数据项：`{ val: 数值, expr: 算式文本 }`。
- **递归归并**：任取两项 → 做 6 种二元运算 `a+b, a−b, b−a, a×b, a÷b, b÷a`（除数非 0）→ 合并为新项，直到只剩 1 项；`|val − 24| < 1e-6` 即命中。
- 返回**全部解**（用于难度归类 + 提示文本；去重：同构算式去重可选）。
- 复杂度：4 数全归并组合 ≤ ~1e3，微秒级，**运行时即时出题**，无需预置题库。

```
// 伪代码
solve24(nums):
    items = [{val: n, expr: String(n)} for n in nums]
    return merge(items)

merge(items):
    if len(items) == 1:
        return [items[0]] if |items[0].val - 24| < 1e-6 else []
    results = []
    for i, j in 所有两两组合(items):
        rest = items 去掉 i,j
        for (a, b, op) in [(a+b,'+'), (a−b,'−'), (b−a,'−'), (a×b,'×'), (a÷b,'÷')(b≠0), (b÷a,'÷')(a≠0)]:
            newItem = {val: a_val, expr: "(" + a.expr + op + b.expr + ")"}
            results += merge(rest + [newItem])
    return 去重(results)
```

### 3.2 难度归类（解的特征）

- 从全部解中取**最简解**（运算符数最少，进一步偏好 `÷` 更少）。
- 按最简解特征归类：`÷` 有无 / 括号嵌套层数 / 是否存在分数中间态 → 映射 §2.3 三档。
- **出题流程**：随机 4 数 → `solve24` → 无解或归错类 → 重抽；**上限 200 次**；
  仍不满足则放宽到"可解即出"（保出题成功率，理论上 1-13 四数可解率约 80%，重抽收敛快）。
- 题面随局记录（供提示），不落盘。

### 3.3 防重复

- 同一局内已出题面（四元组多重集合）去重；单局 10 题复用出题引擎按难度流式产出。

## 4. 交互设计（移动端优先，无软键盘）

### 4.1 表达式构造器（核心交互，规避手机键盘对 `× ÷ ( )` 输入困难）

- **牌面区**：4 张 CSS 卡片（白底大数字 + 花色角标装饰，**无图片资源**）。
- **点牌**：点击某张牌 → 其数字追加进表达式区，该牌剩余张数 −1（置灰）；相同数字可多点（双 3 可点两次）。
- **运算符按钮**：`+  −  ×  ÷` 大按钮（hit area ≥48×48px）。
- **括号按钮**：`(  )`。
- **算式区**：单行横向滚动显示构造中的表达式，右侧**实时计算结果预览**（`= 6`）；未闭合括号/非法尾运算符灰显结果。
- **操作**：`撤销一笔`（删最后一个 token）/ `清空` / `提交`。
- 提交：结果 = 24 → 正确；否则错误提示（算式保留可改）。

### 4.2 判定实现（**无 eval**，CSP 合规）

- 自写**表达式解析器**（solver 同源复用）：`tokenize`（数字/运算符/括号）→ 双栈中缀求值（优先级 + 括号）。
- **合法性校验**：数字 token 多重集合 ≡ 牌面多重集合（构造器天然满足，仍做防御断言）。
- 中间态允许分数；最终结果容差 `1e-6`。
- 禁用 `eval` / `new Function`（容器 CSP 禁），全部经典 ES2017。

### 4.3 提示系统

- 「提示」按钮：展示 `solve24` 输出的一组解文本（如 `(9−5)×(7−1)=24`）。
- 用提示的局：**可打卡**（完成即打卡不变），但 **best 不更新**；`recent10` 记录 `usedHint: true`。

## 5. 反馈与评分

### 5.1 即时反馈

- 提交正确：绿色打勾 + 温和成功动画 → 自动进入下一题（挑战模式进度 `x/10` 前进）。
- 提交错误：红色提示（toast），算式保留可改，不计错、不结束。

### 5.2 结算（每日挑战完成 10 题）

结算页展示：对题数 `/10`（全部正确即为 10，含经提示数）、总用时、星级 1-3★、
本难度历史最佳、连续打卡天数；操作：【再来一次】【分享打卡（v1.1）】。

### 5.3 成绩与打卡（通用能力对齐 `docs/通用需求-打卡分享记录.md`）

localStorage key 统一带工具前缀，**toolId = `math24`**：

```js
math24_checkin: { version: 1, dates: ["YYYYMMDD"], streak, longestStreak }
math24_records: {
  best:     { diff, timeMs, date },                  // 按难度分别记录最快总用时
  recent10: [ { diff, timeMs, correct, total, usedHint, date } ]  // 倒序 FIFO ≤10
}
math24_prefs: { diff, mode }                          // 记忆上次难度/模式
```

- 打卡：完成一局每日挑战即点亮当日；连续天数由 `dates` 回溯计算（跨天/缺天正确）。
- 星级/打卡/成绩与数学口算、舒尔特方格同 schema，未来可沉淀 `_shared/`。

## 7. 技术方案

### 7.1 合规与基线（对齐 `series/学科/设计文档.md` §1）

- **静态工具**（`datasource="static"`）：纯 DOM/CSS，无图片/音频 → 包体 <0.1 MiB ≪ 2 MiB 建议线。
- **JS**：ES2017 经典脚本；无 `eval`/`new Function`/`module`/`import`；事件全部 `addEventListener`。
- **CSS**：Chrome 61 基线（禁 `gap`/`aspect-ratio`/`clamp()`/`:has` 等；Flex 子项 `min-width:0`；按钮 hit ≥48px）。
- **能力**：`localStorage`（禁用时降级为仅本次会话）、`document.execCommand('copy')` + 隐藏 textarea（分享 v1.1，Chrome 61 无 `navigator.clipboard`）、离屏 `<canvas>` 生成分享卡（v1.1）。
- **禁项自检**：无 `fetch`/XHR/Worker/定位/`window.open`、无外部 `http(s)://` 引用。

### 7.2 src 结构（规划）

```
series/学科/24点/src/
├── index.html
└── assets/
    ├── main.js        # 应用逻辑：页面流/状态机/计时/成绩/打卡/星级
    ├── solver.js      # 出题引擎：solve24 求解器 + 难度归类 + 题目去重
    ├── parser.js      # 表达式解析求值（tokenize + 双栈，无 eval）＋合法性校验
    ├── style.css      # Chrome 61 基线样式
    └── icon_base.png  # 公共图标母版（构建时叠加「24点」角标）
```

> `solver.js` / `parser.js` 为纯函数无 DOM，可独立单测；后续同类运算工具（数独/口算等）可沉淀共享模块。

### 7.3 构建与登记

- `tools.py` 登记：`ToolConfig(series="学科", tool="24点", version="1.0", datasource="static", app_name="24点", default_unit=0)`。
- `python build_all.py --tool 24点`（静态复制）→ 审计 → 合规自查 → 冒烟测试（Playwright）：
  出题可解性 / 构造器输入 / 判定计算 / 挑战 10 题结算 / 打卡与成绩持久化。

| 项 | 本工具落地 |
