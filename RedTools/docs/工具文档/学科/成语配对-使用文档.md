# 成语配对 — 使用文档（学科 · v1.0）

> 适用版本：v1.0（2026-09-21）。离线小工具：下载 zip 解压后双击 `index.html` 即可使用，无需联网。

## 1. 这是什么

「成语配对」是练**成语词义**的小游戏：左边是一句话的**释义**，右边是**成语**，
你把「意思对得上」的一条释义和一个成语配成一对（像连线配对）。

适合：1-6 年级小学生（按年级段出题，低年级也有适合的题目）+ 家长 + 老师。

## 2. 开始使用

1. 打开工具进入首页，选一个难度（**简单 / 普通 / 困难**）。
   - **简单**＝1-2 年级成语，3 对
   - **普通**＝3-4 年级成语，4 对
   - **困难**＝5-6 年级成语，5 对
2. 进入游戏：左边是**释义**（一句话），右边是**成语**（带拼音）。
3. 点一条释义（它会变成橙色高亮）→ 再点对应的成语：
   - 配对了 → 两张卡变绿 + 右上角出现 ✓；
   - 配错了 → 红闪提醒，可以重新选（错误次数会计入成绩）。
4. 全部配完就过关！

## 3. 成绩与打卡

- 过关后结算页显示：**用时 · 错误次数 · 星级**（0 错 3★ / 错 1-2 次 2★ / 错再多 1★）。
- 每完成一局自动**打卡**，连续打卡天数在首页可见。
- 每个难度的**最佳成绩**自动记录，最近表现可在「打卡日历」里回看。

## 4. 常见问题

| 问题 | 说明 |
|---|---|
| 释义太长看不完？ | 释义卡片会自动换行完整显示，一屏放不下时页面可上下滚动 |
| 成语不认识怎么办？ | 成语卡上自带**拼音**，先读拼音再对照释义 |
| 想换题目？ | 右下角有「重新开始」；或返回难度页重新选，每次题目都是随机抽取 |

> 词库来自小学课本 975 条核心成语，按年级段出题，与「看图猜成语」「成语接龙」共享同一词库。
