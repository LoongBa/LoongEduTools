## 🔧 技术方案

### 重绘流程
```
原图 → AI 卡通重绘 → 人工质检 → 放入 _重绘图片素材/ → 构建打包
```

### 关键配置
- **提示词**：`cartoon_redraw_v2.txt`（卡通风格，保留装饰，文字保留）
- **模型**：sensenova-u1.5-lite
- **输出目录**：`F:\_教材素材\...\_<年级><册次>\_重绘图片素材\`
- **book.json**：`F:\LoongBa_Git\LoongMediaTools\Downloader\Diandu\data\`（11 个文件）

### 每册工作量估算
- 平均 75 页/册
- 每页 AI 重绘 ~25 秒
- 考虑速率限制（3 秒间隔）
- **预计每册耗时：35-45 分钟**
- **全量 11 册预计：6-8 小时**
