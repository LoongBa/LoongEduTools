# 重绘图片质检与热区校正工具集

> 版本：v1.1 | 更新：2026-09-19
> 用途：AI 重绘教材图片后的人工质检 + 热区坐标校正

## 1. 工具清单

| 工具 | 位置 | 用途 |
|------|------|------|
| **质检报告** | `重绘工具/qa_reports/*.html` | 人工对比原图/重绘图，标记问题 |
| **热区校正** | `重绘工具/hotzone_editor/index.html` | 拖拽调整点读热区坐标 |
| **AI 重绘** | `重绘工具/redraw.py` | 调用 SenseNova API 生成卡通重绘图 |
| **批量构建** | `build_all.py` | 生成点读 zip 包 |

## 2. 质检工具

### 2.1 快速开始

```
双击 qa_reports/四年级_上册.html → 浏览器打开
```

### 2.2 功能

| 功能 | 操作 |
|------|------|
| 左右对比 | 缩略图并排，点击放大（并排 + ESC 关闭） |
| ✅ 通过 | 点击绿色大按钮 |
| ❌ 需重绘 | 勾选问题类型（6 种） |
| 区域标记 | 双击原图 → 拖拽画框 → 填写说明 |
| 导出结论 | 底部「📋 导出」→ 复制 JSON → 发给 AI |

### 2.3 问题类型

- 整图过于相似（未重绘）
- 部分相似（局部未重绘）
- 对话框/文字框少字缺字
- 文字模糊不清
- 伪影/变形/畸变
- 其他问题

### 2.4 数据流

```
用户质检 → localStorage（浏览器本地）
    ↓ 导出 JSON
AI 处理 → qa_reviews.json（持久化）
    ↓ 运行 gen_qa_reports.py
重新生成 HTML → 用户刷新页面
```

### 2.5 命令

```bash
# 重新生成所有质检报告
python gen_qa_reports.py

# 输出：qa_reports/ 下 11 个 HTML 文件
```

## 3. 热区校正工具

### 3.1 快速开始

```
双击 hotzone_editor/index.html → 浏览器打开
```

### 3.2 加载数据

1. 选 book.json：`Downloader/Diandu/data/<书号>_英语（PEP）_*.json`
2. 选重绘图目录：`F:\_教材素材\...\<年级>\<册>\_重绘图片素材\`
3. 选原图目录：`_图片素材\`（可选）
4. 选音频目录：`_音频素材\单句音频\`（可选）

### 3.3 校正操作

| 操作 | 说明 |
|------|------|
| 点击右侧句子 | 选中对应热区 + 播放音频 |
| 拖动热区 | 移动位置 |
| 拖动白色手柄 | 缩放大小 |
| 数字微调 | 右侧面板直接编辑坐标 |
| 还原 | 恢复 book.json 原值 |
| 删除 | 移除热区 |

### 3.4 快捷键

- `←` / `→`：上一页 / 下一页

### 3.5 保存

- 「💾 保存」→ localStorage（换单元/刷新不丢）
- 「导出校正」→ 下载 `热区校正_<单元名>.json`

### 3.6 导出格式

```json
{
  "tool": "hotzone-corrector",
  "book": "1212001401255_英语（PEP）_四年级_上册.json",
  "unit_index": 0,
  "unit_title": "Unit 1 Helping at home",
  "pages": {
    "2": { "1": { "left": 0.0773, "top": 0.0479, "right": 0.8536, "bottom": 0.2396 } }
  }
}
```

### 3.7 测试

```bash
python hotzone_editor/test_hotzone_editor.py
# 12 项断言，覆盖加载/渲染/拖拽/缩放/保存/导出
```

## 6. 常见问题

### Q: 质检报告打不开？
A: 用 Chrome/Edge 直接双击 HTML 文件，file:// 协议即可。

### Q: 审核记录丢失？
A: 记录保存在浏览器 localStorage，清空浏览器数据会丢失。建议及时导出 JSON。

### Q: 热区校正后如何应用？
A: 导出 JSON 后，需手动修改 build_framework.py 接收校正文件（尚未自动集成）。

### Q: 重绘图质量不佳？
A: 在质检报告中标记问题，导出 JSON 发给 AI，AI 会重新生成。
