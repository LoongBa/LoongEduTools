> 核心价值：矩阵中「单词闪卡记忆」是被动认词（翻转卡片），本工具是**主动拼写**（看中文打字出英文）——拼写是词汇学习的最强提取练习（retrieval practice），小学英语词汇"四会"要求（会听、会说、会读、会写）的"写"正是难点。

## 2. 玩法设计

### 2.1 核心规则

- 用户**选册 → 选单元**（如 四年级 上册 → Unit 1）。
- 系统从该单元随机抽 **10 词**（单元词数 <10 则全量），顺序打乱。
- 每题显示**中文释义**（大字），用户拼写英文单词：
  - 屏幕虚拟键盘点按（手机）；实体键盘输入（教室电脑）自动兼容。
  - 字母槽逐格反馈（空格位加宽虚线显示）；输入至目标词长**自动提交**。
- 判定：**大小写不敏感**（统一 `toLowerCase` 比较）；空格/撇号/连字符按词条原样输入
  （`police officer`、`I'm` 需打空格/撇号、`T-shirt` 需打连字符）。
- 反馈：答对绿色 + "✓ 答对了" 600ms 进下一题；答错红色 + 显示**正确答案完整拼写** 1400ms 进下一题。
- 完成一轮（10 题）→ 结算页（对题/总题、用时、正确率、连续打卡天数）。

### 2.2 模式

| 项 | 说明 |
|---|---|
| 练习单元 | 11 册 × 每册 5~6 单元，按册→单元两级选择 |
| 每轮题数 | 10（单元词数不足则全量） |
| 计时 | 本轮总用时（performance.now() 差值，结算展示） |
| 打卡 | 完成一轮即点亮今日（`dazi_checkin`，连续天数回溯） |
| 成绩 | `dazi_records.recent10`（倒序 FIFO ≤10：册/单元/对题/总题/日期） |
| 错题本 | `dazi_wrongbook`（内部记录：答错入本，连续答对 3 次移除，上限 200；成绩页展示收录词数） |

### 2.3 词库数据源（核心创新：教材真实词汇，数据驱动）

- **来源**：`F:\_教材素材\人教版（PEP）（主编：吴欣）\<年级>\<册次>\_音频素材\`
- **9 册**用独立词汇表 `*Words_in_each_unit_en_cn.txt`（如 四上 `09_Appendix_2_Words_in_each_unit_en_cn.txt`）。
- **三下/五上/五下**无独立"单元词汇表"文件（五下独立 Words 文件实为字母序 Vocabulary），
  单元词汇表在整册 `英语（PEP）..._en_cn.txt` 的 **`Words in each unit` 区块**（至 `Useful expressions`/`Vocabulary`/`Appendix` 结束）。
- **统一格式**：`英文单词行 + 中文释义行 + 空行` 两两配对，`Unit N`/`第N单元` 标题行分隔。
- **解析清理**（`build_framework.py` 新增 `datasource='vocab'`）：
  - 剥离教材标记：星号 `*name → name`（听力/重点标记）、HTML 标签 `<i>pl.</i>` 剔除、
    尾部括号复数注释 `tooth (pl. teeth) → tooth`。
  - 中文释义剥离前导括号注释：`（复数children） 儿童；小孩 → 儿童；小孩`。
- **构建期全量解析入 `data.js`**（`window.APP_DATA.books`，63 KB / 11 册 / 976 词），
  前端按册→单元读取，运行时零计算、离线可用。包体 0.05 MiB ≪ 2 MiB 建议线。

## 3. 交互设计（移动端优先）

### 3.1 页面流

```
首页（册选择）
 ├─ 标题 + 版本小字（data.js meta 注入）
 ├─ 11 册列表（年级+册次 + 全册词数 · 单元数）
 └─ 底部导航：练习 / 成绩
单元列表
 ├─ ‹ 返回 + 当前册信息
 └─ 单元列表（Unit N + 词数）
练习页
 ├─ 顶部：‹ 返回 + 第 x/y 题 + 对错计数 + 计时
 ├─ 题目卡：中文释义（大字）+ 字符数提示
 ├─ 字母槽（逐格；空格位加宽虚线）
 ├─ 反馈行（答对绿 / 答错红+正确答案）
 └─ 虚拟键盘（3 行 QWERTY + ⌫ + 底行 空格 ' - ✓）
结算页
 ├─ 册·单元标题 + 对题/总题大字
 ├─ 用时 / 正确率 / 连续打卡
 └─ 【再练一轮】【换个单元】
成绩页
 ├─ 打卡卡片：连续 N 天 · 最长 M 天 + 当月月历圆点 + 错题本词数
 └─ 最近成绩 recent10 列表（册·单元 / 日期 / 对题数）
```

### 3.2 虚拟键盘（`keyboard.js`，独立组件 `window.DaziKeyboard`）

- 布局：Row1 `QWERTYUIOP`、Row2 `ASDFGHJKL ⌫`、Row3 `ZXCVBNM`、
  底行 `[空格(宽键)] ['] [-] [✓ 提交]`。
- 字母键**大写显示**、回调传入小写（判定/存储统一小写）。
- 空格键输入空格（`police officer`）、`'` 键输入撇号（`I'm`）、`-` 键输入连字符（`T-shirt`）。
- 组件无业务状态，全部通过 `handlers` 回调上抛；返回 `{ setDisabled }` 供答后禁用。
- 答后禁用全部键，防连点。

### 3.3 实体键盘（教室电脑投影场景）

- `document keydown` 监听：字母键/空格/撇号/连字符输入、`Enter` 提交、`Backspace` 退格；
  修饰键（Ctrl/Meta/Alt）与 IME 组合输入（`isComposing`）忽略。
- 仅练习视图响应（`state.view === 'quiz'`）。

### 3.4 判定与反馈

- 判定：`state.answer.toLowerCase() === q.word.toLowerCase()`。
- 长度达标自动提交；`✓` 键也可手动提交（长度不足按错误处理）。
- 答对：答案区绿色（`answer-ok`）+ 逐格绿色 + "✓ 答对了" → 600ms 下一题。
- 答错：答案区红色（`answer-bad`）+ 字母槽展示**正确拼写**（逐格红/绿对比）
  + "正确答案：xxx" → 1400ms 下一题；该词入错题本。
- 字母槽逐字符反馈：用户输入与目标逐位比对（空格位显示 `·`），答错时展示目标字母。

## 4. 成绩与打卡（通用能力对齐 `docs/通用需求-打卡分享记录.md`）

localStorage key 统一带工具前缀，**toolId = `dazi`**：

```js
dazi_checkin:   { version: 1, dates: ["YYYYMMDD"], streak, longestStreak }
dazi_records:   { version: 1, recent10: [ { grade, term, unit, correct, total, date } ] }  // 倒序 FIFO ≤10
dazi_wrongbook: { version: 1, words: [ { word, cn, grade, term, unit, wrongCount, correctStreak, lastTime } ] }  // 上限 200
```

- 打卡：完成一轮即点亮当日；连续天数由 `dates` 回溯计算（模式对齐 24点 `calcStreak`）。
- localStorage try/catch + 内存降级（容器禁用时仅会话内有效）。
- 与数学口算/24点同 schema 风格，未来可沉淀 `_shared/`。

## 5. 技术方案

### 5.1 合规与基线（对齐 `series/学科/设计文档.md` §1）

- **数据驱动静态工具**（`datasource="vocab"`）：无图片/音频，纯文本词库入 data.js → 包体 0.05 MiB。
- **JS**：ES2017 经典脚本；无 `eval`/`new Function`/`module`/`import`；事件全部 `addEventListener`；
  无 `?.` `??` 对象展开 `replaceAll`。
- **CSS**：Chrome 61 基线（禁 `gap`/`aspect-ratio`/`clamp()`/`:has`/`dvh`；Flex 子项 `min-width:0`；按钮 hit ≥48px）。
  - **踩坑记录**：`.app-main` 为 flex 子项必须 `min-height: 0`，否则内容超高时 `overflow-y:auto` 不生效
    （11 册列表 1277px 超一屏无法滚动；24点 首页 737px < 844px 未暴露）。修复后滚动正常。
- **能力**：`localStorage`（禁用降级内存）、`performance.now()` 计时（interval 差值刷新）。
- **禁项自检**：无 `fetch`/XHR/Worker/定位/剪贴板/`window.open`、无外部 `http(s)://` 引用。

### 5.2 src 结构

```
series/学科/打字背单词/src/
├── index.html            # data.js → keyboard.js → main.js
└── assets/
    ├── main.js           # 应用逻辑：视图流/出题/判定/计时/成绩/打卡/错题本（733 行）
    ├── keyboard.js       # 屏幕虚拟键盘组件 window.DaziKeyboard（101 行，独立可复用）
    ├── style.css         # Chrome 61 基线样式（627 行）
    └── icon_base.png     # 公共图标母版（构建时叠加「打字背单词」角标）
```

### 5.3 构建管线扩展（`build_framework.py`）

- `ToolConfig.datasource='vocab'` + 新增字段 `vocab_dir`（PEP 素材根目录）。
- 新增 `VOCAB_BOOKS`（11 册清单，含整册提取标记）、`_parse_vocab_lines`（配对+清理）、
  `_load_vocab_book`（单册解析）、`write_vocab_data_js`（全量 data.js 生成）。
- 构建命令：`python build_all.py --tool 打字背单词` → 审计 → 合规自查 → 冒烟测试。
