## 1. 产品定位

| 项 | 说明 |
|---|---|
| 工具名 | 乘法口诀练习 |
| 系列 | 学科 |
| 优先级 | P1（第二波 3-6 月） |
| 对标 | 小猿口算乘法口诀模块、叫叫口算、纸质口诀表/挂图 |
| 形态 | 小红书小工具（离线 zip + H5，Chrome 61 基线，无网络） |
| 目标用户 | K1-3–K4-6（L2–L3），主攻 2-3 年级，延伸 1/4 年级 |
| 核心价值 | **离线可用的九九表口诀记忆专项：口诀表学习（按行解锁）→ 抽查巩固 → 易错专训闭环** |

**差异化（与数学口算的边界）**：
- 数学口算：1-6 年级 25+ 知识点通用出题器（乘法只是其中一个知识点 g2_mult）
- 乘法口诀练习：**单一专项**，不做第二个通用出题器；以「口诀表可视化 + 按行渐进解锁」为主线，
  抽查为巩固手段，错题按口诀聚合做易错专训

## 2. 功能需求

### 2.1 核心功能（P0）

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| F1 | **口诀表学习页** | 小九九三角表 45 句（第 i 行 = i×i ~ i×9）；口诀卡网格展示汉字口诀名（如「三六十八」）；点击卡片展开算式（3×6 = 18）；**按行渐进解锁**：第 1 行默认解锁，行末小测（该行随机 5 题）≥80% 通过解锁下一行 | ✅ 已实现 |
| F2 | **随机抽查** | 从**已解锁口诀集合**随机出题 a×b=?；`<button>` 数字键盘作答（1-9/0/⌫/✓）；即时反馈：答对绿✓ 600ms 进下一题 / 答错红✗+正确答案 1400ms 进下一题 | ✅ 已实现 |
| F3 | **模式选择** | 首页三入口：①学习口诀表 ②随机抽查（模式弹窗：普通 10 题 / ⏱30/60/120s 挑战〔20 题〕）③专项练习（选已解锁行，该行 10 题） | ✅ 已实现 |
| F4 | **打卡 + 星星 + 成绩** | 完成一次练习即打卡（日历火苗 + 连续天数）；星星：全对 3★ / ≥80% 2★ / ≥60% 1★（专项/小测记录于行）；成绩滚动 30 条 | ✅ 已实现 |

### 2.2 增强功能（P1）

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| F5 | **易错专训** | 错题本持久化 {row,a,b,answer,wrongCount,correctStreak,lastTime}，上限 500 FIFO，连续答对 3 次同口诀自动移除；易错聚合：wrongCount≥2 的口诀按降序展示，一键生成易错专练（≤10 题，错题优先） | ✅ 已实现 |

## 3. 出题引擎设计

| 规则 | 实现 | 说明 |
|---|---|---|
| 口诀池 | 三角表 45 句（`ALL_ROWS`：第 i 行 = i×i ~ i×9） | 交换律去重即三角表形态 |
| 出题范围 | 抽查 = 已解锁行并集；专项/小测 = 指定行；易错 = 错 ≥2 次口诀池 | 渐进解锁控制出题范围 |
| 随机 | 每题随机，同次练习内 `a*10+b` 去重，随机重试 ≤8 次 | 池过小（<题量）时允许重复兜底 |
| 反推校验 | `answer = a*b`（乘法无边界陷阱，天然正确） | 对比数学口算的复杂生成器大幅简化 |
| 防重复 | seen 表同次题面去重 | 与数学口算 v1.1 同款 |

## 4. 技术方案

### 4.1 复用 vs 新增（对照同系列已有资产）

| 资产 | 复用来源 | 处理 |
|---|---|---|
| 数字键盘 / 即时反馈 / 计时后台暂停 | 数学口算 main.js | 同款模式（`<button>` 键盘、performance.now + visibilitychange） |
| 打卡 / 错题本 / 最佳 localStorage | 数学口算 §5.3 结构 | 同构（key `redtools.mul.v1`，version 字段 + 迁移兜底） |
| 构建管线 | build_framework `copy_static` | `datasource="static"`，零素材零音频，零框架改动 |
| 口诀表卡片 / 按行解锁 | 新增 | 本工具独有（数学口算无） |
| 家长面板 | 数学口算 | 同款隐藏入口（标题 5 秒连点 5 次） |

### 4.3 持久化结构（redtools.mul.v1）

```js
{
  version: 1,
  unlockedRows: [1],                    // 已解锁口诀行（渐进解锁）
  profile: {
    totalAnswer, totalCorrect,          // 累计答题/答对
    rowStars: { row: n },               // 各行星级（专项/小测）
    best: { normal, timed, special }    // 各模式最佳 {rate,count,elapsedMs}
  },
  checkin: { dates: ["YYYYMMDD"], streak },   // 打卡滚动 365 天
  wrongBook: [ {row,a,b,answer,wrongCount,correctStreak,lastTime} ],  // 上限 500 FIFO
  history: [ {date,mode,row,rate,count,correct,elapsedMs} ]           // 滚动 30 条
}
```

### 4.4 Chrome 61 / 交互合规

- JS：经典脚本（无 module/import/export）、不超 ES2017（无 ?. ?? 对象展开）、事件全 addEventListener、无 eval
- CSS：无 flex gap / aspect-ratio / clamp() / 逻辑属性 / :has / @container / dvh；Flex 子项 min-width:0；安全区 env(safe-area-inset-*)
- 按钮 hit area：键盘 ≥56px、入口/按钮 ≥48px；反馈动画温和（无强闪烁，光敏风险）
- 计时：performance.now() + visibilitychange 后台暂停；剩余 ≤10s 计时变红
- CSP 自检：无 fetch/XHR/Worker/剪贴板/window.open、无外部 http 引用、无内联脚本/样式

## 5. 交互流程

```
首页（进度卡：已解锁 x/9 行 · 连续打卡 N 天）
  ├─ 学习口诀表 ──► 9 行口诀卡网格（行末小测 → 5 题 ≥80% 解锁下一行）
  ├─ 随机抽查 ────► 模式弹窗（普通 10 题 / ⏱30/60/120s 挑战 20 题）
  ├─ 专项练习 ────► 选已解锁行 → 该行 10 题
  └─ 底部导航：打卡日历 / 易错本 / 首页
练习页：进度 + 题目卡 + 输入回显 + 数字键盘 + 即时反馈（对✓600ms / 错✗+答案 1400ms）
  └─ 完成 → 结果页（正确率/星星/答对/用时/打卡/新纪录）→ 再来一组 / 返回
家长面板：标题连点 5 次（总览统计 + 各模式最佳 + 清除数据）
```
