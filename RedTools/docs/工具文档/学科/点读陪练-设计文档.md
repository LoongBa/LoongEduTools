## 2. 双模式架构（骨架 v0.1）

### 2.1 目录结构（新结构试点）

```
series/学科/点读陪练/src/
├── index.html              # 模式无关外壳（脚本注入顺序由构建决定）
├── content.js              # 内容源 window.CONTENT_DATA（JSON 数组，构建按 mode 切分）
├── core/                   # 核心逻辑（双模式共用）
│   ├── main.js             # 主流程：单元选择→答题→即时反馈→结算打卡（消费 LX_SHARED + APP_DATA）
│   └── generators.js       # 出题器（4 选 1：词汇卡英文→中文）
└── adapters/               # 适配层（构建按 --mode 注入）
    ├── offline/            #   auth/storage/content.js（离线默认实现确认）
    └── online/             #   auth/storage/content.js（在线桩确认）
```

### 2.2 运行时注入顺序（oracle 审核 v0.2 定稿）

```
data.js（APP_DATA.meta.mode）→ _shared/lx-shared.js（LX_SHARED 命名空间）
→ adapters/*.js（可 register 覆盖）→ core/*.js（消费）
```

### 2.3 公共模块（_shared/js/，5 模块）

| 模块 | 职责 | 关键契约 |
|---|---|---|
| `lx-shared-core.js` | 命名空间 + register 注册器 + version/mode | `LX_SHARED.register(name, impl)` 适配层覆盖 |
| `storage.js` | 存储适配（**schema-agnostic 透传**） | `get/set/remove/sync`；离线=localStorage，在线=云端桩；数据最小化只约束 sync 上行 |
| `progress.js` | 打卡/连胜/历史（40+ 工具同构抽取） | `checkin/streak/best/history`；`calcStreak(dates)` 全库同构已实测 |
| `auth.js` | 认证契约 + 桩 | `status/login/activate/logout`；离线恒授权，在线读本地桩；接口契约预留（§4.6） |
| `guard.js` | 防沉迷/自控力 | `check/addMinutes/addRound/getSession` |
| `ui-kit.js` | 通用组件（无排行榜 UI） | `btn/badge/overlay/toast/progressBar/starsText` |

### 2.4 构建注入（build_framework.py V0.2）

- `build_all.py --tool 点读陪练 --mode offline` → `dist/学科/点读陪练/offline/` → zip 到 publish；
- `--mode online` → `dist/学科/点读陪练/online/`（仅部署目录，**不入 publish/小红书**——合规红线）；
- `content.js` 按 `free_units=1` 切分（offline=Unit1，online=全量 2 单元）；
- `_shared/js/src/*.js` 合并为 `_shared/lx-shared.js`（core→storage→progress→auth→guard→ui-kit 顺序）。

## 3. 玩法设计（骨架 v0.1）

- **单元选择**：content 列表（offline 1 个 / online 2 个）→ 点选进入；
- **答题**：词汇/句型卡 4 选 1（英文→中文释义），点对 ✓ toast + 自动下一题，点错计数；
- **结算**：正确率 → 星级（100% 3★ / ≥80% 2★ / 其余 1★）+ 打卡（LX_SHARED.progress）+ history；
- **认证门控**（online）：进入单元前 `auth.status()` 校验，未授权弹「完整版需要授权」→ 口令桩解锁；
- **页脚**：offline 显示「🔗 完整版 · 在线练习」引导；online 按授权状态显示。

## 4. 数据与合规

- `STORE_KEY = redtools.点读陪练.v1`（LX_SHARED.storage 前缀注入）；
- 数据最小化：localStorage 完整存工具自有字段；**在线 sync 仅上行 { completedUnits, checkin }**（storage.js pickSyncable）；
- 孩子端无账号、无社交、无排行榜（指导原则 §4.2）；授权走口令（设计要求书 §3.4 前期方案）；
- 在线包不入小红书（设计要求书 §3.2 + 骨架 §4.4 红线）。
