# 新英语四上点读1单元 使用文档

> 人教版（PEP）英语四年级上册 Unit 1 的逐句点读小工具，离线可用，双击即开。
> 面向家长和学生，无需任何操作基础。当前版本 v1.1。

---

## 1. 这个工具能做什么

把课本「Unit 1 Helping at home」变成一本会说话的书：

- 点哪句读哪句：手指点一下课文里的句子，立刻读出声音，中文和英文字幕同时显示。
- 整页连读：按一下播放，一页的句子自动一句接一句读下去。
- 可以调速度、让句子重复两遍，还能设置整页读完后自动翻到下一页继续。

所有内容都存在本地，打开后不需要联网。

## 2. 如何打开

在 `publish/学科/` 目录下找到 `新英语四上点读1单元.zip`，任选一种方式：

1. **解压后打开**：把 zip 解压到一个文件夹，双击里面的 `index.html`。
2. **免解压测试版**：直接打开 `新英语四上点读1单元_解压测试版/` 文件夹，双击 `index.html`。

第一次打开时，浏览器可能会询问是否允许播放声音，请选择「允许」。之后就可以正常使用了。

> 建议用电脑自带的 Edge、Chrome 等现代浏览器打开；手机上也可以先把整个文件夹传到手机再用浏览器打开。

## 3. 界面说明

从上到下共四块：

| 区域 | 内容 |
|------|------|
| 顶栏 | 工具图标 + 工具名 + 版本号小字；如果后续加了多个单元，这里会有单元切换标签 |
| 模式切换 | 「点读」和「顺序」两个按钮，决定这一页怎么读 |
| 中间课本页 | 课本原图；**蓝色虚线框**圈住的区域就是可以点的句子 |
| 底部 | 字幕（英文在上、中文在下）+ 顺序模式控制条 + 翻页按钮 |

打开后字幕默认显示「点击课文区域试听」，这时随手点课文就能听到声音。

## 4. 点读模式（一句话一句话点着读）

1. 确认顶部模式是「**点读**」（按钮高亮显示）。
2. 手指点击课本页上任意一个**蓝色虚线框**内的区域。
3. 会听到该句朗读，虚线框变成蓝底实线表示正在播放，底部同时显示英文和中文。
4. 想听别的句子，直接点另一个虚线框区域即可，前一句会自动停止。

> 只能点虚线框内部，点框外空白处没有反应。

## 5. 顺序模式（整页自动连读）

先点顶部的「**顺序**」按钮切换到顺序模式，底部会出现两行控制条。

### 5.1 开始与基本操作（第一行）

| 按钮 | 作用 |
|------|------|
| `‹ 上一条` | 回到上一句，并从这句开始播放 |
| `▶ 播放` | 从第一句开始整页连读；播放中变成 `⏸ 暂停` |
| `⏸ 暂停` | 暂停当前句 |
| `▶ 继续` | 续播，从**当前句开头**重新播放 |
| `下一条 ›` | 跳到下一句，并从这句开始播放 |
| 进度 | 未播放时显示「共 x 句」；播放中显示「第 x / y 句」 |

在第一句时「上一条」、在最后一句时「下一条」会置灰，这是正常的。

### 5.2 播放设置（第二行）

| 按钮 | 作用 |
|------|------|
| `重复 ×1 / ×2` | 打开后每句话读两遍再读下一句，加深记忆 |
| `速度` | 四档循环切换：`1× 正常` → `0.75× 慢` → `1.25× 快` → `1.5× 较快` → `1× 正常` |
| `自动连播 开/关` | 打开后整页读完自动翻到下一页继续读；关闭则读完停在当前页 |
| `重听本页` | 不管读到哪句，立刻回到本页第一句重新开始 |

> 提示：调快或调慢速度时，声音的调子会跟着变，这是正常的发声原理，不是故障。
> 想让孩子听清楚发音，推荐用 `0.75× 慢` 或 `1× 正常`。

### 5.3 播放规则

- 翻页、切换点读模式、点课本上的句子，都会让顺序播放停止。
- 顺序播放中直接点课本里的虚线框，会自动切回点读模式并播放你点的这句。

## 6. 翻页

两种方式：

- **底部按钮**：`封面`（回第 1 页）/ `‹`（上一页）/ `第 x / y 页`（当前位置）/ `›`（下一页）/ `末页`（最后页）。
- **左右滑动**：在课本页上向左滑进下一页，向右滑回上一页（滑动速度要快一点、滑得长一些才生效）。

## 7. 设置会自动保存

你选好的内容下次打开依然有效：

- 模式（点读/顺序）
- 重复（×1/×2）
- 速度档位
- 自动连播开关

这些会自动记下来，不用每次重新设置。想恢复初始状态，把开关关掉、速度调回 `1× 正常` 即可；
或者清除浏览器里这个网站的数据。

## 8. 常见问题

**Q1：点了课文没声音，怎么办？**
先确认点的是不是蓝色虚线框内部；再检查设备是否静音、音量是否调到最低；
还要确认第一次打开时是否允许了「播放声音」的权限（可以看看浏览器地址栏的喇叭/权限图标）。
如果都不行，换个现代浏览器（Edge/Chrome）再试。

**Q2：为什么有些页面上虚线框很少，甚至没有？**
课本页面内容本来就有多有少：封面页只有标题、个别页可能没有可点内容，这都正常。
虚线框的数量 = 这一页可点句子的数量。

**Q3：自动连播怎么停在这一页不动了？**
说明已经读到**最后一页**，底部会提示「已播放到最后一页」。
把「自动连播」保持打开，往前翻回前面的页再播放，就能继续自动连读了。

**Q4：暂停后点继续，为什么从头开始读？**
这是设计如此：继续播放会从当前这一句的开头重新读起，不会精确接着断掉的位置。
这样做反而方便孩子反复听同一句。

**Q5：速度变了之后声音怪怪的？**
变速连带改变了音调（快 = 声音尖，慢 = 声音沉），是播放引擎的固有行为，不是坏了。

**Q6：设置项会不会丢？**
只要所在环境允许保存数据，设置会自动保存；如果浏览器禁止了本地存储，
工具会自动使用默认设置（不影响正常使用，只是记不住你的偏好）。
