# 重绘质检工具使用文档

> 版本：v1.3.0 | 更新：2026-09-21

## 1. 工具概述

用于人工质检 AI 重绘的教材图片，支持：
- 左右对比（原图 vs 重绘）
- 一键通过/标记需重绘
- 6 种问题类型勾选
- 区域标记（画框 + 说明）
- 结构化 JSON 导出

## 3. 使用流程

### 3.1 打开报告

直接双击 `qa_reports/四年级_上册.html`，浏览器自动打开。

### 3.2 质检操作

#### 基本操作
1. **切换年级**：顶部年级 Tab
2. **切换单元**：单元 Tab 显示进度（已完成/总数）
3. **查看图片**：左=原图，右=重绘
4. **放大对比**：点击任一图片，弹出并排放大视图（ESC 关闭）

#### 标记状态
- **✅ 通过**：点击绿色大按钮，页面标记为通过
- **❌ 需重绘**：勾选下方问题类型，自动标记为需重绘

#### 问题类型
| 类型 | 说明 |
|------|------|
| 整图过于相似 | 未真正重绘，与原图几乎一致 |
| 部分相似 | 局部未重绘（如背景重绘了但人物没变） |
| 对话框少字缺字 | 文字框内容缺失或不完整 |
| 文字模糊不清 | 文字区域模糊、糊掉 |
| 伪影变形畸变 | 人物/物体变形、奇怪的伪影 |
| 其他问题 | 自定义问题（在补充说明中描述） |

#### 区域标记（画框）
1. 双击原图进入画框模式
2. 在原图上拖拽画框
3. 弹出对话框填写标记说明
4. 标记显示在图片上，可删除
5. 放大对比时标记也会显示

### 3.3 数据持久化（双模式）

**模式 A：file:// 直开（浏览器本地缓冲）**
- 双击 `qa_reports/四年级_上册.html` 直开时，操作保存在浏览器 localStorage（key = `redtools_qa_四年级_上册`）
- 关闭页面不丢失，但**清空浏览器数据会丢**——此模式仅适合临时浏览/快速标记

**模式 B：http 经工作台（服务器持久化，推荐）**
- 双击 `重绘工具/启动热区校正.bat` → 打开**重绘工作台**（`workbench/index.html`）→ 单元卡片点「📋 审核」
- 审核视图内操作仍先写 localStorage 缓冲，但点**「💾 保存到服务器」**后：
  - 结论持久化到各册 `_重绘图片素材/审核记录.json`（每册独立、平面 page→entry）
  - 报告自动重新生成（`gen_qa_reports.py --book 四年级_上册`），无需手动跑
  - 工作台单元卡片审核状态（✅/❌/⬜）即时刷新
- 全局 `qa_reviews.json` 已废弃（代码保留兼容回退，不再写入）

### 3.4 导出结论

1. 点击底部「📋 导出结论」按钮
2. 弹出 JSON 格式审核结果
3. 点击「📋 复制」复制到剪贴板（或 http 模式点「💾 保存到服务器」直接入库）

#### 导出格式
```json
{
  "book": "四年级_上册",
  "timestamp": "2026-09-19T00:52:43.068Z",
  "total": 86,
  "flagged": 1,
  "reviews": {
    "9": {
      "pass": false,
      "issues": ["blurry"],
      "reason": "顶部的字糊了...",
      "marks": [{"x": 100, "y": 50, "w": 200, "h": 30, "note": "文字模糊"}],
      "labels": ["文字模糊不清"]
    }
  }
}
```

## 4. 结论入库流程（当前）

- **服务器模式**（推荐）：审核视图点「💾 保存到服务器」→ POST `/api/save_review` → 合并到册级 `审核记录.json` + 报告重生成 + 工作台状态刷新——**闭环完成，无需 AI 中转**
- **file:// 模式**：导出 JSON 后需人工处理（复制给 AI 或手动写入 `审核记录.json` 后重生成报告）

## 5. 注意事项

- 每册独立报告，数据隔离
- **file:// 模式**的 localStorage 仅保存在当前浏览器，清空会丢失（及时保存到服务器或导出）
- **服务器模式**数据在 `_重绘图片素材/审核记录.json`，与素材同在、不入 git
- 区域标记坐标基于缩略图（240px 高度），放大时自动换算
