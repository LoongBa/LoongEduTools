# 重绘质检工具使用文档

> 版本：v1.1 | 更新：2026-09-19

## 1. 工具概述

用于人工质检 AI 重绘的教材图片，支持：
- 左右对比（原图 vs 重绘）
- 一键通过/标记需重绘
- 6 种问题类型勾选
- 区域标记（画框 + 说明）
- 结构化 JSON 导出

## 3. 使用流程

### 3.1 打开报告

直接双击 `qa_reports/四年级_上册.html`，浏览器自动打开。

### 3.2 质检操作

#### 基本操作
1. **切换年级**：顶部年级 Tab
2. **切换单元**：单元 Tab 显示进度（已完成/总数）
3. **查看图片**：左=原图，右=重绘
4. **放大对比**：点击任一图片，弹出并排放大视图（ESC 关闭）

#### 标记状态
- **✅ 通过**：点击绿色大按钮，页面标记为通过
- **❌ 需重绘**：勾选下方问题类型，自动标记为需重绘

#### 问题类型
| 类型 | 说明 |
|------|------|
| 整图过于相似 | 未真正重绘，与原图几乎一致 |
| 部分相似 | 局部未重绘（如背景重绘了但人物没变） |
| 对话框少字缺字 | 文字框内容缺失或不完整 |
| 文字模糊不清 | 文字区域模糊、糊掉 |
| 伪影变形畸变 | 人物/物体变形、奇怪的伪影 |
| 其他问题 | 自定义问题（在补充说明中描述） |

#### 区域标记（画框）
1. 双击原图进入画框模式
2. 在原图上拖拽画框
3. 弹出对话框填写标记说明
4. 标记显示在图片上，可删除
5. 放大对比时标记也会显示

### 3.3 数据持久化

- 所有操作自动保存到浏览器 localStorage
- 关闭页面不丢失
- 每册独立存储（key = `redtools_qa_四年级_上册`）

### 3.4 导出结论

1. 点击底部「📋 导出结论」按钮
2. 弹出 JSON 格式审核结果
3. 点击「📋 复制」复制到剪贴板
4. 发送给 AI 处理

#### 导出格式
```json
{
  "book": "四年级_上册",
  "timestamp": "2026-09-19T00:52:43.068Z",
  "total": 86,
  "flagged": 1,
  "reviews": {
    "9": {
      "pass": false,
      "issues": ["blurry"],
      "reason": "顶部的字糊了...",
      "marks": [{"x": 100, "y": 50, "w": 200, "h": 30, "note": "文字模糊"}],
      "labels": ["文字模糊不清"]
    }
  }
}
```

## 4. AI 处理流程

1. 用户发送导出 JSON
2. AI 更新 `qa_reviews.json`
3. AI 运行 `python gen_qa_reports.py` 重新生成报告
4. 用户刷新 HTML 页面，审核记录恢复

## 5. 注意事项

- 每册独立报告，数据隔离
- localStorage 仅保存在当前浏览器
- 清空浏览器数据会丢失审核记录（建议及时导出）
- 区域标记坐标基于缩略图（240px 高度），放大时自动换算
