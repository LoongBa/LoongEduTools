## 2. 玩法设计（v1.0 仅配对玩法）

### 2.1 核心规则

- 每局限定 N 对：左侧 **N 条释义卡**（固定顺序，题面）+ 右侧 **N 个成语卡**（洗牌，答案）。
- 点一条释义（选中高亮）→ 点对应成语：释义与该成语对应 → **配对成功**（绿框 + 右上角 ✓ 角标 + 卡片淡化）。
- 配错 → 两卡红闪 + 错误计数 + 取消选中，可重试（无惩罚锁定，仅计错误次数）。
- 全部 N 对配对完成 → 过关结算（计时 + 星级 + 打卡 + 成绩记录）。
- 成语卡展示**成语 + 拼音**（辅助认读，零学习成本）。

### 2.2 三档难度（年级段 × 对数联动）

| 档位 | 年级段 | 对数 N | 词库池规模 | 卡片总数 |
|:---:|:---:|:---:|:---:|:---:|
| 简单 | 1-2 年级 | 3 对 | 140 条 | 6 张 |
| 普通 | 3-4 年级 | 4 对 | 323 条 | 8 张 |
| 困难 | 5-6 年级 | 5 对 | 379 条 | 10 张 |

- 年级池由词库「年级」标签驱动：含 1/2 → b12，含 3/4 → b34，其余（含 5/6 与**无年级标签 33 条**）→ b56，保证 975 条教材成语全部可玩。
- 每局从对应池**随机抽 N 条**（Fisher-Yates 洗牌），条目不重复。

### 2.3 星级常模（结算）

| 错误次数 | 星级 |
|:---:|:---:|
| 0 | 3★ |
| 1-2 | 2★ |
| ≥3 | 1★ |

- 星级 = 错误次数的函数（对齐反义词配对口径）；时间不参与星级，仅展示。
- 每局完成自动**打卡**（当日去重 + 连续天数）→ best（按档位存最佳星级+用时）/ recent / history（最近 30 条）。
- 新纪录（更优星级或同星级更快）→ 结算页「🎉 新纪录」角标。

## 3. 数据与选词引擎

### 3.1 词库注入（构建期）

- `datasource='chengyu'`：build_framework 自动读 `series/学科/_shared/成语词库/成语词库.json`
  → 生成 `data.js` 注入 `window.CHENGYU_DATA`（课本 975 + 接龙扩展 781 全量）+ `window.CHENGYU_CHAIN`（接龙索引，本工具不使用）。
- 前端仅从 `CHENGYU_DATA['课本']` 选词（不触碰接龙扩展层）。

### 3.2 年级段分池（运行时）

```js
POOLS = { b12: [], b34: [], b56: [] }
// 课本条目：grade 含 1/2 → b12；含 3/4 → b34；其余（5/6 或无 grade）→ b56
```

- 图1：`inBand` 逻辑与看图猜成语完全一致（无年级条目不流失，归入 b56 兜底近 379 条）。

### 3.3 出题

```
随机抽 N 条（shuffle(pool).slice(0, N)）
→ 每条生成 释义卡（fixed 序）+ 成语卡（洗牌）
→ state.cards = 左列(释义, 顺序) + 右列(成语, 洗牌)
→ 配对判定：pid 相同 && side 不同 → matched
```

## 4. 界面结构

```
首页（难度选择）
  ├─ 标题/版本徽标（header）
  ├─ 页题「选择难度」+ 提示语
  ├─ 三档难度卡（名称 + 年级段徽章 + 对数 + 最佳成绩）
  ├─ 📚 词库说明（975 条 / 年级段出题）
  └─ 📅 打卡日历入口（连续天数）
游戏页
  ├─ 顶栏：←返回 / 「年级段 · 档位」/ ⏱ 计时
  ├─ 进度「配对 x/N」+ 提示「点一条释义，再点对应的成语配对」
  └─ 左右双列：左「释义」N 卡（13px 小字左对齐）｜右「成语」N 卡（23px 大字 + 11px 拼音）
结算浮层
  ├─ 🎉 全部配对啦！+ 用时/错误
  ├─ ★ 星级 + ✅ 打卡行 + 🎉 新纪录
  └─ 再来一局 / 选难度 / 📅 打卡日历
打卡日历页（本月打卡 + 连续天数）
```

- 视觉：橙系（对齐看图猜成语成语系列，#ff7a59 主色）；Chrome 61 兼容（无 flex gap / aspect-ratio / clamp / :has；前后清浮动）。

## 8. 与同系列差异

| 工具 | 玩法 | 词库 | 年级处理 | 交互复杂度 |
|---|---|---|---|---|
| 看图猜成语 | emoji 拼图 4 选 1 | 课本（仅 emoji 非空子集） | 年级段分池 b12/b34/b56 | 单项选择 |

> 三件套错位：看图猜成语测「由画面联想成语」、成语接龙测「成语储备与联想」、成语配对测「词义理解」。共用 `_shared/成语词库/` 单一数据源，分别独立发布、独立迭代。
