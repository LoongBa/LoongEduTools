## 2. 玩法规则

1. **开局**：首页 3 张难度卡（简单 3 次 / 进阶 5 次 / 挑战 8 次），点卡片进入 `startGame`
   并立即开始第 1 轮（`nextRound`）。
2. **等待（waiting）**：红屏 +「👀 等待变绿，变绿后立即点击！」；`scheduleGreen` 生成随机延迟
   `2000 + Math.floor(Math.random() * 3001)`（即 2000~5000ms），到点 `goGreen` 变绿。
3. **变绿（green）**：切换瞬间 `performance.now()` 记录 `greenMs`，绿屏 +「⚡ 点！」。
4. **点击（onTapZone）**：
   - `green` 阶段点击 → **有效成绩**：`ms = Math.round(performance.now() - greenMs)`，
     `round +1`、`results.push(ms)`、`lastMs = ms`，进入 `result`；
   - `waiting` 阶段点击 → **犯规**：清掉 `pendingId`、`foulCount +1`、红闪提示
     「⛔ 太快了！还没变绿，重新等待」，700ms（`foulTimerId`）后回到 waiting 并
     **重新随机延迟**（本轮作废，不计数）；
   - `result` / `foul` 阶段点击一律忽略（防连点误触）。
5. **单次反馈（result）**：白底大号显示本次 `lastMs + ' ms'` + 单次等级标签（`labelFor`）；
   1.2s（`resultTimerId`）后自动进入下一轮；已完成轮数 ≥ 总轮数时 `finishGame` 结算。
6. **结算（finishGame）**：`avg = Math.round(sum / results.length)`；`min / max`；
   `starFor(avg)` 评星级、`labelFor(avg)` 评等级；自动打卡 + 更新最佳/最近/历史；
   弹出结果浮层 `showResult`。

> 设计考量：等待时长随机 2~5 秒，防止孩子"掐表"预判，保证每次点击都是真实反应；
> 犯规不扣分不计次，而是温和地重新等待，规则简单、对低龄无挫败感；
> 晒分分享放在结算主路径上，用"连续打卡 N 天"激励养成每日训练习惯。

## 3. 难度与星级

### 3.1 难度定义（main.js `LEVELS` 常量，键 = 有效轮数）

| 难度 | label | 测试轮数 | 星级门槛（按平均 ms） |
|---|---|---|---|
| 简单 | 简单 · 3 次 | 3 | 与其余难度一致（见 3.2） |
| 进阶 | 进阶 · 5 次 | 5 | 与其余难度一致（见 3.2） |
| 挑战 | 挑战 · 8 次 | 8 | 与其余难度一致（见 3.2） |

> 三档仅区分轮数（低龄友好、坚持成本不同），星级标准统一按平均毫秒，便于跨难度横向比较。

### 3.2 星级评级（按平均毫秒 `avg`，`starFor(avg)`）

| 平均成绩 | 星级 |
|----------|------|
| ≤ 280 ms | 3★ |
| ≤ 400 ms | 2★ |
| 其余 | 1★ |

### 3.3 等级标签（按平均毫秒 `avg`，`labelFor(avg)`）

| 平均成绩 | 标签 |
|----------|------|
| ≤ 200 ms | 神速 |
| ≤ 280 ms | 闪电 |
| ≤ 350 ms | 优秀 |
| ≤ 450 ms | 不错 |
| > 450 ms | 加油 |

> 鼓励语 `motivationFor(label)` 按标签生成：神速/闪电 →「闪电般的反应，太棒了！」；
> 优秀 →「反应又快又准，继续保持！」；不错 →「反应很敏捷，再练更棒！」；加油 →「多练几次，反应会越来越快！」。

## 4. 页面/视图结构

```
首页 viewHome（3 张难度卡 + 各难度最佳成绩/未挑战 + 玩法说明 4 条 + 底栏导航 成绩/打卡/首页）
  │ 点击难度卡
  ▼
游戏页 startGame（顶栏 ‹返回 | 第 x/y 轮 | 当前平均 / 大点击区 tap-zone 红·绿·白·犯规四态 / 重新开始）
  │ 完成 N 轮 → finishGame
  ▼
结果浮层 showResult（本局结束 / 平均 ms 大字 / 『等级』 / 最快·最慢·连续打卡 / ★★★ / 新纪录横幅 /
                    单次成绩列表 / 再来一局·返回首页 / 📷 分享打卡）
  │ 点 📷 分享打卡
  ▼
分享浮层 openShare（canvas 1080×1920 分享卡片预览 + 长按保存提示 + 复制分享文案 / 返回结算）

底栏导航：成绩 viewHistory（最近 30 次，时间倒序）│ 打卡 viewCheckin（本月日历 + 连续天数）
```

- **顶栏（app-header）**：`renderHeader(title)` 渲染图标 + 标题 + 版本号（来自 `APP.meta.version`）。
- **首页 `viewHome`**：标题「选择难度」+ 提示「屏幕变绿后立即点击！测测你的反应有多快」；
  3 张难度卡（`diff-card`），每张含难度按钮 + 该难度最佳成绩（`最佳 X ms`，未玩过显示「未挑战」）；
  下方「玩法说明」4 条（① 看到红屏别着急，等它变绿 ② 屏幕一变绿就立即点击！
  ③ 没变绿就点了算犯规，本轮重来 ④ 完成所有轮次，取平均成绩）。
  `viewHome` 先 `clearTimers()` 清理全部计时（防止 waiting 变绿 / result 自动推进闪现）。
- **游戏页 `startGame`**：重置全部状态 → 清空底栏（游戏页不走底部导航）→ `nextRound()` 开第 1 轮。
- **游戏页顶栏（`game-top`）**：`‹ 返回`（回首页，本局不计成绩）| `第 x/y 轮`
  （已完成轮数 +1，封顶显示总轮数）| `平均 X ms`（无成绩时 `平均 --`）。
- **大点击区（`tap-zone`）**：全宽、`min-height: 240px`、圆角 24px，四态：
  - `waiting` 红底（`#e74c3c`）「👀 等待变绿，变绿后立即点击！」；
  - `green` 绿底（`#2ecc71`）「⚡ 点！」；
  - `result` 白底大号 `lastMs ms` + 等级徽章（`tap-label`）；
  - `foul` 红底黄字「⛔ 太快了！还没变绿，重新等待」+ `foulFlash 0.4s` 单次脉冲动画；
  - `idle` 橙底「准备…」（初始态）。
  点击统一走 `onTapZone`，按 `phase` 分发。
- **结果浮层 `showResult`**：全屏半透明遮罩 + 白色卡片，含「本局结束」、平均 ms 大字、
  『等级』标签、最快/最慢/连续打卡统计、星级、新纪录时「🎉 新纪录！」、单次成绩列表，
  以及「再来一局」「返回首页」「📷 分享打卡」三个按钮。
- **分享浮层 `openShare`**：`drawShareCard()` 绘制 canvas 卡片 → `toDataURL('image/png')`
  预览图 + 提示「📸 长按保存图片 · 发布笔记分享成就」+「复制分享文案」「返回结算」两按钮。
- **成绩页 `viewHistory`**：无记录时提示「暂无成绩，先来一局吧！」；否则按时间倒序列出
  最近 N 次（难度 / 日期·有效 x 次 / 平均 ms / 星级）。
- **打卡页 `viewCheckin`**：本月日历（已打卡日橙色点亮 + 今日红色描边）+ 连续打卡天数
  （≥7 天显示 🎉）；打卡由完成游戏自动触发，本页仅展示。

### 4.1 状态模型（main.js `state`）

```js
{
  level: 3,            // 难度（有效轮数 3 / 5 / 8）
  total: 3,            // 总轮数
  round: 0,            // 已完成有效轮数
  phase: 'idle',       // idle / waiting / green / result / foul / finish
  results: [],         // 有效单次成绩 ms
  greenMs: 0,          // 变绿瞬间时间戳（performance.now()）
  lastMs: 0,           // 最近一次有效成绩
  pendingId: null,     // waiting → green 的 setTimeout id
  resultTimerId: null, // result 阶段自动下一轮 timer
  foulTimerId: null,   // 犯规后重进 waiting timer
  foulCount: 0,        // 犯规次数
  finished: false,     // 是否已结算
  resultOverlay: null, // 结算浮层引用
  shareOverlay: null,  // 分享浮层引用
  summary: null        // 结算摘要（分享/文案用）
}
```

## 5. 成绩持久化（localStorage key `redtools.reaction.v1`）

```js
{
  version: 1,
  best:    { "3": null, "5": null, "8": null },  // 各难度最佳 {avg, date}（平均更小覆盖）
  recent:  { "3": 0, "5": 0, "8": 0 },           // 各难度最近平均 ms
  checkin: { dates: ["YYYYMMDD"], streak },      // 打卡日期（滚动 365 天）+ 连续天数
  history: [ {date, level, rounds, avg, min, max, stars} ]  // 滚动 30 条，最新在前
}
```

- 读写均包 try/catch：`loadStore` 解析失败或首次打开返回默认结构；`saveStore` 写入失败静默。
- 启动时先 `loadStore()` 再 `saveStore()`（初始化写入，建立默认结构）。
- **最佳成绩**：`best[key]` 为空或 `avg < best.avg` 时覆盖为 `{avg, date}` 并标记新纪录
  （结果浮层显示「🎉 新纪录！」）。**平均更小覆盖**（反应越快越好）。
- **最近成绩**：`recent[key]` 直接覆盖为本局平均 ms。
- **历史**：`history.unshift(...)` 最新在前，`while (length > 30) pop()` 滚动保留 30 条；
  每条含 `rounds`（本局有效轮数）、`avg/min/max`（平均/最快/最慢 ms）、`stars`。

### 5.1 打卡逻辑（与系列内舒尔特方格/翻牌记忆配对/数字记忆一致）

- 完成一局即自动打卡：`todayStr()` 生成 YYYYMMDD，不在 `dates` 则 push，然后 `sort()`；
  `while (dates.length > 365) dates.shift()` 滚动保留 365 天。
- 连续天数 `calcStreak(dates)`：从日期列表末尾向前回推，**含今天**往前数连续天数，
  跨天即断（缺一天 streak 归零）；结果写入 `checkin.streak`，打卡页渲染时实时重算。
- 打卡无手动入口，本工具「完成一局（所有轮次跑完结算）」即点亮今日；中途返回不计成绩不打卡。

## 6. 关键实现点

### 6.1 状态机（`nextRound` / `scheduleGreen` / `goGreen` / `onTapZone` / `finishGame`）

- `nextRound`：`phase='waiting'`，渲染游戏页后 `scheduleGreen()`（也用于开局）。
- `scheduleGreen`：先清旧 `pendingId`，`delay = 2000 + Math.floor(Math.random() * 3001)`，
  `setTimeout(goGreen, delay)`。
- `goGreen`：`pendingId = null`、`phase='green'`、`greenMs = performance.now()`、重渲染。
- `onTapZone`：唯一点击入口，按 `phase` 分发（green→记成绩进 result；waiting→犯规进 foul；
  result/foul→忽略防连点）。result 阶段 `setTimeout(1200ms)` 后 `round >= total ? finishGame() : nextRound()`；
  foul 阶段 `setTimeout(700ms)` 后回 waiting 并重新 `scheduleGreen()`。
- `finishGame`：`finished=true`、`phase='finish'`、`clearTimers()`；计算 `avg/min/max/stars/label`；
  打卡 → 更新 best/recent/history → `saveStore()` → 组装 `state.summary` → `showResult()`。
- `state.summary` 为结算摘要（含 results 全量），结算浮层与分享卡片/文案共用。

### 6.2 计时（performance.now() 差值，无轮询）

- 变绿瞬间 `goGreen` 记录 `greenMs = performance.now()`，点击时
  `ms = Math.round(performance.now() - greenMs)` 直接算差值。
- 无需 `setInterval` 轮询：计时天然精确（后台回来不漂移），且省电、逻辑简单。

### 6.3 犯规恢复（foul 阶段 700ms）

- waiting 阶段点击：清 `pendingId`（取消即将到来的变绿）→ `foulCount +1` → 红闪渲染 →
  700ms 后回 waiting 重新随机延迟。犯规轮不进入 `results`，不影响平均与轮数计数。

### 6.4 分享卡片 canvas（`drawShareCard`，1080×1920）

- 暖橙渐变背景（`#fff3e6 → #ffe3cc`）+ 24 个随机装饰点；
- 标题「点击反应测试」（bold 84px `#d95b1e`）+ 副标「反应力小达人」（42px `#f08a4d`）；
- 白底战绩卡（圆角 24、描边 `#ffd6b8`）：难度 `【简单 · 3 次】`、平均反应大字（bold 132px `#ff8c42`）、
  等级圆角徽章（`#ff8c42` 底白字『标签』）、详情行（单次最快/最慢 + 连续打卡）、
  鼓励语 `motivationFor`、署名「龙爸乐学 · 点击反应测试小工具」+ 日期。
- `roundRectPath` 自绘圆角矩形（无 `ctx.roundRect` 依赖，Chrome 61 兼容）。

### 6.5 复制文案（textarea + execCommand，Chrome 61 兼容）

- `shareText()` 生成文案：「孩子玩【点击反应测试】『{难度label}』平均反应 {avg} 毫秒，
  『{等级}』！已连续打卡 {streak} 天，反应力训练走起～#反应力测试 #小学生专注力 #益智训练」。
- `copyShareText`：隐藏 textarea（fixed + `left:-9999px`）→ `select()` →
  `document.execCommand('copy')`；成功 toast「✅ 文案已复制，去小红书粘贴发布吧」，
  失败兜底 toast「📋 文案如下，请长按选择复制：」+ 全文。
- `shareOpen` 标志防分享浮层重复打开。

### 6.6 视图与安全区（同系列工具）

- `syncAppHeight()` 写 `--app-height`，`env(safe-area-inset-*)` + `@supports` 双兜底；
- 无 flex gap（间距用 margin 实现）；`@keyframes` 全部 `-webkit-` 前缀双写（Chrome 61）。

## 7. Chrome 61 / 合规约束

| 事件 | 全部 `addEventListener` | 难度卡/返回/重新开始/浮层按钮逐个绑定；无内联事件 / eval |

| 图片 | 无图片素材 | 除构建生成的 `assets/icon.png` 外，一切图形由 DOM/CSS 生成；分享卡片运行时 canvas 绘制 |

| 动画 | 温和反馈（光敏安全） | 犯规红闪 `foulFlash 0.4s ease` 单次脉冲（≤400ms）；浮层 `cardIn 0.25s`；无强频闪 |
| 触控 | 触摸友好 | 大点击区 `min-height: 240px`；按钮 min-height 48px、难度卡 56px；result/foul 点击忽略防误触 |
| 状态隔离 | 退出清理 | `viewHome`/`startGame` 均 `clearTimers()`，防 waiting 变绿 / result 自动推进闪现 |
