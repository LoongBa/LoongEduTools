4. **三档时长**：简单 5 秒 / 进阶 10 秒 / 挑战 15 秒（`LEVELS`），时长越短越易坚持，低龄友好 ✅
5. **晒分传播（核心卖点）**：结算一键生成 1080×1920 竖版分享卡片 + 一键复制打卡文案，晒分拉新 ✅

## 2. 玩法规则

1. **开局**：首页 3 张难度卡（简单 · 5 秒 / 进阶 · 10 秒 / 挑战 · 15 秒，按时长秒），
   点卡片进入 `startGame` 并立即开始准备倒计时（`startCountdown`）。
2. **准备（ready）**：中央大点击区浅橙底「👆 准备…」+ 3-2-1 逐秒倒计时大字 + 提示
   「倒计时结束立即开始点击！」；此时点击区点击**无效**（toast「⏳ 还没开始，等倒计时结束！」）；
   倒计时归零自动 `startRunning` 开跑。
3. **运行（running）**：`startRunning` 用 `performance.now()` 记录 `startMs`；橙底大点击区显示
   剩余时间（`⏱ 07.2`）+ 总点击数大字 + 实时 CPS（`每秒 X.X 次`）；`setInterval(tickRunning, 100)`
   按差值刷新，剩余归零即 `finishGame`；另设 `setTimeout(finishGame, duration*1000 + 50)` 兜底（双保险）。
4. **点击（onTapZone）**：
   - `running` 阶段点击 → **有效计次**：`count +1`、计数大字弹跳动画（`triggerBounce`，150ms）、
     点击区轻变色反馈（`triggerFlash`，150ms）、顶栏「已点 N 次」同步刷新；
   - `ready` 阶段点击 → **无效**：toast 提示，不计数；
   - `idle` / `finish` 阶段点击一律忽略（防误触）。
5. **结算（finishGame）**：`state.finished` 守卫防重复结算；`cps = count / duration`（保留 1 位小数）；
   `starFor(cps)` 评星级、`labelFor(cps)` 评等级；自动打卡 + 更新最佳/最近/历史；组装 `state.summary`
   弹出结果浮层 `showResult`。

> 设计考量：先 3 秒准备再开跑，给低龄孩子"蓄力"时间，避免没提示就被迫开点；
> 限时采用"差值计时 + 兜底定时"双保险，防 interval 被后台压制导致结算延迟；
> 点击反馈用 ≤150ms 的数字弹跳与轻变色，无频闪又有点击爽感；
> 晒分分享放在结算主路径上，用"连续打卡 N 天"激励养成每日训练习惯。

## 4. 页面/视图结构

```
首页 viewHome（3 张难度卡 + 各难度最佳成绩/未挑战 + 玩法说明 4 条 + 底栏导航 成绩/打卡/首页）
  │ 点击难度卡
  ▼
游戏页 startGame（顶栏 ‹返回 | 难度 label | 已点 N 次 + 大点击区 tap-zone ready/running 两态 + 重新开始）
  │ 时间到 → finishGame
  ▼
结果浮层 showResult（时间到！/ 总点击数大字 / 『等级』· 每秒 CPS / 总点击数·时长·连续打卡 / ★★★ / 新纪录横幅 /
                    再来一局·返回首页 / 📷 分享打卡）
  │ 点 📷 分享打卡
  ▼
分享浮层 openShare（canvas 1080×1920 分享卡片预览 + 长按保存提示 + 复制分享文案 / 返回结算）

底栏导航：成绩 viewHistory（最近 30 次，时间倒序）│ 打卡 viewCheckin（本月日历 + 连续天数）
```

- **顶栏（app-header）**：`renderHeader(title)` 渲染图标 + 标题 + 版本号（来自 `APP.meta.version`）。
- **首页 `viewHome`**：标题「选择难度」+ 提示「疯狂点击大区域，测测你的限时手速！」；
  3 张难度卡（`diff-card`），每张含难度按钮 + 该难度最佳成绩（`最佳 每秒 X 次`，未玩过显示「未挑战」）；
  下方「玩法说明」4 条（① 点击开始后疯狂点击大区域 ② 倒计时结束前尽量多点
  ③ 数字会告诉你点了多少次 ④ 时间到取每秒点击数评星级）。
  `viewHome` 先 `clearAllTimers()` 清理全部计时（防止倒计时/限时在后台继续推进）。
- **游戏页 `startGame`**：重置全部状态 → 清空底栏（游戏页不走底部导航）→ `startCountdown()` 开准备倒计时。
- **游戏页顶栏（`game-top`）**：`‹ 返回`（回首页，本局不计成绩）| 难度 label | `已点 N 次`。
- **大点击区（`tap-zone`）**：全宽、`min-height: 260px`、圆角，两态：
  - `ready` 浅橙底（`#ffc69e`）「👆 准备…」+ 倒计时大字 + 提示「倒计时结束立即开始点击！」；
  - `running` 橙底（`#ff8c42`）剩余时间 `⏱ 07.2` + 计数大字（≥72px）+ 实时 `每秒 X.X 次` +
    「疯狂点点点！」。
  点击统一走 `onTapZone`，按 `phase` 分发（running 计数 / ready 提示 / 其余忽略）。
- **结果浮层 `showResult`**：全屏半透明遮罩 + 白色卡片，含「时间到！」、总点击数大字（`N 次`）、
  『等级』· 每秒 CPS、统计（总点击数 / 时长 / 连续打卡）、星级、新纪录时「🎉 新纪录！」，
  以及「再来一局」「返回首页」「📷 分享打卡」三个按钮。
- **分享浮层 `openShare`**：`drawShareCard()` 绘制 canvas 卡片 → `toDataURL('image/png')`
  预览图 + 提示「📸 长按保存图片 · 发布笔记分享成就」+「复制分享文案」「返回结算」两按钮。
- **成绩页 `viewHistory`**：无记录时提示「暂无成绩，先来一局吧！」；否则按时间倒序列出
  最近 N 次（难度 / 日期·时长 / 总点击数·CPS / 星级）。
- **打卡页 `viewCheckin`**：本月日历（已打卡日橙色点亮 + 今日红色描边）+ 连续打卡天数
  （≥7 天显示 🎉）；打卡由完成游戏自动触发，本页仅展示。

### 4.1 状态模型（main.js `state`）

```js
{
  level: 5,            // 难度（时长秒 5 / 10 / 15）
  duration: 5,         // 本局时长秒
  phase: 'idle',       // idle / ready / running / finish
  count: 0,            // 总点击数

  countdownId: null,   // 准备倒计时 interval

  endTimerId: null,    // 双保险 setTimeout（兜底结束）
  bounceTimerId: null, // 计数弹跳类移除 timer
  flashTimerId: null,  // 点击区变色类移除 timer
  resultOverlay: null, // 结算浮层引用
  shareOverlay: null,  // 分享浮层引用
  summary: null        // 结算摘要（分享/文案用）
}
```

## 5. 成绩持久化（localStorage key `redtools.tapchallenge.v1`）

```js
{
  version: 1,
  best:    { "5": null, "10": null, "15": null },  // 各难度最佳 {cps, count, date}（CPS 更大覆盖）
  recent:  { "5": 0, "10": 0, "15": 0 },           // 各难度最近总点击数
  checkin: { dates: ["YYYYMMDD"], streak },        // 打卡日期（滚动 365 天）+ 连续天数
  history: [ {date, level, duration, count, cps, stars} ]  // 滚动 30 条，最新在前
}
```

- 读写均包 try/catch：`loadStore` 解析失败或首次打开返回默认结构；`saveStore` 写入失败静默。
- 启动时先 `loadStore()` 再 `saveStore()`（初始化写入，建立默认结构）。
- **最佳成绩**：`best[key]` 为空或 `cps > best.cps` 时覆盖为 `{cps, count, date}` 并标记新纪录
  （结果浮层显示「🎉 新纪录！」）。**CPS 更大覆盖**（点得越快越好）。
- **最近成绩**：`recent[key]` 直接覆盖为本局总点击数。
- **历史**：`history.unshift(...)` 最新在前，`while (length > 30) pop()` 滚动保留 30 条；
  每条含 `level`（时长秒）、`duration`（本局时长）、`count`（总点击数）、`cps`、`stars`。

### 5.1 打卡逻辑（与系列内舒尔特方格/点击反应测试一致）

- 完成一局即自动打卡：`todayStr()` 生成 YYYYMMDD，不在 `dates` 则 push，然后 `sort()`；
  `while (dates.length > 365) dates.shift()` 滚动保留 365 天。
- 连续天数 `calcStreak(dates)`：从日期列表末尾向前回推，**含今天**往前数连续天数，
  跨天即断（缺一天 streak 归零）；结果写入 `checkin.streak`，打卡页渲染时实时重算。
- 打卡无手动入口，本工具「完成一局（限时跑完自动结算）」即点亮今日；中途返回不计成绩不打卡。

## 6. 关键实现点

### 6.1 状态机（`startGame` / `startCountdown` / `startRunning` / `onTapZone` / `finishGame`）

- `startGame`：清全部计时 → 重置 level/duration/count → `phase='ready'` → 渲染游戏页 → `startCountdown()`。
- `startCountdown`：`countdownVal = READY_SECONDS(3)`，`setInterval(1000ms)` 逐秒 -1；
  归零 clearInterval 后自动 `startRunning()`；中间只更新 `#countdown-num` 文本（不重建 DOM）。
- `startRunning`：`finished` 守卫 → `phase='running'`、`startMs = performance.now()` → 渲染 running →
  `setInterval(tickRunning, 100)` + `setTimeout(finishGame, duration*1000 + 50)` 双保险。
- `onTapZone`：唯一点击入口，按 `phase` 分发（running→count+1 计数弹跳；ready→toast 提示；
  idle/finish→忽略防误触）。
- `finishGame`：`finished` 守卫防重复结算 → `phase='finish'`、`clearAllTimers()`；
  计算 `cps/stars/label` → 打卡 → 更新 best/recent/history → `saveStore()` → 组装 `state.summary` → `showResult()`。
- `state.summary` 为结算摘要（level/duration/count/cps/stars/label/isNewBest），
  结算浮层与分享卡片/文案共用。

### 6.2 计时（performance.now() 差值 + 双保险）

- `startRunning` 用 `performance.now()` 记 `startMs`；`tickRunning` 每 100ms 按
  `elapsed = (now - startMs) / 1000` 差值算剩余 `remain = duration - elapsed`，归零即 `finishGame`。
- 差值计时天然精确（后台回来不漂移）；另设 `setTimeout(finishGame, duration*1000 + 50)` 兜底
  （+50ms 裕量，防 interval 被后台压制导致结算延迟）。
- `fmtNum(v)`：秒数 `toFixed(1)` 补零到 4 字符（5 → `05.0`、7.2 → `07.2`），顶栏 `⏱ 07.2` 格式。

### 6.3 点击计数与弹跳动画（`triggerBounce` / `triggerFlash`）

- `running` 阶段每次点击 `count +1`，同步刷新计数大字（`#tap-count`）与顶栏（`#game-count`）。
- `triggerBounce`：先清旧 `bounceTimerId` → 移除 `bounce` 类 → `void el.offsetWidth` 强制重排
  （保证连点每次都能重新触发动画）→ 加 `bounce` 类 → 150ms 后移除。
- `triggerFlash`：点击区 `running` → `running flash` 轻变色脉冲（150ms）→ 复原；
  弹跳/变色均 ≤150ms（≤400ms），无频闪光敏安全。

### 6.4 分享卡片 canvas（`drawShareCard`，1080×1920）

- 暖橙渐变背景（`#fff3e6 → #ffe3cc`）+ 24 个随机装饰点；
- 标题「手速挑战」（bold 84px `#d95b1e`）+ 副标「手速小达人」（42px `#f08a4d`）；
- 白底战绩卡（圆角 24、描边 `#ffd6b8`）：难度 `【简单 · 5 秒】`、总点击数大字（bold 128px `#ff8c42`）、
  每秒 CPS（bold 76px）、等级圆角徽章（`#ff8c42` 底白字『标签』）、详情行（时长 + 连续打卡）、
  鼓励语 `motivationFor`、署名「龙爸乐学 · 手速挑战小工具」+ 日期。
- `roundRectPath` 自绘圆角矩形（无 `ctx.roundRect` 依赖，Chrome 61 兼容）。

### 6.5 复制文案（textarea + execCommand，Chrome 61 兼容）

- `shareText()` 生成文案：「孩子玩【手速挑战】『{难度label}』{duration} 秒点了 {count} 次，
  每秒 {cps} 次，『{等级}』！已连续打卡 {streak} 天，手速训练走起～#手速挑战 #小学生专注力 #益智训练」。
- `copyShareText`：隐藏 textarea（fixed + `left:-9999px`）→ `select()` →
  `document.execCommand('copy')`；成功 toast「✅ 文案已复制，去小红书粘贴发布吧」，
  失败兜底 toast「📋 文案如下，请长按选择复制：」+ 全文。
- `shareOpen` 标志防分享浮层重复打开；toast 自动顶掉旧条（2.2s 消失），防连点刷屏。

### 6.6 视图与安全区（同系列工具）

- `syncAppHeight()` 写 `--app-height`，`env(safe-area-inset-*)` + `@supports` 双兜底；
- 无 flex gap（间距用 margin 实现）；`@keyframes` 全部 `-webkit-` 前缀双写（Chrome 61）；
  大点击区 `touch-action: manipulation` 防双击缩放。

## 7. Chrome 61 / 合规约束

| 类别 | 约束 | 本工具做法 |
|---|---|---|
| JS 语法 | ES2017 上限经典脚本 | `var` + `function` 风格，无 `?.` `??` 对象展开 `replaceAll`；无 `type="module"`/import/export |
| 事件 | 全部 `addEventListener` | 难度卡/返回/重新开始/浮层按钮逐个绑定；无内联事件 / eval |
| 网络 | 零网络请求 | 无 fetch/XHR/Worker/外部资源；无 audio |
| 图片 | 无图片素材 | 除构建生成的 `assets/icon.png` 外，一切图形由 DOM/CSS 生成；分享卡片运行时 canvas 绘制 |
| CSS 语法 | Chrome 61 兼容层 | 无 flex `gap`/`aspect-ratio`/`clamp`/`inset`/逻辑属性/`:has`/`@container`/`dvh`；`@keyframes` 加 `-webkit-` 前缀双写；Flex 子项设 `min-width:0` |
| 动画 | 温和反馈（光敏安全） | 数字弹跳 `bounce 0.15s` 与点击区 `flash 0.15s` 均 ≤400ms；浮层 `cardIn` 温和过渡；无强频闪 |

| 状态隔离 | 退出清理 | `viewHome`/`startGame` 均 `clearAllTimers()`，防倒计时/限时在后台继续推进 |
