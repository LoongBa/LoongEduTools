## 2. 玩法规则

1. **开局**：首页 3 张难度卡（简单 · 10 题 / 进阶 · 10 题 / 挑战 · 60 秒），
   点卡片进入 `startGame`（挑战档同时 `startTimer` 开限时）。
2. **出题（genQuestion）**：屏幕中央 `word-card` 显示一个颜色词（红/蓝/绿/黄，96px 大字），
   `word-text` 的 `color` 即本局字色（正确答案）；下方 4 色按钮（红/蓝/绿/黄）供选择。
   简单档字色=词义、进阶档字色≠词义、挑战档约 1/2 一致混合（`Math.random() < 0.5`）。
3. **作答（onPick）**：点 4 色按钮判定 `key === state.color`：
   - **答对**：`score +1`、按钮绿闪（`flashBtn(key, true)` 300ms）、反馈区「✓ 答对了！」、
     350ms（`FEEDBACK_OK_MS`）后自动 `nextQuestion`；
   - **答错**：按钮红闪（300ms）、反馈区「✗ 答案是「X」色」、
     900ms（`FEEDBACK_NO_MS`）后自动 `nextQuestion`（留足读正确答案的时间）。
   - 反馈期间（`phase='feedback'`）点击一律忽略（防连点抢答）；`idle`/`finish` 阶段点击忽略。
4. **进展（nextQuestion）**：非限时档 `index +1`、重出题、更新 `word-text` 颜色并复位反馈区，
   题号顶栏同步 `第 {index+1}/10 题`；答到第 10 题（`index+1 >= total`）即 `finishGame`。
5. **结算（finishGame）**：`state.finished` 守卫防重复结算；自动打卡 +
   更新最佳/最近/历史；`starFor` 评星级、`labelFor` 评等级；组装 `state.summary`
   弹出结果浮层 `showResult`。

> 设计考量：Stroop 干扰是心理学经典范式，玩法一句话讲得清（"看字的颜色，不是字的意思"），
> 且天然可量化（答对题数/正确率），适合评星定级；答错展示正确答案是"学习反馈"而非惩罚，
> 契合家庭训练场景；挑战档引入 60 秒限时制造紧张感与晒分点（"60 秒答对 N 题"），
> 与同子系列点击反应测试/手速挑战的晒分传播形成系列合力。
> 多款游戏内嵌即可组成「反应力三件套」训练营。

## 3. 难度与星级

### 3.1 难度定义（main.js `LEVELS` 常量，键 = 难度编号 1/2/3）

| 难度 | label | mode | 局制 | 限时 |
|---|---|---|---|---|
| 简单 | 简单 · 10 题 | same（字色=词义，无干扰） | 10 题/局 | 无 |
| 进阶 | 进阶 · 10 题 | diff（字色≠词义，经典干扰） | 10 题/局 | 无 |
| 挑战 | 挑战 · 60 秒 | mix（混合，约 1/2 一致） | 不固定题数 | 60 秒（计答对题数） |

> 简单/进阶：字色与词义关系固定，练"看色"基本功与干扰抑制；
> 挑战：混合 + 限时，题数无上限，答得快又准才拿高星级。

### 3.2 星级评级（`starFor(level, score, total)`）

| 难度 | 3★ | 2★ | 1★ |
|---|---|---|---|
| 简单/进阶（10 题） | 全对（10/10，`score >= total`） | 对 ≥ 8 题 | 其余 |
| 挑战（限时） | 答对 ≥ 20 题 | 答对 ≥ 12 题 | 其余 |

### 3.3 等级标签（`labelFor(level, score, total)`）

| 难度 | 色彩大师 | 火眼金睛 | 慧眼识色 | 慢慢来 | 多练习 |
|---|---|---|---|---|---|
| 简单/进阶（按正确率） | 100%（10/10） | ≥ 80%（8-9/10） | ≥ 60%（6-7/10） | ≥ 40% | < 40% |
| 挑战（按题数） | ≥ 25 题 | ≥ 18 题 | ≥ 12 题 | ≥ 8 题 | < 8 题 |

### 3.4 鼓励语（按等级标签，`motivationFor(label)`）

| 标签 | 鼓励语 |
|------|--------|
| 色彩大师 | 色感惊人，反应超快！ |
| 火眼金睛 | 又快又准，太厉害！ |
| 慧眼识色 | 看得仔细，继续加油！ |
| 慢慢来 | 别急，稳住再点！ |
| 多练习 | 多练几次，反应会更快！ |

> ⚠️ 星级/标签阈值为初版参考值（常模），待真机实测后按真实分布校准；
> 两档标签同名但分档口径不同（正确率 vs 题数），结果页/分享卡并不标注口径，
> 答卷时注意按难度对照（见本文 3.3）。

## 4. 页面/视图结构

```
首页 viewHome（3 张难度卡 + 各难度最佳成绩/未挑战 + 玩法说明 4 条 + 底栏导航 成绩/打卡/首页）
  │ 点击难度卡
  ▼
游戏页 startGame（顶栏 ‹返回 | 题号或已对数 | 倒计时或答对数 + 大白色卡片颜色词 word-text ≥96px +
                 反馈区 fb-area + 4 色按钮 color-grid 2×2（min-height 72px）+ 重新开始）
  │ 10 题答完 / 60 秒时间到 → finishGame
  ▼
结果浮层 showResult（本局结束 / 答对 N 或 N/10 题大字 / 『等级』/ 正确率%·答对·连续打卡 或 限时·答对·连续打卡 /
                    ★★★ / 新纪录横幅 / 再来一局·返回首页 / 📷 分享打卡）
  │ 点 📷 分享打卡
  ▼
分享浮层 openShare（canvas 1080×1920 分享卡片预览 + 长按保存提示 + 复制分享文案 / 返回结算）

底栏导航：成绩 viewHistory（最近 30 次，时间倒序）│ 打卡 viewCheckin（本月日历 + 连续天数）
```

- **顶栏（app-header）**：`renderHeader(title)` 渲染图标 + 标题 + 版本号（来自 `APP.meta.version`）。
- **首页 `viewHome`**：标题「选择难度」+ 提示「看字的颜色，不是字的意思！测测你的辨色反应」；
  3 张难度卡（`diff-card`），每张含难度按钮 + 该难度最佳成绩（`最佳 N 题`，未玩过显示「未挑战」）；
  下方「玩法说明」4 条（① 看字的颜色，不是字的意思 ② 比如「红」字是蓝色，要选蓝
  ③ 答对越多越好 ④ 挑战档 60 秒限时）。`viewHome` 先 `stopTimers()` 清理全部计时。
- **游戏页 `startGame`**：重置全部状态 → 出第一题 → `renderGame()` 渲染；
  挑战档 `limit > 0` 时 `startTimer()` 开限时；清空底栏（游戏页不走底部导航）。
- **游戏页顶栏（`game-top`）**：`‹ 返回`（回首页，本局不计成绩）| 中间 `game-name`
  （非限时 `第 X/10 题` / 限时 `已对 N 题`）| 右 `game-timer`
  （限时 `⏱ N 秒` 倒计时 / 非限时 `答对 N 题`）。
- **大颜色词卡（`word-card`）**：白底圆角大卡，`word-text` 96px 900 字重 + 深影描边
  （`text-shadow: 3px 3px 0 rgba(0,0,0,.12)`），`word-text.style.color = COLORS[state.color]` 即字色。
- **反馈区（`fb-area`）**：答对 `✓ 答对了！`（`fb-ok` 绿）/ 答错 `✗ 答案是「X」色`（`fb-no` 红）；
  空反馈时占位保持布局稳定（min-height 34px）。
- **4 色按钮（`color-grid`）**：`COLOR_KEYS` 遍历生成，红/蓝/绿白字、黄深字（`黄色按钮加 .yellow` 类），
  `min-height: 72px`、圆角 16、2×2 布局（`width: calc(50% - 6px)` + margin）。
- **结果浮层 `showResult`**：全屏半透明遮罩 + 白色卡片，含「本局结束」、
  大字成绩（简单/进阶 `答对 N/10 题` / 挑战 `N 题`）、`『等级』` 标签、统计
  （简单/进阶 `正确率%` + `答对` + `连续打卡`；挑战 `限时 60 秒` + `答对` + `连续打卡`）、
  星级、新纪录时「🎉 新纪录！」，以及「再来一局」「返回首页」「📷 分享打卡」三个按钮。
- **分享浮层 `openShare`**：`drawShareCard()` 绘制 canvas 卡片 → `toDataURL('image/png')`
  预览图 + 提示「📸 长按保存图片 · 发布笔记分享成就」+「复制分享文案」「返回结算」两按钮。
- **成绩页 `viewHistory`**：无记录时提示「暂无成绩，先来一局吧！」；否则按时间倒序列出
  最近 N 次（难度 / 日期·答对题数 / 答对题数 / 星级）。
- **打卡页 `viewCheckin`**：本月日历（已打卡日橙色点亮 + 今日红色描边）+ 连续打卡天数
  （≥7 天显示 🎉）；打卡由完成游戏自动触发，本页仅展示。

### 4.1 状态模型（main.js `state`）

```js
{
  level: 1,            // 难度 1/2/3
  total: 10,           // 本局总题数（挑战=0 表示限时）
  limit: 0,            // 限时秒（0=非限时；挑战=60）
  phase: 'idle',       // idle / playing / feedback / finish
  index: 0,            // 已答第几题（0 起）
  score: 0,            // 答对题数
  word: '',            // 当前词义（红/蓝/绿/黄）
  color: '',           // 当前字色（正确答案）
  startMs: 0,          // 限时开始时间戳（performance.now()）
  timeLeft: 0,         // 限时剩余秒（显示用）
  finished: false,     // 是否已结算
  timerId: null,       // 限时计时 interval
  endTimerId: null,    // 双保险 setTimeout（兜底结束）
  feedTimerId: null,   // 反馈进下一题 timer（350/900ms）
  resultOverlay: null, // 结算浮层引用
  shareOverlay: null,  // 分享浮层引用
  summary: null        // 结算摘要（分享/文案用）
}
```

## 5. 成绩持久化（localStorage key `redtools.colorreact.v1`）

```js
{
  version: 1,
  best:    { "1": null, "2": null, "3": null },  // 各难度最佳 {score, date}（score 更大覆盖）
  recent:  { "1": 0, "2": 0, "3": 0 },           // 各难度最近答对题数
  checkin: { dates: ["YYYYMMDD"], streak },      // 打卡日期（滚动 365 天）+ 连续天数
  history: [ {date, level, score, total, stars} ]  // 滚动 30 条，最新在前
}
```

- 读写均包 try/catch：`loadStore` 解析失败或首次打开返回默认结构；`saveStore` 写入失败静默。
- 启动时先 `loadStore()` 再 `saveStore()`（初始化写入，建立默认结构）。
- **最佳成绩**：`best[key]` 为空或 `score > best.score` 时覆盖为 `{score, date}` 并标记新纪录
  （结果浮层显示「🎉 新纪录！」）。**答对题数更大覆盖**（挑战=限时题数，简单/进阶=答对题数）。
- **最近成绩**：`recent[key]` 直接覆盖为本局答对题数。
- **历史**：`history.unshift(...)` 最新在前，`while (length > 30) pop()` 滚动保留 30 条；
  每条含 `level`（难度编号）、`score`（答对题数）、`total`（限时=score，非限时=10）、`stars`。

### 5.1 打卡逻辑（与系列内舒尔特方格/点击反应测试/手速挑战一致）

- 完成一局即自动打卡：`todayStr()` 生成 YYYYMMDD，不在 `dates` 则 push，然后 `sort()`；
  `while (dates.length > 365) dates.shift()` 滚动保留 365 天。
- 连续天数 `calcStreak(dates)`：从日期列表末尾向前回推，**含今天**往前数连续天数，
  跨天即断（缺一天 streak 归零）；结果写入 `checkin.streak`，打卡页渲染时实时重算。
- 打卡无手动入口，本工具「完成一局（10 题答完自动结算 或 60 秒限时跑完自动结算）」即点亮今日；
  中途返回不计成绩不打卡。

## 6. 关键实现点

### 6.1 状态机（`startGame` / `onPick` / `nextQuestion` / `finishGame`）

- `startGame`：`stopTimers()` 清全部计时 → 重置 level/total/limit/index/score → `phase='playing'` →
  出第一题 → 渲染游戏页 → 挑战档 `startTimer()`。
- `onPick`：唯一作答入口，前置守卫 `phase !== 'playing' || finished` 直接返回（防反馈期连点/防结算后误点）；
  判定 `key === state.color` 分入对/错两路（见 6.4），并同步更新顶栏计数。
- `nextQuestion`：`state.feedTimerId = null` → `finished` 守卫 → 非限时档答满 10 题即 `finishGame()`；
  否则 `index +1`、重出题、更新 `word-text` 颜色、复位反馈区、`phase='playing'` 回到可作答。
- `finishGame`：`finished` 守卫防重复结算 → `phase='finish'`、`stopTimers()` → 打卡 →
  评星级/等级 → 更新 best/recent/history → `saveStore()` → 组装 `state.summary` → `showResult()`。
- `state.summary` 为结算摘要（level/limit/total/score/stars/label/isNewBest），
  结算浮层与分享卡片/文案共用；`shareOpen` 标志防分享浮层重复打开。

### 6.2 出题逻辑（`genQuestion` / `randomOther`，含简单去重）

- `COLORS = { 红:'#e74c3c', 蓝:'#3498db', 绿:'#2ecc71', 黄:'#f1c40f' }`；
  `COLOR_KEYS = ['红','蓝','绿','黄']`（按钮遍历顺序与随机取词共用）。
- 随机词义 `w`：`COLOR_KEYS[Math.floor(Math.random()*4)]`；
  按难度决定字色 `c`：level 1 → `c = w`（字色=词义）；level 2 → `c = randomOther(w)`（字色≠词义）；
  level 3 → `Math.random() < 0.5 ? w : randomOther(w)`（混合约 1/2 一致）。
- `randomOther(w)`：其余 3 色随机取一（排除词义本身，保证进阶档绝不出现字色=词义）。
- **简单去重**：与上一题完全相同（`state.word === w && state.color === c`）时重抽，`guard ≤ 5` 次
  （低龄孩子害怕"连着一样的题"，去重让它每题都变一变；guard 上限防极端情况死循环）。

### 6.3 限时双保险 + 挑战档顶栏分工（`startTimer` / `updateTimer`）

- `startTimer`：挑战档专用。`performance.now()` 记 `startMs`；
  `setInterval(100ms)` 按 `remain = max(0, limit - (now-startMs)/1000)` 差值刷新（后台回来不漂移），
  `remain <= 0` 即 `finishGame()`；另设 `setTimeout(finishGame, limit*1000 + 50)` 兜底
  （+50ms 裕量，防 interval 被后台压制导致结算延迟）；`finished` 守卫防重复结算。
- `updateTimer(remain)`：`state.timeLeft = Math.ceil(remain)`，写 `#game-timer`
  「`⏱ N 秒`」；秒数不足 10 补零（`⏱ 05 秒`），避免个位/十位切换时文本宽度跳动错位。
- **顶栏分工（v1.0 显示冲突修复）**：挑战档 `game-timer` 由 interval **独占**倒计时，
  答对题数改显示在 `game-name`「已对 N 题」（`onPick` 单独更新 `game-name`），
  两处数字互不覆盖；非限时档则 `game-timer` 位置显示「答对 N 题」、`game-name` 显示题号
  「第 X/10 题」。不再存在"答对数与倒计时抢同一显示位"的冲突。

### 6.4 对错反馈（`flashBtn` + 反馈区 + 学习反馈计时）

- 答对：`flashBtn(key, true)` 按钮绿闪（`background:#2ecc71`）+ 反馈区 `✓ 答对了！`（`fb-ok`）+
  `setTimeout(nextQuestion, FEEDBACK_OK_MS=350)`；
- 答错：`flashBtn(key, false)` 按钮红闪（`#e74c3c`）+ 反馈区 `✗ 答案是「X」色`（`fb-no`，X=正确答案）+
  `setTimeout(nextQuestion, FEEDBACK_NO_MS=900)`——多停留 550ms，读清正确答案再进下一题（学习反馈）。
- `flashBtn`：记原背景色 → 设闪色 → 300ms 后复原；按钮 + 反馈文字均 **≤400ms** 光敏安全。
- 反馈期间 `phase='feedback'`，点击按钮无效（守卫拦截），防连点抢答/越题。

### 6.6 复制文案（textarea + execCommand，Chrome 61 兼容）
