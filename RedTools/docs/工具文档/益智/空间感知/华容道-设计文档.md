# 华容道 — 设计文档

> 益智 · 空间感知 子系列 P2 收官款。经典滑块拼图，**三国卡通角色**（程序化 SVG 零素材）。
> 产品矩阵 §4.5「华容道：滑块拼图，经典布局」（K4-6，L3）。
> 更新：2026-09-19

## 1. 定位与目标

- **玩法**：经典华容道滑块拼图。4×5 盘面，滑块只能沿空白格平移，
  **目标将「曹操」2×2 大块移到盘面底部中央出口**。
- **目标用户**：K4-6（约 8-12 岁），空间规划 + 策略思考训练。
- **特色**：7 个三国角色化滑块（曹操/关羽/张飞/赵云/马超/黄忠/小兵×4），
  **Q 版卡通头像**为程序化 SVG 绘制（零图片素材、风格统一、Chrome 61 兼容、zip 极小）。

## 2. 关卡数据（build_levels.py 生成）

### 2.1 布局与棋子

- 盘面：**4 列 × 5 行**，出口在底部中央（曹操 2×2 左上角抵达 (3,1) 即胜，占据 3-4 行 1-2 列）。
- 棋子尺寸：
  | 棋子 | 尺寸 | 角色 |
  |------|------|------|
  | 曹操 | 2×2 | 主目标大块 |
  | 关羽 | 2×1（横） | 曹操正下方横档 |
  | 张飞/赵云/马超/黄忠 | 1×2（竖） | 四角将 |
  | 小兵 ×4 | 1×1 | 填空 |

- 4 关经典布局（字符画：c=曹 g=关 z=张 y=赵 m=马 h=黄 b=兵 .=空）：
  | 关 | 名称 | 布局 | 最少步数(BFS) |
  |----|------|------|------|
  | 1 | 近在咫尺 | `.cc.` / `mcch` / `mggh` / `zbby` / `zbby` | 114 |
  | 2 | 兵分三路 | `mcch` / `mcch` / `zbby` / `zggy` / `b..b` | 99 |
  | 3 | 层层设防 | `ccmh` / `ccmh` / `zbby` / `zggy` / `b..b` | 100 |
  | 4 | 横刀立马 | `zccy` / `zccy` / `mggh` / `mbbh` / `b..b` | 116 |

### 2.2 BFS 求解（星级基准）

- **口径**：单格步进（点箭头一次 = 1 步），与游戏交互一致。
- **同型归一化剪枝**：四将（1×2）位置排序、四兵（1×1）位置排序 → 消除 4!×4! 状态爆炸，
  每关仅探索 ~2.4 万态（秒级）。
- **星级**：3 星 ≤ 1.5×b；2 星 ≤ 2.5×b；其余 1 星（b=最少步数）。
  （横刀立马 116 步 = 经典口径，与历史记录一致，验证求解正确）
- 输出 `src/assets/levels.js`：`window.HRD = { levels: [ {id,name,board,min,star3,star2} ] }`。

## 3. 角色视觉（characters.js — 程序化 SVG 零素材）

### 3.1 设计要点

- 7 个角色 = 7 个 draw 函数，返回以 (0,0) 为中心、`viewBox="-50 -50 100 100"` 的 `<svg>`。
- **高头饰角色**（曹操冕冠/赵云银盔红缨/马超紫金冠雉翎）用 `tall` viewBox
  `-50 -70 100 120`（顶部留 20 单位），防止头饰被 SVG 画布裁切（曾踩坑：头饰顶到 -64 被裁掉）。
- 通用部件函数：head（脸+耳）/ roundEye / slantEye / brow / blush / smile / mouthLine /
  body（袍+领）/ bodySoldier（兵袍），保证风格统一。

### 3.2 角色差异化造型（Q 版三国辨识特征）

| 角色 | 肤色 | 头饰 | 胡须 | 袍色 | 辨识特征 |
|------|------|------|------|------|----------|
| 曹操 | 白净 | 黑色冕冠 + 金边 + 前后垂旒 + 顶珠 | 长黑须分叉垂胸 | 暗红 | 帝王威严（细长眼 + 八字胡） |
| 关羽 | 枣红 | 绿头巾（包髻 + 巾结） | 美髯长垂胸 | 深绿 | 丹凤眼 + 卧蚕眉 |
| 张飞 | 深褐（提亮过） | 黑头巾 + 结 | 络腮胡（浓密） | 深棕 | 豹眼圆瞪（大白眼+黑瞳）+ 浓眉 |
| 赵云 | 白净 | 亮银盔 + 三叉红缨 + 护耳 | 无 | 银白 | 剑眉 + 明亮圆眼 |
| 马超 | 白净 | 紫金冠 + 金珠 + 金色雉翎 | 无 | 紫 | 金冠雉翎醒目 |
| 黄忠 | 黄褐 | 黄头巾 + 巾沿 | 白山羊胡 + 白眉 | 橙 | 老将白须 |
| 小兵 | 白净 | 蓝头巾 | 无 | 土黄 | 憨笑（蓝巾与曹操红袍区分） |

### 3.3 视觉迭代记录

- **头饰裁切**（首次质检）：曹操流苏/赵云红缨/马超雉翎顶到 -64 超出 viewBox 顶部 -50 → 高头饰角色
  用 tall viewBox（-70 顶部）+ 低髻角色头巾结压回 -49 内。
- **辨识度优化**（二次质检）：张飞深肤+黑发对比不足 → 肤色提亮 `#7a5238→#9c6a48`、豹眼加大加白、
  浓眉加深；小兵红巾与曹操红袍混淆 → 红巾改**蓝巾** + 灰蓝袍改**土黄袍**。
- 全部经 look_at 多模态质检通过（角色清晰、风格统一、头饰完整）。

## 4. 游戏逻辑（main.js）

### 4.1 交互（低龄友好，点选优于拖拽）

- **点选棋子** → 紫色描边高亮；**可移动方向**显示紫色圆箭头（▲▼◀▶）覆盖在棋子边缘；
  点箭头 → 棋子移动 1 格（步数 +1，计时持续）。
- **滑动手势**：按住棋子沿可移动方向滑动 → 同样移动 1 格。
- **点击不可移动棋子** → 抖动反馈（350ms，光敏安全），不进入选中态。
- 点空白取消选中；「‹ 选关」返回首页。
- 移动判定：边界 + 与他块重叠检查（occupancy 哈希表）。

### 4.2 通关与结算

- 曹操抵达 (3,1)（底部中央 2×2 出口区）→ 结算页：
  🎉 曹操脱困！+ 关卡名 + 星级（⭐）+ 用时 + 步数 + 参考最少步数 + 本关最佳 + 打卡。
- 星级按 §2.2 BFS 基准。

### 4.3 进度与存储（localStorage `redtools.hrd.v1`）

- `best`: 各关最佳（moves/ms/stars/date）；`history`: 滚动 30 条；`checkin`: 打卡日期 + 连续天数。
- **逐关解锁**：第 1 关开放；第 N 关通关后解锁 N+1（卡片显示 🔒 +「先通关上一关」）。
- 打卡：通关即记录今日 + 首页底部「🔥 连续打卡 N 天」。

### 4.4 测试钩子

`window.__hrd`：state/levels/startLevel/parseBoard/canMove/movableDirs/movePiece/isWin/
occupancy/store/doCheckin/render/finishLevel（冒烟与调试用）。

## 5. 构建与合规

- `tools.py`：`ToolConfig(series="益智", subgroup="空间感知", tool="华容道", version="1.0",
  datasource="static")`。
- 构建：`python build_all.py --tool 华容道` → `publish/益智/华容道.zip`（0.02 MiB）。
- 审计：dist + publish zip 各 **7 files 0 warning** PASS。
- 合规自查：zip 白名单全过（js/png/css/html）；唯一 http 引用为 SVG xmlns 命名空间声明
  （非外部资源）；无内联脚本/eval/fetch/onclick；CSP 安全。
- Chrome 61 兼容：经典脚本 ES2017、无 flex `gap`（间距用 margin/padding）、touch 事件
  passive、`env(safe-area-inset-*)`、动画 ≤400ms。
