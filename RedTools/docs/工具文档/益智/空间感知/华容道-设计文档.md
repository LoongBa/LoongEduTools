# 华容道 — 设计文档

> 益智 · 空间感知 子系列 P2 收官款。经典滑块拼图，**三国卡通角色**（AI 生成头像 + SVG 兜底）。
> 产品矩阵 §4.5「华容道：滑块拼图，经典布局」（K4-6，L3）。
> 更新：2026-09-19

## 1. 定位与目标

- **玩法**：经典华容道滑块拼图。4×5 盘面，滑块只能沿空白格平移，
  **目标将「曹操」2×2 大块移到盘面底部中央出口**。
- **目标用户**：K4-6（约 8-12 岁），空间规划 + 策略思考训练。
- **特色**：7 个三国角色化滑块（曹操/关羽/张飞/赵云/马超/黄忠/小兵×4），
  **Q 版卡通头像**为 AI 生成（SenseNova U1.5）+ PIL 抠图透明 WebP（7 张共 179 KB），
  SVG 程序化头像作加载失败兜底（v1.1）。

## 2. 关卡数据（build_levels.py 生成）

### 2.1 布局与棋子

- 盘面：**4 列 × 5 行**，出口在底部中央（曹操 2×2 左上角抵达 (3,1) 即胜，占据 3-4 行 1-2 列）。
- 棋子尺寸：
  | 棋子 | 尺寸 | 角色 |
  |------|------|------|
  | 曹操 | 2×2 | 主目标大块 |
  | 关羽 | 2×1（横） | 曹操正下方横档 |
  | 张飞/赵云/马超/黄忠 | 1×2（竖） | 四角将 |
  | 小兵 ×4 | 1×1 | 填空 |

- 4 关经典布局（字符画：c=曹 g=关 z=张 y=赵 m=马 h=黄 b=兵 .=空）：
  | 关 | 名称 | 布局 | 最少步数(BFS) |
  |----|------|------|------|
  | 1 | 近在咫尺 | `.cc.` / `mcch` / `mggh` / `zbby` / `zbby` | 114 |
  | 2 | 兵分三路 | `mcch` / `mcch` / `zbby` / `zggy` / `b..b` | 99 |
  | 3 | 层层设防 | `ccmh` / `ccmh` / `zbby` / `zggy` / `b..b` | 100 |
  | 4 | 横刀立马 | `zccy` / `zccy` / `mggh` / `mbbh` / `b..b` | 116 |

### 2.2 BFS 求解（星级基准）

- **口径**：单格步进（点箭头一次 = 1 步），与游戏交互一致。
- **同型归一化剪枝**：四将（1×2）位置排序、四兵（1×1）位置排序 → 消除 4!×4! 状态爆炸，
  每关仅探索 ~2.4 万态（秒级）。
- **星级**：3 星 ≤ 1.5×b；2 星 ≤ 2.5×b；其余 1 星（b=最少步数）。
  （横刀立马 116 步 = 经典口径，与历史记录一致，验证求解正确）
- 输出 `src/assets/levels.js`：`window.HRD = { levels: [ {id,name,board,min,star3,star2} ] }`。

## 3. 角色视觉（AI 生成头像 + SVG 兜底）

### 3.1 头像管线（v1.1 升级，2026-09-19）

- **生成**：SenseNova U1.5 文生图（1024×1024），统一 Q 版卡通风格提示词框架
  （大头小身半身像/正面/纯白背景/无文字无水印），逐角色注入三国辨识特征。
- **质检**：look_at contact sheet 批量质检 → 张飞「肤色全黑」（过度字面化"黑脸"）重生成
  （正常偏深小麦色 + natural skin tone）；关羽/黄忠肤色偏橙 → 重生成统一自然肤色。7/7 通过。
- **抠图**：PIL 白底→透明（亮度>232 且低饱和度=透明，215~232 半透明羽化）+ 自动裁边
  居中 → 320×320。边缘白边残留极少（赵云红缨尖端 1-2px，肉眼不可见）。
- **压缩**：透明 **WebP**（Chrome 61 原生支持、zip 白名单含 webp），quality=82 → **7 张共 179 KB**
  （PNG 888 KB 的 -80%），zip 总 0.19 MiB。
- **存储**：`src/assets/faces/<key>.webp`（caocao/guanyu/zhangfei/zhaoyun/machao/huangzhong/soldier）。
- **渲染**：滑块头像 `<img class="tile-img" src="./assets/faces/<key>.webp">`（object-fit: contain），
  **加载失败自动降级 SVG**（img error 事件 → 插入 characters.js 绘制的 SVG，无内联事件，符合 CSP）。

### 3.2 角色差异化造型（三国辨识特征）

### 3.3 SVG 兜底层（原程序化头像，保留为降级方案）

- `characters.js`：7 个 draw 函数，`viewBox="-50 -50 100 100"`，通用部件函数保证风格统一；
  高头饰角色用 tall viewBox `-50 -70 100 120`（防头饰裁切）。
- 头饰裁切/辨识度优化等 SVG 迭代记录保留（见 git 历史），现仅作 WebP 加载失败时兜底。

## 4. 游戏逻辑（main.js）

### 4.1 交互（低龄友好，点选优于拖拽）

- **点选棋子** → 紫色描边高亮；**可移动方向**显示紫色圆箭头（▲▼◀▶）覆盖在棋子边缘；
  点箭头 → 棋子移动 1 格（步数 +1，计时持续）。
- **滑动手势**：按住棋子沿可移动方向滑动 → 同样移动 1 格。
- **点击不可移动棋子** → 抖动反馈（350ms，光敏安全），不进入选中态。
- 点空白取消选中；「‹ 选关」返回首页。
- 移动判定：边界 + 与他块重叠检查（occupancy 哈希表）。

### 4.2 通关与结算

- 曹操抵达 (3,1)（底部中央 2×2 出口区）→ 结算页：
  🎉 曹操脱困！+ 关卡名 + 星级（⭐）+ 用时 + 步数 + 参考最少步数 + 本关最佳 + 打卡。
- 星级按 §2.2 BFS 基准。

### 4.3 进度与存储（localStorage `redtools.hrd.v1`）

- `best`: 各关最佳（moves/ms/stars/date）；`history`: 滚动 30 条；`checkin`: 打卡日期 + 连续天数。
- **逐关解锁**：第 1 关开放；第 N 关通关后解锁 N+1（卡片显示 🔒 +「先通关上一关」）。
- 打卡：通关即记录今日 + 首页底部「🔥 连续打卡 N 天」。

### 4.4 测试钩子

`window.__hrd`：state/levels/startLevel/parseBoard/canMove/movableDirs/movePiece/isWin/
occupancy/store/doCheckin/render/finishLevel（冒烟与调试用）。

## 5. 构建与合规

- `tools.py`：`ToolConfig(series="益智", subgroup="空间感知", tool="华容道", version="1.0",
  datasource="static")`。
- 构建：`python build_all.py --tool 华容道` → `publish/益智/华容道.zip`（0.19 MiB，含 7 张角色 WebP）。
- 审计：dist + publish zip 各 **14 files 0 warning** PASS。
- 合规自查：zip 白名单全过（js×4/webp×7/png/css/html）；唯一 http 引用为 SVG xmlns 命名空间
  声明（非外部资源）；**无内联事件**（头像错误处理用 addEventListener 而非 onerror=）；无
  eval/fetch；CSP 安全。
- Chrome 61 兼容：经典脚本 ES2017、透明 WebP 原生支持、无 flex `gap`（间距用 margin/padding）、
  touch 事件 passive、`env(safe-area-inset-*)`、动画 ≤400ms。
