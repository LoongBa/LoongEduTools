## 1. 背景与目标

### 1.1 背景

走迷宫已完成编程核心概念七块闭环：顺序（v1.0）→ 循环（v1.1 隐式 chip ×N）→ 条件（v1.3）→ 调试（v1.4）→ 分支（v1.5 if）→ 参数化（v1.6 steps）→ 循环块组合（v1.7 loop）。
v1.7 循环块 body 内**禁 loop**（MVP 单层）。v1.8 放开此限制：**循环块内可再嵌循环块**（嵌套循环）——
教学编程核心的**嵌套结构**（循环套循环 = 二维重复，如 3×4 网格逐格清扫）。

### 1.2 教学定位

- v1.7 `🔁×N {组指令}` = 一组动作重复 N 次（循环 = 自动化）
- **v1.8 `🔁×M {🔁×N {指令}}`** = 一组动作重复 N 次，整套再重复 M 次（**嵌套循环** = 二维自动化）
- 教学价值：孩子理解**嵌套结构**——外层循环每轮执行一次内层循环的完整 N 次
- 类比：乘法表 / 网格清扫（行循环 × 列循环）

### 1.3 与 D5「循环指令」区别

D5 独立工具 MVP 单层循环。走迷宫 v1.7 已支持循环块+if/steps 组合，v1.8 再加**嵌套循环块**——
走迷宫控制结构组合教学进阶（循环×循环）。

### 1.4 目标

| 项 | 说明 |
|---|---|
| 教学目标 | **嵌套循环**：循环块内嵌循环块（二维重复/嵌套结构） |
| 玩法 | 循环编辑区内可添加 `🔁 循环`（body 内嵌 loop，最多嵌套 2 层） |
| 合规 | 有标准答案（嵌套次数确定 → 执行确定 → 盘面判定），合规安全区 |
| 合规红线 | 不引入 PK/排行榜；嵌套循环是编程教学（嵌套结构/二维自动化），非"爽快"玩法 |

## 2. 变更设计

### 2.1 放开 body 内嵌 loop + loopDepth 守卫 + renderLoopBody 适配（Oracle I2/I3 修订）

**现状**（v1.7）：renderLoopBody 的 addBtns 不含 CMD_LOOP（body 内禁 loop）；renderLoopBody 的 lbl/click 未处理 loop chip。

**v1.8 变更**：

**(a) body 添加按钮加入 CMD_LOOP + loopDepth 守卫**（限制嵌套 ≤2 层）：
```js
/* v1.8：编辑栈中 loop 类型帧数（嵌套循环深度） */
function loopDepth() {
  var n = 0;
  for (var i = 0; i < editStack.length; i++) {
    if (editStack[i].cmd && editStack[i].cmd.id === 'loop') { n += 1; }
  }
  return n;
}
// renderLoopBody 添加 loop 按钮时：
if (a.id === 'loop') {
  if (loopDepth() >= 2) {
    var fb = document.getElementById('game-feedback');
    if (fb) { fb.textContent = '⚠ 循环嵌套最多 2 层'; fb.className = 'game-feedback miss'; }
    return;
  }
  loopCmd.body.push({ id: 'loop', rep: 2, body: [] });
}
```

**(b) renderLoopBody 的 lbl 计算加 'loop' 分支**（Oracle I2）：
```js
var isLoop = bc.id === 'loop';
var lbl = bc.id === 'fwd' ? '↑' : (bc.id === 'left' ? '↰' : (bc.id === 'right' ? '↱'
  : (bc.id === 'block' ? '🧱' : (bc.id === 'steps' ? '➡走' + (bc.steps || 1) + '步'
  : (bc.id === 'loop' ? '🔁×' + (bc.rep || 2) : (bc.id === 'if' ? '❓if' : '?'))))));
var chip = makeEl('span', 'cmd-chip small' + (isIf ? ' if' : '') + (isLoop ? ' loopb' : ''), (bi + 1) + '.' + lbl + repTxt);
```

**(c) renderLoopBody 的 click 加 loop 路由**（Oracle I2）：
```js
chip.addEventListener('click', function (ev) {
  ev.stopPropagation();
  if (state.execLock) { return; }
  if (isIf) { openNestedEditCtx(bc); }
  else if (isLoop) { openNestedEditCtx(bc); }   // v1.8 新增：内层 loop 打开编辑区
  else if (isSteps) { bc.steps = ((bc.steps || 1) % 9) + 1; renderEditCtx(); }
  else { var next = ((bc.rep || 1) % 4) + 1; bc.rep = next; renderEditCtx(); }
});
```

**(d) 范围限制声明**（Oracle I3）：**仅支持 loop-in-loop**（循环体内直接嵌循环）。
**loop-in-if-branch 不支持**——renderBranchCol（if 的 then/else 编辑）的 addBtns **不加 CMD_LOOP**，
避免 ifDepth+loopDepth 组合守卫复杂化。此限制在 UI/文档中显式体现。

**editCtx 嵌套编辑**：body 内 loop chip 点击 → openNestedEditCtx（现有机制支持任意 cmd 入栈；
loopDepth 守卫在 ADD 时拦截，openNestedEditCtx 无需重复检查）。loop 内嵌 loop 渲染相同
（renderEditCtx 按 `cmd.id==='loop'` 渲染单栏）。

### 2.2 执行器：嵌套循环（工作队列天然支持，Oracle 推演验证）

**Oracle 已逐步推演证实**（loop rep=2, body=[loop rep=2, body=[fwd]] → fwd 执行 4 次）：
- 外层每轮插入内层 loop → 内层 loop 完整执行 rep 次 → 外层下一轮
- **B1 递归覆盖内层 _loopLeft**：execLoop 的 `resetLoopLeft(cmd.body)` 递归清内层 loop._loopLeft（步 6 清 L2._loopLeft=undefined，步 7 重新初始化=2）
- **I-new _execTop 继承**：内层 loop._execTop = 外层 loop._execTop（无条件覆盖，curTop 始终=外层 loop）
- **MAX_QUEUE 安全**：2 层嵌套峰值 queue ~10-15，远低于 500

**无需改 execLoop/resetLoopLeft**（现有实现已正确）。

### 2.3 totalSteps 递归（已支持嵌套，口径确认）

**现状**（v1.7）：`loop: n += 1 + totalSteps(body)` 递归——嵌套 loop 自然递归覆盖。
- `🔁×2{🔁×2{fwd}}` → totalSteps = 1 + (1 + 1) = 3（外层 1 + 内层 1 + fwd 1，**不乘 rep**）
- 编写量语义 = 孩子写的块数（3 块），与教学一致

### 2.4 关卡设计（Oracle B1/S4/S5 修订）

v1.8 新增 **10 关（196-205）**，嵌套循环专关，**网格 M×N ≥ 5**（确保展开/嵌套比 > 1.5）：

| 197 | 二维直推2 | `🔁×2 {🔁×4 {fwd}}`（推箱 2×4 格） | 2×4 | 8/3 = 2.7 ✅ |
| 198 | 网格清扫 | `🔁×3 {fwd 🔁×2 {right fwd} left}`（行清扫） | 3×2 | 6/4 = 1.5 ⚠️ |

> 关 202（2×2）为**概念教学关**，不强求星级激励（Oracle S4）。

**b 值口径（Oracle B1 修订）**：196-205 新关 `b` = **嵌套解 totalSteps**（非 BFS 展开长度）！
- 展开写 totalSteps = b_expanded（M×N）> 1.5×b_nested → 2★
- 嵌套写 totalSteps = b_nested → 3★（激励成立）
- 例：关 196（3×3）b=3；展开写 9 > 1.5×3=4.5 → 2★；嵌套写 3 ≤ 4.5 → 3★ ✅
- 1-195 旧关 b 不动（无 loop，口径一致）
