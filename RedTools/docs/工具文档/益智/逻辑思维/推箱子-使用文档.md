# 推箱子 — 使用文档

> 经典益智推箱子：把箱子推到黄色圆点上即可过关，锻炼空间规划与逆向思维。
> 适用：手机（触屏滑动）/ 电脑（方向键或点击按钮）。
> 版本：v1.0 · 更新：2026-09-18

---

## 1. 怎么练

1. **滑动屏幕**（手机）或按**方向键 / WASD**（电脑）或点击棋盘下方**方向按钮**，控制小人移动。
2. 走到箱子旁边继续往箱子方向走，就能**推动箱子**。
3. 把**所有箱子都推到黄色圆点**上，就过关啦！
4. 过关后按星级、通关数记录成绩，并自动解锁下一关。

## 2. 练习规则

| 规则 | 说明 |
|---|---|
| 目标 | 把所有箱子推到黄色圆点（目标点）上 |
| 推动 | 一次只能推一个箱子，**不能拉**；箱子不能穿过墙或另一个箱子 |
| 胜利 | 全部箱子入坑 → 弹出庆祝页（星级 + 统计 + 下一关） |
| 死锁 | 箱子推到角落里卡死时，用「撤销」或「重开」解决 |
| 技巧 | 推之前先想好路线，别把箱子推到角落或墙边，否则很难再推出来 |

## 3. 界面说明

- **选关**：左上角进入关卡列表；已通关的关卡显示 ★ 星级，未解锁的显示 🔒。
- **第 X / 60 关 · 最优 N 推**：当前关卡号与**理论最少推动数**（星级评定基准）。
- **移动 / 推动**：本次移动步数与推动箱子次数。
- **↺ 撤销**：退回上一步（可连续撤销）；**↻ 重开**：本关重新开始。
- **方向按钮**：十字布局 ▲ ◀ ▼ ▶（与模拟器/无键盘设备兼容）。

## 4. 成绩与打卡

- **星级**（按最少推动数评定，宽松友好）：
  - ★★★：推动数 ≤ 最优的 1.5 倍
  - ★★：推动数 ≤ 最优的 2.5 倍
  - ★：过关即可
- 每过一关即点亮**今日打卡**，页面底部显示连续打卡天数。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- 练习会**自动保存当前进度**：中途退出后重新打开，会恢复到上次的关卡与步数。
- 推错了？点「↺ 撤销」一步一步回退，或者「↻ 重开」直接重来。
- 音效由程序合成（无需网络/音频文件），设备静音时自动无声运行，不影响练习。

## 6. 常见问题

**Q：为什么滑动没反应？**
确保手指从棋盘区域内滑动，且滑动手势超过一定距离（约 24px），太短会被识别为误触忽略。

**Q：箱子推不动了怎么办？**
箱子前方可能有墙或另一个箱子挡着；如果推到了死胡同，用「撤销」或「重开」。

**Q：关卡会丢吗？**
进度保存在设备浏览器 localStorage，换设备/清理浏览器数据会清空。
