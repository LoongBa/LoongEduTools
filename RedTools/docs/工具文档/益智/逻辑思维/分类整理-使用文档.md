# 分类整理 — 使用文档

> 分类归纳训练：把底部乱放的物品点选进正确的盒子里，全部放对就过关，锻炼观察与分类归纳能力。
> 适用：手机 / 电脑（点选即放，无需拖拽）。
> 版本：v1.0 · 更新：2026-09-19

---

## 1. 怎么练

1. 打开工具，在**难度选择页**选一个难度：简单 2 类 6 件 / 普通 3 类 9 件 / 困难 4 类 12 件。
2. **点选一个物品**（底部物品格），选中后物品会带**橙色描边**高亮。
3. **点选正确的类别盒子**（顶部一排带图标和名字的盒子）：
   - 放对：物品缩小淡出消失，盒子变绿确认，计数 +1；
   - 放错：盒子红闪，物品留在原地，错误次数 +1。
4. 所有物品都放进正确的盒子，就过关啦！每次进入都是**随机抽取的新物品组合**（不会背题），过关后按用时与错误次数记录成绩。

## 2. 练习规则

| 规则 | 说明 |
|---|---|
| 目标 | 把全部物品放进正确的类别盒子 |
| 操作 | 点选物品 → 点选盒子（v1.0 无拖拽，点按即放） |
| 放对 | 物品缩小淡出，盒子绿色确认，归位计数 +1 |
| 放错 | 盒子红闪，物品留在原地，错误次数 +1 |
| 出题 | 从 8 类图标池随机抽类别、每类随机抽 3 个图标、再整体洗牌，每局全新 |
| 星级 | 0 错 3 星 / 1~2 错 2 星 / ≥3 错 1 星 |
| 技巧 | 先看盒子名字想好类别再放，减少试错 |

## 3. 界面说明

- **难度选择页**：三个难度卡片，显示该难度**最佳成绩**（星级 · 用时 · 错误次数），底部是打卡日历入口。
- **顶栏**：`← 返回`、当前难度名、`⏱ 用时`（**第一次点选物品后**才开始计时）。
- **类别盒**：白底圆角卡片，顶边是类别主题色，含代表性图标 + 类别名 + `已归位/3` 计数。
- **物品格**：底部 3 列正方形格子；**选中**的物品橙色描边；放对的物品缩小淡出消失。
- **错误计数**：练习页底栏 `❌ N` 实时显示本局放错次数。
- **提示行**：练习页中部提示「点选一个物品，再放进正确的盒子」。

## 4. 成绩与打卡

- **星级**（按本局错误次数评定，宽松友好）：
  - ★★★：一次都没放错
  - ★★：放错 1~2 次
  - ★：放错 3 次及以上（过关即有）
- **防卡提示**：同一局放错 **3 次及以上**，当前选中物品的**正确盒子会温和闪烁**，提醒"它该进哪个盒子"；放对后提示自动消失。这只是提示，不会自动替孩子放。
- 每过关一局即点亮**今日打卡**；打卡日历显示本月打卡与连续天数（连续 7 天及以上有 🎉）。
- 各难度分别记录**最佳成绩**（错误少优先，错误相同比用时短）；**最近用时**与最近 **30 局**成绩记录自动保存。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- 点错物品了？**再点一下同一个物品**取消选中，或直接点另一个物品切换。
- 忘了先选物品就点盒子？会提示「先选一个物品，再放进盒子」，不扣分、不开始计时。
- 想换个组合？练习中点「重新开始」用相同难度重抽一局，或点「返回难度」回难度页换档。
- 计时从第一次点选物品才开始，观察物品的时间不计入成绩。
- 音效由程序合成（无需网络/音频文件），设备静音时自动无声运行，不影响练习。

## 6. 常见问题

**Q：没选物品直接点盒子会怎样？**
不会扣分，也不会开始计时，只会提示「先选一个物品，再放进盒子」，等孩子选好再放即可。

**Q：错误次数怎么算？**
每放错一次（放进不正确的盒子）计 1 次，底栏实时显示。错误次数决定星级：0 错 3 星、1~2 错 2 星、3 次及以上 1 星。同一件物品放错多次会重复累计。

**Q：成绩怎么清除？**
目前没有「清空成绩」按钮。成绩保存在设备浏览器的 localStorage 中，清除浏览器数据即可清空；换设备不会同步，请注意。

**Q：为什么有时候盒子会自己亮？**
放错 3 次及以上后，当前选中物品的正确盒子会温和闪烁，这是给孩子"该放哪"的引导提示，放对后自动消失，不会影响成绩。

**Q：适合几岁的孩子？**
定位低龄（preK 到小学低年级）。「简单 2 类 6 件」适合刚开始接触分类的孩子；「普通 3 类 9 件」适合熟悉练习方式后进阶；「困难 4 类 12 件」适合小学低年级挑战。点按式操作、无拖拽，孩子容易上手。
