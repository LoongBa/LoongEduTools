# 因果排序 — 使用文档

> 看图排顺序小练习：把打乱的图片卡片按「事情发生的先后」排好，先发生的放前面、后发生的放后面，全部排对就过关，锻炼观察与因果顺序推理能力。
> 适用：手机 / 电脑（点选两张卡片交换位置）。
> 版本：v1.0 · 更新：2026-09-19
> ⚠️ Chrome 61 / Android 8.1 / 真机 WebView 未实测。

---

## 1. 怎么练

1. 打开工具，在**难度选择页**选一个难度：简单 3 步 / 普通 4 步 / 困难 5 步。
2. 进入练习后，会看到几张打乱的**图片卡片**，顶上写着这局的主题，比如「把『植物生长』按顺序排好」。
3. **点一张卡片**，它会带**橙色描边**（选中）；**再点另一张**，两张卡片交换位置（卡片轻轻跳一下，步数 +1）。
4. 一张一张换，直到**全部卡片按先后顺序排好**（第一张最先发生、最后一张最后发生），就过关啦！
5. 过关后按**提示次数与步数**评定星级，记录最佳成绩并点亮今日打卡。

## 2. 练习规则

| 规则 | 说明 |
|---|---|
| 目标 | 把打乱的步骤卡片按因果 / 时间先后顺序全部排好（槽位顺序 = 正确顺序） |
| 操作 | 点一张卡片选中 → 点另一张交换；点同一张取消选中 |
| 步数 | 每交换一次计 1 步，步数越少越好（星级依据） |
| 排错 | **没有惩罚**：排序没有「错动作」，任何交换都被接受，继续换到对为止 |
| 提示 | 💡 提示：第一张排错的卡片**高亮 1.2 秒**（只告诉你看哪张，不帮你换） |
| 星级 | 0 提示且步数 ≤2N−1 → 3★（3 步≤5 / 4 步≤7 / 5 步≤9）；提示 ≤1 且步数 ≤3N → 2★；其余 1★（用过提示最高 2★） |
| 出题 | 每局从序列库随机抽一条序列并打乱，每次进入可能不同 |

## 3. 界面说明

- **难度选择页**：三个难度卡片，显示难度名、步数、这局可能的**序列主题**，以及该难度**最佳成绩**（星级 · 用时 · 步数 · 提示）；底部是打卡日历入口。
- **顶栏**：`← 返回`、当前难度名与**序列名**（如「简单 · 3 步 · 昼夜三部曲」）、`⏱ 用时`（**进入练习页即开始**计时）。
- **题面**：卡片上方一句话「把『序列名』按顺序排好」，提示你这局排的是什么。
- **卡片**：一张卡片 = 一步「事情」，SVG 小图画展示这一步的样子（比如植物生长：播种 → 发芽 → 长叶 → 开花 → 结果）。选中卡片橙色描边。
- **操作行**：`💡 提示` 按钮 + `步数 n · 提示 n` 实时统计。
- **练习底栏**：返回难度 / 重新开始 / 步数 n。
- **结算浮层**：过关后展示星级、用时、步数、提示次数与今日打卡。

## 4. 成绩与打卡

- **星级**（按提示与步数两个指标，宽松友好）：
  - ★★★：没点过提示，且步数 ≤ 2×N−1（3 步局 ≤5 步、4 步局 ≤7 步、5 步局 ≤9 步）；
  - ★★：提示 ≤1 次 且 步数 ≤ 3×N（3 步局 ≤9 步、4 步局 ≤12 步、5 步局 ≤15 步）（**点过提示最高 2 星**）；
  - ★：其余情况（过关即有）。
- **提示**：点「💡 提示」，第一张排错的卡片会**高亮 1.2 秒**，告诉你"这张位置不对"。提示**不会帮你换**，只是提醒你重点看哪张；用提示会**封顶 2 星**，卡住时再点。
- 每过关一局即点亮**今日打卡**；打卡日历显示本月打卡与连续天数（连续 7 天及以上有 🎉）。
- 各难度分别记录**最佳成绩**（星级高优先，同星级比用时短）；**最近用时**与最近 **30 局**成绩记录自动保存。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- 点错了？**再点一下同一张卡片**取消选中，或直接点另一张切换。
- 先看顶上的序列名（如「蝴蝶成长」），想想"这件事的第一步是什么样子"，再动手换。
- 动手前先**在心里排一遍顺序**：谁最先发生、谁最后发生；有把握再点，步数少才能拿 3★。
- 卡住的时候用一次提示：它指出第一张排错的位置，但不帮你换，看完自己动手。
- 想熟悉规则，从「简单 3 步」练起（昼夜 / 花开两三个步骤很好懂）；熟悉了再挑战 4 步、5 步。

## 6. 常见问题

**Q：排错了会不会扣分、会不会算失败？**
不会。排序没有"错动作"，怎么换都行，只要最后顺序对就过关。步数只是记录你换了几次，步数越少星级越高。

**Q：提示能不能一直用？会不会掉星？**
可以点。提示会把第一张排错的卡片高亮 1.2 秒提醒你。但**用一次提示，这局最高就只能拿 2 星**，所以能自己排就先自己排。

**Q：重新开始会换题目吗？**
会。点「重新开始」会重新抽一条序列（或同一条重新打乱），又是一局新题，不用担心背答案。

**Q：有的卡片画得看不懂怎么办？**
卡片是"一件事"里的一个步骤（比如蝴蝶成长：虫卵、毛毛虫、蛹、蝴蝶）。先看序列名，再按常识想"这件事从哪一步开始"；实在卡住可以用提示指出第一张错位卡。

**Q：适合几岁的孩子？**
定位 K1-3（幼儿园中大班）到 K4-6（小学中高年级）。「简单 3 步」看图画排先后（昼夜 / 花开），低龄也能练；「普通 4 步」「困难 5 步」排生活流程和自然成长，适合进阶和挑战，家长一起练也不无聊。
