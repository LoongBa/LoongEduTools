## 2. 玩法设计

### 2.1 规则

- 顶部一排 **2~4 个类别盒**（代表性图标 + 类别名 + 归位计数），底部是打乱的**物品格**（3 列正方形）。
- **点选**一个物品 → **点选**一个类别盒：放进**正确**盒子 → 物品缩小淡出消失、盒子绿色确认；放进**错误**盒子 → 盒子红闪、物品留在原地、错误计数 +1。
- 全部物品放对即过关。
- **v1.0 无拖拽**：点按即放（低龄友好，也兼容 PC 鼠标点击）。
- 分类归纳价值：需要孩子先观察物品特征、判断类别归属，再执行归位；每类 3 件同一类物品连续归位，强化类内共性认知。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 点物品 | 选中该物品（橙色描边高亮）；点同一物品取消选中；点另一物品切换选中 |
| 点类别盒 | 有选中物品 → 判定正确/错误；无选中物品 → 提示「先选一个物品，再放进盒子」 |
| 底栏按钮 | 「返回难度」回难度页；「重新开始」同难度重抽一局 |
| 顶栏按钮 | 「← 返回」回难度页 |

### 2.3 反馈

- **选中高亮**：选中物品橙色描边（`outline 3px #ff9f43`）+ 浅橙底（`#fff7ee`）。
- **正确**：物品淡出（`placingOut 0.3s`，缩小到 0.55 + 透明度 0，320ms 后隐藏）+ 盒子绿色确认（`correctFlash 0.3s`，放大 1.08 回弹）+ 盒子计数 +1。
- **错误**：盒子红闪（`wrongFlash 0.4s`，背景 `#ffe9e6 → #ffc9c4 → 白`）+ 物品取消选中留在原地 + 底栏 `❌ N` 计数更新。
- **防卡高亮**：同一局放错 ≥3 次后，当前选中物品的**正确盒子**温和脉冲（`stuckPulse 0.8s` 呼吸式背景明暗），放对后自动重置。
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件）：放对（清脆）/ 放错（低沉）/ 胜利（上行琶音，同推箱子/迷宫寻路）。
  首次用户手势创建 `AudioContext`，播放异常静默降级。

## 4. 技术设计

### 4.1 数据模型

- **难度常量** `LEVELS`：

| key | 难度 | 类别数 | 物品总数 | 每类件数 |
|---|---|---|---|---|
| '2' | 简单 | 2 类 | 6 件 | 3 |
| '3' | 普通 | 3 类 | 9 件 | 3 |
| '4' | 困难 | 4 类 | 12 件 | 3 |

- **运行时状态** `state = { level, cats:[{...类别对象}], items:[{ci, ii, placed}], selected, correct, errors, total, won, started, startMs, ms, timerId }`。
  - `items[i]`：`ci` = 类别下标（引用 `CATEGORIES` 中对象）、`ii` = 该类别内图标下标、`placed` = 是否已归位。
  - `started`：首次点选物品置 true 并开始计时（错误点击/空盒子点击不启动计时）。

### 4.2 出题引擎（随机类别 → 随机图标 → 洗牌，每局全新）

```
newRound(levelKey):
  cats = pickCats(levelKey)      # 8 类池 Fisher-Yates 洗牌取前 M（M = 类别数 2/3/4）
  items = []
  for 每类 ci:
    idxs = 该类全部图标下标洗牌取前 3   # 每类随机 3 个不同图标
    items.push({ci, ii, placed:false}) × 3
  items 整体 Fisher-Yates 洗牌 → 物品格随机布局
```

- **类别抽取**：`pickCats` 对 8 类池洗牌后 `slice(0, n)`，每局类别组合不重复。
- **图标抽取**：每类图标数 ≥4（`icons.js` 约束），洗牌取前 3 保证**本局内该类 3 件互不重复**，且留下冗余给随机性。
- **洗牌**：`shuffle()` 为 Fisher-Yates（返回新数组，不污染原数组）；类别、图标、物品布局三层均随机 → 每次进游戏都是新题，不会背答案。

### 4.3 交互流程与判定（点击式，无拖拽）

- `onItemTap(idx)`：`won` 后忽略；已归位物品不可再选；**首次点选**触发 `ensureAudio()`（用户手势内建 AudioContext）+ `startTimer()`；点同一物品取消选中，点另一物品切换选中。
- `onBoxTap(ci)`：无选中物品 → `showItemHint()` 轻提示 900ms（不扣分、不启动计时）；有选中物品 → 按 `items[selected].ci === ci` 判定：
  - **正确**：`placed=true`、`correct++`、`sndCorrect()`、`setSelected(-1)`（含防卡高亮重置）、物品加 `placing` 淡出类（320ms 后隐藏）、盒子加 `correct` 绿闪类（300ms 后移除并刷新计数）、`correct >= total` 时 `onWin()`。
  - **错误**：`errors++`、`sndWrong()`、盒子加 `wrong` 红闪类（400ms 后移除）、`setSelected(-1)` 物品留原地、刷新错误计数。
- **计数**：每盒 `n/3` 由 `updateBoxCounts()` 按已归位物品实时重算。

### 4.4 防卡关提示（antistuck，低龄友好）

- 触发条件：**本局错误 ≥3 次** 且当前**有选中物品** → 该物品的正确盒子加 `antistuck` 类（`stuckPulse 0.8s` 无限循环，背景白 ↔ 暖橙呼吸式，无频闪）。
- 每次 `setSelected()` 都会调用 `updateAntiStuck()` 更新；正确归位清空选中后自动重置。
- 设计意图：**提示而非代做**——只告诉孩子"它该进哪个盒子"，不放自动入盒，保留分类思考的学习性。

### 4.5 计时

- `startTimer()`：`state.startMs = performance.now()`，`setInterval(100ms)` 按差值刷新 `'⏱ ' + fmtTime(ms)`（秒 + 1 位小数，如 `⏱ 07.5`）。
- **首次点选物品才开始计时**（低龄友好：观察/犹豫时间不计入）；未开始时顶栏显示 `⏱ 00.0`。
- 通关即 `stopTimer()` 定格，`state.ms = performance.now() - state.startMs`。
- 断局恢复：**v1.0 无**（中途退出回难度页，重新进游戏重抽新局）。

### 4.6 星级与最佳成绩判定

- **星级**（按本局错误次数）：
  - ★★★：错误 0 次
  - ★★：错误 1~2 次
  - ★：错误 ≥3 次（过关即有）
- **最佳判定** `betterThan(errorsA, msA, errorsB, msB)`：**错得少优先，同错比用时短**；仅当严格更优才覆盖 `store.best[key]`。
- **最近**：`store.recent[key]` 无条件覆盖为本局用时；**历史**：`history` 无条件 push 后滚动保留最近 30 条。
- 星级计算 `calcStars(errors)` 只与错误次数相关，与用时无关（用时用于最佳同错比较）。

### 4.7 持久化（localStorage）

- key：`redtools.fenleizhengli.v1`（容器内多工具共享存储，必须带工具前缀）。
- 结构：

```js
{
  version: 1,
  best:    { "2": {ms, errors, stars, date}, "3": {...}, "4": {...} },  // 各难度最佳
  recent:  { "2": ms, "3": ms, "4": ms },                               // 各难度最近用时
  checkin: { dates: ["YYYYMMDD", ...], streak },                        // 打卡
  history: [ {date, level, ms, errors, stars} ]                         // 滚动 30 条
}
```

- 读写全部 try/catch（隐私模式等异常静默降级）；`loadStore()` 校验 `version === 1` 并补全缺失字段；初始化写入一次。
- **打卡** `doCheckin()`：通关一局 → `dates` 写入今日 YYYYMMDD（去重 + 排序）、滚动 365 天；`calcStreak()` 连续天数**含今天往前推**（今天未打则从昨天起算），跨天断。

### 4.8 图标库（程序化 SVG，8 类 43 图标）

`window.CATEGORIES`（icons.js 注入）：每个类别 `{ id, name, color, icons: [draw, ...] }`。

| 类别 | id | 主题色 | 图标数 | 图标 |
|---|---|---|---|---|
| 水果 | fruit | #ff8a5c | 6 | 苹果/香蕉/葡萄/西瓜/草莓/梨 |
| 蔬菜 | veg | #4dbf7a | 6 | 胡萝卜/西兰花/番茄/玉米/茄子/南瓜 |
| 动物 | animal | #ff9c4a | 6 | 猫/狗/兔/象/企鹅/长颈鹿 |
| 交通 | transport | #5b8def | 5 | 汽车/火车/飞机/轮船/自行车 |
| 文具 | stationery | #7aa7f0 | 5 | 铅笔/书本/剪刀/尺子/橡皮 |
| 食物 | food | #ff8fb3 | 5 | 蛋糕/冰淇淋/甜甜圈/曲奇/汉堡 |
| 乐器 | instrument | #c46bff | 5 | 钢琴/吉他/鼓/小号/铃鼓 |
| 天气 | weather | #8ad4ff | 5 | 太阳/月亮/云/雨滴/彩虹 |

- **风格**：糖果色童趣扁平风；类别间视觉区分靠轮廓/构图/配色各不相同（水果 vs 蔬菜 也清晰可辨）；每个 `draw()` 返回以 (0,0) 为中心、`viewBox="-20 -20 40 40"` 的完整 `<svg>` 字符串，物品格/盒子直接 `innerHTML` 渲染。
- **盒子复用**：类别盒代表性图标 = 该类 `icons[0]()`（`chip.innerHTML = icons[0]()`）。
- **每类 ≥4 个**：满足困难 4 类 × 每类 3 件抽选不重复，留冗余。
- **形状工具**：`c/ce/rc/pl/pa/ln/star/starPts/svgWrap` 为 icons.js 局部函数（同翻牌记忆配对）；`c()` **双签名兼容**：
  - `c(r, fill[, extra])`：以 (0,0) 为中心的圆（翻牌原版签名）
  - `c(cx, cy, r, fill[, extra])`：指定圆心的圆（本工具图标库大量使用）
  - 判定：`typeof p2 === 'number'` 走四参签名，否则走两参签名。

### 4.9 音效（Web Audio 合成）

```js
tone(freq, dur, type, vol, delay)   // OscillatorNode + GainNode 指数包络（同推箱子/迷宫寻路）
sndCorrect: triangle 523Hz 0.09s    // 放对（清脆）
sndWrong:   square   150Hz 0.12s    // 放错（低沉）
sndWin:     523/659/784/1047 上行琶音（sine，间隔 0.12s）
```

`AudioContext`（含 `webkitAudioContext` 兜底）懒创建 + 用户手势 `resume()`；全部 try/catch 降级，设备静音自动无声。

### 4.10 视图结构

- 三个视图 + 一个浮层：**难度选择页**（初始）/ **游戏页** / **打卡日历页**；**结算浮层**（通关后居中卡片，半透明遮罩 + 星级 + 统计 + 打卡 + 三按钮）。
- 渲染：每次切视图 `clearNode` 全量重建 DOM（物品格 ≤12 个，开销可忽略）；header/footer 随视图重绘。
- 正方形物品格：`width` + `padding-bottom` 同为 33.33%（3 列），格内间距用内层 `item-inner` 绝对定位 inset 4px（无 flex gap）。
- 打卡日历：7 列网格（`14.28%` 宽），已完成日橙色 `#ff9c1a`，今天蓝色描边 `#4aa8ff`，`streak-info` 连续天数（≥7 天 🎉），**与翻牌记忆配对同款**。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：ES2017 经典脚本（var + function），无 `?.`/`??`/对象展开/`replaceAll`/module/import；无内联事件/eval/innerHTML 脚本注入（仅渲染 SVG）；事件全部 `addEventListener`；无 fetch/XHR/Worker/clipboard。
- CSS：无 `gap`/`aspect-ratio`/`clamp()`/`inset`/逻辑属性/`:has`/`@container`/`dvh`；flex 三重前缀；动画双写 `@-webkit-keyframes` + `@keyframes`；
  正方形网格用 `width` + `padding-bottom` 百分比；间距用 margin/内层 inset；安全区 `env(safe-area-inset-*)` + `--app-height` 变量。
- 触控/光敏：主要按钮 hit area ≥48px；动画温和（正确 300ms / 错误 400ms / 淡出 300ms / 浮层 250ms / 星级 350ms）；防卡脉冲 0.8s 呼吸式无频闪。
- 资源：全部内联/本包；无外部 URL；无 CSP meta（容器管理）；图形 SVG 代码生成 + 音效 Oscillator 合成 → **零图片零音频零数据文件**。
- 包体：构建产物 0.02 MiB（≪ 2 MiB 建议值）。

- **可复用核心**：计时/成绩/打卡对齐 `series/益智/设计文档.md` §4（localStorage key 带工具前缀 + 打卡日历模式）；Chrome 61 / 交互合规对齐 §5；程序化 SVG 图标库对齐 §8（翻牌记忆配对落地 pattern，形状工具与 svgWrap 同源）。
- **与同系列的差异**：推箱子/迷宫寻路以「最少推动数/最短步数」为星级基准，本工具改为**错误次数星级**（0/1~2/≥3）更贴合低龄认知；出题 = 类别 + 图标程序化随机（无 levels.js 数据文件，随机源即数据源）；输入为纯点击（无拖拽、无滑动/键盘/D-pad）；结算按钮为「再来一局（同难度新题）/ 选难度 / 打卡日历」；**v1.0 无断局恢复**。
- **打卡一致性**：打卡日历与翻牌记忆配对同款（7 列网格 / orange done / streak-info），系列内视觉统一。
- **扩展**：难度常量 `LEVELS` 可直接加档（类别数/件数改数值即可）；`CATEGORIES` 图标库独立成文件，可整体扩展新类别/新图标（每类 ≥4 的冗余约束自动满足困难档抽选）；后续可加拖拽、断局恢复（`state` 快照持久化）。
