# 扫雷推理 — 使用文档

> 逻辑思维子系列第 7 款：经典扫雷改成「推理练习」——踩雷不判负，看数字推理翻开所有安全格！
> 适用：手机 / 电脑（触屏点击、长按插旗；键盘也可）。
> 版本：v1.0 · 更新：2026-09-23

---

## 1. 怎么玩

1. 打开工具，选难度：**初级（9×9·10 雷）/ 中级（16×16·40 雷）/ 高级（30×16·99 雷）**。
2. 点任意格子开始——**第一下必翻一片安全区**，不会踩雷。
3. **目标：翻开全部安全格**就完成！（不是「找完所有雷」，是「避开雷、翻开安全区」）
4. 看数字推理：**数字几 = 周围 8 格里有几颗雷**，据此判断哪些格安全、哪些格是雷。

## 2. 核心规则（和经典扫雷不一样的地方）

| 规则 | 说明 |
|---|---|
| 🎯 目标 | **翻开全部安全格** = 完成（有标准答案） |
| 💥 踩雷不判负 | 踩到雷**不会输**！雷会标出来（💣），提示你「看周围数字推理避开」，**局继续** |
| 🚩 已踩雷自动标旗 | 踩到的雷 = 已确认的雷，自动标旗提醒避开 |
| 🏆 完成 | `🎉 完成推理！所有安全格都翻开了，逻辑清晰！` + 用时 + 踩雷次数 |

> 一句话：**这不是手气游戏，是逻辑推理练习**——数字告诉你哪里有雷，你推理出安全格，全翻开就赢。

## 3. 操作说明

| 操作 | 翻开模式 | 标旗模式 |
|---|---|---|
| 单击格子 | 翻开（数字/空白/雷） | 插旗 / 取消旗 |
| 长按格子 | 插旗 / 取消旗 | 翻开 |
| 键盘 | 方向键移动光标 + 回车翻开 + 空格插旗 | 同左 |

- 底部**模式切换**：`👆 翻开` / `🚩 标旗`（触屏想稳定插旗就用标旗模式）；
- 高级/中级棋盘可**左右滑动**看全棋盘；
- 数字格周围已标够雷时，点数字可**快速翻开剩余安全格**（经典 chord，若有实现）。

## 4. 界面说明

- **顶部**：标题 + 难度 tab（初级/中级/高级）；
- **信息条**：`剩余雷数 | 🙂表情(点它重新开始) | 用时`（LED 数字）；
- **本难度最佳**：显示当前难度历史最佳用时；
- **防沉迷条**：`⏱ 5 分钟`（单局时长）/ `今日 5 局`（局数上限）/ `🙌 我很自律`（今天到此为止）；
- **结算**：完成 → `🎉 完成推理！`（用时 + 新纪录标记 + 踩雷次数 + 打卡 + 防沉迷结算三选）。

## 5. 成绩与打卡

- **最佳用时**：各难度分别记录（完成即刷新，个人纵向无 PK）；
- **今日打卡**：完成一局点亮今日打卡，底部显示连续天数；
- **分享打卡**：生成分享卡片（1080×1920）+ 一键复制文案；
- **防沉迷/自控力**：到点/到局数自动提醒（延迟额度有限次）；「我很自律」当日结束 + 自律连续天数；
- 全部数据存本地（localStorage），离线可用、不联网上传，无广告无内购。

## 6. 小贴士

- **先翻角角落落**：空白的周围会连成一片，快速展开地图；
- **1 数字推理**：数字 1 旁边如果只有 1 个没翻的格子 → 那格是雷，标旗避开；
- **踩雷是学习**：踩到雷别慌——雷标出来了，看它旁边的数字反推哪些格安全；
- **用标旗模式**：触屏时切到 `🚩 标旗` 模式，就不会手滑点到雷了。

## 7. 常见问题

**Q：踩到雷是不是就输了？**
**不会！** 这是和经典扫雷最大的区别——踩雷会标出雷（💣）并给推理提示，局继续，你继续推理翻开安全格。

**Q：到底怎样算赢？**
**翻开全部安全格**（不是找完所有雷）。安全格全翻开 = `🎉 完成推理！`。

**Q：数字是什么意思？**
数字几 = 它周围 8 个格子里有几颗雷。比如数字 3 旁边已经标了 2 面旗，剩下没翻的格子就很可能有 1 颗雷，要小心。

**Q：高级棋盘太大看不清？**
高级（30×16）棋盘可**左右滑动**；数字小可以放大看。实在吃力就从初级练起。

**Q：和经典扫雷有什么区别？**
经典扫雷踩雷 = 爆炸判负（游戏，已 🔒 推迟）；**扫雷推理踩雷 = 标出继续**（练习，有标准答案）——把「手气」改成「推理」，合规安全区。
