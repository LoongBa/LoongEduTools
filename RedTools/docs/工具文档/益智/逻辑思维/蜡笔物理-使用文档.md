# 蜡笔物理 — 使用文档

> 益智系列 · 逻辑思维子系列。**画一笔变成木板，帮红色小球滚到黄色星星！**
> 适合 5~12 岁，训练物理直觉与空间规划。
> 更新：2026-09-19

---

## 1. 怎么练

1. 在首页选择一关（10 关由易到难，通关后关卡卡片显示星级 ★）；
2. 观察地形：小球在三角台顶部，星星在右侧；
3. **画一条线**——松开后它会变成一块木板/斜坡（画完第一笔，小球才会开始滚动）；
4. 让小球顺着你画的斜坡/桥/拱一路滚到星星 → 过关！

```
    △  ← 三角台（小球从这里滚下）
   ●   ← 红色小球
   ◢◣  ← 你画的斜坡（画一笔就变成木板）
        ★  ← 黄色星星（小球碰到它即过关）
```

**核心技巧**：小球只会**往下滚**——把斜坡画成从高到低的"滑梯"，两端搭在平台上（起点接住台面边缘、终点贴地/贴平台），球就能一路滑到星星。

## 2. 操作说明

| 操作 | 怎么按 |
|---|---|
| 画线 | 按住鼠标左键 / 手指拖动，松开成木板 |
| 换颜色 | 点顶栏 🖍 弹出 6 色蜡笔选择 |
| 擦除 | 按住鼠标右键拖动（桌面）/ 顶栏 🧽 开启橡皮擦模式后拖动（触屏） |
| 撤销上一笔 | 顶栏 ↩ 或键盘 U |
| 重置关卡 | 顶栏 ↻ 或空格键 |
| 返回选关 | 顶栏 ◀ 或 Esc |
| 直达关卡 | 键盘 1~9、0（第 10 关） |
| 声音开关 | 顶栏 🔊/🔇 |

> 世界在画完第一笔后才启动 —— 先想好画什么，慢慢画，小球等你。

## 4. 成绩与打卡

- **星级**：用越少的笔画过关星越多（≤2 笔 ★★★ / ≤4 笔 ★★ / 更多 ★）；
- **打卡**：完成任意一关即点亮今日（首页底部显示连续打卡天数）；
- 成绩保存在本机浏览器（localStorage），换设备不迁移。

## 5. 常见问题

**Q：小球一开始不动？**
A：正常！画完第一笔小球才开始滚动——先观察地形规划好再画。

**Q：画的线挂在空中不掉下来？**
A：画的线是"木板"，画在哪就在哪固定（像贴在纸上）。把木板两端搭在平台上、中间悬空做桥是可以的，但记得球只能往下滚，别画成上坡。

**Q：球滚到一半停了？**
A：球只靠重力滚动，斜坡越陡、越长，球越快越远。如果球停在中途，试试把斜坡画得更斜一点，或加一段接力坡。

**Q：画错了怎么办？**
A：点 ↩ 撤销上一笔，或点 ↻ 重置整关重新来。

## 6. 兼容与环境
