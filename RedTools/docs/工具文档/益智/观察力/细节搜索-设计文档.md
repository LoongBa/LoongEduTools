# 细节搜索 — 设计文档

> 版本：v1.0 ｜ 系列：益智·观察力 ｜ 类型：P2（视觉检索） ｜ 更新：2026-09-19
> 关键词：零图片素材、Wimmelbild 低龄化、SVG viewBox 缩放、藏物引擎、73 元素库复用

## 1. 产品概况

**定位**：观察力子系列第 3 款（P2）。在程序化 SVG 大场景中**逐一检索藏起来的小目标**，首次引入镜头缩放/平移交互维度。

**与系列其余款分工**（能力差异化）：

| 工具 | 视觉任务 | 目标可见性 | 交互 |
|---|---|---|---|
| 找不同 | 两图对比找差异 | 差异隐藏 | 左右图对比点选 |
| 影子配对 | 形状轮廓匹配 | 目标在卡上行 | 配对选择 |
| **细节搜索（本作）** | **单图空间检索** | **目标藏入场景需自行发现** | **缩放/平移浏览 + 点选** |

**维度归属说明**：与特质记忆组「物品藏匿（思海拾遗）」不同——那是**记位置**（记忆维度），本作是**视觉检索**（观察维度）。对标上无同名产品，机制源自 Wimmelbild（找物图）玩法低龄化（Ravensburger Kita Kobold 2 岁+ 逐次找物模型；开源 ispy-game hotspot 方案）。

**目标用户**：K1-3–K4-6（L2–L3），低龄友好设计（逐次 1 个目标、错点零惩罚、无限时）。

## 2. 玩法设计

### 2.1 规则
1. 选难度（简单 3 物 / 普通 5 物 / 困难 7 物）→ 8 场景随机抽一局。
2. 顶部目标栏亮显**当前目标**（SVG 小卡 + 中文名 + 进度 i/N）。
3. 在大场景中**缩放（🔍+/− 三档 1x/1.5x/2.2x）+ 平移（⬆⬇⬅➡）** 浏览查找。
4. 点中当前目标 → 绿音 + 自动揭示下一个；点错（空白/固有元素/其它藏物）→ 红闪 + 点错计数（**零惩罚**，仅计数影响星级）。
5. 全部找到 → 星级结算 + 打卡。

### 2.2 操作
| 操作 | 控件 | 说明 |
|---|---|---|
| 缩放 | 🔍+ / 🔍− | 按当前视口中心缩放，1x→1.5x→2.2x |
| 还原 | 🔄 | 一键回 1x 整图 |
| 平移 | ⬆⬇⬅➡（缩放 >1x 时出现） | 步长 = 视口宽/高的 30%，边界 clamp |
| 提示 | ✋ 提示 (n) | 深橙描边环 + 元素脉冲 2.5s；每局限次（简单 1、普通/困难 2）；**用过提示星级 ≤2★** |

### 2.3 反馈
- **命中**：清脆双音 + 藏物从场景移除 + 目标栏推进。
- **错点**：低沉双音 + 场景抖动(shake 300ms) + 「点错 n」计数。
- **提示**：深橙环 `#ff5a00` 粗描边（SVG 根级，线宽恒定不受藏物缩放影响）+ 元素透明度脉冲。
- **结算**：🎉 全部找到！/ 👏 找齐啦！；星星（0 错 3★ / ≤2 错 2★ / 其余 1★；**提示 >0 → 上限 2★**）；摘要「找到 N 个 · 点错 x 次 · 用时 t」；打卡行；🏅 新纪录徽章。

## 3. UI 设计

- 配色：**观察力·清新橙绿**（与找不同/影子配对一致：橙 `#ff8b3d` 主色 + 绿点缀，背景 `#f5f7fa`）。
- 布局（390×844 基准）：顶栏（🔍 logo + 标题 + 版本）→ 目标栏（SVG 小卡 + 「找一找：名字」+ i/N）→ 场景卡（480×320 viewBox 自适应宽）→ 缩放行（+ / − / 倍数 / 还原）→ 平移行（缩放后出现）→ 状态行（提示按钮 / 点错 / 提示计数）→ 固定底栏「← 结束这一局」。
- 场景 SVG：`width:100% height:auto` 响应式；`touch-action:manipulation`。

## 4. 素材方案（★核心决策）

**纯程序化 SVG，零图片素材。** 三个来源：

| 层 | 来源 | 说明 |
|---|---|---|
| 大场景背景 | `scenes.js`（复制自找不同）8 场景 × 480×320 | 渐变 + 装饰 + 固有元素原位渲染 |
| **藏物目标** | 同场景元素库副本，**缩小随机摆放** | `draw({fill,variant})` 任意复用；与固有元素同源 = 天然相似干扰（海边找小螃蟹，背景已有大螃蟹） |
| 中文名表 | ELEM_NAMES（74 条 id→中文名，与找相同/划消/影子配对同源） | 「找一找：小船」显示 |

**否决 AI 生图/真实图片路线**（调研证据）：
1. **不可复现**：位图进 zip 后无法 diff/版本化；对标项目 ispy-game 实测**废弃** DALL·E sprite 路线（README 明示）。
2. **判定精度**：位图需 bbox 近似（不规则物体框内大量空白）；SVG 元素**浏览器原生精确命中**，`viewBox` 变换下无需屏幕坐标手算。
3. **体积/合规**：SVG 全套仅 ~85KB（<1% 的 10MiB 预算）；无 raster/`<image>`/外部引用，天然满足白名单与 CSP。
4. **难度解耦**：藏物尺寸/数量/位置全是运行时参数，换难度不重画。

## 5. 技术设计

### 5.1 数据模型
```js
LEVELS = [ {key:'1',名称'简单', targets:3, hideScale:0.72, hintLimit:1}, … (5 物 0.56/7 物 0.42)]
state = { level, scene, hides:[{e,x,y,s,rot,hitR,showR,found}], curIdx, errors, hints, won, ms, zoomIdx, viewX, viewY, viewW, viewH }
```

### 5.2 藏物引擎（makeHides）
- 从目标场景元素库抽 N 个**不同元素** → 各生成 1 个藏物副本。
- 位置：随机采样 + **碰撞避让**（与固有元素及各藏物圆心距 ≥ (hitR+showR)×0.85）+ 边距 34px；80 次重试后兜底靠边放置。
- 尺寸：`showR = max(16, round(e.hitR × hideScale × 1.45))`（**实际显示命中半径**，触摸友好）；
  **`chipR = ceil(showR / hideScale)`** 传给渲染（因 wrapOffset 的 scale(s) 会压缩 circle 半径，需预补偿）。
- 旋转：±30° 随机。

### 5.3 渲染与命中
- `renderSceneSvg()`：bg + 固有元素（`data-eid="prop-i"`）+ 未找到藏物（`data-eid="hide-j"`）；每元素外包**透明命中圆**（`pointer-events="all"`）。
- **缩放实现**：动态改 SVG `viewBox`（`setAttribute`），Chrome 61 支持；1x/1.5x/2.2x 三档 + 4 向平移（步长 30% 视口）+ clamp 边界。
- **命中机制**：浏览器按当前 viewBox 自动换算点击坐标 → 事件委托向上找 `data-eid` —— **无需屏幕坐标手算**（对比 ispy-game 的 bbox div 方案）。
- 命中后 `reRenderScene()` 重建 SVG（保留 viewBox 状态，视角不跳变）。

### 5.4 星级与最佳
- `stars = errors===0 ? 3 : errors<=2 ? 2 : 1`；`if (hints>0) stars = min(stars, 2)`。
- best 键=难度 → `{ms, errors, stars, date}`；recent/history（≤30 条）含 scene 名/目标数/提示数。
- 存储 key：`redtools.xijiesousuo.v1`，结构同系列（version/best/recent/checkin/history）。

### 5.5 通用组件复用
打卡日历/连续天数/结算浮层/星级/新纪录/Web Audio 音效/performance.now 计时/syncAppHeight——全套照既定模式复用。
