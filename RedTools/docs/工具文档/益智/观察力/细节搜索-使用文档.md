# 细节搜索 — 使用文档

> 版本：v1.0 ｜ 系列：益智·观察力 ｜ 更新：2026-09-19

## 1. 这是什么

**细节搜索**是一款**在大场景里找小东西**的观察力小游戏：每个场景藏了几个小小的目标（小船、螃蟹、泡泡……），孩子需要用放大镜功能把画面放大，仔细找出来——非常考验观察力和耐心。

- 8 个场景轮换：海边、森林、农场、太空、海底、城市、冬日、花园。
- 完全离线可用，画面全部由程序绘制，没有图片文件。

## 2. 怎么玩

1. 打开页面 → 选难度：**👶 简单**（找 3 个，目标大）/ **😊 普通**（找 5 个）/ **💪 困难**（找 7 个，目标小）。
2. 顶部会显示**当前要找的东西**（小卡片 + 名字 + 进度，如「找一找：小船 1/5」）。
3. 在场景里用工具条寻找：
   - **🔍 + 放大 / 🔍 − 缩小**：画面会逐渐放大（1 倍 → 1.5 倍 → 2.2 倍）
   - **⬆ ⬇ ⬅ ➡ 平移**：放大后拖动视野（会出现在放大按钮下方）
   - **🔄 还原**：一键回到整图
4. **找到后点一下那个小东西** → 它会消失，自动告诉你下一个要找什么。
5. 全部找到 → 结算星星 + 自动打卡。

## 3. 界面说明

| 位置 | 作用 |
|---|---|
| 顶部目标卡 | 当前要找的目标图案 + 名字 + 第几个/共几个 |
| 大场景 | 目标藏在里面，可能很小，放大才看得清 |
| 缩放工具条 | 放大 / 缩小 / 当前倍数 / 还原 |
| ✋ 提示按钮 | 不知道在哪时点它——目标会被橙色圆环圈出来（每局限用 1~2 次） |
| 点错计数 | 点错地方会数一下（不惩罚，只影响星星） |

## 4. 打分规则

| 条件 | 星星 |
|---|---|
| 一次都没点错 | ★★★ |
| 点错 1~2 次 | ★★ |
| 其他 | ★ |
| 用过提示 | 最多 ★★（提示帮了忙，就不算"全凭自己"啦） |

另有「🎉 新纪录」徽章：刷新本难度历史最佳（星星优先、用时短者胜）。

## 5. 进度与打卡

- 每次通关自动记入「本月打卡」日历（首页底部「📅 打卡日历」查看），显示连续打卡天数。
- 每个难度保存历史最佳（星星/用时/点错数），难度选择页可见。

## 6. 常见问题

**Q：东西太小找不到怎么办？**
A：先 🔍 + 放大到 2.2 倍，再四处平移；实在找不到点「✋ 提示」，目标会被橙色圆环圈出来。

**Q：点错了会怎样？**
A：只会闪一下提醒 + 数的点错次数增加，不会失败、不会重来。注意点错太多次就难拿 3 星了。

**Q：目标会不会藏在很刁钻的地方（比如半遮住）？**
A：不会。设计上**目标主体始终全部可见**（不藏在遮挡物后面），放大后一定找得到——找小不等于找不见。

**Q：为什么每次进去场景不一样？**
A：8 个场景随机轮换，目标每局重新抽取和摆放，每局都是新地图。

## 7. 数据存储

- 数据保存在本机浏览器（未同步云端），清除浏览器数据会丢失记录。
- 存储键：`redtools.xijiesousuo.v1`。

## 8. 技术信息（家长选读）

- Chrome 61+ / 现代浏览器可用；端到端全离线，可解压后双击 `index.html` 使用。
- 画面为程序化 SVG（零图片素材），音效为程序合成；放大通过 SVG viewBox 实现，不损失清晰度。
