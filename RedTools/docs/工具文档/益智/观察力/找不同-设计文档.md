## 2. 玩法规则

1. **开局**：从首页选择难度进入（简单 3 处 / 进阶 5 处 / 挑战 8 处差异）。
2. **出题**：随机选 1 个场景（8 选 1）→ 随机选 N 个不同元素 → 对每个元素随机应用一种差异变换。
3. **双图对比**：左图 = 原场景；右图 = 应用差异后的场景。差异可能表现为：
   改色（换 palette 色）、变位（元素移动）、缩放/旋转（变大变小或旋转）、
   隐藏（右图没有该元素）、替换变体（换外观版本）。
4. **点击**：点中差异处 → 绿色对勾标记锁定 + 进度 +1；点错 → 红色叉提示 + 点错计数（不结束）。
5. **隐藏差异特殊规则**：右图中该元素不存在，孩子要点**左图（原图）对应位置**才算找到；
   左图元素也全部可点，但左图只认隐藏类差异，点左图非隐藏差异元素算点错。
6. **计时**：首个正确点击时启动计时；找齐全部差异结束计时。
7. **结算**：找齐即 `finishGame()`，显示用时 + 找对/点错统计 + 星级 + 打卡。

> 设计考量：要求"差异在右图点、隐藏差异在左图点"是为了让孩子**指出改变发生的具体位置**，
> 而不是仅仅看到"好像不一样"——观察力训练的核心是定位差异。

## 3. 程序化关卡生成（核心方案）

详见 `series/益智/设计文档.md` §6。本工具落地如下：

### 3.1 场景库（scenes.js `window.SCENES`）

| 场景 | id | 元素数 | 元素 |
|---|---|---|---|
| 海边 | ocean | 10 | sun / cloud / boat / fish / starfish / shell / crab / seagull / lighthouse / palm |
| 森林 | forest | 9 | tree / flower / mushroom / butterfly / bird / squirrel / rabbit / fox / owl |
| 农场 | farm | 9 | barn / cow / sheep / chicken / tractor / apple / fence / windmill / duck |
| 太空 | space | 9 | star-sun / planet / rocket / astronaut / satellite / star2 / ufo / moon / comet |
| 海底 | undersea | 9 | fish2 / octopus / turtle / coral / seaweed / jellyfish / starfish2 / bubble / whale |
| 城市 | city | 9 | house / car / tree2 / lamp / cloud2 / sun2 / bicycle / balloon / bird2 |
| 冬日 | winter | 9 | snowman / snowflake / pine / igloo / sled / penguin / scarf / deer / mitten |
| 花园 | garden | 9 | flower2 / bee / butterfly2 / snail / watering / fence2 / sun3 / mushroom2 / ladybug |

- 每个元素：`{ id, x, y, s, rot, hitR, fill, palette, variantMax, draw(opt) }`
  - `x/y`：元素中心（SVG 视口 480×320 内）；`s`：缩放；`rot`：旋转
  - `hitR`：命中圆半径（≥26px，触摸友好）
  - `fill`：主色；`palette`：可改色候选（改色变换用）
  - `draw(opt)`：返回以 (0,0) 为中心的内层 SVG 字符串，`opt = {fill, variant}`

### 3.2 差异变换（main.js `DIFF_OPS`，5 种原子操作）

| 操作 | 实现 | 明显度控制 |
|---|---|---|
| recolor 改色 | 从 `palette` 中选一个与当前主色不同的颜色 | palette 均为高对比色 |
| move 变位 | 偏移 40~75px（方向随机，clamp 保持场景边界） | 位移量 |
| scale 缩放旋转 | 放大 1.35~1.7 / 缩小 0.55~0.75 / 旋转 ±15~40° | 比例/角度 |
| hide 隐藏 | 右图不渲染该元素（最多 2 处） | 固定明显 |
| variant 替换变体 | `opt.variant=1`，元素 draw 输出不同外观 | 变体差异 |

- 同一局内同一元素只变换一次；差异元素不重复。
- 隐藏变换最多 2 处：避免整局都在左图找、也避免右图太空。

### 3.3 出题引擎（main.js `buildDiff`）

```
随机选场景 → 洗牌元素下标 → 取前 N 个 → 每个随机选一种差异变换
（hide 超 2 次则降级为 recolor）→ diffs[] + diffMap{}
```

每次进游戏（含「重新开始」「再来一局」）重新出题。

## 4. 难度与星级

### 4.1 难度定义（main.js `LEVELS` 常量）

| 难度 | label | 差异数 | 3★ 阈值（threeMs） | 2★ 阈值（twoMs） |
|---|---|---|---|---|
| 简单 | 简单 · 3 处 | 3 | ≤20000ms（20 秒） | ≤40000ms（40 秒） |
| 进阶 | 进阶 · 5 处 | 5 | ≤40000ms（40 秒） | ≤75000ms（75 秒） |
| 挑战 | 挑战 · 8 处 | 8 | ≤75000ms（75 秒） | ≤120000ms（120 秒） |

### 4.2 星级评级

| 难度 | 3★ | 2★ | 1★ |
|------|------|------|------|
| 简单（3 处） | ≤20 秒 | ≤40 秒 | 其余 |
| 进阶（5 处） | ≤40 秒 | ≤75 秒 | 其余 |
| 挑战（8 处） | ≤75 秒 | ≤120 秒 | 其余 |

> ⚠️ 星级阈值为需求草案参考值，待真机实测后按真实分布校准。

`calcStars(level, ms)`：`ms <= threeMs` → 3★；`ms <= twoMs` → 2★；否则 1★。

## 5. 页面/视图结构

```
首页 viewHome（3 个难度卡片 + 各难度最佳成绩/未挑战 + 底栏导航 成绩/打卡/首页）
  │ 点击难度卡片
  ▼
游戏页 startGame（顶部 返回|难度·场景|计时 / 进度条 / 左图原图 + 右图找不同 / 已找到·点错 / 重新开始）
  │ 找齐全部差异 → finishGame（延迟 350ms）
  ▼
结果浮层 showResult（完成 / 大号用时 / 用时·找对·点错统计 / 星级 / 新纪录横幅 / 再来一局 / 返回首页）

底栏导航：成绩 viewHistory（最近 30 次，时间倒序） │ 打卡 viewCheckin（本月日历 + 连续天数）
```

- **顶栏（app-header）**：`renderHeader(title)` 渲染图标 + 标题 + 版本号（来自 `APP.meta.version`）。
  首页显示工具名「找不同」；游戏页显示工具名（header 不覆盖）。
- **首页 `viewHome`**：标题「选择难度」+ 提示「找出两幅图中的不同之处，点一点！」；
  3 个难度卡片（`diff-card`），每张含难度按钮 + 该难度最佳成绩（`最佳 x.x 秒`，未玩过显示「未挑战」）。
- **游戏页 `startGame`**：
  - 顶部状态栏：`‹ 返回` | `难度 · 场景名`（如「简单 · 3 处 · 海边」）| `⏱ 00.0`；
  - 进度条 `fd-progress`（绿色，随已找到比例填充）；
  - 双图 `scene-pair`：左图（原图）+ 右图（找不同），每张 `scene-wrap` 内 `scene-label` + `scene-box`；
    **手机竖屏上下堆叠、宽屏（≥560px）左右并排**（CSS media query）；
  - 状态行：`已找到 x/N`（绿）+ `点错 y`（红）；
  - 底部「重新开始」按钮（重新出题再来）。
  - 游戏页**不渲染底栏导航**（顶部返回 + 底部重新开始，避免误触退出）。
- **结果浮层 `showResult`**：全屏半透明遮罩 + 白色卡片，含「完成！」、大号用时、
  用时/找对/点错统计、星级、新纪录时「🎉 新纪录！」、以及「再来一局」「返回首页」；
  `finishGame` 延迟 350ms 后展示，让最后一次点击的绿色高亮先被看到。
- **成绩页 `viewHistory`**：无记录时提示「暂无成绩，先来一局吧！」；否则按时间倒序列出
  最近 N 次（难度·场景 / 日期·点错次数 / 用时 / 星级）。
- **打卡页 `viewCheckin`**：本月日历（已打卡日高亮点亮 + 今日蓝色描边）+ 连续打卡天数
  （≥7 天显示 🎉）；打卡由完成游戏自动触发，本页仅展示。

### 5.1 状态模型（main.js `state`）

```js
{
  level: 3,          // 当前难度 3 / 5 / 8
  scene: null,       // 当前场景对象（SCENES 中随机选中）
  elems: [],         // 场景元素列表
  diffs: [],         // 差异列表 [{id, type}]（本轮出题）
  diffMap: {},       // id → {type, found}（命中判定）
  found: 0,          // 已找到差异数
  errors: 0,         // 点错次数
  started: false,    // 是否已开始计时（首个正确点击置 true）
  finished: false,   // 是否已结算
  startMs: 0,        // 开始计时时间戳（performance.now()）
  elapsed: 0,        // 结算用时 ms
  timerId: null,     // setInterval 句柄
  leftP: {},         // 左图渲染参数 id → {x,y,s,rot,fill,variant}
  rightP: {}         // 右图渲染参数（应用差异变换后）
}
```

## 6. 成绩持久化（localStorage key `redtools.finddiff.v1`）

```js
{
  version: 1,
  best:   { "3": {ms, date}, "5": null, "8": null },  // 各难度最佳（ms 更小覆盖）
  recent: { "3": ms, "5": 0, "8": 0 },                // 各难度最近成绩
  checkin: { dates: ["YYYYMMDD"], streak },           // 打卡日期（滚动 365 天）+ 连续天数
  history: [ {date, level, scene, ms, errors, stars} ] // 滚动 30 条，最新在前
}
```

- 读写均包 try/catch：`loadStore` 解析失败或首次打开返回默认结构；`saveStore` 写入失败静默。
- 启动时先 `loadStore()` 再 `saveStore()`（初始化写入，建立默认结构）。
- **最佳成绩**：`msRound = Math.round(elapsed)`；`best[level]` 为空或 `msRound < best.ms` 时
  覆盖为 `{ms, date}` 并标记新纪录（结果浮层显示「🎉 新纪录！」）。
- **最近成绩**：`recent[level]` 直接覆盖为本局用时。
- **历史**：`history.unshift(...)` 最新在前，`while (length > 30) pop()` 滚动保留 30 条；
  每条含 `scene` 字段（记录本局场景名，便于回顾）。

### 6.1 打卡逻辑（与学科系列/舒尔特方格一致）

- 完成一局即自动打卡：`todayStr()` 生成 YYYYMMDD，不在 `dates` 则 push，然后 `sort()`；
  `while (dates.length > 365) dates.shift()` 滚动保留 365 天。
- 连续天数 `calcStreak(dates)`：从日期列表末尾向前回推，**含今天**往前数连续天数，
  跨天即断（缺一天 streak 归零）；结果写入 `checkin.streak`，打卡页渲染时实时重算。
- 打卡无手动入口，本工具「完成一局」即点亮今日。

## 7. 关键实现点

### 7.1 双图渲染（`renderSceneSvg` / `elementSvg`）

- 左右两图共用**同一场景定义**，右图按 `rightP`（差异参数）渲染，左图按 `leftP`（原参数）渲染；
  无需存两张图，包体≈代码体积。
- 每个元素渲染为 `<g data-eid="元素id">`：
  - 内层 `<g transform="translate(x,y) scale(s) rotate(rot)" pointer-events="none">`：元素图形；
  - 透明命中圆 `<circle r="hitR" fill="rgba(0,0,0,0)" pointer-events="all" class="hit-circle">`：
    负责接收点击（触摸友好）。
- 图形 `pointer-events="none"` + 命中圆 `pointer-events="all"`：视觉上元素重叠时点击仍准确命中。
- 隐藏差异：`rightP[id].hidden=true`，右图 `renderSceneSvg` 跳过不渲染该元素 g。

### 7.2 点击判定（`onElementTap(eid, side)`）

- `state.finished` 时忽略（结算后不再响应）。
- `diffMap[eid]` 不存在 → 点错（`missAt`）。
- 已标记（`d.found`）→ 忽略（不重复计数）。
- **左图点击**：仅当该差异为 `hide`（右图无此元素）→ 正确；否则点错。
- **右图点击**：该差异在差异列表 → 正确（改色/变位/缩放/变体差异都在右图表现）。
- 正确 → `markFound`（绿色圆 + 对勾 polyline，持久）+ `found++` + 启动计时（首个）+ 更新进度；
  `found >= level` → `finishGame()`。
- 点错 → `missAt`（红色圆 + 双斜线叉，400ms 后自动移除）+ `errors++`。

### 7.3 标记实现（SVG 动态节点）

- 用 `document.createElementNS(SVG_NS, ...)` 创建标记节点（不重渲染 SVG，性能好）；
- 对勾/红叉定位用元素在**对应图**中的渲染参数 `p.x/p.y` + `hitR`；
- 对勾 `.fd-found`：`opacity` 淡入 0.3s（持久）；红叉 `.fd-miss`：淡入淡出 0.4s 后 JS 移除。

### 7.4 布局（双图对比）

- `.scene-pair`：移动端竖屏 `flex-direction: column`（上下堆叠，每图全宽）；
  `@media (min-width: 560px)` 切 `row`（左右并排，PC/横屏）。
- 间距用 margin（无 flex gap）；`.scene-wrap` 设 `min-width:0` 防溢出。
- SVG `width:100%; height:auto`（viewBox 保持比例），圆角卡片样式。

### 7.5 计时与安全区（同舒尔特方格）

- `performance.now()` 实算差值 + `setInterval(100ms)` 刷新（后台回来计时仍准）；
- `syncAppHeight()` 写 `--app-height`，`env(safe-area-inset-*)` + `@supports` 双兜底。

## 8. Chrome 61 / 合规约束

| 类别 | 约束 | 本工具做法 |
|---|---|---|
| JS 语法 | ES2017 上限经典脚本 | `var` + `function` 风格，无 `?.` `??` 对象展开 `replaceAll`；无 `type="module"`/import/export |
| 事件 | 全部 `addEventListener` | SVG 点击用事件委托（`g[data-eid]` 向上查找）；无内联事件 / eval |
| 网络 | 零网络请求 | 无 fetch/XHR/Worker/外部资源；无 audio；SVG 全代码生成（`http://www.w3.org/2000/svg` 仅为命名空间标识符，非网络请求） |
| 图片 | 无图片素材 | 除构建生成的 `assets/icon.png` 外，一切图形 SVG 代码生成；zip 内无额外图片文件 |
| CSS 语法 | Chrome 61 兼容层 | 无 flex `gap`/`aspect-ratio`/`clamp`/`inset`/逻辑属性/`:has`/`@container`/`dvh`；间距用 margin/padding；Flex 子项设 `min-width:0` |
| 动画 | 温和反馈（光敏安全） | 对勾淡入 0.3s、红叉淡入淡出 0.4s，无强频闪 |
| 触控 | 触摸友好 | 命中圆 hitR≥26px（直径≥52px）；按钮 min-height 48px |
