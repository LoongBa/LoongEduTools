## 2. 玩法设计

### 2.1 规则

- 每局抽 M 个不同元素：**上排 M 张「实物卡」**（原色图案，独立洗牌）+ **下排 M 张「影子卡」**（同一批元素的黑剪影，再洗一次牌，位置与实物不同）。
- **点实物**（选中，橙色描边）→ **点影子**：图案与影子形状一致 → 配对成功（两张卡绿色 ✓ 标记）；形状不一致 → 影子红闪 + 错误计数 +1 + 取消选中。
- 全部 M 对配对完成即过关。
- **价值**：孩子要对比「彩色图案的形状」与「黑色剪影的轮廓」——剥离颜色干扰、专注形状匹配。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 点实物卡 | 选中该实物（橙色高亮）；点同一张取消；点另一张切换 |
| 点影子卡 | 有选中实物 → 判定配对正确/错误；无选中 → 提示「先点上面的一个图案」 |
| 底栏按钮 | 「返回难度」回难度页；「重新开始」同难度重抽一局 |
| 顶栏按钮 | 「← 返回」回难度页 |

### 2.3 反馈

- **配对成功**：实物 + 影子卡绿色底 + `✓` 角标（`popCheck 0.35s`）+ 轻音效 + 配对计数 +1 + 已配对卡不可再点。
- **配对错误**：影子卡红闪（`wrongFlash 0.4s`，浅灰 ↔ 浅红）+ 低音效 + 错误计数 +1 + 取消实物选中，可继续尝试。
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件）：选中轻音 / 配对成功清脆 / 错误低沉 / 胜利琶音。

## 4. 技术设计

### 4.1 数据模型

- **难度常量 `LEVELS`**：

| key | 难度 | 对数 M | 列布局 |
|---|---|---|---|
| '1' | 简单 | 3 | 3 列单行 |
| '2' | 普通 | 4 | 4 列单行 |
| '3' | 困难 | 5 | 5 列单行 |

- **运行时状态**：`state = { level, ids:[eid...], objects:[eid...], shadows:[eid...], matched:[eid...], selectedObj, errors, won, startMs, ms, timerId }`。

### 4.2 元素库与出题

- `window.SCENES`（8 场景）+ `window.ELEMENTS`（73 元素平铺池），**复用找相同 elements.js**（元素 `draw({fill,variant})` 返回以 (0,0) 为中心的内层 SVG）。
- `newRound()`：池内随机抽 M 个**互不相同**的元素 id → `objects = shuffle(ids)` + `shadows = shuffle(ids)`（**双行独立洗牌**，保证影子顺序与实物不同）。
- `isMatched(eid)`：已配对 eid 集合判断（配对后实物/影子行对应卡禁用）。

### 4.3 ⭐ 影子实现：同一元素 SVG + CSS `filter: brightness(0)`

- 影子卡渲染**与实物完全相同的 SVG 字符串**（统一 `class="cell-svg"`），仅由所在容器区别：
  - 实物卡容器 `.obj-cell`：白色底，原色显示；
  - 影子卡容器 `.shd-cell`：浅灰底 + CSS 滤镜 `.shd-cell .cell-svg { filter: brightness(0); -webkit-filter: brightness(0); }` —— 将图形整体压成**纯黑剪影**（保留形状，透明背景不受影响）。
- **优点**：零元素库改造、零逐元素颜色分析；Chrome 61 支持 `filter`（自 Chrome 53 起无前缀）；SVG 字符串一致还便于自动化测试做「实物 ↔ 影子」匹配校验（冒烟测试依赖此一致性）。
- **即物即影**：集合 patch，新增元素进库即自动获得影子能力。

### 4.4 交互与判定

- `onObjTap(i)`：已配对实物忽略；点同一张取消选中、点另一张切换；无配对状态下允许选中。
- `onShdTap(j)`：已配对影子忽略；无选中实物 → 轻提示；判定 `objects[selectedObj] === shadows[j]`：
  - 相同 eid → `matched.push(eid)` + 双卡 `matched` 类（绿勾）+ 计数 +1；全部配对 → `onWin()`；
  - 不同 eid → `errors++` + 影子 `wrong` 红闪 400ms + 取消选中 + 提示。
- 列宽类 `m3/m4/m5` 控制 CSS 列数。

### 4.5 计时

- `startTimer()`：`performance.now()` + `setInterval(100ms)` 差值刷新 `'⏱ ' + fmtTime(ms)`（秒 + 1 位小数）。
- 进入游戏页即开始计时（整局计时）；v1.0 无断局恢复。

### 4.6 星级与最佳成绩

- **星级**（按错误次数）：★★★ 错误 0 次；★★ 错误 ≤2 次；★ 其余（过关即有）。
- **最佳判定** `betterThan`：星级高优先，同星级比用时短；仅严格更优才覆盖。
- **最近/历史**：`recent` 无条件覆盖、`history` 滚动保留最近 30 条。

### 4.7 持久化（localStorage）

- key：`redtools.yingzipedui.v1`（工具前缀）。
- 结构：`{ version:1, best:{}, recent:{}, checkin:{dates,streak}, history:[...] }`（各难度最佳 / 最近用时 / 打卡 / 滚动 30 条记录）。
- 读写全部 try/catch；`loadStore()` 校验 `version === 1` 并补全缺失字段。
- **打卡** `doCheckin()`：过关一局 → 今日 YYYYMMDD 去重 + 排序 + 滚动 365 天；`calcStreak()` 含今天往前推、跨天断。

### 4.8 音效（Web Audio 合成）

```js
sndClick:   sine  392Hz 0.06s   // 选中（轻）
sndCorrect: triangle 523Hz 0.09s // 配对成功（清脆）
sndWrong:   square 150Hz 0.12s  // 错配（低沉）
sndWin:     523/659/784/1047 上行琶音
```

`AudioContext`（含 `webkitAudioContext` 兜底）懒创建 + 用户手势 `resume()`；全部 try/catch 降级。

### 4.9 视图结构

- 三个视图 + 一个浮层：**难度选择页** / **游戏页** / **打卡日历页**；**结算浮层**（`🎉 全配齐啦！` + 星级 + 统计 + 打卡 + 三按钮：再来一局 / 选难度 / 打卡日历）。
- 每次切视图 `clearNode` 全量重建 DOM；卡片正方形 `width` + `padding-bottom` 百分比；打卡日历 7 列网格同系列（done 橙 / today 蓝描边 / streak-info）。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：ES2017 经典脚本（var + function），无 `?.`/`??`/对象展开/`replaceAll`/module/import；无内联事件/eval；事件全部 `addEventListener`；无 fetch/XHR/Worker；localStorage try/catch。
- CSS：无 `gap`/`aspect-ratio`/`clamp()`/`inset`/逻辑属性/`:has`/`@container`/`dvh`；flex 三重前缀；动画双写前缀（`popCheck`/`wrongFlash` ≤400ms 无频闪）；`filter` 双层前缀（Chrome 61 支持）；正方形网格 `width` + `padding-bottom` %；安全区 `env(safe-area-inset-*)`。
- 触控：按钮/卡片 hit area ≥48px。
- 资源：全部内联/本包；无外部 URL；图形 SVG 代码生成 + 音效 Oscillator 合成 → **零图片零音频零数据文件**。
- 包体：0.03 MiB（≪ 2 MiB 建议值）。
