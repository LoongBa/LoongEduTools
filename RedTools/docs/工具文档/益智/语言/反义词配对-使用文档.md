# 反义词配对 — 使用文档

> 词汇语义训练：把意思相反的词配成一对，全部配对就过关。
> 适用：手机 / 电脑（点选即可）。
> 版本：v1.0 · 更新：2026-09-19

---

## 1. 怎么玩

1. 打开工具，在**难度选择页**选一个难度：简单 3 对（6 张）/ 普通 4 对（8 张）/ 困难 5 对（10 张）。
2. 屏幕上是打乱了的**词卡**（每张有 emoji 图标 + 大字词），比如「大🐘」「小🐭」「热🔥」「冷❄️」。
3. **先点一张词卡**（会亮绿色边框），**再点另一张**：
   - 如果两张**意思相反**：都打上绿色 ✓，配对计数 +1；
   - 如果不是反义词：两张红闪一下，错误次数 +1，重新选。
4. 把所有反义词都配成对，就过关啦！每局的词对都是程序随机抽的。

## 2. 游戏规则

| 规则 | 说明 |
|---|---|
| 目标 | 把意思相反的词两两配成一对 |
| 操作 | 点第一张（选中）→ 点第二张（判定）；点同一张取消选中 |
| 配对成功 | 两卡 ✓ 角标 + 绿框 + 变淡，计数 +1 |
| 配错 | 两卡红闪，错误 +1，取消选中可重试（不扣分不结束） |
| 出题 | 内置 28 对常用反义词库，每局随机抽 3/4/5 对 + 洗牌 |
| 星级 | 0 错 3★ / 1~2 错 2★ / 3 错及以上 1★（通关即有） |
| 技巧 | 先想「表示相反的词」再找卡；不看 emoji 也能认字就来读词 |

## 3. 界面说明

- **难度选择页**：三个难度卡片，显示该难度**最佳成绩**（星级 · 用时 · 错误次数），底部是打卡日历入口。
- **顶栏**：`← 返回`、当前难度名、`⏱ 用时`（**进入游戏页即开始**计时，整局计时）。
- **配对计数**：游戏页上方「配对 n/N」实时显示进度。
- **词卡**：2 列大卡，emoji + 词语；选中 = 绿框；配对 = ✓ + 绿框 + 变淡；配错 = 红闪。
- **错误计数**：游戏页底栏 `❌ N` 实时显示本局配错次数。

## 4. 成绩与打卡

- **星级**（按本局配错次数，宽松友好）：一次没错 ★★★；错 1~2 次 ★★；3 次及以上 ★。
- 每过关一局即点亮**今日打卡**；打卡日历显示本月打卡与连续天数（连续 7 天及以上有 🎉）。
- 各难度分别记录**最佳成绩**（星级高优先，星级相同比用时短）；**最近用时**与最近 **30 局**成绩记录自动保存。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- **先盯住一张卡**：选中一张后心里想「它的反义词是什么」，再去找对应卡，减少乱点。
- emoji 是提示不是答案：小🐘/蚂蚁🐜 能帮认词，但真正要比的是**词的意思**（比如「上」的相反是「下」，不是形状相反）。
- 点错了不着急，红闪一下就过去，卡都还在，重新配就行。
- 想换一组？游戏中点「重新开始」用相同难度重抽（新词对），或点「返回难度」换档。
- 每局词对随机抽取，不会重复出题。

## 6. 常见问题

**Q：配错会扣分或结束吗？**
不会。配错只计错误次数（影响星级），词卡都保留，重新选配即可，全程无惩罚。

**Q：为什么有的不是反义词也看着很像？**
反义词是**意思相反**（大↔小、热↔冷），不是「长得像」或「一个类别的」（比如苹果和梨是同类，不是反义词）。可以多玩几局熟悉常见反义词。

**Q：emoji 是干什么用的？**
帮小朋友识别词义（比如🐘 大 / 🐭 小）。等识字多了可以只看词不看图。

**Q：适合几岁的孩子？**
定位小学阶段（K1-3–K4-6）。简单档 3 对（大-小、热-冷这类最基础的反义词）适合刚学；困难档 5 对、词更抽象（休息-运动、安静-吵闹），适合大孩子。

**Q：成绩怎么清除？**
目前没有「清空成绩」按钮。成绩保存在设备浏览器的 localStorage 中，清除浏览器数据即可清空；换设备不会同步，请注意。
