## 2. 玩法规则

### 2.1 规则

- 从难度池随机取一条**步数匹配的叙事故事序列**，把故事卡片打乱。
- 目标：按故事情节发生顺序把卡片全部排好（`cards[i].stepIdx === i`，数组槽位 = 正确情节步序）。
- 交互：**点选一张卡片（橙色高亮）→ 点另一张 → 交换位置**；点已选中的卡片取消选中。
- 全部归位即过关；**排序类无「错动作」**：任何交换都被接受，不会像分类整理/数独那样报错，**步数即操作质量**（交换次数越少越好）。
- 每局序列随机抽取 + 洗牌，孩子不会背顺序。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 点卡片（无选中） | 选中该卡（橙色高亮 + 轻微抬起 + 轻音效） |
| 点已选中卡片 | 取消选中 |
| 点另一张卡片 | 交换两张位置（重渲染 SVG + 280ms 弹跳动画 + 步数 +1 + 轻音效） |
| 💡 提示 | 高亮第一张错位卡片 1.2s（温和脉冲，**不自动归位**）；提示次数 +1（星级封顶 2★） |
| 重新开始 | 同难度重抽一局（重新取序列 + 重新洗牌） |
| 返回难度 | 回难度选择页 |

### 2.3 反馈

- **选中**：卡片橙色高亮 + 轻微抬起；**交换**：两张卡 280ms 弹跳动画（`swap-anim`）+ 轻音效。
- **提示**：第一张错位卡 1.2s 温和脉冲（`hinting` 呼吸），只「告诉你看哪张」，不代做。
- **通关**：全部卡片绿色边框闪烁 400ms（`solved`）+ 确认音 + 胜利上行琶音，350ms 后弹结算浮层「🎉 排好啦！」。
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件）：点选（520Hz 0.05s triangle）/ 交换与提示（660→990 双音）/ 胜利（523/659/784/1047 上行琶音，同因果排序）。首次用户手势创建 `AudioContext`，播放异常静默降级。

## 3. 难度与星级

### 3.1 三档难度（按卡片步数 N）

| key | 难度 | 步数 N | 序列池（随机取 1） | 3★ 步数上限（2N−1） | 2★ 步数上限（3N） |
|-----|------|-------|-------------------|---------------------|-------------------|
| '3' | 简单 | 3 | 小宇的早晨 / 去野餐 | 5 | 9 |
| '4' | 普通 | 4 | 放风筝 / 下雨啦 / 煮面条 / 种番茄 | 7 | 12 |
| '5' | 困难 | 5 | 逛动物园 / 露营之夜 | 9 | 15 |

- 序列池按难度硬编码在 `main.js` 的 `SEQ_POOL`（`'3'`→morning/picnic、`'4'`→kite/rain/noodle/tomato、`'5'`→zoo/camp）；`pickSequence` 池未命中时按 `steps.length` 全库兜底。

### 3.2 星级（= f(提示, 步数)，`calcStars`）

| 条件 | 星级 |
|---|---|
| 提示 0 次 **且** 步数 ≤ N×2−1（3→5、4→7、5→9） | ★★★ |
| 提示 ≤1 次 **且** 步数 ≤ N×3（3→9、4→12、5→15） | ★★ |
| 其余（过关即有） | ★ |

- 用过提示星级**封顶 2★**。
- **最佳判定 `betterThan(starsA, msA, starsB, msB)`**：**星级高优先，同星级比用时短**；仅严格更优才覆盖 `store.best[key]`。
- **最近**：`store.recent[key]` 无条件覆盖为本局用时；**历史**：`history` 无条件 push 后滚动保留最近 30 条。
- 结算浮层展示：星级 + 「用时 X 秒 · 步数 N 次 · 提示 N 次」+ ✅ 今日已打卡 + 新纪录徽标 + 三按钮（再来一局 / 选难度 / 📅 打卡日历）。

## 4. 叙事序列库（stories.js，`window.STORIES`）

8 条「看图讲故事」叙事序列，共 **32 张故事卡**，全部程序化 SVG 生成、零图片素材。每条序列 = `{ id, name, steps: [drawFn, ...] }`，`steps` 数组顺序即正确故事情节顺序（`steps[0]` 最先发生）。

| id | 序列 | 步数 | 各步内容（steps[0] → 最后） |
|----|------|------|------------------------------|
| morning | 小宇的早晨 | 3 | 起床（被窝里太阳升起）→ 餐桌吃早餐 → 背书包上学去 |
| picnic | 去野餐 | 3 | 准备野餐篮 → 草地上铺开毯子 → 围坐分享 |
| kite | 放风筝 | 4 | 桌上做风筝 → 举着风筝到草地 → 奔跑起飞 → 风筝飞上天空 |
| rain | 下雨啦 | 4 | 乌云飘来 → 落下雨点 → 撑起雨伞 → 雨后彩虹 |
| noodle | 煮面条 | 4 | 水烧开冒泡 → 面条下锅 → 加入蔬菜 → 端碗开吃 |
| tomato | 种番茄 | 4 | 挖土播种 → 发芽出土 → 浇水长大 → 结出红番茄 |
| zoo | 逛动物园 | 5 | 买门票进园 → 看大象 → 喂小羊 → 看猴子 → 开心回家 |
| camp | 露营之夜 | 5 | 搭帐篷 → 点起篝火 → 烤棉花糖 → 数星星 → 甜甜入睡 |

- **程序化 SVG 卡片**：每张卡 `viewBox="-65 -65 130 130"`，内容以 (0,0) 为中心，糖果色童趣扁平风；由 `sky/ground/greenHill/cloud/sunRays/sunm/moonArc/kid/treem/bird/bowl` 等共享场景配件 + 序列专属 drawFn 拼装，`w()` 包装为完整 `<svg>`（`caus-card-svg`）；形状工具 `c/cc/ce/rc/pl/pa/ps/ln/starPts/star`（与因果排序/简单拼图局部风格一致）。
- **cc 圆心圆 vs c 原点圆命名约定**：形状工具中 `cc(cx, cy, r, f)` 是**四参圆心圆**（显式指定圆心坐标），`c(r, f)` 是**原点圆**（圆心固定在 (0,0)）。`rc(x, y, w, h, f, rx)` 参数顺序为 x/y/宽/高/**填充色**/圆角。**修复记录（v1.0 视觉质检发现）**：`rc()` 曾存在参数颠倒 bug（rx/fill 顺序互换导致部分卡圆角/填充错乱），已修复为 fill 在前、rx 在后；此后新卡片统一按此签名。
- **情节递进是卡片设计核心**：同一条序列内每张卡必须有肉眼可辨的「状态推进」（煮面条：水开 → 下面 → 加菜 → 开吃；种番茄：播种 → 发芽 → 浇水 → 红果），跨序列不重复图形；视觉质检按此标准逐卡校验。**v1.0 已优化**：zoo 序列「看猴子」卡放大猴身/长尾/攀枝动作、「开心回家」卡放大气球，提升辨识度。

## 6. 成绩持久化（localStorage）

- key：`redtools.tushuopaixu.v1`（容器内多工具共享存储，必须带工具前缀）。
- 结构：

```js
{
  version: 1,
  best:    { "3": {ms, moves, hints, stars, date}, "4": {...}, "5": {...} },  // 各难度最佳
  recent:  { "3": ms, "4": ms, "5": ms },                                     // 各难度最近用时
  checkin: { dates: ["YYYYMMDD", ...], streak },                              // 打卡
  history: [ {date, level, ms, moves, hints, stars} ]                         // 滚动 30 条
}
```

- 读写全部 try/catch（隐私模式等异常静默降级）；`loadStore()` 校验 `version === 1` 并补全缺失字段（best/recent/checkin/history），history 超 30 条截尾；初始化写入一次。
- **打卡 `doCheckin()`**：通关一局 → `dates` 写入今日 YYYYMMDD（去重 + 排序）、滚动 365 天；`calcStreak()` 连续天数**含今天往前推**（今天未打则从昨天起算），跨天断。
- **计时**：从**游戏页渲染开始**（`startTimer()` 在 `startGame` 中调用，整局计时）；`performance.now()` + `setInterval(100ms)` 按差值刷新 `⏱ 07.5`（秒 + 1 位小数）；通关 `stopTimer()` 定格。

## 7. 关键实现点

| 模块 | 实现 |
|------|------|
| 出题防还原重洗 | `pickSequence(lv)` 难度池随机取 1 条（池未命中按 `steps.length` 全库兜底）→ `buildCards(seq)` Fisher-Yates 洗牌，**`isSortedArr` 为真则重洗（guard ≤ 100）** |
| 归位判定 | `isSolved()` 全遍历 `cards[i].stepIdx === i`（数组槽位 = 正确步序）；`firstMisplaced()` 返回第一张错位槽位（-1 表示全归位） |
| 点选/交换 | `onCardTap(slot)`：无选中→选中（`selected` 橙色高亮 + 抬起）；点同张取消；点另一张→`swapSlots(a,b)` 换数组 + `updateCardSvg` 重渲染两张 + 280ms 弹跳（`swap-anim`）+ 音效 + 步数 +1 + 归位判定 |
| 提示脉冲 | `useHint()` → `firstMisplaced` 高亮该卡 1.2s（`hinting` 呼吸脉冲，一次呼吸温和），提示次数 +1，双音确认；**不自动归位** |
| 通关结算 | `finishGame()` 全卡 `solved` 绿色闪烁 400ms + 确认/胜利音，350ms 后 `showSettlement()` 弹浮层；提示按钮禁用 |
| 音效合成 | Web Audio `OscillatorNode`：`sndClick`(520Hz triangle)/`sndCorrect`(660→990)/`sndWin`(523/659/784/1047 上行琶音)；首次手势创建 `AudioContext`，异常静默降级 |
| 计时 | `performance.now()` 起点 + `setInterval(100ms)` 差值刷新 `⏱ 07.5`；游戏页渲染即开始（整局计时），通关定格 |

## 11. 与系列规范的关系

- **系列归属**：`产品矩阵规划.md` §4.7 语言表达训练（P1 看图说话排序）→ `series/益智/语言/` 子系列**首款**；对标小象「语言」/未来之光「故事接龙」，适用 K1-3–K4-6（L2–L3）。
- **可复用核心**：计时/成绩/打卡对齐 `series/益智/设计文档.md` §4（localStorage key 带工具前缀 + 打卡日历模式，与舒尔特方格/因果排序同款）；Chrome 61 / 交互合规对齐 §5。
- **与同系列的差异**：因果排序以「因果/时间先后」排序、卡片是单步骤画面，本工具改为**完整小故事的情节顺序**（人物/物品/地点连贯），训练看图讲故事与**表达逻辑**；星级与交互机制与因果排序**完全同构**（提示×步数双指标、排序类无「错动作」、计时从游戏页渲染开始、难度以卡片步数区分）。
- **交互复用因果排序**：点选两张交换（选中高亮 / 点同张取消）、数组槽位 = 目标位归位判定、Fisher-Yates 洗牌 + **防「恰好还原」重洗（guard≤100）**、提示/星级/结算/打卡全套机制均沿用 `series/益智/逻辑思维/因果排序`（逻辑思维第 5 款已交付）。
- **程序化 SVG 新主题**：在因果排序「程序化 SVG 步骤卡片」基础上换为**清新绿主题**（语言子系列配色 `#f2f9f0/#45ae72/#2FBF9E`，区别于逻辑思维天蓝系），共享场景配件新增 `moonArc`（露营夜景）、`bowl`（煮面碗）、`bird` 等；序列库独立成 `stories.js`，后续可整体扩展新故事序列。
- **语言子系列起点**：益智七大能力至此 **6 个子系列落地**（专注力/观察力/记忆力/逻辑思维/空间感知/反应力 + 语言）；语言维度后续故事复述/反义词配对/绕口令节奏可复用本工具成绩打卡模式。
- **扩展**：`SEQ_POOL` 加序列 id 即可扩档；`stories.js` 新增 `{id, name, steps}` 即新增故事序列；后续可加断局恢复（`state` 快照持久化）、拖拽排序（交互升级）、更多生活/自然/节日故事序列。
