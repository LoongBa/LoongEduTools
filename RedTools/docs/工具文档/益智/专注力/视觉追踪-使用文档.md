# 视觉追踪 — 使用文档

> 持续注意力训练：用眼睛跟着目标泡泡走，它停下来后点出它现在的位置。
> 适用：手机 / 电脑（点选即可）。
> 版本：v1.0 · 更新：2026-09-19

---

## 1. 怎么玩

1. 打开工具，在**难度选择页**选一个难度：
   - 简单：6 个泡泡 · 追 3 秒 · 5 轮；
   - 普通：8 个泡泡 · 追 4 秒 · 6 轮；
   - 困难：10 个泡泡 · 追 5 秒 · 8 轮。
2. 每轮开始，屏幕上有几只**长得一模一样的泡泡**在动，其中**一个泡泡会亮起橙色光环**（1.5 秒）——它就是本轮要追的目标！
3. 光环消失后，所有泡泡看起来完全一样，**用眼睛盯住刚才那个目标泡泡**不放。
4. 几秒后泡泡全部**停住**，**点一下目标泡泡现在的位置**：
   - 点对：泡泡绿闪，进入下一轮；
   - 点错：泡泡红闪，错误次数 +1，可以再点（不惩罚）。
5. 全部轮次追完，就过关啦！每轮目标、泡泡、运动方向都是随机生成的。

## 2. 游戏规则

| 规则 | 说明 |
|---|---|
| 目标 | 追踪开头高亮的那个泡泡，停止后点出它 |
| 操作 | 标记阶段记住目标；停止阶段点目标泡泡（移动中不可点） |
| 标记 | 目标橙色光环仅 1.5 秒，消失后只能靠眼睛追踪 |
| 泡泡 | 全部外观一致（同一图案），唯一线索 = 视觉追踪 |
| 难度 | 简单 6 泡·3s·5 轮 / 普通 8 泡·4s·6 轮 / 困难 10 泡·5s·8 轮 |
| 点错 | 红闪 + 错误 +1，可继续点（不扣分不结束） |
| 星级 | 0 错 3★ / 1~2 错 2★ / 3 错及以上 1★（通关即有） |
| 技巧 | 眼睛**粘住目标**别眨眼，泡泡会反弹转向——盯住它走过的轨迹 |

## 3. 界面说明

- **难度选择页**：三个难度卡片，显示该难度**最佳成绩**（星级 · 用时 · 错误次数），底部是打卡日历入口。
- **顶栏**：`← 返回`、当前难度名、`⏱ 用时`（**进入游戏页即开始**计时，整局计时）。
- **轮次指示**：游戏页上方「第 x/y 轮」。
- **状态行**：标记时「记住这个泡泡！」→ 追踪时「眼睛跟上它，别跟丢！」→ 停止时「点一下目标泡泡现在的位置」。
- **棋盘**：浅蓝圆角区域，泡泡在里面漂移（碰到边缘会反弹）。
- **错误计数**：游戏页底栏 `❌ N` 实时显示本局点错次数。

## 4. 成绩与打卡

- **星级**（按本局点错次数，宽松友好）：一次没错 ★★★；错 1~2 次 ★★；3 次及以上 ★。
- 每过关一局即点亮**今日打卡**；打卡日历显示本月打卡与连续天数（连续 7 天及以上有 🎉）。
- 各难度分别记录**最佳成绩**（星级高优先，星级相同比用时短）；**最近用时**与最近 **30 局**成绩记录自动保存。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- **标记出现时别眨眼**：1.5 秒很短，第一眼先锁定目标的位置和它即将移动的方向。
- 泡泡反弹时会突然转向，眼睛要**跟着它动**而不是盯着某块区域。
- 点错不着急，泡泡停在原地，红闪一下继续找，孩子压力小。
- 想换一局？游戏中点「重新开始」用相同难度重抽，或点「返回难度」换档。
- 每轮目标、泡泡数量、运动方向全随机，不会重复出题。

## 6. 常见问题

**Q：泡泡怎么都长得一样？**
对——这正是训练目的：泡泡全部同款，**没有颜色/形状线索可偷懒**，只能靠眼睛追踪目标（这是经典的视觉追踪训练范式）。

**Q：点错会不会扣分或结束？**
不会。点错只计错误次数（影响星级），泡泡停在原位可以继续点，直到点对为止，全程无惩罚。

**Q：目标标记只亮一下，来不及看怎么办？**
简单档只有 6 个泡泡、标记 1.5 秒，足够看一眼；如果跟不上，可以先在简单档多练，再逐步升普通/困难。

**Q：适合几岁的孩子？**
定位较广（preK 到小学中年级）。简单档 6 泡 3 秒起步友好；困难档 10 泡 5 秒、泡泡更多更久，适合大孩子挑战追踪耐力。

**Q：成绩怎么清除？**
目前没有「清空成绩」按钮。成绩保存在设备浏览器的 localStorage 中，清除浏览器数据即可清空；换设备不会同步，请注意。
