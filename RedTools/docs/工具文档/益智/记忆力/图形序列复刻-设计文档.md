## 2. 玩法设计

### 2.1 规则

- 每局 **5 轮**。每轮：
  1. **播放阶段**：生成一段颜色序列（随机色块下标，可重复），色块**依次点亮**（每个亮 600ms + 间隔 350ms，点亮伴随**音高提示音**——颜色→音高，视听双通道）；
  2. **复刻阶段**：孩子按顺序点色块复刻。
- 复刻：点对一个 → 闪烁确认 + 进度 +1；**点错 → 红闪 + 错误计数 +1 + 复刻进度清零并重新播放序列**（播放不扣分，低龄友好——看几次都行）。
- 全部 5 轮完成即过关。
- **价值**：序列长度固定但每次随机，需要孩子短时记住「颜色顺序」并输出——序列记忆核心训练。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 点色块按钮 | 复刻阶段：判定位序正确/错误；播放阶段不可点（禁用） |
| 底栏按钮 | 「返回难度」回难度页；「重新开始」同难度重抽一局 |
| 顶栏按钮 | 「← 返回」回难度页 |

### 2.3 反馈

- **播放点亮**：色块放大 + 外发光（`lit` 类 600ms）+ 音高音效。
- **复刻正确**：色块放大白环闪烁（`flashOk 300ms`）+ 音高音效 + 进度「已复刻 n/len」更新。
- **复刻错误**：色块亮度骤降再恢复（`wrongFlash 0.4s`）+ 低音效 + 错误计数 +1 → 600ms 后重新播放序列。
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件）：播放/复刻按色块下标递增高音（392Hz+60×idx），错误低沉，胜利琶音。

## 4. 技术设计

### 4.1 数据模型

- **难度常量 `LEVELS`**：

| key | 难度 | 序列长度 len | 色池大小 | 每局轮数 |
|---|---|---|---|---|
| '1' | 简单 | 3 | 3 色 | 5 |
| '2' | 普通 | 4 | 4 色 | 5 |
| '3' | 困难 | 5 | 5 色 | 5 |

- **运行时状态**：`state = { level, totalRounds:5, round, seq:[色下标...], seqPos, phase:'idle'|'playing'|'repro'|'win', playTimers, errors, won, startMs, ms, timerId }`。

### 4.2 出题与播放

- `genSequence(len, colorCount)`：`[randInt(colorCount) × len]`（允许重复，序列天然多样）。
- `startRound()`：生成序列 → `renderSeqPreview()`（预览点）→ `updateProgress()` → 播放：每个色块 `lit` 600ms（`setTimeout` 链，间隔 950ms）→ 播放结束进入复刻（`phase='repro'` + 按钮启用）。
- `clearPlayTimers()`：切视图/重开时清残留定时器（防泄漏）。
- 点错重放：`onColorTap` 错误分支 → `errors++` + `seqPos=0` + 按钮禁用 → 600ms 后重新 `startRound()`（新随机序列）。

### 4.3 复刻判定

- `onColorTap(ci)`：`phase!=='repro'` 忽略；`ci === seq[seqPos]` → `flashOk` + `seqPos++`；全对 → 600ms 后 `nextRound()`；不等 → `flashWrong` + 错误分支（见上）。

### 4.4 计时

- `startTimer()`：`performance.now()` + `setInterval(100ms)` 差值刷新 `'⏱ ' + fmtTime(ms)`（秒 + 1 位小数）；进入游戏页即开始。
- v1.0 无断局恢复（中途退出回难度页重抽）。

### 4.5 星级与最佳成绩

- **星级**（按错误次数）：★★★ 错误 0 次；★★ 错误 ≤2 次；★ 其余（过关即有）。
- **最佳判定** `betterThan`：星级高优先，同星级比用时短；仅严格更优才覆盖。最近/历史同系列模式。

### 4.6 持久化（localStorage）

- key：`redtools.tuxingxuliefuke.v1`（工具前缀）。
- 结构：`{ version:1, best:{}, recent:{}, checkin:{dates,streak}, history:[...] }`（各难度最佳 / 最近用时 / 打卡 / 滚动 30 条）。
- 读写 try/catch；`loadStore()` 校验 `version === 1` 并补全缺失字段；打卡 `doCheckin()` YYYYMMDD 去重 + 365 滚动 + `calcStreak()` 含今天往前推。

### 4.7 音效（Web Audio 合成）

```js
playNote(idx): sine (392+60*idx) Hz 0.1s   // 播放/复刻确认（颜色越靠后越高）
sndWrong:     square 150Hz 0.12s            // 复刻错误
sndCorrect:   triangle 523Hz 0.09s
sndWin:       523/659/784/1047 上行琶音
```

`AudioContext`（含 `webkitAudioContext`）懒创建 + 用户手势 `resume()`；全部 try/catch 降级。

### 4.8 视图结构

- 三个视图 + 一个浮层：**难度选择页** / **游戏页** / **打卡日历页**；**结算浮层**（星级 + 统计 + 打卡 + 三按钮）。
- 每次切视图 `clearNode` 全量重建 DOM；打卡日历 7 列网格同系列（done 橙 / today 主色描边 / streak-info）。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：ES2017 经典脚本（var + function），无 `?.`/`??`/对象展开/`replaceAll`/module/import；无内联事件/eval；事件全部 `addEventListener`；无 fetch/XHR/Worker；localStorage try/catch；`setTimeout` 句柄统一管理。
- CSS：无 `gap`/`aspect-ratio`/`clamp()`/`inset`/逻辑属性/`:has`/`@container`/`dvh`；flex 三重前缀；动画双写前缀（`wrongFlash`/`popCard` ≤400ms）；`filter: brightness()` 动画双层前缀（Chrome 61 支持）；安全区 `env(safe-area-inset-*)`。
- 触控/光敏：按钮 hit area ≥48px（色块 76px）；动画温和无频闪。
- 资源：全部内联/本包；无外部 URL；色块纯 CSS + 音效 Oscillator → **零图片零音频零数据文件**。
- 包体：0.02 MiB（≪ 2 MiB 建议值）。

## 8. 与系列规范的关系

- **系列归属**：`产品矩阵规划.md` §4.3 记忆力训练（P1 图形序列复刻）→ `series/益智/记忆力/` 子系列第 3 款；适用 preK–K1-3（L1–L2）。
- **可复用核心**：计时/成绩/打卡对齐 `series/益智/设计文档.md` §4；Chrome 61 / 交互合规对齐 §5。
- **与同系列差异**：翻牌/数字记忆以「步数/位数」为指标，本工具以**序列长度 × 错误次数**为难度与星级维度；**首个纯 CSS 色块游戏**（无 SVG 库依赖）；点错采用「重放序列」而非「给答案」——保持记忆训练完整性（与分类整理防卡高亮提示不同：此处不代做，只重播）。
- **扩展**：`LEVELS` 可加长度/轮数档位；后续可加「形状序列」（色块换图形图标）、候选干扰（复刻时展示多个色块防猜）、节奏序列（快慢变化）。
