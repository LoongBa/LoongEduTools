# 位置记忆 — 使用文档

> 位置记忆训练：先记住图案藏在哪个格子，藏起来后再把它们一个个找出来。
> 适用：手机 / 电脑（点选即可）。
> 版本：v1.0 · 更新：2026-09-19

---

## 1. 怎么玩

1. 打开工具，在**难度选择页**选一个难度：
   - 简单：3×3 盘 · 记 4 个图案的位置；
   - 普通：4×4 盘 · 记 6 个图案的位置；
   - 困难：4×4 盘 · 记 8 个图案的位置（展示时间更短）。
2. **看一遍**：进入游戏后，网格里显示出几个彩色图案，屏幕上方有倒计时（「记住图案的位置！还有 x 秒」），**趁这段时间记住每个图案藏在哪个格**。
3. 时间到，图案全部藏起来（格子变成「?」）。
4. 上方出现**要找的图案**（大卡提示「找出这个图案！」），点它藏的位置：
   - 点对了：格子翻出图案并打上绿勾，进度 +1，进入下一个目标；
   - 点错了：格子红闪一下，错误次数 +1，继续找（不惩罚、可重试）。
5. 把所有图案都找到，就过关啦！每局图案、位置、找的顺序都是随机生成的。

## 2. 游戏规则

| 规则 | 说明 |
|---|---|
| 目标 | 隐藏后，按提示把每个图案从正确位置找出来 |
| 操作 | 展示阶段只看不点；查找阶段点格子 |
| 展示 | 简单/普通 5 秒、困难 4 秒倒计时后自动隐藏 |
| 点对 | 翻回图案 + 绿勾 + 进度 +1（该格保持显示） |
| 点错 | 红闪 + 错误 +1，可继续点（不翻回、不惩罚） |
| 出题 | 24 个图案库随机抽（简单 4 / 普通 6 / 困难 8），位置与找的顺序均随机 |
| 星级 | 0 错 3★ / 1~2 错 2★ / 3 错及以上 1★（通关即有） |
| 技巧 | 记位置时**默念「苹果在第三格」**，找的时候先排除已找到的格子 |

## 3. 界面说明

- **难度选择页**：三个难度卡片，显示该难度**最佳成绩**（星级 · 用时 · 错误次数），底部是打卡日历入口。
- **顶栏**：`← 返回`、当前难度名、`⏱ 用时`（**进入游戏页即开始**计时，展示倒计时也算在内）。
- **状态行**：展示时显示「记住图案的位置！还有 x 秒」；查找时显示「找到 n/x 个图案」。
- **目标提示大卡**：查找阶段顶部显示「要找的图案」图标 +「找出这个图案！」。
- **网格**：3×3 或 4×4 方格；展示=图案可见、隐藏=`?` 背面、找到=绿色描边+图案。
- **错误计数**：游戏页底栏 `❌ N` 实时显示本局点错次数。

## 4. 成绩与打卡

- **星级**（按本局点错次数，宽松友好）：一次没错 ★★★；错 1~2 次 ★★；3 次及以上 ★。
- 每过关一局即点亮**今日打卡**；打卡日历显示本月打卡与连续天数（连续 7 天及以上有 🎉）。
- 各难度分别记录**最佳成绩**（星级高优先，星级相同比用时短）；**最近用时**与最近 **30 局**成绩记录自动保存。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- **展示时间很宝贵**：别只看热闹，要把每个图案「钉」在位置记忆里（心里默念几遍位置）。
- 找的时候**先看目标图案**，再在网格里回忆——不要乱点试探（乱点会增加错误次数，影响星级）。
- 点错了不着急，红闪一下就过去，继续凭记忆找。
- 想换一局？游戏中点「重新开始」用相同难度重抽（新的图案、新的位置），或点「返回难度」换档。
- 每局图案、位置、顺序全随机，不会重复出题。

## 6. 常见问题

**Q：展示时间太短记不住怎么办？**
简单档 5 秒记 4 个图案是低龄友好起步；如果觉得快，先玩简单档多练几局，再升普通/困难。这是记忆训练，记不住正是要练的部分。

**Q：点错了要重来吗？**
不用。点错只计错误次数（影响星级），格子不翻回，你可以继续凭记忆找正确的位置。

**Q：已经找到的格子还能点吗？**
不能。找到的格子会保持显示图案并打绿勾，再点它没有反应，避免误操作。

**Q：适合几岁的孩子？**
定位较广（preK 到小学中年级）。简单档 3×3 盘 4 图案适合刚开始；困难档 4×4 盘 8 图案、展示仅 4 秒，适合大一点的孩子挑战。

**Q：成绩怎么清除？**
目前没有「清空成绩」按钮。成绩保存在设备浏览器的 localStorage 中，清除浏览器数据即可清空；换设备不会同步，请注意。
