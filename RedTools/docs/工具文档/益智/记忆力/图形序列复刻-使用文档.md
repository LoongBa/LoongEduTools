# 图形序列复刻 — 使用文档

> 序列记忆训练：看一遍颜色亮起的顺序，再按顺序点一遍，全部记住就过关。
> 适用：手机 / 电脑（点选即可）。
> 版本：v1.0 · 更新：2026-09-19

---

## 1. 怎么玩

1. 打开工具，在**难度选择页**选一个难度：简单 记 3 个颜色 / 普通 记 4 个 / 困难 记 5 个。
2. 每轮屏幕上有几个**彩色大方块**，先自动**亮一遍**（一个个依次点亮，同时有提示音）——这就是"要记住的顺序"。
3. 亮完了，**按刚才的顺序点一遍色块**：
   - 点对了：色块闪一下白光，进度 +1；
   - 点错了：色块闪红一下，错误次数 +1，然后色块**再亮一遍**，重新来。
4. 每局 5 轮，全部按顺序点完，就过关啦！每轮的顺序都是随机生成的。

## 2. 游戏规则

| 规则 | 说明 |
|---|---|
| 目标 | 记住色块亮起的顺序，按顺序复刻点选 |
| 操作 | 播放阶段等待（不可点）；复刻阶段按顺序点色块 |
| 点错 | 红闪 + 错误 +1 + 复刻清零并**重新播放**（可再看几遍，不扣分不惩罚） |
| 难度 | 简单 记 3 色 × 3 色池 / 普通 记 4 色 × 4 色池 / 困难 记 5 色 × 5 色池 |
| 轮数 | 每局 5 轮，顺序每次随机（可重复颜色） |
| 星级 | 0 错 3★ / 1~2 错 2★ / 3 错及以上 1★（通关即有） |
| 技巧 | 边看边**心里默念顺序**（红-蓝-绿…），也可跟着提示音哼音阶 |

## 3. 界面说明

- **难度选择页**：三个难度卡片，显示该难度**最佳成绩**（星级 · 用时 · 错误次数），底部是打卡日历入口。
- **顶栏**：`← 返回`、当前难度名、`⏱ 用时`（**进入游戏页即开始**计时，整局计时）。
- **轮次与进度**：游戏页上方「第 x/5 轮 · 已复刻 n/len」。
- **序列预览点**：轮次下方的彩色圆点，显示本轮要记的长度（正式玩法是记顺序，不是记点）。
- **状态提示**：播放时「仔细看，记住顺序！」、复刻时「轮到你了：按顺序点一遍」、点错「再看一遍」。
- **色块按钮**：3~5 个彩色大方块，播放时自动点亮，复刻时点击。
- **错误计数**：游戏页底栏 `❌ N` 实时显示本局点错次数。

## 4. 成绩与打卡

- **星级**（按本局点错次数，宽松友好）：一次没错 ★★★；错 1~2 次 ★★；3 次及以上 ★。
- 每过关一局即点亮**今日打卡**；打卡日历显示本月打卡与连续天数（连续 7 天及以上有 🎉）。
- 各难度分别记录**最佳成绩**（星级高优先，星级相同比用时短）；**最近用时**与最近 **30 局**成绩记录自动保存。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- **记顺序而不是记颜色数量**——每次亮起的颜色可能重复（比如 红-红-蓝），顺序才是关键。
- 跟着提示音哼一哼：颜色越靠后音高越高，音阶能帮孩子"串"起顺序。
- 点错了别着急：色块会重新亮一遍，再看一遍接着点，不怕看几遍（不扣分）。
- 想换一组？游戏中点「重新开始」用相同难度重抽一局（新顺序），或点「返回难度」换档。
- 每轮顺序完全随机，不会重复出题，孩子不容易背题。

## 6. 常见问题

**Q：点错了会扣分或结束吗？**
不会。点错只计错误次数（影响星级），随后序列会自动重播一遍，孩子可以再看再点，想重试多少次都行，直到点完整轮。

**Q：颜色会重复吗？**
会。每轮的每个位置都是随机从色池（3/4/5 色）里选的，可能出现「红-红-蓝」这种重复——这正是序列记忆的一部分，需要孩子记住**位置和顺序**而不是"看到过的颜色集合"。

**Q：播放太快跟不上怎么办？**
播放点是 600ms 一个 + 间隔，节奏舒缓；如果没记住，只需故意点错一次就能触发重播，等于"请求再看一遍"。

**Q：适合几岁的孩子？**
定位低龄（preK 到小学低年级）。简单档 3 个颜色从 3 色里选，起步友好；困难档 5 个颜色、候选也更多，适合大一点的孩子。

**Q：成绩怎么清除？**
目前没有「清空成绩」按钮。成绩保存在设备浏览器的 localStorage 中，清除浏览器数据即可清空；换设备不会同步，请注意。
