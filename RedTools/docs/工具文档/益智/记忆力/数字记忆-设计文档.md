2. **递增挑战**：答对位数 +1 无限递增（上限 12 位），挑战纪录感强，对标小象玩法 ✅

5. **双输入**：屏幕数字键盘（触屏）+ 实体键盘（0-9/Backspace/Enter）增强 ✅

## 2. 玩法规则

1. **开局**：从首页选择难度进入（简单 3 位起步 / 进阶 4 位起步 / 挑战 5 位起步）。
2. **出题**：每局第 1 题为起始位数，答对/答错均进入下一题且位数 +1（上限 `MAX_DIGITS=12`）。
   数字由 `genSeq(n)` 生成：首位 1-9，其余 0-9，允许重复（真实记忆训练）。
3. **显示阶段（show）**：显示 n 位数字卡片 + 「👀 记住数字！」+ 倒计时「⏳ n 秒后消失」；
   显示时长 = 位数 × 1 秒（`startShowTimer` 每秒递减，归零自动 `enterInput`）。
4. **输入阶段（input）**：数字隐藏为空格（虚线占位），出现屏幕数字键盘（1-9 / ⌫ / 0 / 确定）；
   逐位输入，⌫ 退格可改；**未满位时「确定」禁用**（防误触），满位变绿可点。
5. **判定（submitRound）**：
   - 全对 → `correct +1`、`maxDigits = digits`，绿色反馈「✓ 答对了！」→ 900ms 后 `nextRound`；
   - 有错 → 展示正确答案（错误位 `.wrong` 标红）+「✗ 正确答案：XXX」+「机会 -1，剩余 x 次」，
     `lives -1` → 机会 >0 则 2000ms 后 `nextRound`，机会 =0 则 2000ms 后 `finishGame`。
6. **最高位数**：仅答对时更新（`maxDigits`），答错不降，体现"记住过的最长数字"。
7. **计时**：第 1 题显示时启动整局计时（`performance.now()`），结算时停止。
8. **动画锁定**：反馈阶段 `phase='feedback'` 时键盘不渲染、输入无效，避免连点错乱。

> 设计考量：显示时长与位数成正比（3 位 3 秒 → 8 位 8 秒），长度增加给更多观察时间，
> 符合工作记忆容量随年龄增长的自然规律；答错仍继续升位，避免挫败感并鼓励突破纪录。

## 4. 页面/视图结构

```
首页 viewHome（3 个难度卡片 + 各难度最佳成绩/未挑战 + 底栏导航 成绩/打卡/首页）
  │ 点击难度卡片
  ▼
游戏页 startGame（顶栏 返回|题号|机会❤ / 数字格子区 show→input→feedback / 数字键盘 / 重新开始）
  │ 机会用尽 → finishGame（延迟 500ms）
  ▼
结果浮层 showResult（本局结束 / 大号最高位数 / 最高位数·答对·用时 / 星级 / 新纪录横幅 / 再来一局 / 返回首页）

底栏导航：成绩 viewHistory（最近 30 次，时间倒序） │ 打卡 viewCheckin（本月日历 + 连续天数）
```

- **顶栏（app-header）**：`renderHeader(title)` 渲染图标 + 标题 + 版本号（来自 `APP.meta.version`）。
- **首页 `viewHome`**：标题「选择难度」+ 提示「看几秒数字，凭记忆输入！答对位数会越来越长」；
  3 个难度卡片（`diff-card`），每张含难度按钮 + 该难度最佳成绩（`最佳 x 位`，未玩过显示「未挑战」）。
  `viewHome` 会先 `stopTimer/stopShowTimer` 清理游戏计时（防止 feedback 阶段退出后结算浮层闪现）。
- **游戏页 `startGame`**：重置全部状态 → `nextRound()` 开始第 1 题。
- **游戏页顶栏（`game-top`）**：`‹ 返回` | `第 x 题 · n 位` | `❤❤❤`（剩余机会，`❤❤♡` 扣减）。
- **数字格子区（`seq-area`）**：白卡片内数字格子 + 阶段提示；格子宽度 JS 内联 `80/digits %`
  （总宽 80% 居中均分，3 位约 26.7%、12 位约 6.7%），高度 56px 固定，字号 30px。
- **阶段提示（`seq-hint`）**：
  - show：「👀 记住数字！」+ 倒计时「⏳ n 秒后消失」（`#show-count`）；
  - input：「输入你记住的数字」+ 实时整局用时（`#game-timer`，每 100ms 刷新）；
  - feedback：绿「✓ 答对了！」或红「✗ 正确答案：XXX」+「机会 -1，剩余 x 次[，本局结束]」。
- **数字键盘（`num-kbd`）**：仅 input 阶段渲染；12 键 `1-9 / ⌫ / 0 / 确定`，flex wrap 3 列 × 4 行
  （`justify-content: space-between` + 按钮 `width:30%`，无 flex gap）；
  「确定」`#kbd-ok` 未满位 `disabled`，满位移除。
- **结果浮层 `showResult`**：全屏半透明遮罩 + 白色卡片，含「本局结束」、大号最高位数、
  最高位数/答对题数/用时统计、星级、新纪录时「🎉 新纪录！」、以及「再来一局」「返回首页」；
  `finishGame` 延迟 500ms 后展示，让正确答案反馈先被看到。
- **成绩页 `viewHistory`**：无记录时提示「暂无成绩，先来一局吧！」；否则按时间倒序列出
  最近 N 次（难度 / 日期·答对 x 题 / 最高位数 / 星级）。
- **打卡页 `viewCheckin`**：本月日历（已打卡日高亮点亮 + 今日紫色描边）+ 连续打卡天数
  （≥7 天显示 🎉）；打卡由完成游戏自动触发，本页仅展示。

### 4.1 状态模型（main.js `state`）

```js
{
  level: 3,          // 难度（起始位数 3 / 4 / 5）
  digits: 3,         // 当前题位数
  round: 0,          // 题号（第几题）
  lives: 3,          // 剩余机会（LIVES 常量 = 3）
  correct: 0,        // 答对题数
  maxDigits: 0,      // 达到的最高位数（答对时更新）
  phase: 'idle',     // idle / show / input / feedback
  seq: [],           // 当前题目标数字数组
  input: [],         // 已输入数字数组
  started: false,    // 是否已开始计时（第 1 题显示时置 true）
  finished: false,   // 是否已结算
  startMs: 0,        // 开始计时时间戳（performance.now()）
  elapsed: 0,        // 结算用时 ms
  timerId: null,     // 整局计时 setInterval 句柄
  showTimerId: null, // 显示阶段倒计时 setInterval 句柄
  lastOk: false      // 上一题是否答对（feedback 渲染用）
}
```

## 5. 成绩持久化（localStorage key `redtools.digitmem.v1`）

```js
{
  version: 1,
  best:   { "3": {digits, date}, "4": null, "5": null },  // 各难度最佳（digits 更大覆盖）
  recent: { "3": 0, "4": 0, "5": 0 },                     // 各难度最近最高位数
  checkin: { dates: ["YYYYMMDD"], streak },                // 打卡日期（滚动 365 天）+ 连续天数
  history: [ {date, level, maxDigits, correct, wrong, ms, stars} ]  // 滚动 30 条，最新在前
}
```

- 读写均包 try/catch：`loadStore` 解析失败或首次打开返回默认结构；`saveStore` 写入失败静默。
- 启动时先 `loadStore()` 再 `saveStore()`（初始化写入，建立默认结构）。
- **最佳成绩**：`best[level]` 为空或 `maxDigits > best.digits` 时覆盖为 `{digits, date}` 并标记新纪录
  （结果浮层显示「🎉 新纪录！」）。
- **最近成绩**：`recent[level]` 直接覆盖为本局 `maxDigits`。
- **历史**：`history.unshift(...)` 最新在前，`while (length > 30) pop()` 滚动保留 30 条；
  每条含 `maxDigits/correct/wrong` 字段（记录挑战深度与对错分布）。

### 5.1 打卡逻辑（与学科系列/舒尔特方格/翻牌记忆配对一致）

- 完成一局即自动打卡：`todayStr()` 生成 YYYYMMDD，不在 `dates` 则 push，然后 `sort()`；
  `while (dates.length > 365) dates.shift()` 滚动保留 365 天。
- 连续天数 `calcStreak(dates)`：从日期列表末尾向前回推，**含今天**往前数连续天数，
  跨天即断（缺一天 streak 归零）；结果写入 `checkin.streak`，打卡页渲染时实时重算。
- 打卡无手动入口，本工具「完成一局（机会用尽结算）」即点亮今日。

## 6. 关键实现点

### 6.1 阶段机（`nextRound` / `startShowTimer` / `enterInput` / `submitRound`）

- `nextRound`：`round +1`，`digits = start + (round - 1)`（上限 12），`seq = genSeq(digits)`，
  `phase='show'`；第 1 题时启动整局计时；渲染后 `startShowTimer`。
- `startShowTimer`：`remain = digits`，每秒递减；归零 `enterInput`（`phase='input'`，重渲染出键盘）。
- `submitRound`：`phase='feedback'`；`arraysEqual(input, seq)` 判定；
  对 → `correct+1`、`maxDigits=digits`、900ms 后 `nextRound`；
  错 → `lives-1`、渲染正确答案（错误位 `.wrong` 标红）、机会 >0 则 2000ms 后 `nextRound`、
  机会 =0 则 2000ms 后 `finishGame`。
- `renderRound` 为全量重渲染（顶栏 + 格子 + 提示 + 键盘 + 重新开始），阶段切换简单可靠；
  输入阶段局部更新用 `renderInputState`（格子文本 + 确定按钮可用性），避免整页重绘丢焦点。

### 6.2 数字格子布局（style.css + 内联宽度）

- `.seq-grid` flex 居中；格子 `width: 80/digits %`（JS 内联 `cell.style.width`，保留两位小数）；
  高度 56px、圆角、浅紫底 + 紫字。
- 状态类：`.show`（实线边框）/ `.input`（虚线占位）/ `.input.filled`（已填实线）/
  `.feedback`（绿色边框）/ `.feedback.wrong`（红边框红字，标出错误位）。

### 6.3 数字键盘（无 flex gap 方案）

- `.num-kbd`：flex wrap + `justify-content: space-between`，按钮 `width: 30%`、
  `margin-bottom: 8px` → 自动 3 列 × 4 行（1-9 / ⌫ 0 确定），无 gap 依赖。
- `.kbd-ok` 绿色实底；`[disabled]` 灰底浅字（未满位防误触）。

### 6.4 实体键盘增强（keydown 监听）

- `document.addEventListener('keydown')`：`phase==='input'` 时数字键 `onKey`、
  `Backspace` → `onBack`、`Enter` → `onSubmit`。桌面浏览器可用实体键盘输入。

### 6.5 计时与安全区（同系列工具）

- `performance.now()` 实算差值 + `setInterval(100ms)` 刷新（后台回来计时仍准）；
  整局计时在 input 阶段于格子下方 `#game-timer` 显示，show/feedback 阶段仅后台累计。
- `syncAppHeight()` 写 `--app-height`，`env(safe-area-inset-*)` + `@supports` 双兜底。

## 7. Chrome 61 / 合规约束

| 类别 | 约束 | 本工具做法 |
|---|---|---|
| JS 语法 | ES2017 上限经典脚本 | `var` + `function` 风格，无 `?.` `??` 对象展开 `replaceAll`；无 `type="module"`/import/export |
| 事件 | 全部 `addEventListener` | 按钮/键盘逐个绑定；无内联事件 / eval |
| 网络 | 零网络请求 | 无 fetch/XHR/Worker/外部资源；无 audio；数字纯 CSS 渲染 |
| 图片 | 无图片素材 | 除构建生成的 `assets/icon.png` 外，一切图形由 DOM/CSS 生成；zip 内无额外图片文件 |
| CSS 语法 | Chrome 61 兼容层 | 无 flex `gap`/`aspect-ratio`/`clamp`/`inset`/逻辑属性/`:has`/`@container`/`dvh`；Flex 子项设 `min-width:0` |
| 动画 | 温和反馈（光敏安全） | 无动画/闪烁；对错仅静态颜色边框，无强频闪 |
| 触控 | 触摸友好 | 键盘按钮 min-height 52px、格子 56px；确定按钮禁用防误触 |
| 状态隔离 | 退出清理 | `viewHome` 停表（timer/showTimer），防 feedback 阶段返回后结算浮层闪现 |

```python
ToolConfig(
    series="益智", tool="数字记忆",

```
