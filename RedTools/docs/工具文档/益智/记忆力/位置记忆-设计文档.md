## 2. 玩法设计

### 2.1 规则

- 每局：网格（3×3 或 4×4）随机放置 M 个图案（其余空格）→ **展示阶段**（全部可见 + 倒计时 N 秒）→ **隐藏**（全部翻为「?」背面）→ **查找阶段**：逐轮提示目标图案（大卡显示图标 +「找出这个图案！」），孩子点出它藏的位置（点中 → 翻回 + 绿勾；点错 → 红闪 + 错误计数 + 可继续点）→ 全部找到过关。
- 每局图案随机、位置随机、目标提示顺序随机——不背题。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 点格子 | 查找阶段：判目标图案是否正确；展示阶段忽略（等待倒计时） |
| 底栏按钮 | 「返回难度」/「重新开始」（同难度重抽一局） |
| 顶栏按钮 | 「← 返回」回难度页 |

### 2.3 反馈

- **展示**：顶栏状态「👀 记住图案的位置！还有 x 秒」逐秒倒计时 → 到时全部翻面。
- **点中**：格子翻回图案 + 绿色描边 + `popFound 0.35s` 弹跳 + 轻音效 + 「找到 n/x」进度更新；已找到格保持显示。
- **点错**：格子红闪（`wrongFlash 0.4s`）+ 低音效 + 错误计数 +1（不翻回，可继续找）。
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件）：选中轻音 / 点中清脆 / 点错低沉 / 胜利琶音。

## 4. 技术设计

### 4.1 数据模型

- **难度常量 `LEVELS`**：

| key | 难度 | 网格 | 图案数 M | 展示秒数 |
|---|---|---|---|---|
| '1' | 简单 | 3×3（9 格） | 4 | 5 |
| '2' | 普通 | 4×4（16 格） | 6 | 5 |
| '3' | 困难 | 4×4（16 格） | 8 | 4 |

- **运行时状态**：`state = { level, gridN, cells:[{iconId|null, found}], targets:[iconId...], curTarget, phase:'show'|'find'|'idle'|'win', showLeft, showTimerId, found, errors, won, startMs, ms, timerId }`。

### 4.2 出题（布局 + 目标顺序）

- 从 `window.ICONS`（24 图标数组）洗牌取前 M 个 → 网格随机选 M 个格子放置（`cells[idx] = {iconId, found:false}`，其余 `{iconId:null}`）。
- `targets = shuffle(ids)`：目标提示顺序随机。
- 每局 8 轮之内完成（M 个目标依次），无额外轮数上限（找完即过关）。

### 4.3 阶段流转

- `startShowPhase()`：`phase='show'` + 全部渲染可见 + 状态行倒计时（`setInterval` 1s）→ 归零 → `hideAll()`。
- `hideAll()`：`phase='find'` + 全部格子翻面（`renderCells(false)`：空格/未找到格显示「?」背面，已找到格保持图案）→ `nextTarget()`。
- `nextTarget()`：`curTarget = targets[0]` + 提示大卡显示该图标 + 状态行「找到 n/x」。
- 点中：`targets.shift()` + 格 `found` + 若空 → `onWin()`（500ms 后）；否则 450ms 后提示下一个目标。

### 4.4 交互与判定

- `onCellTap(idx)`：`phase!=='find'` 忽略；`found` 格忽略；空格轻响应；`cells[idx].iconId === curTarget` → 点中分支；否则错误分支（红闪 + `errors++` + 不翻回）。

### 4.5 计时

- `startTimer()`：`performance.now()` + `setInterval(100ms)` 差值刷新 `'⏱ ' + fmtTime(ms)`（秒 + 1 位小数）；进入游戏页即开始（**展示倒计时计入总用时**——记忆-找全整局计时）。
- v1.0 无断局恢复。

### 4.6 星级与最佳成绩

- **星级**（按错误次数）：★★★ 错误 0 次；★★ 错误 ≤2 次；★ 其余（过关即有）。
- **最佳判定** `betterThan`：星级高优先，同星级比用时短；仅严格更优才覆盖。最近/历史同系列模式。

### 4.7 持久化（localStorage）

- key：`redtools.weizhijiyi.v1`（工具前缀）。
- 结构：`{ version:1, best:{}, recent:{}, checkin:{dates,streak}, history:[...] }`。
- 读写 try/catch；`loadStore()` 校验 `version === 1` 并补全缺失字段；打卡 `doCheckin()` YYYYMMDD 去重 + 365 滚动 + `calcStreak()` 含今天往前推。

### 4.8 图标库（程序化 SVG，复用翻牌）

- `window.ICONS`：**数组**，每项 `{ id, draw() }`，`draw()` 返回 `viewBox="-20 -20 40 40"` 居中 SVG（24 个图标：水果/动物/天气/物品等，糖果色扁平风）。
- 网格格子 `iconSvg(iconId)` 渲染；提示大卡同源渲染——同图标字符串一致，测试可依赖。

### 4.9 音效（Web Audio 合成）

```js
sndClick:   sine  392Hz 0.06s    // 空格轻响应
sndCorrect: triangle 523Hz 0.09s // 点中（清脆）
sndWrong:   square 150Hz 0.12s   // 点错（低沉）
sndWin:     523/659/784/1047 上行琶音
```

`AudioContext`（含 `webkitAudioContext`）懒创建 + 用户手势 `resume()`；全部 try/catch 降级。

### 4.10 视图结构

- 三个视图 + 一个浮层：**难度选择页** / **游戏页** / **打卡日历页**；**结算浮层**（星级 + 统计 + 打卡 + 三按钮）。
- 网格用 `float:left` + 格子 `width %` + `padding-bottom` 正方形（Chrome 61 兼容，无 gap）；打卡日历 7 列网格同系列（done 橙 / today 主色描边 / streak-info）。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：ES2017 经典脚本（var + function），无 `?.`/`??`/对象展开/`replaceAll`/module/import；无内联事件/eval；事件全部 `addEventListener`；无 fetch/XHR/Worker；localStorage try/catch；`setInterval`/`setTimeout` 句柄统一管理（切视图清理）。
- CSS：无 `gap`/`aspect-ratio`/`clamp()`/`inset`/逻辑属性/`:has`/`@container`/`dvh`；flex 三重前缀；动画双写前缀（`popFound`/`wrongFlash`/`popCard` ≤400ms 无频闪）；`float` 网格 + `:after` 清浮动；安全区 `env(safe-area-inset-*)`。
- 触控/光敏：格子/按钮 hit area ≥48px；动画温和无频闪。
- 资源：全部内联/本包；无外部 URL；图形 SVG 代码生成 + 音效 Oscillator → **零图片零音频零数据文件**。
- 包体：0.02 MiB（≪ 2 MiB 建议值）。

## 8. 与系列规范的关系

- **系列归属**：`教育工具产品矩阵规划.md` §4.3 记忆力训练（P1 位置记忆）→ `series/益智/记忆力/` 子系列第 4 款；适用 preK–K4-6（L1–L3）。
- **可复用核心**：计时/成绩/打卡对齐 `series/益智/设计文档.md` §4；Chrome 61 / 交互合规对齐 §5；**图标库对齐 §8（翻牌记忆配对程序化 SVG 图标库）**——直接复用 24 图标，零新增素材。
- **与同系列差异**：翻牌=配对记忆、数字记忆=数字序列、图形序列复刻=顺序记忆，本工具为**空间位置记忆**（位置 × 图案绑定）；「展示→隐藏→找图」流程为系列首次（隐藏后无任何提示残留，纯靠记忆）；目标提示大卡给「找什么」但**不给位置**——保留记忆训练完整性（与图形序列复刻"重放不改题"同理，不代做）。
- **扩展**：网格尺寸/图案数/展示秒数均参数化（`LEVELS` 直接加档）；图标库增补即扩题；后续可加「旋转网格」「遮挡多层」等空间记忆变体。
