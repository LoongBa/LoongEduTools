## 2. 玩法设计

### 2.1 规则（经典贪吃蛇原版）

- **棋盘**：17×17 网格（深绿棋盘格底 + 蛇身绿色渐变 + 红色圆形食物）。
- **初始**：蛇 3 节横向朝右（头在 index 0），食物随机生成在非蛇格（从空位列表取，杜绝重叠）。
- **移动**：`setTimeout` 驱动 tick——蛇头沿当前方向 +1 格，尾部出队（吃食物则尾部不出队 → 蛇长+1）。
- **转向**：方向键/WASD/触屏滑动/方向按钮；**不能 180° 掉头**（蛇长=1 时除外）；转向缓冲
  `nextDir` 下一 tick 生效（连按两次方向时以最后一次为准，且反向输入基于待生效方向拦截）。
- **得分**：每吃 1 个食物 +10 分。
- **胜利**：吃满 **20 个食物**（200 分）即胜利（单局目标制，避免无限刷分无成就感）。
- **失败**：撞墙（出界）或撞自身（未吃时尾格让位，蛇身其余格碰撞即死）。
- **提速**：速度三档 base（慢 200 / 中 150 / 快 100 ms），每吃 5 个食物 ×0.94（-6%），下限 60ms。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 键盘 | 方向键 + WASD 转向（`preventDefault` 防滚动）；空格 = 暂停/继续 |
| 触屏 | 棋盘滑动转向：`\|dx\|>\|dy\|` 判水平，阈值 24px 防误触，方向 = 滑动方向 |
| 方向按钮 | 棋盘下**左右两组**（左 ↑← / 右 →↓ 竖排，双手拇指分控；hit 58×58px），
  对齐系列规范 `series/经典游戏/设计文档.md` §4.4 左右分组布局 |
| 暂停按钮 | 信息条 ⏸/▶ 切换（暂停停 tick 停计时）；暂停状态按钮变 ▶ |
| 速度 tab | 顶部 慢速/中速/快速 一键新局（含存盘 cur 清空） |

> 输入在 `guardPaused / over / won / selfLocked` 时全部忽略（方向输入缓冲下一 tick 生效）。

### 2.3 反馈

- **动画**（温和，光敏合规）：结算卡片弹性入场（scale 0.92→1 + fade，250ms）；蛇身无逐格动画
  （贪吃蛇以即时 tick 移动为主，蛇头/蛇身颜色渐变区分，不引入频闪）。
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件零包体）：
  转向（sine 220Hz/35ms 轻响）、吃食物（triangle 660Hz/80ms）、胜利（上行琶音 523/659/784/1047）、
  失败（sawtooth 180→50Hz 下滑 350ms + 增益衰减）。首次用户手势创建 `AudioContext`，异常静默降级。
- **图片**：无任何图片素材，棋盘/蛇身/蛇头/食物全部 DOM/CSS 绘制。

## 4. 技术设计

### 4.1 模块拆分（本工具核心工程决策）

> 背景：扫雷单文件 `main.js` 1353 行 / 46 KB，维护困难。贪吃蛇按职责拆 **7 个 JS 模块**，
> 全部 IIFE + 挂载 `window.SnakeApp` 命名空间，index.html 按依赖顺序引用，每文件 ≤350 行。

```
series/经典游戏/贪吃蛇/src/
├── index.html                 # 骨架 + 8 个 script（data.js → core → audio → game → guard → share → ui → main）
└── assets/
    ├── core.js     (200 行)   # 命名空间、工具函数、常量、store 读写/归一化、打卡、防沉迷数据层
    ├── audio.js    (67 行)    # Web Audio 合成（ensureAudio/tone/sndTurn/sndEat/sndWin/sndLose）
    ├── game.js     (325 行)   # 核心逻辑：棋盘/蛇/食物/碰撞/tick/得分/速度/胜负/saveCur/restore
    ├── guard.js    (210 行)   # 防沉迷 UI+逻辑：设置条/到点暂停弹窗/延迟×2/自律锁/结算三选
    ├── share.js    (156 行)   # 分享卡片 canvas(1080×1920)/文案/复制/toast
    ├── ui.js       (301 行)   # 渲染：顶栏/tab/信息条/棋盘绘制/结算弹层
    ├── main.js     (82 行)    # 启动 init/键盘+触屏+按钮输入/resize
    ├── style.css   (658 行)   # Chrome 61 基线绿系样式
    └── icon_base.png          # 图标母版（绿底网格+蛇形+红苹果，构建时叠加角标）
```

- **模块通信**：跨模块仅通过 `SnakeApp.xxx` 导出属性调用；game 运行时引用 ui/guard（函数体内
  `uiMod()/guardMod()` 惰性取用，规避加载顺序问题）。
- **构建兼容**：`build_framework.copy_static` 用 `shutil.copytree` 复制整个 assets 目录 →
  多 JS 文件天然支持，无需改构建框架（已验证）。

### 4.2 数据模型（game.js）

- 蛇：`state.snake` = 坐标数组 `[{r,c}]`，**头在 index 0**。
- 方向：`DIRS = { left:{dr:0,dc:-1}, right:{dr:0,dc:1}, up:{dr:-1,dc:0}, down:{dr:1,dc:0} }`；
  `state.dir`（当前生效）+ `state.nextDir`（缓冲，tick 开头 `dir = nextDir` 应用）。
- 状态：`state = { snake, dir, nextDir, food, score, foods, time, timerId, moveId, speedKey,
  startedAt, started, paused, guardPaused, guardWarned, over, won, newRec }`。

### 4.3 核心算法

```
placeFood():                    # 食物不与蛇重叠
  empty = 全部格子 − 蛇身占用 → 随机取 1；无空位返回 false（棋盘填满 → 视为胜利条件之一）

tick():                         # 单步移动（setTimeout 驱动，speedMs 间隔）
  over/won/paused/guardPaused 守卫 → dir = nextDir（应用缓冲）
  新头 = head + DIRS[dir]；撞墙 → loseGame
  eating = (food === 新头)
  撞自身：limit = eating ? 全长 : 全长−1（未吃时尾格让位）→ 撞 → loseGame
  snake.unshift(新头)；eating ? (foods+1, score+10, sndEat, 吃满 TARGET 或无空位 → winGame)
                        : snake.pop()
  paintBoard → updateInfo → saveCur → scheduleMove

setDirection(dir):              # 转向（180° 拦截 + 缓冲）
  guardPaused/over/won/selfLocked 守卫 → cur = nextDir || dir
  opposite(dir, cur) && 蛇长>1 → 忽略；nextDir = dir（变化才播转向音效）

speedMs(): base × 0.94^⌊foods/5⌋，下限 60ms
```

- **胜利**：`foods >= TARGET(20)` 或 `placeFood()` 无空位（棋盘填满）→ `winGame`。
- **失败**：撞墙/撞自身 → `loseGame`。
- **胜负结算**（game.js）：`updateBest()` 按 `speedKey` 档记录最高分（胜/负均计，新纪录标
  `newRec`）；胜利 `games+1, wins+1` + `countPlayed`（必计）+ `doCheckin`（仅胜利打卡）；
  失败 `games+1` + `countPlayed`（<10s 试错豁免）。

### 4.4 渲染（ui.js）

- 17×17 格子**绝对定位 + JS 百分比**（复用 2048/扫雷 GAP 模式）：`GAP=1.2%`，
  `CELL=(100−GAP*(SIZE+1))/SIZE`；棋盘高度 `padding-bottom = GAP*(SIZE+1)+CELL*SIZE`(%)。
- 每个 `.cell` 直接承载状态类：`cell`（棋盘格，`(r+c)%2` 深浅交替）/ `food`（红圆点）/
  `snake-head dir-*`（亮绿+朝向）/ `snake`（`lerpColor(j/(len-1))` 内联背景色渐变）。
- `setCellCls(idx, cls, bg)` 增量更新（仅状态变化的格重设 className/背景），tick 重绘性能无压力。
- 信息条：得分（绿底白字 LED）/ 暂停按钮（⏸⇄▶）/ 计时（000 上限 999s，暂停停走）。

### 4.5 持久化（localStorage，core.js）

- key：`redtools.snake.v1`（容器内多工具共享存储，必须带工具前缀）。
- 结构（v2，guard/selfDaily 对齐 `docs/通用需求-防沉迷自控力.md` §4）：
  ```json
  {
    "version": 2,
    "best": { "slow": 0, "medium": 0, "fast": 0 },   // 分速度档最高分（0=无记录）
    "games": 0, "wins": 0,                            // 总局数 / 胜局
    "checkin": { "dates": [], "streak": 0 },           // 打卡（通用需求 schema）
    "guard": { "minutePref": 5, "gamesPref": 5, "today": "",
               "playedToday": 0, "delayMinTimes": 0, "delayGamesTimes": 0 },
    "selfDaily": [], "selfStreak": 0,                  // 自律天数 + 连续自律
    "cur": { "snake": [], "dir", "food", "score", "foods", "time",
             "speedKey", "startedAt", "started", "over", "won" }
  }
  ```
- **恢复**：`isValidCur` 校验（字段齐全 + 蛇长 1..SIZE² + 坐标合法去重 + 食物不叠蛇 + dir/speedKey
  合法 + `!over && !won`）→ 完整恢复渲染 + `cur.started` 续启计时与移动循环；非法或**自律锁今日**
  → 清 cur 开新局。
- **存盘节奏**：每次有效移动 `saveCur()`（含 foods 续算提速）；计时每 5s 批量写盘。
- **打卡（与扫雷一致）**：**仅胜利** `doCheckin`（去重、滚动 365 天、`calcStreak`）。贪吃蛇失败
  是常态（撞墙/撞自己是多数局的结局），吃满 20 个才算「完成练习」才点亮成就。

### 4.6 防沉迷 / 自控力（对齐 `docs/通用需求-防沉迷自控力.md`）

| 维度 | 实现 |
|---|---|
| 开局前设置 | 设置条三按钮：⏱ 单局时长（5/10/15 分钟，默认 5）、今日局数（3/5/10/不限，默认 5）、
  🙌 我很自律。选择即时落库并记忆（`guard.minutePref/gamesPref`） |
| 试错局豁免 | `state.startedAt`（开局毫秒时间戳）→ 终局时 `(now−startedAt)/1000 < 10s 且失败`
  视为试探，`playedToday` 不 +1；胜利或 ≥10s 的失败才 +1 |
| 跨日重置 | `refreshGuardDay()`：`guard.today` 变化 → 清零 `playedToday / delay*Times` |
| 时长到点 | `tickTimer` 内 `checkGuardTime()`：`time >= (minutePref + delayMinTimes*5) * 60`
  → 停表 + 停移动循环 + `openGuardTimer()` 弹窗（游戏暂停，输入被 `guardPaused` 拦截） |
| 局数到点 | 终结算时 `guardSettleNotes/Btns()`：`playedToday >= gamesPref + delayGamesTimes*2`
  → 结算弹窗取消「再来一局」，改「延迟 +2 局（剩 N 次）」；N=0 时仅剩分享/自律 |
| 延迟 | 时长 +5 分钟 / 局数 +2 局，各上限 2 次（跨日重置）；延迟后 `guardWarned` 复位允许再次提醒 |
| 自律退出 | `doSelfDiscipline()`：`selfDaily` 记今日 + 重算 `selfStreak` → 清 `cur` → 祝贺弹窗 →
  今日锁定（`isSelfLocked()`：速度 tab/新游戏/棋盘输入/恢复旧局全部拦截，明日自动解锁） |
| 结算三选 | 胜利/失败弹层：再来一局（局数满时被延迟替代）｜分享打卡｜我很自律，今天足够了 |

> 与扫雷差异：贪吃蛇是**实时游戏**，到点弹窗必须同时**停移动循环 + 停计时**（`guardPaused` 守卫
> tick 与方向输入），否则后台蛇继续跑；扫雷只需停计时（回合制无自动推进）。

### 4.7 分享打卡（对齐 `docs/通用需求-打卡分享记录.md` §2.3/§5）

- `drawShareCard()`：离屏 `<canvas>` 1080×1920 绘制暖绿渐变成绩卡（标题/速度档+得分/本局连吃/
  本速度最佳/连续打卡/连续自律/鼓励语「每吃一口，都是专注」/工具名/日期），纯系统字体零素材。
- 预览：`canvas.toDataURL('image/png')` → `openShare()` 弹层展示，提示**长按保存图片**。
- 文案：`shareText()` 生成（速度档/得分/连吃/最佳/打卡/自律 + 标签）；`copyShareText()` 用
  隐藏 `<textarea>` + `document.execCommand('copy')`（Chrome 61 兼容），失败降级 toast 展示全文。

### 4.8 音效（Web Audio 合成，audio.js）

```js
tone(freq, dur, type, vol, delay)   // OscillatorNode + GainNode 包络
sndTurn: sine 220Hz 35ms   sndEat: triangle 660Hz 80ms
sndWin:  523/659/784/1047 上行琶音（各间隔 120ms）
sndLose: sawtooth 180→50Hz exponentialRamp 350ms（增益衰减）
```

`AudioContext` 懒创建 + 用户手势 `resume()`；全部 try/catch 降级。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：ES2017 经典脚本（var + function），无 `?.`/`??`/对象展开/module/class/箭头函数/模板串；
  无内联事件/eval/innerHTML；无 fetch/XHR/Worker/clipboard；localStorage try/catch。
- CSS：无 `gap`/`aspect-ratio`/`clamp()`/逻辑属性/`:has`/dvh/grid；flex 三重前缀；动画双写
  `@-webkit-keyframes` + `@keyframes`；棋盘高度 padding-bottom + 格子 JS 百分比；
  body `100vh` + `--app-height` 兜底；安全区 `var(--safe-area-inset-*)`；`:active` 主要反馈；
  动画全部 ≤400ms。
- 资源：全部内联/本包；无外部 URL；无 CSP meta（容器管理）；音频零文件（Oscillator 合成）。
- 包体：构建产物 0.03 MiB（≪ 2 MiB 建议值）。
