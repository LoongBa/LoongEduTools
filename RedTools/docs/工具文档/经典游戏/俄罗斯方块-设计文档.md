## 2. 玩法设计

### 2.1 规则（经典俄罗斯方块）

- 10 列 × 20 行棋盘，7 种方块（I/O/T/S/Z/J/L）逐一从顶部下落，**7-bag 随机**（公平不连发同款）。
- 方块下落速度随等级提升：`间隔 = max(70, 700 × 0.78^(level-1))` 毫秒/格。
- 玩家可**左右移动 / 旋转 / 软降 / 硬降**；锁定后堆满整行即消除。
- 消行计分（指南标准）：1/2/3/4 行 = 100/300/500/800 × 等级；软降每格 +1、硬降每格 +2。
- **等级**：每消 10 行升 1 级（`level = floor(lines/10) + 1`），顶部小字实时显示。
- **结束**：新方块出生即与堆叠相撞（堆到顶）→ 游戏结束，结算打卡。
- **无胜利条件**（经典规则：可无限继续，追求更高分更高层级）。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 触屏滑动 | 棋盘上滑动：左右滑 = 左右移、上滑 = 旋转、下滑 = 硬降（阈值 24px，防误触） |
| 键盘 | ←/A 右/→/D 移动 · ↑/W/X 旋转 · ↓/S 软降或快速落地（见下方选项）· 空格硬降 · P 暂停 |
| 按钮 | 棋盘下 5 键：← ↻ → ▼软降/快速落地 ⤓硬降（PC 模拟器 / 无键盘兜底，hit area 56×56px） |
| 暂停/新游戏 | 侧栏「暂停 / 继续」「新游戏」按钮 |
| **快速下落** | 侧栏开关（localStorage 持久化）：开启后 **↓/S 与 ▼ 按钮按一下直接落地**（等同空格硬降，每格 +2 分）；关闭恢复逐格软降（每格 +1 分） |

### 2.3 反馈

- **投影 ghost**：当前方块下方淡色投影落点（opacity 0.22），预判落位。
- **动画**（温和，光敏合规）：消行整行闪烁（scale 1→1.08 + 淡出，320ms）后从棋盘移除，
  顶部补空行；得分数字上浮变色（200ms）。
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件零包体）：移动（低频轻响）/ 旋转
  （中频）/ 软降（短低频）/ 硬降（低沉）/ 锁定（轻微）/ 消行（n 行 = 上行琶音 n 音）/
  升级（双音上行）/ 失败（下行三音）。首次用户手势创建 `AudioContext`，播放异常静默降级。
- **图片**：无任何图片素材，全部 CSS 绘制 + 经典七色方块（I 青 / O 黄 / T 紫 / S 绿 / Z 红 / J 蓝 / L 橙）。

## 4. 技术设计

### 4.1 数据模型

- 棋盘：一维数组 `grid[200]`（0=空，1-7 = 锁定方块 type+1），索引 `row*10+col`。
- 状态：`state = { grid, piece, nextType, bag, score, lines, level, over, paused, clearing, newRec, lastTime }`。
- 活动块：`piece = { type: 0-6, rot: 0-3, x, y }`；形状表 `SHAPES[type][rot]` = 4 个相对 `[col,row]` 坐标（**手写 4 旋转态**，minY=0 保证出生顶行不出界）。

### 4.2 核心逻辑

```
collides(p, dx, dy, rot)：遍历形状 cell，(x=p.x+dx+dx_i, y=p.y+dy+dy_i)
  越界（x<0||x>=10||y>=20）或 grid 非空 → 碰撞
movePiece(dx,dy)：可移动则更新坐标并 draw
rotatePiece()：rot+1，踢墙序列 KICKS=[0,-1,1,-2,2]（向左/右尝试平移）
hardDrop：ghostDist() 计算落点格数 → y+=dy、得分 += dy*2 → lockPiece
lockPiece：写 grid（type+1）；出生位 cell y<0 → game over；
  否则 findFullRows → 满行闪烁 340ms → afterClear 删行/加分/升级 → spawnNext
spawnNext：7-bag popType() → piece 出生 (x=3, y=0) → 碰撞即 game over
```

- **7-bag**：`bag` 打乱 [0..6] 逐块弹出，空则重洗——保证每种方块 7 块一轮、杜绝"连发"。
- **无效移动**（左右移/旋转撞墙）不改变状态、无惩罚；软降/硬降仅在可下落时计分。
- **主循环**：`requestAnimationFrame(tick)`，按 `now - lastTime >= baseSpeed(level)` 推进一格；
  `state.clearing/paused/over` 期间暂停推进（暂停恢复时重置 `lastTime`，避免瞬时补落）。
- **锁定与消行**：`clearingRows` 记录满行渲染闪烁 class；`afterClear` 过滤删除满行、
  顶部 `unshift` 补空行，分/行/级更新后 `spawnNext` + `saveCur`。
- **恢复**：每次锁定后 `store.cur = {grid, piece, nextType, score, lines, level}`；
  打开时 `has` 检测 grid 非空 → 恢复活动块继续下落；数据异常（含死局）自动重开新局。

### 4.3 渲染

- 200 个 `.cell` 绝对定位（JS 计算百分比：`GAP=1%`，`CELL_W=8.9%`，`CELL_H=3.95%`）。
- `draw()`：全量重设 className——锁定块 `c{n}` / 活动块 `c{n} active` / 投影 `c{n} ghost` /
  消行 `clearing` / 空格。
- 下一块预览：5×3 网格（15 个小 cell，固定 17px），按形状包围盒居中绘制 `nextType` 的 rot0。

### 4.4 持久化（localStorage）

- key：`redtools.tetris.v1`（容器内多工具共享存储，必须带工具前缀）。
- 结构：`{ version, best, games, checkin: {dates, streak}, cur: {grid, piece, nextType, score, lines, level}, fastDrop }`。
- **最佳成绩**：一局结束时 `best = max(best, score)`，新纪录结算页高亮「🏆 新纪录」。
- **打卡**：一局结束（game over）→ `dates` 写入今日（去重、滚动 365 天）、重算连续天数。
- **快速下落**：`fastDrop` 布尔开关持久化，开启后 ↓/S 与 ▼ 按钮改为直接落地。
- 对齐 `docs/通用需求-打卡分享记录.md` P0（打卡 + 最高分）。

### 4.5 音效（Web Audio 合成）

```js
tone(freq, dur, type, vol, delay)   // OscillatorNode + GainNode 包络
sndMove: sine 170Hz 40ms   sndRotate: sine 300Hz 50ms   sndSoft: sine 130Hz 30ms
sndHard: triangle 150Hz 90ms   sndLock: triangle 210Hz 60ms
sndClear(n): 523+i*120 上行琶音 n 音（i*90ms 间隔）   sndLevelUp: 880/1175 双音上行
sndLose: 400→300→190 下行三音
```

`AudioContext` 懒创建 + 用户手势 `resume()`（浏览器自动播放策略）；全部 try/catch 降级。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：ES2017 经典脚本（var + function 风格），无 `?.`/`??`/对象展开/module；无内联事件/
  eval/innerHTML；keydown 用 `keyCode`（全兼容）；触屏用 `touches/changedTouches`；
  无 fetch/XHR/Worker/clipboard；localStorage 读写 try/catch。
- CSS：无 `gap`/`aspect-ratio`/`clamp()`/逻辑属性/`:has`；flex 三重前缀；动画双写
  `@-webkit-keyframes` + `@keyframes`；2:1 矩形用 `padding-bottom:200%`；安全区 env() 兜底。
- 资源：全部内联/本包；无外部 URL；无 CSP meta（容器管理）；音频零文件（Oscillator 合成）。
- 包体：构建产物 0.02 MiB（≪ 2 MiB 建议值）。
