# 2048 — 使用文档

> 经典 2048 数字练习：滑动合并相同数字，合成 2048 即胜利。
> 适用：手机（触屏滑动）/ 电脑（方向键或点击按钮）。
> 版本：v1.0 · 更新：2026-09-18

---

## 1. 怎么练

1. **滑动屏幕**（手机）或按**方向键 / WASD**（电脑）或点击棋盘下方**方向按钮**，让所有方块向该方向移动。
2. 相同数字**相撞会合并**成它们的和（如 2+2=4、4+4=8），并计入得分。
3. 每次有效移动后，棋盘会随机出现一个新的 **2** 或 **4**。
4. 不断合并更大的数字，**合成 2048 即胜利**！

## 2. 练习规则

| 规则 | 说明 |
|---|---|
| 目标 | 合成 2048 数字块 |
| 得分 | 每次合并得分 = 合并后的数值（如 2+2→4 得 4 分） |
| 胜利 | 出现 2048 → 弹出庆祝页，可「继续挑战」冲击更高分，或「重新开始」 |
| 结束 | 棋盘被填满且相邻方块都无法合并时，练习结束 |
| 技巧 | 尽量把大数字往一个角落堆，保持大数字递减排列，更容易合成更高数 |

## 3. 界面说明

- **得分**：本次练习累计分数。
- **最高**：历史最高分（自动保存，刷新/重开都还在）。
- **重新开始**：随时重新开始一局。
- **方向按钮**：棋盘下方**左右两组**（左 ↑← / 右 →↓），双手拇指各控一侧——手机横屏/双手持机
  操作更顺手，也兼容模拟器/无键盘设备。

## 4. 成绩与打卡

- 一局结束（game over）自动记录：**本次得分 + 最高分**，破纪录会标注「🏆 新纪录」。
- 每完成一局即点亮**今日打卡**，页面底部显示连续打卡天数。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- 练习会**自动保存当前进度**：中途退出后重新打开，可接着上次继续练。
- 想换个思路？点「重新开始」随时重开。
- 音效由程序合成（无需网络/音频文件），若设备静音或浏览器限制将自动无声运行，不影响练习。

## 6. 常见问题

**Q：为什么滑动没反应？**
确保手指从棋盘区域内滑动，且滑动手势超过一定距离（约 24px），太短会被识别为误触忽略。

**Q：数字块会飞出屏幕吗？**
不会，数字块始终在 4×4 棋盘内，超长数字（8192+）会自动缩小字号显示。

**Q：最高分会丢吗？**
本地保存在设备浏览器 localStorage，换设备/清理浏览器数据会清空。
