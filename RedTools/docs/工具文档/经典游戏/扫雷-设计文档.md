## 2. 玩法设计

### 2.1 规则（经典 Windows 扫雷原版）

- **三档难度**：初级 9×9/10 雷，中级 16×16/40 雷，高级 30×16/99 雷（经典规格）。
- **首点安全**：首次翻开前不布雷；布雷时把首点及其 8 邻域（共 3×3=9 格）从候选池剔除，
  再 Fisher-Yates 洗牌取前 `mines` 颗雷 → **首点永远安全且为 0（数字空洞）**，天然触发洪水平铺开局。
- **翻开**：数字格显示周围 8 格雷数（1~8，经典配色）；空格（0）**洪水展开**相邻的 0 区与数字边界。
- **标旗**：在未翻开格上标旗/取消旗，剩余雷数 = 总雷 − 旗数（可为负）；已翻开、已结束/胜利局禁止标旗。
- **chord（经典双击）**：点击**已翻开的数字格**，若周围旗数 = 数字 → 自动翻开周围所有未标旗的
  未翻开格（其中含雷 → 爆炸失败，被点雷红底突出）。
- **计时**：首次翻开启动，每秒 +1，上限 999（经典）；信息条黑底红字 LED 显示「剩余雷 | 表情 | 计时」。
- **表情**：游戏中 🙂 / 胜利 😎 / 失败 😵；点击表情 = 重开当前难度新局。
- **胜利**：已翻开格数 = 总格数 − 雷数；胜利时全部雷自动以 🚩 展示（经典表现）。
- **失败**：展示全部雷（未标旗雷 💣、被点雷红底、错旗 ✗、正确旗保留 🚩）。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 单击（左键/触屏轻点） | **翻开模式**（默认）：未翻开格 → 翻开；已翻开数字格 → chord；已翻开空白 → 无操作 |
| 右键（button===2） | 标旗 / 取消旗；`contextmenu` 统一 `preventDefault`（禁用长按菜单/选中） |
| 触屏长按（350ms） | 标旗 / 取消旗；移动 >12px 或 touchcancel 取消；长按后 `suppressClick` 屏蔽合成 click 防误翻开 |
| **标旗模式按钮**（v1.1） | 模式条「👆 翻开 / 🚩 标旗」切换并持久化（`store.flagMode`）：标旗模式下单击未翻开格 = 插旗（不翻开），已翻开数字格仍 chord；触屏无右键时的稳定标旗入口 |
| **键盘光标**（v1.1） | 方向键移动光标（高亮 `cursor` class）、Enter/空格翻开光标格（已翻开则 chord）、F 或 Shift+空格 标旗；经典 Windows 扫雷键位，PC/高格密场景精准操作 |
| 难度 tab | 点头即开对应难度新局并清空当前局（存盘 cur 同步清） |

### 2.4 棋盘横向滚动（v1.1，高级/中级手机可横滑）

- `.board` 外层包 `.board-scroll`（`overflow-x:auto` + `-webkit-overflow-scrolling:touch`）。
- `renderBoard` 计算最小棋盘宽：`minBoardW = ceil(MIN_CELL*100/cw)`（`MIN_CELL=14px`），
  棋盘宽 = `max(容器宽, minBoardW)` —— 高级 30 列在手机（容器 ~358px，格子仅 ~11.9px）
  时自动加宽到格子 ≥14px，容器横向滚动；初级/中级容器宽足够则棋盘宽=容器宽（不滚动）。
- 触屏横向滑动由容器原生滚动处理（`touch-action` 由容器接管），与单击/长按天然区分，误触率低。

### 2.3 反馈

- **动画**（温和，光敏合规）：结算卡片弹性入场（scale 0.92→1 + fade，250ms）；无棋盘块动画
  （扫雷以即时翻开反馈为主）。
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件零包体）：
  翻开（sine 300Hz/35ms 轻响）、标旗（triangle 520Hz/45ms）、取消旗（triangle 380Hz/40ms）、
  胜利（上行琶音 523/659/784/1047）、爆炸失败（sawtooth 180→50Hz 下滑 350ms + 增益衰减）。
  首次用户手势创建 `AudioContext`，播放异常静默降级，无音效不影响游戏。
- **图片**：无任何图片素材，棋盘/数字/旗/雷全部 DOM/CSS + emoji 字符绘制。

## 4. 技术设计

### 4.1 数据模型

- 棋盘：`cols × rows` 网格，索引 `row*cols+col`，邻接表 `adj[i]` 预计算 8 邻域（越界剔除）。
- 雷位：`state.layout` 为**雷索引数组**（长度 = 雷数）。
- 状态：`state = { cols, rows, mines, layout[], opened[], flagged[], revealed, over, won,
  time, timerId, firstTouch, bestKey, boomIdx, newRec }`。

### 4.2 核心算法

```
placeMines(firstIdx):   # 首点安全
  excl = firstIdx ∪ adj[firstIdx]（3×3）
  cands = 全部索引 − excl → Fisher-Yates 洗牌 → 取前 mines 个

floodOpen(start):       # 洪水展开（显式队列 BFS，防深递归）
  q = [start]; 已翻开则跳过
  循环出队：数字格(countMines>0)仅翻开自身；空格向未翻开/未标旗邻居扩散（继续入队）

revealCell(idx):        # 单击翻开
  over/won 守卫 → 已标旗/已翻开 return
  首次(!revealed)：记录首点 → revealed=true → placeMines → startTimer
  isMine → loseGame（首点不可能触发）
  否则 floodOpen → 音效 → paint → saveCur → checkWin

chord(idx):             # 数字格双击扫开
  !isOpened return；num=countMines(idx)
  num>0 且 countFlags(idx)==num 才动作（否则无操作）
  扫描邻域未旗未翻格：含雷 → loseGame(mineIdx)；否则逐个 floodOpen

toggleFlag(idx):        # 右键/长按标旗
  over/won 守卫 → 已翻开 return → 切旗 + 音效 → saveCur
```

- **胜利判定**：`opened.length === cols*rows − mines`（翻开格数 = 全部非雷格数）。
- **无效操作**：点已翻开空白（0）、旗数≠数字的 chord、已翻开格标旗等一律静默忽略。
- **计时持久化**：`tickTimer` 每秒 +1，`time%5===0` 时批量 `saveCur()` 防频繁写盘（翻开/标旗/开新局实时写）。

### 4.3 渲染

- 格子**绝对定位 + JS 百分比**（复用 2048 的 GAP/CELL 模式，无 flex gap / grid）：
  `GAP=1.5%`，`CELL=(100 − GAP*(cols+1)) / cols`；
  棋盘高度 `padding-bottom = GAP*(rows+1) + CELL*rows`(%) → 高级 30×16 呈经典宽扁比例。
- **横向滚动容器**：`.board` 外包 `.board-scroll`（`overflow-x:auto` + momentum 滚动），
  `renderBoard` 计算 `boardW = max(容器宽, ceil(MIN_CELL*100/cw))`（MIN_CELL=14px）——
  高级/中级手机格子不足 14px 时棋盘加宽、容器横向滚动；够宽则棋盘=容器宽不滚动。
- 每个 `.cell`（定位盒）内嵌 `.cell-fill`（100% 填充，绘制凸起/平凹/数字/旗/雷）。
- **字号自适应**：`boardEl.style.fontSize` 按实际棋盘宽（`boardW*cw/100*0.75`px，下限 9px）
  设置，数字与 emoji 用 `em` 等比缩放 → 高级 30 列小格仍可读。
- **键盘光标**：`state.cursor` 高亮格渲染 `cell-fill.cursor`（3px 橙描边）；paintCell 全量刷新。
- 棋盘坐标换算：`cellIndexAt(e)` = 相对棋盘百分比 → `floor((pct−GAP)/(CELL+GAP))` 行列，
  供 click/contextmenu/长按共用（`getBoundingClientRect`）。

### 4.4 持久化（localStorage）

- key：`redtools.minesweeper.v1`（容器内多工具共享存储，必须带工具前缀）。
- 结构（v1.1 扩展 guard/selfDaily，v1 数据自动迁移）：
  ```json
  {
    "version": 2,
    "best": { "easy": 0, "medium": 0, "hard": 0 },  // 分难度最小用时（秒，0=无记录）
    "games": 0, "wins": 0,                           // 总局数 / 胜局
    "checkin": { "dates": [], "streak": 0 },          // 打卡（通用需求 schema）
    "guard": {                                        // 防沉迷/自控力（通用需求-防沉迷自控力.md）
      "minutePref": 5, "gamesPref": 5,                // 单局时长/今日局数档位
      "today": "YYYYMMDD", "playedToday": 0,          // 计数日 + 今日有效局数
      "delayMinTimes": 0, "delayGamesTimes": 0        // 时长/局数延迟次数（上限 2，跨日重置）
    },
    "selfDaily": [], "selfStreak": 0,                 // 自律天数 + 连续自律
    "cur": {                                          // 断局恢复
      "cols", "rows", "mines",
      "layout": [], "opened": [], "flagged": [],      // 雷/翻开/旗 索引数组
      "time", "startedAt", "started", "revealed", "over", "won"
    }
  }
  ```
- **恢复**：`isValidCur` 校验（字段齐全 + `cols/rows≥2` + `layout.length ≤ cols*rows` +
  `!over && !won`）→ `sanitizeIdxs` 清洗（越界/重复防御）→ 完整重渲染 + `cur.started` 续启计时；
  非法则 `store.cur=null` 开新局。⭐ 注：`layout` 是**雷索引数组**（长度=雷数），恢复校验按
  `≤ 总格数` 而非 `== 总格数`（初版曾误写为全量长度判断导致恢复永远失败，已修复）。
- **打卡（与 2048 的关键差异）**：**仅胜利** `doCheckin`（去重、滚动 365 天、`calcStreak`
  回溯连续天数）。扫雷失败是常态（玩家高频踩雷），打完才算「完成练习」才点亮成就；
  2048 是任意 game over 打卡（2048 失败=局自然结束）。胜利 `games+1, wins+1, best=min`；
  失败 `games+1` 不打卡。结算弹层展示用时/本难度最佳/🏆 新纪录/连续打卡天数。
- 对齐 `docs/通用需求-打卡分享记录.md` P0（打卡 + 最佳成绩）。

### 4.5 防沉迷 / 自控力（v1.1，对齐 `docs/通用需求-防沉迷自控力.md`）

| 维度 | 实现 |
|---|---|
| 开局前设置 | 信息条下方 `guard-bar` 三个按钮：⏱ 单局时长（5/10/15 分钟，默认 5）、
  今日局数（3/5/10/不限，默认 5）、🙌 我很自律。选择即时落库并记忆（`guard.minutePref/gamesPref`） |
| 试错局豁免 | `state.startedAt`（首点毫秒时间戳）→ 终局时 `(now−startedAt)/1000 < 10s 且失败`
  视为试探，`playedToday` 不 +1；胜利或 ≥10s 的失败才 +1 |
| 跨日重置 | `refreshGuardDay()`：`guard.today` 变化 → 清零 `playedToday / delay*Times` |
| 时长到点 | `tickTimer` 内 `checkGuardTime()`：`time >= (minutePref + delayMinTimes*5) * 60`
  → 停表 + `openGuardTimer()` 弹窗（游戏暂停，棋盘输入被 `guardPaused` 拦截） |
| 局数到点 | 终结算时 `guardSettleNotes/Btns()`：`playedToday >= gamesPref + delayGamesTimes*2`
  → 结算弹窗取消「再来一局」，改「延迟 +2 局（剩 N 次）」；N=0 时仅剩分享/自律 |
| 延迟 | 时长 +5 分钟 / 局数 +2 局，各上限 2 次（`delayMinTimes/delayGamesTimes`，跨日重置） |
| 自律退出 | `doSelfDiscipline()`：`selfDaily` 记今日 + 重算 `selfStreak` → 清 `cur` → 祝贺弹窗 →
  今日锁定（`isSelfLocked()`：难度 tab/新游戏/棋盘输入全部拦截，明日自动解锁） |
| 结算三选 | 胜利/失败弹层：再来一局（局数满时被延迟替代）｜分享打卡｜我很自律，今天足够了 |

### 4.6 分享打卡（v1.1，对齐 `docs/通用需求-打卡分享记录.md` §2.3/§5）

- `drawShareCard()`：离屏 `<canvas>` 1080×1920 绘制暖色调成绩卡（标题/难度/用时/最佳/
  连续打卡/连续自律/鼓励语/工具名/日期），纯系统字体，零素材零外部引用。
- 预览：`canvas.toDataURL('image/png')` → `openShare()` 弹层展示，提示**长按保存图片**；
  桌面/部分安卓可另存。移动端 H5 无法静默写相册（如实提示长按）。
- 文案：`shareText()` 生成（难度/用时/最佳/打卡/自律 + 标签）；`copyShareText()` 用
  隐藏 `<textarea>` + `document.execCommand('copy')`（Chrome 61 兼容），复制失败降级
  toast 展示全文供长按选择。

### 4.5 音效（Web Audio 合成）

```js
tone(freq, dur, type, vol, delay)   // OscillatorNode + GainNode 包络
sndReveal: sine 300Hz 35ms   sndFlag: triangle 520Hz 45ms
sndUnflag: triangle 380Hz 40ms
sndWin:  523/659/784/1047 上行琶音（各间隔 120ms）
sndLose: sawtooth 180→50Hz exponentialRamp 350ms（增益衰减模拟爆炸）
```

`AudioContext` 懒创建 + 用户手势 `resume()`（浏览器自动播放策略）；全部 try/catch 降级。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：ES2017 经典脚本（var + function），无 `?.`/`??`/对象展开/module；无内联事件/eval/innerHTML；
  触屏用 `touches/changedTouches`；`contextmenu` preventDefault；无 fetch/XHR/Worker/clipboard。
- CSS：无 `gap`/`aspect-ratio`/`clamp()`/逻辑属性/`:has`/dvh/grid；flex 三重前缀；动画双写
  `@-webkit-keyframes` + `@keyframes`；棋盘高度 padding-bottom + 格子 JS 百分比；
  body `100vh` + `--app-height` 兜底；安全区 `var(--safe-area-inset-*)`；`:active` 主要反馈；
  动画全部 ≤400ms。
- 资源：全部内联/本包；无外部 URL；无 CSP meta（容器管理）；音频零文件（Oscillator 合成）。
- 包体：构建产物 0.02 MiB（≪ 2 MiB 建议值）。
