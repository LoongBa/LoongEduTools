## 2. 玩法设计

### 2.1 规则（经典 2048 原版）

- 4×4 棋盘，初始随机 2 块（2 概率 90% / 4 概率 10%）。
- 每次移动：所有方块整体滑动，相同数字 **相邻且从移动方向起** 合并一次（2+2→4，得分 +4）。
- 每步有效移动后在随机空位生成一个新块（2 / 4）。
- 合成 2048 → 胜利（可继续挑战，分数累计不封顶）；无空位且无相邻相同 → 游戏结束。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 触屏滑动 | 棋盘上滑动手势（阈值 24px，水平/垂直占优判定，防误触） |
| 键盘 | 方向键 ←↑↓→ 或 WASD |
| 方向按钮 | 棋盘下**左右两组**（左 ↑← / 右 →↓ 竖排，双手拇指分控；hit 58×58px），
  对齐系列规范 `series/经典游戏/设计文档.md` §4.4 |

### 2.3 反馈

- **动画**（温和，光敏合规）：合并块 `pop`（scale 1→1.15→1，180ms）；新块 `appear`
  （scale 0→1 + fade，150ms）；得分数字上浮变色（200ms）。
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件零包体）：
  移动（低频轻响）/ 合并（清脆三角波）/ 胜利（上行琶音）/ 失败（下行滑音）。
  首次用户手势创建 `AudioContext`，播放异常静默降级，无音效不影响游戏。
- **图片**：无任何图片素材，棋盘与数字块全部 CSS 绘制 + 经典 2048 配色。

## 4. 技术设计

### 4.1 数据模型

- 棋盘：一维数组 `grid[16]`（0=空，其余为 2 的幂），索引 `row*4+col`。
- 状态：`state = { grid, score, over, wonFired, wonLock, popIdxs, newRec }`。

### 4.2 移动与合并（核心算法）

```
applyMove(dir):  # dir 0左 1上 2右 3下
  对 4 条线（行/列视方向）：
    line = 依方向取值（右/下先 reverse）
    out = slideLine(line)   # 去零 → 相邻相同合并（只一次）→ 补零
    (右/下再 reverse 写回)
  changed = 与移动前比较；merged 位置收集为 popIdxs（动画用）
  score 在合并处累加（score += 合并值）
```

- **无效移动**（无任何格子变化）不生成新块、不记步、不触发胜负检查。
- **恢复**：每次有效移动后 `store.cur = {grid, score}` 持久化；重开自动续局。

### 4.3 渲染

- 16 个 `.cell` 绝对定位（JS 计算百分比：`GAP=2.6%`，`CELL=(100-5*GAP)/4`）。
- 每次移动后重建全部 cell（16 节点，开销可忽略）；值 → 色板 class + 字号 class（按位数）。

### 4.4 持久化（localStorage）

- key：`redtools.game2048.v1`（容器内多工具共享存储，必须带工具前缀）。
- 结构：`{ version, best, games, checkin: {dates, streak}, cur: {grid, score} }`。
- **最佳成绩**：一局结束时 `best = max(best, score)`，新纪录结算页高亮「🏆 新纪录」。
- **打卡**：一局结束（game over）→ `dates` 写入今日（去重、滚动 365 天）、重算连续天数。
- 对齐 `docs/通用需求-打卡分享记录.md` P0（打卡 + 最高分）。

### 4.5 音效（Web Audio 合成）

```js
tone(freq, dur, type, vol, delay)   // OscillatorNode + GainNode 包络
sndMove: sine 180Hz 50ms   sndMerge: triangle 660Hz 90ms
sndWin:  523/659/784/1047 上行琶音     sndLose: 400→320→200 下行
```

`AudioContext` 懒创建 + 用户手势 `resume()`（浏览器自动播放策略）；全部 try/catch 降级。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：ES2017 经典脚本（var + function），无 `?.`/`?.?`/对象展开/module；无内联事件/eval/innerHTML；
  keydown 用 `keyCode`（全兼容）；触屏用 `touches/changedTouches`；无 fetch/XHR/Worker/clipboard。
- CSS：无 `gap`/`aspect-ratio`/`clamp()`/逻辑属性/`:has`；flex 三重前缀；动画双写
  `@-webkit-keyframes` + `@keyframes`；正方形 `padding-bottom:100%`；安全区 env() 兜底。
- 资源：全部内联/本包；无外部 URL；无 CSP meta（容器管理）；音频零文件（Oscillator 合成）。
- 包体：构建产物 0.01 MiB（≪ 2 MiB 建议值）。
