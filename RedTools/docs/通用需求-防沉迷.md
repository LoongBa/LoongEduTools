# 通用需求：小工具防沉迷（限时训练）

> **通用能力规范**（跨工具复用），适用于学科/益智类小工具（24点、舒尔特方格、找不同等）的
> 儿童使用时长管理。定位：软提醒型防沉迷（不锁死、不强制），鼓励家长与孩子自觉规划训练量。
> 状态：**需求记录（2026-09-18）**，24点 v1.2 为首发实现，其余工具接入时复用本规范。
> 关联：`docs/通用需求-打卡分享记录.md`（打卡/成绩/分享为相邻通用能力，全局共用 localStorage 前缀约定）。
> 更新：2026-09-18

---

## 1. 定位与范围

| 项 | 说明 |
|---|---|
| 通用能力 | **防沉迷设置（档位）/ 会话内累计计时 / 到点提醒（延迟 / 我很自律，今天足够了）** |
| 本质 | 软提醒：到点弹窗提示，不强制打断操作；「延迟」可续，「足够」主动退出 |
| 本期形态 | 小红书小工具（离线 zip + H5，纯前端，不联网） |
| 计时口径 | **会话内累计**：仅对局进行中的时间累加（首页/结算/设置页不计）；关闭页面即重置（不持久化） |
| 核心价值 | 家长放心把工具交给孩子：有节制的训练量 + 孩子自主说"今天足够了"的自律养成 |

## 2. 核心功能

### 2.1 防沉迷设置（P0）

- 首页提供设置行：**5 分钟 / 10 分钟 / 15 分钟** 三档单选，默认 **10 分钟**。
- 选择持久化到工具 `prefs`（`<toolId>_prefs`，如 `math24_prefs.limitMin`）。
- "每一局开始前可以设置"：任何一次开局前都可回首页调整档位。

### 2.2 会话内累计计时（P0）

- 计时对象：**对局进行中**的时间（对局计时器在跑的时间；自由练习单题 / 每日挑战整段）。
- 待首页、结算浮层、设置弹层时**不累计**。
- 关闭页面 / 刷新即清零（会话级，不落盘）。

### 2.3 到点提醒（P0）

达到设定时长后弹全屏提醒层：

```
训练时间到
已练习 X 分钟，休息一下吧～
┌──────────────┐ ┌────────────────┐
│   延迟 5 分钟   │ │ 我很自律，今天足够了 │
└──────────────┘ └────────────────┘
```

- **延迟 5 分钟**：配额 +5 分钟缓冲（可多次），关闭弹层继续当前对局。
- **我很自律，今天足够了**：结束当前对局回首页，**本轮累计清零**（视为一次完整训练会话收尾）；
  用户随时可再开新局（软提醒，不锁定今日）。

### 2.4 结算页动作（每局完成结算）

结算页统一提供三动作（按需出按钮）：

| 动作 | 行为 |
|---|---|
| 再来一局 | 同难度/模式再来（现有一致） |
| 分享打卡 | 生成打卡卡片 + 复制文案（见通用需求-打卡分享记录） |
| **我很自律，今天足够了** | 结束本次回首页 + 清零本轮防沉迷累计（与 2.3 一致） |

> 自由练习 / 快速模式视工具实际结算结构调整（动作语义不变）。

## 3. 交互流程

```
首页（设置行：5/10/15 选中当前档）
  ↓ 选难度/模式开始
对局中（累计计时 ticking）
  ↓ 达到档位
提醒层：「延迟 5 分钟」 → 继续对局；「我很自律，今天足够了」 → 回首页 + 清零
  ↓ 正常完成 / 主动退出
结算页（再来一局 / 分享打卡 / 我很自律，今天足够了）
```

## 4. UI 要求

- 设置行：三档按钮，当前档高亮；文案「训练限时」（或各工具主题语）。
- 提醒层：全屏浮层（同 result-overlay 视觉体系），温和反馈，无强闪烁；
  按钮 hit area ≥48×48；主按钮「延迟 5 分钟」（首要建议，蓝色）、次按钮「我很自律，今天足够了」（次级）。
- 所有界面一屏看完，无复杂导航（与系列基线一致）。

## 5. 技术约束

### 5.1 会话状态（内存，不落盘）

```js
// 工具内会话状态（页面关闭/刷新即重置）
session = {
  limitMin: 10,      // 当前档位（来自 prefs.limitMin，开局时读取）
  usedMs: 0,         // 本会话已累计对局毫秒
  extraMs: 0,        // 已延期的缓冲毫秒（每次延迟 +5min 累加）
  limitTimerId: null,
  shown: false       // 本次死线是否已弹过提醒（防重复弹）
}
```

- 触发临界：`usedMs >= limitMin*60000 + extraMs` 且 `!shown` → 弹提醒层，`shown = true`。
- 「延迟」：`extraMs += 5*60000; shown = false;` 关闭弹层。
- 「足够」：`usedMs = 0; extraMs = 0; shown = false;` 停止计时，回首页。

### 5.2 计时挂载（关键实现点）

- **复用工具对局计时器生命周期**：对局 `startTimer()` 时启动累计 interval，
  `stopTimer()` 时停止 —— 天然满足"仅对局中累计"（首页/结算浮层时对局计时器已停）。
- interval 按 `performance.now()` 差值累加（与既有计时器一致，避免 setInterval 漂移）。
- localStorage 仅持久化 `prefs.limitMin`；会话计时内容一律内存。

### 5.3 合规自查（系列规范）

- 无 `fetch`/XHR/Worker/`window.open`、无外部 `http(s)://` 引用、无 `setTimeout` 滥用。
- JS：ES2017 经典脚本；CSS：Chrome 61 基线（禁 gap/aspect-ratio/clamp/:has/dvh/inset）。
- 发布前跑 `audit_artifact.py` + 冒烟测试（file:// 与 http:// 双协议）。

## 6. 不同小游戏类型的落地差异

> 防沉迷是跨工具通用能力，但**不同产品类别的单局时长相差悬殊**，到点打断的时机与文案需按类适配。
> 下表为落地对照；共性部分（会话累计口径、5/10/15 档、延迟+5 分、足够=回首页清零）所有工具一致。

| 维度 | 学科练习类（24点/数学口算/口算打卡） | 益智训练类（舒尔特/找不同/翻牌配对/点击反应） | 经典游戏类（2048/推箱子/华容道） |
|------|------|------|------|
| 单局时长 | 长（一局 1-5 分钟，10 题挑战整段） | 短（单局 10-60 秒，可连续多局） | 中长（单局几分钟到十几分钟） |
| 计时挂载 | 复用对局计时器（单题/整段），一局即累计段 | 对局进行中累计（每局计时起止），多局连续累计 | 同左：对局进行中累计 |
| **到点打断时机** | 可在对局中直接弹（一局较长，等局结束太久） | **建议完成当前局后再弹**（单局秒级，局间弹更温和） | 建议完成当前关/局（+ 可选「返回后保留进度」） |
| 到点时长的兜底 | — | 若单局极短（<10s）连续刷，到点即弹（防连续开局绕过） | 若一局时长 > 配额，配额达成的当下即弹，足够=放弃本局 |
| 提醒文案 | 「已练习 X 分钟，休息一下吧～」（训练口吻） | 同左，可更轻松（游戏口吻，如「先休息一下，眼睛也放松放松」） | 同左，可带进度安抚（「本局进度已保留」若实现保留） |
| 结算页「足够」按钮 | ✅ 全部结算都有 | ✅ 同左 | ✅ 同左 |
| 进度保存 | 不支持（足够=放弃当前局） | 同左 | 可选：到点弹层提示保存后再退出（v1 不做，注记未来扩展） |
| 设置默认档 | 10 分钟 | 10 分钟（也可按工具 5/15 调） | 10 分钟 |
| 实现复杂度 | 基准（24点 v1.2 首发） | 低（对局起止即累计点） | 低～中（如需进度保存/关底判断） |

**通用实现建议**：
1. **打断点 = 对局边界优先**：能等到自然局间/结算再弹的工具，避免中途打断操作（音乐/节奏类尤其）；
   单局很长的工具（>3 分钟）允许对局中弹（此时「延迟」应恢复局内状态，见 §5.2 挂载方式）。
2. **防绕过**：会话累计以实际对局时间为准，任何"局间返回首页再开局"都不断计（软提醒下继续累计，页面关闭才重置）。
3. **「足够」语义全工具统一**：结束本次回首页 + 本轮累计清零；不锁定今日、不强制。
4. 各工具落地时，若需偏离本表（如新增档位、进度保存），先更新本文档再动代码（对齐产品矩阵-本地维护规则）。
