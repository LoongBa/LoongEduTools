## 2. 目标与原则

### 2.1 目标

- **玩法**：给定目标布局（K 个四格骨牌堆成），孩子为**每块**编排指令
  （↻ 旋转 / ⬅➡ 移动 / ⬇ 落下）→ ▶ 执行 → 全部落完 → 布局比对判定。
- **判定**：最终网格 vs 目标网格**逐格比对** = 有标准答案（合规安全区，同走迷宫）。
- **概念教学**：顺序（逐块）+ 旋转（空间变换）+ 参数化移动（移 N 格）+ 空间规划
  （看目标反推每块位置）——补全「构建型」编程维度。
- **星级**：指令步数（旋转次数 + 移动格数 + 落下数）vs 最优解 → ≤1.5× 3★ / ≤2.5× 2★。
- **形态**：离线 zip 静态 + 双模式（offline/online）；零素材（SVG 程序化渲染）。

### 2.2 原则

1. 有标准答案判定（布局比对）——合规安全区核心。
2. 逐块放置（低龄直观），不做多块整体编排（留后续迭代）。
3. 复用俄罗斯方块 SHAPES 几何 + 通用模式（打卡/星级/best/recent）+ lx-shared。
4. 零素材、Chrome 61 兼容（ES2017 内、无 flex gap、无 module）。

## 3. 变更设计

### 3.1 玩法与指令模型

**盘面**：W×H 网格。简单 6×6（2 块）/ 普通 8×8（4 块）/ 挑战 10×10（6 块）。

**指令集**（每块独立编排，**每条 chip 即参数化**：1 条 = N 次操作）：

| 指令 | 语义 | 参数化 |
|---|---|---|
| ↻ 旋转 | 顺时针旋转 90°×N | chip 单击递增 1→2→3→1（1 条 = 转 N 次） |
| ⬅ 左移 / ➡ 右移 | 水平移动 N 格 | chip 单击递增 1→2→3→…→max→1（1 条 = 移 N 格，max=W-1） |
| ⬇ 落下 | 垂直下落到底（重力触底） | 固定 1 条 |

> **重要（oracle 修订）**：每块指令序列**固定为「旋转 → 移动 → 落下」三段，不可重排**（执行顺序固定，降低低龄认知负担）。星级按**指令条数**计（非操作格数）：旋转 chip 1 条（含 N 次）、移动 chip 1 条（含 N 格）、落下 1 条。

**执行语义**（每块）：旋转（原位）→ 水平移动 → 落下（垂直触底）。执行顺序固定，动画逐格展示（旋转 300ms / 移动 200ms/格 / 下落 200ms/格）。

**边界语义**：移动指令超出棋盘 → **截断到边界**（不算非法），落完后布局自然对不上 → 差格提示引导调整。执行动画到达边界时块**闪烁一次**给「到边了」事中提示（oracle UX 建议）。

### 3.2 关卡生成器（程序化，必有解）

```
genLevel(diff):
  K = {simple:2, normal:4, hard:6}[diff]
  for i in 0..K-1:
    type = rand(diff==simple ? 6 : 7)   # 简单难度排除 O 型（旋转无变化，低龄困惑）
    rot  = rand(4)                       # 目标旋转态 0-3
    w    = pieceWidth(type, rot)         # 该旋转态宽度 = maxCol-minCol+1
    col  = rand(W - w + 1)               # ★ 事前约束不越界（oracle 修订）
    place(type, rot, col)                # 模拟落下：dropRow 由 bounding box + 已有堆叠推导
  targetGrid = 全部块落定的网格
  optimal    = Σ((rot_i===0?0:1) + (col_i===mid?0:1) + 1)   # ★ 参数化语义：1 chip=1 条（oracle 修订）
```

**bounding box（oracle 补）**：SHAPES 各旋转态坐标非归一化（如 I rot0 col 范围 0-3、rot1 col 范围 2-2）。
`place()` 前须计算每态 `minCol/maxCol/minRow/maxRow`：① 判断越界（col+w ≤ W）② 推导 dropRow（从 row=0 逐行下落，遇已有块或触底停止）。

- **必有解保证**：生成过程即执行过程（每块从 mid 列 + rot=0 起，指令 = [转 rot 次] + [移 |col-mid| 格] + [落下]，目标布局必然可达）。
- **最优解**：程序可算 = Σ((rot_i?1:0) + (col_i!=mid?1:0) + 1)。
- **落点校验**：生成时逐块模拟，若某块落下后与已有块重叠/越界 → 重新随机该块（重试上限 50）。
- **O 型处理**：简单难度排除 O 型；普通/挑战含 O 型，旋转 O 型时提示「这个形状转完一样哦」。

### 3.3 判定与反馈（对齐 v1.4 调试理念）

- 全部 K 块落完 → `finalGrid` vs `targetGrid` 逐格比对；
- 一致 → 过关结算（星级/打卡/下一关）；
- 不一致 → 差异格**红框标记** + 反馈文案：
  - 有差格且目标格空/实有格空 → `✗ 还有 M 格没对上：看看是哪块要转一下、或往旁边移几格`
  - 每块落下前显示**执行高亮**（当前块描边）+ 块进度 `第 i/K 块`；
  - 执行中锁定指令编辑（复用 v1.4 execLock 理念）。
- **重置**：⟲ 重置清空盘面回起点（块进度归 0），↺ 清空清当前块指令。

### 3.4 目标布局显示

目标布局**半透明叠加**在盘面上（同格双色区分：目标格半透明橙 + 已放格实心），低龄对照编排。

### 3.5 页面结构

```
首页（三难度卡 + best/星）
关卡页：顶栏（‹ 返回 / 难度·第N关 / 计时）
        盘面（目标半透明叠加 + 已落块 + 当前块高亮）
        指令区（当前块预览 + 指令 chips + ▶ 执行 / ↺ 清空 / ⟲ 重置）
        反馈条（执行结果 / 差格提示）
        结算（星级 / 打卡 / 下一关 ›）
```

## 7. 风险表

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 生成器死循环/无解 | 低 | 高（核心） | 重试上限 50 + 生成后必达校验（M1 专项） |
| 落下模拟与执行器不一致 | 中 | 高 | 执行器与生成器共用同一 `dropPiece()` 函数（单一实现） |
| 旋转态形状越界 | 中 | 中 | 生成时 `col = rand(W - pieceWidth + 1)` 事前约束（oracle 修订） |
| 低龄认知负担（旋转方向） | 中 | 中 | 目标半透明叠加 + 块预览 + 概念教学卡标题（如「旋转让方块转向」） |
| oracle 额度不可用 | 中 | 低 | 主会话自审替代（对齐 V1.4 先例） |
| **最优解公式与参数化 chip 矛盾**（oracle 补） | 高 | 高（星级判定错误） | 公式统一为参数化语义 `Σ((rot?1:0)+(col!=mid?1:0)+1)`（§3.2 已修订） |
| **bounding box 计算缺失**（oracle 补） | 高 | 中（实现必须补） | §3.2 明确 place() 前计算 minCol/maxCol/minRow/maxRow + dropRow 推导 |
| **两块同型同落点 → 等价路径**（oracle 补） | 中 | 低 | 生成器路径最优非全局最优，3★ 阈值 1.5× 容差可吸收；风险表记录 |
| **O 型旋转无变化**（oracle 补，UX） | 中 | 低 | 简单难度排除 O 型 + 旋转 O 型提示 |
| **截断到边界缺事中反馈**（oracle 补，UX） | 中 | 低 | 移动动画到边界时块闪烁提示（§3.1 已修订） |
