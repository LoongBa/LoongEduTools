## 0. Oracle 审核意见处理（v0.1 → v0.2 修订记录）

| 意见 | 等级 | 处理 |
|---|---|---|

| **ISSUE-3（Med-High）**：点击反应测试/手速挑战 = 🔒 推迟款（测速无标准答案，AGENTS.md「推迟款源码保留、不宣传、不迭代」）——版本 bump + 迁移 = 违反政策 | 阻断 | **采纳**：**样板改为颜色反应（非推迟款，有标准答案，反应力家族同构最纯）**；点击反应/手速挑战 🔒 不动（仅文档标注，不迁移） |
| **ISSUE-4（Medium）**：toast 2600ms→uikit.toast 1500ms 默认 = 可见 UX 变化，与「行为完全一致」矛盾 | 阻断 | **采纳**：**toast 统一传 `ms=2600` 保持行为一致**（不降级；§3.2 明确） |
| ISSUE-2（Medium）copyText 默认 toast 丢失工具专属消息 | 备注 | **采纳**：迁移 `S.copyText(text, {onOk, onFail})` 由工具传专属文案（非默认） |
| ISSUE-5（Low）shareOpen 幂等标志 | 备注 | **采纳**：`if (shareOpen) return` 保留在工具 openShare wrapper（S.overlay 不防双开） |
| 其余 PASS（API 形状/drawFn 切分/build order/范围控制） | — | 维持 |

## 2. 目标与原则

- 目标：新增 `LX_SHARED.share` 模块抽「文案复制 + 弹层骨架 + 卡片 canvas 容器」通用层；**卡片绘制回调留工具**（内容/配色工具专属）。**颜色反应**为样板迁移（非推迟款、有标准答案、反应力家族同构最纯），验证模块可用性。
- 原则：① 纯新增模块，不破坏既有；② 颜色反应 v1.0→v1.0.1（patch，行为完全一致）；③ 其余内联款（点击反应/手速挑战 🔒 推迟不动 + 学科 4 款/扫雷推理/数独思维活跃款）后续按需迁移（本次不动）；④ Chrome 61 基线（textarea+execCommand，无 navigator.clipboard）。

## 3. 变更设计

### 3.1 新增 `_shared/js/src/share.js`（核心变更）

合并顺序追加：core → storage → progress → auth → guard → ui-kit → **share**（build_framework merge_shared_js 的 order 列表 + lx-shared-core __loaded 补 share）。

```js
/* LX_SHARED.share — 分享通用层（V0.7 抽取）
   能力：
   - copyText(text)            文案复制（textarea+execCommand，Chrome 61；保底提示手动复制）
   - cardCanvas(canvasW, canvasH, drawFn)  离屏 canvas 容器（drawFn(ctx,W,H) 工具专属绘制）
   - overlay({ title, imgSrc, hint, copyText, backLabel, onBack })  分享弹层骨架
      （img + 复制按钮 + 返回按钮；返回 { el, close } 兼容 uikit.overlay 风格）
   - roundRectPath(ctx,x,y,w,h,r)  Chrome 61 圆角路径（无 ctx.roundRect）
   约定：卡片内容/配色/文案 = 工具专属（drawFn / shareText 回调）；本模块不感知工具数据
   ES2017；Chrome 61 */
```

**API 签名**（Oracle 复核点）：
```js
S.copyText = function (text, opts)      // opts.onOk/onFail 回调（默认 toast）
S.cardCanvas = function (w, h, drawFn)  // 返回 canvas；drawFn(ctx,w,h)
S.overlay = function (opts)             // { title, imgSrc, hint, copyText, backLabel, onBack }
S.roundRectPath = function (ctx,x,y,w,h,r)
```

### 3.2 颜色反应样板迁移（v1.0→v1.0.1 patch，Oracle ISSUE-3：点击反应/手速 🔒 推迟不迁移）

| 迁移点 | 现状 | 迁移 |
|---|---|---|
| copyShareText | 内联 textarea+execCommand+toast（专属消息） | `S.copyText(text, { onOk, onFail })`——工具传专属文案（Oracle ISSUE-2） |
| drawShareCard 容器 | 内联 createElement('canvas')+尺寸+getContext | `S.cardCanvas(1080, 1920, drawFn)`；drawFn 内工具专属绘制（渐变/装饰点/标题/战绩卡——内容不动） |
| openShare 弹层 | 内联 overlay 骨架 | `S.overlay({ imgSrc, copyText, backLabel, onBack })`；`if (shareOpen) return` 幂等标志保留在工具 wrapper（Oracle ISSUE-5） |
| roundRectPath | 内联 | `S.roundRectPath`（删本地函数） |
| toast | 内联（2600ms） | `LX_SHARED.uikit.toast(msg, 2600)`——**显式 ms=2600 保持行为一致**（Oracle ISSUE-4，不降级） |

**行为不变性**：迁移仅替换「容器/复制/弹层骨架」为共享调用，卡片绘制内容（drawFn 内）与文案（shareText）逐字节不变；toast 时长显式 2600ms 保持。
