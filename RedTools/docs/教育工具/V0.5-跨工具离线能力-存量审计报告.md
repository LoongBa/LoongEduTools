## 3. 缺口①：guard 统一接入（优先级最高）

### 3.1 现状（三款内联，重复实现）

| 工具 | 内联规模 | 说明 |
|---|---|---|
| 经典游戏/扫雷 v1.1 | **253 处**防沉迷/自控力命中 | 全 §2 规则（时长/局数/试错局豁免/延迟×2/自律锁/结算三选）+ 分享卡片自律徽标 |
| 学科/24点 v1.2 | 14 处 | 5/10/15 档 + 到点提醒（延迟/足够）+ 结算「我很自律」动作 |
| 经典游戏/贪吃蛇 v1.0 | 2 处 | 轻量接入（防沉迷/自控力 + 结算三选） |

> **均未使用 `LX_SHARED.guard`**——guard.js 抽取后无消费方。但三款均 🔒 推迟（版号红线）！

### 3.2 关键决策点

⚠️ **三款内联工具全部是推迟款**（扫雷/贪吃蛇在经典游戏系列 🔒，24点已整改为学科款 v1.2 但防沉迷为 24点 自身逻辑）。「统一接入」价值 = **消除模块无消费状态 + 为未来新工具提供现成 guard 能力**；但**不能改动推迟款**（AGENTS.md：推迟款源码保留、不宣传、不迭代）。

→ **候选实施对象**：将 guard.js 的 API 对齐通用需求文档 §4（version 2 迁移/试错局豁免/自律锁语义已在 24点 v1.2 验证过），补齐 guard.js 缺失的**试错局豁免 + 自增 round 判定 + 延迟计数**能力，并在**非推迟款**（如数学口算-题量口径 / 编程教学 4 款-关卡口径）选 1-2 款做真实接入样板，验证模块可用性。四款内联者维持现状不动（文档标注）。

## 4. 缺口②：uikit feedback 抽取接入（中等优先级）

### 4.1 现状

- ui-kit.js 提供 btn/badge/overlay/toast/progressBar/starsText，**0 处消费**
- **反馈/结算/星级/即时提示在各工具 main.js 内联**（如涂色练习/认识时间实采：uikit 相关命中 0——连 UI 组件也未复用）
- ui-kit 注释自述："feedback（即时正反馈 UI）仍内联于各工具 main.js，**B 批再抽**"——即已知遗留

### 4.2 候选实施对象

- 抽取 feedback 通用实现入 ui-kit（`.lx-feedback` 成功/错误态 + 定时清除）
- 选编程教学线 1 款（如循环指令 v1.2.1 刚交付，工具有反馈/结算浮层/星级）做接入样板——**但循环指令已在 v1.2.1 刚发布，改它需 bump**；也可选新接入面稳定的工具

## 5. 缺口③：分享卡片模块化（中等优先级）

### 5.1 现状（10 款内联实现模式高度雷同）

| 工具 | 同类实现 |
|---|---|
| 反应力 3 款（点击反应/手速挑战/颜色反应） | 同构：`shareText()` 文案 + `drawShareCard()` canvas 1080×1920 + `openShare()` 弹层 + `copyShareText()` execCommand |
| 学科 4 款（24点/成语接龙/数学口算/看图猜成语） | 分享卡片 + 复制文案 |
| 逻辑思维 2 款（扫雷推理/数独思维） | 分享成绩卡 + 复制文案 |
| 经典游戏扫雷 | 分享卡片 + 自律徽标 |

### 5.2 候选实施对象

- 提炼 `LX_SHARED.share` 新模块：`shareText(模板数据)` + `drawShareCard(canvas, 数据, 主题)` + `openShareOverlay(数据)` + `copyText(兼容 execCommand)`——**统一 Chrome 61 兼容实现**（textarea+execCommand + 失败兜底展示文案）
- 选反应力 1 款（3 款同构，改造样板可复用）做接入样板；其余 9 款按需接入（文档标注，不全量改——避免 10 款全改的大规模 diff 与回归面）

## 6. 优先级排序与建议

| 序 | 子方向 | 价值 | 风险 | 建议 |
|---|---|---|---|---|
| 1 | **guard 统一接入** | 消除模块无消费 + 补全能力（试错豁免/延迟计数） | 低（模块不动，补 API + 样板接入） | **先做**：补 guard.js API → 选非推迟款 1 款样板 |
| 2 | **uikit feedback 抽取** | 激活模块 + 消除重复 | 低（纯新增 + 样板接入） | 与 guard 并行或顺序跟进 |
| 3 | **分享卡片模块化** | 10 款同构 → 1 模块 | 中（canvas 绘制细节多） | 提炼模块 + 1 款样板 |
| 4 | 存量排查（共性问题） | 发现潜在键冲突/历史遗留 | 低（只读） | 本次审计即完成第一轮；无阻断性发现 |
