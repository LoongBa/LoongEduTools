## 1. 目标与原则

**目标**：新增 `LX_SHARED.ui`（ui-flow 模块），沉淀 12 项通用 UI 流程能力，数学口算作为样板接入（行为不变内部替换），其余工具按需迁移。

**原则**：
1. **状态与 UI 分离**：guard/progress 只做状态判定，`ui` 只做 UI 呈现，两者通过 opts/callback 解耦（延续 Oracle I-2「guard 不持 DOM」）。
2. **纯函数优先**：文案生成/能力探测/卡片绘制 = 纯函数；弹层/设置条 = DOM 工厂函数（返回元素/关闭句柄）。
3. **工具专属靠配置**：卡片内容/配色/文案/档位数组 = 调用方传入（drawFn/opts），不感知工具数据（延续 V0.7 ISSUE-2/ISSUE-5 约定）。
4. **Chrome 61 基线**：ES2017 经典脚本、无新 API。
5. **最小化修复**：仅新增 `ui.js` + 数学口算样板迁移 + 文档对齐，不重构既有模块。

### 2.1b storage.js 新增 migrate 模板方法（Oracle B1）

`storage.migrate(store, {from, to, migrate})`：读 `store.version` → 若 `version === from` 则调用调用方 `migrate(store)` → 写回 `store.version = to`。storage 仍 **schema-agnostic**（version 字段名 + 迁移函数均由调用方传，storage 不感知具体字段——与既有透传定位一致）。

**涉及文件**：`storage.js`（+migrate API）、`lx-shared-core.js`（无需改——storage 槽位已存在）。

### 2.2 `progress.js` 补写 longestStreak + 暴露读取 API（#19 落地，Oracle N1）

`doCheckin()` 内：`store.checkin.longestStreak = Math.max(store.checkin.longestStreak || 0, calcStreak(dates))`（动态 streak 与静态峰值正交，无冲突）。新增 `P.longest(store)` 读取 API（返回 `store.checkin.longestStreak || 0`），供 A7 selfStreakCard 使用，避免工具直读字段名。
