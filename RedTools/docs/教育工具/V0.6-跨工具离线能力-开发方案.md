## 2. 目标与原则

- 目标：uikit 增 `setFeedback(el, msg, state)` 通用 API（文本 + 状态类统一封装），数学口算作为样板迁移双用法，验证模块可用性。
- 原则：① 纯新增 API，不破坏既有组件；② 数学口算为样板（quiz-feedback/share-feedback 双态），迁移后**行为完全一致**（DOM 类名不变——`ok/bad` 态映射）；③ 其余工具按需后续迁移（本次不动，避免 47 款大 diff）；④ Chrome 61 基线。

## 3. 变更设计

### 3.1 ui-kit.js 增 setFeedback（核心变更）

```js
/* 即时正反馈：el.textContent = msg + 状态类统一管理
   state: '' | 'ok' | 'bad' | 'miss'（映射到 el.className = base + [ ' '+state ]）
   调用方传入 base 类名（如 'quiz-feedback'），返回 el 供链式复用
   统一兜底：state 非法 → 不附加状态类（仅文本） */
U.setFeedback = function (el, msg, state, baseCls) {
  if (!el) { return el; }
  el.textContent = msg !== undefined && msg !== null ? msg : '';
  var base = baseCls || (el._lxBaseCls || 'lx-feedback');
  el.className = state ? (base + ' ' + state) : base;
  el._lxBaseCls = base;
  return el;
};
```

**设计要点（Oracle 复核点）**：
- **类名兼容**：现各工具类名 `quiz-feedback ok` / `game-feedback miss`——`base + ' ' + state` 与现有 DOM 类完全一致 → **迁移后 CSS 零改动**（数学口算 style.css `.quiz-feedback.ok/.bad`、`.share-feedback.ok/.bad` 不变）
- **state 语义统一**：`''`(中性) / `'ok'`(正确) / `'bad'`(错误) / `'miss'`(违规/未命中)——对齐现有工具类名约定
- 保存 `_lxBaseCls` 于元素防重设（同元素多态调用时免重复传 base）

### 3.2 数学口算样板迁移（v1.2 → v1.2.1 patch）

| 接入点 | 现状 | 迁移 |
|---|---|---|
| quiz-feedback 提交反馈（submitAnswer） | `feedbackEl.textContent='✓ 答对了！'; feedbackEl.className='quiz-feedback ok';` ×2（ok/bad） | `LX_SHARED.uikit.setFeedback(feedbackEl, '✓ 答对了！', 'ok', 'quiz-feedback');` |
| share-feedback 复制反馈（copyShareText） | `textContent + className = 'share-feedback ok/bad'` ×3（成功/失败/清空） | `setFeedback(el, text, 'ok'\|'bad', 'share-feedback')`；清空 = `setFeedback(el, '', '', 'share-feedback')` |

**行为不变性**：迁移仅替换「赋值方式」（textContent+className 双操作 → setFeedback 单调用），DOM 输出（textContent / className 字符串）逐字节一致。
