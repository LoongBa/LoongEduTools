| N-5 streak 格式 | N | selfDaily = YYYYMMDD 升序数组，复用 progress.calcStreak（与打卡同构） |
| N-6 enough(cfg, todayStr) 签名 | N | 统一内部 todayStr()，签名 `enough(cfg)` |
| N-7 试错豁免口算无意义 | N | 口算恒 ok=true，豁免分支休眠；guard.addPlayed 保留豁免逻辑供游戏类未来复用（文档标注学科类不触发） |

## 3. 变更设计

### 3.1 guard.js 补齐（`_shared/js/src/guard.js`，核心变更）

**现状**（仅会话累计骨架）：

| API | 现状 | 问题 |
|---|---|---|
| check(cfg) | {limited, minutes, rounds, remaining*} | 无分钟/局数档位区分、无跨日重置、无自律锁 |
| addMinutes/addRound | 仅累计 | 无试错局豁免、无延迟计数 |
| getSession | 读 today 会话 | schema 与通用契约 §4 不对齐 |

**补齐后**（对齐通用需求 §4 schema，新增 6 API，旧 4 API 保留 + deprecated 标注）：

```js
// schema（对齐 §4）（写法：工具 store 内嵌 guard 对象，固定字段名，无 keySelf）
store = {
  version: 2,                       // 数学口算 1→2（Oracle N-2 采纳）
  ...,
  guard: {
    minutePref: 5, gamesPref: 5,    // 档位（分钟 5/10/15；题量/局数 3/5/10/0=不限）
    today: '', playedToday: 0,      // 今日计数（学科类=题量；游戏类=局数）
    delayMinTimes: 0, delayGamesTimes: 0  // 延迟次数（上限 2/类）
  },
  selfDaily: [], selfStreak: 0, selfLocked: false  // 顶层固定字段（Oracle I-3：无 keySelf）
}

// 新增 API（cfg = { store, guardKey?: 'guard' }）
G.setPrefs(cfg, {minute, games})        // 档位设置（钳制 5/10/15、3/5/10/0）→ 仅写档位，不重置计数（N-4）
G.startRound(cfg, nowMs)                // 开局：跨日重置（playedToday/延迟清零）+ 记录 today；curStartedAt 归工具管（I-2）
G.addPlayed(cfg, {ok, count, nowMs, startedAt})  // 结算：playedToday += count（Oracle I-1：按题数/局数计）；
                                            //   试错豁免：!ok 且 nowMs-startedAt<10s → 不计（供游戏类；学科类恒 ok=true 休眠 N-7）
G.checkDue(cfg, nowMs)                  // 到点判定 { due, reason:'min'|'games'|null, state }（nowMs 用于分钟累计校验）
G.extend(cfg, type)                     // 延迟：'min' +5 分钟 / 'games' +2 题；计数 ≤2，达上限返回 false
G.enough(cfg)                           // 自律：selfDaily 记今日 + selfStreak 重算 + selfLocked=true（签名统一 N-6）
G.isLocked(cfg)                         // 今日自律锁（N-1：selfLocked && guard.today===今日）
G.streak(cfg)                           // 自律连续天数（复用 progress.calcStreak，selfDaily YYYYMMDD 升序 N-5）
```

完整契约对照（通用需求 §2/§4 → API 映射）：

| 通用需求规则 | guard.js 实现 |
|---|---|
| §2.1 开局前设置（档位记忆） | `setPrefs`（minutePref/gamesPref 持久化） |
| §2.1 试错局豁免（<10s 失败不计） | `addPlayed(ok, nowMs)` 内部判定（curStartedAt - nowMs < 10s 且 !ok → 豁免） |
| §2.1 跨日重置 | `startRound/addPlayed` 内 today 比对清零 |
| §2.2 到点提醒（暂停/延迟×2/自律） | `checkDue` + `extend`（min/games 各自计数） + `enough` |
| §2.3 自律锁 | `enough`（selfDaily/selfStreak/selfLocked）+ `isLocked` |
| §2.4 结算三选 | 调用方 UI（弹层/按钮），guard 提供状态判定 |

### 3.2 数学口算样板接入（`series/学科/数学口算/src/assets/main.js`，v1.1 → v1.2 minor）

**学科练习类口径**（通用需求 §3 表：无"局"概念 → 组/题量 10/20/30/不限，默认 10；触发时机延后到组间）：
