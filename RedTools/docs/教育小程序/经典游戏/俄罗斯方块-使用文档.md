# 俄罗斯方块 — 使用文档

> 经典俄罗斯方块，零门槛上手：控制下落的方块填满整行即可消除。
> 适用：手机（触屏滑动 + 按钮）/ 电脑（方向键或点击按钮）。
> 版本：v1.1 · 更新：2026-09-18

---

## 1. 怎么练

1. **方块会自动下落**，练习方式是调整它的位置和方向，让它整齐地堆在底部。
2. 填满**一整行**（10 格全部有方块）→ 该行消除，上方所有行整体下落，**得分 +100 起**。
3. 一次消除的行越多分越高（1/2/3/4 行 = 100/300/500/800 分，再乘等级）——把方块堆整齐，
   等着四连消（消四行，经典练习方式叫"Tetris"）！
4. 方块堆到顶部放不下新方块时，**练习结束**（一局完整练完即自动打卡）。

## 2. 操作说明

| 动作 | 手机 | 电脑 |
|------|------|------|
| 左右移动 | 棋盘上左右滑动 / 按 ← 或 → 键 | 方向键 ←→ 或 A / D |
| 旋转 | 向上滑动 / 按 ↻ 键 | ↑ / W / X |
| 下落一格（软降） | 按 ▼ 键（每格 +1 分） | ↓ / S |
| 快速落地（硬降） | 向下滑动 / 按 ⤓ 键（每格 +2 分） | 空格 |
| **快速下落选项** | 侧栏「快速下落」开关：开启后 ▼ 键和 ↓ 键**按一下就落地** | 同左（开关持久保存） |
| 暂停 / 继续 | 侧栏「暂停」按钮 | P |
| 重新开始 | 侧栏「重新开始」按钮 | 鼠标点击 |

## 3. 界面说明

- **得分 / 最高**：本次得分与历史最高分（自动保存，刷新/重开都还在），破纪录会标注「🏆 新纪录」。
- **下一个**：预览即将出现的下一块，提前规划摆放位置。
- **等级 / 行数**：每消除 10 行升 1 级，**下落速度随等级越来越快**。
- **淡色投影**：当前方块下方的淡色影子，就是它落到底的位置。
- **快速下落**：侧栏开关（开启后按钮变蓝）。想快节奏练就开启——按下键直接落地；想精打细算落位就关闭——一格一格降。
- **控制按钮**：棋盘下方从左到右 ← 旋转 → 软降/落地 硬降（与模拟器/无键盘设备兼容）。

## 4. 成绩与打卡

- 一局结束（练习结束）自动记录：**本次得分 + 最高分 + 消除行数**。
- 每完成一局即点亮**今日打卡**，页面底部显示连续打卡天数。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- 练习会**自动保存当前进度**：中途退出后重新打开，可以从上次位置接着练。
- 想换个思路？点「重新开始」随时重开；练累了点「暂停」休息。
- 堆方块时尽量**留出 3 格以上的空位**放 I 长条，有机会一次消四行得高分。
- 追求速度可以把「快速下落」打开，↓ 键一步到底；追求精细落位就关掉它，一格一格微调。
- 音效由程序合成（无需网络/音频文件），若设备静音或浏览器限制将自动无声运行，不影响练习。

## 6. 常见问题

**Q：为什么滑动没反应？**
确保手指从棋盘区域内滑动，且滑动手势超过一定距离（约 24px），太短会被识别为误触忽略。

**Q：方块卡在边上转不过去？**
贴近墙壁旋转会被"踢墙"尝试向左/右让位一格；若仍转不动说明另一侧也堵住了，先移开再转。

**Q：最高分会丢吗？**
本地保存在设备浏览器 localStorage，换设备/清理浏览器数据会清空。
