## 2. 玩法设计

### 2.1 核心规则

- 系统展示 **emoji/图形序列**（如 `1️⃣ ❤️ 1️⃣` = 一心一意、`🌺 🌷 🌹 🌸` = 万紫千红），
  下方给出 **4 个成语候选**（点选猜成语，规避手机中文输入），选对过关。
- 题目区同时展示**字格占位**（`____ ____ ____ ____`，与成语字长一致），辅助低年级联想。
- 猜不出 →「💡 看答案」→ 展示 成语 + 拼音 + 释义 + 例句 + 年级标签（学习反馈）。
- 答对 → 即时反馈（绿标）+ **连击** + 提示音；答错 → 红闪 + 高亮正确答案（即时纠错）。

### 2.2 难度分级（词库年级标签驱动）

| 难度 | 年级段 | 出题池（243 条带 emoji 成语分池） | 目标人群 |
|------|--------|:---:|------|
| 1-2 年级 | 词条 `年级` 含 1 或 2 | 66 条 | 低年级入门（成语启蒙） |
| 3-4 年级 | 词条 `年级` 含 3 或 4 | 84 条 | 中年级进阶 |
| 5-6 年级 | 词条 `年级` 含 5 或 6 | 121 条 | 高年级挑战 |

> 部分成语跨年级段（37 条），允许进入多个池；出题池均 ≥ 66 条，满足每日挑战 10 题 + 3 干扰项去重。

### 2.3 模式

| 模式 | 玩法 | 计时 | 打卡 | 成绩/分享 |
|------|------|:---:|:---:|:---:|
| **练一练（自由练习）** | 无限刷题，单题即时反馈后自动下一题 | — | — | 仅当局连击展示 |
| **挑战 10 题（每日挑战）** | 10 题闯关（同池不重复），答错不中止 | ✅ 总用时 | ✅ 完成即点亮 | `best`（分池星级/用时）+ `recent10` + 分享卡片 |

> 每日挑战为打卡与晒分的主要来源（对齐数学口算「每日打卡」模式）。

### 2.4 星级常模（挑战模式）

| 错误数 | 星级 |
|:---:|:---:|
| 0 次 | 3★ |
| 1-2 次 | 2★ |
| ≥3 次 | 1★ |

> 「看答案」计为一次错误（防刷分）；挑战完成即打卡。

## 3. 出题引擎（数据驱动，零运行时生成）

- **题源**：`_shared/成语词库/成语词库.json`（975 课本成语，公共领域；emoji 拼图字段为本工具专用）。
- **可玩过滤**：仅取 `emoji` 非空的词条（243 条）；构建期注入 `window.CHENGYU_DATA`（`datasource="chengyu"`，build_framework 已有管线）。
- **分池**：运行时按词条 `年级[]` 归属年级段池（b12/b34/b56），支持跨池。
- **出题**：从所选池随机抽 1 条为正确答案 → 同池随机抽 3 条为干扰项（与答案去重、彼此去重）→ 洗牌 4 选项。
- **不重复**：挑战局内已出成语不重复（池内 10 题）；练一练避免与上一题重复。

## 4. 交互设计（移动端优先，点选式）

### 4.1 页面流

```
首页
 ├─ 标题 + 版本小字（data.js meta 注入，同现有工具）
 ├─ 年级段三卡（1-2 年级·66 题 / 3-4 年级·84 题 / 5-6 年级·121 题）
 │   每卡：段名 + 池大小 + 历史最佳（星级/用时/错误）或「暂无成绩」
 │   ├─ [练一练] → 自由练习局
 │   └─ [挑战10题] → 每日挑战局
 └─ 底部：📅 打卡日历（连续 N 天）
对局页
 ├─ 顶部：←返回、年级段、进度（第 x/10 题 或 自由练习）、⏱ 计时（仅挑战）
 ├─ 题目区：emoji 序列大字 + 字格占位 + 💡 看答案 + 🔥 连击展示
 └─ 4 个成语选项大按钮（≥48px，洗牌）
结算页（挑战完成浮层）
 ├─ 答对数 /10 + 总用时 + 星级大卡
 ├─ ✅ 今日已打卡 · 连续 N 天 +（新纪录徽章）+ 🔥 最大连击
 └─ 【再来一局】【📤 分享打卡】【返回难度】
```

### 4.2 判定与反馈

- 点选即判定：正确 → 绿色高亮 + 连击 +1 + 正确音 → 700ms 后自动下一题；
  错误 → 所点红闪 + 正确答案绿高亮 + 错误音 + 挑战局错误计数 → 1200ms 后自动下一题。
- 「看答案」：浮层展示 成语/拼音/释义/例句/年级标签；关闭后进入下一题；挑战局计入一次错误。
- 音效：Web Audio `OscillatorNode` 合成（无音频文件，合规），正确/错误/胜利三音。

## 5. 成绩与打卡（通用能力对齐 `docs/通用需求-打卡分享记录.md`）

localStorage 单 key，**toolId = `kantucy`**：

```js
redtools.kantucy.v1: {
  version: 1,
  best:      { b12: {stars, errors, ms, date}, b34: {...}, b56: {...} },  // 分池最佳（挑战）
  recent10:  { b12: {correct, total, stars, errors, ms, maxCombo, date} }, // 各池最近一次挑战
  checkin:   { dates: ["YYYYMMDD"], streak, ... },
  history:   [ { date, band, correct, total, errors, ms, stars } ]        // ≤30 条 FIFO
}
```

- 打卡：完成一局挑战（10 题）即点亮当日；连续天数由 `dates` 回溯计算。
- 星级/打卡/成绩 schema 与反义词配对/数学口算一致，未来可沉淀 `_shared/`。

### 5.1 分享打卡（挑战结算）

- **分享卡片**：离屏 `<canvas>` 1080×1920（同数学口算 drawShareCard 模式）——暖色渐变底、
  白内卡、工具名、连续打卡胶囊、大字「答对 8/10」、三列统计（答对/用时/最大连击）、
  按正确率分级鼓励语、日期落款。
- **一键复制文案**：`document.execCommand('copy')` + 隐藏 textarea（Chrome 61 无 clipboard API），
  失败时保底提示长按选择复制。

## 6. 技术方案

### 6.1 合规与基线（对齐 `series/学科/设计文档.md` §1）

- **静态工具**（`datasource="chengyu"`）：复制 src/ + 注入共享词库 data.js → 包体 <0.6 MiB。
- **JS**：ES2017 经典脚本（var/function）；无 `eval`/`new Function`/`module`/`import`；事件全部 `addEventListener`；
  动态内容一律 `createElement` + `textContent`（无 innerHTML 数据注入）。
- **CSS**：Chrome 61 基线（禁 `gap`/`aspect-ratio`/`clamp()`/`:has` 等；Flex 子项 `min-width:0`；按钮 hit ≥48px）；
  `--app-height` 视图高度方案。
- **能力**：`localStorage`（禁用时降级为仅本次会话）、`document.execCommand('copy')` + 隐藏 textarea、
  离屏 `<canvas>` 分享卡、Web Audio 合成音效。
- **禁项自检**：无 `fetch`/XHR/Worker/定位/`window.open`/剪贴板 API、无外部 `http(s)://` 引用。

### 6.2 src 结构

```
series/学科/看图猜成语/src/
├── index.html        # 入口（title=看图猜成语；引用 data.js + assets/main.js）
└── assets/
    ├── main.js       # 全部应用逻辑：页面流/出题/判定/连击/计时/成绩/打卡/分享
    ├── style.css     # Chrome 61 基线样式
    └── icon_base.png # 公共图标母版（构建时 make_static_icon 出 128/1024）
```

### 6.3 构建与登记

- `tools.py` 已登记：`ToolConfig(series="学科", tool="看图猜成语", version="1.0", datasource="chengyu", app_name="看图猜成语")`。
- `python build_all.py --tool 看图猜成语` → 审计 → 合规自查 → 冒烟测试（Playwright）：

## 8. 风险与待验证

| 风险 | 对策 |
|------|------|
| ⚠️ 部分 emoji（2019+ 字符如 🪨）在 Chrome 61 渲染为方块 | 选项为文字不影响游戏可玩性；README 已备案；后续按真机实测降级 CSS 图形 |
