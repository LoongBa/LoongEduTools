## 2. 功能需求

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| F1 | **选册选单元** | 首页 → 11 册（年级+册次+总词数+已掌握数）→ 单元（词数+已掌握 x/y）→ 学习 | ✅ |
| F2 | **翻转卡片** | 正面英文大字 → 点击 CSS 3D 翻面 → 背面中文 + 提示；翻面前"认识/不认识"按钮隐藏，翻面后显示 | ✅ |
| F3 | **两级记忆曲线** | 翻面后点「✓ 认识」（连续 2 次 → 已掌握不再出）或「✗ 不认识」（streak 清零 + **该卡重出到队尾**）；认识 1 次（streak=1）仍属学习中 | ✅ |
| F4 | **学习轮次** | 初始随机抽 ≤10 个非已掌握词；不认识重出（队列上限 16 防死循环）；完成 → 打卡 + 结算（认识率/用时/星级） | ✅ |
| F5 | **我的词卡** | 总词数 / 已掌握 / 学习中统计 + 规则说明 | ✅ |
| F6 | **打卡 + 星星 + 家长面板** | 完成轮次即打卡；3★ ≥90% / 2★ ≥60% / 1★ ≥30%；家长面板（累计打卡/连续/已掌握）+ 清除数据 | ✅ |

## 3. 数据与技术

### 3.1 数据源（复用打字背单词 voc 管线）

```js
window.APP_DATA = { meta, books: [
  { grade, term, book, units: [{ unit, words: [{ word, cn }] }] }  // 11 册 / 978 词
]}
```
- `tools.py`：`datasource="vocab"` + `vocab_dir`（与打字背单词相同），构建期解析注入 data.js
- 词清洁（星号/HTML/括号注释）复用打字背单词构建逻辑

### 3.2 持久化（redtools.flash.v1）

```js
{ version:1,
  wordState: { "grade|term|unitIdx|word": { streak, known } },  // key 全局唯一
  checkin: { dates: ["YYYYMMDD"], streak } }
```
- 记忆曲线状态：`streak` 连续认识次数，`known=true` → 已掌握
- **首次认识必须写回**（streak=1 持久化，否则永远缺 1 次——已修复的 bug）

### 3.3 文件结构

```
series/学科/单词闪卡/
├── README.md
└── src/
    ├── index.html
    └── assets/
        ├── main.js         # 视图层：持久化/首页/选册选单元/我的词卡/打卡/家长面板
        ├── flashcards.js   # 卡片引擎：翻转/记忆曲线/轮次/评分/结算
        ├── style.css       # Chrome 61 基线 + CSS 3D 翻转
        └── icon_base.png
```

### 3.4 关键实现点

- **翻转**：CSS `perspective + transform-style:preserve-3d + backface-visibility`（-webkit- 前缀，翻牌记忆配对同款）；`flip-inner.flipped` 切 rotateY(180deg)
- **重出**：不认识 → `session.queue.push(card)` 队尾 + `MAX_ROUNDS=16` 截断防死循环
- **按钮门控**：`#judge-row.visibility=hidden`（翻面后 visible），避免未翻面误判
- 合规：ES2017、addEventListener、无 gap/aspect-ratio/clamp/:has、localStorage version + 迁移

## 4. 交互流程

```
首页（已掌握 x/y 词 + 连续打卡 → 开始学习/我的词卡）
  ├─ 开始学习 → 选册（11）→ 选单元 → 学习轮次
  │    卡片正面(英文) → 点击翻面 → 背面(中文) → ✓认识 / ✗不认识
  │    （不认识重出队尾；连认 2 次已掌握）→ 结算(认识率/星级/打卡)
  │    → 再来一轮 / 返回单元
  └─ 我的词卡：总词/已掌握/学习中 + 规则
家长面板：标题连点 5 次（累计打卡/连续/已掌握 + 清除）
```
