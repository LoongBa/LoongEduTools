# 看图猜成语 — 使用文档

> 成语联想训练：看 emoji 拼图猜成语，4 选 1 点选即练，零打字门槛。
> 适用：手机 / 电脑（点选即可，无需输入法）。
> 版本：v1.0 · 更新：2026-09-20

---

## 1. 怎么练

1. 打开工具，首页**选一个年级段**：1-2 年级 / 3-4 年级 / 5-6 年级（词库按课本年级标签分池出题）。
2. 每个年级段有两个入口：
   - **[练一练]**：自由刷题，答完自动出下一题，适合熟悉练习方式、无压力积累；
   - **[挑战10题]**：10 题挑战 + 计时，完成即打卡，可拿星级、刷新纪录、分享打卡。
3. 看屏幕上的 **emoji 拼图**（比如 `1️⃣ ❤️ 1️⃣`），在下方 **4 个成语**里点选一个：
   - 猜对 → 绿色高亮 + 连击 +1，自动进入下一题；
   - 猜错 → 红闪一下，同时**正确答案会亮绿标**（即时学习），随后自动进入下一题。
4. 猜不出 → 点 **[💡 看答案]**：弹出 成语 + 拼音 + 释义 + 例句 + 年级标签，看完点「知道了」继续（挑战局会算一次答错）。

## 2. 练习规则

| 规则 | 说明 |
|---|---|
| 题目 | emoji 拼图 + 字格占位（`____ ____ ____ ____` 提示几个字）→ 4 个成语选 1 |
| 操作 | 点选项即判定，无需输入法 |
| 答对 | 绿标 + 连击 +1 + 提示音 → 自动下一题 |
| 答错 | 所点红闪 + 正确答案绿标 + 挑战局错误计数 +1 → 自动下一题 |
| 看答案 | 展示 成语/拼音/释义/例句/年级标签；挑战局计一次答错 |
| 出题 | 243 条课本成语 emoji 拼图库，按年级段分池（66/84/121 条），挑战局内不重复 |
| 星级（挑战） | 0 错 3★ / 1~2 错 2★ / 3 错及以上 1★（完成 10 题即有） |
| 技巧 | 先数字格猜字数，再看 emoji 关键形象（动物/数字/自然），最后对候选成语 |

## 3. 界面说明

- **首页**：三个年级段卡片（显示该段历史最佳：星级 · 用时 · 错误数），每卡 [练一练] / [挑战10题] 两按钮；底部「📅 打卡日历」。
- **对局页顶栏**：`← 返回`、年级段、进度（`第 x/10 题` 或 `自由练习`）、`⏱ 用时`（仅挑战局计时）。
- **题目区**：emoji 大字拼图 + 字格占位；连击 ≥2 显示 `🔥 连击 xN`。
- **挑战结算**：答对数 /10 + 总用时 + 星级 + 连续打卡天数 + 最大连击；按钮：再来一局 / 📤 分享打卡 / 返回难度。

## 4. 成绩与打卡

- **打卡**：每完成一局挑战（10 题）即点亮当日；打卡日历显示本月打卡与连续天数（连续 7 天及以上有 🎉）。
- **最佳成绩**：各年级段分别记录（星级高优先，星级相同比用时短）；最近一次挑战结果与最近 30 局记录自动保存。
- **分享打卡**：挑战结算点「📤 分享打卡」→ 生成 **1080×1920 分享卡片**（答对数/用时/最大连击 + 鼓励语）+ 一键复制文案，粘贴到小红书/微信即可晒成绩。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- **先看字格数**：字格数量就是成语字数，先排除字数不符的候选。
- **emoji 是线索不是答案**：数字拼图（`3️⃣ 6️⃣`）多与「三头六臂」「五颜六色」这类数字成语有关；动物/自然形象直接对应词义。
- **答错不丢人**：正确答案会亮绿标，看完自动下一题，错题本身就是学习机会。
- 挑战局**看答案会算答错**，想拿 3★ 尽量先猜；练一练模式随便看答案不计数。
- 想换年级段？对局页顶栏 `← 返回` 回到首页重选即可。

## 6. 常见问题

**Q：猜对猜错会惩罚吗？**
不会。练一练无任何计数；挑战局答错只影响星级（0 错 3★ / 1-2 错 2★ / 更多 1★），不中止、不扣分。

**Q：有些 emoji 显示成方块/空白？**
部分 emoji（2019 年之后新出的字符）在很老的手机浏览器（如 2017 年的 Chrome 61）上会显示为方块，但成语选项都是文字，照常可以猜；新设备/新浏览器上显示完整。

**Q：适合几岁的孩子？**
1-2 年级段（66 题，基础数字/自然类成语）适合启蒙；5-6 年级段（121 题）含抽象与典故成语，适合高年级。家长可陪练讲解「看答案」里的释义与例句。

**Q：挑战局题目会重复吗？**
单局 10 题不会重复；跨局可能遇到已猜过的（有复习价值）。练一练不会连续出同一题。

**Q：成绩怎么清除？**
目前没有「清空成绩」按钮。成绩保存在浏览器 localStorage 中，清除浏览器数据即可清空；换设备不会同步。
