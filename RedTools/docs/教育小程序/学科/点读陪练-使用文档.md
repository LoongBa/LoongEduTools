# 点读陪练 — 使用文档（学科 · 双模式 v0.1）

> 适用版本：v0.1（2026-09-21）。**双模式**：离线包（免费试学 Unit1）与在线版（全单元解锁）。

## 1. 这是什么

「英语点读陪练」是跟着课本单元同步练英语的小工具：每个单元有**词汇卡**（英文→选中文）和
**句型卡**（英文→选翻译），点选练习、即时反馈、自动打卡。

适合：小学生 1-6 年级 + 家长（同步课堂进度巩固）。

## 2. 双模式怎么用

| 版本 | 内容 | 怎么用 |
|---|---|---|
| **离线版**（zip） | Unit 1 免费试学 | 下载解压 → 双击 index.html 即用；页脚有「在线练习」引导 |
| **在线版**（全量） | 全部单元 | 部署后经公众号/网站进入；输入产品授权口令解锁完整版 |

## 3. 开始练习

1. 打开工具进入「选择单元」（离线版 1 个单元，在线版全部单元）。
2. 点选一个单元 → 出题：显示英文单词/句子，**4 个选项选中文意思**。
3. 点对 → ✓ 提示自动下一题；点错 → 计数，可继续。
4. 全部答完 → 结算（正确率 + 星级）+ 自动打卡（连续天数）。

## 4. 在线版授权

- 完整版需要**产品授权口令**（在公众号/网站购买获得）。
- 进入单元时若未授权，会提示「输入口令」→ 输入后解锁完整版。
- 口令按工具范围 × 有效期授权（详见《教育工具在线版设计要求》§3.4）。

## 5. 常见问题

| 问题 | 说明 |
|---|---|
| 离线版能玩多久？ | 不限时；内容是 Unit1 免费样例，完整版在在线版 |
| 数据存在哪？ | 本地浏览器（离线）/ 云端（在线，仅完成状态与打卡） |
| 会收集孩子信息吗？ | 不会——孩子端无账号，只有家长手机号承载授权 |
