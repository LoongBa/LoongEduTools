# 打字背单词 — 使用文档（学科 · P1）

> 状态：**v1.0 已构建（2026-09-18）**；⚠️ Chrome 61 / 真机未实测时如实标记。
> 版本：v1.0（词库数据管线 + 册→单元两级选择 + 中→英打字（虚拟键盘+实体键盘）+ 字母槽即时反馈 + 结算打卡 + 成绩 recent10 + 错题本）。
> 产品配套：`docs/教育小程序/学科/打字背单词-设计文档.md`。

## 1. 这是什么

看中文释义，打字拼出英文单词的小工具。词库**完全来自 PEP 人教版小学英语教材 11 册的真实单元词汇**
（976 词，与课堂进度同步），覆盖"四会"单词里最难练的**"会写"**环节。

- 面向：小学生（1-6 年级，按年级选册）、家长（陪练）、教师（课堂拼写检测）
- 训练：单词拼写（中→英）、字母识别、拼写准确性
- 离线可用：解压后双击 `index.html` 即可用，无需联网

## 2. 开始使用

1. **选册次**：首页列出 11 册（一年级 上册 ~ 六年级 上册，附全册词数与单元数）
2. **选单元**：点某册 → 显示单元列表（Unit 1~6，附每单元词数）→ 点单元开始
3. **打字拼单词**：
   - 上方显示**中文释义**（大字），下方是**字母槽**（每字母一格）
   - 手机：点屏幕键盘字母输入；电脑：直接敲实体键盘
   - 空格词（如 `police officer`）按键盘「空格」键输入空格
   - 撇号词（如 `I'm`）按 `'` 键；连字符词（如 `T-shirt`）按 `-` 键
   - 输满词长自动提交；也可点「✓」提前提交
4. **即时反馈**：
   - 答对：字母槽变绿 + "✓ 答对了"，自动进入下一题
   - 答错：字母槽变红并展示**正确拼写** + 显示完整正确答案，稍后进入下一题（该词进错题本）

## 3. 一轮练习

- 每轮随机抽该单元 **10 个词**（单元词数不足 10 则全练），全程计时
- 顶部显示：第 x/10 题 + 对/错计数 + 计时
- 完成 10 题 → 结算页：对题数、用时、正确率、连续打卡天数
- 结算后可选：【再练一轮】（同单元换一批词重抽）/【换个单元】

## 4. 功能一览

| 功能 | 位置 | 说明 |
|------|------|------|
| 选册/选单元 | 首页 | 11 册 × 每册 5~6 单元，与教材进度同步 |
| 虚拟键盘 | 练习页 | 3 行 QWERTY + 退格 + 空格/撇号/连字符/提交（手机端） |
| 实体键盘 | 练习页 | 字母输入、Enter 提交、Backspace 退格（教室电脑自动兼容） |
| 错题本 | 成绩页 | 答错单词自动收录（连续答对 3 次移除），成绩页显示已收录词数 |
| 打卡日历 | 成绩页 | 完成一轮即点亮今日 + 连续打卡天数 + 最长连续 |
| 成绩记录 | 成绩页 | 最近 10 次（册·单元 / 日期 / 对题数） |
| 记住我在哪 | 自动 | 成绩与打卡记录自动保存在浏览器本地 |

## 5. 常见问题

- **单词中间有个空格怎么打**：按键盘底部「空格」宽键（如 `police officer`）
- **首字母大写也算对吗**：算，判定不区分大小写（`I'm` 打 `i'm` 也对）
- **为什么有的单元只有 3~5 题**：该单元教材词汇不足 10 个（低年级），全练即完成
- **错题本有什么用**：答错的词会被记住，连续答对 3 次自动移除——下次复习时可优先关注
- **换一个册/单元**：练习页点「‹ 返回」回单元列表，或结算页点「换个单元」

## 6. 小提示

- 低年级从「一年级」开始，词短易上手；高年级挑战长词与短语（如 `Jinggangshan Revolution Museum`）
- 家长可让孩子先口头拼一遍再打字，效果更好
- 页面内所有记录都存在浏览器本地，卸载/清缓存会清空
