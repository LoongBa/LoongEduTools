# 成语接龙 — 使用文档（学科 · v1.1）

> 适用版本：v1.1（2026-09-20）。离线小工具：下载 zip 解压后双击 `index.html` 即可使用，无需联网。

## 1. 这是什么

「成语接龙」是练成语的小练习：系统出一条成语，你用它的**最后一个字**接出一条新成语
（如 一石二鸟 → **鸟**语花香）。接得越长越厉害，还会自动打卡、记录成绩、生成分享卡片。

适合：3-6 年级小学生巩固课本成语；家长亲子共学；老师课堂复习。

## 2. 开始使用

1. 打开工具进入首页，点 **【开始接龙】** 即可开局。
2. 系统显示当前成语，**尾字会变橙色高亮**（如「一石二鸟」的「鸟」）。
3. 下方给出 **3 个候选成语**，点选以橙色字开头的那个：
   - 点对 → 绿色闪光，接着会弹出一张**释义卡**（拼音 / 释义 / 出处 / 例句），看完自动出下一题；
   - 点错 → 红闪提示，可重新选（点错的卡会锁住，不算重复扣分）。

## 3. 卡壳了怎么办

- **💡 提示按钮**：每局最多用 2 次，点击后正确答案会加上**橙色边框**。
- 提示次数会计入结算评分（提示越多星级越低），建议留到最后再用。

## 4. 首页设置

| 设置 | 说明 |
|------|------|
| **同音容忍** | 默认关。打开后，同音字也能接（如「石 shí」可以接「时 shí」开头的成语），门槛更低，适合低年级 |
| **限时模式** | 默认关。打开后每步倒计时（可选 30 / 20 / 10 秒），超时算一次错误并自动标出正确答案 |

设置会自动保存，下次打开仍生效。

## 5. 结算与打卡

- 当某个字**没人接得上**（死路）或你觉得尽兴了（点右上角「退出」），一局结束。
- 结算页展示：**接了 N 条 · 总用时 · 错误 · 提示**，按长度和表现给 **1~3 星**。
- 每完成一局（含死路结算）自动**打卡**，连续打卡天数在首页可见。
- 最佳成绩（最长接龙）自动记录，最近 10 次成绩可在家长面板查看。

## 6. 分享打卡

结算页点 **【分享打卡】**：
- 生成一张**打卡卡片图**（长按图片保存到相册，可发小红书 / 朋友圈）；
- 【复制文案】一键复制分享文字（如「成语接龙挑战！孩子一口气接了 8 条成语…」）；
- 桌面端可直接【保存图片】下载。

## 7. 家长面板（隐藏功能）

在首页**顶部标题上连续点 5 次**进入家长面板：
- **打卡日历**：本月小圆点日历，橙色 = 已打卡；
- **最近成绩**：近 10 局记录（长度 / 用时 / 星级）；
- **重置数据**：一键清空所有打卡与成绩（不可恢复，谨慎操作）。

## 8. 小贴士

- 成语带「扩展」小角标 = 课外扩展词（不在课本范围，只作候选，不用专门背）；
- 接不上的字不是你的错，是这条成语本身"无路可走"，系统会提示并结算；
- 建议每天练几局，坚持打卡，成语量会悄悄涨起来～
