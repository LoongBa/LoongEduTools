# 乘法口诀练习（学科系列）— 使用文档

> 版本：v1.0（2026-09-19）· 适用：手机竖屏（离线 zip，双击 index.html 即用）

## 1. 这是什么

九九乘法口诀记忆小工具：**学习口诀表 → 抽查巩固 → 易错专训** 闭环。
适合 2-4 年级孩子背熟九九表，家长陪练或孩子自习均可。

## 2. 首页

打开即见顶部进度卡 + 三个入口：

| 入口 | 作用 |
|---|---|
| 📖 学习口诀表 | 看口诀、行末小测解锁下一行 |
| 🎲 随机抽查 | 从已解锁口诀随机出题（含计时挑战） |
| 🎯 专项练习 | 选某一行的口诀强化训练 |

顶部进度卡显示：已解锁几行口诀、连续打卡几天。

## 3. 学习口诀表（按行解锁）

- 口诀表共 **9 行**（1 的口诀 → 9 的口诀），每行是三角表（如第 3 行：三三得九 ~ 三九二十七）
- **第 1 行默认解锁**；点击已解锁的绿色卡片可展开算式（如「三六十八」→ 3×6 = 18）
- 每行下方有「行末小测 · 解锁下一行」按钮：随机 5 题，**答对 ≥80% 即解锁下一行**
- 锁定行显示 🔒，需要先通过上一行小测

## 4. 随机抽查

- 从**已解锁**的所有口诀中随机出题（已学过的才考）
- 进入后选模式：
  - **普通练习**：10 题，无时间限制
  - **⏱ 30 / 60 / 120 秒挑战**：限时答题，共 20 题，时间到自动交卷；剩余 ≤10 秒计时变红
- 用屏幕数字键盘输入答案（1-9、0、退格 ⌫、确认 ✓），**不需要切换系统输入法**
- 每道题即时反馈：答对绿✓自动下一题；答错红✗并显示正确答案

## 5. 专项练习

- 选择某一**已解锁**的口诀行，只练这一行（10 题）
- 适合集中攻克：如孩子 7 的口诀不熟，就练「7 的口诀」

## 6. 打卡与成绩

- **每次完成一次练习自动打卡**：底部导航「打卡日历」查看本月火苗和连续天数
- 成绩星级：全对 3★ / 答对 ≥80% 2★ / ≥60% 1★（专项和小测的星级记录在对应口诀行上）
- 结果页显示：正确率、星星、答对数、用时、是否新纪录

## 7. 易错本

- 答错的题自动进「易错本」；底部导航进入
- 同一口诀错 **≥2 次**会被标为易错口诀，一键「易错专练」（≤10 题）集中重练
- 连续答对 3 次同一口诀，自动从易错本移除

## 8. 家长面板（隐藏入口）

- 标题（顶部中间"乘法口诀练习"文字）**5 秒内连点 5 次**进入
- 可看：累计打卡天数、累计答题/答对数、当前错题数、已解锁进度、各模式历史最佳
- 提供「清除所有数据」按钮（确认后重置全部进度）

## 9. 常见问题

| 问题 | 说明 |
|---|---|
| 想重练已解锁的行？ | 专项练习里选那一行即可 |
| 解锁了第 2 行，随机抽查会考第 2 行吗？ | 会。随机抽查范围 = 所有已解锁行 |
| 数据存在哪？ | 手机浏览器本地存储（redtools.mul.v1），离线可用，不联网不上传 |
| 清掉浏览器缓存会怎样？ | 解锁进度/打卡/错题会重置（可先在家长面板备份认知） |

## 10. 提示

- 建议每天 1-2 次，每次 5-10 分钟即可（防沉迷：随学随停，无强制时长）
- 先「学习口诀表」看一遍口诀，再「专项」练不熟的行，最后「随机抽查」巩固，效果最好
