# 点击反应测试（益智 · 反应力）· 使用文档

> 适用对象：家长 / 学生（无需读代码即可上手）。
> 适用版本：v1.0（2026-09-19）。
> 本文档描述的功能以实际软件为准，数据仅保存在本机，不联网。

## 1. 这是什么

「点击反应测试」是一个**反应力**训练小工具：屏幕先是**红色**，等一小会儿突然变成**绿色**，
一看到绿色就**立刻点一下屏幕**，系统会记下你这次反应用了多少**毫秒**。连续测几轮，
取**平均成绩**，看看你的反应有多快！

每次等待的时间都是随机的（2~5 秒），猜不准、背不下来，测出来的都是真实反应速度。
打开即用，无广告、无网络依赖。

## 2. 如何打开

1. 解压 `publish/益智/点击反应测试.zip`，或直接使用现成的 `publish/益智/点击反应测试_解压测试版/` 目录。
2. 双击目录里的 `index.html`，用浏览器打开即可使用。
3. 建议在手机/平板上使用（或电脑浏览器开启手机模式），体验最佳。

> 提示：把解压后的整个文件夹发给家长或孩子，双击 index.html 就能用，无需安装任何软件，
> 离线也能用。

## 3. 首页与底部导航

打开后先看到「选择难度」，共 3 张难度卡片：

| 卡片 | 测试轮数 | 适合 |
|---|---|---|
| 简单 · 3 次 | 3 轮 | 低龄启蒙 / 初次接触 |
| 进阶 · 5 次 | 5 轮 | 常规训练 |
| 挑战 · 8 次 | 8 轮 | 进阶提速 |

每张卡片下方显示该难度的**最佳成绩**（如「最佳 250 ms」），还没练过则显示「未挑战」。

卡片下方还有「练习方式说明」4 条：

1. 看到红屏别着急，等它变绿
2. 屏幕一变绿就立即点击！
3. 没变绿就点了算犯规，本轮重来
4. 完成所有轮次，取平均成绩

页面底部有 3 个导航入口：

| 入口 | 作用 |
|---|---|
| 成绩 | 查看最近成绩记录 |
| 打卡 | 查看本月打卡日历与连续天数 |
| 首页 | 返回选难度 |

## 4. 练习方法

### 4.1 开始练习

点击一个难度卡片进入练习。比如「简单 · 3 次」就是连续测 **3 轮**反应。

### 4.2 一局是怎么进行的

一局 = 连续 N 轮"等变绿 → 点击"（N = 难度轮数），每轮流程：

1. **等待**：屏幕变红，显示「👀 等待变绿，变绿后立即点击！」。
   这次要等多久是**随机的**（2~5 秒），每次都不同，没法掐着表提前准备。
2. **点击**：屏幕一变绿（显示「⚡ 点！」），**立刻**点击中间的大区域。
   系统记下这次反应用了多少毫秒。
3. **单次反馈**：屏幕变白，显示本次成绩（如 `250 ms`）+ 等级标签（如「闪电」）。
   稍等 1 秒多，自动进入下一轮。
4. 所有轮次完成后，弹出本局结果卡片（见第 5 节）。

### 4.3 犯规说明

**还没变绿就点了，算犯规**：

- 屏幕变红并提示「⛔ 太快了！还没变绿，重新等待」；
- 本轮作废，等一小会儿后重新进入等待（重新随机延迟）；
- **犯规不计入成绩**，犯规多少次都不会扣分，只是会多等几轮。

> 提醒孩子："看到绿色再点"才是得分的关键，红屏时管住小手。

### 4.4 练习页说明

顶部一行从左到右：

| 内容 | 含义 |
|---|---|
| ‹ 返回 | 返回首页，本局不计成绩、不打卡 |
| 第 x/y 轮 | 当前第几轮（如「第 2/3 轮」） |
| 平均 xx ms | 已完成轮次的平均成绩（还没成绩时显示 --） |

中间是**大点击区**：红（等待）/ 绿（快点）/ 白（单次成绩）三种状态，面积很大，
孩子随便一点就能点到。底部有「重新开始」按钮：本局清零，从第 1 轮重新开始。

## 5. 结果页

所有轮次跑完后，弹出结果卡片：

- 大号显示本局**平均成绩**（如 `250 ms`）
- 等级标签（如『闪电』）
- 统计：最快 / 最慢 / 连续打卡
- **星级**：★★★ / ★★ / ★（标准见第 6 节）
- 刷新该难度最佳成绩时，显示「🎉 新纪录！」
- 单次成绩列表（第 1 次 xxx ms、第 2 次 xxx ms ……）
- 三个按钮：「再来一局」同难度重新挑战；「返回首页」回到选难度；「📷 分享打卡」
  把成绩做成卡片分享出去（见第 7 节）

> 完成一局即自动打卡，今天的日期自动点亮，无需额外操作。

## 6. 星级与等级说明

星级看**平均毫秒**（数字越小越快）：

| 平均成绩 | 星级 |
|---|---|
| ≤ 280 毫秒 | ★★★ |
| ≤ 400 毫秒 | ★★ |
| 其余 | ★ |

等级标签（同样按平均毫秒）：

| 平均成绩 | 等级 |
|---|---|
| ≤ 200 ms | 神速 |
| ≤ 280 ms | 闪电 |
| ≤ 350 ms | 优秀 |
| ≤ 450 ms | 不错 |
| > 450 ms | 加油 |

简单说：**平均 280 毫秒以内就是 3★，400 毫秒以内就是 2★**。家长可以拿
「280 闪电」「400 优秀」当小目标，鼓励孩子一点点进步。

## 7. 分享打卡怎么用

结果卡片点「📷 分享打卡」：

1. 弹出**分享卡片**：一张自动生成的竖版长图（1080×1920），包含工具名、难度、
   平均毫秒大字、等级、最快最慢、连续打卡天数、鼓励语、署名和日期。
2. **手机上长按图片**保存到相册，然后去小红书发布笔记。
3. 点「**复制分享文案**」自动复制一段打卡文案，成功时提示
   「✅ 文案已复制，去小红书粘贴发布吧」；万一复制失败，文案会直接显示出来，
   长按选择复制即可。文案内容例如：

   > 孩子练【点击反应测试】『简单 · 3 次』平均反应 250 毫秒，『闪电』！
   > 已连续打卡 3 天，反应力训练走起～#反应力测试 #小学生专注力 #益智训练

4. 点「返回结算」回到结果卡片。

## 8. 成绩页

底部导航点「成绩」，按时间倒序列出最近完成的记录（最多保留最近 30 次）：

- 难度（如「简单 · 3 次」）
- 日期 · 有效 x 次（本局实际计分的轮数）
- 平均成绩（如 `250 ms`）
- 星级

还没有成绩时显示「暂无成绩，先来一局吧！」。

## 9. 打卡日历

底部导航点「打卡」：

- 显示**本月日历**，完成过练习的日子点亮橙色，今天有红色描边
- 下方显示「连续打卡 N 天」，连续 ≥7 天显示 🎉
- 打卡**自动完成**：完成一局练习即点亮今日，不需要任何手动操作
- 打卡记录最长保留 365 天

## 10. 数据存储说明

- 所有数据（最佳成绩、最近成绩、打卡记录）保存在**本机浏览器**的本地存储中
  （键名 `redtools.reaction.v1`），不联网、不上传
- 清除浏览器数据、更换设备或卸载浏览器会导致数据丢失
- 暂无云端同步；换设备前建议先记录当前最佳成绩

## 11. 常见问题

**为什么等待时间不一样？**
每次变绿前的等待时长是随机生成的（2~5 秒），无法预判。这样才能测出真实反应速度，
防止"掐着表"提前点。

**还没变绿就点了会怎样？**
算犯规：红屏提示「⛔ 太快了！还没变绿，重新等待」，本轮作废，稍等片刻重新进入等待。
犯规不计入成绩，只是会多等一轮。

**平均成绩怎么算？**
把本局所有有效轮次的毫秒数加起来，除以轮数，四舍五入取整。犯规的轮次不参与计算。

**星级怎么评？**
按平均毫秒：≤280 毫秒 3★，≤400 毫秒 2★，其余 1★。平均越短越快，星级越高。

**最快 / 最慢是什么意思？**
本局所有有效轮次里，单次最少和最多的毫秒数。两个数字越接近，说明反应越稳定。

**分享卡片怎么保存？**
结算时点「📷 分享打卡」→ 弹出卡片图 → 手机上长按图片保存到相册，再去小红书发布笔记；
也可以点「复制分享文案」把文字一起带上。

**数据存在哪里？**
只存在当前设备的浏览器本地存储里，不联网、不上传。

**需要网络吗？**
不需要。所有画面和内容都由代码生成，解压后完全离线可用。

**换设备数据会丢吗？**
会。数据只保存在当前设备，不跨设备同步；清除浏览器数据也会丢失。
换设备前建议先记下当前最佳成绩。
