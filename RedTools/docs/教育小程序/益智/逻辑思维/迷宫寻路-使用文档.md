# 迷宫寻路 — 使用文档

> 路径规划训练：从左上角出发，走到右下角出口即过关，锻炼观察与规划能力。
> 适用：手机（触屏滑动）/ 电脑（方向键或点击按钮）。
> 版本：v1.0 · 更新：2026-09-19

---

## 1. 怎么练

1. 打开工具，在**难度选择页**选一个难度：简单 7×7 / 普通 11×11 / 困难 15×15。
2. **滑动屏幕**（手机）或按**方向键 / WASD**（电脑）或点**方向按钮**，让蓝色小圆从**左上角起点**出发。
3. 找到通往**右下角红色出口**的路线，走到出口就过关啦！
4. 每次进入都是**随机生成的新迷宫**（不会背题），过关后按用时与步数记录成绩。

## 2. 练习规则

| 规则 | 说明 |
|---|---|
| 目标 | 绿色起点 → 红色出口，走通即过关 |
| 移动 | 每次一格，不能穿墙、不能走出边界 |
| 迷宫 | 每次随机生成「完美迷宫」（有且只有一条最优路线），三档难度 |
| 步数 | 走一步算一步，绕远路会增加步数、影响星级 |
| 提示 | 卡住了点「💡 提示」看最短路径，但用过提示本局**最多 2 星** |
| 技巧 | 先通观全局规划路线再走，尽量避免回头路 |

## 3. 界面说明

- **难度选择页**：三个难度卡片，显示该难度**最佳成绩**（步数 · 用时）。
- **顶栏**：`← 返回`（回到难度页）、当前难度名、`⏱ 用时`、`步数`。
- **迷宫**：灰块是墙、浅色是通道；走过的格子留**浅黄色足迹**，一眼看清走过哪些路。
- **步数 · 最优 N 步**：本次步数与**理论最少步数**（星级评定基准，程序算出的最短路径）。
- **💡 提示**：高亮显示最短路径（黄色圆点）；用后会禁用，本局星级封顶 2 星。
- **↻ 重新生成**：同难度换一个全新迷宫（相当于「重开」+「换题」）。

## 4. 成绩与打卡

- **星级**（按最短步数评定，宽松友好）：
  - ★★★：步数 ≤ 最优的 1.5 倍
  - ★★：步数 ≤ 最优的 2.5 倍
  - ★：过关即可
  - 用过「提示」本局最多 2 星
- 每过关一局即点亮**今日打卡**，页面底部显示连续打卡天数。
- 各难度分别记录最佳成绩；最近 30 局自动保存。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- 练习会**自动保存当前进度**：中途退出后重新打开，会恢复刚才的迷宫、步数与用时（计时按真实经过时间继续）。
- 走远了迷路了？点「↻ 重新生成」换个新迷宫，或点「💡 提示」看最短路径。
- 音效由程序合成（无需网络/音频文件），设备静音时自动无声运行，不影响练习。

## 6. 常见问题

**Q：为什么滑动没反应？**
确保手指从棋盘区域内滑动，且滑动手势超过一定距离（约 24px），太短会被识别为误触忽略。

**Q：迷宫总是新随机生成，会不会太难？**
先练「简单 7×7」熟悉练习方式。迷宫是程序生成的「完美迷宫」——一定走得通，且能提前看到全貌规划路线。

**Q：用了提示还能得 3 星吗？**
不能。用过「💡 提示」的本局星级封顶 2 星，想冲 3 星请凭自己的观察力走完。

**Q：中途退出了，进度会丢吗？**
不会。重新打开会自动恢复上次的迷宫、步数、足迹与计时（计时按离开的时间照常走）。
