## 2. 玩法设计

### 2.1 核心玩法

1. **经典扫雷盘面**：三档难度（初级 9×9·10 雷 / 中级 16×16·40 雷 / 高级 30×16·99 雷）；
2. 首点必翻安全区；数字格 = 周围 8 格雷数；
3. **目标 = 翻开全部安全格**（有标准答案：安全格集合程序可判）；
4. **踩雷不判负**（D2 核心改造）：踩雷 → 红闪标出该雷（💣）+ 推理提示 toast + **局继续**，
   已踩雷格自动标旗（= 已确认雷，提示避开）。

### 2.2 判定（有标准答案）

| 判定维度 | 机制 |
|---|---|
| 对/错 | 全部安全格翻开 = 完成（程序可判定：opened 集合 ⊇ 安全格集合） |
| 完成反馈 | `🎉 完成推理！所有安全格都翻开了，逻辑清晰！`（用时 + 踩雷次数记录） |
| 踩雷提示 | `💥 踩到雷了（第 N 次）——已标出。看周围数字：几就代表周围有雷，已标出的雷不用再踩` |
| 个人纵向 | 各难度最佳用时（无排行榜/PK） |

### 2.3 D2 改造要点（脱离经典游戏分类）

| 项 | 原扫雷（游戏化） | 扫雷推理（练习化） |
|---|---|---|
| 踩雷 | boom 音效 + 判负终局 | **不判负**：标雷 + 推理提示 + 局继续（`loseGame` 不再置 over） |
| 计时 | 记录用时（可竞争感） | 仅个人纵向（本难度最佳） |
| 胜负 | 排完全部雷 = 赢（gameOver） | **全部安全格翻开 = 完成**（无胜负文案） |
| 推理依据 | 无 | **踩雷格自动标旗** + 数字推理提示（`showMineHint`） |
| 文案 | 「踩雷/输了/胜利」 | 「翻开/完成练习/看看推理」 |
| 键名 | `redtools.minesweeper.v1` | **独立** `redtools.saoleituili.v1`（脱离经典游戏，UI/文档全新） |

### 2.4 输入双模式

- **翻开模式**（默认）：单击未翻开格 = 翻开；长按 = 插旗；
- **标旗模式**：单击未翻开格 = 插旗（触屏稳定标旗入口，防误点到雷）；
- 键盘光标（键盘用户）+ 触屏/鼠标双支持；高级棋盘横向滚动。

## 3. 复用与双模式

- **复用**：经典扫雷 v1.1 全部逻辑（布局/邻接/翻开/标旗/首点安全/键盘/断局恢复）+ 防沉迷 + 结算三选 + 分享卡片；
- **D2 改造**：`state.missCount`（踩雷次数，影响展示不判负）+ `state.hitMines`（已踩雷集合，💣 标记）+ `showMineHint`（推理 toast）+ 完成判定改「安全格全翻开」；
- **持久化**：`LX_SHARED.storage.configure({toolName:'saoleituili'})` → `redtools.saoleituili.v1`（V0.4 迁移）；
- **双模式**：offline（zip → publish）+ online（部署目录），index.html 注入 lx-shared.js。

## 4. 防沉迷 / 自控力（复用通用需求）

- **单局时长**：5/10/15 分钟档位，到点提醒（延迟 +5 分钟，每类上限 2 次）；
- **今日局数**：3/5/10/不限 档位，赢满即提醒（延迟 +2 局，上限 2 次）；
- **试错局豁免**：<10 秒失败的局不计今日局数（对齐 TRIAL_SEC=10）；
- **自律锁**：「我很自律，今天足够了」→ 今日结束 + 自律连续天数（selfDaily/selfStreak）；
- **结算三选**：再来一局 / 分享打卡 / 我很自律（局数满时无「再来」仅分享/自律）。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：经典脚本（无 module）、ES2017 内、事件全部 addEventListener；
- CSS：无 flex gap / aspect-ratio / clamp / 逻辑属性 / :has；
- CSP：无 fetch/XHR、无外部 http(s) 引用、无内联事件（合规自查 PASS）；
- 命名：UI 无「游戏/踩雷判负/胜利」字样（「踩雷」仅指翻开到雷的提示）；
- 数据最小化：仅最佳成绩/打卡/防沉迷状态/断局，纯离线。
