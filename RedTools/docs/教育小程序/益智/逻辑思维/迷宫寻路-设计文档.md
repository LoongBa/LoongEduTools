## 2. 玩法设计

### 2.1 规则

- 程序化生成**完美迷宫**（递归回溯算法：任意两点间有且仅有一条通路，无环无死胡同歧义）。
- 玩家从**左上角**出发，走到**右下角出口**即过关。
- 每次移动一格（上/下/左/右），不能穿墙、不能越界。
- 胜利条件：到达右下角出口格。
- 路径规划价值：出口不可见（迷宫全貌可见），需要玩家提前规划最优路线、避免绕远路。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 触屏滑动 | 棋盘上滑动手势（阈值 24px，水平/垂直占优判定，防误触） |
| 键盘 | 方向键 ←↑↓→ 或 WASD |
| 方向按钮 | 十字 D-pad（▲◀▼▶，56px hit area，PC 模拟器/无键盘兜底） |
| 功能按钮 | 「💡 提示」显示 BFS 最短路径（用后本局星级封顶 2 星）；「↻ 重新生成」同难度换一个新迷宫 |

### 2.3 反馈

- **足迹**：玩家经过的格子留下浅黄色足迹标记，直观回顾走过的路线（当前局内定位/复盘）。
- **提示**：点「💡 提示」高亮 BFS 最短路径（黄色圆点串联），并提示"已用提示"——用提示通关的星级**封顶 2 星**（保持挑战性）。
- **动画**（温和，光敏合规）：通关时出口格 winPulse 脉冲（400ms）+ 浮层 cardIn 250ms + 星级 starPop 350ms。
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件）：
  移动（低频轻响）/ 撞墙（闷响）/ 使用提示（清脆）/ 胜利（上行琶音，同推箱子）。
  首次用户手势创建 `AudioContext`，播放异常静默降级。
- **视觉区分**：墙灰蓝立体块、通道浅米色、足迹浅黄、起点绿圆、出口红方旗标、提示路径黄圆点、玩家蓝色圆（两只白眼）。

## 4. 技术设计

### 4.1 数据模型

- **迷宫**：程序化生成（无数据文件），运行时 `state.pass`（idx → true 通路格，墙 = 非通路）。
- **运行时状态**：`state = { size, seed, pass, player:idx, visited:[idx], steps, bestSteps, hintUsed, hintActive, hintMap, ms, startStamp, won, playing }`。
  idx = `y*size + x`；pass/visited 用对象哈希集 + 数组（O(1) 查询 + 有序足迹）。
- 三档难度：`DIFFS = [ {key:'7', name:'简单', size:7}, {'11','普通',11}, {'15','困难',15} ]`（奇数尺寸保证出入口为偶数坐标房间）。

### 4.2 迷宫生成（递归回溯 + seed 确定性）

```
genMaze(size, seed):
  rnd = makeRng(seed)          # 线性同余 LCG：s=(s*1664525+1013904223)>>>0
  pass = {}, visited = {}, stack = [(0,0)]
  while stack 非空:
    cur = stack 顶
    四方向 Fisher-Yates 洗牌（rnd 驱动）
    遍历方向 dir：
      nx,ny = cur + dir*2      # 隔一格（房间间距）
      若 nx,ny 在界内且未访问：
        打通中间格 pass[(cx+dx, cy+dy)] = true   # 打通墙
        打通目标格 pass[(nx,ny)] = true          # 打通房间
        visited；push；break
    无方向可走 → pop（回溯）
  return pass                  # (0,0) 与 (n-1,n-1) 双保险强制通路
```

- **完美迷宫保证**：递归回溯生成的是**生成树**（N 房间 N-1 条通路），任意两格唯一路径、无环 → BFS 距离即最短步数。
- **seed 确定性**：`seed = Date.now() % 100000`；LCG 产确定序列 → 断局恢复按 seed 重放 `genMaze` 还原同一迷宫（不存迷宫数据，只存 seed，体积≈0）。

### 4.3 BFS 最短路（星级基准 + 提示路径）

```
bfsShortest(size, pass, startIdx=0, goalIdx=size*size-1):
  队列 + 头指针（不用 shift），dist/prev 哈希
  从起点 BFS 到终点，返回 { dist: 最短步数, path: [idx...]（不含起点含终点） }
```

- `computePathInfo()`：每次新迷宫/恢复/提示时计算；`bestSteps = bfs.dist`；提示开启时构建 `hintMap`（path 哈希集）。
- **星级**（按最短步数比例，宽松档）：
  - 3 星：`steps ≤ ceil(best × 1.5)`；2 星：`steps ≤ ceil(best × 2.5)`；1 星：通关
  - 用提示 `hintUsed` 且算得 >2 星 → 强制封顶 2 星
  - 重复通关仅当星级更高才覆盖记录

### 4.4 计时

- `performance.now()` 思路对齐：`startStamp = Date.now()` 起点 + `setInterval(100ms)` 刷新 `fmtTime(ms)`（秒 + 1 位小数 `⏱ 07.5`）。
- **离开续算**：`saveCur()` 时 `state.ms = currentElapsed()`（存累计 ms + 新 startStamp 基线），恢复时 `currentElapsed() = state.ms + (Date.now() - startStamp)` 续算 → 中途退出间隔时间照常计入用时（诚实计时）。
- 通关即 `stopTimer()` 定格；`state.ms` 覆盖。

### 4.5 持久化（localStorage）

- key：`redtools.migongxunlu.v1`（容器内多工具共享存储，必须带工具前缀）。
- 结构：`{ version, best:{ "7":{ms,steps,date}, "11":{...}, "15":{...} }, recent:{}, checkin:{dates,streak}, history:[{date,size,ms,steps,stars}]（滚动30条）, cur:{...} }`。
- **最佳成绩**：各难度独立比较——步数少优先，同步数比用时短。
- **打卡**：通关一局 → `dates` 写入今日（去重、滚动 365 天）、重算连续天数（对齐 `docs/通用需求-打卡分享记录.md`）。
- **断局恢复**：每次有效移动后 `store.cur = { size, seed, player, visited, steps, ms, startStamp, hintUsed, hintActive }`；重新打开按 seed 重放迷宫 + 校验玩家在通路/visited 合法；通关/点返回难度后清空 cur。

### 4.6 渲染

- 棋盘容器 `padding-bottom: 100%`（方形迷宫）→ 格子正方形（每格 `100/n% × 100/n%` 绝对定位）。
- 每次渲染重建全部 cell（≤ 15×15=225 格，开销可忽略）。
- 渲染优先序：**墙 > 玩家 > 起点 > 出口 > 提示路径 > 足迹**（玩家在出口时 ongoingal 变绿庆祝）。
- 起点/出口/提示用 `::before/::after` 伪元素绘制；玩家双眼同推箱子。

### 4.7 音效（Web Audio 合成）

```js
tone(freq, dur, type, vol, delay)   // OscillatorNode + GainNode 包络（同推箱子）
sndWalk: sine 200Hz 50ms   sndBlock: square 90Hz 80ms
sndGoal: triangle 523Hz 90ms        // 提示用
sndWin:  523/659/784/1047 上行琶音
```

`AudioContext` 懒创建 + 用户手势 `resume()`；全部 try/catch 降级。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：ES2017 经典脚本（var + function），无 `?.`/`??`/对象展开/module/import；无内联事件/eval/innerHTML；
  keydown 用 `keyCode`；触屏用 `touches/changedTouches`；无 fetch/XHR/Worker/clipboard。
- CSS：无 `gap`/`aspect-ratio`/`clamp()`/逻辑属性/`:has`；flex 三重前缀；动画双写 `@-webkit-keyframes` + `@keyframes`；
  棋盘比例用 `padding-bottom:100%`（非 aspect-ratio）；安全区 env() 兜底。
- 资源：全部内联/本包；无外部 URL；无 CSP meta（容器管理）；音频零文件（Oscillator 合成）。
- 包体：构建产物 0.02 MiB（≪ 2 MiB 建议值）。
