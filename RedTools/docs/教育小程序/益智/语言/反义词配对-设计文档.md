## 2. 玩法设计

### 2.1 规则

- 每局随机抽 N 对反义词（内置 28 对词库）→ 洗牌 2N 张词卡布阵。
- **点第一张**（选中，绿框高亮）→ **点第二张**：两张互为反义词 → 配对成功（✓ 角标 + 绿框 + 淡化）；不是反义词 → 两卡红闪 + 错误计数 +1 + 取消选中。
- 全部 N 对配对完成即过关。
- **价值**：语义对立理解（大↔小、热↔冷、开心↔难过…）——语言子系列词汇训练切入点。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 点词卡 | 第一张选中；点同一张取消；点第二张判定配对 |
| 底栏按钮 | 「返回难度」/「重新开始」（同难度重抽一局） |
| 顶栏按钮 | 「← 返回」回难度页 |

### 2.3 反馈

- **选中**：绿框 + 轻微放大（`selected`）。
- **配对成功**：两卡绿色 ✓ 角标（`pop` 弹出）+ 绿框 + 淡化（`opacity:0.6`）+ 轻音效 + 计数「配对 n/N」更新。
- **配错**：两卡红闪（`wrongFlash 0.4s`）+ 低音效 + 错误计数 +1（可重试）。
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件）：选中轻音 / 配对成功清脆 / 配错低沉 / 胜利琶音。

## 4. 技术设计

### 4.1 数据模型

- **难度常量 `LEVELS`**：

| key | 难度 | 对数 N | 词卡数 |
|---|---|---|---|
| '1' | 简单 | 3 | 6 |
| '2' | 普通 | 4 | 8 |
| '3' | 困难 | 5 | 10 |

- **反义词库 `PAIRS`**：28 对（大-小、长-短、高-矮、快-慢、热-冷、多-少、新-旧、开-关、上-下、左-右、白天-夜晚、开心-难过、哭-笑、黑-白、早-晚、胖-瘦、远-近、好-坏、对-错、甜-苦、亮-暗、休息-运动、起立-坐下、进来-出去、干净-脏、安静-吵闹、前-后、满-空），每对配 emoji 辅助。
- **运行时状态**：`state = { level, cards:[{pid, side:'a'|'b', word, emoji, matched}], selected, matchedCount, totalMatches, errors, won, startMs, ms, timerId }`。

### 4.2 出题

- `newGame()`：`shuffle(PAIRS).slice(0, pairs)` 随机抽 N 对 → 每对生成 `{pid:i, side:'a'}` + `{pid:i, side:'b'}` 两卡 → `shuffle(cards)` 洗牌布阵。
- 同 `pid` 且 `side` 不同 = 反义词对（判定键）。

### 4.3 交互与判定

- `onCardTap(idx)`：已配对卡忽略；`selected===-1` → 选中；点同一张 → 取消；否则判定：
  - `a.pid === card.pid && a.side !== card.side` → 配对成功（双卡 `matched` + 计数 + 全配完后 500ms `onWin()`）；
  - 否则 → 两卡红闪 + `errors++` + 取消选中 + `updateErrorsUI()`。

### 4.4 计时

- `startTimer()`：`performance.now()` + `setInterval(100ms)` 差值刷新 `'⏱ ' + fmtTime(ms)`（秒 + 1 位小数）；进入游戏页即开始。
- v1.0 无断局恢复。

### 4.5 星级与最佳成绩

- **星级**（按配错次数）：★★★ 0 错；★★ ≤2 错；★ 其余（过关即有）。
- **最佳判定 `betterThan`**：星级高优先，同星级比用时短；最近/历史同系列模式。

### 4.6 持久化（localStorage）

- key：`redtools.fanyicidui.v1`。
- 结构：`{ version:1, best:{}, recent:{}, checkin:{dates,streak}, history:[...] }`。
- 读写 try/catch；`loadStore()` 校验 version + 补全字段；打卡 `doCheckin()` YYYYMMDD 去重 + 365 滚动 + `calcStreak()` 含今天往前推。

### 4.7 音效（Web Audio 合成）

```js
sndClick:   sine  392Hz 0.06s    // 选中（轻）
sndCorrect: triangle 523Hz 0.09s // 配对成功（清脆）
sndWrong:   square 150Hz 0.12s   // 配错（低沉）
sndWin:     523/659/784/1047 琶音
```

`AudioContext`（含 `webkitAudioContext`）懒创建 + 用户手势 `resume()`；try/catch 降级。

### 4.8 视图结构

- 三个视图 + 浮层：难度选择页 / 游戏页 / 打卡日历页；结算浮层（星级 + 统计 + 打卡 + 三按钮）。
- 词卡 2 列 `float:left` + `width:50%` + 内层 padding 撑高；`✓` 角标依赖 `.pc-card-inner { position:relative }`（v1.0 已修：初版缺 relative 导致 ✓ 角标定位异常，视觉质检发现后修复）；打卡日历 7 列网格同系列。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：ES2017 经典脚本（var + function），无 `?.`/`??`/对象展开/`replaceAll`/module/import；无内联事件/eval；事件 `addEventListener`；无 fetch/XHR/Worker；localStorage try/catch。
- CSS：无 `gap`/`aspect-ratio`/`clamp()`/`inset`/逻辑属性/`:has`/`@container`/`dvh`；flex 三重前缀；动画双写前缀（`wrongFlash`/`popCard` ≤400ms 无频闪）；`float` 网格 + `:after` 清浮动；安全区 `env(safe-area-inset-*)`。
- 触控/光敏：词卡/按钮 hit area ≥48px；动画温和无频闪。
- 资源：全部内联/本包；无外部 URL；词卡 = 文字 + **系统 emoji**（零素材、零字体打包，依赖设备 emoji 字体——Chrome 61 桌面/Android 均内置）→ **零图片零音频零数据文件**。
- 包体：0.02 MiB（≪ 2 MiB 建议值）。

## 8. 与系列规范的关系

- **系列归属**：`教育工具产品矩阵规划.md` §4.7 语言能力训练（P2 反义词配对）→ `series/益智/语言/` 子系列第 2 款；适用 K1-3–K4-6（L2–L3）。
- **可复用核心**：计时/成绩/打卡对齐 `series/益智/设计文档.md` §4；Chrome 61 / 交互合规对齐 §5。
- **与同系列差异**：看图说话排序 = 排序类（叙事逻辑）；反义词配对 = **配对类（语义对立）**——配对交互与翻牌配对的"点两张判定"一脉相承，但全部卡可见（无记忆翻面），更偏语义理解而非记忆；**语言子系列首款"纯文字+emoji"工具**（无 SVG 库依赖）。
- **扩展**：`PAIRS` 词库可扩充（成语反义词/近反义混合进阶）；词卡可加读音（TTS 受限则留空）；后续可加「先读词再配对」听音模式。
