# 绕口令节奏 — 设计文档

> 版本：v1.0 ｜ 系列：益智·语言 ｜ 类型：P2（节奏·语音启蒙） ｜ 更新：2026-09-19
> 关键词：零音频依赖、节奏同步、跟读训练、8 首经典绕口令

## 1. 产品概况

**定位**：语言子系列第 3 款（P2 语音节奏训练）。以**经典绕口令 + 节奏点击同步**训练口腔节奏感与朗读流畅度。

**与「故事复述」的分工**：
- **故事复述（⏸ 暂缓）**：核心输入依赖音频（听后复述，无 TTS 则无故事）——语音方案未定前不开发。
- **绕口令节奏**：绕口令**文字展示、孩子自己大声念**，工具只做节奏引导与「念完」同步判定。**不需要任何音频/TTS/麦克风**，离线 100% 可实现，故不受暂缓影响。

**目标用户**：preK–K1-3（L1–L2）学龄前与小低年级，识字基础薄弱者可看图跟读（短句为主）。

## 2. 玩法设计

### 2.1 规则
1. 选难度（简单/普通/困难）→ 选一首绕口令（共 8 首经典，无版权素材）。
2. 逐句节奏训练：当前句大字展示，顶部给速度档倒计时（慢速 8s / 常速 6s / 快速 4s），绿色节奏条实时消耗。
3. 孩子大声念完当前句 → 点「👄 我念完啦！」→ **命中** → 自动进下一句。
4. 倒计时耗尽仍未点 → **过时（miss）** → 自动进下一句。
5. 全部句子念完 → 结算：**命中率星级** + 打卡。

### 2.2 操作
| 操作 | 位置 | 说明 |
|---|---|---|
| 选难度 | 首页 3 卡片 | 简单👶2 首·2~4 句 / 普通😊3 首·3~5 句 / 困难💪3 首·4~9 句 |
| 选绕口令 | 档位列表 | 每首显示句数 + 历史最佳（星级/命中/用时） |
| 切速度 | 局内 3 按钮 | 🐢慢速 8s / 🐇常速 6s / ⚡快速 4s；**切档后当前句计时重置**为新秒数 |
| 念完 | 底部大按钮 | 点按判定命中，即时进下一句 |
| 返回 | 顶栏/底部 | 局内切速不重置整局，仅重置当前句倒计时 |

### 2.3 反馈
- **命中**：清脆双音（880→1318Hz）+ 句项变灰 + 命中计数 +1。
- **过时**：低沉双音（240→180Hz）+ 句项跳过 + 过时计数 +1，自动推进。
- **高亮**：句列表中当前句绿色加粗、已读灰色、未读深灰；当前句大字卡绿色描边。
- **结算**：🎉一气呵成（命中 100%）/ 👏念完啦；★★★ / ★★ / ★；命中 x/y 句 · 用时；今日已打卡 · 连续 n 天；🏅 新纪录徽章。
- **节奏条**：绿色填充按剩余时间比例收缩；剩余 ≤25% 转警示红。

## 3. UI 设计

- 配色：**语言系列绿系**（`#2fbe9e` 主色，与看图说话排序 / 反义词配对一致），背景 `#f0fbf8`，警示红 `#ff6b57`。
- 布局（390×844 基准）：顶栏（🗣️ 图标 + 标题 + 版本）→ 难度/曲目列表 → 赛局区：进度头 → 速度档 → 完整句列表 → **当前句大字卡**（min-height 168px）→ 节奏条 + 倒计时 → 命中/过时 → 底部固定「我念完啦！」大按钮。
- 大字卡字号 `7.2vw`（≥480px 宽时 34px），长句自动换行；**Chrome 61 无 clamp/Min()，故用 vw + 媒体查询兜底**。
- 结算浮层：半透明遮罩 + 白卡片（标题/星级/摘要/打卡行/徽章/3 按钮）。

## 4. 技术设计

### 4.1 数据模型
```js
var RAPS = [ { title, diff: '1'|'2'|'3', lines: [ '…', … ] }, … ]; // 8 首
var DIFFS = [ { key:'1', name:'简单' }, … ];
var SPEEDS = [ { key:'1', name:'慢速', sec:8 }, { key:'2', name:'常速', sec:6 }, { key:'3', name:'快速', sec:4 } ];
var state = { diff, rap, speed, curIdx, hits, misses, won, startMs, ms, lineTimerId, remainMs };
```

### 4.2 出题
无随机出题：**曲目固定**（经典绕口令，可控字数/句数），8 首分布：简单 2（4/2 句）、普通 3（5/4/3 句）、困难 3（4/4/9 句）。「数枣」为困难档一口气计数训练（9 句渐密节奏）。

### 4.3 交互与判定
- 节奏判定 = **窗口期按钮点击**（无麦克风/无语音识别）：`onHit()` 命中 → `advanceLine()`；`onLineTimeout()` 过时 → miss → `advanceLine()`；`curIdx >= lines.length` → `onWin()`。
- 计时：`setInterval(100ms)` 按差值刷新节奏条宽度 + 倒计时文字（**不依赖 setInterval 计数精度**，剩余毫秒 -= 100 为近似，100ms 粒度对节奏条无感）。
- 速度切换 `switchSpeed()`：停旧计时 → 重置 `remainMs(新秒数)` → 重绘速度高亮 → 重启计时；**不重置整局**（hits/misses 保留）。
- 防御：`state.won` 短路防止结算后残留 timer 触发。

### 4.4 计时
- 整局用时：`performance.now()` 起止差值（`startTotalTimer/stopTotalTimer`）。
- 单句倒计时：`state.remainMs` 独立管理，`stopLineTimer()` 于命中/超时/结算/切档/离开赛局时清理。

### 4.5 星级与最佳成绩
```js
rate = hits / (hits + misses);
stars = rate >= 1 ? 3 : rate >= 0.8 ? 2 : 1;   // 命中 100%→3★，≥80%→2★，其余 1★
```
- **best 键 = `diff-rapIndex`**（每首绕口令独立最佳）：`{hits, misses, ms, stars, date}`；更优判定 = 星级优先、用时次之。
- recent[键] = ms（最近一次用时）。
- history 推 30 条上限。

### 4.6 持久化（localStorage）
`redtools.raokoulingjiezou.v1`：
```json
{ "version": 1, "best": {}, "recent": {}, "checkin": { "dates": [], "streak": 0 }, "history": [] }
```
读写 try/catch 包裹，结构缺失自动补齐。

### 4.7 音效（Web Audio 合成）
命中 880→1318Hz / 过时 240→180Hz / 胜利 523-659-784Hz 琶音；OscillatorNode + GainNode 包络，`AudioContext` 惰性创建（首个用户手势后），无音频文件，符合 CSP 与 zip 白名单。

### 4.8 视图结构
难度视图 → 绕口令列表视图 → 赛局视图（`renderRoundView`：进度头 / speed-row / full-list / cur-box / rhythm-block / muted 提示；`renderCurrentLine` 同步当前句大字 + 句项高亮 + 进度文字）→ 结算浮层（`showOverlay` + `showStarsInOverlay` + `showRecordBadge`）→ 打卡日历视图。

## 8. 与系列规范的关系

- 存储 key 带工具前缀；打卡/连续天数/日历视图复用系列通用模式（`redtools.*.v1`）。
- 结算三要素（星级/最佳/打卡）与看图说话排序、反义词配对同构；语言子系列视觉绿系统一。
- **零素材 + 零音频**：延续「程序化 SVG / CSS 纯色块 / emoji」路线——本作连 SVG 都不需要（纯文字节奏交互），包体 0.02 MiB。
