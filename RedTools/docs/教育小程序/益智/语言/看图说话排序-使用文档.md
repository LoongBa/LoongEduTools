# 看图说话排序 — 使用文档

> 看图讲故事小练习：把打乱的「小故事」图片卡片按故事情节排好，先发生的放前面、后发生的放后面，全部排对就过关，锻炼看图讲故事与表达逻辑。
> 适用：手机 / 电脑（点选两张卡片交换位置）。
> 版本：v1.0 · 更新：2026-09-19
> ⚠️ Chrome 61 / Android 8.1 / 真机 WebView 未实测。

---

## 1. 这是什么

一个「把故事排对」的小练习。屏幕上会有几张打乱的图片卡片，它们其实是**一个小故事的几个情节**：比如「煮面条」有 4 张卡——水烧开冒泡、面条下锅、加蔬菜、端碗开吃。你要按照故事发生的先后，把卡片一张一张排好。排对了，就相当于把一个小故事「讲通顺」了，孩子边练边学怎么有顺序地讲故事。

## 2. 如何打开

- 本工具是一个**离线 zip 小工具**，不需要联网、不需要注册。
- 手机/平板/电脑都可以练：把 zip 解压后打开里面的 `index.html` 即可（或按平台约定安装后从图标进入）。
- 打开后先看到**难度选择页**，选一个难度就能开始。

## 3. 首页与难度选择

首页有三个难度卡片，选一个开始练：

| 难度 | 步数 | 这局可能抽到的故事 |
|------|:---:|-------------------|
| 👉 简单 · 排 3 步 | 3 张卡 | 小宇的早晨 / 去野餐 |
| 普通 · 排 4 步 | 4 张卡 | 放风筝 / 下雨啦 / 煮面条 / 种番茄 |
| 困难 · 排 5 步 | 5 张卡 | 逛动物园 / 露营之夜 |

- 每个难度卡片会显示**序列池**（这局可能抽到哪些故事）和你的**最佳成绩**（星级 · 用时 · 步数 · 提示）；还没练过就显示「暂无成绩 · 来挑战！」。
- 每局会从对应难度的故事里**随机抽一个并打乱**，每次进入可能不同，练多了也不会背答案。
- 底部有「📅 打卡日历 · 连续 N 天」按钮，可以查看打卡情况。

## 4. 练习方法

**怎么练（点两张交换）：**

1. 进入练习，顶上写着这局的主题，比如「把『煮面条』按顺序排好」。
2. **点一张卡片**，它会带**橙色描边**并轻轻抬起（选中）；**再点另一张**，两张卡片交换位置（卡片轻轻跳一下，步数 +1）。
3. 想取消？**再点一下同一张卡片**就取消选中，或直接点另一张切换。
4. 一张一张换，直到**全部卡片按故事情节排好**（第一张最先发生、最后一张最后发生），就过关啦！

**怎么算过关：** 全部卡片按故事情节顺序归位（槽位顺序 = 正确顺序），卡片会闪一圈绿色，弹出结算页。

**提示怎么用：** 卡住了点「💡 提示」，**第一张排错的卡片会高亮 1.2 秒**，告诉你"这张位置不对"。提示**不会帮你换**，只是提醒你重点看哪张；用提示会**封顶 2 星**，能自己排就先自己排。

## 5. 结果页

过关后弹出结算浮层「🎉 排好啦！」，显示：

- **星级** ★★★ / ★★ / ★（按提示次数与步数评定，见下节）；
- **用时 X 秒 · 步数 N 次 · 提示 N 次**；
- **✅ 今日已打卡 · 连续 N 天**（完成一局自动点亮今日）；
- **🎉 新纪录！**（如果打破了该难度的最佳成绩）；
- 三个按钮：**【再来一局】** 同难度重抽一局 / **【选难度】** 回首页 / **【📅 打卡日历】** 查看打卡。

## 6. 星级说明

星级看两个指标：**点过几次提示**、**用了多少步**（宽松友好，过关即有星）：

| 星级 | 条件 |
|------|------|
| ★★★ | 没点过提示，且步数 ≤ 2×N−1（3 步局 ≤5 步、4 步局 ≤7 步、5 步局 ≤9 步） |
| ★★ | 提示 ≤1 次，且步数 ≤ 3×N（3 步局 ≤9 步、4 步局 ≤12 步、5 步局 ≤15 步）（**点过提示最高 2 星**） |
| ★ | 其余情况（过关即有） |

- 想拿 3 星：**不点提示 + 步数少**。动手前先在心里想一遍"故事从哪一步开始"，有把握再换。
- 各难度分别记录**最佳成绩**（星级高的优先，同星级比用时短）；**最近用时**和最近 **30 局**成绩会自动保存。

## 7. 打卡日历

- 每过关一局就**点亮今日打卡**。
- 打开打卡日历可以看到**本月日历**：打过卡的日子橙色高亮，今天有绿框标记。
- 页面下方显示**连续打卡 N 天**，连续 7 天及以上会显示 🎉。
- 坚持每天练一局，帮孩子养成练表达的好习惯。

## 8. 常见问题

**Q：顺序排错了会怎样？会扣分、会失败吗？**
不会。排序没有"错动作"，怎么换都行，只要最后故事顺序对就过关。步数只是记录你换了几次，步数越少星级越高。

**Q：提示会影响成绩吗？**
会。提示会把第一张排错的卡片高亮 1.2 秒提醒你，但**用一次提示，这局最高只能拿 2 星**。卡住时再用，别一上来就点。

**Q：故事卡能换别的吗？**
故事库固定 8 个故事（简单 2 个、普通 4 个、困难 2 个），每局从对应难度的故事里随机抽一个并重新打乱。想换故事练，多点几次「重新开始」或换难度就行。

**Q：星级怎么评？**
看提示和步数两个指标：0 提示且步数够少 → 3★；提示 ≤1 次且步数在范围内 → 2★；其余过关即 1★。详见第 6 节。

**Q：成绩和打卡数据存在哪里？**
全部保存在**本机**（浏览器 localStorage，key：`redtools.tushuopaixu.v1`），离线可用、不联网上传。

**Q：需要网络吗？**
不需要。所有内容都在 zip 包里，完全离线运行。

**Q：换设备/清浏览器数据，成绩会丢吗？**
会。数据存在当前设备的浏览器里，换设备或清除浏览器数据后记录会清空（重新练就会重新记录）。

**Q：适合几岁的孩子？**
定位 K1-3（幼儿园中大班）到 K4-6（小学中高年级）。「简单 3 步」讲起床、野餐这类生活小事，低龄也能练；「困难 5 步」排逛动物园、露营之夜，适合进阶，家长一起练也不无聊。
