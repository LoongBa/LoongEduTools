# 绕口令节奏 — 使用文档

> 版本：v1.0 ｜ 系列：益智·语言 ｜ 更新：2026-09-19

## 1. 这是什么

**绕口令节奏**是一款训练**朗读节奏与口腔灵活性**的小练习：孩子大声念经典绕口令，跟着每句的节奏倒计时，念完一句点一下「我念完啦」，全部念完即过关。

- **无需联网、无需语音文件、无需麦克风**：绕口令由孩子自己念，工具只负责节奏引导与「念完」判定。
- 内置 **8 首经典绕口令**（四是四、吃葡萄、扁担与板凳、八百标兵、红鲤鱼绿鲤鱼、黑化肥灰化肥、山前四十四棵柿子树、数枣）。

## 2. 怎么练

1. 打开页面 → 选难度：**👶 简单**（2 首）/**😊 普通**（3 首）/**💪 困难**（3 首）。
2. 选一首绕口令 → 句子列表显示全部内容，**当前句大字高亮**。
3. 大声念出当前句 → 念完点屏幕下方绿色大按钮「👄 我念完啦！」→ 自动进入下一句。
4. 如果倒计时结束还没点，会自动跳过（算「过时」1 次）。
5. 所有句子念完 → 弹出结算界面，记录**命中率星级**并自动完成打卡。

## 3. 界面说明

| 位置 | 作用 |
|---|---|
| 顶部速度档 | 🐢 慢速（每句 8 秒）/ 🐇 常速（6 秒）/ ⚡ 快速（4 秒），可随时切换，切换后当前句重新计时 |
| 完整句列表 | 当前句**绿色加粗**、已念过**灰色**、未念**深灰** |
| 大字当前句 | 绿色描边卡片内居中展示，长句自动换行 |
| 绿色节奏条 | 随倒计时收缩，剩 25% 内变红提醒要加油 |
| 命中/过时 | 左侧「👄 命中 n」，右侧「过时 n」 |

## 4. 打分规则

- 结算星星只看**命中率**（念完点中的句数 ÷ 总句数）：
  - **★★★ 一气呵成**：全部命中（每句都念完并点中）
  - **★★**：命中率 ≥ 80%
  - **★**：完成本篇
- 另有「🎉 新纪录」徽章：刷新本篇最佳（星级优先、用时短者胜）。

## 5. 进度与打卡

- 每次通关自动记入「本月打卡」日历（首页底部「📅 打卡日历」查看），显示**连续打卡天数**。
- 每首绕口令保存历史最佳（星级/命中/用时），在选曲列表可见。

## 6. 常见问题

**Q：怎么没有范读音频？孩子不会念怎么办？**
A：本工具定位「节奏引导」——文字提供内容，节奏引导孩子大声开口。家长可先带读一遍再让孩子跟念；若需要标准范读，属「故事复述」语音方案讨论范畴，暂缓中。

**Q：工具怎么知道我念得好不好？**
A：它不评判发音，只做**节奏同步**（是否在时限内念完并点击）。发音质量由家长陪伴时把关——这是学前语言启蒙的常态做法。

**Q：孩子点太快怎么办？**
A：切到 ⚡ 快速（每句 4 秒）更有挑战；反之切 🐢 慢速。速度随时可换。
