# 七巧板 — 使用文档

> 益智系列 · 空间感知子系列第 2 款。设计文档：`七巧板-设计文档.md`
> 版本：v1.0 ｜ 更新：2026-09-19

## 这是什么

经典七巧板拼图：用 7 块拼板（2 大三角 + 1 中三角 + 2 小三角 + 1 正方形 + 1 平行四边形）拖拽旋转，拼出指定图案。训练空间感知（形状拼合、旋转方位、局部-整体认知）。

## 练习方式

1. **选图案**（首页按难度分三组，共 12 款）：
   - **简单**（4 款）：正方形 / 小房子 / 小鱼 / 小碗 —— 拼图区有**分块占位**（每块该放哪、什么角度一目了然）
   - **进阶**（4 款）：箭头 / 大鹅 / 小猫 / 小狗 —— 只显示**整体剪影**
   - **挑战**（4 款）：天鹅 / 火箭 / 海豚 / 大象 —— 无提示，靠顶部**缩略图**参考
2. **拼图**：
   - **拖拽**：手指按住拼板（彩色区域）拖动到目标位置
   - **旋转**：先点选拼板（蓝色高亮 + 阴影），再点「↻ 旋转」按钮（每次转 45°）
   - **磁吸**：拼板靠近目标位（距离 < 24px 且角度对齐）会自动吸附锁定；想调整直接再拖走即可
   - **提示**：💡 高亮下一块未拼块的目标位置（每局最多 2 次）
   - **重置**：所有拼板回到底部，计时归零
3. **完成**：7 块全部就位 → 结算（星级 + 用时 + 提示次数 + 本图案最佳 + 连续打卡）

## 难度提示说明

| 档位 | 目标提示 | 适合 |
|---|---|---|
| 简单 | 分块占位（每块轮廓 + 位置） | 3-5 岁（preK） |
| 进阶 | 整体剪影 | 6-8 岁（K1-3） |
| 挑战 | 缩略图参考 | 9-10 岁（K4-6） |

## 星级规则

- 3★：全程不用提示
- 2★：用了 1-2 次提示

## 常见问题

**Q：拼板拖不动？**
A：手指需按在拼板的彩色区域内再拖动；先点选（出现蓝色高亮）再拖更稳。

**Q：块吸附后想调整？**
A：直接再次拖动已吸附的块即可（吸附不是永久锁定，移出容差自动解锁）。

**Q：提示次数用完？**
A：提示封顶 2 次/局，可用「重置」重新开始（重置后提示次数也归零）。

**Q：完成但只有 2★？**
A：用了提示就是 2★；想拿 3★ 试试全程不用提示拼完。

## 记录与打卡

- 每局完成自动保存到本机（localStorage）：各图案最快用时 + 星级 + 完成标记
- 首页卡片带「✓」表示已通关，并显示该图案最佳成绩
- 底部导航「成绩」看最近 30 次记录、「打卡」看本月日历 + 连续天数
- 结算页可「再来一局 / 下一个图案 / 返回首页」
