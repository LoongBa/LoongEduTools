# 影子配对 — 使用文档

> 形状观察训练：把上面的彩色图案，和下面与它**形状一样**的黑色影子配成一对，全部配齐就过关。
> 适用：手机 / 电脑（点选即可）。
> 版本：v1.0 · 更新：2026-09-19

---

## 1. 怎么练

1. 打开工具，在**难度选择页**选一个难度：简单 3 对 / 普通 4 对 / 困难 5 对。
2. 上方是几张**图案卡**（彩色的物品图案，顺序是乱的），下方是同样数量的**影子卡**（每个物品的黑色轮廓，顺序也是乱的、和上面不一样）。
3. **先点一张图案卡**（会有橙色描边选中），**再点下面和它形状一样的影子**：
   - 配对成功：两张卡变绿打勾，配对计数 +1；
   - 配对错误：影子红闪一下，错误次数 +1，再选别的影子试试。
4. 全部图案都配到自己的影子，就过关啦！每局都是程序随机抽的新图案组合，不会重复出题。

## 2. 练习规则

| 规则 | 说明 |
|---|---|
| 目标 | 把每张图案卡配到它对应的影子卡 |
| 操作 | 点图案（选中）→ 点影子（配对）；无拖拽，点选即配 |
| 配对成功 | 实物 + 影子都打上绿色 ✓，配对计数 +1 |
| 配对错误 | 影子红闪，错误次数 +1，图案取消选中可重新配 |
| 出题 | 从 73 个图案库随机抽（简单 3 / 普通 4 / 困难 5 对），上下两行独立打乱 |
| 星级 | 0 错 3★ / 1~2 错 2★ / 3 错及以上 1★（通关即有） |
| 技巧 | **忽略颜色，只看形状**——影子是黑色剪影，比的是轮廓不是颜色 |

## 3. 界面说明

- **难度选择页**：三个难度卡片，显示该难度**最佳成绩**（星级 · 用时 · 错误次数），底部是打卡日历入口。
- **顶栏**：`← 返回`、当前难度名、`⏱ 用时`（**进入练习页即开始**计时，整局计时）。
- **配对计数**：练习页上方「配对 x/M」实时显示已配对数。
- **图案行**：白色卡片 + 彩色图案；选中 = 橙色描边。
- **影子行**：浅灰卡片 + **黑色剪影**（和图案同一形状，只是变成影子）；配对后变绿 + ✓。
- **错误计数**：练习页底栏 `❌ N` 实时显示本局配对错误的次数。

## 4. 成绩与打卡

- **星级**（按本局配对错误次数，宽松友好）：一次没错 ★★★；错 1~2 次 ★★；3 次及以上 ★。
- 每过关一局即点亮**今日打卡**；打卡日历显示本月打卡与连续天数（连续 7 天及以上有 🎉）。
- 各难度分别记录**最佳成绩**（星级高优先，星级相同比用时短）；**最近用时**与最近 **30 局**成绩记录自动保存。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- 配对口诀：**别看颜色，看形状**。比如上面的红苹果和绿苹果形状一样——它们的影子都是苹果形状，要配到"苹果影子"而不是"别的形状的影子"。
- 点错图案了？再点一下同一张取消选中，或直接点另一张切换。
- 先点影子会怎样？会提示「先点上面的一个图案，再点它的影子」，不扣分不开始计时。
- 想换一组图案？练习中点「重新开始」用相同难度重抽一局，或点「返回难度」换档。
- 每局图案由程序随机抽（73 种图案库），影子由图形自动生成（同一形状压黑），保证图案和影子严丝合缝。

## 6. 常见问题

**Q：配对错了会不会扣分或结束练习？**
不会。配对错误只计错误次数（影响星级），图案取消选中可以继续配，直到配对为止，全程无惩罚。

**Q：影子是哪里来的？**
影子就是同一个图案的"黑色版"——程序把图案整体压成黑色剪影（`brightness(0)` 滤镜），所以形状 100% 一致，不会出现"影子对不上"的情况。

**Q：为什么图案和影子的顺序不一样？**
上下两行是**分别打乱**的，位置对不上，需要孩子靠"形状记忆"配对——正是训练目的。

**Q：适合几岁的孩子？**
定位低龄（preK 到小学低年级）。简单 3 对起步，图案之间形状差异大、好分辨；困难 5 对需要更仔细对比轮廓。

**Q：成绩怎么清除？**
目前没有「清空成绩」按钮。成绩保存在设备浏览器的 localStorage 中，清除浏览器数据即可清空；换设备不会同步，请注意。
