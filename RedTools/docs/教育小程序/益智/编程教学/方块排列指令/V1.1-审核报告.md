## 4. 变更摘要

| 变更 | 说明 |
|---|---|
| **数据模型** | state 增 `blockCmds[K]`（每块独立指令序列）+ `curEditIdx`（编辑态当前块）+ `stepTimer`（N-6 超时句柄）；移除 `cmds`/`cmdCounts`（星级改 Σ blockCmds[i].length） |
| **块 tab UI** | 新增 `.block-tabs` 行（第 N 块 + 类型色块 + ✓ 已编标记 + active 高亮）；点击切换 curEditIdx → 序列/预览联动；执行中 disabled（setCmdLocked 含 .block-tab） |
| **编辑器** | 指令区/添加/清空/cycleParam 全绑 blockCmds[curEditIdx]（各块独立）；预览编辑态 curEditIdx（I-3）；进度「已编 X/K」 |
| **执行器** | execRun：守卫（全空 Total=0 非静默提示）+ 执行态重置（curIdx=0/placed=[] + stepTimer 清理）→ execCmdStep 按块消费 blockCmds[curIdx] → endBlock 提取（6 处变更：删 cmdCounts.push/execLock 释放/UI 解锁/cmds 清空；新增 state.cur 重建/300ms 续跑）→ 全部落完统一 checkWin；逐块差格即时提示不中断 |
| **N-6 幻影执行防护** | stepTimer 句柄贯穿 execCmdStep/endBlock 5 存点 + startGame/reset/nextLevel/execRun 4 入口 clearTimeout |
| **N-1 修复** | clearBtn 清空后补 renderBlockTabs（✓/进度同步） |
| **零改动** | 生成器（dropRowFor 顺序落定）/落定物理/关卡数据/存储结构/星级 threshold |
