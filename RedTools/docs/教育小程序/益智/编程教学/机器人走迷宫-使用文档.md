# 机器人走迷宫 — 使用文档

> 编程教学子系列首款：像搭积木一样给机器人编指令，让机器人把箱子推到目标点。
> 适用：手机 / 电脑（点击指令按钮即可，无需键盘）。
> 版本：v1.12 · 更新：2026-09-25

---

## 1. 怎么玩

1. 打开工具，选一个难度：**简单（1-30 关）/ 普通（31-80 关）/ 挑战（81-205 关）**。
2. 画面里是迷宫盘面：灰色是**墙**、橙色圆圈是**目标点**、棕色方块是**箱子**、蓝色圆球是**机器人**。
3. 目标：**编一段指令让机器人把全部箱子推到橙色圈上**（推箱规则：正前方有箱子时会推着它走）。
4. 点下方指令按钮（`↑前进` / `↰左转` / `↱右转` / `🧱探测` / `➡N步` / `❓if墙` / `🔁循环` / `🧩块`）逐条加入指令序列，
   再点 **▶ 执行**，机器人就会按你的指令动起来！（块可以带参数：点序列里的 `🧩块名(3)` 调距离）

## 2. 指令说明（编程七件套）

| 指令 | 作用 | 小提示 |
|---|---|---|
| ↑ 前进 | 机器人朝当前方向走一格 | 前方是墙、是箱子推不动、或走出边界时，原地不动 |
| ↰ 左转 | 原地向左转 90°，不移动 | 机器人默认朝右 |
| ↱ 右转 | 原地向右转 90°，不移动 | 转完方向再前进 |
| 🧱 前方探测 | **先看前方再走**：前方有墙/箱子/边界 → 不动；前方空地 → 走一格 | 怕撞墙？用它最稳 |
| **➡ 走N步** | **一次直线走 N 格**（参数化移动）：前方畅通 → 一次走 N 格；有墙/推不动 → 自动停 | v1.6 新增！一条指令走多格 |
| **❓ if前方有墙** | **判断前方再分支**：前方有墙/箱子/边界 → 执行「then（有墙）」；前方空地 → 执行「else（无墙）」 | v1.5 新增！让机器人自己做选择 |
| **🔁 循环** | **一组指令重复 N 次**（显式循环块）：点击展开编辑区，块内可放前进/转弯/探测/走N步/if，**还能再放一个 🔁 循环（嵌套循环）** | v1.7 新增！v1.8 支持嵌套循环 |

> 🧱 前方探测是 v1.3 新增的「条件指令」——它让机器人学会**先观察、再行动**。
>
> **❓ if前方有墙 是 v1.5 新增的「分支指令」**——前方有墙就走「then」路线，前方畅通就走「else」路线。
>
> **➡ 走N步 是 v1.6 新增的「参数指令」**——点序列里的 ➡ 小方块，参数在 `走1步 → … → 走9步` 间切换。
> 注意它和「前进 ×3」不一样：×3 是一步一步试（撞墙会报错），走3步是一口气走到墙前自动停。
>
> **🔁 循环 是 v1.7 新增的「循环块指令」**——它让**一组动作**重复做：点序列里的 🔁 小方块，
> 展开「循环编辑区」，往里面放指令（前进/转弯/探测/走N步/if），设置重复次数。
> 比如 `🔁×3 {↑前进}` = 前进 3 次（一组动作做 3 遍）——这就是编程里的**自动化**！
> 更厉害的是：循环块里可以放 **if 分支** 或 **走N步**，让机器人**一边循环一边判断、一边循环一边走一大段**。

## 3. 循环次数（v1.1 起）

- 指令加到序列后，**点一下序列里的指令小方块**，循环次数会在 `1 → ×2 → ×3 → ×4 → 1` 之间切换。
- 显示 `×3` 表示这条指令机器人会连续执行 3 次——`↑前进 ×3` = 连走 3 格。
- 这样就不用一根根加指令啦，还更省步数（星级更高）。

## 3.1 使用 if/else 分支（v1.5 新增）

1. 点指令区 **`❓ if前方有墙`** 按钮，指令序列会多出一个紫色 **`❓if`** 小方块。
2. **点一下这个 ❓if 小方块**，下方会展开「分支编辑区」，里面有**两栏**：
   - **✅ then（有墙）**：前方有墙/箱子/边界时，机器人执行这里的指令；
   - **❌ else（无墙）**：前方畅通时，机器人执行这里的指令。
3. 每栏下面有 `+ ↑` `+ ↰` `+ ↱` 小按钮，点它们给这条分支添加指令；分支里的指令小方块也可以
   点一下调循环次数、点 ✕ 删除。
4. 编辑完点 **关闭**，❓if 就准备好了。执行时机器人会**自己判断前方**，走对应的分支！

> 💡 **挑战关卡（156-175）是「岔路口」设计**：机器人在岔路口前方可能是墙、可能是空地，
> 用 ❓if 可以让它自己选路——一条 if 顶好几条转弯指令，写得更短、星级更高！
> 这也是编程里的经典思想：**让程序自己根据情况做决定**。

## 3.2 使用走N步参数（v1.6 新增）

1. 点指令区 **`➡N步`** 按钮，指令序列会多出一个 **`➡走1步`** 小方块。
2. **点一下这个 ➡ 小方块**，参数会在 `走1步 → 走2步 → … → 走9步 → 走1步` 之间切换
   （9 步封顶）。
3. 执行时机器人会**一次直线走这么多格**：前方畅通就一口气走完；遇到墙/推不动箱子就
   **自动停在墙前**（不会报错——像人走路走到墙边停住）。
4. 如果**第一步就撞墙**（参数设大了、前面就是墙），会像「前进」一样标记 ❗ 错误，
   提示你调整。

> 💡 **挑战关卡（176-185）是「参数化」设计**：长直道用 `➡走3步` 一条指令就顶三条 `↑`，
> 写得更短、星级更高——这就是编程里的**参数**思想！
> 和 `↑×3`（循环）的区别：×3 是一步一步试、撞墙会报错；走3步是一口气走到墙前自动停。
> 孩子会发现：**循环是重复做，参数是一次做够**。

## 3.3 使用循环块（v1.7 新增）

1. 点指令区 **`🔁循环`** 按钮，指令序列会多出一个绿色 **`🔁×2`** 小方块（默认重复 2 次）。
2. **点一下这个 🔁 小方块**，下方展开「循环编辑区」：
   - **次数**：`− 次数` / `+ 次数` 按钮调重复次数（2→3→…→9）；
   - **块内指令**：点 `+ ↑` / `+ ↰` / `+ ↱` / `+ 🧱` / `+ ➡N步` / `+ ❓if墙` 往循环块里放指令
     （放好的指令小方块可点一下调循环/参数、点 ✕ 删除）；
   - 如果放了 **❓if**，点它还能再展开嵌套分支编辑。
3. 编辑完点 **关闭**，执行时机器人会把**块内指令重复做 N 遍**！

> 💡 **挑战关卡（186-195）是「循环块」设计**：让一组动作（比如走 3 步再转）重复做 N 遍，
> 写一次就顶写好多次——这就是编程里的**自动化**思想！
> 和 `↑×3` 的区别：×3 是**一个动作**重复 3 次；🔁×3 是**一组动作**重复 3 次（更强大）。
> 循环块里还能放 if 和走N步，让机器人**一边循环一边判断、一边循环一边走一大段**——这是进阶编程！

## 3.4 使用嵌套循环（v1.8 新增）

1. 打开一个循环块的编辑区（点序列里的 🔁 小方块）。
2. 点 `+ 🔁循环` 按钮，循环块里就多了一个**内层循环**（`🔁×2` 绿色小方块）——这就是**嵌套循环**！
3. 点内层循环小方块，会展开内层循环的编辑区（有「返回上层」按钮可回去）。
4. 内层循环里可以放指令（前进/转弯/探测/走N步/if），还能再套一层循环（最多 2 层）。

> 💡 **挑战关卡（196-205）是「嵌套循环」设计**：让一组动作重复 N 次，整套再重复 M 次——
> 比如 `🔁×2 {🔁×3 {前进}}` 让机器人推进 6 格，但只写了 3 个指令块！这就是**二维自动化**。
> 想想乘法表：外层循环是"行"，内层循环是"列"——嵌套循环让机器人像扫网格一样工作。
> 注意：**循环块里还能套循环，但 if 分支里不能放循环**（先掌握嵌套循环，再学更复杂的组合）。

## 3.5 自建关卡（v1.9 新增）

设计自己的迷宫，让机器人（或小伙伴）来解！

1. **进编辑器**：首页点 `🛠 自建关卡` → 关卡库 → `+ 新建关卡`。
2. **画盘面**：选工具（🧱墙 / 📦箱 / 🎯目标 / 🤖玩家 / 🧹橡皮），点格子或按住拖动连续画。
   - 玩家只能放 1 个（再放会自动替换旧位置）
   - 箱子和目标可以放多个；箱子上涂目标 = 箱子一开始就在目标上
3. **检查可解**：点 `✓ 检查可解`——机器人会自己推箱子试试，确认箱子都能推到目标。
   - ✅ 可解 → 可以保存啦
   - 😅 无解 → 调整盘面（箱子推不到所有目标，比如箱子卡在墙角）
4. **保存**：通过校验才能保存（最多 20 关）。给关卡起个名字（≤12 字）。
5. **挑战**：在关卡库点 `▶ 挑战` 玩自己设计的关卡——用指令把箱子推到目标，通关得 2★，关卡上会亮起「✅已解」。
6. **管理**：`✏ 编辑` 修改关卡，`🗑` 删除。

> 💡 **为什么要有「可解」检查？** 设计关卡时最难的其实是"怎么保证箱子推得到目标"——
> 检查可解就是让机器人先替你试试，避免做出解不出来的迷宫（那样玩的人会很困惑）。
> 试试：把箱子放墙角（两堵墙夹住）再检查，看会发生什么？

## 3.6 自定义指令块（v1.10 新增）

把一段常用指令**打包成一个有名字的块**，之后一条 `🧩块名` 就能代替整段指令——这就是编程里的
**抽象**（像抽屉里的一件工具：一次做好，随时取用）！

1. **建块**：首页点 `🧩 我的块` → 块库 → `+ 新建块`。
2. **起名**：给块起个名字（≤6 字，如「前进2」），名字不能重复。
3. **放指令**：往块里放指令（前进/左转/右转/前方探测/走N步，最多 8 条）。点指令小方块可调
   循环次数/参数，点 ✕ 删除。
4. **保存**：点 `💾 保存`，块就进库啦（最多存 8 个块）。
5. **用块**：练习时点指令区 **`🧩块`** 按钮 → 弹出块选择面板（能看到每个块的指令预览）→
   点一个块，序列里就多了一条 **`🧩块名`**（紫色）。执行时机器人会**先把块里的指令做完**，
   再继续后面的指令。
6. **改块**：点序列里的 `🧩块名` 小方块，直接进块编辑器改；改完保存，所有用到它的地方
   自动生效。
7. **删块**：块库里点 🗑 删除。删除后，指令序列里还留着它的旧引用会变灰，执行时会提示
   「块已删除」（把那条指令 ✕ 删掉就好了）。

> 💡 **为什么用块星级更高？**
> 同一段动作要做 3 遍：直接写 3 遍 = 写 9 条指令；打包成块再引用 3 次 = 主序列只写 3 条。
> 编写量更少 → 星级更高——这就是**抽象**的价值：把重复的东西藏进一个有名字的块里！
> 试试：在任意关卡找一段反复出现的动作，打包成块后再通关，看看编写量少了多少。

## 3.7 带参数的块（v1.11/v1.12/v1.13 新增）

让**同一个块**在不同地方**走不同距离**——这就是编程里的**函数参数**（一个块，N 种用法）！

**一个参数贯穿**（v1.11/v1.12）：
1. **开参数**：在块编辑器里点 `🔢 带参数：走 N 步`（紫色按钮）。**块里所有 `➡N步` 都会变成
   **`➡?₁步`**（紫色）——`?₁` 表示"走多少由调用时决定"（v1.12：一个参数贯穿块内所有步数）。
2. **建块**：放几条 `➡N步`（比如"走N步 → 左转 → 走N步"），开参数，配上别的指令，保存——
   你就有了一个「走 N 步再左转再走 N 步」的参数块（拐角/方形路径一个块搞定！）。
3. **用块**：练习时点 `🧩块` 选这个块，序列里出现 **`🧩块名(3)`**——默认走 3 步。
4. **调参数**：**点一下序列里的 `🧩块名(3)` 小方块**，参数会在 `3 → 4 → … → 9 → 1 → … → 2 → 3`
   之间循环。比如点成 `(5)`，块里**所有** `➡?₁步` 都走 5 步。

**多参数 + 混合态**（v1.13 新增——每步独立参数，Scratch 多输入积木）：
5. **第二个参数**：参数模式里**单击**某条 `➡?₁步` → 变成 **`➡?₂步`**（下标 ₂ = 第二个参数）。
   块里同时有 `?₁` 和 `?₂`，就是这个块有**两个独立参数**（如"先走 N 步再走 M 步"）。
6. **固定某步**：**长按**（按住 350ms）或 **shift+单击** 某条 `➡?步` → 变回固定的 `➡走1步`（再点调步数）。
   参数步骤和固定步骤**可以混在一个块里**——参数只管被标记的那几步，其余固定不变（混合态）。
7. **多参数调参**：序列里的 `🧩块名(3,5)`——**两个数字分开点**！点左边 `3` 调第一个参数，
   点右边 `5` 调第二个参数，互不影响。单参数块还是 `(3)` 一个数，点一下即调。

**块里放循环**（v1.14 新增——循环藏在块里，调用时还能调参数）：
8. **加循环**：块编辑器点 `🔁循环` → 块里出现 `🔁×2`（绿色循环块）。**点它进入循环编辑**：
   `− 次数 / + 次数` 调重复几次，`➕` 按钮往循环里放指令（可以放 `➡?₁步` 参数步！）。
9. **参数 × 循环**：循环里的 `➡?₁步` 是参数步——块「走 ?₁ 步 ×3 次」调用传 `2` 就走 2×3=6 格。
   **循环次数 + 步数**两个都能变（如 `🧩绕圈(2)` = 每次走 2 步 ×3 次）。
10. **循环里不能套循环/分支**（低龄线性）：循环编辑里只放基础指令（前进/转向/推箱/走步 + 参数步）。
11. **预览一看便知**：块选择面板里——**➡2步 灰底**（固定步）、**➡?₁步 浅紫**（可调步）、
    **🔁×2{...} 灰框**（循环段，看得到里面哪步可调）——三种一眼分辨！

> 💡 **为什么用参数块星级更高？**
> 同一个"走N步→转→走N步"动作要做 3 次（每次距离不同，如 2/3/4 步）：直接写 3 段 = 9 条指令；
> 用一个参数块引用 3 次（各带不同参数）= 3 条调用 + 块体 1 次 ≈ 5 条。写得少 → 星级高——
> 这就是**参数**的价值：**一次定义，多种用法**！
> 小提示：参数块里最好**配上别的指令**（如左转/右转），单放一条 `➡N步` 的参数块不划算哦。

## 4. 界面说明

- **难度页**：三张难度卡，显示该难度历史最佳成绩（星级 · 关卡数）。
- **顶栏**：`‹ 返回`、当前难度与第几关、`⏱ 计时`。
- **迷宫盘面**：机器人按指令一格一格走，每步都看得见（260ms 一步）。
- **指令序列区**：已排好的指令；`✕` 删除单条，`↺ 清空` 全清。
- **执行中**：当前执行的指令会**蓝框高亮**（告诉你机器人正在跑哪一条）。
- **执行后反馈**：
  - 通关：`✓ 完成！箱子都到目标点了！`
  - 失败：`✗ 第 M 条指令 ⬆ 卡住了：前面是墙/推不动箱子（还差 N 个箱子）`——**红框 ❗ 标记出错指令**，
    你一眼就知道哪条指令出了问题，改掉它再执行！
  - 未出错但箱子未到位：`✗ 还差 N 个箱子到目标点，调整指令再试`。
- 通关后出现 **下一关 ›** 按钮，可继续挑战。

## 5. 成绩与打卡

- **星级**（实际走的步数 vs 每关最优解，越少步数越高星）：
  - ★★★：步数 ≤ 最优的 1.5 倍
  - ★★：步数 ≤ 最优的 2.5 倍
  - ★：过关即可（个别大关无最优解参考，通关 2 星）
- 每通关一关即点亮**今日打卡**，页面底部显示连续打卡天数；各难度分别记录最佳成绩。
- 全部数据存本地（localStorage），离线可用、不联网上传，无广告无内购。

## 6. 小贴士

- **先观察再编程**：看看箱子离目标点远不远、中间有没有墙，规划好路线再动手。
- **善用循环**：一条直线连走好几格 → `↑前进 ×3` 或 `➡走3步`；回头路 → 左转/右转 ×2 调头。
- **循环块自动化**：一组动作要重复做 → 用 `🔁 循环` 包起来，写一次顶写好多遍。
- **前方探测妙用**：走廊走到头会自动停，不会一头撞墙；把它排在一串前进后面当「保险」。
- **试错是学习**：机器人走歪了很正常，改指令再点执行，观察它每一步的变化就行。

## 7. 常见问题

**Q：机器人撞墙了怎么不动？**
前进遇到墙就是推不动，机器人会原地停住（这是设计好的「安全行为」）。换条路或加一个右转再走。
执行后如果卡住了，反馈文案会告诉你「第 M 条指令卡住了：前面是墙」，红框 ❗ 标记的就是那条指令。

**Q：箱子推错方向了怎么办？**
点 `↺ 清空` 重编，或点 `⟲ 重置` 把盘面恢复原样再试。箱子被推到一个角上推不出来只能重开。

**Q：怎么让机器人在一堵墙前面自动停？**
在前进指令后面加一条 `🧱 前方探测`——它会先看前方，有墙就不走、没墙才走一步。

**Q：if前方有墙和前方探测有什么区别？**
`🧱 前方探测` 是「一步」的判断：有墙就不走，没墙才走一格。`❓ if前方有墙` 是「一组」的判断：
前方有墙就执行 then 里的整组指令，前方畅通就执行 else 里的整组指令——就像岔路口选路，
可以一次处理好几步，是真正的 if/else 分支结构。

**Q：走N步和前进×N有什么区别？**
`↑×N` 是**循环**：把"前进"这条指令重复 N 次，每次都是一步一步试，中间撞墙会报错 ❗。
`➡走N步` 是**参数**：机器人一次直线走 N 格，前方畅通就走完，遇到墙**自动停在墙前不报错**
（除非第一步就撞墙）。循环是"重复做"，参数是"一次做够"——这是编程里两个不同的概念。

**Q：🔁循环块和前进×N有什么区别？**
`↑×3` 是**一个动作**重复 3 次；`🔁×3 {↑ 前进}` 是**一组动作**重复 3 次——循环块可以包住
好几个指令一起重复，还能在里面放 if 和走N步，是更强的「自动化」工具。

**Q：循环块里能放什么？**
前进 / 左转 / 右转 / 前方探测 / 走N步 / if分支都可以放，**还能再放一个循环块（嵌套循环，最多 2 层）**。
循环块里的 if 还能再展开嵌套编辑。（if 分支里不能放循环块——这是 v1.8 的范围限制。）

**Q：循环块怎么改重复次数？**
点开循环编辑区，用 `− 次数` / `+ 次数` 按钮调整（2→3→…→9）。

**Q：分支编辑区怎么打开？怎么知道机器人走了哪条分支？**
点指令序列里的紫色 `❓if` 小方块，下方就会展开 then/else 两栏编辑区。执行时机器人的每一步
都会在序列里**蓝框高亮**——如果高亮跳到 ❓if 下面的分支指令，就说明它选了这条分支。

**Q：为什么我的指令比最优解多很多？**
每关有个「最优步数」参考（星级基准），但**只要把箱子推到目标就过关**，多走几步只是星少一颗。
先通关，再回来挑战 3 星。

**Q：执行后机器人卡住了，怎么知道是哪条指令的问题？**
v1.4 新增**失败定位**：卡住后，那条出错的指令会变红并标 ❗，反馈文案会说「第 M 条指令卡住了」，
从序列里数第 M 条就是问题指令。如果箱子没到位但没报错，会提示「还差 N 个箱子」。

**Q：学到什么编程概念？**
顺序（一步步编）→ 循环（×N 重复）→ 条件（🧱 前方探测：先判断再行动）→ 分支（❓ if前方有墙：
if/else 选路）→ 参数（➡ 走N步：一个指令带数量）→ 循环块（🔁 循环：一组动作自动化）→
嵌套循环（🔁 内嵌 🔁：二维自动化/嵌套结构）→ 调试（看高亮/找错误/改指令）→
抽象（🧩 我的块：把重复动作打包成命名块复用，v1.10）→
块参数（🔢 带参数：同一个块不同参数走不同距离——函数参数化，v1.11）→
**参数贯穿（🔢 一个参数贯穿块内所有步数 + ? 占位/数字对照——参数是"名字"、调用是"值"，v1.12）**，
这就是编程的核心能力。
