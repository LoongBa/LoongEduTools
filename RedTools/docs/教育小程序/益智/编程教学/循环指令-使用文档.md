# 循环指令 — 使用文档

> 编程教学子系列第 4 款：让机器人沿着走廊走到目标，用「循环」少写指令！
> 适用：手机 / 电脑（点击指令按钮即可，无需键盘）。
> 版本：v1.2 · 更新：2026-09-26

---

## 1. 怎么玩

1. 打开工具，选一个难度：**简单 / 普通 / 挑战**。
2. 盘面上有**走廊**（灰墙围成的路），蓝色圆球是**机器人**，⭐ 是**目标**。
3. 用指令让机器人从起点走到 ⭐：`⬆ 前进` / `↰ 左转` / `↱ 右转` / `🔁 循环`。
4. **走廊只有一条路**——机器人只能沿着走廊走，走到 ⭐ 就过关！

## 2. 循环块是什么（核心）

| 概念 | 说明 |
|---|---|
| 🔁 重复 N 次 { 组指令 } | 让**一组**动作重复做 N 遍（比如「前进、前进、右转」重复 3 次） |
| 和走迷宫 ×N 的区别 | 走迷宫的 ×N 是让**一个**动作做多遍；循环块是让**一「组」**动作做多遍 |

> 💡 核心思想：**循环 = 自动化**——不用把重复的动作写很多遍，写一个循环块搞定！
> 看走廊的路线有没有「每一段都一样」的规律：找到规律 → 用一个循环块 → 指令最少 → 3★。

## 3. 指令说明

| 指令 | 作用 | 小提示 |
|---|---|---|
| ⬆ 前进 | 机器人朝当前方向走 1 格 | 撞墙会停下并提示 |
| ↰ 左转 / ↱ 右转 | 原地转 90°，不移动 | 走廊转弯处要用 |
| 🔁 循环 | 插入一个「重复 N 次 { }」块 | 点开块，往里面加指令 |

**循环块怎么用**：
1. 点 `🔁 循环` → 序列里出现一个紫色块 `🔁×2 {}`；
2. 点紫色块 → 打开块内编辑区（显示「第 1 条循环块 · 重复 2 次」）；
3. 点 `重复次数` 按钮调到 3（或 4/5…9）次；
4. 点块内的 `⬆ 前进` / `↰ 左转` / `↱ 右转` 加指令（这就是循环体，会重复执行）；
5. 点 `✓ 完成` 收合。

**嵌套循环（v1.1 新功能）**：走廊太复杂、一层循环不够时，**循环块里还能再放一个循环块**！
- 打开外层循环块编辑区 → 点 `🔁 循环` 加一个内层循环块 → 内层显示为绿色小块 `🔁×2`；
- 点绿色小块 → 进入内层编辑区（显示「内层循环」），往里面加指令；
- 点 `✓ 返回外层` 回外层，点 `✓ 完成` 收合。
- 原理：**外层每轮完整执行一遍内层**——比如 `🔁×3 { 🔁×5 {前进} 右转 }` = 「前进 5 步、右转」这一组做 3 遍（走 3 层螺旋）！
- 最多嵌套 2 层（内层里不能再套循环）。

## 4. 界面说明

- **难度页**：三张难度卡，显示该难度历史最佳星级。
- **顶栏**：`‹ 返回`、当前难度与目标（`让机器人到 ⭐`）、`⏱ 计时`。
- **盘面**：灰墙 = 走廊墙；浅色格 = 走廊路；蓝点 = 机器人；⭐ = 目标。
- **概念卡**：循环块 vs 走迷宫 ×N 的对比提示。
- **指令序列区**：浅蓝 = 基础指令；紫色 = 循环块；`✕` 删除，`↺ 清空` 全清。
- **执行反馈**：
  - 成功：`✓ 完成！机器人到目标啦（N★，指令 M 条 / 最优 K）`
  - 未达：`✗ 机器人走到了 (x,y)，目标 (gx,gy)（还差 M 格）`
  - 撞墙：`⛔ 第 K 次循环第 M 条指令（前进）撞墙啦`

## 5. 成绩与打卡

- **星级（指令条数 = 编写量）**：
  - 循环块 = 1 条 + 块内每条指令计 1（**不乘重复次数**）
  - ★★★：编写量 ≤ 最优的 1.5 倍（找到规律用循环块 → 3★）
  - ★★：编写量 ≤ 最优的 2.5 倍（把动作展开写很多遍 → 只能 2★）
  - ★：走到 ⭐ 即可
- 每过一题点亮**今日打卡**；各难度分记最佳。全部数据存本地，离线可用，无广告无内购。

## 6. 自建关卡（v1.2 新功能）

想自己出题？点首页的 **🛠 自建关卡** 卡片：

1. **新建关卡**：关卡库 → `+ 新建关卡` → 进入 10×10 走廊编辑器，左上角是起点 **S**（机器人固定从 S 出发）。
2. **画走廊**：从 S 开始，**一格一格点相邻的格子**画路径——机器人的路就是这条线！画到哪，⭐ 终点就在哪。
   - 点不相邻的格：提示「要从上一格接着画」；
   - 点画过的格：提示「这条路绕回自己了」；
   - `🧹 撤销末端` 回退一步、`↺ 清空` 从头画。
3. **检查路径**：点 `✓ 检查路径`——程序验证这条走廊「只有一条路、没有近路」：
   - `✓ 唯一路径！可以保存` → 可以保存（至少走 4 格才有意思）
   - `这条路离太近，会抄近道` → 走廊两段贴太近，会走近路，隔开一点再画
   - `路径有断开` → 中间断了，接上
4. **保存**：检查通过后点 `💾 保存` → 关卡出现在列表（最多存 20 个）。
5. **挑战自建关**：列表里点 `▶ 挑战` → 和普通关一样编循环块/嵌套循环指令，让机器人走到 ⭐（通关 2★ + 已解徽章）。
6. 还可以 `✏ 编辑` 修改（改了就是改了）、`🗑 删除` 不要的关卡。

> 自己出题要动脑筋：**走廊只能有一条路、不能有近路**——这样答案唯一，才是合格的「有标准答案」关卡！

## 7. 小贴士

- **先看走廊找规律**：路线是不是「同一组动作」重复了好几遍？如「前进前进右转」反复出现。
- **用循环块压缩**：走廊走 3 遍「前进前进右转」→ 写一个 `🔁×3 {前进, 前进, 右转}` 就行。
- **撞墙别慌**：看「第 K 次循环第 M 条指令」提示，就知道是哪一步出问题（嵌套时提示「第 a 次外层循环里的第 b 次内层循环里的第 c 条指令」）。
- **卡住了？** 点 `⟲ 重置` 回到起点，换个思路。

## 8. 常见问题

**Q：循环块和直接写很多遍有什么区别？**
循环块让**一「组」动作**重复执行——写 1 个块 = 写 1 组，重复的次数由 `重复次数` 决定。
直接写很多遍要多占很多指令条数（星级低）。**循环 = 少写代码 = 高效！**

**Q：为什么我的星级只有 2★？**
大概率是把重复的动作展开写了很多遍（指令条数多），或普通/挑战档只用了一层循环。
找到走廊的重复规律，改用**嵌套循环**（循环套循环）压缩，就能 3★。

**Q：循环块里能放几个动作？**
随便几个（前进/左转/右转都行），它们会作为一个**整体**重复执行 N 遍。v1.1 起循环块里**还能再放一个循环块**（嵌套，最多 2 层）——这就是「循环套循环」：外层每轮完整执行一遍内层。

**Q：走廊为什么全是墙？**
设计成「只有一条路」——这样目标唯一、答案唯一（有标准答案），不会绕路抄近道。焦点全在「怎么编指令最少」。

**Q：学到什么编程概念？**
顺序（一步步指令）→ **循环**（一组动作重复 = 自动化）→ **嵌套循环**（循环套循环 = 二维自动化）→ **创作/出题**（画走廊 → 理解唯一路径/无近路结构）——编程里最核心的「少写多做」思想！

**Q：自建关卡怎么才能通过检查？**
走廊要「只有一条路、没有近路」：画的时候从 S 一格一格连着画（别跳格、别绕回自己），两段路别贴太近（会抄近道）。检查不通过会告诉你原因，改一改再检查。
