# 循环指令 — 使用文档

> 编程教学子系列第 4 款：让机器人沿着走廊走到目标，用「循环」少写指令！
> 适用：手机 / 电脑（点击指令按钮即可，无需键盘）。
> 版本：v1.0 · 更新：2026-09-23

---

## 1. 怎么玩

1. 打开工具，选一个难度：**简单 / 普通 / 挑战**。
2. 盘面上有**走廊**（灰墙围成的路），蓝色圆球是**机器人**，⭐ 是**目标**。
3. 用指令让机器人从起点走到 ⭐：`⬆ 前进` / `↰ 左转` / `↱ 右转` / `🔁 循环`。
4. **走廊只有一条路**——机器人只能沿着走廊走，走到 ⭐ 就过关！

## 2. 循环块是什么（核心）

| 概念 | 说明 |
|---|---|
| 🔁 重复 N 次 { 组指令 } | 让**一组**动作重复做 N 遍（比如「前进、前进、右转」重复 3 次） |
| 和走迷宫 ×N 的区别 | 走迷宫的 ×N 是让**一个**动作做多遍；循环块是让**一「组」**动作做多遍 |

> 💡 核心思想：**循环 = 自动化**——不用把重复的动作写很多遍，写一个循环块搞定！
> 看走廊的路线有没有「每一段都一样」的规律：找到规律 → 用一个循环块 → 指令最少 → 3★。

## 3. 指令说明

| 指令 | 作用 | 小提示 |
|---|---|---|
| ⬆ 前进 | 机器人朝当前方向走 1 格 | 撞墙会停下并提示 |
| ↰ 左转 / ↱ 右转 | 原地转 90°，不移动 | 走廊转弯处要用 |
| 🔁 循环 | 插入一个「重复 N 次 { }」块 | 点开块，往里面加指令 |

**循环块怎么用**：
1. 点 `🔁 循环` → 序列里出现一个紫色块 `🔁×2 {}`；
2. 点紫色块 → 打开块内编辑区（显示「第 1 条循环块 · 重复 2 次」）；
3. 点 `重复次数` 按钮调到 3（或 4/5）次；
4. 点块内的 `⬆ 前进` / `↰ 左转` / `↱ 右转` 加指令（这就是循环体，会重复执行）；
5. 点 `✓ 完成` 收合。

## 4. 界面说明

- **难度页**：三张难度卡，显示该难度历史最佳星级。
- **顶栏**：`‹ 返回`、当前难度与目标（`让机器人到 ⭐`）、`⏱ 计时`。
- **盘面**：灰墙 = 走廊墙；浅色格 = 走廊路；蓝点 = 机器人；⭐ = 目标。
- **概念卡**：循环块 vs 走迷宫 ×N 的对比提示。
- **指令序列区**：浅蓝 = 基础指令；紫色 = 循环块；`✕` 删除，`↺ 清空` 全清。
- **执行反馈**：
  - 成功：`✓ 完成！机器人到目标啦（N★，指令 M 条 / 最优 K）`
  - 未达：`✗ 机器人走到了 (x,y)，目标 (gx,gy)（还差 M 格）`
  - 撞墙：`⛔ 第 K 次循环第 M 条指令（前进）撞墙啦`

## 5. 成绩与打卡

- **星级（指令条数 = 编写量）**：
  - 循环块 = 1 条 + 块内每条指令计 1（**不乘重复次数**）
  - ★★★：编写量 ≤ 最优的 1.5 倍（找到规律用循环块 → 3★）
  - ★★：编写量 ≤ 最优的 2.5 倍（把动作展开写很多遍 → 只能 2★）
  - ★：走到 ⭐ 即可
- 每过一题点亮**今日打卡**；各难度分记最佳。全部数据存本地，离线可用，无广告无内购。

## 6. 小贴士

- **先看走廊找规律**：路线是不是「同一组动作」重复了好几遍？如「前进前进右转」反复出现。
- **用循环块压缩**：走廊走 3 遍「前进前进右转」→ 写一个 `🔁×3 {前进, 前进, 右转}` 就行。
- **撞墙别慌**：看「第 K 次循环第 M 条指令」提示，就知道是哪一步出问题。
- **卡住了？** 点 `⟲ 重置` 回到起点，换个思路。

## 7. 常见问题

**Q：循环块和直接写很多遍有什么区别？**
循环块让**一「组」动作**重复执行——写 1 个块 = 写 1 组，重复的次数由 `重复次数` 决定。
直接写很多遍要多占很多指令条数（星级低）。**循环 = 少写代码 = 高效！**

**Q：为什么我的星级只有 2★？**
大概率是把重复的动作展开写了很多遍（指令条数多）。找到走廊的重复规律，改用循环块压缩，就能 3★。

**Q：循环块里能放几个动作？**
随便几个（前进/左转/右转都行），它们会作为一个**整体**重复执行 N 遍。本版循环块里暂时不能放另一个循环块（那叫嵌套，后续版本再加）。

**Q：走廊为什么全是墙？**
设计成「只有一条路」——这样目标唯一、答案唯一（有标准答案），不会绕路抄近道。焦点全在「怎么编指令最少」。

**Q：学到什么编程概念？**
顺序（一步步指令）→ **循环**（一组动作重复 = 自动化）——编程里最核心的「少写多做」思想！
