# 方块排列指令 — 使用文档

> 编程教学子系列第 2 款：像搭积木一样，用指令让方块排成目标图案！
> 适用：手机 / 电脑（点击指令按钮即可，无需键盘）。
> 版本：v1.2 · 更新：2026-09-26

---

## 1. 怎么玩

1. 打开工具，选一个难度：**简单（2 块）/ 普通（4 块）/ 挑战（6 块）**，或点**🛠 自建关卡**自己当出题人！
2. 盘面上有**橙色半透明图案**（目标布局），你要用指令把方块排成它。
3. **v1.1：一次为所有方块编指令**——顶部「第 1 块 / 第 2 块…」的小标签（块 tab）切换，每块各有自己的指令区：
   `↻ 旋转` / `⬅ 左移` / `➡ 右移` / `⬇ 落下`。
4. 全部方块都编完后，点 **▶ 执行**——方块按顺序一块一块落下；全部落完，图案排对 = 过关！

> 💡 **v1.1 升级**：v1.0 是一块一块试（编一块执行一块）；v1.1 要**先想好所有块怎么放**，一口气编完整套指令再执行——
> 这就是编程里的「先规划、后执行」！
>
> 🛠 **v1.2 新增·自建关卡**：在首页点「自建关卡」→「新建关卡」→ 在 10×10 格子里**涂出你的图案** → 点「✓ 检查可拼」确认能拼出来 → 保存 → 点「▶ 挑战」自己来解（通关 2★）。和朋友换着题目玩，当一回出题人！

## 2. 指令说明

| 指令 | 作用 | 小提示 |
|---|---|---|
| ↻ 旋转 | 让方块顺时针转 90°（点一下转 1 次，可切 ×2/×3） | 转到目标图案的方向再落下 |
| ⬅ 左移 / ➡ 右移 | 让方块水平移动 N 格（点一下移 1 格，可切 ×2/×3…） | 看橙色目标在哪列 |
| ⬇ 落下 | 让方块垂直落到底（碰到已放的方块或底部就停） | 每块最后都要点它 |

> 指令小方块可以：**点一下**调整次数（旋转 ×1→×2→×3、移动 ×1→×2→…）、**✕** 删除单条。

## 3. 界面说明

- **难度页**：三张难度卡，显示该难度历史最佳星级。
- **顶栏**：`‹ 返回`、「已编 X / K 块」（编了几块指令）、`⏱ 计时`。
- **块 tab 行**：「第 1 块 / 第 2 块…」——切到哪块就编哪块；编过指令的块有个 ✓ 记号。
- **盘面**：橙色半透明 = 目标图案；实心彩色 = 执行后你放的方块。
- **当前块预览**：显示正在编的这块长什么样、转了几次。
- **指令序列区**：当前块的指令；`✕` 删除单条，`↺ 清空` 全清。
- **执行中**：块 tab 会变灰（执行完才能改）；顶部显示「执行中 N/K 块」。
- **执行后反馈**：
  - 排对了：`✓ 完成！图案排好啦！（N★，指令 M 条 / 最优 K）`
  - 某块放偏了（执行中即时提示）：`块 N 落定（有 M 格放偏，执行完再调整）`——红框标出放错位置
  - 全部放完但没对上：`✗ 还有 M 格没对上，调整指令再试（点 ⟲ 重置）`

## 4. 成绩与打卡

- **星级**（指令条数 vs 每关最优解，越少越高星）：
  - ★★★：指令条数 ≤ 最优的 1.5 倍
  - ★★：指令条数 ≤ 最优的 2.5 倍
  - ★：排对即可
- **自建关卡**：没有「最优解」参考，通关统一 2★（用自己的图案练习，重在过关！）
- 每排对一关即点亮**今日打卡**，页面底部显示连续打卡天数；各难度分别记录最佳成绩。
- 全部数据存本地（localStorage），离线可用、不联网上传，无广告无内购。

## 5. 自建关卡（v1.2）

1. 首页点 **🛠 自建关卡** → **+ 新建关卡**。
2. 起个名字（≤12 字），在 **10×10 格子里涂色**画你的目标图案：
   - 点 **🧱 画格** 后点/拖动格子涂色；点 **🧹 橡皮** 擦除。
   - 橙色半透明格 = 你画的图案（和练习时看到的目标一样）。
3. 点 **✓ 检查可拼**——程序会判断「这个图案能不能由方块拼出来」：
   - 能拼 → 「✓ 可拼！可以保存啦」
   - 拼不出来 → 提示原因（比如「格子数要是 4 的倍数」「方块要从上往下落」——看看有没有悬空的格子）
4. 校验通过后再点 **💾 保存**（没通过时保存会被拦住）。
5. 回到关卡库：点 **▶ 挑战** 自己解（通关得 2★ 并点亮「已解」）；**✏ 编辑** 改图案；**🗑 删除** 不要的关卡（最多 20 关）。

> 💡 **出题人的诀窍**：方块是从上往下落的，所以图案里不能有「悬空」的格子——
> 每个格子的正下方要么贴着另一个格子，要么贴到棋盘底部。画完记得点「检查可拼」验证！

## 6. 小贴士

- **先规划再动手**：先看完整盘面的橙色目标，想好每一块放哪、朝哪个方向，再一块一块编指令。
- **善用参数化**：移 3 格不用点 3 次，点一下移动指令再点两次变成 ×3。
- **旋转只有顺时针**：转 ×3 就是转了 3 个 90°（等于转到另一边）。
- **放偏了别急**：红框标出放错的位置，点 `⟲ 重置` 重来，观察目标图案再编（重置后会换一道新题）。

## 7. 常见问题

**Q：方块转了半天没变化？**
有些方块（黄色 O 型）转完和原来一样，这是正常的——它四个方向都一样。

**Q：移过头了会怎样？**
移到边界会自动停住（不会掉出棋盘），块会闪一下提醒你「到边了」。

**Q：放偏了怎么办？**
红框标出的就是放错的位置。点 `↺ 清空` 清当前块的指令，或点 `⟲ 重置` 全部重来。

**Q：为什么我的指令比最优解多很多？**
每关有个「最优指令数」参考（星级基准），但只要图案排对就过关，多几步只是星少一颗。先通关，再回来挑战 3 星。

**Q：自建关卡为什么只能得 2★？**
自建关卡没有「最优指令数」参考（图案千变万化），所以通关统一 2★——重点是自己出的题能解出来，当出题人的成就感！

**Q：画的图案保存时被说拼不出来？**
检查两点：① 格子数要是 4 的倍数（每块方块占 4 格）；② 不能有悬空的格子（正下方要贴着别的格子或棋盘底部）。改一改图案再「检查可拼」。

**Q：学到什么编程概念？**
顺序（一块一块编）→ 旋转（改变方向）→ 参数化移动（移 N 格）→ 空间规划（看目标反推位置）→ 出题创作（v1.2：自己画图案、理解方块怎么落）。
和机器人走迷宫互补：那里学「让机器人走」，这里学「让方块排好」。
