# 合并策略编程 — 使用文档

> 编程教学子系列第 3 款：像指挥数字排队一样，用方向指令让数字合出目标！
> 适用：手机 / 电脑（点击方向按钮即可，无需键盘）。
> 版本：v1.0 · 更新：2026-09-23

---

## 1. 怎么玩

1. 打开工具，选一个难度：**简单（目标 8）/ 普通（目标 16）/ 挑战（目标 32）**。
2. 盘面上有一些数字块（2 / 4），左上角显示**目标数字**。
3. 点方向按钮（`⬅ 左移` / `➡ 右移` / `⬆ 上移` / `⬇ 下移`）把指令排成序列。
4. 点 **▶ 执行**，数字块就按你的指令滑动合并——**合出目标数字就过关！**

## 2. 合并规则

| 规则 | 说明 |
|---|---|
| 相同的数字相撞 | 两个相同数字碰到一起，合成一个双倍（2+2=4，4+4=8…） |
| 每轮每个块只合一次 | `2 2 2 2` 左移一次 = `4 4 0 0`（不是 8！），再左移一次 = `8` |
| 没有新数字 | 和 2048 不同，这里**不会自动冒出**新数字块，只有你指令的移动 |

> 合并规则概念卡：想想「两个相同数字相撞 → 合成一个双倍」，规划好移动顺序。

## 3. 指令说明

| 指令 | 作用 | 小提示 |
|---|---|---|
| ⬅ 左移 / ➡ 右移 | 整盘数字向左/右滑 | 相同数字滑到一起会合并 |
| ⬆ 上移 / ⬇ 下移 | 整盘数字向上/下滑 | 换方向让数字换个位置碰头 |

> 指令小方块：**点一下**增加重复次数（`⬅` → `⬅×2` → ×3 → ×4），表示连续移动 2/3/4 次；**✕** 删除单条。

## 4. 界面说明

- **难度页**：三张难度卡，显示该难度历史最佳星级。
- **顶栏**：`‹ 返回`、当前难度与目标（`目标合出 8`）、`⏱ 计时`。
- **盘面**：米黄色棋盘 + 彩色数字块（2048 经典配色）。
- **指令序列区**：已排好的方向指令；点一下切换 ×N，`✕` 删除，`↺ 清空` 全清。
- **执行后反馈**：
  - 成功：`✓ 完成！合出了 8！（N★，指令 M 条 / 最优 K）`
  - 超额：`✓ 完成！合出了 16，超过目标 8 🎉`
  - 未达成：`✗ 最大只有 4，还没合出 8（还差一点！调整指令再试）`
  - 无变化：盘面闪一下 + `⬅ 这边没有块可以移动哦`（方向选错，不扣分但计 1 条）

## 5. 成绩与打卡

- **星级**（指令条数 vs 每关最优解，越少越高星）：
  - ★★★：指令条数 ≤ 最优的 1.5 倍
  - ★★：指令条数 ≤ 最优的 2.5 倍
  - ★：合出目标即可
- 每过一题点亮**今日打卡**，底部显示连续打卡天数；各难度分记最佳。
- 全部数据存本地（localStorage），离线可用、不联网上传，无广告无内购。

## 6. 小贴士

- **先想好再动手**：看看哪两个数字能先碰上，规划 2-3 步再编排。
- **善用重复**：连续同方向（如 `⬅×2`）不用点两次，点一下变 ×2 就行。
- **合一次只合一对**：`2 2 2 2` 左移一次只变 `4 4`，要再移一次才变 `8`——别急！
- **卡住了？** 点 `⟲ 重置` 回到初始盘面，换个思路重新规划。

## 7. 常见问题

**Q：为什么 `2 2 2 2` 左移一次变成 `4 4` 不是 `8`？**
2048 合并规则「每轮每个数字块只合一次」——`2+2=4` 后这个新 `4` 本轮就不再合了。这是编程里「一次操作只做一件事」的思维训练。

**Q：怎么知道哪步没变化？**
执行时如果某方向数字块根本动不了（方向选错），盘面会闪一下，提示「这边没有块可以移动哦」。

**Q：为什么我的指令比最优解多？**
每关有个「最优指令数」参考（程序算出的最短解法），但只要合出目标就过关，多几步只是星少一颗。先过关，再回来挑战 3 星。

**Q：学到什么编程概念？**
顺序（一步步方向指令）→ 循环（×N 重复移动）→ **策略规划**（提前想好几步的合并路径）。
和走迷宫（让机器人走）、方块排列（让方块排好）互补：这里学「让数字合起来」的多步规划。
