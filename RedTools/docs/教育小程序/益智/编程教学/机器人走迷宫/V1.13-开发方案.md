## 1. 背景与目标

### 1.1 背景

v1.11/v1.12 块参数实现「带 **1 个**数字参数的块」——块内所有参数化 steps（`steps:null`）执行时填**同一个** `call.param`（参数贯穿）。教学上落地的是「参数 = 贯穿整块的一个名字」。

**缺口（两处，均为既往版本明确记录的后继）**：
1. **混合态**：块内 steps 只能「全部参数化 or 全部固定」——无法表达「部分走固定步数、部分走调用步数」的混合动作段；
2. **多参数数组**：一个块只能有 **1 个**参数——Scratch My Blocks 支持**多输入**（`walk steps: turn: `）。v1.12 的「共享同一 N」无法表达「走 N 步、再走 M 步」类**多变量**模式。

设计文档 §9 明确定义：**混合态/多参数数组（v1.13+，部分 steps 参数化或每步独立参数——高阶参数化）**。

### 1.2 教学定位

- v1.11 块参数：**同块不同参数 → 不同行为**（单一参数）
- v1.12 参数贯穿：一个 N 贯穿块内**所有** steps（方形/拐角模式）
- **v1.13 高阶参数化**：① **混合态**——参数只影响被标记的步骤，其余步骤固定（`?` 与数字可同块共存）；
  ② **多参数数组**——块可携带**多个独立参数**（每个参数化步骤绑定各自的槽位），调用时**每个参数独立取值**（`?₁` 与 `?₂` 各自不同数字）
- 教学价值：真实函数**多形参**（Scratch My Blocks 多输入积木）；「参数 = 变量」从单变量进阶多变量；
  混合态让「块的定义 = 固定骨架 + 可调部分」更直观

### 1.3 与既有能力关系

| 项 | v1.11 | v1.12 | v1.13 |
|---|---|---|---|
| 参数数量 | 1（≤1 处参数化） | 1（全部参数化共享 N） | **0~2**（`?₁`/`?₂` 槽位，每步独立） |
| 参数化范围 | 仅第 1 条 | 全部 steps | **逐条可设**（固定 ⇌ 参数#0 ⇌ 参数#1） |
| 混合态（固定+参数同块） | ✗ | ✗ | **✓** |
| call 数据 | `param:N` | `param:N` | `params:[N,M]`（存量 `param` 兼容） |
| 调用调参 | cycleCallParam(3→9→1) | 同 | **逐槽调参**（?₁ / ?₂ 独立循环） |
| 执行 | execCall 副本 | 零改动 | **paramIdx 填对应槽**（execCall 小改） |
| 星级 | totalSteps 统一 | 零改动 | **零改动**（仍计 1/条） |
| 定义态显示 | `➡N步(N)` | `➡?步` | `➡?₁步` / `➡?₂步`（槽位下标）+ 固定 `➡走N步` 共存 |

### 1.4 目标

| 项 | 说明 |
|---|---|
| 教学目标 | **多参数函数**（Scratch 多输入积木）：一个块两个独立参数；**混合态**：参数=块内可替换的精准部分 |
| 玩法 | 参数态下 steps chip：单击切换槽位（?₁⇌?₂）/固定循环数值（1-9）/长按或 shift+单击切换 固定⇌参数；toggle 开=全部参数#0（幂等）/关=全部固定（v1.12 兼容）；call chip `🧩名(3,5)` 两数字独立调参 |
| 合规 | 本地存储（同前）、无 PK/云同步；多参数 = 编程概念教学 |
| 范围 | 0 新关；**参数上限 2**（低龄，Scratch 启蒙够用）；执行器/星级小改；不影响 v1.10-v1.12 已存数据（**零迁移**：存量 steps:null 无 paramIdx → 槽#0；存量 call.param → params[0]） |

## 2. 变更设计

### 2.1 数据模型扩展（customBlocks + call，向后兼容）

```js
// 块 body 参数化 steps（v1.13 扩展）：{ id:'steps', steps:null, paramIdx?: 0|1 }
//   steps:null          → 绑定参数槽 #0（缺省，兼容 v1.11/v1.12）
//   steps:null,paramIdx:1 → 绑定参数槽 #1（新增，第二参数）
//   steps:N             → 固定（不变）；参数化 steps 与固定 steps 可同块共存（混合态）
// call 指令（v1.13 扩展）：{ id:'call', bid, name, params:[N,M]? }
//   params:[N,M] 数组（长度=块参数数，N→槽#0 / M→槽#1；缺省值 3）
//   存量 { id:'call', ..., param: N } → 读取兼容为 params[0]（零迁移）
```

- **参数数量派生**（B2 风格，不存字段）——**I3 修订（undefined 处理）**：
  ```js
  function blockParamCount(id) {
    var def = getCustomBlock(id);
    if (!def || !def.body) { return 0; }
    var maxIdx = 0, hasNull = false;
    for (var i = 0; i < def.body.length; i++) {
      var c = def.body[i];
      if (c.id === 'steps' && c.steps === null) {
        hasNull = true;
        var idx = c.paramIdx || 0;          // I3：undefined → 0（v1.11/1.12 存量）
        if (idx > maxIdx) { maxIdx = idx; }
      }
    }
    if (!hasNull) { return 0; }
    return Math.min(maxIdx + 1, 2);          // I4：clamp 到 2（低龄上限，异常 paramIdx>1 防御）
  }
  // blockHasParam 兼容 = blockParamCount(id) > 0（协议镜像，渲染分流不变）
  ```
  - `blockParamCount(id) = min(max(paramIdx)+1, 2)`（无 null → 0）；仅当 hasNull 计数（无 null 的 body 即使有 paramIdx 字段也不计数——防御畸形数据）
- **backward compat（关键，Oracle 确认成立）**：
  - v1.10 无参块：body 无 steps:null → paramCount=0 → call 无 params → 完全 v1.10 行为 ✅
  - v1.11/v1.12 单参块：steps:null 无 paramIdx → 槽#0；call.param 读作 params[0] → 行为不变 ✅
  - **零迁移**：无 schema 版本号、无改写旧数据（读取层兼容即可）
- **上限**：paramIdx ∈ {0,1}（2 参数封顶）；`blockParamCount` clamp 兜底异常数据

**存取函数**：复用现有（load/save 数组直存，字段透传）；新增 `blockParamCount(id)` 派生函数。

### 2.2 块编辑器交互（逐条参数化 + 槽位切换）— I1 修订：弃 dblclick，改长按+shift 切换

**渲染**（renderBlockBodyChip，v1.13 扩展）：
- 参数化 steps：`➡?₁步`（槽#0）/ `➡?₂步`（槽#1）——`₁`/`₂` 下标（`.param-q` 浅紫保留）
- 固定 steps：`➡走N步`（不变）——混合态肉眼可辨
- 面板预览（renderBlockPicker，**I5 修订**）：同款（`➡?₁步`/`➡?₂步`/`➡N步` 混合）

**点击/长按交互**（**I1 采纳：弃用 dblclick**——DOM 先触发 click×2 再 dblclick，单击槽位切换会先闪两轮；且工具**手机竖屏为主**，移动端 dblclick 常触发缩放。改三态交互，全部单一手势）：

| 步骤状态 | 单击 chip | 长按（≥350ms）/ shift+单击 |
|---|---|---|
| 固定 steps | cycleSteps 数值 1→9（v1.12 不变） | **切换为参数化槽#0**（steps:null） |
| 参数化 steps（槽#0） | **切换槽位 → 槽#1**（paramIdx:1） | **恢复固定（steps:1）** |
| 参数化 steps（槽#1） | **切换槽位 → 槽#0**（删除 paramIdx） | **恢复固定（steps:1）** |

- **单击 = 语义分流**：固定步进数值（cycleSteps 保持）/ 参数化步骤切换槽位（?₁ ⇌ ?₂）——**互斥动作，态不同入口不同**，无意图冲突
- **长按 / shift+单击 = 固定 ⇌ 参数 双向切换**：混合态创建的主入口；
  - 长按实现：`pointerdown` 起 350ms 定时器 → 触发切换；`pointerup` 早于 350ms 取消（单击走正常 handler）。指尖按住看提示文字「长按变参数/固定」
  - shift+单击兜底：桌面/冒烟确定性入口（keydown shift 检测），**Playwright 验证用 shift+click**
  - **I1 补充**：避免长按与单击冲突——长按触发后抑制随后的 click 事件（flag + timestamp 去抖，≤500ms 内的 click 忽略）
- **toggle 语义（I2 修订——幂等，不抹槽位）**：
  - **ON**（v1.12 为全部参数化）：改为「未参数化 steps → 槽#0」，**已参数化（含槽#1）保持不变**（幂等不破坏混合态/槽位；无参数化 → 全部变槽#0，行为 = v1.12 现状）
  - **OFF**：全部恢复固定（v1.12 保持）
- **addBlockBodyCmd**：参数态新增 steps → `steps:null`（槽#0，v1.12 现状 keep）
- **删除参数化 steps**：沿用 v1.11 B2 重新派生（editBlockHasParam/参数槽均由 body 派生，删除自动降级）

### 2.3 调用与调参（params 数组 + 逐槽循环）— I6 修订：分段 span

**渲染**（renderSeq call chip，**I6 采纳**）：参数块显示 `🧩名(N₀,N₁)`——**chip 结构从单文本改为内嵌子 span**：

```js
// 结构：<span class="cmd-chip call param-call">  +  序号span  +  🧩名span  +  "("  +  N₀span  +  ",N₁span"  +  ")"
// N₀/N₁ 各自：<span class="call-param" data-slot="0">3</span>
```
- 参数#0 值 `N₀` / 参数#1 值 `N₁`（槽#1 存在时显示；单参块维持 `🧩名(3)` 单段 = v1.12 兼容）
- `.call-param` 浅紫小字 + `data-slot` 属性；点击 N₀ 段 → `cycleCallParamSlot(i, 0)`；点击 N₁ 段 → `cycleCallParamSlot(i, 1)`
  （独立 click listener + `stopPropagation` 防冒泡；空段区域点击（`🧩名`/序号/逗号）→ 调参 slot#0，v1.12 盲点行为保持）
- **存量 call 显示升级（Oracle 完整性缺口 2）**：块升 2-param 后存量 call（`param:5` 无 params 数组）
  渲染：`blockParamCount>1` → 显示 `🧩名(5,3)`（slot#1 缺失按默认 3 显示——仅渲染补默认，不写数据；
  点击 N₁ 段调参时写时归一化创建 params 数组）

**调参交互**（cycleCallParamSlot，含写时归一化——Oracle 边界用例全覆盖）：
```js
function cycleCallParamSlot(i, slot) {
  if (state.execLock) { return; }
  var cmd = state.cmds[i];
  if (!cmd || cmd.id !== 'call') { return; }
  var pc = blockParamCount(cmd.bid);
  if (slot >= pc) { return; }                               // 无效槽 no-op
  if (!cmd.params) {                                        // 存量 param → params 归一化（写时迁移）
    cmd.params = [cmd.param !== undefined ? cmd.param : 3];
    delete cmd.param;
  }
  while (cmd.params.length < pc) { cmd.params.push(3); }    // 补足槽位默认 3
  cmd.params[slot] = ((cmd.params[slot] || 3) % 9) + 1;     // 槽位独立 3→4→…→9→1
  renderSeq();
}
```
- **边界（Oracle 缺口 5）**：
  - (a) 首次写 slot#1：params 不存在 → `[param||3, 3]` 再写 slot#1 → 删 param ✅
  - (b) 块降级 2→1-param：存量 params:[N,M] → slot#1 不再被读取（blockParamCount=1 限制）→ 脏数据残留但不读、不显示 ✅
  - (c) 块降级后 call chip 显示回退单参数 `🧩名(N)`（渲染按 blockParamCount 分段）✅
- **块选择面板追加（I5 修订）**：`blockParamCount(b.id)>1` → `{id:'call', bid, name, params:[3,3]}`；
  单参块保持 `{param:3}`（兼容）；无参块不设（v1.10 兼容）

### 2.4 执行器（execCall paramIdx → params 槽值）— B2 修订：槽位感知回退链

```js
var runBody = def.body.map(function (c) {
  var nc = { id: c.id };
  if (c.rep !== undefined) { nc.rep = c.rep; }
  if (c.id === 'steps') {
    if (c.steps === null) {
      var slot = c.paramIdx || 0;                            // 槽位（缺省 #0）
      // B2：槽位感知回退——params[slot] 优先；param 仅对 slot#0 有效；slot#1 直接兜底 3（防错误继承）
      nc.steps = (cmd.params && cmd.params[slot] !== undefined)
        ? cmd.params[slot]
        : (slot === 0 ? (cmd.param || 3) : 3);
    } else { nc.steps = c.steps; }                            // 混合态：固定步骤原样
  }
  else if (c.steps !== undefined) { nc.steps = c.steps; }
  return nc;
});
```
- **B2 场景验证**：1-param 块 call `param:5` → 编辑器为块加槽#1（blockParamCount=2）→ 存量 call 无 params：
  - slot#0 → `params[0]` undefined → `param`=5 ✅
  - slot#1 → `params[1]` undefined → **slot≠0 → 兜底 3**（不错误继承 5）✅（v0.1 缺陷已修）
- **混合态天然支持**：固定 steps 走 `nc.steps = c.steps`（v1.12 已实现，无改动）
- **存量兼容**：v1.12 call.param → params 为 undefined → 回退 param\|\|3（行为不变）；无参块共享引用路径不动
- **运行时副本隔离保持**：参数块仍走 map 浅拷贝；**execCall 副本无需复制 paramIdx**
  （steps:null 已在副本上解析为具体值，paramIdx 不参与运行时——Oracle B1 确认安全）
- **B1 修订（阻断必修）**：`viewBlockEdit` 深拷贝（L506-511）补 `paramIdx`：
  ```js
  editBlockBody = def.body.map(function (c) {
    var nc = { id: c.id };
    if (c.rep !== undefined) { nc.rep = c.rep; }
    if (c.steps !== undefined) { nc.steps = c.steps; }
    if (c.paramIdx !== undefined) { nc.paramIdx = c.paramIdx; }   // B1：防编辑即销毁槽位
    return nc;
  });
  ```
- **MAX_PARAMS guard**：blockParamCount clamp 到 2；异常 paramIdx>1 → 按槽#0 fallback（不崩）

### 2.5 toggle 语义（I2 修订——幂等，不抹槽位）

| 场景 | v1.12 | v1.13 I2 修订 |
|---|---|---|
| toggle ON（无参数化 steps） | 全部 steps:null | **全部 steps:null（槽#0）**（行为同 v1.12） |
| toggle ON（已有参数化含槽#1） | 全部归 null（抹槽位） | **仅未参数化 steps 归 null（槽#0），已参数化（含槽#1）保持不变**（幂等，不破坏混合态/槽位） |
| toggle OFF | 全部恢复 steps:1 | **全部恢复 steps:1**（含槽#1；v1.12 保持） |
| 存量 v1.12 块 | toggle 显示 on | 无槽#1，实际零差异 ✅ |

- **教学语义**：toggle = 「这个块带参数」总开关（ON：内部步骤可自由设；OFF：整个块回固定）
- **交互流状态机（Oracle 缺口 1 补齐）**：
  ```
  [全固定块] --toggle ON--> [全?₁（槽#0）]
     ↑                        │
     │  toggle OFF             ├─ 单击某 ?₁ → ?₂（槽位切换）
     │                         ├─ 长按/shift+单击某 ?  → 该条回固定（混合态出现）
     │                         ├─ 长按/shift+单击某固定步 → 该条变 ?₁
     │                         │
     └── toggle OFF ───────────┘（全部恢复固定，混合态/槽位清空）
  ```
  混合态/多参数是**逐条长按 + 单击槽位**精细构建；toggle 只做「全参 / 全固定」粗粒度设置（ON 幂等防误抹）

- 0 新关；不涉及关卡编辑器/防沉迷/结算
- **参数上限 2**：paramIdx ∈ {0,1}；blockParamCount clamp 防御；**Chrome 61 兼容**

  totalSteps 断言：`totalSteps([{id:'steps',steps:null,paramIdx:1}]) === 1`、`totalSteps([{id:'steps',steps:5,paramIdx:0},{id:'left',rep:1}]) === 2`
  （steps 无 rep → `c.rep||1` 计 1；paramIdx 不影响）＋ call 计 1 + body 一次（seenBlockIds 按 bid 去重）不乘参数数

  编辑器入口只在块编辑视图；块库异常步骤 execSteps 的 `steps===null→return` guard 保留兜底，I3 v1.11）

### 4.1 totalSteps/数据单元测试（Node）

| 测试项 | 断言 |
|---|---|
| 混合态 body 星级 | 块 body=[steps:2 固定, steps:null 槽0, left] 单 call → 1 + (1+1+1) = 4 |

| toggle off→on 抹槽位（数据破坏） | 中 | **I2：ON 幂等**（仅未参数化变槽#0，已参数化含槽#1 保持）；off=全固定语义显式 |
