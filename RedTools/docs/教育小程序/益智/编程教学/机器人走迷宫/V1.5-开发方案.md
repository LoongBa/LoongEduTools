## 1. 背景与目标

### 1.1 背景

编程教学线 D1-D5 全部交付（2026-09-23），编程基础四块（顺序/循环/条件/分支）已覆盖前三块（v1.0 顺序→v1.1 循环→v1.3 条件探测→v1.4 调试）。v1.5 引入 **if/else 条件分支教学**，完成编程基础四块闭环（分支结构）。

### 1.2 目标

| 项 | 说明 |
|---|---|
| 教学目标 | **if/else 分支结构**：如果[条件]则…否则…（二选一分支） |
| 玩法 | 推箱子关卡中设「岔路口」（前方有墙 vs 前方无障碍），孩子用 `❓ if前方有墙` 指令块做分支判断，**更高效地**推箱到目标 |
| 合规 | 有标准答案（条件分支由盘面确定 → 路径正确 → 箱子到目标），合规安全区 |
| 合规红线 | 不引入 PK/排行榜/无标准答案玩法；条件分支是「更高效编程」的教学，不是「选择哪条路更爽」 |

### 1.3 与 v1.3/v1.4 的关系

| 版本 | 机制 | 语义 |
|---|---|---|
| v1.3 | `🧱 前方探测`（CMD_BLOCK） | **条件跳过**：前方有障碍→不前进；否则前进（单指令级条件） |
| **v1.5** | `❓ if前方有墙`（CMD_IF） | **条件分支**：前方有墙→执行 then 分支指令；否则→执行 else 分支指令（多指令分支） |

> v1.3 是「如果条件成立就跳过这一步」，v1.5 是「如果条件成立就执行 A 组指令，否则执行 B 组指令」——教学维度不同。

### 1.4 教学定位（P2 修订：if/else 是「更高效编程」策略）

**问题**：在全可见棋盘上，孩子总能预先知道哪里该转弯（直接写 `↰` 或 `↱`），if/else **不是必要条件**。

**解决方案**：将 if/else 定位为**编程效率教学**——岔路口关卡中，展开写需要 N 条转弯指令（每个岔路口写 2 条：先判断再转），用 if/else 可以 1 条搞定（自动根据前方墙决定走 then/else）。星级按「编写量」（指令 chip 数）vs 最优编写量（含 if 块的最优解），激励孩子使用条件分支。

**类比**：v1.1 循环指令也是同理——展开写也能解（重复 N 条指令），但循环块更高效。v1.5 if/else 同理。

## 2. 变更设计

### 2.1 新增指令块（CMD_IF）

**指令**：`❓ if前方有墙`

**数据结构**（P1 修订：去掉 rep 字段）：
```js
// state.cmds 数组中新增类型
{ id: 'if', then: [/* 指令对象数组 */], else: [/* 指令对象数组 */] }
// 注：无 rep 字段——if 块是条件分支，不是循环，不应有 rep 属性
// cycleRep() 需跳过 id==='if' 的指令
```

**语义**：
1. 检测机器人前方（当前 face 方向）是否为墙/越界（障碍）
2. **条件成立**（前方有墙/越界）→ 执行 `then` 分支内的全部指令
3. **条件不成立**（前方无障碍）→ 执行 `else` 分支内的全部指令
4. 每个分支内可包含：前进/左转/右转/循环块/嵌套 if 块（v1.5 建议最多嵌套 2 层）

**条件语义明确**（O3 修订）：
- `前方有墙` = 前方越界 **或** 前方格是墙（`state.walls`）**或** 前方格是箱子（`state.boxes`）——与 v1.3 CMD_BLOCK 语义一致（前方有障碍）
- 不检查目标格（`.`），目标格不算障碍

### 2.2 关卡设计（P2+P3 修订：推箱子 + 岔路口）

**关卡数据**（P3 修订：必须含箱子/目标）：
- v1.5 新增 20 关（156-175），全部是**推箱子关卡**（含 `$` 箱 + `.` 目标 + `@` 玩家 + `#` 墙）
- 每关有 1-2 个「岔路口」：机器人站在岔路口，前方有墙（条件成立）→ 走 then 路；前方无障碍（条件不成立）→ 走 else 路
- 岔路口设计在推箱路径中（如：岔路口左推箱到目标 A，岔路口右推箱到目标 B）

**示例关卡**（修订：含箱子/目标）：
```
  #####
  #   #
  # # ###
  # . $ #
  #     #
  #######
  @
```
- 玩家 `@` 在底部，前方（上）有墙 → 条件成立 → 走 then（左转再前进推箱）
- 岔路口：`# #` 中间的空位——机器人前方有墙，必须走 then 分支

**关卡设计原则**（P2 修订：更高效策略）：
1. 每关有 1-2 个岔路口（前方有墙 → 走 then；无墙 → 走 else）
2. **展开写可解**（不必须用 if/else），但用 if/else 更高效（编写量更少 → 星级更高）
3. 三档渐进：简单（1 岔路口）→ 普通（2 岔路口）→ 挑战（嵌套分支）

### 2.3 执行器重写（P1 修订：工作队列模型）

**废弃方案**：`execBranch` 递归模型（与 state.prog 线性索引不兼容）

**新方案**：**运行时工作队列模型**（状态机 + 可变队列）

```js
/* ---------- v1.5 工作队列执行器 ---------- */
function execRun() {
  if (state.execDone || state.won || !state.cmds.length) { return; }
  state.execLock = true;
  state.firstFail = null;
  state.absStep = 0;
  loadLevelState();
  // 将 state.cmds 浅拷贝为可变队列（每个元素是指令对象引用，then/else 共享引用）
  state.execQueue = state.cmds.slice();
  state.queueIdx = 0; // 当前队列执行位置
  var fb = document.getElementById('game-feedback');
  if (fb) { fb.textContent = '机器人执行中…'; fb.className = 'game-feedback'; }
  setCmdLocked(true);
  renderSeqHighlight();
  execStep();
}

function execStep() {
  if (state.queueIdx >= state.execQueue.length) {
    // 队列执行完毕：判定胜利
    state.execDone = true;
    checkWin();
    return;
  }
  var cmd = state.execQueue[state.queueIdx];
  state.queueIdx += 1;
  state.absStep += 1;

  if (cmd.id === 'fwd') {
    execFwd(cmd);
  } else if (cmd.id === 'left') {
    state.face = (state.face + 3) % 4;
  } else if (cmd.id === 'right') {
    state.face = (state.face + 1) % 4;
  } else if (cmd.id === 'block') {
    execBlock(cmd);
  } else if (cmd.id === 'if') {
    execIf(cmd);
  } else if (cmd.id === 'loop') {
    execLoop(cmd);
  }
  renderBoardOnly();
  renderSeqHighlight();
  setTimeout(function () { execStep(); }, 260);
}

/* if 条件分支：求值条件 → 选中分支指令插入队首 */
function execIf(cmd) {
  var pr = state.player % state.w;
  var pc = Math.floor(state.player / state.w);
  var dx = DIRS[state.face][0], dy = DIRS[state.face][1];
  var nr = pr + dx, nc = pc + dy;
  // 条件：前方越界/墙/箱子 → 有障碍
  var hasObstacle = (nr < 0 || nr >= state.w || nc < 0 || nc >= state.h ||
                     state.walls[nc * state.w + nr] || state.boxes[nc * state.w + nr]);
  var branch = hasObstacle ? (cmd.then || []) : (cmd.else || []);
  // 将选中分支指令【插入队首】（当前 queueIdx 已 +1，所以插在 queueIdx 处）
  if (branch.length > 0) {
    state.execQueue.splice.apply(state.execQueue,
      [state.queueIdx, 0].concat(branch));
  }
}

/* 循环：rep>1 时，执行一次后 rep-1，若 rep>0 则重新插入队首 */
function execLoop(cmd) {
  if (cmd._loopLeft === undefined) { cmd._loopLeft = cmd.rep || 1; }
  cmd._loopLeft -= 1;
  if (cmd._loopLeft > 0) {
    // 重新插入队首（再执行一次循环体）
    state.execQueue.splice(state.queueIdx, 0, cmd);
  }
}
```

**关键特性**：
- **工作队列**：可变数组 `state.execQueue`，队首弹出/插入，天然支持嵌套（if 内套 if = 递归插入队首）
- **无递归函数**：execStep 是单循环，不需要 execBranch 回调
- **状态完全兼容**：`absStep` 按队列弹出计数，`firstFail` 记录当前弹出指令（可追溯来源），`execLock` 不变
- **`_loopLeft` 处理**：循环体指令对象复用（if 分支内循环也通过 execLoop 处理），`execRun` 初始化时需递归重置所有 `_loopLeft = undefined`（含分支内循环指令）

### 2.5 星级计算（O5 修订）

**编写量规则**（if 块）：
- if 块本身计 1 条指令
- then 分支内指令数（不含 if 块自身）
- else 分支内指令数（不含 if 块自身）
- 总编写量 = 1 + then.length + else.length

**星级**：
- 编写量 ≤ bestPushes × 1.5 → 3★
- 编写量 ≤ bestPushes × 2.5 → 2★
- 其他 → 1★

**bestPushes 基准**（新关卡 156-175）：
- v1.5 新关卡的 `b` 值需通过**求解器计算**（推箱子 BFS 求解器，输出最优步数作为 bestPushes 基准）
- 或 `b = null`（兜底 2★）

### 2.6 渲染扩展（renderSeq）

**顶层 chip 渲染**（保持 v1.4 模式）：
```js
state.cmds.forEach(function(cmd, i) {
  var lbl;
  if (cmd.id === 'fwd') { lbl = '↑'; }
  else if (cmd.id === 'left') { lbl = '↰'; }
  else if (cmd.id === 'right') { lbl = '↱'; }
  else if (cmd.id === 'block') { lbl = '🧱'; }
  else if (cmd.id === 'if') { lbl = '❓if'; }
  else if (cmd.id === 'loop') { lbl = '🔁'; }
  // 渲染 chip（无 rep 的 if 块不显示 ×N）
  var chip = makeEl('span', 'cmd-chip' + (cmd.id === 'if' ? ' if' : ''),
    (i + 1) + '.' + lbl);
  // 点击 if 块 → 打开 editCtx
  if (cmd.id === 'if') {
    chip.addEventListener('click', function() { openEditCtx(i, cmd); });
  }
  // ... X 角标删除
  box.appendChild(chip);
});
```

**editCtx 打开/关闭**：
```js
var editCtxIdx = -1; // 当前编辑的 if 块下标
function openEditCtx(idx, cmd) {
  editCtxIdx = idx;
  // 渲染 then/else 分支 chip + 添加按钮
  renderBranchChips('then-chips', cmd.then, idx, 'then');
  renderBranchChips('else-chips', cmd.else, idx, 'else');
  // 显示编辑区
  document.getElementById('block-edit').style.display = 'block';
}
function closeEditCtx() {
  editCtxIdx = -1;
  document.getElementById('block-edit').style.display = 'none';
}
```
