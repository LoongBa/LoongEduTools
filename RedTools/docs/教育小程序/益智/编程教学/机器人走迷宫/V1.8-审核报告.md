## 2. 发现的问题

### 🔴 重要级（must-fix，已修复）

**F1 — 新关 197 与 198 完全重复**

- **位置**：`levels.js` 数组索引 196/197（关卡 197/198）
- **问题**：两关 `g` 数组逐字符相同（12 行×11 列，第 6 行 `# @$......#`，玩家 col2、箱 col3、目标 col4-9），b 均为 3。孩子玩到第 198 关发现与 197 一模一样，无新教学内容。
- **修复**：关卡 198 改为 `🔁×3{🔁×2{fwd}}` 结构（rep 内外互换），盘面行位置不同（目标行 3 非行 5），与 197 区分。

**F2 — 新关 202 与 203 完全重复**

- **位置**：`levels.js` 数组索引 201/202（关卡 202/203）
- **问题**：两关 `g` 逐字符相同（`# @$.... #`，11 行），b 均为 3。方案 §2.4 明确区分 202（概念教学关 2×2）与 203（3×2 正常激励关），实际布局完全一致。
- **修复**：关卡 203 改为**右转下推 steps 结构**（`right + loop×2{loop×3{steps1}}`，盘面 `#    @    # / #    $    # / … / #    .    #`），与 202（左推 fwd 概念关）方向+指令双区分。

**F3 — 全部 10 新关可被单条 `fwd` 秒解，星级激励完全失效**

- **位置**：`levels.js` 数组索引 195-204（关卡 196-205）+ `main.js` finishLevel 星级判定
- **问题**：10 关盘面全部为「单行走廊 `# @$...(N 目标)...#`」——1 箱 + N 连续目标紧邻箱。玩家初始朝右（face=0），执行单条 `fwd` 即将箱推至第一个目标 → `isWon()`（1 箱在任一目标即胜）通过 → `totalSteps([fwd])=1 ≤ 1.5×b` → **3★**。星级激励（方案 §2.4「展开写 > 1.5×b → 2★，嵌套写 ≤ 1.5×b → 3★」）完全落空——最简解比嵌套解更优，孩子无动机使用嵌套循环，**v1.8 教学目标无法达成**。
- **根因**：方案设想的 M×N 二维网格盘面（需转向/多行）未实施，全部简化为一维直推。
- **修复**：10 关全部重做为 **2D 盘面**——
  - **目标唯一且远离箱**（箱→目标 ≥4 格，单 fwd 推 1 格必不到目标 → 不秒解）
  - **方向多样**（右推 196/198/200/202 / 左转上推 197/201/205 / 右转下推 199/203/204，含转向指令 = 二维推箱路径）
  - **嵌套激励成立**：展开写 totalSteps 与嵌套解 totalSteps 比值 1.75~2.25（除概念关 202 豁免），`展开 > 1.5×b → 2★`、`嵌套 = b → 3★` 全部成立
  - **202 概念教学关**（方案 §2.4 明确不强求星级）保留豁免
