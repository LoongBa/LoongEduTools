## 4. 变更摘要

| 变更 | 说明 |
|---|---|
| **hasParamInBody 补 if 递归** | `c.then && c.then.length` / `c.else && c.else.length`（对齐 scanParamSteps）→ `editBlockHasParam` 派生与 `blockParamCount` 一致：分支内参数化 steps 的块编辑时 toggle 正确显示 on |
| **toggleStepsInArr 补 if 递归** | toggle 批量操作覆盖 then/else 内 steps（无 .length，与自身 loop 风格一致） |
| **hasStepsInArr 补 if 递归** | toggle ON 前置检查覆盖分支内 steps——仅分支有 steps 不再误报「先加一条 ➡N步」 |
| **toggleBlockHasParam 三处** | OFF 分支恢复固定 / ON hasSteps 检查 / ON 批量操作——各补 if 分支进入（含短路防空 + v1.16.1 注释） |
| **注释同步（N2 两处）** | hasEditBodyParam 上方 + toggleBlockHasParam 上方大段注释补 v1.16.1 说明（含 toggleStepsInArr/hasStepsInArr 各一） |
| **保留语义** | I2 幂等（ON 仅未参数化→槽#0，已参数化含槽#1 保持）；OFF 全恢复固定清槽；存量块零迁移；执行路径零改动 |
