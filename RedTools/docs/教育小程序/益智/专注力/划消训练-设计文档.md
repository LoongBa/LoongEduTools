## 2. 玩法设计

### 2.1 规则

- 每局 N 轮（按难度）。每轮：顶部**目标大卡**（要找的图案）+ 满屏 M 张卡片——其中 K 张与目标**完全一致**（要划掉的），其余 M−K 张为「带一种小差异」的相似干扰项。
- 点击卡片：**目标** → 划掉（红 ✕ 覆盖 + 图案淡化 + 计数 +1）；**干扰项** → 红闪 + 错误计数 +1（可继续划）。
- 本轮 K 个目标全部划掉 → 下一轮；全部轮次完成即过关。
- **价值**：孩子要「牢牢记住目标特征，在相似物中反复筛选划出所有目标」——经典划消测验的注意力-抗干扰核心。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 点卡片 | 目标 → 划掉（红叉标记，不可再点）；干扰项 → 红闪 + 错误 +1（保留可再点） |
| 底栏按钮 | 「返回难度」/「重新开始」（同难度重抽一局） |
| 顶栏按钮 | 「← 返回」回难度页 |

### 2.3 反馈

- **划对**：卡片红 ✕ 覆盖（`popMark 0.3s`）+ 图案淡化 + 边框变红 + 轻音效 + 「已划 n/K」进度更新；
- **划错**：卡片红闪（`wrongFlash 0.4s`）+ 低音效 + 错误计数 +1；
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件）：划对清脆 / 划错低沉 / 胜利琶音。

## 4. 技术设计

### 4.1 数据模型

- **难度常量 `LEVELS`**：

| key | 难度 | 轮数 | 卡片数 M | 目标数 K | 干扰明显度 |
|---|---|---|---|---|---|
| '1' | 简单 | 5 | 12 | 4 | 明显：palette 对比色 / scale 1.4·0.7；无位移 |
| '2' | 普通 | 6 | 16 | 5 | 中等：近似色 ±18~28% / scale 1.25·0.8 / 位移 10~16px |
| '3' | 困难 | 8 | 20 | 6 | 细微：近似色 ±5~13% / scale ±0.08~0.13 / 位移 5~9px |

- **运行时状态**：`state = { level, round, cards:[{svgKey, isTarget, marked}], targetKey, markedCount, targetTotal, errors, won, startMs, ms, timerId }`。

### 4.2 元素库与出题

- `window.ELEMENTS`（73 元素平铺池，复用找相同 elements.js；`draw({fill,variant})` 参数化 + `palette`/`variantMax` 元数据）。
- `newRound()`：`pickRoundElement()`（本局不重复抽取）→ 目标参数 `{fill, variant:0, s:1, dx:0, dy:0}` → 生成 M−K 个**视觉上确实不同**的干扰项（渲染签名去重）→ 目标 K 份 + 干扰 M−K 份 → Fisher-Yates 洗牌。

### 4.3 差异引擎与干扰项去重（渲染签名）

- **4 种差异操作** `applyOp`（recolor/scale/variant/move），难度控制强度（同找相同）。
- **去重键 = 渲染结果字符串** `elementCardSvg(e, p)`（`<svg class="card-svg" viewBox="-50 -50 100 100">` + translate/scale 变换 + draw 内层）——部分元素 draw 忽略 fill/variant，参数签名不足，必须渲染级去重（找相同同款修复经验）。
- **fallback 去重**：主循环 60 次 guard 未成功时，**scale 递增（1.25→2.6 阶梯）逐个验证渲染签名可用**（初版 fallback 固定 1.5 导致多干扰项重复——v1.0 已修复），保证任意元素都能生成足够数量的互异干扰项。

### 4.4 交互与判定

- `onCardTap(idx)`：卡已划忽略；`isTarget` → 划掉（`marked` + 计数 + `popMark` 动画 + 进度更新）+ 划满 K 个 → 500ms 后 `nextRoundOrWin()`；非目标 → 红闪 + `errors++` + `updateErrorsUI()`。

### 4.5 计时

- `startTimer()`：`performance.now()` + `setInterval(100ms)` 差值刷新 `'⏱ ' + fmtTime(ms)`（秒 + 1 位小数）；进入游戏页即开始。
- v1.0 无断局恢复。

### 4.6 星级与最佳成绩

- **星级**（按划错次数）：★★★ 0 错；★★ ≤2 错；★ 其余（过关即有）。
- **最佳判定 `betterThan`**：星级高优先，同星级比用时短；最近/历史同系列模式。

### 4.7 持久化（localStorage）

- key：`redtools.huaxiaoxunlian.v1`。
- 结构：`{ version:1, best:{}, recent:{}, checkin:{dates,streak}, history:[...] }`。
- 读写 try/catch；`loadStore()` 校验 version + 补全字段；打卡 `doCheckin()` YYYYMMDD 去重 + 365 滚动 + `calcStreak()` 含今天往前推。

### 4.8 音效（Web Audio 合成）

```js
sndCorrect: triangle 523Hz 0.09s   // 划对（清脆）
sndWrong:   square 150Hz 0.12s     // 划错（低沉）
sndWin:     523/659/784/1047 琶音
```

`AudioContext`（含 `webkitAudioContext`）懒创建 + 用户手势 `resume()`；try/catch 降级。

### 4.9 视图结构

- 三个视图 + 浮层：难度选择页 / 游戏页 / 打卡日历页；结算浮层（星级 + 统计 + 打卡 + 三按钮）。
- 卡片网格 4 列 `float:left` + `width:25%` + `padding-bottom:100%` 正方形（Chrome 61 兼容）；`:after` 清浮动；打卡日历 7 列网格同系列。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：ES2017 经典脚本（var + function），无 `?.`/`??`/对象展开/`replaceAll`/module/import；无内联事件/eval；事件 `addEventListener`；无 fetch/XHR/Worker；localStorage try/catch。
- CSS：无 `gap`/`aspect-ratio`/`clamp()`/`inset`/逻辑属性/`:has`/`@container`/`dvh`；flex 三重前缀；动画双写前缀（`popMark`/`wrongFlash`/`popCard` ≤400ms 无频闪）；正方形卡片 `width`+`padding-bottom` %；安全区 `env(safe-area-inset-*)`。
- 触控/光敏：hit area ≥48px；动画温和无频闪。
- 资源：全部内联/本包；无外部 URL；图形 SVG 代码生成 + 音效 Oscillator → **零图片零音频零数据文件**。
- 包体：0.03 MiB（≪ 2 MiB 建议值）。

## 8. 与系列规范的关系

- **系列归属**：`教育工具产品矩阵规划.md` §4.1 专注力训练（P2 划消训练）→ `series/益智/专注力/` 子系列第 3 款；适用 K1-3–K4-6（L2–L3）。
- **可复用核心**：计时/成绩/打卡对齐 `series/益智/设计文档.md` §4；Chrome 61 / 交互合规对齐 §5；**元素库与差异引擎对齐 §6（找不同 scenes.js 73 元素）+ 找相同渲染签名去重经验**——直接复用 elements.js 与 applyOp/buildDistractors。
- **与找相同的关系（进阶玩法）**：找相同 = 单选（1 个唯一一致，点对即过关）；划消训练 = **多选 K（全部一致都要划掉）** + 卡片数/目标数拉满（12~20 卡）→ 抗干扰强度显著提升；同差异引擎、同去重方案。
- **扩展**：`LEVELS` 可加轮数/卡片数/目标数档位；元素库增补即扩题；后续可加「按特征划消」（划掉所有红色/圆形，进阶分类注意）。
