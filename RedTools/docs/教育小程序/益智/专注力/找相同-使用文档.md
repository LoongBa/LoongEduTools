# 找相同 — 使用文档

> 抗干扰专注训练：看上面的目标图案，在下面几张候选里找出**和它一模一样的那一个**，全部找对就过关。
> 适用：手机 / 电脑（点选即可）。
> 版本：v1.0 · 更新：2026-09-19

---

## 1. 怎么练

1. 打开工具，在**难度选择页**选一个难度：简单 5 轮 / 普通 6 轮 / 困难 8 轮。
2. 每轮顶部有一张**目标图案**（大卡，带"目标"标签），下面有 3~5 张**候选卡**——其中**恰好 1 张**和目标一模一样，其余都"差一点"（颜色、大小、位置、部件不同）。
3. **点选与目标一模一样的那张**：
   - 找对：卡片变绿，自动进入下一轮；
   - 找错：卡片红闪一下，错误次数 +1，再点别的继续找。
4. 所有轮次都找对，就过关啦！每局都是程序随机生成的新图案组合，孩子不会背答案。

## 2. 练习规则

| 规则 | 说明 |
|---|---|
| 目标 | 找出一轮中与目标图案**完全一致**的唯一候选 |
| 操作 | 点选候选卡（无需拖拽）；错误不换题，可继续重试 |
| 干扰项 | 颜色 / 大小 / 位置 / 部件变体 4 种差异，三档难度控制差异明显度 |
| 轮数 | 简单 5 轮 · 每轮 3 选 1；普通 6 轮 · 4 选 1；困难 8 轮 · 5 选 1 |
| 错误 | 点错计 1 次（无惩罚、不扣分），底栏显示 `❌ N` |
| 星级 | 0 错 3★ / 1~2 错 2★ / 3 错及以上 1★（通关即有） |
| 技巧 | 先记住目标特征（颜色、形状、大小），再逐张排除 |

## 3. 界面说明

- **难度选择页**：三个难度卡片，显示该难度**最佳成绩**（星级 · 用时 · 错误次数），底部是打卡日历入口。
- **顶栏**：`← 返回`、当前难度名、`⏱ 用时`（**进入练习页即开始**计时，整局计时）。
- **轮次指示**：练习页上方「第 x/y 轮」。
- **目标卡**：大号图案，带"目标"标签，一眼可辨。
- **候选卡**：正方形网格（3/4/5 张），点选反馈绿闪/红闪。
- **错误计数**：练习页底栏 `❌ N` 实时显示本局点错次数。

## 4. 成绩与打卡

- **星级**（按本局点错次数，宽松友好）：一次没点错 ★★★；点错 1~2 次 ★★；3 次及以上 ★。
- 每过关一局即点亮**今日打卡**；打卡日历显示本月打卡与连续天数（连续 7 天及以上有 🎉）。
- 各难度分别记录**最佳成绩**（星级高优先，星级相同比用时短）；**最近用时**与最近 **30 局**成绩记录自动保存。
- 全部数据保存在本地（localStorage），离线可用、不联网上传。

## 5. 小贴士

- 候选里**干扰项只差一点**：先看目标是什么颜色（比如红苹果），候选里绿苹果/小苹果/歪苹果都不是，找红苹果。
- 点错了不着急，卡片不会消失，红闪一下接着试，孩子压力小。
- 想换一组图案？练习中点「重新开始」用相同难度重抽一局，或点「返回难度」换档。
- 困难档的干扰差异最细微，适合已经熟练的孩子挑战眼力。
- 每局图案由程序随机生成（73 种图案库），不会重复出题。

## 6. 常见问题

**Q：点错会不会扣分或结束练习？**
不会。点错只计错误次数（影响星级），卡片留在原地可以继续点，直到找对为止，全程无惩罚。

**Q：为什么有时候两张候选看起来一模一样？**
这是**程序生成缺陷防护**的体现——所有候选在生成时都会校验"和目标的渲染结果必须不同、彼此也必须不同"（150 轮 × 5 轮专项扫描 0 重复），保证每轮**恰好只有 1 张**正确候选，不会有"看着一样点错"的情况。

**Q：每局要练多久？**
简单 5 轮、普通 6 轮、困难 8 轮，每轮 3~5 选 1，快的话 1~2 分钟一局，适合碎片时间训练。

**Q：适合几岁的孩子？**
定位低龄（preK 到小学低年级）。简单档差异明显（颜色对比强、大小差异大），适合刚开始的孩子；困难档差异细微，适合大一点的孩子挑战。

**Q：成绩怎么清除？**
目前没有「清空成绩」按钮。成绩保存在设备浏览器的 localStorage 中，清除浏览器数据即可清空；换设备不会同步，请注意。
