## 2. 玩法设计

### 2.1 规则

- 每局 N 轮（按难度）。每轮：
  1. **标记阶段**：棋盘上 N 个**完全相同的泡泡**缓慢漂移，唯一目标泡泡**橙色高亮 1.5s**（「记住这个泡泡！」）；
  2. **追踪阶段**：高亮消失（所有泡泡外观一致），泡泡继续漂移 N 秒——孩子必须**用眼睛追踪**目标泡泡；
  3. **停止阶段**：全部泡泡停止（「点一下目标泡泡现在的位置」），孩子点出目标 → 点对绿闪进下一轮；点错红闪 + 错误计数（可重试）。
- 全部轮次完成即过关。

### 2.2 操作

| 输入 | 说明 |
|---|---|
| 点泡泡 | 停止阶段：判是否目标；标记/移动阶段忽略（移动中泡泡点击无效） |
| 底栏按钮 | 「返回难度」/「重新开始」（同难度重抽一局） |
| 顶栏按钮 | 「← 返回」回难度页 |

### 2.3 反馈

- **标记**：目标泡泡橙色光环 + 放大（`target` 类）1.5s + 提示音。
- **点对**：目标泡泡绿闪（`flash-ok` 400ms）+ 轻音效 + 「找到啦！第 x 轮」→ 600ms 后下一轮。
- **点错**：泡泡红闪（`wrongFlash 0.4s`）+ 低音效 + 错误计数 +1 + 提示「不是它，再找找」。
- **音效**（Web Audio `OscillatorNode` 合成，零音频文件）：标记轻音 / 点对清脆 / 点错低沉 / 胜利琶音。

## 4. 技术设计

### 4.1 数据模型

- **难度常量 `LEVELS`**：

| key | 难度 | 轮数 | 泡泡数 | 追踪时长 |
|---|---|---|---|---|
| '1' | 简单 | 5 | 6 | 3s |
| '2' | 普通 | 6 | 8 | 4s |
| '3' | 困难 | 8 | 10 | 5s |

- **运行时状态**：`state = { level, round, bubbles:[{x,y,vx,vy,iconId}], targetIdx, iconId, phase:'mark'|'move'|'stop', moveTimer, phaseTimer, errors, won, startMs, ms, timerId }`。

### 4.2 出题与泡泡

- 每轮从 `window.ICONS`（24 图标）任选一个 → **所有泡泡渲染同一图标**（外观完全一致，唯一线索 = 追踪；无"找不同"特征可用）。
- 泡泡初始位置棋盘内随机；运动 `vx/vy` 随机（0.6~2.0 px/帧）——简单/普通/困难档速度相同，靠**数量 × 时长**递增难度（低龄友好，不靠速度压人）。
- `targetIdx` 随机指定；每轮独立。

### 4.3 动画（setInterval 步进，Chrome 61 兼容）

- `startMove()`：`setInterval(50ms)` 步进 `stepMove()`——每帧更新每泡 `x/y`（`b.x += vx`）+ **边界反弹**（触边反向）+ 偶发（2% 概率）轻微变速换向 `clampSpeed`（限速 0.4~3.2 px/帧，增加迷惑性防直线往返）。
- 泡泡 DOM `left/top` 直接更新（绝对定位，无 transform 依赖）；泡泡 `border-radius:50%` + 内嵌 SVG 图标。
- 移动持续 `lv.moveMs` 后 `clearInterval` → `phase='stop'`。
- `setTimeout` 句柄（`phaseTimer`）统一管理，切视图/重开清理（防泄漏）。

### 4.4 交互与判定

- 标记阶段 `markTarget(true)`（目标 `target` 类橙色光环）→ 1.5s 后 `markTarget(false)` + `startMove()`。
- `onBubbleTap(idx)`：仅 `phase==='stop'` 生效；`idx === targetIdx` → 绿闪 + 600ms 后 `nextRoundOrWin()`；否则红闪 + `errors++`（可重试点）。

### 4.5 计时

- `startTimer()`：`performance.now()` + `setInterval(100ms)` 差值刷新 `'⏱ ' + fmtTime(ms)`（秒 + 1 位小数）；进入游戏页即开始。
- v1.0 无断局恢复。

### 4.6 星级与最佳成绩

- **星级**（按点错次数）：★★★ 0 错；★★ ≤2 错；★ 其余（过关即有）。
- **最佳判定 `betterThan`**：星级高优先，同星级比用时短；最近/历史同系列模式。

### 4.7 持久化（localStorage）

- key：`redtools.shijuezhuizong.v1`。
- 结构：`{ version:1, best:{}, recent:{}, checkin:{dates,streak}, history:[...] }`。
- 读写 try/catch；`loadStore()` 校验 version + 补全字段；打卡 `doCheckin()` YYYYMMDD 去重 + 365 滚动 + `calcStreak()` 含今天往前推。

### 4.8 音效（Web Audio 合成）

```js
sndClick:   sine  392Hz 0.06s    // 标记提示（轻）
sndCorrect: triangle 523Hz 0.09s // 点对（清脆）
sndWrong:   square 150Hz 0.12s   // 点错（低沉）
sndWin:     523/659/784/1047 琶音
```

`AudioContext`（含 `webkitAudioContext`）懒创建 + 用户手势 `resume()`；try/catch 降级。

### 4.9 视图结构

- 三个视图 + 浮层：难度选择页 / 游戏页 / 打卡日历页；结算浮层（星级 + 统计 + 打卡 + 三按钮）。
- 棋盘 `.vt-board`（`position:relative; height:380px; overflow:hidden`）承载绝对定位泡泡；打卡日历 7 列网格同系列。

## 5. 合规自检（Chrome 61 / 容器规范）

- JS：ES2017 经典脚本（var + function），无 `?.`/`??`/对象展开/`replaceAll`/module/import；无内联事件/eval；事件 `addEventListener`；无 fetch/XHR/Worker；localStorage try/catch；定时器句柄统一管理（`moveTimer`/`phaseTimer`/`timerId` 切视图清理）。
- CSS：无 `gap`/`aspect-ratio`/`clamp()`/`inset`/逻辑属性/`:has`/`@container`/`dvh`；flex 三重前缀；动画双写前缀（`wrongFlash`/`popCard` ≤400ms 无频闪）；安全区 `env(safe-area-inset-*)`。
- 触控/光敏：泡泡/按钮 hit area ≥48px；动画温和（标记 1.5s 光环为静态高亮，非频闪）。
- 资源：全部内联/本包；无外部 URL；图形 SVG 代码生成 + 音效 Oscillator → **零图片零音频零数据文件**。
- 包体：0.02 MiB（≪ 2 MiB 建议值）。
