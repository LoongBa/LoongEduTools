## 3. 技术方案

### 3.1 线稿设计（程序化几何构图，零图片素材）

```js
// 6 主题：{id, name, w:320, h:260, parts:[{id, name, svg}]}
// parts.svg = 绝对坐标 shape（circle/rect/ellipse/polygon，全部自闭合）
// 渲染：shape 追加 fill=当前色 + stroke=#4a4a4a stroke-width=4（深色线稿边框）
```

| 主题 | 分区 | 构图 |
|---|---|---|
| 太阳 | 9（日轮+8 光芒） | circle + ray() 极坐标光芒三角 |
| 苹果 | 4（果身/柄/叶/高光） | ellipse + rect + 旋转椭叶 |
| 小花 | 9（6 花瓣+花心+茎+叶） | 6 花瓣绕心 60° 旋转 + circle + rect + 叶 |
| 房子 | 7（墙/顶/囱/门/2 窗/小太阳） | rect 组合 + 三角屋顶 polygon |
| 小鱼 | 5（身/尾/鳍×2/眼） | ellipse + 三角尾鳍 polygon |
| 大树 | 6（3 树冠+干+草地+小草） | 三圆树冠 + rect 干 |

- 分区热区：每区 `g.art-part[data-id]` 点击（事件委托找最近 data-id），命中 ≥30px 实际尺寸（儿童友好）
- 颜色无对错：`isComplete = 全部 part 颜色 ≠ 白色/#ffffff`

### 3.2 持久化（redtools.color.v1）

```js
{ version:1,
  works: { themeId: { date, colors: { partId: hexColor } } },  // 每主题一份，重涂覆盖
  checkin: { dates, streak },
  history: [ {date, theme, blocks} ] }   // 滚动 30 条
```

### 3.4 关键实现点

- **渲染**：`p.svg.replace(/\s*\/>/, ' fill="c" stroke="..." stroke-width="4"/>')` 给自闭合 shape 追加属性（注意保留 `/`）
- **填色**：点区后 `shape.setAttribute('fill', curColor)`（重涂即改色）；调色板选中态 outline 高亮
- **完成打卡**：`isComplete` 触发 → 当日首次打卡 + 作品保存
- 合规：ES2017、addEventListener、无 gap/aspect-ratio/clamp/:has、CHROME 61 CSP 自检

## 4. 交互流程

```
首页（已涂作品 x 幅 + 连续打卡 → 开始涂色/作品集）
  ├─ 开始涂色 → 6 主题网格 → 填色页
  │    进度(已涂 x/y 块) + 大线稿(点区填色) + 调色板(10 色+橡皮)
  │    全部涂满 → "完成啦！🎉" + 自动打卡 + 作品保存
  ├─ 作品集 → 已涂作品网格（点击回看/继续改）
  └─ 打卡日历 / 家长面板（标题连点 5 次）
```
