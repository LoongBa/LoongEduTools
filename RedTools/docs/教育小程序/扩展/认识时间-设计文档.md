## 2. 功能需求

### 2.1 核心功能

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| F1 | **学习模式「认识钟面」** | SVG 钟面（12 数字刻度 + 整点大刻度 + 5 分钟小刻度 + 时针短粗深色 + 分针长细亮色 + 中心点）；「整点」（分针指 12）/「半点」（分针指 6）切换按钮 + 讲解文案；示例 3:00 / 3:30 | ✅ 已实现 |
| F2 | **读钟题「读一读」** | 随机目标时间渲染 SVG 钟面，4 选 1 选项；干扰 = ±1 小时 / ±5 分钟 / 整点↔半点变体（去重取 3，**严格 4 选项 2×2**）；即时反馈 600ms/1400ms | ✅ 已实现 |
| F3 | **拨钟题「拨一拨」** | 目标时间大字（"7:00"+ 中文"七点整"）；**小时预置为目标**（分步教学，先定小时再拨分针），分针从 45 分起拨；交互：①点击表盘 → 分针吸附最近 5 分钟刻度 ②+15/−15 步进按钮；「检查」分钟差 <2.5 判对；容错：差 X 分提示鼓励再试，**重试 ≤3 次**后显示正确答案并判错 | ✅ 已实现 |
| F4 | **三阶段渐进解锁** | 阶段 1 整点（m∈{0}）→ 阶段 2 半点（m∈{30}）→ 阶段 3 混合；每阶段 10 题（读钟 5 + 拨钟 5 交替）；完成 ≥80% 解锁下一阶段 | ✅ 已实现 |
| F5 | **打卡 + 星星 + 成绩** | 完成一次练习即打卡（日历火苗 + 连续天数）；星星按阶段记录（全对 3★ / ≥80% 2★ / ≥60% 1★）；成绩滚动 30 条 | ✅ 已实现 |
| F6 | **家长面板** | 标题 5 秒内连点 5 次进入：累计打卡/连续打卡/累计答题/累计答对/已解锁阶段 + 各阶段星星 + 清除数据 | ✅ 已实现 |

### 2.2 关键交互决策（拨钟题的演进）

| 版本 | 交互 | 问题 | 结论 |
|---|---|---|---|
| 初版（agent 自动变更） | 从 12:00 起拨 + 点击全联动（时针+分针同驱） | 点击表盘 3 点位置分针吸到 15 分，**永远无法精确拨到整点/半点** | ❌ 不可用 |
| **交付版** | **小时预置为目标 + 分针独立吸附**（点击 = 分针到最近 5 分钟刻度，12 点=0 分、6 点=30 分）+ ±15 步进 + 直出提示 | 符合教具分步教学（先定小时再拨分针），一次点击可达目标（阶段内 m 仅 0/30） | ✅ 采用 |

> 经验：低龄拨钟类工具，**指针联动驱动的"自由拨针"对 3-8 岁过难**；"预置小时 + 分针定位"才能一次点达。

## 3. 技术方案

### 3.1 SVG 钟面渲染（零图片素材）

```js
// viewBox 0 0 200 200，圆心 (100,100) 半径 92
// 时针角 = (h%12)*30 + m/2 分针角 = m*6（0°=12 点，顺时针）
// 60 个 5 分钟小刻度（细 #c9cdd4）+ 12 个整点大刻度（粗 #1f2329）+ 数字 1-12
// 时针 line stroke-width 7 #1f2329；分针 stroke-width 4 #165dff；中心圆 r=6
// transform="rotate(angle 100 100)"；拨钟题 svg 挂 click → 分针吸附
```

- 字符串模板拼接 innerHTML（Chrome 61 兼容，无 SVG DOM API 依赖）
- 分针吸附：`m = Math.round(deg/30)*5 % 60`（deg = atan2(dx,-dy) 换算 0°=12 点顺时针）
- 点击忽略区：距圆心 <30（中心圆内）或 >92（表盘外）

### 3.2 持久化（redtools.time.v1）

```js
{
  version: 1,
  unlockedStage: 1,                    // 渐进解锁阶段
  profile: { totalAnswer, totalCorrect, stageStars: {1..3: n} },
  checkin: { dates: ["YYYYMMDD"], streak },   // 滚动 365 天
  history: [ {date, stage, rate, count, correct, stars} ]  // 滚动 30 条
}
```

### 3.4 Chrome 61 / 交互合规

- JS：ES2017 经典脚本、addEventListener、无内联事件/eval；CSS 无 gap/aspect-ratio/clamp/:has/@container/dvh
- 按钮/表盘热区 ≥48px；无强计时（L1-L2 无计时挑战，鼓励为主）
- 首页 `.view.home` flex + `min-height:100%` + `justify-content:center`（整体垂直居中，上下留白均分）
- localStorage 带 version + 迁移兜底；CSP 自检全过

## 4. 交互流程

```
首页（进度卡 + 2 入口，整体垂直居中）
  ├─ 认识钟面 ────► 钟面 + 整点/半点切换 + 讲解
  ├─ 开始练习 ────► 阶段选择（1 整点 / 2 半点 / 3 混合，未解锁 🔒）
  └─ 底部导航：打卡日历 / 首页
练习页（10 题，读钟/拨钟交替）：
  读钟：钟面 + 4 选 1（对✓600ms / 错✗+答案 1400ms）
  拨钟：目标大字 + 可点钟面（点击拨分针）+ ±15 + 检查（<2.5 分判对；容错 3 次）
  └─ 结果页（正确率/星星/答对/阶段/打卡 + 解锁提示）→ 再来一组 / 返回
家长面板：标题连点 5 次
```
