## 系列原则

1. **零素材优先**：钟表/钱币/动物等一律程序化 SVG/CSS 绘制，不引入图片素材（符合离线包体 ≤2 MiB 目标）。
2. **低龄交互**：preK–K1-3 目标，按钮/点击热区 ≥48px，无强计时压力（L1-L2 以鼓励为主）。
3. **复用模式**：打卡/星星/成绩/家长面板等通用能力直接复用数学口算/乘法口诀练习的 localStorage 模式。
4. **合规**：遵守 `RedTools/.skill/minitool-zip-builder/` 规范（离线、CSP、白名单、Chrome 61）。
