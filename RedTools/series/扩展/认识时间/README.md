## 需求摘要（草案）

- **钟表认知专项**：认识钟面（时针/分针/刻度）+ 整点/半点读写，低龄数学启蒙（对标实体教具钟表）
- 目标用户：preK–K1-3（L1–L2），3-8 岁
- 形态：离线 zip，纯前端静态工具（`datasource="static"`），**程序化 SVG 钟面零素材**，目标 ≤ 2 MiB
- 核心功能：
  - F1 学习模式：认识钟面（12 个数字刻度 + 时针/分针），整点讲解（分针指 12、时针指几点）+ 半点讲解（分针指 6、时针走过半点）
  - F2 读时间题：显示钟面（指针角度），4 选 1 选正确时间（整点阶段选项为整点；半点阶段含 x:30；混合阶段含任意）
  - F3 拨钟题：显示目标时间（文字 + 数字），孩子把指针拨到正确位置（点击表盘刻度拨分针到最近 5 分钟档，时针随分针联动 30°/小时），点「检查」核对
  - F4 三阶段：整点（L1）→ 半点（L2）→ 混合（L2+），每阶段 10 题；进度解锁（整点完成 ≥80% 解锁半点）
  - F5 每日打卡 + 星星 + 成绩记录：完成即打卡；星星按阶段记录（全对 3★ / ≥80% 2★ / ≥60% 1★）
  - F6 家长面板：标题 5 秒内连点 5 次进入（累计打卡/答题/阶段进度/清除数据）
- 复用：打卡/星星/成绩/家长面板 localStorage 模式（key `redtools.time.v1`）、build_framework `copy_static`
- 交互细节：
  - 拨针用**点击表盘**（分针吸附到最近 5 分钟刻度）+ **+15 分钟快进按钮**（低龄孩子无需精密拖拽）
  - 时针联动：分针角度 → 时针 = 小时*30° + 分/60*30°（真实钟表联动）
  - 时间校验：目标时间与当前指针时间按分钟差 <2.5 分钟判对（容差）
  - 读钟题选项：干扰项为 ±1 小时 / ±5/10 分钟的整点半点变体
- 合规：Chrome 61 基线（ES2017 / 无 gap/aspect-ratio/clamp/:has）、CSP 无内联脚本、按钮 ≥48px
