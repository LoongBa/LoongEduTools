|---|---|---|

```json

  "成语": "守株待兔",

  "例句": "小明守株待兔，不努力学习，成绩越来越差了。",
  "出处": "《韩非子·五蠹》",
```

- `年级`：出现过的年级并集（[] = 通用，来自日积月累分类）；`emoji` 仅看图猜成语用，未配图为空字符串
- 接龙扩展层无 年级/册/主题/emoji，释义为底库原文（仅接龙展示用）

## 数据来源与版本口径

1. **底库**：`mapull/chinese-dictionary`（MIT，49,639 条）→ 拼音/释义/出处/例句
2. **课本清单 5 源**：sohu 部编版 1-6 下册 + yuwenmi 人教版全 12 册 + sohu 日积月累分类 + 新课标 1-2 年级人工确认（`_shared` 未收录，见 temp 工作区）+ XiaoShuTong 三年级
3. **年级标签版本口径**（重要）：
   - 1-3 年级 → 新课标版（2024 修订，已全部启用）
   - 4-6 年级上册 → 新课标版（2026 秋启用）
   - 4-6 年级下册 → 老版统编代替（新课标 2027 春才出版，**出版后需校准**）
4. **释义改写**：975 条全部改写成小学口吻（1-2/3-4/5-6 三个难度档），例句同步改写为校园/生活场景
5. **emoji**：243 条配画面式直译 emoji（Chrome 61 安全字符集），供看图猜成语
