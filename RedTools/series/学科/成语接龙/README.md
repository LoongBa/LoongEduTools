## 定位

- **教学转化款**：学科类核心变现工具，同时兑现教育工具产品矩阵规划 P2「成语配对」
- 与「看图猜成语」共用同一份课本成语词库，独立发布、独立迭代
- 差异化：强调**成语积累 + 接龙策略**，教学价值高于传播属性

## 目标用户

| 用户 | 场景 | 诉求 |
|------|------|------|
| 小学生 3-6 年级 | 课间 / 家庭作业辅助 | 巩固课本成语，积累词汇量 |
| 家长 | 亲子接龙对战 | 陪孩子学，检验积累 |
| 教师 | 课堂成语复习 | 趣味复习工具 |

## 玩法需求

### 玩法 A：成语接龙（核心）

- **规则**：系统出首条成语 → 玩家用**尾字**接一条以该字开头的成语（如 一石二鸟 → 鸟语花香）
- **词库校验**：内置 `CHENGYU_DATA` 做合法判定（离线，无网络词典）
- **接龙索引**：词库预建 `尾字 → 以该字开头的成语列表` 索引（data.js 生成时附带）
- **关键交互**：
  - **提词按钮**：卡壳时点击，给一条可接成语的首字提示（降低挫败）
  - **同音容忍开关**：低年级可开，同音字也可接（门槛大降）
  - **死路检测**：当前尾字无词可接时，系统自动判定并换题/结算
  - **限时模式**：每步限时（可关）
- **结算**：接龙长度 + 用时 → 星级 → 成绩记录 + 打卡

### 玩法 B：成语配对（P2 落地）

- 模式 1：四选一（给成语选释义 / 给释义选成语）
- 模式 2：连线配对（成语 ↔ 释义 打乱连线）
- 复用数学口算「即时反馈 + 连击 + 错题本」框架

## 词库需求（共享词库）

- 与「看图猜成语」共用一份源数据：`series/学科/_shared/成语词库/成语词库.json`
- 300~500 条课本核心成语（覆盖 1-6 年级语文课本），字段：
  `成语 / 释义（自写，公共领域）/ 造句 / 年级标签 / 主题标签 / 首字 / 尾字 / emoji 拼图（本工具忽略）`
- **接龙可用性**：词库需保证常见尾字有 ≥2 条可接成语，避免死路过多（整理时按尾字密度检查）

## 构建方案

- `datasource="chengyu"`（build_framework 新增类型，**向后兼容**，与看图猜成语共用）：
  1. 复制 src/（同 static）
  2. 读 `_shared/成语词库/成语词库.json` → 生成 `assets/chengyu_data.js`
     （`window.CHENGYU_DATA = [...]` + 预建尾字接龙索引 `window.CHENGYU_CHAIN = {...}`）
  3. 图标复用 make_static_icon
- Chrome 61 基线：经典脚本 + ES2017，无 fetch/网络
- 合规：纯文本数据零素材版权风险（成语公共领域，释义自写）

## 待办 / 风险

- ⚠️ 接龙体验依赖词库尾字密度：整理阶段必须做「尾字 → 可接数」统计，密度不足的尾字补词或标死路
- ⚠️ 小学生词汇量有限：提词 + 同音容忍是刚需，默认开提词，同音容忍默认关（高年级挑战性）
- 错题本对接龙类玩法（开放性作答）适配度低，错题本主要服务配对玩法；接龙记录成绩+长度即可
