# 看图猜成语（学科系列）

> 完整设计将在立项确认后写入 `docs/工具文档/学科/看图猜成语-设计文档.md`。

## 定位

- **传播爆款单品**：宝妈最爱转的裂变款（对标「看图猜成语」裂变 H5），零认知成本
- 产品矩阵映射：学科类 · 语文基础补充款（成语方向，与规划 P2「成语配对」同属成语系列）
- 与「成语接龙」共用同一份课本成语词库，独立发布、独立迭代

## 目标用户

| 用户 | 场景 | 诉求 |
|------|------|------|
| 小学生 1-6 年级 | 课间 / 碎片时间 | 玩中学，猜对有成就感 |
| 家长 | 亲子互动 / 朋友圈分享 | 检验孩子成语积累，晒成绩 |
| 教师 | 教室投影课堂互动 | 成语复习游戏化 |

## 玩法需求

- **核心玩法**：emoji/图形序列拼出一个成语（🪨🐦🐦 = 一石二鸟），用户输入/点选猜成语
  - 猜不出 → 「看答案」→ 展示 释义 + 造句 + 年级标签
  - 答对 → 即时反馈 + 连击 + 加分
- **关卡/难度**：按 1-2 年级 / 3-4 年级 / 5-6 年级 分级出题（词库年级标签驱动）
- **每日挑战**：每日固定一局（如 10 题），可打卡（复用通用打卡能力）
- **激励**：连击 + 星星 + 成绩记录 + 分享卡片（复用数学口算已验证框架）
- **家长面板**：可看孩子成绩曲线（后置 P1，参考数学口算）

## 词库需求（共享词库）

- 与「成语接龙」共用一份源数据：`series/学科/_shared/成语词库/成语词库.json`
- 300~500 条课本核心成语（覆盖 1-6 年级语文课本），字段：
  `成语 / 释义（自写，公共领域）/ 造句 / 年级标签 / 主题标签（数字/动物/颜色/叠字/自然/人物）/ 首字 / 尾字 / emoji 拼图`
- emoji 拼图为本玩法专用字段（接龙工具忽略）
- 数据量估算 ≈ 150~300KB 纯文本，包体无压力

## 构建方案

- `datasource="chengyu"`（build_framework 新增类型，**向后兼容**）：
  1. 复制 src/（同 static）
  2. 读 `_shared/成语词库/成语词库.json` → 生成 `assets/chengyu_data.js`（`window.CHENGYU_DATA = [...]`）
  3. 图标复用 make_static_icon（无角标或固定角标）
- Chrome 61 基线：经典脚本 + ES2017，词库数据用经典对象，无 fetch/网络
- 合规：纯文本数据零素材版权风险（成语公共领域，释义自写）
