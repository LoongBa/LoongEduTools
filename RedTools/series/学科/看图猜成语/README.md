# 看图猜成语（学科系列）

> 状态：**✅ v1.0 已交付（2026-09-20）**。
> 设计/使用文档：`docs/教育小程序/学科/看图猜成语-{设计,使用}文档.md`。

## 定位

- **传播爆款单品**：宝妈最爱转的裂变款（对标「看图猜成语」裂变 H5），零认知成本
- 产品矩阵映射：学科类 · 语文基础补充款（成语方向，与规划 P2「成语配对」同属成语系列）
- 与「成语接龙」共用同一份课本成语词库，独立发布、独立迭代

## 目标用户

| 用户 | 场景 | 诉求 |
|------|------|------|
| 小学生 1-6 年级 | 课间 / 碎片时间 | 玩中学，猜对有成就感 |
| 家长 | 亲子互动 / 朋友圈分享 | 检验孩子成语积累，晒成绩 |
| 教师 | 教室投影课堂互动 | 成语复习游戏化 |

## 玩法需求

- **核心玩法**：emoji/图形序列拼出一个成语（1️⃣❤️1️⃣ = 一心一意），4 选 1 点选猜成语（零输入法门槛）
  - 猜不出 → 「💡 看答案」→ 展示 拼音 + 释义 + 例句 + 年级标签
  - 答对 → 即时反馈（绿标）+ 连击 + 提示音；答错 → 红闪 + 亮正确答案（即时纠错）
- **关卡/难度**：按 1-2 年级 / 3-4 年级 / 5-6 年级 分级出题（词库年级标签驱动，分池 66/84/121 条）
- **每日挑战**：挑战 10 题（单局不重复）+ 计时星级 + 打卡（复用通用打卡能力）
- **激励**：连击 + 星星 + 成绩记录（best/recent10/history）+ 分享卡片（1080×1920 canvas + 一键复制文案）
- **家长面板**：可看孩子成绩曲线（后置 P1，参考数学口算）

## 词库（共享词库）

- 与「成语接龙」共用一份源数据：`series/学科/_shared/成语词库/成语词库.json`
- 975 条课本核心成语（覆盖 1-6 年级语文课本），字段：
  `成语 / 拼音 / 释义 / 例句 / 年级 / 主题 / 首字 / 尾字 / 字长 / emoji 拼图`
- emoji 拼图为本玩法专用字段（243 条已配）；接龙工具忽略
- 数据量 ≈ 517KB 纯文本（data.js 注入），包体 0.26 MiB

## 构建方案

- `datasource="chengyu"`（build_framework 已有管线，向后兼容）：
  1. 复制 src/（同 static）
  2. 读 `_shared/成语词库/成语词库.json` → 生成 `assets/chengyu_data.js`（`window.CHENGYU_DATA`）
  3. 图标复用 make_static_icon（角标「看图猜成语」）
- Chrome 61 基线：经典脚本 + ES2017，词库数据用经典对象，无 fetch/网络
- 合规：纯文本数据零素材版权风险（成语公共领域，释义自写）；审计 PASS（5 files 0 warning）
