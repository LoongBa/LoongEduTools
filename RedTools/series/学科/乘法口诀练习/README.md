## 需求摘要（草案）

- **九九表聚焦专项**：口诀表学习 + 随机抽查 + 易错专训（与数学口算「全年级通用出题器」错位，不做第二个通用出题器）
- 目标用户：K1-3–K4-6（L2–L3），主攻 2-3 年级，延伸 1/4 年级
- 形态：离线 zip，纯前端静态工具（`datasource="static"`），零素材零音频，目标 ≤ 2 MiB
- 核心功能：
  - F1 口诀表学习页：9×9 笛卡尔口诀卡，点击展开整句口诀（"六八四十八"）；**按行渐进解锁**（1 的口诀 → 9 的口诀，行末小测过关解锁下一行）
  - F2 随机抽查：随机出题（`a×b=?`），`<button>` 数字键盘作答，即时反馈（对✓ / 错✗+正确答案）；**交换律去重**（6×8 与 8×6 只出一道）
  - F3 模式选择：普通练习（10 题）/ ⏱30/60/120s 计时挑战 / 专项模式（指定口诀行）
  - F4 每日打卡 + 星星 + 成绩记录：完成即打卡，全对 3 星 / ≥80% 2 星 / ≥60% 1 星
  - F5 易错专项：错题本按口诀聚合（"6×8 错 3 次"），一键生成该口诀专项组
  - F6 本地历史最佳：各模式最佳成绩榜（替代在线排行）
  - F7 家长面板：标题 5 秒内连点 5 次进入（复用数学口算模式）
- 复用：数字键盘 / 即时反馈 / 计时后台暂停 / 打卡-错题本-成就 localStorage 结构（key `redtools.mul.v1`）
- 出题引擎：纯运行时生成器 `a∈[1,9] b∈[1,9]` + 交换律去重 + `answer=a*b` 反推校验 + 同次防重复
- 合规：Chrome 61 基线（ES2017 / 无 gap/aspect-ratio/clamp/:has）、CSP 无内联脚本、按钮 hit area ≥48×48px
