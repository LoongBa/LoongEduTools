## 1. 产品定位

| 项 | 说明 |
|---|---|
| 工具名 | 数学口算 |
| 系列 | 学科 |
| 对标 | 小猿口算（功能标杆）、宝宝巴士数学（低龄交互）、叫叫口算（激励体系） |
| 形态 | 小红书小工具（离线 zip + H5，Chrome 61 基线，无网络） |
| 目标用户 | 1-6 年级小学生（家长陪练/自习） |
| 核心价值 | **离线可用的口算练习 + 每日打卡 + 分层知识点** |

**差异化机会**（主流 app 普遍需联网）：
1. 完全离线可用（zip 内所有数据）
2. 本地段位 + 历史最佳榜（替代在线排行榜）
3. 简洁无游戏化负担的激励（家长友好）

## 2. 年级与知识点分级体系（v2：按"口算能力子集"修订）

> 依据：课标 2022 + 人教版教材目录 + Oracle 评审修正。
> **核心原则：知识点 = 该单元中适合口算的子集，而非笼统单元名**。
> **三年级是分水岭**（整数→分数、具体→抽象过渡）。

| 年级 | 口算知识点（id） | 口算子集边界（明确题型范围） |
|---|---|---|
| **一年级** | g1_10addsub / g1_20add / g1_20sub / g1_100 | 10 以内加减（分与合/连加连减）；20 以内进位加（凑十法）；20 以内退位减（破十法）；整十数加减、两位数±一位数/整十数（不进位/不退位） |
| **二年级** | g2_mult / g2_div / g2_100 / g2_mixed | 表内乘法（2-9 口诀）；表内除法（口诀求商）；100 以内加减（进位/退位）；混合运算（先乘除后加减/小括号）、有余数除法 |
| **三年级** | g3_wan / g3_mult1 / g3_mult2 / g3_div1 / g3_frac | 万以内加减（几百几十/验算）；整十整百×一位数；**两位数×两位数（口算子集：整十数乘两位数）**；一位数除法（口算/有余数/0 除）；同分母分数加减、1 减几分之几 |
| **四年级** | g4_big / g4_simple / g4_div2 / g4_dec | 亿以内大数（读写/近似数/改写）；**运算定律简便计算（25×4×8、125×8、凑整）**；整十数÷整十数口算、试商；小数读写比较、一位小数加减 |
| **五年级** | g5_decmul / g5_decdiv / g5_frac1 / g5_frac2 | 小数×整数/小数×小数（口算）；小数÷整数/小数÷小数（口算）；约分通分/分数小数互化；异分母分数加减 |
| **六年级** | g6_fracmul / g6_fracdiv / g6_pct / g6_ratio | 分数×分数/分数四则混合口算；倒数/分数÷分数；**百分数互化（25%↔1/4↔0.25）**；**化简比/求比值（不含解比例）** |

**v2 修订说明（对照 Oracle 意见）**：
- 三年级补充 `g3_mult2`（两位数乘两位数口算子集）✅
- 四年级 `g4_mult2`（三位数乘两位数，笔算内容）→ **移除**，改为 `g4_simple`（运算定律简便计算）✅
- 六年级 `g6_ratio` 限定**化简比/求比值**，**排除解比例**（方程笔算非口算）✅
- 六年级 `g6_pct` 限定**互化口算**，不含百分数应用题 ✅

**难度分层**（与年级解耦 4 级，供挑战模式复用）：
- 入门（10 以内）→ 基础（20 以内/表内乘除）→ 提高（100 以内/多位数）→ 挑战（大数/小数/分数混合）

## 3. 功能需求

### 3.1 核心功能（P0）

| 编号 | 功能 | 说明 | 对标 |
|---|---|---|---|
| F1 | **年级+知识点选题** | 首页选年级 → 选知识点 → 进入练习 | 小猿口算 |
| F2 | **随机出题** | 每次随机生成，同配置结果不同；题量 10/20/30/50 可选 | 小猿口算 |
| F3 | **点选作答** | **纯 `<button>` 数字键盘**（禁用 `<input type=number>` 避免 IME 冲突）；可删除/提交 | 叫叫口算 |
| F4 | **逐题即时反馈** | 答对绿✓+连击，答错红✗+显示正确答案 | 练学宝 |
| F5 | **计时挑战** | 30/60/120 秒限时；`performance.now()` + **`visibilitychange` 后台自动暂停**；倒计时+成绩 | 练学宝 |
| F6 | **每日打卡** | 日历火苗点亮 + 连续天数；完成今日任务即打卡 | 叫叫口算 |
| F7 | **错题本** | localStorage 持久化；**上限 500 条 FIFO 淘汰**；连续答对 3 次同类型移除；下次练习优先重练 | 叫叫口算 |

### 3.2 激励体系（v2 精简）

| 编号 | 功能 | 优先级 | 说明 |
|---|---|---|---|
| F8 | **连击** | P0 | 即时反馈核心（答对连击计数） |
| F9 | **每日打卡** | P0 | 习惯养成（与 F6 同一系统） |
| F10 | **星星制** | P0 | 每关 3 星（全对 3 星）解锁下一关 |
| F11 | **成就系统** | P1 | **勋章墙 + 本地段位合并为单一「成就」**（里程碑勋章 + 累计题数/正确率升级段位：青铜→王者），减少游戏化负担 |
| F12 | **今日表现摘要** | P1 | 成绩报告精简：正确率/用时/错题数/薄弱知识点（替代完整报告页） |

**v2 精简说明（对照 Oracle 意见）**：
- ❌ 移除：独立"勋章墙 + 段位"双系统 → 合并为单一「成就」✅
- ⏬ 降级：F12 双人对战 → **P2 后置**（离线场景使用率低，ROI 低）✅
- 保留 P0：连击 + 打卡 + 星星（不过度设计，家长友好）

### 3.3 裁剪说明（离线约束）

| 主流功能 | 处理 |
|---|---|
| 在线 PK/排行榜 | ❌ → 本地段位 + 历史最佳榜（P1） |
| 手写 + OCR 批改 | ❌ → 点选作答（`<button>` 数字键盘） |
| AI 薄弱点诊断 | ⚠️ 错题本知识点统计 + 薄弱优先（v2 待定，见 §4.2） |
| 班级/教师端 | ❌ 不做 |
| 打印题卡 | ⚠️ `window.print()`（P2） |
| 教材版本 | ⚠️ 先人教版，留接口（P2） |

## 4. 出题引擎设计（v2：混合方案 + 反推校验）

### 4.1 生成策略（混合）

| 知识点类型 | 方案 | 理由 |
|---|---|---|
| 简单四则（加减乘除/表内/整十数） | **运行时纯函数生成器** | 算法简单、正确性可控、零体积 |
| 复杂知识点（异分母分数/通分/小数除/百分数互化） | **参数化模板**（题干模板 + 受约束参数，如分母∈{2,3,4,5,6,8,10}） | 保证正确性，体积小 |

### 4.2 反推校验（P0 强制）

- **每个生成器配反推校验函数**：生成题目后用数学运算反向验算答案，校验失败则重新生成。
- 理由：离线小工具不可远程修复，生成器 bug 产出错误题目是**致命伤**，必须生成期自校验。
- 除法保证整除性、分数保证约分后最简、进位/退位按知识点配置过滤。

### 4.3 出题规则

| 规则 | 实现 |
|---|---|
| 随机范围 | 每题随机参数（如 20 以内进位加：和 ≤20 且需进位） |
| 难度过滤 | 按知识点配置范围 |
| 薄弱优先 | 错题本该知识点错题多时，提高该类型权重（见 3.3 AI 诊断简化） |
| 防重复 | 同一次练习内不连续出同一题 |

### 4.4 题目结构

```js
{ type: "g1_20add", text: "9 + 6 =", answer: 15, check: fn(answer) }
// check 为反推校验函数（或生成期已校验，运行时仅存 answer）
```

## 5. 技术方案

### 5.1 数据驱动架构（复用 build_framework）

```
series/学科/数学口算/
├── src/                        # 前端静态资源
│   ├── index.html
│   └── assets/
│       ├── main.js             # 口算逻辑（选题/练习/打卡/错题本/成就）
│       ├── style.css           # Chrome 61 基线样式
│       ├── icon_base.png       # 系列公共图标母版（构建时叠加角标）
│       └── generators.js       # 各知识点出题生成器（纯函数 + 反推校验）
└── README.md
```

- 无 book.json 数据源：知识点/题目全部内置前端。
- `tools.py` 登记 ToolConfig；`build_framework.py` 复用 copy_static / make_icon / package_zip，
  跳过 convert_images / convert_audio（无图片素材、无音频）。

### 5.2 听算（P2，明确降级）

- **开发前必须先真机验证** Android 8.1 WebView 下中文 speechSynthesis 可用性
  （重点测华为/小米/OPPO 低端机——部分国产设备阉割或用户禁用 TTS）。
- 降级路径明确：**TTS 不可用时自动隐藏听算入口，不报错**。
- 听算定位为**增值功能**，非核心（F4 点选是核心）。

### 5.3 持久化（localStorage，v2 修订）

```js
{
  version: 1,                          // ★ 版本字段 + 迁移函数（v1→v2）
  profile: { grade, lastPoint, segment, stars },
  checkin: { dates: ["YYYYMMDD"], streak, longestStreak },
  wrongBook: [ {topic, answer, wrongCount, correctStreak, lastTime} ],  // ★ 上限 500 FIFO
  history: [ {date, topic, rate, avgMs} ],   // ★ 滚动 30 天
  achievements: { unlocked: [...], progress: {...} }
}
```

**v2 修订**：加 `version` 字段 + 迁移函数；错题本上限 500（FIFO）；历史滚动 30 天 ✅

### 5.4 Chrome 61 / 交互合规（v2 补强）

- **数字键盘**：`<button>` 实现，禁用 `<input type=number>`（避免 Android 软键盘/IME 冲突）✅
- **计时**：`performance.now()` + `visibilitychange` 后台暂停（后台标签页 Date.now 被节流）✅
- **分数渲染**：HTML+CSS 上下排列（分子/分母），不用图片；无竖式（口算无竖式）✅
- **触控**：按钮 hit area ≥48×48px（小学生手指粗）；反馈动画避免强闪烁（光敏风险）✅
- **CSS**：禁用 gap/aspect-ratio/clamp/:has/container queries；CSS 变量、flex 基础 OK ✅
- **首屏**：≤1 秒渲染，数据 localStorage 预加载，无"加载中"等待 ✅
- JS：ES2017 经典脚本（无 module/import/export）；无网络请求/外部资源/Worker/eval

## 6. 交互流程

```
首页 ──► 选年级（1-6）──► 选知识点 ──► 练习页
                                      ├─ 随机出题（题量 10/20/30/50）
                                      ├─ button 数字键盘 + 即时反馈（绿✓/红✗ + 连击）
                                      ├─ 计时挑战（可选，后台自动暂停）
                                      └─ 完成 → 今日表现摘要（正确率/用时/错题数）
                                              └─ 打卡（完成即点亮火苗）
首页另有：打卡日历 / 错题本 / 成就（勋章+段位） / 历史最佳
```

## 7. 验收标准

| 项 | 标准 |
|---|---|
| 知识点覆盖 | 1-6 年级（三年级 5 个、其余 4 个/年级，共 25+），每生成器 ≥50 道不重复题 |
| 正确性 | **每个生成器反推校验函数验证**，单元测试覆盖边界（进位/退位/整除/约分） |
| 打卡 | 连续天数计算正确（跨天/缺天） |
| 错题本 | 记录、连续答对 3 次移除、上限 500 FIFO |
| 激励 | 连击/打卡/星星（P0）+ 成就系统（P1）闭环 |
| 体积 | zip ≤ 2 MiB（纯前端无音频） |
| 合规 | 审计 PASS + Chrome 61 自查 + 冒烟测试 |
| 交互 | 数字键盘无 IME 冲突；计时后台暂停；按钮 ≥48px |
