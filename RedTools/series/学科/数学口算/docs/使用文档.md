# 数学口算 — 使用文档

> 适用对象：家长 / 学生（无需读代码即可上手）。
> 适用版本：v1.0（2026-09-18）。
> 本文档描述的功能以实际软件为准，数据仅保存在本机，不联网。

## 1. 这是什么

「数学口算」是一个完全离线的口算练习小工具：覆盖 1-6 年级 25 个口算知识点，支持
普通练习与限时挑战，并内置打卡日历、错题本、成就系统。打开即用，无广告、无网络依赖。

## 2. 如何打开

1. 解压 `publish/学科/数学口算.zip`，或直接使用现成的 `publish/学科/数学口算_解压测试版/` 目录。
2. 双击目录里的 `index.html`，用浏览器打开即可使用。
3. 建议在手机/平板上使用（或电脑浏览器开启手机模式），体验最佳。

> 提示：把解压后的整个文件夹发给家长或孩子，双击 index.html 就能用，无需安装任何软件。

## 3. 首页与底部导航

打开后先看到「选择年级」：一年级 ~ 六年级，共 6 个按钮。

页面底部有 4 个导航入口：

| 入口 | 作用 |
|---|---|
| 打卡日历 | 查看本月打卡火苗与连续打卡天数 |
| 错题本 | 查看做错的题 |
| 成就 | 查看段位、勋章与历史最佳 |
| 首页 | 返回选年级 |

## 4. 完整操作流程

### 4.1 选年级

点击对应年级按钮（如「三年级」），进入该年级的知识点列表。

### 4.2 选知识点

每年级 4-5 个知识点。未练过的显示「未练习」，练过的显示「已获 N ★」。

| 年级 | 知识点 |
|---|---|
| 一年级 | 10 以内加减法 / 20 以内进位加法 / 20 以内退位减法 / 整十数加减 |
| 二年级 | 表内乘法 / 表内除法 / 100 以内加减法 / 混合运算 |
| 三年级 | 万以内加减法 / 整十整百乘一位数 / 两位数乘两位数 / 一位数除法 / 同分母分数加减 |
| 四年级 | 大数改写 / 运算定律简算 / 整十数除法 / 小数加减法 |
| 五年级 | 小数乘法 / 小数除法 / 约分与互化 / 异分母分数加减 |
| 六年级 | 分数乘法 / 分数除法 / 百分数互化 / 化简比求比值 |

### 4.3 选模式

点击知识点后弹出「选择模式」：

- **普通练习（10 题）**：不限时，适合日常练习
- **⏱ 30 秒挑战** / **⏱ 60 秒挑战** / **⏱ 120 秒挑战**：限时出 20 题，拼速度与正确率

### 4.4 练习页

- **顶部**：进度「第 x / N 题」；挑战模式还显示倒计时，剩余 ≤10 秒时计时变红；答对连续 2 题起显示连击 🔥
- **中间**：题目卡片 + 作答区
- **底部**：数字键盘按钮 `1-9`、`.`、`0`、`⌫`（退格）、`✓`（提交）
  - 分数用 `/` 输入（如 `1/2`）；小数用 `.`（如 `0.25`）
  - 整数、小数、分数等价会自动判断（如 `3/2` 与 `1.5` 都算对）
- **即时反馈**：
  - 答对：绿色「✓ 答对了！」，0.6 秒后自动进入下一题，连击 +1
  - 答错：红色「✗ 正确答案：xxx」，1.4 秒后进入下一题，连击清零
- 练习中底部显示「退出练习」，点击返回知识点列表

### 4.5 结果页

做完一组后展示：

- 正确率 %（大号显示）
- 答对 x/N 题、用时、最大连击
- 星星：100% 得 3★ / ≥80% 得 2★ / ≥60% 得 1★
- 两个按钮：「再来一组」重新练同一知识点；「返回知识点」回到知识点列表

> **完成一组即自动打卡**：今天的火苗自动点亮，连续打卡天数随之更新，无需额外操作。

## 5. 各功能模块说明

### 5.1 打卡日历

- 显示本月日历，练过的日子带火苗标记，今天有特殊标记
- 底部显示「连续打卡 N 天」，连续 ≥7 天显示 🎉
- 打卡记录最长保留 365 天

### 5.2 错题本

- 答错的题自动记录：题目 + 答案 + 错 N 次
- 同一道题连续答对 3 次后自动从错题本移除
- 上限 500 条，超出后自动淘汰最早的记录
- 错题本只做记录与查看，不影响出题内容

### 5.3 成就

- **当前段位**：按累计答对数自动升级：青铜 → 白银（50 题）→ 黄金（200 题）→ 钻石（500 题）→ 星耀（1000 题）→ 王者（2000 题），并提示「距下一段位还需 N 题」
- **勋章墙**：共 7 枚勋章，达成条件自动解锁（已解锁 🏅 / 未解锁 🔒）

| 勋章 | 解锁条件 |
|---|---|
| 初学者 | 完成第一次练习 |
| 百题斩 | 累计答对 100 题 |
| 千题王 | 累计答对 1000 题 |
| 全对达人 | 单次练习 100% 正确 |
| 连击大师 | 单次连击 ≥10 |
| 打卡 7 天 | 连续打卡 7 天 |
| 打卡 30 天 | 连续打卡 30 天 |

- **历史最佳**：历史最高正确率 / 最大连击 / 最快用时

### 5.4 家长面板（隐藏入口）

**进入方式**：在顶部标题处 **5 秒内连续点按 5 次**（触屏点按或鼠标点击均可）。

面板内容：

- **今日数据**：今日练习次数、今日正确率、当前错题数、连续打卡天数、当前段位
- **清除所有数据**：点击后需确认，确认后清空全部练习数据（打卡、错题、成就、历史最佳），**不可恢复**，请谨慎使用

## 6. 数据存储说明

- 所有数据保存在本机浏览器的本地存储中（键名 `redtools.math.v1`），不联网、不上传
- 清除浏览器数据、更换设备或卸载浏览器会导致数据丢失
- 暂无云端同步；需要换设备前，建议先记录当前段位与历史最佳

## 7. 常见问题

**为什么答错后会停顿约 1.4 秒？**
那是展示正确答案的时间，让孩子看清错在哪里。答对时停顿 0.6 秒，节奏更快。

**挑战模式切到后台或别的 App 会怎样？**
计时会自动暂停，回到页面后继续倒计时，不会白白扣时间。

**清除数据后还能恢复吗？**
不能。清除操作会直接删除本地存储，确认前请三思。

**数据会同步到其他设备吗？**
不会。数据只保存在当前设备的浏览器里。

**分数和小数都能输入吗？**
可以。用 `/` 输入分数、用 `.` 输入小数，系统会自动做等价判断（如 `3/2` 与 `1.5` 都算对）。

**需要网络吗？**
不需要。解压后完全离线可用。
