## 需求摘要

- **玩法**：4 张数字牌，用 `+ − × ÷` 和括号算出 24；每张牌恰好用一次；允许中间分数
- **模式**：自由练习（单题无限时）/ 每日挑战（10 题总计时，完成即打卡）
- **难度**：入门（1-9，无必需 ÷）/ 进阶（1-10，含 × ÷）/ 挑战（1-13，需 ÷ + 多级括号）
- **出题引擎（核心创新）**：`solve24` 归并求解器 → 难度特征归类 → 重抽至满足 → **100% 可解**，
  零题库、零素材，运行时即时出题
- **交互**：表达式构造器（点牌带数 + 运算符/括号按钮 + 实时结果预览），手机无键盘输入；
  判定用自写中缀解析器（**无 eval**，CSP 合规）
- **反馈**：提交正确绿色打勾进下一题；错误红色提示可改；提示按钮（用提示不改 best）
- **成绩**：星级（用时常模，待实测校准）+ 各难度 best + recent10 + 连续打卡（`math24_*` 前缀）
- **形态**：离线 zip 静态工具（datasource=static），无图片无音频，包体 <0.1 MiB；Chrome 61 基线
