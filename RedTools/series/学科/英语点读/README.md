## 功能清单（v1.1）

- 点读模式：热区虚线框 + 点击播放 + 高亮 + 中英字幕
- 顺序模式：自动连播 + 上一条/下一条/重听本页/重播当前句/暂停继续 + 重复×2 + 变速四档
- 自动连播开关（本页播完自动翻下一页，末页提示）
- 翻页：封面/‹/›/末页 + 触屏滑动
- 设置记忆（模式/重复/变速/自动连播 localStorage）
