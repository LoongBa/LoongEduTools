## 需求摘要（草案）

- **英语认词专项**：PEP 教材词汇翻转卡片（正面英文 → 翻面中文）+ 简单两级记忆曲线（学习中→已掌握）
- 目标用户：preK–K1-3（L1–L2），与打字背单词（拼写）错位，本工具是**认词**（看英文知中文）
- 形态：离线 zip，**datasource="vocab"**（复用打字背单词 PEP 11 册词库解析管线，978 词构建期注入 data.js）
- 核心功能：
  - F1 选书选单元：首页 → 11 册（年级+册次+词数）→ 单元列表 → 进入学习
  - F2 翻转卡片：正面英文大字，点击 CSS 3D 翻面显示中文 + 单元归属；支持手动翻回
  - F3 记忆曲线（两级简化）：每卡翻面后点「认识 ✓」（连认识 2 次 → 已掌握）或「不认识 ✗」（回炉待复习，本学习轮次优先重出）；已掌握卡不再出
  - F4 学习轮次：每轮 10 卡（待复习优先 + 新词补足），完成 → 打卡 + 成绩（认识率/用时/待复习数）
  - F5 我的词卡：已掌握词数 / 待复习词数统计 + 全部已掌握
  - F6 打卡 + 星星 + 成绩 + 家长面板（复用既定模式，key `redtools.flash.v1`）
- 差异化：认词（闪卡） vs 拼写（打字背单词）；两级队列即"记忆曲线"最小闭环（不引入复杂 SRS 公式，L1-L2 够用）
- 合规：Chrome 61（ES2017 / 无 gap/aspect-ratio/clamp/:has）、CSP 无内联、卡片翻转用 CSS transform 3D（参照翻牌记忆配对）
