## 需求摘要（已确认设计决策）

- **玩法**：看中文释义 → 屏幕虚拟键盘拼写英文单词；答对进下一题，答错即时反馈
- **词库**：PEP 人教版小学英语 11 册全量词汇（按单元组织，数据驱动按册构建）
  - 9 册：`_音频素材/*Words_in_each_unit_en_cn.txt`（独立词汇表）
  - 三下/五上/五下：整册 `英语（PEP）..._en_cn.txt` 中 `Words in each unit` 区块（格式一致）
  - 统一格式：`英文行 + 中文释义行 + 空行` 配对，`Unit N` 标题行分隔；构建期清理星号/HTML/括号注释
- **方向**：中→英为主（看中文释义拼写英文）
- **输入**：屏幕虚拟键盘为主（手机端），同时兼容实体键盘（教室电脑投影）
- **发音**：第一版**不带发音**，纯打字拼写（轻量 0.05 MiB），后续版本可加
- **成绩/打卡**：复用通用需求（打卡/成绩记录），模式对齐 24点/数学口算
- **形态**：数据驱动静态工具（词库 json 构建期注入 data.js），离线 zip，Chrome 61 基线
