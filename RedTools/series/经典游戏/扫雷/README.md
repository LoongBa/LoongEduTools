# 扫雷（经典游戏）

> 经典 Windows 扫雷，逻辑推理+概率判断训练，自带情怀流量；经典游戏系列第 2 款（P3，见
> `docs/教育工具/教育工具产品矩阵规划.md` §4「经典游戏类 · 情怀引流」）。
> 工具文档见 `RedTools/docs/教育小程序/经典游戏/`（设计/使用文档）。

## 需求摘要

- **玩法**：经典 Windows 扫雷——三档难度（初级 9×9/10 雷、中级 16×16/40 雷、高级 30×16/99 雷），
  翻开数字格推理周围雷位，标旗排雷，全部非雷格翻开即胜利
- **首点安全**：首次点击（含 8 邻域共 3×3）不布雷，杜绝"首点即炸"，保证开局体验
- **操作（v1.1）**：单击翻开 / 右键或长按（350ms）标旗 / 点击已翻开数字格自动扫开周围（chord）
  + **标旗模式按钮**（触屏单击=插旗的稳定入口）+ **键盘光标**（方向键/Enter/F，PC 精准操作）
- **高级/中级横滑（v1.1）**：格子最小 14px，手机放不下时棋盘横向滚动（左右滑动看全棋盘）
- **反馈**：洪水展开 + 数字配色（经典扫雷 1~8 色）+ Web Audio 合成音效（翻开/标旗/爆炸/胜利琶音）
- **成绩**：分难度最佳用时（越小越好，localStorage 持久化，新纪录高亮）+ 总局数/胜局
- **打卡**：**胜利**一局即点亮今日，显示连续打卡天数（扫雷失败是常态，胜利才算完成练习）
- **防沉迷/自控力（v1.1）**：开局前设置单局时长（5/10/15 分钟，默认 5）+ 今日局数（3/5/10/不限，
  默认 5）；**试错局豁免**（<10s 失败的局不计今日局数）；到点温和提醒：**延迟**（时长 +5 分钟 /
  局数 +2 局，各上限 2 次）或 **我很自律，今天足够了**（记自律天数、锁今日、次日解锁）
- **结算三选（v1.1）**：再来一局（局数满时转为延迟）｜分享打卡（1080×1920 卡片 + 文案复制）｜
  我很自律，今天足够了
- **恢复**：结算前棋局自动保存（含布局/翻开/旗子/计时/首点时刻），重开自动续局；表情/新游戏重开
- **形态**：离线 zip 静态工具，纯代码（DOM/CSS 绘制 + Oscillator 音效），无图片/音频素材、
  无网络，Chrome 61 基线，包体 0.02 MiB（≪2 MiB 建议值）

