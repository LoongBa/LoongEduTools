## 需求摘要

- **玩法**：经典俄罗斯方块——10×20 棋盘 7 种方块（I/O/T/S/Z/J/L）逐一下落，
  **7-bag 随机**不连发，填满整行消除；**ghost 投影**预判落位
- **操作**：触屏滑动（左右移/上滑旋转/下滑落地）+ 键盘（方向键/WASD/空格/P）+ 5 键按钮兜底
- **快速下落选项**：侧栏开关（持久化），开启后 ↓/S 与 ▼ 按一下直接落地，快节奏玩法
- **反馈**：消行闪烁动画 + 得分上浮（温和 ≤400ms）＋ Web Audio 合成音效（移动/旋转/消行/升级/失败）
- **成绩**：本次得分 + 消行数 + 等级 + 历史最高分（localStorage 持久化，新纪录高亮）
- **打卡**：一局结束（game over）即点亮今日，显示连续打卡天数（与通用需求对齐）
- **恢复**：断局自动保存（棋盘+活动块+下一块+分数），重开自动续局；可暂停/新游戏
- **形态**：离线 zip 静态工具，纯代码（DOM/CSS 绘制 + Oscillator 音效），无图片/音频素材、
  无网络，Chrome 61 基线，包体 0.02 MiB

## 构建

```bash
python build_all.py --tool 俄罗斯方块
```

产物：`publish/经典游戏/俄罗斯方块.zip` + `俄罗斯方块-图标(1024).png` + `俄罗斯方块_解压测试版/`
