> 工具文档见 `RedTools/docs/工具文档/经典游戏/`（设计/使用文档）。

## 需求摘要

- **玩法**：经典 2048 规则——4×4 棋盘滑动合并相同数字，2/4 随机生成，合成 2048 胜利
- **操作**：触屏滑动 + 键盘（方向键 / WASD）+ 方向按钮兜底（PC 模拟器可用）
- **反馈**：合并 / 出现动画（温和 ≤400ms）＋ Web Audio 合成音效（可随手势起效，零音频文件）
- **成绩**：本次得分 + 历史最高分（localStorage 持久化，新纪录高亮标注）
- **打卡**：一局结束（game over）即点亮今日，显示连续打卡天数（与通用需求对齐）
- **恢复**：当前棋局自动保存，重开自动续局；「新游戏」重开
- **形态**：离线 zip 静态工具，纯代码（DOM/CSS 绘制 + Oscillator 音效），无图片/音频素材、
  无网络，Chrome 61 基线，包体 <0.1 MiB

## 构建

```bash
python build_all.py --tool 2048
```

产物：`publish/经典游戏/2048.zip` + `2048-图标(1024).png` + `2048_解压测试版/`
