## 1. 通用约束（所有经典游戏系列工具必须遵守）

来源：`RedTools/.skill/minitool-zip-builder/`（小红书小工具平台规范）。

| 约束 | 内容 |
|------|------|
| zip 白名单 | 仅 `jpg css gif svg png js jpeg json html woff2 webp woff`，**无音频格式** |
| CSP | 无内联脚本/eval/module；`<audio>/<video>` 禁 `data:`/`blob:` 媒体；**不自建 CSP meta**（容器统一管理） |
| 离线 | 所有资源打包在内，不联网（无外部字体/图片/库/CDN） |
| 基线 | JS: ES2017 / Chrome 61；CSS: Chrome 61 基线 + 能力检测增强 |
| 体积 | zip ≤ 10 MiB（建议 ≤ 2 MiB；纯代码游戏实测 <0.1 MiB） |
| 光敏 | 反馈动画温和（≤400ms、无强闪烁/频闪），对儿童友好 |

## 2. 系列结构：平铺无子系列

经典游戏按「情怀引流」定位，**无能力子系列**，工具平铺：

```
series/经典游戏/
├── README.md            # 系列说明 + 工具清单
├── 设计文档.md           # 本文件：系列设计规范（2048 引擎为核心可复用资产）
└── 2048/                # 工具（src/ + README.md；文档见 docs/教育小程序/经典游戏/）
```

**构建框架支持**：`build_framework.ToolConfig` 不设置 `subgroup`，`tool_dir` 解析为
`series/<系列>/<工具>/`；`dist/` 与 `publish/` 系列内平铺（`dist/经典游戏/`、`publish/经典游戏/`）。

## 3. 静态工具构建模式（经典游戏类通用）

与益智类一致，无数据源，统一走**静态工具**管线：

```
src/（index.html + assets/）──► copy_static（复制 + 剔除 icon_base.png）
                              ├─► write_static_data_js（生成 data.js，仅 meta）
                              ├─► make_static_icon（母版 + 角标「工具名」→ 128px 入包 + 1024px 到 publish/）
                              └─► package_zip → publish/<系列>/<工具名>.zip + 解压测试版
```

- `tools.py` 登记：`ToolConfig(series="经典游戏", tool="2048", version="1.0",
  datasource="static", app_name="2048")`
- 前端数据：`window.APP_DATA = { meta: { name, version, series, tool, ... }, units: [] }`
  （静态工具 units 为空，渲染不依赖它；**不要手写 data.js**，构建时生成）
- 构建/审计命令：
  ```bash
  python build_all.py --tool 2048
  python .skill/minitool-zip-builder/scripts/audit_artifact.py dist/经典游戏/2048
  ```

## 4. 可复用核心：2048 游戏引擎（本系列首个落地）

以下设计已在 2048 落地，俄罗斯方块/贪吃蛇等可复刻其「输入 → 动画 → 音效 → 得分打卡」骨架。

### 4.1 棋盘与渲染（DOM 方案，零素材）

- **数据**：4×4 二维数组 `grid`，0=空，其余为 2 的幂。
- **渲染**：16 个 `.cell` 绝对定位（JS 按百分比设置 `left/top/width/height`，间距用 padding
  模拟，**不用 flex gap / aspect-ratio**），内容 = 数字文本 + 颜色 class（`n2`~`n2048`）。
  每次移动后更新全部 cell（16 节点，性能无压力）。
- **动画**（温和 ≤400ms）：
  - 合并块：`.pop`（scale 1→1.15→1，180ms）
  - 新块：`.appear`（scale 0→1 + fade，150ms）
  - 得分数字：`.score-pop`（上浮 + scale，200ms）

### 4.2 移动与合并算法（关键，须正确）

以左移为例（右移 = 逆转行后左移再逆转；上/下 = 转置后左移再转置）：

```
slideRow(row):
  t = row 去零
  out = []
  for i in t:
    if i+1 < t.len && t[i] == t[i+1]:
      out.push(t[i]*2)   # 合并（每块每轮只合一次）
      score += t[i]*2
      i++                # 跳过被合并块
    else:
      out.push(t[i])
  while out.len < 4: out.push(0)
```

- **有效性**：移动前深拷贝 grid，移动后比较，**无变化则该方向无效**（不生成新块、不记步）。
- 新块：随机空位生成，90% = 2 / 10% = 4。

### 4.3 胜负判定

- **游戏结束**：无空位 且 无任意相邻（横向/纵向）相等。
- **胜利**：任一格 ≥ 2048（弹出成就，可「继续挑战」）。

### 4.4 输入（键盘 + 触屏 + 按钮兜底）

| 输入 | 实现 |
|------|------|
| 键盘 | `keydown`，方向键 + WASD；方向键 `preventDefault` 防滚动 |
| 触屏 | `touchstart/touchend` 计算向量：`|dx|>|dy|` 判水平，阈值 24px 防误触，绝对方向定左右/上下 |
| 按钮 | 棋盘下方向按钮（PC 模拟器/无键盘兜底，hit area ≥48×48px），见下方**左右分组布局** |

**方向按钮左右分组布局（2026-09-18 起系列默认，2048/贪吃蛇已落地，俄罗斯方块沿用）**：

```
      [↑]              [→]        ← 左组竖排：↑ ←（左手拇指）
      [←]              [↓]        ← 右组竖排：→ ↓（右手拇指）
            [新游戏]              ← 居中，位于两组下方
```

- **结构**：`.dpad` 容器 `flex + justify-content: space-between + padding: 0 10px`；
  内部两个 `.dpad-group`（`flex-direction: column` 竖排）；每个 `.dpad-btn` 之间
  `margin: 4px 0`（第一/末个用 `.dpad-group .dpad-btn` 选择器统一，不用 gap——Chrome 61 无 gap）。
- **分组语义**：左组 = 上 + 左（←↑），右组 = 下 + 右（→↓）——左右手拇指各控一组，
  双指操作不打架；手机横屏双手持机体验最佳，竖屏单手亦可够到。
- **aria-label**：每个按钮带「向左/右/上/下移动」，无障碍可读。
- **DOM 生成**：`addDirBtn(group, ch, dir)` 工厂函数，事件 `addEventListener('click')`。
- 布局原因：初版 4 按钮单行居中，双手拇指需跨屏够按、易误触；改左右分组后左右手各管一侧，
  拇指活动半径小、按错率低（2026-09-18 2048/贪吃蛇同改）。

### 4.5 音效（Web Audio 合成，零文件零包体）

音频格式不入白名单 + CSP 禁 data:/blob: 媒体 → **不使用 `<audio>`/音频文件**，用
`OscillatorNode` 合成（Chrome 61 原生支持）：

| 场景 | 合成 |
|------|------|
| 移动 | 正弦 180Hz / 40ms / 低音量 |
| 合并 | 三角 660Hz / 90ms |
| 胜利 | 上行琶音（523/659/784/1047，各间隔 120ms） |
| 失败 | 下行（400→200Hz，两短音） |

- `AudioContext` **懒创建**，首次用户手势（滑动/按键/点击）后 `resume()`（浏览器自动播放策略）。
- 全部播放失败静默忽略（`try/catch`），无音效不影响游戏。

### 4.6 得分 / 最高分 / 打卡（localStorage 通用 schema）

- key：`redtools.game2048.v1`（命名空间 `redtools.<tool>.v1`；容器内多工共享 localStorage，
  **必须带工具前缀**）。
- 结构：
  ```json
  {
    "version": 1,
    "best": 0,                       // 历史最高分（新纪录覆盖并标注）
    "games": 0,                      // 总局数
    "checkin": { "dates": [], "streak": 0 },   // 打卡（通用需求 schema）
    "cur": { "grid": [], "score": 0 }          // 当前局自动保存（重开恢复）
  }
  ```
- **自动保存**：每次有效移动后存 `cur`；打开时若 `cur.grid` 非空则恢复旧局。
- **打卡**：一局结束（game over 或胜利结算）→ 点亮今日 `YYYYMMDD`（去重、滚动 365 天）、
  重算连续天数 `calcStreak`。

## 5. Chrome 61 / 交互合规要点（经典游戏类通用）

- **JS**：ES2017 上限经典脚本（**var + function 风格**，零 `let`/`const`/`class`/箭头函数/
  `?.`/`??`/对象展开/`replaceAll`、module/import/export）、事件全部 `addEventListener`、
  DOM 构建用 `createElement + textContent`（**不用 innerHTML**）、无 eval/内联事件、
  无 fetch/XHR/Worker、localStorage 读写 try/catch 包裹
- **CSS**：无 `gap`/`aspect-ratio`/`clamp()`/`inset`/逻辑属性/`:has`/`@container`/`dvh`；
  flex 三重前缀（`-webkit-box` → `-webkit-flex` → `flex`）；正方形用
  `height:0; padding-bottom:100%` + 绝对定位子项；安全区 `var(--safe-area-inset-top, env(...))`
  双层兜底；动画双写 `@-webkit-keyframes` + `@keyframes`；`:active` 代替 `:hover`
- **触控**：按钮 hit area ≥48×48px；动画温和（合并 180ms / 新块 150ms，无频闪）
- **适配**：手机竖屏为主，PC 打开居中且内容 max-width 约 480px；
  高度用 `100vh` + `--app-height` 变量兜底（resize 时 JS 更新）
