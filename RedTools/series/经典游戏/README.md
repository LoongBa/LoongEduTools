## 系列原则

1. **经典玩法原汁原味**：不魔改核心规则，只做「战斗民族」级体验打磨（动画/音效/结算反馈）。
2. **零素材零版权风险**：棋盘/方块/砖块全部 DOM/CSS/SVG 绘制，无图片素材；音效用
   **Web Audio 振荡器合成**（无音频文件、不占包体、合规）。
3. **激励闭环**：复用通用需求（`docs/通用需求-打卡分享记录.md`）——得分/最高分持久化 +
   完成一局打卡，localStorage 键带工具前缀（`<toolId>_<key>`）。
4. **复用优先**：共享 `build_framework.py`（静态工具走 copy_static + make_static_icon）；
   后续经典游戏直接复制 2048 的 src 骨架（棋盘/输入/音效模块）按玩法裁剪。
   **贪吃蛇（v1.0）确立多模块拆分范式**：`window.SnakeApp` 命名空间 + 按依赖顺序加载
   （core→audio→game→guard→share→ui→main），每文件 ≤350 行，实时游戏主循环
   （tick/setTimeout）可复用给俄罗斯方块/打砖块。
5. **合规**：遵守 `RedTools/.skill/minitool-zip-builder/` 规范（离线、CSP、白名单、Chrome 61）。
