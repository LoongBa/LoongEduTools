# 贪吃蛇（经典游戏）

> 状态：**✅ v1.0 已构建（2026-09-18）**。
> 经典贪吃蛇，专注力+反应力+空间感知训练，自带情怀流量；经典游戏系列第 3 款（P2，见
> `docs/教育工具/教育工具产品矩阵规划.md` §4「经典游戏类 · 情怀引流」）。
> 工具文档见 `RedTools/docs/工具文档/经典游戏/`（设计/使用文档）。

## 需求摘要

- **玩法**：经典贪吃蛇——17×17 网格，蛇 3 节朝右开局，吃红色食物 +10 分/变长一节；
  **吃满 20 个食物（200 分）即胜利**；撞墙/撞自己失败
- **速度三档**：慢 200 / 中 150 / 快 100ms（默认中），顶部 tab 切档即开新局；每吃 5 个食物提速
  6%（下限 60ms），蛇越吃越快
- **操作**：触屏滑动（阈值 24px）/ 键盘方向键+WASD / 棋盘下方方向按钮；空格或 ⏸ 按钮暂停；
  **180° 掉头拦截**（转向缓冲下一 tick 生效）
- **反馈**：蛇身绿色渐变（头亮尾深）+ 食物红点 + Web Audio 合成音效（转向/吃食物/胜利琶音/失败下行）
- **成绩**：分速度档最高分（越大越好，localStorage 持久化，新纪录高亮）+ 总局数/胜局
- **打卡**：**胜利**（吃满 20 个）一局即点亮今日，显示连续打卡天数（撞死是常态，胜利才算完成练习）
- **防沉迷/自控力**：开局前设置单局时长（5/10/15 分钟，默认 5）+ 今日局数（3/5/10/不限，默认 5）；
  **试错局豁免**（<10s 失败的局不计今日局数）；到点游戏自动暂停：**延迟**（时长 +5 分钟 /
  局数 +2 局，各上限 2 次）或 **我很自律，今天足够了**（记自律天数、锁今日、次日解锁）
- **结算三选**：再来一局（局数满时转为延迟）｜分享打卡（1080×1920 卡片 + 文案复制）｜
  我很自律，今天足够了
- **恢复**：游戏进行中自动存盘（蛇/食物/得分/速度档/计时），重开自动续局；自律锁今日不恢复旧局
- **工程**：**首次多模块拆分**——7 个 JS（core/audio/game/guard/share/ui/main）挂
  `window.SnakeApp` 命名空间、按依赖顺序加载，每文件 ≤350 行（告别扫雷单文件 1353 行）
- **形态**：离线 zip 静态工具，纯代码（DOM/CSS 绘制 + Oscillator 音效），无图片/音频素材、
  无网络，Chrome 61 基线，包体 0.03 MiB（≪2 MiB 建议值）

## 构建

```bash
python build_all.py --tool 贪吃蛇
```

产物：`publish/经典游戏/贪吃蛇.zip` + `贪吃蛇-图标(1024).png` + `贪吃蛇_解压测试版/`
