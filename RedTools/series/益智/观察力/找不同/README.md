## 需求摘要

- **玩法**：左右同屏两幅场景图，找出 N 处差异；点击差异处打勾标记；找齐全部差异即过关
- **关卡生成（核心创新，零图片依赖）**：
  - 场景 = SVG 元素树（背景 + 元素列表），元素为可参数化矢量模板（太阳/云/船/鱼/花/树…）
  - 关卡 = 场景定义 + 差异描述；出题时随机选 N 个元素应用随机「差异变换」
  - 差异变换 5 种原子操作：改色 / 变位 / 缩放旋转 / 隐藏 / 替换变体
  - 渲染：左右两图共用同一 SVG 树，右图按差异描述改属性即可 —— **无需两张图片、零素材成本、包体极小（实测 0.04 MiB）**
- **场景库**：8 个场景（海边/森林/农场/太空/海底/城市/冬日/花园）× 8~10 元素 = 73 个 SVG 元素模板
- **难度**：差异数量（3 / 5 / 8 处）+ 差异明显度（色差/位移/比例）组合分级
- **反馈**：点中差异处绿色打勾锁定；点错红色提示并计数（不结束）；隐藏差异需点左图原图对应位置
- **成绩**：完成显示用时 + 找对/点错计数 + 星级；各难度最佳 + 最近成绩本地记录
- **打卡**：完成一局即点亮今日（与学科系列/舒尔特方格一致的打卡逻辑，localStorage）
- **形态**：离线 zip 静态工具（datasource=static），无网络，Chrome 61 基线，包体 0.04 MiB

## 难度与星级评级（参考，待实测校准）

| 进阶 | 5 | ≤40 秒 | ≤75 秒 | 其余 |
