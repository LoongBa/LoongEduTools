# 影子配对 — 工具说明

> 益智系列 · **观察力子系列第 2 款**（P1 影子配对，产品矩阵 §4.2；对标小象/未来之光「影子配对」类任务）。
> 适用 preK–K1-3（L1–L2）。设计/使用文档见 `RedTools/docs/教育小程序/益智/观察力/影子配对-{设计,使用}文档.md`。

## 玩法

把上面的**图案**和下面与它**形状一样**的**影子**配成一对：点一个图案（橙色高亮）→ 点它的影子，
配对成功（绿框 + ✓ 角标 + 淡出缩小）；点错影子红闪 + 错误计数，可继续重试。全部配对完成即过关。

- 三档难度（每局随机抽不同元素 × 双行独立洗牌，两行排列保证不同）：

  | key | 名称 | 对数 M | 布局 |
  |-----|------|--------|------|
  | 1 | 简单 | 3 | 上 3 实物 / 下 3 影子 |
  | 2 | 普通 | 4 | 上 4 实物 / 下 4 影子 |
  | 3 | 困难 | 5 | 上 5 实物 / 下 5 影子 |

- **影子实现（关键技巧）**：影子 = **同一元素 SVG** + CSS `filter: brightness(0)`
  （双写 `-webkit-filter` + `filter`，纯黑剪影、透明背景保留；Chrome 61 支持无前缀 filter）
  —— 不改元素 draw、不按元素算颜色，零元素库改动
- 元素库：复用找相同/找不同 `elements.js`（73 元素程序化 SVG，零图片素材）
- 星级：0 错 3 星 / 1~2 错 2 星 / ≥3 错 1 星
- 计时：进入游戏页即开始（performance.now + setInterval 100ms，⏱ 07.5 格式）
- 进度：各难度最佳（星高优先，同星比用时）/ 最近用时 / 成绩记录 / 每日打卡
  （localStorage `redtools.yingzipedui.v1`）

## 目录

```
影子配对/
├── src/
│   ├── index.html          # 入口（data.js → elements.js → main.js）
│   └── assets/
│       ├── main.js         # 游戏逻辑（配对/交互/成绩打卡，ES2017 经典脚本）
│       ├── elements.js     # 元素库（window.SCENES + window.ELEMENTS，73 元素，复用找相同）
│       ├── style.css       # 样式（Chrome 61 基线，天蓝系；影子 filter brightness(0)）
│       └── icon_base.png   # 图标母版（构建叠加角标）
└── README.md               # 本文件
```

图形全由 SVG 代码程序化生成，**无外部图片/音频/网络资源**。
