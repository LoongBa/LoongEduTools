## 核心资产：程序化关卡生成器（无图片方案）

观察力类工具（找不同 / 找相同 / 细节搜索 / 错误在哪里）共享同一套**程序化场景生成**方案，
**不依赖任何图片素材**，零版权风险、包体极小：

- **SVG 场景元素库**：背景 + 可参数化元素模板（太阳/云/船/鱼/花/树…），每个元素 = 一段
  SVG 函数（参数：位置/颜色/大小/旋转/变体）
- **差异变换原子操作（5 种）**：改色 / 变位 / 缩放旋转 / 隐藏 / 替换变体
- **出题引擎**：随机选 N 个元素 × 随机差异变换 → 每次进游戏都是新关卡
- **渲染**：左右两图共用同一 SVG 树，右图按差异描述改属性 → 无需两张图片
- 详细方案见 `RedTools/series/益智/设计文档.md` §6「观察力子系列：程序化关卡生成」

## 观察力训练通用要点

- 核心指标：**找对率**（准确率）+ **用时**（效率）双指标
- 激励：完成即打卡 + 各难度最佳成绩（家长可见进步曲线）
- 难度分级：低龄从「少差异 + 大差异」起步，避免挫败感
- 视觉：差异点要「一眼能训练、两秒找得到」；反馈动画温和（≤400ms、无频闪、光敏安全）
