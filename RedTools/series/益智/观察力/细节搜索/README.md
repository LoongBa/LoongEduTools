# 细节搜索（益智·观察力）

> 状态：🚧 开发中（v1.0）｜ 优先级：P2 ｜ 更新：2026-09-19
> 文档：`docs/工具文档/益智/观察力/细节搜索-{设计,使用}文档.md`

## 定位

观察力子系列第 3 款（P2）：**大图里找出指定小物体**——在程序化 SVG 大场景中，通过缩放/平移逐一检索目标小物。

- **能力维度**：视觉检索 + 细节观察 + 工具操作（缩放/平移），对标 Wimmelbild 找物玩法低龄化。
- **与找不同/影子配对的关系**：找不同是「两图对比」，影子配对是「形状匹配」，细节搜索是「**单图空间检索**」（目标不可见、需自行发现）——首个引入镜头交互的工具。
- **注意**：与记忆组「物品藏匿（思海拾遗）」不同——那是记位置，本作是视觉检索，归**观察力**。

## 需求草案

### 玩法
1. 选难度（简单 3 物 / 普通 5 物 / 困难 7 物）→ 随机 8 场景抽一局。
2. 大场景显示目标清单，**当前目标顶部亮显**（SVG 小卡 + 名称）。
3. 工具条：🔍 放大 / 🔍 缩小 / 🔄 还原 + ⬆⬇⬅➡ 平移（缩放时可用）。
4. 找到当前目标 → 点击命中 → 绿勾 + 下一目标；点错 → 红闪 + 错误计数。
5. 全部找到 → 星级结算 + 打卡。

### 素材方案（★核心）
- **零图片素材**：8 场景背景 + 73 元素库（`scenes.js` 复制自找不同，480×320 viewBox）+ 藏物 = 元素库副本缩小随机摆放。
- 藏物与场景元素同源 → 天然相似干扰（如海边藏小螃蟹，背景已有大螃蟹）。
- 禁止位图/AI 图路线：不可复现、bbox 判定差、体积不可控（详见设计文档素材方案节）。

### 技术要点
- 缩放：动态改 SVG `viewBox`（Chrome 61 支持），按钮式（非手势），档位 1 / 1.5 / 2.2。
- 命中：SVG 内 pointer-events 由浏览器按 viewBox 自动换算，**无需屏幕坐标手算**。
- 藏物：随机采样 + 碰撞避让（与固有元素/藏物 hitR 圆心距），边距保护。
- 存储：`redtools.xijiesousuo.v1`；星级/打卡/最佳/历史全套复用。
- 提示：✋ 提示按钮高亮当前目标 2s，每局 ≤2 次，使用则星级 ≤2★。
