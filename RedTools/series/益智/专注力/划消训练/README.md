# 划消训练 — 工具说明

> 益智系列 · 专注力子系列第 3 款（P2 划消训练，抗干扰选择训练，对标经典划消测验 Cancellation Test）。
> 设计/使用文档见 `RedTools/docs/教育小程序/益智/专注力/划消训练-{设计,使用}文档.md`。

## 玩法

每轮显示一个**目标图案**（大卡）+ 满屏卡片：其中若干个与目标**完全一致**（要划掉的），其余是**带小差异的相似干扰项**。
**划掉（点击 ✕）所有目标**：划对红叉标记 + 计数；点错干扰项红闪 + 错误计数（可继续划）。全部划完进下一轮，完成所有轮次过关。

- 三档难度：简单 5 轮 × 12 卡划 4 个 / 普通 6 轮 × 16 卡划 5 个 / 困难 8 轮 × 20 卡划 6 个
- 干扰项 = 差异变换（颜色/大小/位置/部件变体，难度控制强度），**渲染签名去重**保证干扰项视觉上确实与目标不同
- 元素库：复用找相同 `elements.js`（73 元素程序化 SVG，零图片素材）
- 星级：0 错 3 星 / 1~2 错 2 星 / ≥3 错 1 星
- 计时：进入游戏页即开始（⏱ 07.5 格式）
- 进度：各难度最佳（星高优先，同星比用时）/ 最近用时 / 成绩记录 / 每日打卡
  （localStorage `redtools.huaxiaoxunlian.v1`）

## 目录

```
划消训练/
├── src/
│   ├── index.html          # 入口（data.js → elements.js → main.js）
│   └── assets/
│       ├── main.js         # 游戏逻辑（差异引擎/划消判定/星级/成绩打卡，ES2017 经典脚本）
│       ├── elements.js     # 元素库（window.SCENES + window.ELEMENTS，73 元素，复用找相同）
│       ├── style.css       # 样式（Chrome 61 基线，专注力·天蓝系）
│       └── icon_base.png   # 图标母版（构建叠加角标）
└── README.md               # 本文件
```

图形全由 SVG 代码程序化生成，**无外部图片/音频/网络资源**。
