# 视觉追踪 — 工具说明

> 益智系列 · 专注力子系列第 4 款（P2 视觉追踪，眼球运动跟踪/持续注意力训练，
> 对标「目标追踪」类经典任务）。
> 设计/使用文档见 `RedTools/docs/教育小程序/益智/专注力/视觉追踪-{设计,使用}文档.md`。

## 玩法

屏幕上多个**完全相同的泡泡**缓慢漂移——开局唯一目标泡泡**高亮 1.5 秒**（这正是要追的），
高亮消失后靠**眼睛追踪**跟上它，几秒后泡泡全部停止，**点出目标泡泡现在的位置**。
点对进下一轮；点错红闪 + 错误计数（可重试）。全部轮次完成过关。

- 三档难度：简单 6 泡 · 追 3 秒 · 5 轮 / 普通 8 泡 · 追 4 秒 · 6 轮 / 困难 10 泡 · 追 5 秒 · 8 轮
- 泡泡运动：随机漂移 + 边界反弹 + 偶发变速换向（迷惑性），所有泡泡外观完全一致（唯一线索 = 视觉追踪）
- 图标库：复用翻牌记忆配对 `icons.js`（24 个程序化 SVG 图标，零图片素材）
- 星级：0 错 3 星 / 1~2 错 2 星 / ≥3 错 1 星
- 计时：进入游戏页即开始（⏱ 07.5 格式）
- 进度：各难度最佳（星高优先，同星比用时）/ 最近用时 / 成绩记录 / 每日打卡
  （localStorage `redtools.shijuezhuizong.v1`）

## 目录

```
视觉追踪/
├── src/
│   ├── index.html          # 入口（data.js → icons.js → main.js）
│   └── assets/
│       ├── main.js         # 游戏逻辑（泡泡漂移动画/目标标记/追踪判定/星级/成绩打卡，ES2017）
│       ├── icons.js        # 图标库（window.ICONS，24 图标，复用翻牌记忆配对）
│       ├── style.css       # 样式（Chrome 61 基线，专注力·天蓝系）
│       └── icon_base.png   # 图标母版（构建叠加角标）
└── README.md               # 本文件
```

图形全由 SVG 代码程序化生成，**无外部图片/音频/网络资源**。
