## 专注力训练通用要点

- 核心指标：**用时**（专注效率）+ **错误数**（准确率）双指标
- 激励：完成即打卡 + 各难度最佳成绩（家长可见进步曲线）
- 难度分级：低龄从 3×3 起步，逐步升级，避免挫败感
- 视觉：低刺激配色、大元素、无强闪烁（光敏安全）
