## 玩法

每轮显示 1 个**目标图案**（大图，上方），下方 M 个候选图案中**只有一个与目标完全相同**，
其余是同一元素的各种「小差异」变体（干扰项）——孩子快速找出相同者，抗干扰专注训练。
**点选**候选卡：相同 → 绿色闪 + 进下一轮；不同 → 红色闪 400ms + 记错一次，留在本轮可重试。
全部完成即过关。

- 三档难度：

  | key | 名称 | 轮数 | 候选数 M | 干扰明显度 |
  |-----|------|------|---------|-----------|
  | 1 | 简单 | 5 | 3 | 明显差异（改色用对比色 / 缩放大 / 变体） |
  | 2 | 普通 | 6 | 4 | 中等（改色混合对比+近似 / 缩放中 / 位移中 / 变体） |
  | 3 | 困难 | 8 | 5 | 细微（改色近似色 ±5~13% / 缩放微调 / 位移小 / 相似变体） |

- 出题：73 元素池随机抽 1 个元素（本局内不重复）→ 生成 M-1 个两两不同、且与目标不同的
  干扰项（Fisher-Yates 洗牌布阵，答案位置每轮随机）→ 每局全新
- 星级：0 错 3 星 / 1~2 错 2 星 / ≥3 错 1 星
- 计时：整局计时，游戏页渲染即开始（performance.now + setInterval 100ms，⏱ 07.5 格式）
- 进度：各难度最佳（星级高优先，同星比用时）/ 最近用时 / 成绩记录 / 每日打卡
  （localStorage `redtools.zhaoxiangtong.v1`）

## 元素库与差异变换

`src/assets/elements.js` 内 `window.ELEMENTS`：**8 场景 73 个程序化 SVG 元素**（展平 + 按 id 去重），
来自 `益智/观察力/找不同/src/assets/scenes.js` 复制改编——元素 draw 函数原样保留，
完全兼容 `{ fill, variant }` 参数（改主色 / 切换外观变体）；同时保留 `window.SCENES` 向后兼容。
每轮目标 = 元素原样渲染（fill 主色 / variant 0 / 缩放 1 / 居中）。

差异变换（复用找不同 `applyDiff` 思路，作用于单元素卡片）：

| 操作 | 说明 | 难度控制 |
|------|------|---------|
| recolor | 改主色 | 难度 1 用 palette 对比色；难度 2 对比/近似混合；难度 3 近似色 shade(±5~13%) |
| scale | 缩放 | 难度 1 大（1.4/0.7）；难度 2 中（1.25/0.8）；难度 3 微调（±8~13%） |
| variant | 替换变体 | 切换 draw 的 variant 参数（等价找不同「替换变体/隐藏部件」类差异），仅 variantMax>0 元素可用 |
| move | 卡片内位移 | 难度 2 中距离（10~16px）；难度 3 小距离（5~9px）；难度 1 不用 |

同轮内干扰项按「渲染后的卡片 SVG 串」去重（包含位移/缩放变换与颜色/变体），
保证干扰项视觉上两两不同、且都不等于目标（防止部分元素 draw 忽略 fill 导致改色无效出现两张相同卡）。

## 目录

```
找相同/
├── src/
│   ├── index.html          # 入口（data.js → elements.js → main.js）
│   └── assets/
│       ├── main.js         # 游戏逻辑（出题/差异引擎/交互/成绩打卡，ES2017 经典脚本）
│       ├── elements.js     # 元素库（window.SCENES + window.ELEMENTS 73 元素池）
│       ├── style.css       # 样式（Chrome 61 基线，专注力·清爽蓝绿）
│       └── icon_base.png   # 图标母版（构建叠加角标）
└── README.md               # 本文件
```

图形全由 SVG 代码程序化生成，**无外部图片/音频/网络资源**（icon_base.png 除外，仅作图标母版）。
