## 子系列原则

1. **有标准答案判定**：执行结果盘面 vs 目标盘面（程序可判，非表现性分数）——合规安全区核心。
2. **编程思维培养**：编排 → 执行 → 观察 → 调试（顺序/规划/优化），非直接控制玩法。
3. **复用优先**：关卡/解析/求解基准复用推箱子资产；概念关卡演进（顺序 → 循环 → 条件）。
4. **零素材**：SVG 程序化盘面，符合离线包体目标。
5. **低龄友好渐进**：不一步上完整 if/else → 先用「🧱 前方探测」（单条件判断）入门，
   完整条件分支/参数化/嵌套循环留后续（设计文档 §9）。

## 规划

- ✅ 顺序指令（v1.0）→ ✅ 循环指令（v1.1）→ ✅ 条件指令「前方探测」（v1.3）——概念三件套完成
- 后续候选：完整 if/else 分支、参数化移动（走 N 步）、嵌套循环、关卡编辑器（孩子自建迷宫题）
- 转型候选（矩阵 §10 阶段 D）：方块排列指令（俄罗斯方块）、合并策略编程（2048）、循环指令（测速）
