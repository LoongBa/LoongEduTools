## 子系列原则

1. **有标准答案判定**：执行结果盘面 vs 目标盘面（程序可判，非表现性分数）——合规安全区核心。
2. **编程思维培养**：编排 → 执行 → 观察 → 调试（顺序/规划/优化），非直接控制玩法。
3. **复用优先**：关卡/解析/求解基准复用推箱子资产；后续扩展概念关卡（循环/条件）。
4. **零素材**：SVG 程序化盘面，符合离线包体目标。

## 规划

- 概念教学关卡（顺序 → 循环 → 条件）；
- 扩展关卡区段（11-15 → 全 155 关）；
- 后续转型候选：方块排列指令（俄罗斯方块）、合并策略编程（2048）、循环指令（测速）。
