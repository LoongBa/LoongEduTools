## 1. 需求草案

### 1.1 背景与问题

| 编号 | 优先级 | 问题 | 现状 |
|------|:---:|------|------|
| D3-1 | 高 | 经典游戏类「俄罗斯方块」🔒 推迟（版号政策：无标准答案、下落消除 = 表现性玩法） | 源码保留、不宣传不迭代（`series/经典游戏/俄罗斯方块/`） |
| D3-2 | 高 | 编程教学线只有 1 款工具（机器人走迷宫），概念覆盖「移动型」路径编程，缺「构建型」布局编程 | 系列 README §规划：转型候选含「方块排列指令（俄罗斯方块）」 |
| D3-3 | 中 | 低龄儿童需「旋转 + 参数化移动」的空间编程训练（走迷宫只有 ↑↰↱ 无旋转维度） | 机器人走迷宫指令集无旋转、无参数化移动 |

### 1.2 目标

- **玩法**：给定目标布局（由 N 个四格骨牌堆成的图案），孩子为每块骨牌编排指令
  （↻ 旋转 / ⬅➡ 左右移 N 格 / ⬇ 落下）→ 执行落定 → 全部块落完 → 程序比对布局。
- **判定**：最终网格 vs 目标网格逐格比对 = 有标准答案（合规安全区核心，同走迷宫）。
- **概念教学**：顺序（逐块放置）+ 参数化移动（移 N 格）+ 旋转（空间变换）+ 空间规划
  （看目标布局反推每块位置）——补全编程教学线「构建型」维度。
- **星级**：指令步数 vs 最优解（程序可算：每块旋转次数 + 水平格数 + 1 落下）→ ≤1.5× 3★。
- **形态**：离线 zip 静态工具 + 双模式（offline/online），零素材（SVG/Canvas 程序化渲染）。

### 1.3 玩法细节（MVP 草案）

1. **盘面**：俄罗斯方块式网格（简单 6×6 / 普通 8×8 / 挑战 10×10）；
2. **目标布局**：右侧/下方显示半透明目标图案（由 K 块四格骨牌堆成）；
3. **逐块放置**：当前骨牌从顶部中间出现，孩子编排指令 chips（↻ 旋转 ×1/×2/×3、⬅ 左移 N、➡ 右移 N、⬇ 落下）→ ▶ 执行 → 动画落定 → 下一块；
4. **判定**：全部 K 块落完 → 最终网格 = 目标网格 → 过关；不等 → 差格提示（「还有 M 格没对上」）+ 定位提示。
5. **关卡生成**：程序化——随机取 K 块（类型/旋转/落下列随机）→ 模拟逐块落下堆叠生成目标布局；生成过程即保证可达（必有解）；每块记录 (类型, 旋转, 落下列) → 最优解 = 各块最少指令之和。

### 1.4 范围（MVP）

- 指令：旋转 ×1/×2/×3 + 左移/右移（可重复叠加）+ 落下；▶ 执行 / ↺ 清空 / ⟲ 重置；
- 三档难度：简单（2 块 · 6×6）/ 普通（4 块 · 8×8）/ 挑战（6 块 · 10×10）；
- 判定：布局比对 + 差格提示 + 星级 + 打卡 + best/recent（复用通用模式）；
- 双模式接入（LX_SHARED.storage，键名 `redtools.fangkuai.v1`）；
- 概念教学卡（每关标题如「旋转让方块转向」「移 3 格对齐」）。

### 1.5 非目标（MVP 不做）

- 不做消行/下落速度/得分（那是游戏残留）；
- 不做多块整体编排（一次编完全部块）——低龄逐块更直观，留后续迭代；
- 不做 7-bag 随机（那是游戏机制）——生成器按关卡设计随机即可；
- 不做 if/else / 循环指令（机器人走迷宫已有条件/循环概念，本工具聚焦旋转+参数化）。
