## 需求摘要

- **玩法**：打乱一组「小故事」卡片，按**故事情节发生顺序**排好（点选两张交换位置）——
  与逻辑思维「因果排序」同款交互（点选交换），卡片内容改为**叙事场景**（人物/物品/地点连贯的小故事）。
- **难度（三档，按卡片步数）**：简单 3 步 / 普通 4 步 / 困难 5 步（同因果排序）。
- **序列库（stories.js）**：`window.STORIES`，8 条叙事序列（共 32 张卡），
  全部程序化 SVG 绘制（viewBox `-65 -65 130 130` 居中，糖果色童趣扁平风），**零图片素材**。
- **交互**：点选一张卡（绿色描边高亮）→ 点另一张 → 交换位置（弹跳动画 280ms + 合成音效，步数 +1）；
  点已选中卡片取消选中；全部归位（`cards[i].stepIdx === i`）→ 绿色闪烁 400ms → 结算浮层。
- **提示**：高亮第一张错位卡 1.2s（不自动归位），提示次数 +1，星级封顶 2★。
- **星级（= f(提示, 步数)）**：★★★ 提示 0 且 步数 ≤ N×2−1（3→5、4→7、5→9）；
  ★★ 提示 ≤1 且 步数 ≤ N×3（3→9、4→12、5→15）；其余 1★（完成即 1★）。
- **计时/成绩/打卡**：performance.now + interval 整局计时；各难度最佳（星级高优先，
  同星级比用时）/ 最近 / 历史 30 条 / 每日打卡（localStorage `redtools.tushuopaixu.v1`）。
- **形态**：离线 zip 静态工具（datasource=static），无图片素材，无网络，Chrome 61 基线，包体 <0.1 MiB。

## 难度与星级评级（同因果排序）

| 难度 | 步数 | 3★ | 2★ | 1★ |
|------|:---:|------|------|------|
| 简单 | 3 步 | 提示 0 且步数 ≤5 | 提示 ≤1 且步数 ≤9 | 完成即 1★ |
| 普通 | 4 步 | 提示 0 且步数 ≤7 | 提示 ≤1 且步数 ≤12 | 完成即 1★ |
| 困难 | 5 步 | 提示 0 且步数 ≤9 | 提示 ≤1 且步数 ≤15 | 完成即 1★ |
