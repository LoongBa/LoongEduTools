# 反义词配对 — 工具说明

> 益智系列 · 语言子系列第 2 款（P2 反义词配对，词汇/语义理解训练）。
> 设计/使用文档见 `RedTools/docs/工具文档/益智/语言/反义词配对-{设计,使用}文档.md`。

## 玩法

把**意思相反的词**配成一对：点第一张词卡（选中）→ 点第二张（判定）——互为反义词 →
配对成功（绿标 ✓ + 淡化）；配错红闪 + 错误计数（可重试）。全部配对完成过关。

- 三档难度：简单 3 对（6 张）/ 普通 4 对（8 张）/ 困难 5 对（10 张）
- 词库：内置 28 对常用反义词（大-小、热-冷、开心-难过、上-下…），每局随机抽 + 洗牌，不背题
- 词卡 = 大字词语 + emoji 辅助图标（零素材：纯文字 + 系统 emoji）
- 星级：0 错 3 星 / 1~2 错 2 星 / ≥3 错 1 星
- 计时：进入游戏页即开始（⏱ 07.5 格式）
- 进度：各难度最佳（星高优先，同星比用时）/ 最近用时 / 成绩记录 / 每日打卡
  （localStorage `redtools.fanyicidui.v1`）
