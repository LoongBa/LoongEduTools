# 点击反应测试（益智 · 反应力）

> 状态：**开发中（v1.0 首版）**。
> 经典反应时间测试：屏幕等待变绿 → 变绿瞬间点击 → 测出反应毫秒数，多次取平均，
> **自带晒分传播**（分享卡片 + 复制文案），反应力训练 P0 首款（见 `docs/教育工具/教育工具产品矩阵规划.md` §4.6）。
> 打卡/成绩/计时通用能力复用 `series/益智/设计文档.md` 与 `RedTools/docs/通用需求-打卡分享记录.md`。
> 工具文档见 `RedTools/docs/教育小程序/益智/反应力/`（设计/使用文档）。

## 需求摘要

- **玩法**：每局进行 N 次单次反应测试。每轮：红屏等待（随机 2~5 秒）→ 屏幕变绿 → 尽快点击 →
  记录单次反应毫秒；全部轮次完成后取**平均毫秒**结算。
  - 变绿前点击 = 犯规（⛔ 太快了！），本轮作废重新等待（不计入统计）。
- **难度（三档，按测试轮数）**：简单 3 次 / 进阶 5 次 / 挑战 8 次（低龄友好，轮数越少越易坚持）。
- **成绩指标**：平均反应毫秒（主，越小越好）+ 单次成绩列表（次）；星级按平均毫秒评级。
- **星级（参考常模，待实测校准）**：平均 ≤280ms → 3★；≤400ms → 2★；否则 1★。
- **评分标签**：≤200ms 神速 / ≤280ms 闪电 / ≤350ms 优秀 / ≤450ms 不错 / >450ms 加油。
- **持久化**：各难度最佳（平均 ms）+ 最近成绩 + 历史滚动 30 条 + 打卡日历（完成一局自动点亮）。
- **晒分传播（核心卖点）**：结算浮层【分享打卡】→ canvas(1080×1920) 分享卡片
  （平均毫秒大字 + 等级 + 打卡天数 + 鼓励语）+ 一键复制文案（textarea + execCommand，Chrome 61 兼容）。
- **输入**：全屏大点击区（触屏为主），等待/点击两态；顶部返回可中途退出。
- **形态**：离线 zip 静态工具（datasource=static），无图片素材（纯 CSS 红/绿状态），
  无网络，Chrome 61 基线，包体 <0.1 MiB。

## 难度与星级评级（参考，待实测校准）

| 难度 | 测试轮数 | 3★ | 2★ | 1★ |
|------|:---:|------|------|------|
