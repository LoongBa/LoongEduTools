# 反应力子系列（益智）· README

> 反应力训练：测反应速度、快速响应能力，经典玩法家长零认知成本，**自带晒分传播**。
> 排期见 `RedTools/docs/产品矩阵规划.md` §4.6；系列通用规范见 `series/益智/设计文档.md`。
> 更新：2026-09-19

## 子系列定位

| 项 | 说明 |
|---|---|
| 子系列 | 反应力（益智七大能力之一） |
| 目标用户 | 小学生 / 家长（家庭训练）/ 教师（课堂） |
| 核心价值 | **红→绿反应测试毫秒数即时反馈 + 分享卡片/文案晒分传播**（家长愿意发笔记引流的形态） |
| 对标 | humanbenchmark.com 反应时间测试 / 小象脑力「反应力」组 |

## 工具清单

| 工具 | 优先级 | 状态 | 版本 | 说明 |
|------|:---:|------|------|------|
| 点击反应测试 | P0 | ✅ 已构建 | v1.0 | 红屏等待→变绿点击测反应毫秒；三档轮数（3/5/8）取平均；犯规重来；平均毫秒星级 + 晒分传播（分享卡片 + 复制文案）+ 成绩打卡 |
| 手速挑战 | P1 | ✅ 已构建 | v1.0 | 限时点击速度测试（CPS）；3-2-1 准备倒计时 + 三档时长（5/10/15 秒）+ 总点击数/CPS 实时反馈 + CPS 星级 + 晒分传播（分享卡片 + 复制文案）+ 成绩打卡 |
| 颜色反应 | P2 | ✅ 已构建 | v1.0 | Stroop 字色干扰（看字的颜色不是字义）；三档难度（同义/异义/混合+60秒限时）+ 答错展示正确答案（学习反馈）+ 星级 + 晒分传播（分享卡片 + 复制文案）+ 成绩打卡 |
| 接物品游戏 | P2 | 📋 待建 | — | 手指移动接物品，躲炸弹 |
