# 因果排序 — 工具说明

> 益智系列 · 逻辑思维子系列第 5 款（P2 因果排序，产品矩阵 §3.4，对标小象/未来之光「因果关系排序」类任务）。
> 适用 K1-3–K4-6（L2–L3）。玩法：打乱卡片，按因果 / 时间顺序排好。
> 设计/使用文档见 `RedTools/docs/工具文档/益智/逻辑思维/因果排序-{设计,使用}文档.md`。

## 定位

小象/未来之光「因果关系排序」类任务的低龄本地版：把一组「事情发生先后」的卡片
（程序化 SVG 绘制，零图片素材）打乱，小朋友点选两张卡片交换位置，全部排对即过关。
从「先…后…」的直观图像中建立因果 / 时间顺序感。

## 玩法

- 三档难度（按卡片步数）：

  | key | 名称 | 步数 | 序列池（随机取 1） |
  |-----|------|------|--------------------|
  | 3 | 简单 | 3 | 昼夜三部曲 / 花开三部曲 |
  | 4 | 普通 | 4 | 晨起流程 / 蝴蝶成长 / 做蛋糕 / 青蛙成长 |
  | 5 | 困难 | 5 | 植物生长 / 洗手流程 |

- 输入：点选一张卡片（橙色描边高亮）→ 点另一张 → 交换位置（弹跳动画 280ms +
  轻柔音效，步数 +1）；点已选中卡片取消选中
- 题面：顶栏显示序列名「把『植物生长』按顺序排好」，底部「步数 n · 提示 n」实时统计
- 归位判定：`cards[i].stepIdx === i`（数组槽位 = 正确步序）；全部归位 → 绿色闪烁
  400ms → 结算浮层
- 提示：高亮第一张错位卡片 1.2s（温和脉冲，不自动归位），提示次数 +1，星级封顶 2★
- 星级（= f(提示, 步数)）：★★★ 提示 0 且 步数 ≤ N×2−1（3→5、4→7、5→9）；
  ★★ 提示 ≤1 且 步数 ≤ N×3（3→9、4→12、5→15）；其余 1★（完成即 1★）
- 计时：游戏页渲染起算（performance.now + setInterval 100ms，⏱ 07.5 格式），整局计时
- 进度：各难度最佳（星级高优先，同星级比用时，仅严格更优覆盖）/ 最近用时 / 成绩记录 /
  每日打卡（localStorage `redtools.yinguopaixu.v1`）；无断局恢复（v1.0）

## 序列库（causals.js）

`src/assets/causals.js` 内 `window.CAUSALS`：8 条序列 / 32 张卡片，全部程序化 SVG 生成
（viewBox `-65 -65 130 130` 居中，糖果色童趣扁平风），**零图片素材**。

| id | 序列 | 步数 | 因果递进视觉 |
|----|------|------|--------------|
| daycycle | 昼夜三部曲 | 3 | 粉霞半轮日出 → 蓝天烈日 → 橘红低垂日落 |
| bloom | 花开三部曲 | 3 | 闭合花苞 → 花瓣尖探出 → 六瓣盛开 |
| morning | 晨起流程 | 4 | 起床 → 洗漱 → 早餐 → 背书包出门 |
| butterfly | 蝴蝶成长 | 4 | 叶上虫卵 → 毛毛虫 → 挂枝的蛹 → 展翅蝴蝶 |
| cake | 做蛋糕 | 4 | 搅拌面糊 → 烤箱烘烤 → 裱奶油 → 成品蛋糕 |
| frog | 青蛙成长 | 4 | 蛙卵 → 小蝌蚪 → 长腿蝌蚪 → 青蛙 |
| plant | 植物生长 | 5 | 播种 → 发芽 → 长叶 → 开花 → 结果 |
| wash | 洗手流程 | 5 | 开水 → 打肥皂 → 搓手起泡 → 冲水 → 擦干 |

每条序列 `steps` 数组顺序即正确因果顺序（`steps[0]` 最先）；难度池按序列 id 硬编码在
`main.js` 的 `SEQ_POOL`。

## 目录

```
因果排序/
├── src/
│   ├── index.html          # 入口（data.js → causals.js → main.js）
│   └── assets/
│       ├── causals.js      # 序列卡片库（window.CAUSALS，8 序列 32 卡，纯 SVG）
│       ├── main.js         # 游戏逻辑（交换排序/提示/成绩打卡，ES2017 经典脚本）
│       ├── style.css       # 样式（Chrome 61 基线，天蓝系 + 绿色点缀）
│       └── icon_base.png   # 图标母版（构建叠加角标）
└── README.md               # 本文件
```

纯代码 + 母版图标，**无外部图片/音频/网络资源**，包体极小。
