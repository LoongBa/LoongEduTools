# 蜡笔物理

> 益智系列 · 逻辑思维（问题解决）小工具。核心玩法源自经典《Crayon Physics Deluxe》（蜡笔物理学）：
> **画一笔 → 变成刚体 → 借助重力/杠杆/碰撞，让红色小球滚到黄色星星。**
> 与 `docs/草稿/蜡笔物理原型` 的关系：原型存在「画面抖动、画出的物体不掉落」等 bug，
> 本工具为**全新实现**（渲染零抖动 + 物理手感修正 + 关卡制 + 星级打卡），不改动原型代码与原型开发方案。
>
> 产品矩阵定位：逻辑思维 · 问题解决（对标推箱子/迷宫寻路同子系列）；产品排期见
> `RedTools/docs/产品矩阵规划.md` §4.4。设计/使用文档见 `RedTools/docs/工具文档/益智/逻辑思维/`。

## 需求草案

- [x] 手绘笔画（鼠标/触控）→ 刚体化（凹形笔画凸分解焊接）
- [x] 红色小球 + 黄色星星 + 触星过关
- [x] 10 个教学关卡（斜坡→搭桥→跷跷板→撞落→翻越→综合），数据驱动 + 参考解法
- [x] 橡皮擦 / 撤销 / 重置 / 6 色蜡笔 / 音效 / 静音
- [x] 过关星级（笔画数基准）+ 打卡 + 成绩记录（localStorage）
- [x] 渲染零抖动：静态层离屏预烘焙 + 笔画 sprite 化（修复原型抖动 bug）
- [x] 物理手感修正：重力调校 + 创建重叠抬升防卡死（修复原型"物体不掉落" bug）
- [x] Chrome 61 基线、离线 zip、无素材（物理库内联）
