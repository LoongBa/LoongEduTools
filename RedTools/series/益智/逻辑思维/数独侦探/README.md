## 玩法

经典数独：点选空格 → 底部数字条点数字填入，目标让每行 / 每列 / 每宫（粗线框）都只出现一次 1~N。
全部填满且无冲突即过关。**每次进入随机生成全新盘面**（随机挖洞，保证唯一解）。

- 三档难度（双参数：盘面尺寸 × 目标已知格）：

  | key | 名称 | 盘面 | 目标已知格 | 约挖空 |
  |-----|------|------|-----------|--------|
  | 4 | 简单 | 4×4 | 10 | ~6 空 |
  | 6 | 普通 | 6×6 | 21 | ~15 空 |
  | 9 | 困难 | 9×9 | 33 | ~48 空 |

  （生成器实际已知格落在 [目标, 目标+4]，顶栏显示实际值。）

- 输入：点选格子 + 底部数字条（1..N 按钮 ≥48px）；实体键盘 1-9 / Backspace / Delete 增强
- **规则教学（v1.3）**：难度页「📖 规则教学」入口 → 4×4 演示盘三步讲解（行 → 列 → 宫不重复），每步高亮对应约束格 + 引导填空，末步「开始挑战」回难度页；可上一步/跳过
- **技巧教学关（v1.4/v1.5）**：难度页技巧入口（单宫排除 / 行列排除 / 区块排除）→ 独立教学关（4×4 简化盘，逐步引导落子 + 讲解），完成点亮技巧徽章（localStorage `store.skills`）；独立标记不计普通进度、可跳过、可重练；**技巧徽章墙（v1.5）**：难度页「🏆 技巧徽章墙」入口 → 展示全部技巧徽章点亮状态（✅ 已点亮 / 🎯 可学习 / 🔒 即将上线）
- 反馈：合法落子绿色确认（答错不惩罚，静默接受）；冲突红闪 400ms + 温和提示，错误计数 +1
- 教具高亮：选中格橙色描边，同行/列/宫浅蓝 tint，同数字格子浅橙 tint
- 工具：橡皮（清选中格，含候选笔记）/ 撤销（恢复上一步，含提示/橡皮/笔记均可撤）/ 提示（自动找候选最少格填正确解）/ **✏ 铅笔模式（候选笔记）**：切换后点数字在格子里记候选数，再点取消；行/列/宫已有该数时拒绝并温和提示
- 自动铅笔：普通或提示落定某数后，同行/列/宫其他格的该候选数自动清除（持续同步约束）
- 星级：0 提示 0 错 → 3★；提示 ≤1 且 错 ≤3 → 2★；其余 1★（用提示星级封顶 2★）；笔记不影响星级
- 计时：游戏页渲染起算（performance.now + setInterval 100ms，⏱ 07.5 格式），整局计时
- **断局恢复（v1.2）**：每步操作自动存对局快照（盘面/候选笔记/撤销栈/提示/错误/计时）；中途退出后难度页显示「▶ 继续上次」，续玩时计时从保存点续算；通关或重开后快照清除
- 进度：各难度最佳（星级高优先，同星级比用时）/ 最近用时 / 成绩记录 / 每日打卡
  （localStorage `redtools.shudurumen.v1`）

## 算法

`src/assets/solver.js` 内 `window.SUDOKU`，移植自 `docs/教育小程序/益智/逻辑思维/数独/数独小侦探原型/logic_test.js`
（其自身 node 测试已断言唯一解 / 已知格范围 / 解合法性），并降级为 ES2017（var + function）：

- `boxDims(N)`：宫尺寸 4→[2,2]、6→[2,3]、9→[3,3]
- `cellValid`：行/列/宫冲突判定
- `fillBoard(N)`：随机回溯完整解
- `solveCount(board,N,limit)`：解计数（唯一解判定）
- `genPuzzle(N,givens)`：从完整解随机挖洞，每次挖洞校验唯一解，多轮尝试逼近目标已知格
- `getCandidates` / `findHintCell`：候选few格 / 提示选格
