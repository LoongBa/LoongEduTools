# 迷宫寻路 — 工具说明

> 益智系列 · 逻辑思维子系列第 2 款（P1 路径规划，从起点到终点）。
> 设计/使用文档见 `RedTools/docs/工具文档/益智/逻辑思维/迷宫寻路-{设计,使用}文档.md`。

## 玩法

程序化生成完美迷宫（递归回溯算法，任意两格唯一路径），从迷宫左上角出发，走到右下角出口即过关。
- 三档难度：简单 7×7 / 普通 11×11 / 困难 15×15（每次进入随机生成新迷宫）
- 输入：触屏滑动 / 方向键 WASD / 十字 D-pad
- 计分：过关计时 + 步数；BFS 最短路径作为最优基准
- 星级：步数 ≤1.5× 最优 3 星、≤2.5× 最优 2 星、其余 1 星；「显示最短路径」提示用后封顶 2 星
- 足迹：经过的格子留浅色足迹标记，回顾走过的路
- 进度：各难度最佳 / 成绩记录 / 每日打卡 / 断局恢复（localStorage `redtools.migongxunlu.v1`）
