# 位置记忆 — 工具说明

> 益智系列 · 记忆力子系列第 4 款（P1 位置记忆，对标未来之光「图形追忆」）。
> 设计/使用文档见 `RedTools/docs/工具文档/益智/记忆力/位置记忆-{设计,使用}文档.md`。

## 玩法

先看一遍**图案在网格里的位置**（倒计时记忆）→ 图案全部藏起来（问号背面）→ 逐轮提示「找出这个图案」→
点中它藏的位置 → 翻回 + 绿勾；点错红闪 + 计数（可继续点）→ 全部找到过关。

- 三档难度：简单 3×3 盘 4 图案 / 普通 4×4 盘 6 图案 / 困难 4×4 盘 8 图案（每局随机布局）
- 展示时长：5 / 5 / 4 秒倒计时后自动隐藏
- 图标库：复用翻牌记忆配对 `icons.js`（24 个程序化 SVG 图标，零图片素材）
- 星级：0 错 3 星 / 1~2 错 2 星 / ≥3 错 1 星
- 计时：进入游戏页即开始（含展示倒计时，⏱ 07.5 格式）
- 进度：各难度最佳（星高优先，同星比用时）/ 最近用时 / 成绩记录 / 每日打卡
  （localStorage `redtools.weizhijiyi.v1`）

## 目录

```
位置记忆/
├── src/
│   ├── index.html          # 入口（data.js → icons.js → main.js）
│   └── assets/
│       ├── main.js         # 游戏逻辑（布局/展示倒计时/隐藏/找图判定/成绩打卡，ES2017 经典脚本）
│       ├── icons.js        # 图标库（window.ICONS，24 图标，复用翻牌记忆配对）
│       ├── style.css       # 样式（Chrome 61 基线，记忆紫系）
│       └── icon_base.png   # 图标母版（构建叠加角标）
└── README.md               # 本文件
```

图形全由 SVG 代码程序化生成，**无外部图片/音频/网络资源**。
