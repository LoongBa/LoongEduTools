# 翻牌记忆配对（益智 · 记忆力）

> 状态：**✅ v1.0 已构建（2026-09-19）**。
> 经典翻牌配对找相同（Memory/Concentration），记忆力训练 P0 首款（见 `docs/教育工具/教育工具产品矩阵规划.md` §3.3）。
> 核心方案：**程序化 SVG 图标（无图片素材）**，详见 `series/益智/设计文档.md` §4（计时/成绩/打卡复用）。
> 工具文档见 `RedTools/docs/工具文档/益智/记忆力/`（设计/使用文档）。

## 需求摘要

- **玩法**：卡片网格全部背面朝上，每次翻两张；图案相同则配对成功并锁定翻开，不同则翻回。
  全部配对完成即过关。经典记忆训练，家长认知度极高。
- **图标生成（零图片依赖）**：20+ 个童趣扁平 SVG 图标模板（太阳/云/月亮/星星/花/树/鱼/船/
  苹果/西瓜/蝴蝶/爱心/雨滴/雪人/气球/猫咪…），随机选取 N 对洗牌布阵，每次进游戏都是新布局。
- **难度**：简单 6 对（3×4）/ 进阶 8 对（4×4）/ 挑战 10 对（4×5）。
- **交互**：CSS 3D 翻转动画（正面图案 / 背面问号底纹）；配对成功绿色高亮锁定；
  配对失败红色闪烁后翻回；全部配对完成结算。
- **指标**：用时（主）+ 翻牌步数（次）；各难度最佳 + 最近成绩本地记录 + 历史滚动 30 条。
- **打卡**：完成一局即点亮今日（与学科系列/舒尔特方格一致的打卡逻辑，localStorage）。
- **形态**：离线 zip 静态工具（datasource=static），无网络，Chrome 61 基线，包体 <0.1 MiB。
