## 记忆力训练通用要点

- 核心指标：**用时**（记忆效率）+ **步数**（翻牌次数，策略质量）双指标
- 激励：完成即打卡 + 各难度最佳成绩（家长可见进步曲线）
- 难度分级：低龄从 6 对起步，逐步升级，避免挫败感
- 训练要点：鼓励「先观察记忆、再翻牌」而非盲目乱翻（步数指标引导策略）
- 视觉：卡片图案用高辨识度童趣图标（形状+颜色双重区分，适配低龄），无强闪烁（光敏安全）

## 核心资产：程序化 SVG 图标库（无图片方案）

记忆力类工具（翻牌记忆配对 / 图形序列复刻 / 位置记忆）共享同一套**程序化图标库**方案，
**不依赖任何图片素材**，零版权风险、包体极小：

- **SVG 图标库**：20+ 个可复用图标模板（太阳/云/月亮/星星/花/树/鱼/船/水果/动物…），
  每个图标 = 一个 SVG draw 函数（以 (0,0) 为中心，童趣扁平风）
- **出题**：随机选 N 个图标 × 每图标 2 张卡 → 洗牌布阵 → 每次进游戏都是新布局
- 详细方案见 `RedTools/series/益智/设计文档.md`（翻牌记忆配对落地实现）
