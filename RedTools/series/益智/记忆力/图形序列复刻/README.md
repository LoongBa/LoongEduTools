# 图形序列复刻 — 工具说明

> 益智系列 · 记忆力子系列第 3 款（P1 图形序列复刻，对标未来之光「矩阵序列」）。
> 设计/使用文档见 `RedTools/docs/工具文档/益智/记忆力/图形序列复刻-{设计,使用}文档.md`。

## 玩法

看一遍**颜色序列**（色块依次点亮）→ 按顺序点色块**复刻** → 全对进下一轮（每局 5 轮）→ 全部完成过关。
点错：红闪 + 错误计数 + 复刻进度清零并**重新播放序列**（播放不扣分，可再看一遍，低龄友好）。

- 三档难度：简单 记 3 色 × 3 色池 / 普通 记 4 色 × 4 色池 / 困难 记 5 色 × 5 色池（每局 5 轮，序列每次随机）
- 零素材：色块 = 纯 CSS 着色大按钮（红/蓝/绿/黄/紫 5 色池），无图片无音频文件
- 播放辅助：每次点亮伴随音高提示音（颜色→音高），视听双通道记忆
- 星级：0 错 3 星 / 1~2 错 2 星 / ≥3 错 1 星
- 计时：进入游戏页播放第 1 轮即开始（⏱ 07.5 格式）
- 进度：各难度最佳（星高优先，同星比用时）/ 最近用时 / 成绩记录 / 每日打卡
  （localStorage `redtools.tuxingxuliefuke.v1`）
