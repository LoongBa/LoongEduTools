# 数字记忆（益智 · 记忆力）

> 状态：**✅ v1.0 已构建（2026-09-19）**。
> 显示一串数字几秒 → 隐藏 → 凭记忆输入，答对位数 +1 递增挑战（对标小象「数字记忆游戏」），
> 记忆力训练 P0 第 2 款（见 `docs/教育工具/教育工具产品矩阵规划.md` §4.3）。
> 打卡/成绩/计时通用能力复用 `series/益智/设计文档.md` 与 `RedTools/docs/通用需求-打卡分享记录.md`。
> 工具文档见 `RedTools/docs/工具文档/益智/记忆力/`（设计/使用文档）。

## 需求摘要

- **玩法**：每局从起始位数开始递增挑战。出题显示一串数字（显示时长 = 位数 × 1 秒），
  倒计时结束数字隐藏为空格；用屏幕数字键盘逐位输入，提交判定：
  - 全对 → 答对数 +1，位数 +1 进入下一题（数字更长）；
  - 有错 → 展示正确答案（学习反馈），机会 -1，位数 +1 继续；
  - 机会（3 次）用尽 → 本局结束结算。
- **难度（三档，只改起始位数）**：简单 3 位起步 / 进阶 4 位起步 / 挑战 5 位起步。
- **成绩指标**：最高位数（主）+ 答对题数（次）+ 整局用时；星级按达到的最高位数评级。
- **持久化**：各难度最佳（最高位数）+ 最近成绩 + 历史滚动 30 条 + 打卡日历（完成一局自动点亮）。
- **输入**：屏幕数字键盘（0-9 + ⌫ 退格 + 确定），低龄友好；另支持实体键盘
  （数字键输入 / Backspace 退格 / Enter 提交）作为增强。
- **形态**：离线 zip 静态工具（datasource=static），无图片素材（数字纯 CSS 渲染），
  无网络，Chrome 61 基线，包体 <0.1 MiB。

## 难度与星级评级（参考，待实测校准）

| 难度 | 起始位数 | 3★ | 2★ | 1★ |
|------|:---:|------|------|------|
| 简单 | 3 位 | ≥5 位 | ≥4 位 | 3 位 |
| 进阶 | 4 位 | ≥6 位 | ≥5 位 | 4 位 |
| 挑战 | 5 位 | ≥7 位 | ≥6 位 | 5 位 |
