## 空间感知训练通用要点

- 核心指标：**用时**（空间推理效率）+ **步数**（交换次数，策略质量）双指标
- 激励：完成即打卡 + 各难度最佳成绩（家长可见进步曲线）
- 难度分级：低龄从 2×2 起步（4 块零计时压力），逐步升级 3×3 → 4×4，避免挫败感
- 训练要点：鼓励先看参照图规划「目标位置」再操作（局部-整体认知）；点选交换比拖拽更
  适合低龄触屏（无精确拖拽精度要求）
- 视觉：天蓝系主题，碎片缝隙清晰、选中紫色描边高亮；完成绿色闪烁 ≤400ms（光敏安全）

## 核心资产：程序化 SVG 场景切块（无图片方案）

空间感知类工具共享**程序化场景**方案，**不依赖任何图片素材**，零版权风险、包体极小：

- **场景库**：8 个正方形 400×400 童趣场景（海边/森林/太空/花园/农场/海底/冬日/城堡），
  每场景 6-9 个元素，SVG draw 函数程序化生成（scenes.js `window.SCENES`）
- **切块**：碎片 = `<svg viewBox>` 裁剪完整场景局部（viewBox 用该块「目标行列」），
  归位即恢复完整画面；零图片文件、包体≈代码体积
- **出题**：随机场景 + N×N 切块 + Fisher-Yates 洗牌 + 防「恰好还原」重洗 → 每次布局不同
- 详细方案见 `RedTools/series/益智/设计文档.md`（简单拼图落地实现）
