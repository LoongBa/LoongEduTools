# 简单拼图（空间感知 · P0）

> 益智系列 · 空间感知子系列首款。产品矩阵规划 §4.5（P0：拖拽拼合，从少块到多块）。
> 设计/使用文档：`RedTools/docs/工具文档/益智/空间感知/简单拼图-{设计,使用}文档.md`
> 更新：2026-09-19

## 定位

| 项 | 说明 |
|---|---|
| 能力维度 | 空间感知（空间关系、局部-整体认知、旋转与方位） |
| 目标用户 | 3–10 岁（L1 preK / L2 K1-3 / L3 K4-6） |
| 对标 | 小象脑力「限时拼图」/ 未来之光「像素拼图」降龄版 |
| 玩法 | 交换拼图（swap puzzle）：完整场景图切块打乱 → 点选两块交换归位 |

## 玩法设计

- **出题**：程序化生成正方形场景图（400×400 SVG，童趣扁平风）→ 切 N×N 碎片 → 洗牌打乱
- **交互**：点选一块高亮 → 点另一块交换；点已选块取消；全部归位即过关
- **难度分档**（从少块到多块）：

| 档位 | 块数 | 学段 | 3★ / 2★ 时间阈值 |
|---|---|---|---|
| 简单 2×2 | 4 块 | L1 preK | 25s / 60s |
| 进阶 3×3 | 9 块 | L2 K1-3 | 90s / 180s |
| 挑战 4×4 | 16 块 | L3 K4-6 | 240s / 480s |

- **辅助**：完整图小缩略图常显（L1/L2）；4×4 默认收起，「看原图」浮层显示 3 秒
- **闭环**：计时 + 步数 + 星级 + 最佳/最近 + 打卡 + 成绩历史（复用益智系列通用核心）

## 复用与实现

- 模板：`series/益智/记忆力/翻牌记忆配对/src/`（IIFE 经典脚本 / 难度星级 / 打卡成绩 / 结算浮层）
- 场景库：参照 `series/益智/观察力/找不同/src/assets/scenes.js`（SVG 程序化元素库）→ 正方形 400×400
- 切块：每块 `<svg viewBox="x y w h">` 内嵌完整场景（浏览器 viewBox 裁剪显示局部），零图片素材
- 存储：localStorage `redtools.jiandanpintu.v1`
- 合规：Chrome 61 基线（ES2017 / CSS 无 gap/aspect-ratio/clamp）、离线、无音频文件（可选 Web Audio 合成音）
