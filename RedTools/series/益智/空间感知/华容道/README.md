# 华容道 — 需求草案与开发记录

> 益智 · 空间感知 子系列 P2 收官款。
> 对标：经典华容道滑块游戏；产品矩阵 §4.5「华容道：滑块拼图，经典布局」（K4-6，L3）。
> 立项：2026-09-19

## 需求草案

### 玩法
- 经典华容道：4×5 盘面，滑块只能沿空白格平移，目标将「曹操」2×2 大块移到盘面底部中央出口。
- 角色化滑块（用户强调"好好设计卡通风格角色"）：
  - 曹操 2×2（目标大块）
  - 关羽 2×1（横）
  - 张飞 / 赵云 / 马超 / 黄忠 1×2（竖）×4
  - 小兵 1×1 ×4
- 交互：点选滑块 → 显示可移动方向 → 点击方向格移动（低龄友好，点选优于拖拽）；支持四方向滑动手势。
- 关卡：经典「横刀立马」起步，逐步增加经典布局（近在咫尺 / 层层设防 / 兵分三路 / 横刀立马变体…），按最少步数分级。

### 视觉
- 角色 = **程序化 SVG 手绘 Q 版三国头像**（零素材、风格统一、Chrome 61 兼容、zip 极小）
  - 差异化：曹操白脸黑须 + 黑冠、关羽红脸 + 长须 + 绿巾、张飞黑脸虬髯 + 豹眼、赵云白脸银盔红缨、
    马超白脸金/紫冠、黄忠黄脸白须、小兵统一憨厚布衣兵
  - 滑块：圆角木纹底 + 居中头像 + 底部角色名（儿童认字）
- 主题：天蓝系（与简单拼图/七巧板一致），滑块木色温暖对比

### 闭环
- 计时 + 步数双指标（空间推理效率 + 策略质量）
- 星级：按最少步数基准（BFS 构建期求解），≤1.5× 3★ / ≤2.5× 2★ / 其余 1★
- 打卡 + 各关卡最佳成绩 + 家长面板（复用益智通用核心）

## 技术方案
- 零图片素材：角色/盘面/出口全部 SVG 程序化（`characters.js` + 渲染函数）
- 关卡数据 `levels.js`：构建期转换脚本（布局文本 → 数据）+ BFS 求最少步数
- 静态工具管线（`datasource="static"`），tools.py 登记 ToolConfig
