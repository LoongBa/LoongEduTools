# 七巧板（空间感知 · P1）

> 益智系列 · 空间感知子系列第 2 款。教育工具产品矩阵规划 §4.5（P1：传统益智，拼成指定图案）。
> 设计/使用文档：`RedTools/docs/教育小程序/益智/空间感知/七巧板-{设计,使用}文档.md`
> 更新：2026-09-19

## 定位

| 项 | 说明 |
|---|---|
| 能力维度 | 空间感知（形状拼合、旋转与方位、局部-整体认知） |
| 目标用户 | 3–10 岁（L1 preK / L2 K1-3 / L3 K4-6） |
| 对标 | 传统七巧板；洪恩七巧板 / 小象脑力「积木搭建」 |
| 玩法 | 经典 7 块（2 大三角 + 1 中三角 + 2 小三角 + 1 正方形 + 1 平行四边形）拖拽旋转，拼成指定目标图案 |

## 玩法设计

- **板块**：程序化 SVG 渲染 7 块经典七巧板（零素材，质心为原点顶点 + scale/rotate/translate 变换）
- **交互**：pointer 拖拽移动 + 点选旋转按钮（每次 45°）+ 磁吸（位置 < 24px 且角度差 < 22.5° 自动吸附）
- **判定**：7 块全归位过关；移出容差自动解锁
- **难度分档**（遮挡信息递减）：

| 档位 | 学段 | 目标提示 | 图案库 |
|---|---|---|---|
| 简单 | L1 preK | 拼图区显示**分块轮廓占位**（每块目标位蓝色虚线描边） | 正方形/小房子/小鱼/小碗 |
| 进阶 | L2 K1-3 | 只显示**整体图案剪影**（outline 半透明填充） | 箭头/大鹅/小猫/小狗 |
| 挑战 | L3 K4-6 | 顶部缩略图参考，拼图区无任何提示 | 天鹅/火箭/海豚/大象 |

- **辅助**：提示按钮（高亮下一块目标位，封顶 2 次）；点选旋转 ↻ 45°；全部重置
- **闭环**：计时 + 提示次数 + 星级（0 提示 3★ / 1-2 次 2★）+ 最佳/最近 + 打卡 + 成绩历史（复用益智系列通用核心）

## 数据与合规

- **图案数据源**：OMerkel/Tangram（MIT，(c) 2019 Oliver Merkel）经典图案库，
  由 `build_tangram.py` 解析 `data/challenges.js` + `data/hmi.js` 生成 `src/assets/tangram.js`
  （自动校验：45° 步进旋转兼容、7 块无重叠、采样覆盖 outline ≥ 95%）
- localStorage key：`redtools.tangram.v1`
- 零素材（无图片/音频）；Chrome 61 基线；遵守 `.skill/minitool-zip-builder/` 规范
- 图案数据集中在 `src/assets/tangram.js`（`window.TAN = {shapes, puzzles}`），扩图案在 `build_tangram.py` SELECT 追加后重跑
