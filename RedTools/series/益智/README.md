## 构建命令

```bash
python build_all.py --tool 舒尔特方格     # 构建舒尔特方格（静态工具，无单元概念）
python build_all.py --list               # 列出已登记工具
```

## 系列原则

1. **经典玩法 + 能力训练包装**：选用家长零认知成本的经典游戏（舒尔特、找不同、翻牌配对等），
   包装为对应能力维度的训练方案。
2. **子系列分组**：工具按能力维度放在 `series/益智/<能力>/` 下，便于按能力组织排期与复用。
3. **复用优先**：共享 `build_framework.py`（静态工具走 copy_static + make_static_icon）；
   计时器/成绩记录/打卡逻辑与学科系列一致（localStorage，见通用需求文档）。
4. **合规**：遵守 `RedTools/.skill/minitool-zip-builder/` 规范（离线、CSP、白名单、Chrome 61）。
